# 高欢篇参考文字存档

这些是公版史籍的电子录文和用于对读的选段，不是扫描校勘本。经浏览工具实际读取后去除网页导航与引用标记保存；没有把终端下载失败写成成功。

《北齐书》卷一、二存正文全文；《魏书》卷十和《周书》卷二、三十一为实际对读的局部摘录。后两者包含摘录时相邻的上下文，不代表整卷均已逐字校勘。卷三十一另保存本次续读的玉壁战后短段。

网址、修订状态与 SHA-256 固定在 `web/scripts/archived-refs.json`。`npm run refs` 可从随库存档恢复 `.refs/` 中对应文件，再以 `npm run check-sources` 独立比较故事底本。普通网络抓取脚本不假装能够重现页面工具的同一份提取结果。

原作者包括李百药、魏收、令狐德棻等，古籍文字属公有领域。电子整理来源为维基文库，具体网址见上述清单；其整理贡献按该站署名与相同方式共享条款保留来源。本库白话及叙事为新编文字，未使用现代出版社译文。
