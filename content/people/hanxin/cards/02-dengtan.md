# 02 · 复习卡 · 登坛

> 原则：**问动机，不问年代。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：「国士无双」这四个字，是谁说的？**

答：**是萧何说的，说给汉王听的。**

| 谁 | 说了什么 | 出处 |
|---|---|---|
| 萧何 | 「諸將易得耳。至如信者，國士無雙。」 | `006` |
| 汉王 | 上一句是「追信，詐也」——跑掉的将军几十个你不追，追韩信，是骗我 | `006` |
| 韩信 | 这四个字里没有一个字出自他嘴里 | — |

这一句话是替别人说的：萧何在替韩信作保。把它读成韩信的自夸，就把说话的人换了。

| | |
|---|---|
| 依据 | `006`「上複罵曰：『諸將亡者以十數，公無所追；追信，詐也。』何曰：『諸將易得耳。至如信者，國士無雙。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 谁说话、对谁说、在什么语境下说；这一句是萧何的保举，不是韩信的自述 |

---

### 卡 2 · 因果

**问：萧何追韩信这一段，底本给了几个动作？**

答：五个，一步接一步。

```
005  何聞信亡 → 不及以聞 → 自追之
     人有言上曰「丞相何亡」→ 上大怒，如失左右手
     居一二日，何來謁上 → 臣不敢亡也，臣追亡者
     上曰：若所追者誰何？→ 曰：韓信也
```

要紧的是「不及以聞」四个字：追一个人，是连上报都等不及的事。汉王那一头，是把丞相的离开当成「失左右手」。

| | |
|---|---|
| 依据 | `005`「何聞信亡，不及以聞，自追之」「上大怒，如失左右手」「臣不敢亡也，臣追亡者」「曰：『韓信也。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两边同时写：追的人在追，被追的人在怒；「不及以闻」是这一段的关键词 |

---

### 卡 3 · 结构 ★

**问：汉中对说了四层，哪四层？**

答：**勇、仁、天下心、三秦。** 一层对一层，最后落到眼前的秦地。

| 层 | 说的是什么 | 原话 | 出处 |
|---|---|---|---|
| 一 | 匹夫之勇 | 「不能任屬賢將，此特匹夫之勇耳」 | `009` |
| 二 | 妇人之仁 | 「印刓敝，忍不能予，此所謂婦人之仁也」 | `009` |
| 三 | 失天下心 | 「名雖為霸，實失天下心。故曰其彊易弱」 | `010` |
| 四 | 三秦可传檄而定 | 「今大王舉而東，三秦可傳檄而定也」 | `012` |

前两层说的是他怎么待身边人：兵不肯交给贤将，爵不肯给有功的人。第三层说他怎么待天下：位置、信义、杀伐。第四层落到秦地：那三个王站不住，汉王进得去。

| | |
|---|---|
| 依据 | `009`「此特匹夫之勇耳」「此所謂婦人之仁也」；`010`「名雖為霸，實失天下心」；`011`–`012`「三秦可傳檄而定也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 四层要能分开说：每层有自己的原话，不是一句笼统的「项羽不行」 |

---

### 卡 4 · 因果

**问：汉中对为什么先问「勇悍仁彊孰与项王」？**

答：因为这一问要汉王自己开口，说「不如也」。

| 次序 | 谁 | 说了什么 |
|---|---|---|
| 1 | 韩信 | 「大王自料勇悍仁彊孰與項王？」 |
| 2 | 汉王 | 「默然良久，曰：不如也。」 |
| 3 | 韩信 | 「惟信亦為大王不如也。然臣嘗事之，請言項王之為人也。」 |

「默然良久」是汉王答话之前的那一段沉默。汉王答完，韩信先跟着承认，然后才开口说项王。**先承认，再拆解——不承认就说不下去。**

| | |
|---|---|
| 依据 | `008`「大王自料勇悍仁彊孰與項王？漢王默然良久，曰：『不如也。』信再拜賀曰：『惟信亦為大王不如也。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三步的次序：问 → 承认 → 再说；「惟信亦為大王不如也」是韩信自己的话 |

---

### 卡 5 · 陷阱题 ⚠️

**问：韩信一到汉营就被重用了，是吗？**

答：**不是。他到汉营之后，一路是「没有人看出来」。**

| 段落 | 他的处境 | 原话 |
|---|---|---|
| `004` | 归汉，未得知名 | 「未得知名，為連敖」 |
| `004` | 犯法当斩，同案十三人已斩 | 「坐法當斬，其輩十三人皆已斬」 |
| `004` | 滕公放他，汉王给官 | 「上拜以為治粟都尉，**上未之奇也**」 |

官给了，人还是没有看出来。真正把他推上去的是萧何那一句「國士無雙」，和追人那一段。**「上未之奇也」这五个字，是这一段里最要紧的反面证据。**

| | |
|---|---|
| 依据 | `004`「未得知名，為連敖」「坐法當斬」「上拜以為治粟都尉，上未之奇也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「滕公奇其言」是一个「奇」，「上未之奇也」是另一个「奇」——一有一无 |

---

### 卡 6 · 细节

**问：拜一个大将，为什么要筑坛、斋戒？**

答：因为萧何说，汉王平日太随便，拜大将像叫小孩，这正是韩信要走的原因。

| 萧何要的四样 | 原文 |
|---|---|
| 日子 | 擇良日 |
| 洁净 | 齋戒 |
| 台子 | 設壇場 |
| 礼数 | 具禮 |

「王素慢無禮，今拜大將如呼小兒耳，此乃信所以去也。」他要的不只是一个官位，是一个所有人都看得见的礼。

| | |
|---|---|
| 依据 | `007`「王素慢無禮，今拜大將如呼小兒耳，此乃信所以去也」「擇良日，齋戒，設壇場，具禮，乃可耳」 |
| 标记 | ◆ 出自原文 |
| 考点 | 四样礼的次序；坛的形制与地点，这十段没有记 |

### 卡 7 · 对照

**问：萧何为什么连着两次把官往上顶？**

答：因为汉王给的官，一次比一次大，萧何判断还不够。

| 汉王说 | 萧何答 | 出处 |
|---|---|---|
| 「吾為公以為將」 | 「雖為將，信必不留」 | `006`、`007` |
| 「以為大將」 | 「幸甚」 | `007` |

两句话同一个意思：不给他一个能留下来的位置，他还是要走。汉王第二次没有还价。

| | |
|---|---|
| 依据 | `006`「王曰：『吾為公以為將。』」；`007`「何曰：『雖為將，信必不留。』王曰：『以為大將。』何曰：『幸甚。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两次加官都是被推上去的；「幸甚」是萧何的反应，不是汉王的 |

---

### 卡 8 · 主题

**问：这一篇为什么收在「一军皆惊」？**

答：因为从头到尾，这支军队里没有一个人知道要拜的是谁。

```
007  诸将皆喜，人人各自以为得大将
     至拜大将，乃韩信也
     一军皆惊
```

前一句是诸将自己的猜想，后一句是揭晓。中间没有过渡——「乃韩信也」四个字一出来，满军的猜想一齐落空。

| | |
|---|---|
| 依据 | `007`「諸將皆喜，人人各自以為得大將。至拜大將，乃韓信也，一軍皆驚」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「人人自以為」与「一軍皆驚」是一对：一个是猜，一个是惊 |

---

### 卡 9 · 陷阱题 ⚠️

**问：汉中对说的那些，后来都应验了吗？**

答：**这一段只记了两件事，一件朝着那个方向，一件不是。**

| 记的 | 原话 | 出处 |
|---|---|---|
| 八月出陈仓，定三秦 | 「八月，漢王舉兵東出陳倉，定三秦」 | `013` |
| 四月至彭城，汉兵败散而还 | 「四月，至彭城，漢兵敗散而還」 | `013` |

三秦确实定了。彭城那一败，这十段没有归因，也没有拿它反过来证明或推翻那四层分析。**汉中对是韩信当面的判断，不是记这件事的人写下的结论。**

| | |
|---|---|
| 依据 | `012`「三秦可傳檄而定也」；`013`「八月，漢王舉兵東出陳倉，定三秦」「四月，至彭城，漢兵敗散而還」 |
| 标记 | ○ 合理推演 |
| 考点 | 区分「人物说的判断」和「史书记的结果」；一段里两件事都有，不能只取一件 |
