# 01 · 复习卡 · 胯下

> 原则：**问动机，不问年代。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 细节 ★

**问：那一段里，他到底做了几个动作？顺序是什么？**

答：四个动作，顺序是看、低头、从裤裆下过去、伏地爬行。每一步都是他自己做的，没有人按他下去。

| 来源 | 动作 |
|---|---|
| 孰視之 | 把他看了很久（「孰」通「熟」） |
| 俛 | 低头 |
| 出袴下 | 从他裤裆底下出去 |
| 蒲伏 | 伏在地上爬行 |

「孰視之」三个字排在最前面。**停顿在最前面，动作在后面。**

| | |
|---|---|
| 依据 | `003`「於是信孰視之，俛出袴下，蒲伏」 |
| 标记 | ◆ 出自原文 |
| 考点 | 顺序：先看，然后才动；底本把这一步单独写出来，不是一笔带过 |

---

### 卡 2 · 陷阱题 ⚠️

**问：他一定是忍辱负重、心里有大志，才从裤裆下爬过去的吧？**

答：**这一段没有这样的记载。**

`003` 只写了四件事：他看了很久，低头，从裤裆下过去，伏地爬行；接着满市的人笑他，认为他胆怯。他心里想什么、有什么打算，一个字都没有。

「忍辱负重」「大丈夫能屈能伸」「留得青山在」都是后人读出来的话，不是这一段写的话。它们是解释，不是记载。

| | |
|---|---|
| 依据 | `003` 只记「孰視之」「俛出袴下」「蒲伏」与「一市人皆笑信，以為怯」，不记他的心思 |
| 标记 | — 史书未载 |
| 考点 | 分清楚哪些是原文写的、哪些是后人评的；不把评价放回现场 |

| 说明 | 问「他是不是有大志」，答案不是「不是」，而是「这一段没有记」。**没写不等于没发生，也不等于发生过**——两种断定都越过了这段材料 |
|---|---|

---

### 卡 3 · 因果

**问：满市的人为什么笑他「怯」？**

答：因为那个少年先把话说成了「怯」，众人接着用同一个字下了结论。

| 谁 | 说了什么 | 出处 |
|---|---|---|
| 屠中少年 | 「若雖長大，好帶刀劍，**中情怯耳**」 | `003` |
| 一市之人 | 「皆笑信，**以為怯**」 | `003` |

一个词从一句话变成了所有人的结论：少年是当众挑他，市人是事后定他。

| | |
|---|---|
| 依据 | `003`「若雖長大，好帶刀劍，中情怯耳」「一市人皆笑信，以為怯」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「以为怯」是市人的判断，不是记这件事的人的判断 |

---

### 卡 4 · 对照

**问：前一段的「怒」和后一段的「爬」，是同一个人的两种反应吗？**

答：是同一个人，两处动作，底本给的字不一样。

| 段落 | 他做了什么 | 底本的字 |
|---|---|---|
| `001` 亭长家 | 明白了他们的意思，发怒，从此断绝往来 | 「信亦知其意，**怒，竟絕去**」 |
| `003` 市上 | 看了很久，低头，过去，伏地爬行 | 「**孰視之**，俛出袴下，蒲伏」 |

一处是「怒」加「绝去」——他走了；一处是留下来，从人胯下过去。两处之间，底本没有解释。

| | |
|---|---|
| 依据 | `001`「信亦知其意，怒，竟絕去」；`003`「於是信孰視之，俛出袴下，蒲伏」 |
| 标记 | ○ 合理推演 |
| 考点 | 对照两处的动作，不加「所以他是为了……」的因果 |

---

### 卡 5 · 细节

**问：「王孙」是什么意思？**

答：当时对年轻人的客气称呼，犹言「公子」，不是说他真是王孙。

漂母面前的人穷到在河边钓鱼充饥，她还是这样叫他。她给饭的理由，她自己说了：「吾哀王孫而進食」——可怜他，才给他饭。

| | |
|---|---|
| 依据 | `002`「吾哀王孫而進食，豈望報乎」 |
| 标记 | ○ 合理推演 |
| 考点 | 「王孙」是称呼，不是家世；这一解是后人的训释 |

---

### 卡 6 · 结构

**问：这一篇的三段是怎么排的？**

答：

```
001  寄食：亭长家的饭断了
002  城下：漂母给饭，他许下重报
003  市上：屠中少年给他两条路，他爬了过去
```

三段是三次「饭」的处境一层层往下掉：先是别人家的饭没了，再是陌生人的饭，最后连站着走路都保不住。第三段结尾不是他，是一市之人。

| | |
|---|---|
| 依据 | `001`–`003`；`001` 止于「怒，竟絕去」，`002` 记漂母饭信，`003` 止于「一市人皆笑信，以為怯」 |
| 标记 | ○ 合理推演 |
| 考点 | 三段的次序本身就是叙事；末句的主语是市人，不是韩信 |

---

### 卡 7 · 主题

**问：这一篇最重的是哪一句？**

答：**「一市人皆笑信，以為怯。」**

他刚才那一眼看了多久、看的是什么，这段里没有一个人问。满市的人只留下两个判断：笑，和怯。

而这九个字的后半截，用了一个「以為」——记的是他们怎么想。记这件事的人没有另加一句评语。

| | |
|---|---|
| 依据 | `003`「一市人皆笑信，以為怯」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「以为」二字：那是市人的判断，不是叙述者的判词 |

| 说明 | 「最重」是编者的判断，不是史书的判断。史书只是把这一句放在三段最后，没有加评语 |
|---|---|

---

### 卡 8 · 陷阱题 ⚠️

**问：漂母给他饭，是因为看出了他将来会发达吗？**

答：她给的理由，她自己说得很清楚：可怜他，不图报答。

「大丈夫不能自食，吾哀王孫而進食，豈望報乎！」——她先骂他连自己都养不活，再说自己是可怜这位「王孙」才给饭，哪里是图报答。她还把韩信的许诺退了回来。

「她看准了他日后必成大器」是后人的读法；这一段能核到的只有她这一句话。

| | |
|---|---|
| 依据 | `002`「大丈夫不能自食，吾哀王孫而進食，豈望報乎」 |
| 标记 | ◆ 出自原文 |
| 考点 | 人物自己给出的理由，优先于后人的推测；她的理由是「哀」，不是「识英雄」 |

---

### 卡 9 · 细节

**问：「晨炊蓐食」是四个什么字？**

答：清早做饭，在床上把饭吃完。

要紧的不是这四个字怎么训，是时间：饭在他到之前就吃完了。所以他到了，才「不為具食」——没有给他摆饭。

| 词 | 意思 |
|---|---|
| 晨炊 | 清早做饭 |
| 蓐食 | 在床上吃（蓐：床蓐） |

| | |
|---|---|
| 依据 | `001`「乃晨炊蓐食。食時信往，不為具食」 |
| 标记 | ○ 合理推演 |
| 考点 | 「蓐」训作床蓐是后人的解释；「赶在他来之前」是接读下一句得出的 |
