# 复习卡 · 故事 06 · 钟室

> 原则：**问动机，不问年代。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

## 故事 06 · 钟室（10 张）

---

### 卡 1 · 结构 ★

**问：这一篇的坡度，是怎么标出来的？**

答：**四个纪年。**

| 纪年 | 发生了什么 | 王号 |
|---|---|---|
| 汉五年 | 会垓下；项羽破；袭夺齐军；徙楚王 | 齐王 → 楚王 |
| 汉六年 | 告反；游云梦；缚信；赦为淮阴侯 | 楚王 → 淮阴侯 |
| 汉十年 | 陈豨反；信称病不从；谋起事 | 淮阴侯 |
| — | 吕后与萧何定计；斩于长乐钟室 | 死 |

一条下坡路。坡度不是形容词，是这几个纪年。

| | |
|---|---|
| 依据 | `053`「漢五年正月，徙齊王信為楚王，都下邳」；`055`「漢六年，人有上書告楚王信反」；`061`「漢十年，陳豨果反」；`062`「斬之長樂鍾室」 |
| 标记 | ◆ 出自原文 |
| 考点 | 纪年是原文的，公元年份不是；四个纪年各带一个身份变化 |

---

### 卡 2 · 细节 ★

**问：韩信是怎么死的？**

答：**吕后与萧相国定计，诈称陈豨已死，骗他进宫来贺，斩于长乐钟室。**

```
061  舍人弟上变，告信欲反
062  吕后欲召，恐其党不就 → 与萧相国谋
062  诈令人从上来，言豨已得死，列侯群臣皆贺
062  相国绐信：「雖疾，彊入賀。」
062  信入 → 武士缚信 → 斩之長樂鍾室
062  临斩：「吾悔不用蒯通之計……」
```

杀他的主意是和萧相国一起定的，骗他进宫的是萧相国。

| | |
|---|---|
| 依据 | `062`「乃與蕭相國謀，詐令人從上所來，言豨已得死，列侯群臣皆賀」；`062`「相國紿信曰：『雖疾，彊入賀。』」；`062`「信入，呂後使武士縛信，斬之長樂鍾室」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三个动作要连起来：定计 → 诈称 → 骗贺 → 斩 |

---

### 卡 3 · 陷阱 ⚠️

**问：韩信是被装进布袋里、吊在钟上刺死的吗？**

答：**底本没有这一层。**

`062` 写的是「斬之長樂鍾室」——一个地点（长乐宫钟室），一个动作（斩）。

布袋、钟下之说，是后世小说、戏曲里的说法，不在这一篇的底本里。

| | |
|---|---|
| 依据 | `062` 只记「斬之長樂鍾室」 |
| 标记 | — 史书未载 |
| 考点 | 问到怎么死的，答底本这一句：定计、诈称、骗贺、斩于钟室 |

| 备注 | 这一段没有「装进口袋」这回事。**演义里的细节不能当史实补进来** |
|---|---|

### 卡 4 · 因果 ★

**问：韩信到底想不想反？**

答：**底本给了两处，没有替我们裁。**

| 出处 | 他说了什么 / 做了什么 |
|---|---|
| `057` | 被缚时说：天下已定，我固当亨——把自己比作该被烹的猎狗 |
| `060` | 与陈豨步于庭：我在里面起事，天下可以图 |
| `061` | 陈豨反后，阴使人至豨所：弟举兵，吾从此助公 |
| `061` | 谋与家臣夜诈诏赦诸徒奴，欲发以袭吕后、太子 |

一处是自认冤枉的话，一处是私下的约定和部署。两处都写在底本里。

| | |
|---|---|
| 依据 | `057`「天下已定，我固當亨」；`060`「吾為公從中起，天下可圖也」；`061`「陰使人至豨所」 |
| 标记 | ○ 合理推演 |
| 考点 | 两处并置，不取其一——**不替人選边**，也不宣布哪一处是假的 |

### 卡 5 · 人物

**问：蒯通教过韩信反，为什么没有被烹？**

答：**因为他答的不是罪，是立场。**

| 高祖问 | 蒯通答 |
|---|---|
| 若教淮阴侯反乎 | 然，臣固教之 |
| 你教他反，有什么冤 | 秦失其鹿，天下共逐之；狗因吠非其主；臣唯独知韩信，非知陛下也 |
| — | 天下想干陛下所干的事的人很多，只是力量不够——又可尽亨之邪 |

高帝听完，只说了一句「置之」，就免了他的罪。

| | |
|---|---|
| 依据 | `063`「然，臣固教之」；`064`「秦失其鹿，天下共逐之…狗因吠非其主。當是時，臣唯獨知韓信，非知陛下也…又可盡亨之邪」；`064`「高帝曰：『置之。』乃釋通之罪」 |
| 标记 | ◆ 出自原文 |
| 考点 | 他承认教过；辩的是「那时候我只认一个主子」 |

---

### 卡 6 · 对读

**问：韩信到楚国以后，三笔旧账怎么还的？**

答：**三种人，三种给法。**

| 人 | 给什么 | 原话 |
|---|---|---|
| 漂母 | 千金 | 召所從食漂母，賜千金（`054`） |
| 南昌亭长 | 百钱 | 公，小人也，為德不卒（`054`） |
| 胯下少年 | 楚中尉 | 此壯士也……殺之無名，故忍而就於此（`054`） |

不是按恩情大小排的价。给亭长的判语是「做好事不做到底」；给少年的不是钱，是一个官。

| | |
|---|---|
| 依据 | `054`「召所從食漂母，賜千金」；`054`「賜百錢，曰：『公，小人也，為德不卒。』」；`054`「召辱己之少年令出胯下者以為楚中尉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三笔账的给法都是原文；「为什么这样给」底本不解释 |

---

### 卡 7 · 细节

**问：「且喜且憐之」五个字，重在哪里？**

答：**重在前后的次序：喜在前，怜在后。**

高祖从陈豨军中回来，到了，看见韩信死了——「且喜且憐之」。然后他问的第一句是「信死亦何言？」

喜什么、怜什么，底本一个字都没有写。

| | |
|---|---|
| 依据 | `063`「高祖已從豨軍來，至，見信死，且喜且憐之，問：『信死亦何言？』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 五个字是原文；喜与怜各指什么，不载 |

---

### 卡 8 · 主题 ★

**问：司马迁怎么看韩信？**

答：**这一段是原话，不是概括。**

> 假令韓信學道謙讓，不伐己功，不矜其能，則庶幾哉，於漢家勳可以比周、召、太公之徒，後世血食矣。不務出此，而天下已集，乃謀畔逆，夷滅宗族，不亦宜乎！

顺序不能倒：先「假令」——学道谦让、不伐己功、不矜其能，可以比周、召、太公；再「不務出此，而天下已集，乃謀畔逆」。

判词落在「天下已集」四个字上：天下已经定了，他才谋反。

| | |
|---|---|
| 依据 | `065`「假令韓信學道謙讓，不伐己功，不矜其能，則庶幾哉，於漢家勳可以比周、召、太公之徒，後世血食矣。不務出此，而天下已集，乃謀畔逆，夷滅宗族，不亦宜乎」 |
| 标记 | ◆ 出自原文 |
| 考点 | 引原文，不概括。「不務出此」的「此」，就是前面那几句 |

---

### 卡 9 · 对照

**问：萧何在这条路上出现了两次，是哪两次？**

答：**一次追他回来，一次骗他进宫。**

| 时候 | 萧何做了什么 |
|---|---|
| 韩信亡楚归汉、未得知名，跑了 | 「何聞信亡，不及以聞，自追之」（`005`，见 `02-dengtan`） |
| 吕后欲召，恐其党不就 | 「乃與蕭相國謀」；「相國紿信曰：『雖疾，彊入賀。』」（`062`） |

第一次，他追的是那个「國士無雙」的人；最后一次，他骗的是同一个人的命。两件事都记在底本里，中间隔了多年。

| | |
|---|---|
| 依据 | `062`「乃與蕭相國謀」；`062`「相國紿信曰：『雖疾，彊入賀。』」；追信见 `02-dengtan` |
| 标记 | ◆ 出自原文 |
| 考点 | 两处都是原文；本卡只并置，不替萧何解释 |

### 卡 10 · 辨析

**问：「多多益善」是一句狂言吗？**

答：**它是一句实话，也是一句顶到死处的话。**

高祖问：像我能将多少？信说：陛下不过能将十万。问：于你怎么样？信说：臣多多而益善耳。

高祖笑了，问：越多越好，怎么反倒被我擒了？韩信答：陛下不能将兵，却善于将将——这就是我被擒的原因。

| | |
|---|---|
| 依据 | `058`「陛下不過能將十萬」；`058`「臣多多而益善耳」；`059`「陛下不能將兵，而善將將，此乃言之所以為陛下禽也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 前一句顶到死处，后一句解围；两句都是他的原话 |
