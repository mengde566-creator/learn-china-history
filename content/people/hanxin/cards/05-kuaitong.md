# 复习卡 · 故事 05 · 相君之背

> 原则：**问动机，不问年代。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

## 故事 05 · 相君之背（9 张）

---

### 卡 1 · 结构 ★

**问：蒯通这一次说了三层话，是哪三层？**

答：**相术、实况、猎狗。三层说的不是一件事。**

| 层 | 段 | 说的是什么 |
|---|---|---|
| ① 相术 | `041`–`042` | 一个由头：面不过封侯，背贵不可言 |
| ② 实况 | `042`–`043` | 楚也困，汉也困；两主的命悬在第三者身上 |
| ③ 猎狗 | `048` | 打完天下以后，功劳本身成了罪名 |

第一层是术士的话，第二层是谋士的话，第三层才是他真正要说的话。压成一段劝说，就看不见它们各自的分量。

| | |
|---|---|
| 依据 | `041`「相君之面，不過封侯，又危不安」；`043`「此所謂智勇俱困者也」；`048`「野獸已盡而獵狗亨」 |
| 标记 | ○ 合理推演 |
| 考点 | 三层分开：由头、实况、判决 |

---

### 卡 2 · 细节 ★

**问：「相君之面」和「相君之背」各说了什么？**

答：**一句比一句短，一句比一句重。**

| 看哪里 | 原话 | 意思 |
|---|---|---|
| 面 | 相君之面，不過封侯，又危不安 | 最多封侯，而且又危又不安 |
| 背 | 相君之背，貴乃不可言 | 贵得没法说 |

韩信听完第二句，只问了三个字：「何謂也？」蒯通才从相术转到天下。

| | |
|---|---|
| 依据 | `041`「相君之面，不過封侯，又危不安」；`042`「相君之背，貴乃不可言」；`042`「韓信曰：『何謂也？』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「背」先指背脊；劝的是背汉。一个字两个读法，底本没有点破 |

---

### 卡 3 · 因果 ★

**问：「野獸已盡而獵狗亨」这个比方，比的是什么？**

答：**比的是打完天下之后的功臣。** 前面两层还在讲天下怎么分，这一句讲的是打完之后。

| 例子 | 他们的结局 |
|---|---|
| 张耳与陈余 | 刎颈之交，最后相禽，头足异处（`046`–`047`） |
| 大夫种、范蠡 | 存亡越、霸句践，立功成名而身死亡（`048`） |

蒯通把这两个例子收成一句：「野獸已盡而獵狗亨。」野兽打光了，猎狗就下锅。

这一句里没有一个字在劝，也没有一个字留余地。

| | |
|---|---|
| 依据 | `048`「大夫種、范蠡存亡越，霸句踐，立功成名而身死亡。野獸已盡而獵狗亨」；`047`「患生於多欲而人心難測也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「亨」就是烹；这一句和「勇略震主者身危」是同一天平的两端 |

---

### 卡 4 · 人物

**问：蒯通为什么先说自己会看相？**

答：**为了一个由头。**

`041` 写得明白：他「欲為奇策而感動之」，然后「以相人說韓信」——先自报学过相人的方术，再请单独说话，再报出相君之面、相君之背。

相术只占了开头几句。韩信一问「何谓也」，他讲的就是楚汉相持、三分天下——**再没有一句相术**。

| | |
|---|---|
| 依据 | `041`「欲為奇策而感動之，以相人說韓信曰：『僕嘗受相人之術』」；`042` 以下无一字相术 |
| 标记 | ○ 合理推演 |
| 考点 | 相术是入口，不是内容——从 `042` 起就换了话题 |

---

### 卡 5 · 陷阱 ⚠️

**问：韩信说「汉王遇我甚厚」，这就是他不反的全部原因吗？**

答：**这是他的说法，不是底本给的唯一答案。**

`046` 记下的是他自己的话：车、衣、食三样，和「乘人之車者載人之患」那套回报。他说得很整，也很长。

但底本只记了这一段自述。他没说出口的考量，一个字都没有。

| | |
|---|---|
| 依据 | `046`「漢王遇我甚厚，載我以其車，衣我以其衣，食我以其食」；`046`「吾豈可以鄉利倍義乎」 |
| 标记 | ◆ 出自原文 |
| 考点 | 分清「他这样说」和「事情就是这样」——**自述不等于唯一真实原因** |

| 备注 | 上一篇他对武涉说过内容相近的一段。两次都这么说，不等于这就是全部 |
|---|---|

---

### 卡 6 · 辨析

**问：「先生且休矣，吾將念之」——这是拒绝吗？**

答：**不是明确拒绝，也不是答应。它是一句推迟。**

`050` 只记这九个字。几天之后，`051` 蒯通又来劝，`052` 才写「韓信猶豫不忍倍漢……遂謝蒯通」。

所以真正的拒绝在 `052`，不在 `050`。

| | |
|---|---|
| 依据 | `050`「先生且休矣，吾將念之」；`051`「後數日，蒯通複說曰」；`052`「遂謝蒯通」 |
| 标记 | ○ 合理推演 |
| 考点 | 两次之间隔了几天；「念之」之后还有一次劝说 |

---

### 卡 7 · 细节

**问：「參分天下，鼎足而居」是什么局面？**

答：**天下分成三份，像鼎的三只脚，谁也不先动。**

`044` 的方案是：两边都不帮，让汉、楚都留下来；韩信据着强齐，联合燕、赵，从空虚的地方出兵，向西替百姓请命。

`045` 再往下是分封：割大的、削强的，立诸侯。

| | |
|---|---|
| 依据 | `044`「莫若兩利而俱存之，參分天下，鼎足而居，其勢莫敢先動」；`045`「割大弱彊，以立諸侯」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三分天下是方案，不是已经发生的事；哪一块归谁，底本不载 |

---

### 卡 8 · 主题

**问：蒯通第二次劝说，最重的是哪一句？**

答：**「時乎時，不再來。」**

第二次他说的是：听是事的征候，计是事的机括；知者决之断，疑者事之害；审毫氂的小计，会遗下天下的大数。

然后收在六个字上：时啊时，不会再来。

韩信还是犹豫，不忍背汉，又自以为功多，汉终究不会夺他的齐。

| | |
|---|---|
| 依据 | `051`「聽者事之候也，計者事之機也」；`052`「夫功者難成而易敗，時者難得而易失也。時乎時，不再來」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「最重」是读出来的判断；原文只把它放在第二次劝说的末尾 |

---

### 卡 9 · 陷阱 ⚠️

**问：蒯通装疯做了巫，是躲过去了吗？**

答：**底本不支持「躲过去了」这个说法。**

`052` 的原文只有五个字：「已詳狂為巫」——詳就是佯，装疯去做巫。为什么，没有写。

后一篇里，高祖还是下诏到齐地捕他，他被带到了高祖面前。

| | |
|---|---|
| 依据 | `052`「蒯通說不聽，已詳狂為巫」；后一篇记下诏到齐地捕他，见 `06-zhongshi` |
| 标记 | ○ 合理推演 |
| 考点 | 装疯是记下来的；装疯之后仍被捕，也记下来了。**「躲过去了」两头都不成立** |
