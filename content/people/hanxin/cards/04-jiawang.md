# 复习卡 · 故事 04 · 假王

> 原则：**问动机，不问年代。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

## 故事 04 · 假王（9 张）

---

### 卡 1 · 结构 ★

**问：韩信派人去要一个「假王」，汉王为什么骂他「自立為王」？**

答：**因为这两个说法不是同一件事。**

| 谁 | 原话 | 说的是什么 |
|---|---|---|
| 韩信派去的人 | 不為假王以鎮之，其勢不定 | 齐地反复，要一个名号去镇住 |
| 汉王 | 乃欲自立為王 | 我在荥阳被围，你在这个当口要王位 |

请求里写的是「镇齐」，骂出口的是「自立」。两个意思在一封信上撞了一下。

| | |
|---|---|
| 依据 | `036`「齊偽詐多變，反覆之國也，南邊楚，不為假王以鎮之，其勢不定」；`036`「吾困於此，旦暮望若來佐我，乃欲自立為王」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两句话都在 `036`，一句是使者带来的，一句是汉王骂的 |

---

### 卡 2 · 因果 ★

**问：汉王为什么改口？**

答：**因为他被踩了脚。**

`036` 大怒骂完，紧接一句「張良、陳平躡漢王足，因附耳語曰」；`037` 才有「漢王亦悟，因複罵曰」。

```
036  大怒：「乃欲自立為王！」
036  张良、陈平蹑足附耳：「漢方不利，寧能禁信之王乎？」
037  漢王亦悟
037  因複罵：「大丈夫定諸侯，即為真王耳，何以假為！」
```

改口不是自己转的，是被人踩了脚、附耳说了话之后转的。

| | |
|---|---|
| 依据 | `036`「張良、陳平躡漢王足，因附耳語曰：『漢方不利，寧能禁信之王乎？』」；`037`「不如因而立，善遇之，使自為守。不然，變生。漢王亦悟，因複罵曰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 顺序：怒 → 蹑足附耳 → 悟 → 复骂。中间那个「悟」字是原文 |

---

### 卡 3 · 陷阱 ⚠️

**问：汉王改口把「假王」升成「真王」，说明他大方吗？**

答：**不说明。** 底本给的是「先怒后改口」，不是「一开始就肯」。

两次骂，方向相反：先骂「乃欲自立為王」，后骂「何以假為」。**骂还是骂**，第二次只是比第一次好听。而且第二次前面有「亦悟」两个字——悟是被人点醒，不是自己想通。

| | |
|---|---|
| 依据 | `036`「漢王大怒，罵曰」；`037`「漢王亦悟，因複罵曰」 |
| 标记 | ○ 合理推演 |
| 考点 | 「不是大方」是读出来的判断；原文只给了怒、悟、复骂的顺序 |

| 备注 | 哪一句骂是真心，底本不载——这里不替汉王选 |
|---|---|

---

### 卡 4 · 细节 ★

**问：「假王」的「假」是假的王吗？**

答：**不是。是代理、非正式。**

`037` 汉王改口那句把这一层挑明了：「大丈夫定諸侯，即為真王耳，何以假為」——「假」与「真」相对，说的是正式不正式。

所以「假王」是暂署的王，不是冒充的王。韩信要的是名号，汉王最后给的是正式的名号。

| | |
|---|---|
| 依据 | `036`「不為假王以鎮之」；`037`「即為真王耳，何以假為」 |
| 标记 | ○ 合理推演 |
| 考点 | 「假＝代理」是后人对这个词的训释；底本没有解释，只给了「真／假」的对照 |

---

### 卡 5 · 人物

**问：蒯通劝韩信继续攻齐，算的是哪一笔账？**

答：**功劳记在谁头上。**

| 谁 | 做了什么 | 得了多少城 |
|---|---|---|
| 郦生 | 伏在车轼上，摇三寸之舌 | 七十余城 |
| 韩信 | 带几万兵，打了一年多 | 赵五十余城 |

他一句没提齐该不该打。他提的是诏书——受诏击齐，没有诏叫停。他说的是：一个士人，凭什么比几万兵功劳大。

| | |
|---|---|
| 依据 | `032`「酈生一士，伏軾掉三寸之舌，下齊七十餘城，將軍將數萬眾，歲餘乃下趙五十餘，為將數歲，反不如一豎儒之功乎」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「寧有詔止將軍乎」是反问，不是诏书——汉有没有下过止军的诏，底本未载 |

---

### 卡 6 · 对照

**问：武涉劝韩信反，韩信怎么答？**

答：**武涉说的是利害，韩信答的是自己受过什么。**

| 武涉说的 | 韩信答的 |
|---|---|
| 「足下右投則漢王勝，左投則項王勝」（`039`） | 「漢王授我上將軍印，予我數萬眾」（`040`） |
| 「項王今日亡，則次取足下」（`039`） | 「解衣衣我，推食食我」（`040`） |
| 「何不反漢與楚連和，參分天下王之」（`040`） | 「我倍之不祥，雖死不易」（`040`） |

他没有一句去驳「右投左投」——那个没法驳。他讲的是车、衣、食。

| | |
|---|---|
| 依据 | `039`「足下右投則漢王勝，左投則項王勝。項王今日亡，則次取足下」；`040`「解衣衣我，推食食我…雖死不易」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两边说的不是同一层：一边是天下大势，一边是个人恩义 |

| 备注 | 「汉王遇我甚厚」是韩信的自述。**自述不等于唯一真实原因**——底本没有另给一份动机清单 |
|---|---|

---

### 卡 7 · 细节

**问：「亨」是什么意思？**

答：**煮。就是烹。**

`033` 用的是这个字：齐王田广认为郦生卖了自己，「乃亨之」——把他煮了。

这一句写得很短，夹在袭历下和走高密之间，前后没有一句议论。

| | |
|---|---|
| 依据 | `033`「齊王田廣以酈生賣己，乃亨之，而走高密」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「亨＝烹」是通假；怎么执行的，底本未载 |

---

### 卡 8 · 主题

**问：这一篇里，哪一个动作最轻、后果最重？**

答：**「躡漢王足」——踩一下脚。**

`036` 记张良、陈平踩了汉王的脚，附耳说了两句话；`037` 汉王就「悟」了，改口把假王升成真王，派张良去立韩信为齐王，然后「徵其兵擊楚」。

一个踩脚的动作，换来一个王号和一支兵。

| | |
|---|---|
| 依据 | `036`「張良、陳平躡漢王足，因附耳語曰」；`037`「乃遣張良往立信為齊王，徵其兵擊楚」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「最轻／最重」是编者的判断；踩脚、附耳、改口、立王、征兵，都记在同一段里 |

---

### 卡 9 · 陷阱 ⚠️

**问：韩信上书要假王的时候，是不是已经有了自立的心？**

答：**底本没有回答这个问题。**

`036` 记下了使者带来的请求和理由；请求之外他想什么，一个字都没有。`037` 记下了汉王的怒与悟；韩信听到改口之后怎么想，也没有。

能说的只有：他写下的理由是镇齐。

| | |
|---|---|
| 依据 | `036` 只记请求与理由；`037` 只记汉王怒、悟、改口 |
| 标记 | — 史书未载 |
| 考点 | 「未载」不等于「没发生」，也不等于「发生了」——两种推法都推不出来 |
