# 03 · 复习卡 · 背水

> 原则：**问动机，不问年代。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一仗的胜负，到底是在哪儿定的？**

答：**不在河边上，在前一夜和赵军的营壁上。**

| 时候 | 做了什么 | 出处 |
|---|---|---|
| 未至井陉口三十里 | 夜半传发，选轻骑二千人，人持一赤帜，从间道萆山而望赵军 | `019` |
| 天亮前 | 使万人先行，出，背水陈——赵军望见而大笑 | `020` |
| 接战 | 信、张耳详弃鼓旗，走水上军——把赵军引空 | `020` |
| 赵营空 | 二千骑驰入赵壁，皆拔赵旗，立汉赤帜二千 | `021` |

河边那一军只做一件事：不退。「軍皆殊死戰，不可敗」。真正让赵军垮掉的是回头看见营壁换了颜色。

| | |
|---|---|
| 依据 | `019`「夜半傳發，選輕騎二千人，人持一赤幟」；`020`「信乃使萬人先行，出，背水陳」「於是信、張耳詳棄鼓旗，走水上軍」；`021`「皆拔趙旗，立漢赤幟二千」 |
| 标记 | ◆ 出自原文 |
| 考点 | 四个时辰四件事的次序；背水是最后一步，不是全部 |

---

### 卡 2 · 陷阱题 ⚠️

**问：背水列阵就是把一万人放在死地赌一把，赢在运气？**

答：**不是运气。但「陷之死地」也不是全部原因。**

战前有布置：`019` 先派人探明成安君没有用广武君的计，才「乃敢引兵遂下」；同段记两千骑带赤帜绕山；`020` 记他判断对面不见大将旗鼓就不肯打前队；`020` 记诈败丢旗鼓把赵军引空；`021` 记两千骑入营换旗。

战后有解释：`023`–`024` 是诸将问、韩信答。他说兵法有「陷之死地而後生」，又说这一军是「驅市人而戰之」，给了活路就会跑。

两边要分开看：**前者是底本记的事，后者是他自己的说法。**

| | |
|---|---|
| 依据 | `019`「使人間視，知其不用」「乃敢引兵遂下」；`020`「詳棄鼓旗」；`021`「皆拔趙旗，立漢赤幟二千」；`023`–`024` 为韩信答诸将之语 |
| 标记 | ○ 合理推演 |
| 考点 | 人物自述不等于唯一真实原因；把「布置」和「他事后的解释」分成两条 |

| 说明 | 这一条不是否认兵法解释，是不让它独占解释权。`024` 是韩信说给部下听的，底本没有加一句评语 |
|---|---|

### 卡 3 · 因果

**问：赵军为什么会一下子乱掉？**

答：因为他们回营的时候，看见的不是自己的旗。

```
021  欲還歸壁
     壁皆漢赤幟 → 大驚
     以為漢皆已得趙王將矣 → 兵遂亂，遁走
     趙將雖斬之，不能禁也
```

他们不是打输了才乱，是看见颜色以后才乱。「以為」两个字说明这是他们的判断——判断未必对，但足以让一支军队崩掉。

| | |
|---|---|
| 依据 | `021`「欲還歸壁，壁皆漢赤幟，而大驚，以為漢皆已得趙王將矣，兵遂亂，遁走」 |
| 标记 | ◆ 出自原文 |
| 考点 | 乱的原因是营壁的颜色，不是河边的死战；「以为」是赵军的判断 |

---

### 卡 4 · 细节

**问：「今日破赵会食」这句话，诸将信吗？**

答：不信。他们的反应，底本只留了四个字：「詳應曰：『諾』」。

| 谁 | 说了什么 | 意思 |
|---|---|---|
| 韩信 | 「今日破趙會食！」 | 今天破了赵，再一起吃饭 |
| 副将 | 传飧 | 先把饭发下去 |
| 诸将 | 「皆莫信，詳應曰：『諾』」 | 都不信，假意应了一声诺 |

饭发在破赵之前，吃饭定在破赵之后。这一句是当着全军说的。

| | |
|---|---|
| 依据 | `019`「令其裨將傳飧，曰：『今日破趙會食！』諸將皆莫信，詳應曰：『諾』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「莫信」与「详应」两个词：不服，但答应；「详」通「佯」 |

### 卡 5 · 因果

**问：成安君为什么不用广武君的计？**

答：他给了两条理由，都不是「这条计不好」。

| 理由 | 原话 | 出处 |
|---|---|---|
| 兵法上该打 | 「吾聞兵法十則圍之，倍則戰」 | `018` |
| 对方已疲，且人少 | 「今韓信兵號數萬，其實不過數千。能千里而襲我，亦已罷極」 | `018` |
| 怕被人说怯 | 「則諸侯謂吾怯，而輕來伐我」 | `018` |

他驳的是「避而不击」，不是「计策不成」。他还常常说「義兵不用詐謀奇計」——这一仗他不是没想到奇计，是不肯用。

| | |
|---|---|
| 依据 | `018`「成安君，儒者也，常稱義兵不用詐謀奇計」「十則圍之，倍則戰」「其實不過數千」「則諸侯謂吾怯」 |
| 标记 | ◆ 出自原文 |
| 考点 | 他反对的理由是兵法与面子，不是判断计策有误 |

---

### 卡 6 · 细节

**问：广武君的计分几步？他凭什么说十天？**

答：两步；凭的是井陉那条道窄。

| 步 | 做什么 | 原话 |
|---|---|---|
| 一 | 借三万奇兵，从小路断粮道 | 「原足下假臣奇兵三萬人，從間道絕其輜重」 |
| 二 | 主力深沟高垒，坚守不出 | 「足下深溝高壘，堅營勿與戰」 |

他要的不是打赢，是熬到对方「前不得鬥，退不得還」，野外又没得抢。理由是同段给的：道窄，车不能并行，骑不能成列，粮一定落在后头。

| | |
|---|---|
| 依据 | `017`「原足下假臣奇兵三萬人，從間道絕其輜重；足下深溝高壘，堅營勿與戰」「車不得方軌，騎不得成列」「不至十日，而兩將之頭可致於戲下」 |
| 标记 | ◆ 出自原文 |
| 考点 | 计的两半：断粮与守营；十天是估计，理由在同段 |

---

### 卡 7 · 主题 ★

**问：「解其缚，东乡对，西乡对，师事之」——这一句里，他一共做了几件事？**

答：**三件，一件比一件低。**

| 次 | 动作 | 原话 |
|---|---|---|
| 1 | 下令活捉，不许杀 | 「令軍中毋殺廣武君，有能生得者購千金」 |
| 2 | 有人把他绑了送来，先解绑 | 「有縛廣武君而致戲下者，信乃解其縛」 |
| 3 | 让他面朝东，自己面朝西，以师礼事之 | 「東鄉對，西鄉對，師事之」 |

前面用千金买这个人，中间有人把他绑来，后面把自己放在下位。**抓了他，又把他当先生供着。**

| | |
|---|---|
| 依据 | `022`「信乃令軍中毋殺廣武君，有能生得者購千金。於是有縛廣武君而致戲下者，信乃解其縛，東鄉對，西鄉對，師事之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三步都记下来了：千金、解缚、师事；东向是上位 |

---

### 卡 8 · 对照

**问：广武君献过两次计，结果有什么不同？**

答：**战前那条没有被用，战后那条被用了。**

| 时候 | 献的计 | 结果 | 出处 |
|---|---|---|---|
| 战前，对成安君 | 三万奇兵断粮，主力深沟高垒不出战 | 「不聽廣武君策，廣武君策不用」 | `018` |
| 战后，对韩信 | 案甲休兵，镇赵抚孤，遣辩士奉书于燕 | 「從其策，發使使燕，燕從風而靡」 | `029` |

两条计是同一个路数：不硬打，先把样子摆出来。前一条的成败不在计上——`018` 把「不听」这件事连说了两遍。

| | |
|---|---|
| 依据 | `017`；`018`「不聽廣武君策，廣武君策不用」；`028`「莫如案甲休兵，鎮趙撫其孤」；`029`「從其策，發使使燕，燕從風而靡」 |
| 标记 | ◆ 出自原文 |
| 考点 | 同一个人、同一个路数，两次的差别只在听与不听 |

---

### 卡 9 · 细节

**问：「先声而后实」是什么意思？**

答：先造声势，后见实际。

广武君的话是：「兵固有先聲而後實者，此之謂也。」他给的做法是先摆出北向燕国的架势、送一封书信过去，燕不敢不听；燕服了，再让人往东告诉齐，齐也跟着服。**先让人听见，再让人看见。**

| | |
|---|---|
| 依据 | `029`「兵固有先聲而後實者，此之謂也」；`028`「北首燕路，而後遣辯士奉咫尺之書」 |
| 标记 | ○ 合理推演 |
| 考点 | 「声」在前、「实」在后；白话解说是后人的训释 |

### 卡 10 · 因果

**问：韩信为什么敢带几万人下井陉？**

答：因为开打之前，他先做了两个判断。

| 判断 | 原话 | 出处 |
|---|---|---|
| 对面不会用计 | 「使人間視，知其不用，還報，則大喜，乃敢引兵遂下」 | `019` |
| 对面不敢先打前队 | 「彼未見吾大將旗鼓，未肯擊前行」 | `020` |

第一个判断是对赵军做的功课，第二个判断是对自己这一军摆出来的样子。**背水不是赌气，是算过的。**

| | |
|---|---|
| 依据 | `019`「使人間視，知其不用，還報，則大喜，乃敢引兵遂下」；`020`「彼未見吾大將旗鼓，未肯擊前行」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两个判断都在开打之前；一在敌情，一在我形 |
