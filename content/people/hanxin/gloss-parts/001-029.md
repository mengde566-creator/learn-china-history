| 001 | 淮陰侯韓信者，淮陰人也。始為布衣時，貧無行，不得推擇為吏，又不能治生商賈，常從人寄食飲，人多厭之者，常數從其下鄉南昌亭長寄食，數月，亭長妻患之，乃晨炊蓐食。食時信往，不為具食。信亦知其意，怒，竟絕去。 | 淮陰侯韓信，是淮陰人。起初做布衣（布衣：平民）的時候，家貧，沒有可稱道的品行，不能被推舉選任為吏（吏：官府屬吏），又不會營治生業、做商賈（商賈：行商坐賈），常常跟從別人寄託飲食，人多厭惡他。常常多次跟從他的下鄉（下鄉：鄉名）南昌亭長（亭長：亭的長官）寄託飲食，幾個月，亭長的妻子憂患這件事，就清早做飯、在床上把飯吃完（蓐食：在床上進食）。到了吃飯的時候信去，不給他備飯。信也知道他們的意思，發怒，終於斷絕離去。 |
| 002 | 信釣於城下，諸母漂，有一母見信饑，飯信，竟漂數十日。信喜，謂漂母曰：「吾必有以重報母。」母怒曰：「大丈夫不能自食，吾哀王孫而進食，豈望報乎！」 | 信在城下釣魚，幾位老婦人在漂洗（漂：在水中漂洗），有一位老婦人見信饑餓，給信飯吃，直到那幾十天的漂洗做完。信高興，對漂母（漂母：漂洗的老婦人）說：「我必定有可以用來重重報答您的東西。」老婦人發怒說：「大丈夫不能自己養活自己，我可憐王孫（王孫：對年輕人的客氣稱呼）而進獻飲食，哪裡指望報答呢！」 |
| 003 | 淮陰屠中少年有侮信者，曰：「若雖長大，好帶刀劍，中情怯耳。」眾辱之曰：「信能死，刺我；不能死，出我袴下。」於是信孰視之，俛出袴下，蒲伏。一市人皆笑信，以為怯。 | 淮陰屠戶之中有侮辱信的少年，說：「你雖然長大，喜好帶刀劍，內心（中情：內心）卻是怯的罷了。」眾人（一解作「當眾」）羞辱他說：「信能死（能死：敢於死），刺我；不能死，出我袴下（袴下：褲襠下）。」於是信熟視（孰視：同「熟視」，看了很久）他，低頭（俛：同「俯」）從袴下出去，伏地爬行（蒲伏：同「匍匐」）。一市（一市：滿市）的人都笑信，認為他怯。 |
| 004 | 及項梁渡淮，信杖劍從之，居戲下，無所知名。項梁敗，又屬項羽，羽以為郎中。數以策幹項羽，羽不用。漢王之入蜀，信亡楚歸漢，未得知名，為連敖。坐法當斬，其輩十三人皆已斬，次至信，信乃仰視，適見滕公，曰：「上不欲就天下乎？何為斬壯士！」滕公奇其言，壯其貌，釋而不斬。與語，大說之。言於上，上拜以為治粟都尉，上未之奇也。 | 等到項梁渡過淮水，信拄著劍跟從他，居於戲下（戲下：同「麾下」，將旗之下），沒有知名的地方。項梁敗，又屬項羽，項羽任他為郎中（郎中：侍從性質的官）。多次拿計策求見（幹：求見、進言）項羽，項羽不用。漢王入蜀，信逃離楚歸漢，沒有得到知名，任連敖（連敖：楚官名）。犯法當斬，他同輩十三人都已經斬了，次序輪到信，信才仰頭看，正好看見滕公，說：「上（上：指漢王）不想成就天下嗎？為什麼斬壯士！」滕公認為他的話奇特，認為他的相貌壯偉，釋放而不斬。與他談話，大為喜歡他。向漢王說，漢王拜他為治粟都尉（治粟都尉：掌管糧食的官），漢王沒有認為他奇特。 |
| 005 | 信數與蕭何語，何奇之。至南鄭，諸將行道亡者數十人，信度何等已數言上，上不我用，即亡。何聞信亡，不及以聞，自追之。人有言上曰：「丞相何亡。」上大怒，如失左右手。居一二日，何來謁上，上且怒且喜，罵何曰：「若亡，何也？」何曰：「臣不敢亡也，臣追亡者。」上曰：「若所追者誰何？」曰：「韓信也。」 | 信多次與蕭何談話，蕭何認為他奇特。到南鄭，諸將在行路中逃亡的有數十人，信揣度蕭何等人已經多次向漢王說過，漢王不任用我，就逃了。蕭何聽說信逃，來不及把這件事上報，自己去追他。有人向漢王說：「丞相蕭何逃了。」漢王大怒，像失去左右手。過了一二日，蕭何來謁見漢王，漢王又怒又喜，罵蕭何說：「你逃，為什麼？」蕭何說：「臣不敢逃，臣追逃的人。」漢王說：「你所追的是誰？」說：「韓信。」 |
| 006 | 上複罵曰：「諸將亡者以十數，公無所追；追信，詐也。」何曰：「諸將易得耳。至如信者，國士無雙。王必欲長王漢中，無所事信；必欲爭天下，非信無所與計事者。顧王策安所決耳。」王曰：「吾亦欲東耳，安能鬱鬱久居此乎？」何曰：「王計必欲東，能用信，信即留；不能用，信終亡耳。」王曰：「吾為公以為將。」 | 漢王又罵說：「諸將逃亡的以十為數，你沒有所追的；追信，是詐。」蕭何說：「諸將容易得到罷了。至於像信這樣的人，國士（國士：一國之中可當大事的人）無雙（無雙：沒有第二個）。王如果一定要長久在漢中稱王，用不著信；如果一定要爭天下，除了信沒有可以與他謀事的人。只看王的計策在哪裡決斷罷了。」王說：「我也想要向東罷了，怎麼能鬱鬱地長久居在這裡呢？」蕭何說：「王的計策如果一定要向東，能任用信，信就留下；不能任用，信終究要逃罷了。」王說：「我為了你任他為將。」 |
| 007 | 何曰：「雖為將，信必不留。」王曰：「以為大將。」何曰：「幸甚。」於是王欲召信拜之。何曰：「王素慢無禮，今拜大將如呼小兒耳，此乃信所以去也。王必欲拜之，擇良日，齋戒，設壇場，具禮，乃可耳。」王許之。諸將皆喜，人人各自以為得大將。至拜大將，乃韓信也，一軍皆驚。 | 蕭何說：「即使做將，信必定不留。」王說：「任他為大將。」蕭何說：「好極了。」於是王想要召信來拜他。蕭何說：「王向來輕慢沒有禮數，如今拜大將像呼喚小兒罷了，這正是信所以要離去的原因。王如果一定要拜他，選擇好日子，齋戒（齋戒：行禮前不飲酒、不食葷、不近內），設置壇場（壇場：土築的高台與場地），具備禮數，才可以罷了。」王允許了。諸將都歡喜，人人各自認為自己會得到大將。到拜大將時，竟是韓信，全軍都驚。 |
| 008 | 信拜禮畢，上坐。王曰：「丞相數言將軍，將軍何以教寡人計策？」信謝，因問王曰：「今東鄉爭權天下，豈非項王邪？」漢王曰：「然。」曰：「大王自料勇悍仁彊孰與項王？」漢王默然良久，曰：「不如也。」信再拜賀曰：「惟信亦為大王不如也。然臣嘗事之，請言項王之為人也。 | 信行完拜禮，入席就坐。王說：「丞相多次說起將軍，將軍拿什麼教寡人計策？」信辭謝，於是問王說：「如今向東（東鄉：向東）爭天下的權，難道不是項王嗎？」漢王說：「是。」說：「大王自己估量，勇、悍、仁、彊（彊：同「強」）與項王相比誰強？」漢王沉默了很久，說：「不如他。」信兩次下拜祝賀說：「我韓信也認為大王不如他。然而臣曾經事奉他，請讓臣說一說項王的為人。 |
| 009 | 項王喑噁叱吒，千人皆廢，然不能任屬賢將，此特匹夫之勇耳。項王見人恭敬慈愛，言語嘔嘔，人有疾病，涕泣分食飲，至使人有功當封爵者，印刓敝，忍不能予，此所謂婦人之仁也。項王雖霸天下而臣諸侯，不居關中而都彭城。有背義帝之約，而以親愛王，諸侯不平。諸侯之見項王遷逐義帝置江南，亦皆歸逐其主而自王善地。 | 項王發怒呵斥（喑噁叱吒：發怒的聲音與呵斥），千人都被壓得不能行動（廢：倒下、不能行動），然而不能任用、委託賢能的將領，這只是匹夫（匹夫：一個普通人）的勇罷了。項王見人恭敬慈愛，言語絮絮不休（嘔嘔：言語溫和絮煩的樣子），人有疾病，流著眼淚分自己的飲食給人；到了派人有功勞該當封爵的時候，印（印：官印）都摩弄到磨損（刓敝：磨損破舊），忍著捨不得給，這就是所謂婦人的仁。項王雖然稱霸天下而使諸侯臣服，不住在關中而建都彭城。又背棄義帝的約定，而把親近喜愛的人封王，諸侯心中不平。諸侯看見項王把義帝遷逐安置到江南，也都回去驅逐自己的君主，自己在好地方稱王。 |
| 010 | 項王所過無不殘滅者，天下多怨，百姓不親附，特劫於威彊耳。名雖為霸，實失天下心。故曰其彊易弱。今大王誠能反其道：任天下武勇，何所不誅！以天下城邑封功臣，何所不服！以義兵從思東歸之士，何所不散！ | 項王所經過的地方沒有不被摧殘毀滅的，天下人多怨恨，百姓不親近歸附，只是被威勢強力劫住罷了。名義上雖然是霸，實際上失了天下人的心。所以說他的彊容易變弱。如今大王果真能反過來做（反其道：反轉他那種做法）：任用天下的武勇之人，有什麼不被誅滅！拿天下的城邑封給功臣，有什麼人不服！用義兵（義兵：合乎正義的軍隊）率領想東歸的將士，有什麼不被沖散！ |
| 011 | 且三秦王為秦將，將秦子弟數歲矣，所殺亡不可勝計，又欺其眾降諸侯，至新安，項王詐阬秦降卒二十餘萬，唯獨邯、欣、翳得脫，秦父兄怨此三人，痛入骨髓。今楚彊以威王此三人，秦民莫愛也。大王之入武關，秋豪無所害，除秦苛法，與秦民約，法三章耳，秦民無不欲得大王王秦者。於諸侯之約，大王當王關中，關中民鹹知之。 | 況且三秦王（三秦王：秦地分封的三個王）本是秦的將領，率領秦的子弟好幾年了，所殺死、所亡失的不可勝計，又欺騙他們的部眾投降諸侯，到新安，項王用詐把秦的降卒二十餘萬坑殺（阬：同「坑」，活埋），唯獨邯、欣、翳得以脫身，秦的父兄怨恨這三個人，痛入骨髓。如今楚用強力憑威勢讓這三個人做王，秦的百姓沒有人愛戴他們。大王進入武關，秋毫（秋豪：同「秋毫」，喻極細微）都沒有所傷害，除去秦的苛法，與秦的百姓約定，法只有三章罷了，秦的百姓沒有不想讓大王在秦地做王的。就諸侯的約定說，大王應當在關中做王，關中的百姓都知道這件事。 |
| 012 | 大王失職入漢中，秦民無不恨者。今大王舉而東，三秦可傳檄而定也。」於是漢王大喜，自以為得信晚。遂聽信計，部署諸將所擊。 | 大王失去職分（失職：失掉應得的職位）進入漢中，秦的百姓沒有不怨恨的。如今大王起兵而向東，三秦可以傳一道檄文（檄：曉諭、徵召的文書）就平定。」於是漢王大喜，自己認為得到信太晚。就聽信的計策，部署諸將所攻擊的目標。 |
| 013 | 八月，漢王舉兵東出陳倉，定三秦。漢二年，出關，收魏、河南，韓、殷王皆降。合齊、趙共擊楚。四月，至彭城，漢兵敗散而還。信複收兵與漢王會滎陽，複擊破楚京、索之間，以故楚兵卒不能西。 | 八月，漢王舉兵向東出陳倉，平定三秦。漢二年，出關，收取魏、河南，韓王、殷王都投降。聯合齊、趙共同攻擊楚。四月，到達彭城，漢兵敗散而回。信又收集兵眾與漢王在滎陽會合，又在京、索之間攻擊破楚軍，因此楚兵終於不能西進。 |
| 014 | 漢之敗卻彭城，塞王欣、翟王翳亡漢降楚，齊、趙亦反漢與楚和。六月，魏王豹謁歸視親疾，至國，即絕河關反漢，與楚約和。漢王使酈生說豹，不下。其八月，以信為左丞相，擊魏。魏王盛兵蒲阪，塞臨晉，信乃益為疑兵，陳船欲度臨晉，而伏兵從夏陽以木罌鮓渡軍，襲安邑。魏王豹驚，引兵迎信，信遂虜豹，定魏為河東郡。 | 漢在彭城敗退，塞王欣、翟王翳背離漢投降楚，齊、趙也反漢與楚講和。六月，魏王豹請假回去探視親人的疾病，到國中，就斷絕河關（河關：黃河上的關口）反漢，與楚結約講和。漢王派酈生（酈生：酈食其）遊說豹，不能說下。這年八月，任信為左丞相，攻擊魏。魏王把兵盛聚在蒲阪，堵塞臨晉，信就更加設置疑兵，陳列船隻做出要渡臨晉的樣子，而伏兵從夏陽用木罌（木罌：木製的罌缶，可縛在身上浮水）渡軍，襲擊安邑。魏王豹驚，領兵迎信，信就俘虜豹，平定魏地為河東郡。 |
| 015 | 漢王遣張耳與信俱，引兵東，北擊趙、代。後九月，破代兵，禽夏說閼與。信之下魏破代，漢輒使人收其精兵，詣滎陽以距楚。 | 漢王派張耳與信一同，領兵向東，向北攻擊趙、代。後九月，攻破代的兵，在閼與擒獲夏說。信攻下魏、攻破代，漢就派人收取他的精兵，送到滎陽來抵拒楚。 |
| 016 | 信與張耳以兵數萬，欲東下井陘擊趙。趙王、成安君陳餘聞漢且襲之也，聚兵井陘口，號稱二十萬。廣武君李左車說成安君曰：「聞漢將韓信涉西河，虜魏王，禽夏說，新喋血閼與，今乃輔以張耳，議欲下趙，此乘勝而去國遠鬥，其鋒不可當。臣聞千里餽糧，士有饑色，樵蘇後爨，師不宿飽。 | 信與張耳率兵數萬，想要向東下井陘攻擊趙。趙王、成安君陳餘聽說漢將要襲擊他們，聚兵在井陘口，號稱二十萬。廣武君李左車遊說成安君說：「聽說漢的將領韓信渡過西河，俘虜魏王，擒獲夏說，新近在閼與喋血（喋血：踏血，形容殺戮之多），如今又輔以張耳，議想要攻下趙，這是乘勝離開本國遠道爭鬥，他的鋒不可抵擋。臣聽說從千里之外饋送糧食，兵士有饑色；打柴割草之後才燒火做飯（樵蘇後爨：先砍柴再炊煮），軍隊不能隔夜吃飽（師不宿飽：軍隊不能安穩地飽食一夜）。 |
| 017 | 今井陘之道，車不得方軌，騎不得成列，行數百裡，其勢糧食必在其後。原足下假臣奇兵三萬人，從間道絕其輜重；足下深溝高壘，堅營勿與戰。彼前不得鬥，退不得還，吾奇兵絕其後，使野無所掠，不至十日，而兩將之頭可致於戲下。原君留意臣之計。否，必為二子所禽矣。」 | 如今井陘這條道，車不能並軌（方軌：兩車並行），騎不能成列，行走數百里，那形勢糧食必定在後面。願足下借臣奇兵三萬人，從小路上斷絕他們的輜重（輜重：軍械糧草等後方物資）；足下深挖溝、高築壘，堅守營壘不要與他交戰。他們向前不能爭鬥，退後不能回去，我的奇兵斷絕他們後面，使野外沒有可掠奪的東西，不到十天，那兩個將領的頭就可以送到戲下（戲下：同「麾下」）。願君留意臣的計策。不然，必定被這兩個人擒獲了。」 |
| 018 | 成安君，儒者也，常稱義兵不用詐謀奇計，曰：「吾聞兵法十則圍之，倍則戰。今韓信兵號數萬，其實不過數千。能千里而襲我，亦已罷極。今如此避而不擊，後有大者，何以加之！則諸侯謂吾怯，而輕來伐我。」不聽廣武君策，廣武君策不用。 | 成安君，是儒者，常稱說義兵不用詐謀奇計，說：「我聽說兵法上十倍就圍他，一倍就與他戰。如今韓信的兵號稱數萬，其實不過數千。能從千里之外來襲擊我，也已經疲極（罷極：同「疲極」，極度疲勞）。如今這樣躲避而不出擊，以後有更大的敵人，拿什麼加在他們身上！那麼諸侯說我們怯，就輕易來討伐我們。」不聽廣武君的計策，廣武君的計策沒有被用。 |
| 019 | 韓信使人間視，知其不用，還報，則大喜，乃敢引兵遂下。未至井陘口三十裏，止舍。夜半傳發，選輕騎二千人，人持一赤幟，從間道萆山而望趙軍，誡曰：「趙見我走，必空壁逐我，若疾入趙壁，拔趙幟，立漢赤幟。」令其裨將傳飧，曰：「今日破趙會食！」諸將皆莫信，詳應曰：「諾。」 | 韓信派人暗中偵察（間視：伺機窺視），知道他們不用，回來報告，就大喜，才敢領兵就此下去。不到井陘口三十里，停軍宿營。半夜傳令出發，選輕騎二千人，每人拿一面赤旗，從小路上山（萆山：隱蔽於山中）而望趙軍，告誡說：「趙軍看見我逃走，必定空營出來追我，你們就趕快進入趙的營壘，拔掉趙的旗幟，立起漢的赤旗。」命令他的副將（裨將：副將）傳送飯食（飧：飯食），說：「今天破了趙再一起吃飯（會食：聚在一起吃飯）！」諸將都不信，假意答應說：「諾。」 |
| 020 | 謂軍吏曰：「趙已先據便地為壁，且彼未見吾大將旗鼓，未肯擊前行，恐吾至阻險而還。」信乃使萬人先行，出，背水陳。趙軍望見而大笑。平旦，信建大將之旗鼓，鼓行出井陘口，趙開壁擊之，大戰良久。於是信、張耳詳棄鼓旗，走水上軍。水上軍開入之，複疾戰。趙果空壁爭漢鼓旗，逐韓信、張耳。 | 對軍吏說：「趙已經先占據便利的地形築了營壘，況且他們沒有看見我的大將旗鼓，不肯攻擊前隊，怕我到險阻處就退回去。」信就派一萬人先走，出去，背著水布陣（陳：同「陣」）。趙軍望見而大笑。天亮（平旦：天大亮時），信樹立大將的旗鼓，鼓行出井陘口，趙開營壘攻擊他，大戰很久。於是信、張耳假裝（詳：同「佯」）丟棄鼓旗，走向水上的軍。水上的軍開壘放他們進去，又急戰。趙果然空營出來爭奪漢的鼓旗，追趕韓信、張耳。 |
| 021 | 韓信、張耳已入水上軍，軍皆殊死戰，不可敗。信所出奇兵二千騎，共候趙空壁逐利，則馳入趙壁，皆拔趙旗，立漢赤幟二千。趙軍已不勝，不能得信等，欲還歸壁，壁皆漢赤幟，而大驚，以為漢皆已得趙王將矣，兵遂亂，遁走，趙將雖斬之，不能禁也。於是漢兵夾擊，大破虜趙軍，斬成安君泜水上，禽趙王歇。 | 韓信、張耳已經進入水上的軍，軍都拼死作戰（殊死：拼死），不可敗。信所派出的奇兵二千騎，一同等候趙空營出來逐利，就馳入趙的營壘，都拔掉趙旗，立起漢的赤旗二千面。趙軍已經不能勝，不能捉到信等人，想要回去歸營，營壘都是漢的赤旗，於是大驚，認為漢已經把趙王、趙將都得到了，兵就亂了，逃走，趙的將領即使斬他們，也不能禁止。於是漢兵兩面夾擊，大破、俘虜趙軍，在泜水上斬成安君，擒獲趙王歇。 |
| 022 | 信乃令軍中毋殺廣武君，有能生得者購千金。於是有縛廣武君而致戲下者，信乃解其縛，東鄉對，西鄉對，師事之。 | 信就命令軍中不要殺廣武君，有能活捉他的懸賞千金（購：懸賞）。於是有把廣武君綁了送到戲下的人，信就解開他的綁，面朝東相對（東鄉對），面朝西相對（西鄉對），以師禮事奉他（師事之：像對待老師一樣事奉他）。 |
| 023 | 諸將效首虜，畢賀，因問信曰：「兵法右倍山陵，前左水澤，今者將軍令臣等反背水陳，曰破趙會食，臣等不服。然竟以勝，此何術也？」信曰：「此在兵法，顧諸君不察耳。兵法不曰『陷之死地而後生，置之亡地而後存』？ | 諸將呈獻首級與俘虜（效：呈獻），都道賀，於是問信說：「兵法上右邊和背後（右倍：右邊與背後，倍同「背」）要靠山陵，前面和左邊要臨水澤，如今將軍命令臣等反而背水布陣，說破了趙再吃飯，臣等不服。然而竟然因此得勝，這是什麼術？」信說：「這在兵法上，只是諸君沒有察覺罷了。兵法不是說『陷之死地而後生，置之亡地而後存』嗎？ |
| 024 | 且信非得素拊循士大夫也，此所謂『驅市人而戰之』，其勢非置之死地，使人人自為戰；今予之生地，皆走，甯尚可得而用之乎！」諸將皆服曰：「善。非臣所及也。」 | 況且信所率領的不是素來撫慰順從（拊循：撫慰使順從）慣了的士大夫，這就是所謂『驅趕市上的人去作戰』，那形勢不把他們放在死地，使人人為自己作戰；如今給他們可以生的地方，就都逃走，難道還能得到而使用他們嗎！」諸將都服了，說：「好。不是臣所能趕上的。」 |
| 025 | 於是信問廣武君曰：「僕欲北攻燕，東伐齊，何若而有功？」廣武君辭謝曰：「臣聞敗軍之將，不可以言勇，亡國之大夫，不可以圖存。今臣敗亡之虜，何足以權大事乎！」信曰：「僕聞之，百裡奚居虞而虞亡，在秦而秦霸，非愚於虞而智於秦也，用與不用，聽與不聽也。誠令成安君聽足下計，若信者亦已為禽矣。 | 於是信問廣武君說：「我想要向北攻擊燕，向東討伐齊，怎樣才有功？」廣武君辭謝說：「臣聽說敗軍的將領，不可以談勇；亡國的大夫，不可以圖謀生存。如今臣是敗亡的俘虜，哪裡足以權衡大事呢！」信說：「我聽說，百里奚居於虞而虞亡，在秦而秦霸，不是對虞愚而對秦智，是任用與不任用、聽從與不聽從的差別。果真讓成安君聽足下的計策，像我這樣的人也早就被擒了。 |
| 026 | 以不用足下，故信得侍耳。」因固問曰：「僕委心歸計，原足下勿辭。」廣武君曰：「臣聞智者千慮，必有一失；愚者千慮，必有一得。故曰『狂夫之言，聖人擇焉』。顧恐臣計未必足用，原效愚忠。夫成安君有百戰百勝之計，一旦而失之，軍敗鄗下，身死泜上。 | 因為不用足下，所以信得以侍奉罷了。」於是堅決地問說：「我把心交出來、把計謀歸託於您（委心歸計：傾心歸計），願足下不要推辭。」廣武君說：「臣聽說智者千次謀慮，必有一次失誤；愚者千次謀慮，必有一次得著。所以說『狂夫的話，聖人從中選擇』。只是怕臣的計策未必夠用，願意獻上愚忠。那成安君有百戰百勝的計，一旦失去它，軍隊在鄗下戰敗，身死在泜上。 |
| 027 | 今將軍涉西河，虜魏王，禽夏說閼與，一舉而下井陘，不終朝破趙二十萬眾，誅成安君。名聞海內，威震天下，農夫莫不輟耕釋耒，褕衣甘食，傾耳以待命者。若此，將軍之所長也。然而眾勞卒罷，其實難用。今將軍欲舉倦弊之兵，頓之燕堅城之下，欲戰恐久力不能拔，情見勢屈，曠日糧竭，而弱燕不服，齊必距境以自彊也。 | 如今將軍渡過西河，俘虜魏王，在閼與擒獲夏說，一舉而下井陘，不到一個早晨破趙二十萬之眾，誅成安君。名聲聞於海內，威震天下，農夫沒有不停止耕作、放下耒耜的，穿上美衣、吃甘美之食（褕衣甘食：美衣美食），側著耳朵等待命令的。像這樣，是將軍的長處。然而眾人勞苦、士卒疲弊，那實情難以使用。如今將軍想要率領疲倦困弊的兵，停頓在燕的堅城之下，想要作戰，怕時間久了力量不能攻拔，實情顯露、形勢困屈，曠日持久而糧食耗盡，而弱小的燕不服，齊必定據守邊境來使自己強固。 |
| 028 | 燕齊相持而不下，則劉項之權未有所分也。若此者，將軍所短也。臣愚，竊以為亦過矣。故善用兵者不以短擊長，而以長擊短。」韓信曰：「然則何由？」廣武君對曰：「方今為將軍計，莫如案甲休兵，鎮趙撫其孤，百裡之內，牛酒日至，以饗士大夫醳兵，北首燕路，而後遣辯士奉咫尺之書，暴其所長於燕，燕必不敢不聽從。 | 燕、齊相持而不能攻下，那麼劉、項的權力就沒有所分的了。像這樣，是將軍的短處。臣愚，私下認為這也錯了。所以善於用兵的人不拿短處攻擊長處，而拿長處攻擊短處。」韓信說：「那麼從哪裡入手？」廣武君回答說：「如今為將軍打算，不如停止軍事行動（案甲：按兵不動）、休整士卒，鎮守趙地、撫恤趙的遺孤，百里之內，牛酒天天送到，用來饗士大夫、讓兵士飲酒（醳：飲酒），向北朝著燕的道路（北首：頭朝北，指向北），然後派辯士奉上短小的書信（咫尺之書：短小的書信），在燕面前暴露他們的長處，燕必定不敢不聽從。 |
| 029 | 燕已從，使諠言者東告齊，齊必從風而服，雖有智者，亦不知為齊計矣。如是，則天下事皆可圖也。兵固有先聲而後實者，此之謂也。」韓信曰：「善。」從其策，發使使燕，燕從風而靡。乃遣使報漢，因請立張耳為趙王，以鎮撫其國。漢王許之，乃立張耳為趙王。 | 燕已經順從，派宣揚的人（諠言者：宣揚、放話的人）向東告訴齊，齊必定隨風而服，即使有智者，也不知道為齊打算了。像這樣，那麼天下的事都可以圖謀了。用兵本來就有先造聲勢而後見實際的，說的就是這個。」韓信說：「好。」聽從他的計策，派使者出使燕，燕隨風而倒（靡：倒伏）。於是派使者報告漢，趁便請求立張耳為趙王，來鎮撫趙國。漢王允許，就立張耳為趙王。 |
