| 030 | 楚數使奇兵渡河擊趙，趙王耳、韓信往來救趙，因行定趙城邑，發兵詣漢。楚方急圍漢王於滎陽，漢王南出，之宛、葉間，得黥布，走入成皋，楚又複急圍之。六月，漢王出成皋，東渡河，獨與滕公俱，從張耳軍脩武。至，宿傳舍。晨自稱漢使，馳入趙壁。張耳、韓信未起，即其臥內上奪其印符，以麾召諸將，易置之。 | 楚几次派奇兵渡河攻击赵，赵王张耳、韩信往来救赵，趁便巡行平定赵的城邑，发兵到汉去。楚正急围汉王于荥阳，汉王向南出，到宛、叶之间，得到黥布，走入成皋，楚又再急围他。六月，汉王出成皋，向东渡河，只与滕公同行，到张耳的军中于脩武。到了，宿在传舍（传舍：驿路上的客舍）。早晨自称汉的使者，驰入赵的壁垒。张耳、韩信还没有起身，（他）就在两人的卧内夺了他们的印符，用麾（麾：指挥用的旗）召来诸将，把他们一一换过位置。 |
| 031 | 信、耳起，乃知漢王來，大驚。漢王奪兩人軍，即令張耳備守趙地。拜韓信為相國，收趙兵未發者擊齊。 | 韩信、张耳起身，才知道汉王来了，大惊。汉王夺了两人的军，就命令张耳备守赵地。拜韩信为相国（相国：辅佐君主总理政务的最高官），收取赵兵中还没有发遣的，去击齐。 |
| 032 | 信引兵東，未渡平原，聞漢王使酈食其已說下齊，韓信欲止。範陽辯士蒯通說信曰：「將軍受詔擊齊，而漢獨發間使下齊，寧有詔止將軍乎？何以得毋行也！且酈生一士，伏軾掉三寸之舌，下齊七十餘城，將軍將數萬眾，歲餘乃下趙五十餘，為將數歲，反不如一豎儒之功乎？」於是信然之，從其計，遂渡河。 | 韩信领兵向东，还没有渡平原，听说汉王派郦食其已经把齐说降了，韩信想要停止。范阳的辩士蒯通游说韩信说：「将军受诏击齐，而汉另外派密使（间使：秘密的使者）下齐，难道有诏叫将军停止吗？凭什么可以不前行呢！况且郦生一个士人，伏在车轼上（轼：车前横木）摇动三寸之舌，下齐七十余城；将军率领数万众，一年多才下赵五十余城，为将几年，反而比不上一个竖儒（竖儒：对儒生的鄙称）的功劳吗？」于是韩信认为他说得对，听从他的计，就渡河。 |
| 033 | 齊已聽酈生，即留縱酒，罷備漢守禦信因襲齊曆下軍，遂至臨菑。齊王田廣以酈生賣己，乃亨之，而走高密，使使之楚請救。韓信已定臨菑，遂東追廣至高密西。楚亦使龍且將，號稱二十萬，救齊。 | 齐已经听信郦生，就留他纵酒，撤了防备汉军的守御，韩信趁势袭击齐的历下军，于是到临菑。齐王田广认为郦生出卖自己，就烹（亨：通「烹」，煮）了他，而逃到高密，派使者到楚请救。韩信已经平定临菑，就向东追田广到高密以西。楚也派龙且率领（军队），号称二十万，救齐。 |
| 034 | 齊王廣、龍且並軍與信戰，未合。人或說龍且曰：「漢兵遠鬥窮戰，其鋒不可當。齊、楚自居其地戰，兵易敗散。不如深壁，令齊王使其信臣招所亡城，亡城聞其王在，楚來救，必反漢。漢兵二千里客居，齊城皆反之，其勢無所得食，可無戰而降也。」龍且曰：「吾平生知韓信為人，易與耳。且夫救齊不戰而降之，吾何功？ | 齐王田广、龙且合军与韩信战，还没有交锋。有人游说龙且说：「汉兵远来苦战，它的锋芒不可挡。齐、楚在自己地上作战，兵容易败散。不如深沟高垒（壁：壁垒），让齐王派他的亲信之臣招回已经降亡的城，亡城听说他们的王还在、楚来救，必定反汉。汉兵客居二千里外，齐城都反他们，那形势（他们）弄不到吃的，可以不战而降。」龙且说：「我平生知道韩信的为人，容易对付罢了。况且救齐不战就让他降，我有什么功？ |
| 035 | 今戰而勝之，齊之半可得，何為止！」遂戰，與信夾濰水陳。韓信乃夜令人為萬餘囊，滿盛沙，壅水上流，引軍半渡，擊龍且，詳不勝，還走。龍且果喜曰：「固知信怯也。」遂追信渡水。信使人決壅囊，水大至。龍且軍大半不得渡，即急擊，殺龍且。龍且水東軍散走，齊王廣亡去。信遂追北至城陽，皆虜楚卒。 | 现在战而胜他，齐的一半可以得到，为什么要停！」于是就战，与韩信隔着濰水布阵（陈：同「阵」）。韩信就夜里令人做一万多个袋子，装满沙，堵住上流，领兵一半渡水，攻击龙且，假装（詳：同「佯」，假装）不能取胜，退回走。龙且果然高兴说：「本来就知道韩信胆小。」就追韩信渡水。韩信派人决开堵水的沙囊，水大至。龙且的军大半不能渡，就急击，杀龙且。龙且在水的东边的军散走，齐王田广逃走。韩信就追败北的（军）到城阳，把楚的卒全部俘虏。 |
| 036 | 漢四年，遂皆降平齊。使人言漢王曰：「齊偽詐多變，反覆之國也，南邊楚，不為假王以鎮之，其勢不定。原為假王便。」當是時，楚方急圍漢王於滎陽，韓信使者至，發書，漢王大怒，罵曰：「吾困於此，旦暮望若來佐我，乃欲自立為王！」張良、陳平躡漢王足，因附耳語曰：「漢方不利，寧能禁信之王乎？ | 汉四年，（齐）就都降了、平定了齐。派人对汉王说：「齐伪诈多变，是反复之国，南边挨着楚，不设假王（假王：代理的王，非正式受封）来镇住它，那形势定不下来。希望让我做假王，便利。」在这个时候，楚正急围汉王于荥阳，韩信的使者到，发开书信，汉王大怒，骂道：「我被困在这里，早晚盼着你能来佐我，你却想自立为王！」张良、陈平踩汉王的脚，就附耳说：「汉正不利，难道能禁止韩信称王吗？ |
| 037 | 不如因而立，善遇之，使自為守。不然，變生。」漢王亦悟，因複罵曰：「大丈夫定諸侯，即為真王耳，何以假為！」乃遣張良往立信為齊王，徵其兵擊楚。 | 不如趁势立他，好好待他，让他自己守（那里）。不然，变故生。」汉王也醒悟，就再骂道：「大丈夫平定诸侯，就是真王罢了，为什么用假（王）！」就派张良去立韩信为齐王，征他的兵击楚。 |
| 038 | 楚已亡龍且，項王恐，使盱眙人武涉往說齊王信曰：「天下共苦秦久矣，相與戮力擊秦。秦已破，計功割地，分土而王之，以休士卒。今漢王復興兵而東，侵人之分，奪人之地，已破三秦，引兵出關，收諸侯之兵以東擊楚，其意非盡吞天下者不休，其不知厭足如是甚也。 | 楚已经失掉龙且，项王恐惧，派盱眙人武涉前往游说齐王韩信说：「天下共同苦于秦很久了，相互并力击秦。秦已破，计功割地，分土而封他们为王，以休养士卒。如今汉王又兴兵向东，侵入别人的分（分：分封的份地），夺人的地，已破三秦，领兵出关，收取诸侯的兵向东击楚，他的意思不是把天下吞尽不肯停，他不知满足到这样厉害。 |
| 039 | 且漢王不可必，身居項王掌握中數矣，項王憐而活之，然得脫，輒倍約，複擊項王，其不可親信如此。今足下雖自以與漢王為厚交，為之盡力用兵，終為之所禽矣。足下所以得須臾至今者，以項王尚存也。當今二王之事，權在足下。足下右投則漢王勝，左投則項王勝。項王今日亡，則次取足下。 | 况且汉王不可以（必：信赖、断定），他自身落在项王掌握中几次了，项王怜惜而让他活，然而（他）得脱，就背约，又击项王，他不可亲信到这样。如今足下虽然自以为与汉王是厚交，为他尽力用兵，最终要被他擒了。足下所以能够片刻到今天，是因为项王还在。当今二王的事，权在足下。足下向右投，汉王就胜；向左投，项王就胜。项王今天亡，那么下一个取足下。 |
| 040 | 足下與項王有故，何不反漢與楚連和，參分天下王之？今釋此時，而自必於漢以擊楚，且為智者固若此乎！」韓信謝曰：「臣事項王，官不過郎中，位不過執戟，言不聽，畫不用，故倍楚而歸漢。漢王授我上將軍印，予我數萬眾，解衣衣我，推食食我，言聽計用，故吾得以至於此。夫人深親信我，我倍之不祥，雖死不易。幸為信謝項王！」 | 足下与项王有旧交，为什么不反汉与楚联合和好，三分天下而称王？如今放弃这个时候，而自己一定于汉来击楚，况且作为智者本当这样吗！」韩信谢说：「臣事奉项王，官不过郎中（郎中：宿卫侍从之官），位不过执戟（执戟：执戟的卫士），言不听，画（画：计谋）不用，所以背楚而归汉。汉王授我上将军印，给我数万众，脱下衣服给我穿，推过（自己的）食物给我吃，言听计用，所以我得以到这里。人家深深亲信我，我背他不祥，虽然死也不变。希望替我谢过项王！」 |
| 041 | 武涉已去，齊人蒯通知天下權在韓信，欲為奇策而感動之，以相人說韓信曰：「僕嘗受相人之術。」韓信曰：「先生相人何如？」對曰：「貴賤在於骨法，憂喜在於容色，成敗在於決斷，以此參之，萬不失一。」韓信曰：「善。先生相寡人何如？」對曰：「原少間。」信曰：「左右去矣。」通曰：「相君之面，不過封侯，又危不安。 | 武涉已经走了，齐人蒯通知道天下的权在韩信手里，想用奇策打动他，用相人（相人：看相）之说游说韩信说：「我曾经受过相人的方术。」韩信说：「先生相人怎么样？」回答说：「贵贱在于骨法（骨法：骨相），忧喜在于容色，成败在于决断，用这三样参验，万不失一。」韩信说：「好。先生相寡人怎么样？」回答说：「请稍等一下。」韩信说：「左右已经走了。」蒯通说：「相君的面，不过封侯，而且又危又不安。 |
| 042 | 相君之背，貴乃不可言。」韓信曰：「何謂也？」蒯通曰：「天下初發難也，俊雄豪桀建號壹呼，天下之士雲合霧集，魚鱗櫜鵷，熛至風起。當此之時，憂在亡秦而已。今楚漢分爭，使天下無罪之人肝膽塗地，父子暴骸骨於中野，不可勝數。楚人起彭城，轉鬥逐北，至於滎陽，乘利席捲，威震天下。 | 相君的背，贵得没法说。」韩信说：「这话怎么说？」蒯通说：「天下刚发难的时候，俊雄豪杰建号一呼，天下的士人像云一样合、像雾一样集，像鱼鳞、像鸟翅，像火星飞、像风起。在这个时候，愁的只是亡秦罢了。如今楚汉分争，使天下的无罪之人肝脑涂地，父子暴骨于中原，数都数不过来。楚人从彭城起，转斗逐北，到荥阳，乘利席卷，威震天下。 |
| 043 | 然兵困於京、索之間，迫西山而不能進者，三年於此矣。漢王將數十萬之眾，距鞏、雒，阻山河之險，一日數戰，無尺寸之功，折北不救，敗滎陽，傷成皋，遂走宛、葉之間，此所謂智勇俱困者也。夫銳氣挫於險塞，而糧食竭於內府，百姓罷極怨望，容容無所倚。以臣料之，其勢非天下之賢聖固不能息天下之禍。當今兩主之命縣於足下。 | 然而兵困在京、索之间，被西山所迫而不能进，到现在三年了。汉王率领几十万的众，在巩、雒相拒，靠着山河的险，一天交战几次，没有尺寸之功，折北不能救，荥阳败了，成皋伤了，就跑到宛、叶之间，这就是所谓智勇俱困。那锐气在险塞上挫了，粮食在内府里竭了，百姓疲极怨望，惶惶没有依靠。以臣料想，那形势不是天下的贤圣就不能息天下的祸。当今两主的命悬（县：同「悬」）在足下。 |
| 044 | 足下為漢則漢勝，與楚則楚勝。臣原披腹心，輸肝膽，效愚計，恐足下不能用也。誠能聽臣之計，莫若兩利而俱存之，參分天下，鼎足而居，其勢莫敢先動。夫以足下之賢聖，有甲兵之眾，據彊齊，從燕、趙，出空虛之地而制其後，因民之欲，西鄉為百姓請命，則天下風走而回應矣，孰敢不聽！ | 足下替汉，汉就胜；跟楚，楚就胜。臣愿意披腹心、输肝胆，献愚计，怕足下不能用。真能听臣的计，不如两边都利而都保存下来，三分天下，鼎足而居（鼎足：像鼎的三只脚并立），那形势没有谁敢先动。凭着足下的贤圣，有甲兵之众，据着强齐，联合燕、赵，从空虚的地方出兵而制住他们的后方，顺着百姓的愿望，向西替百姓请命，天下就会像风一样走、像回声一样应，谁敢不听！ |
| 045 | 割大弱彊，以立諸侯，諸侯已立，天下服聽而歸德於齊。案齊之故，有膠、泗之地，懷諸侯以德，深拱揖讓，則天下之君王相率而朝於齊矣。蓋聞天與弗取，反受其咎；時至不行，反受其殃。原足下孰慮之。」 | 割大的、削强的，来立诸侯，诸侯已经立了，天下服听而归德于齐。按齐的旧地，有胶、泗之地，用德怀诸侯，拱手谦让，天下的君王就一个接一个来朝于齐了。听说天给的不要，反受其咎；时到了不动，反受其殃。希望足下仔细考虑这件事。」 |
| 046 | 韓信曰：「漢王遇我甚厚，載我以其車，衣我以其衣，食我以其食。吾聞之，乘人之車者載人之患，衣人之衣者懷人之憂，食人之食者死人之事，吾豈可以鄉利倍義乎！」蒯生曰：「足下自以為善漢王，欲建萬世之業，臣竊以為誤矣。始常山王、成安君為布衣時，相與為刎頸之交，後爭張黶、陳澤之事，二人相怨。 | 韩信说：「汉王待我很厚，用他的车让我坐，用他的衣让我穿，用他的食让我吃。我听说，坐人家车的，担人家的患；穿人家衣的，怀人家的忧；吃人家食的，为人家的职事而死，我难道可以向着利而背义吗！」蒯生说：「足下自以为与汉王相善，想建立万世之业，臣私下以为错了。起初常山王、成安君还是布衣时，相互成为刎颈之交（刎颈之交：以死相许的交情），后来争张黡、陈泽的事，二人相怨。 |
| 047 | 常山王背項王，奉項嬰頭而竄，逃歸於漢王。漢王借兵而東下，殺成安君泜水之南，頭足異處，卒為天下笑。此二人相與，天下至驩也。然而卒相禽者，何也？患生於多欲而人心難測也。今足下欲行忠信以交於漢王，必不能固於二君之相與也，而事多大於張黶、陳澤。故臣以為足下必漢王之不危己，亦誤矣。 | 常山王背项王，捧着项婴的头逃窜，逃归汉王。汉王借兵而东下，在泜水之南杀成安君，头和脚分在两处，终于被天下笑。这两个人相交，是天下最欢的。然而最终互相擒住，为什么？患生于多欲而人心难测。如今足下想行忠信来交于汉王，必定不能比二君的交情更固，而事情大多比张黡、陈泽（的事）大。所以臣以为足下断定汉王不会危害自己，也错了。 |
