> 原文 014–029，十六段，一千五百余字。
> 一万人背对河水列阵，对面是号称二十万的赵军。赵军在壁上看见了，笑出声来。
> **这一仗的胜负，在前一夜就布置完了。**

## 二、情节点

### 情节点 1 · 二十万对几万

> 韩信带着张耳往东，要下井陉口去打赵。
>
> 赵王和成安君陈馀听说汉军要来偷袭，把兵聚在井陉口。
>
> 「信與張耳以兵數萬，欲東下井陘擊趙。趙王、成安君陳餘聞漢且襲之也，聚兵井陘口，號稱二十萬。」
>
> ——韩信和张耳带着几万兵，要往东下井陉去打赵。赵王、成安君陈馀听说汉军将要袭击他们，把兵聚在井陉口，号称二十万。
>
> 「號稱」是赵人自己报的数。二十万在壁上，几万在道里。

| 标记 | ◆ |
| 原文 | `016` 信與張耳以兵數萬，欲東下井陘擊趙。 |
| 依据 | `016`「趙王、成安君陳餘聞漢且襲之也，聚兵井陘口，號稱二十萬」 |

| 说明 | 「號稱」是报出来的数。**底本写这两个字，不担保实数** |
| 说明 | 汉这边的兵一直说不准：`018` 说「其實不過數千」，`019` 又出来「輕騎二千人」 |

---

### 情节点 2 · 广武君的计

> 赵军里有人看得很清楚。
>
> 广武君李左车对成安君说：韩信这一路，是先胜之后离了本国、远道来斗的，锋不可当。远道运粮的人，脸上有饿色。
>
> 「臣聞千里餽糧，士有饑色，樵蘇後爨，師不宿飽。」
>
> ——我听说，从千里之外送粮，兵士就有饿色；要现打柴草才做饭，军队就吃不上一顿饱的。
>
> 他说，井陉这条路窄，车不能并行，骑不能成列，走上几百里，粮食一定落在后头。
>
> 然后他请兵：
>
> 「原足下假臣奇兵三萬人，從間道絕其輜重；足下深溝高壘，堅營勿與戰。」
>
> ——请足下借我三万人，从小路去断绝他们的辎重；足下深挖壕沟、高筑营垒，守住营盘不要出战。
>
> 他连日子都算好了：
>
> 「不至十日，而兩將之頭可致於戲下。」
>
> ——不到十天，那两个人的头就能送到你的帐下。

| 标记 | ◆ |
| 原文 | `017` 原足下假臣奇兵三萬人，從間道絕其輜重；足下深溝高壘，堅營勿與戰。 |
| 依据 | `016`「臣聞千里餽糧，士有饑色」；`017`「今井陘之道，車不得方軌，騎不得成列」「不至十日，而兩將之頭可致於戲下」 |

| 说明 | 他的计分两半：三万人断粮道，主力守营不出。**不要打赢，只要熬到对方没饭吃** |
| 说明 | 「原」是「愿」，求的意思。**他在求兵权，不是在下命令** |
| 说明 | 这一计成不成，全看赵军肯不肯守。**下一段就有人不肯** |

### 情节点 3 · 成安君不听

> 成安君是儒者。他常常说，义兵不用诈谋奇计。
>
> 他回答广武君：
>
> 「吾聞兵法十則圍之，倍則戰。今韓信兵號數萬，其實不過數千。」
>
> ——我听说兵法上：十倍于敌人就围他，一倍于敌人就战。如今韩信号称几万，其实不过几千。
>
> 他接着说：几千里跑来偷袭，已经疲极。这样还躲着不打，以后来了更大的，拿什么对付？诸侯会说他怯，轻易来打他。
>
> 于是他不听。
>
> 「不聽廣武君策，廣武君策不用。」
>
> ——他没有听广武君的计策。广武君的计策没有被用。
>
> 这一句说了两遍。同一件事，连着说了两次。

| 标记 | ◆ |
| 原文 | `018` 成安君，儒者也，常稱義兵不用詐謀奇計，曰：「吾聞兵法十則圍之，倍則戰。……」 |
| 依据 | `018`「吾聞兵法十則圍之，倍則戰」「今韓信兵號數萬，其實不過數千」「不聽廣武君策，廣武君策不用」 |

| 说明 | 成安君驳的是「避而不击」，不是「计不成」。**他怕的是被人说怯** |
| 说明 | 「義兵不用詐謀奇計」是他平日的主张。**这一仗他不是没想到奇计，是不肯用** |
| 说明 | 一句连说两遍，是记这件事的人留下的分量。**计策本身没有错，错在没有被用** |

---

### 情节点 4 · 夜半传发

> 韩信派人去探。探到成安君没有用广武君的计，回来报。韩信大喜，这才敢带兵往下走。
>
> 离井陉口三十里，停下宿营。
>
> 半夜传令出发。他挑了两千轻骑，每人拿一面红旗，从小路绕上山，望着赵军的动静。
>
> 交代的话很具体：
>
> 「趙見我走，必空壁逐我，若疾入趙壁，拔趙幟，立漢赤幟。」
>
> ——赵军看见我退走，一定全营出来追我。你们就赶快进赵营，把赵的旗拔掉，插上汉军的红旗。
>
> 然后他让副将传饭，说：
>
> 「今日破趙會食！」
>
> ——今天破了赵，再一起吃饭。
>
> 诸将都不信，照样应了一声：诺。
>
> 他先对军吏交代了一句：赵军已经占了好地形筑好营垒；他们没有看见我的大将旗鼓，不会出来打前队，怕我到了险处就退回去。
>
> 然后才派一万人先走。出了井陉口，背对河水列阵。
>
> 「信乃使萬人先行，出，背水陳。趙軍望見而大笑。」
>
> ——韩信让一万人先出去，背对河列阵。赵军在壁上看见，大笑。

| 标记 | ◆ |
| 原文 | `019` 夜半傳發，選輕騎二千人，人持一赤幟，從間道萆山而望趙軍 |
| 依据 | `019`「趙見我走，必空壁逐我，若疾入趙壁，拔趙幟，立漢赤幟」「今日破趙會食」；`020`「信乃使萬人先行，出，背水陳」「趙軍望見而大笑」 |

| 说明 | 两千轻骑带的是**红旗**，不是兵器之外的东西。他们要做的只有一件事：换旗 |
| 说明 | 「破趙會食」是当着诸将说的。**他们说「诺」，不信** |
| 说明 | 背水之前先有判断：对面看不见大将旗鼓就不敢打前队。**背水不是赌气，是算过的** |

### 情节点 5 · 水上军

> 天一亮，他竖起大将的旗鼓，一路鼓行，出井陉口。
>
> 赵军开壁出来打。大战很久。
>
> 于是韩信、张耳佯装败退，丢下旗鼓，往水上的军退。
>
> 水上军开壁放他们进去，又回身急战。
>
> 「趙果空壁爭漢鼓旗，逐韓信、張耳。」
>
> ——赵军果然空营出来争夺汉军的旗鼓，追赶韩信、张耳。
>
> 进了水上军的韩信、张耳，背后是河。那一军的兵，没有一个还有退路。

| 标记 | ◆ |
| 原文 | `020` 於是信、張耳詳棄鼓旗，走水上軍。水上軍開入之，複疾戰。 |
| 依据 | `020`「趙開壁擊之，大戰良久」「趙果空壁爭漢鼓旗，逐韓信、張耳」；`021`「軍皆殊死戰，不可敗」 |

| 说明 | 「詳」是「佯」：丢旗鼓是故意的。**赵军抢的是旗鼓，不是人** |
| 说明 | 水上军「開入之」——开壁放自己人进去。**退路是阵里，不是岸上** |

---

### 情节点 6 · 拔赵帜

> 赵军的营空了。
>
> 那两千骑一直在山上等着。看见赵军全营出来逐利，他们驰下来，进了赵营。
>
> 「皆拔趙旗，立漢赤幟二千。」
>
> ——把赵的旗全拔掉，插上汉军的红旗，两千面。
>
> 赵军打不赢，又捉不到韩信这些人，想回营。营壁上都成了汉军的红旗。
>
> 「趙軍已不勝，不能得信等，欲還歸壁，壁皆漢赤幟，而大驚」
>
> ——赵军已经打不赢，又捉不到韩信这些人，想回营去；营壁上都成了汉军的红旗，于是大惊。
>
> 他们以为汉军已经把赵王和赵将都拿下了。兵就乱了，逃。赵将斩逃兵，也禁不住。
>
> 汉兵两面夹击，大破赵军。成安君被斩在泜水上，赵王歇被擒。

| 标记 | ◆ |
| 原文 | `021` 皆拔趙旗，立漢赤幟二千。 |
| 依据 | `021`「信所出奇兵二千騎，共候趙空壁逐利，則馳入趙壁」「以為漢皆已得趙王將矣，兵遂亂，遁走」「於是漢兵夾擊，大破虜趙軍，斬成安君泜水上，禽趙王歇」 |

| 说明 | 胜负不在河边的死战，在营壁上的颜色。**两千人的活，是换两千面旗** |
| 说明 | 「以為漢皆已得趙王將矣」——赵军是照着旗判断的。**他们怕的不是汉兵，是营里已经没有自己的人** |

### 情节点 7 · 诸将问

> 仗打完了。诸将献上首级和俘虏，向韩信贺过，然后问：
>
> 「兵法右倍山陵，前左水澤，今者將軍令臣等反背水陳，曰破趙會食，臣等不服。然竟以勝，此何術也？」
>
> ——兵法上说，右边和背后要靠着山陵，前面和左边要临着水泽。这回将军却叫我们反过来背水列阵，还说破了赵再吃饭，我们不服。可是竟然胜了，这是什么办法？
>
> 韩信说：这在兵法上，只是诸君没有看出来。
>
> 「兵法不曰『陷之死地而後生，置之亡地而後存』？」
>
> ——兵法上不是说：把人放在死地上，然后才得生；放在亡地上，然后才得存？
>
> 然后他说自己这一军是什么兵：
>
> 「且信非得素拊循士大夫也，此所謂『驅市人而戰之』，其勢非置之死地，使人人自為戰；今予之生地，皆走，甯尚可得而用之乎！」
>
> ——再说，我并没有素来抚慰惯了的将士，这就是所谓赶着市上的人去打仗。这种情形下，不把他们放在死地、让人人为自己拼命，是不行的。要是给了他们可以活的地方，都跑了，还怎么用得上！
>
> 诸将都服了，说：好。这不是我们能赶上的。

| 标记 | ◆ |
| 原文 | `023` 信曰：「此在兵法，顧諸君不察耳。兵法不曰『陷之死地而後生，置之亡地而後存』？ |
| 依据 | `023`「兵法右倍山陵，前左水澤，今者將軍令臣等反背水陳」「陷之死地而後生，置之亡地而後存」；`024`「此所謂『驅市人而戰之』」「諸將皆服曰：『善。非臣所及也』」 |

| 说明 | 他答的不是「我比兵法强」，是「你们没有看全」。**他说这话在兵法里** |
| 说明 | 他给这一军下的定义是「驱市人而战之」（`024`）。**这军不是他练出来的：精兵被调走了**（`015`） |
| 说明 | 「陷之死地」不是目的，是**没有别的办法**：给了活路，人就走 |

### 情节点 8 · 师事广武君

> 仗还没收拾完，韩信先下了一道令：军中不许杀广武君；有能活捉他的，赏千金。
>
> 有人把广武君绑了，送到帐下。
>
> 「信乃解其縛，東鄉對，西鄉對，師事之。」
>
> ——韩信解开他的绑，让他面朝东，自己面朝西相对而坐，以师礼待他。
>
> 然后他问：我想北攻燕、东伐齐，怎么才有功？
>
> 广武君推辞：
>
> 「臣聞敗軍之將，不可以言勇，亡國之大夫，不可以圖存。」
>
> ——我听说，败军之将不可以谈勇，亡国的大夫不可以图存。
>
> 韩信不接这个推辞，把话说到自己身上：
>
> 「誠令成安君聽足下計，若信者亦已為禽矣。」
>
> ——假如成安君听了足下的计策，像我这样的人，也早就被擒了。
>
> 韩信不放，又请他一次。广武君这才开口，先说了一句：
>
> 「臣聞智者千慮，必有一失；愚者千慮，必有一得。」
>
> ——我听说，智者千次谋虑，必有一次失；愚者千次谋虑，必有一次得。
>
> 他的办法是：停甲休兵，镇赵、抚恤赵的遗孤；牛酒天天送到，慰劳士大夫；然后摆出北向燕国的架势，派一个能说的人带一封信去，把长处摆在燕面前。燕不敢不听。
>
> 「方今為將軍計，莫如案甲休兵，鎮趙撫其孤」
>
> ——如今为将军打算，不如收起甲兵、休整士卒，镇住赵地，抚恤赵的遗孤。
>
> 燕服了，再让人往东告诉齐。齐会跟着服。他还留了一句：
>
> 「兵固有先聲而後實者，此之謂也。」
>
> ——用兵本来就有先造声势、后见实际的，说的就是这个。
>
> 韩信说好，照他的计办。派使者去燕，燕从风而靡。
>
> 然后他派人报汉，请立张耳为赵王，镇抚赵地。汉王答应了。

| 标记 | ◆ |
| 原文 | `022` 信乃解其縛，東鄉對，西鄉對，師事之。 |
| 依据 | `022`「信乃令軍中毋殺廣武君，有能生得者購千金」；`025`「臣聞敗軍之將，不可以言勇，亡國之大夫，不可以圖存」；`026`「臣聞智者千慮，必有一失；愚者千慮，必有一得」；`028`「莫如案甲休兵，鎮趙撫其孤」；`029`「兵固有先聲而後實者」「從其策，發使使燕，燕從風而靡」 |

| 说明 | 「東鄉對，西鄉對」是坐向：广武君东向，韩信西向。**东向是上位** |

| 说明 | 广武君的第二条计（先声后实）与第一条同路：**不硬打，先摆出样子** |

## 四、背景卡

### 井陉 ○

井陉是太行山的一条隘道，从河北入山西的咽喉。`017` 说它「車不得方軌，騎不得成列」——车不能并排，骑兵不能成列。

道窄，粮就在后头。广武君的整个计策，就是从这句话里长出来的。

> **依据**：`016`「今井陉之道」；`017`「車不得方軌，騎不得成列，行數百裡，其勢糧食必在其後」。**隘道的具体里程，这十六段里没有**；「太行八陉之一」是后世的说法。

---

### 广武君李左车 ○

赵的谋臣，封广武君。`016` 第一次出现时写全了他的名字。

他献的计没有被用；赵军破后，被绑到韩信帐下，反过来成了韩信的先生。

> **依据**：`016`「廣武君李左車說成安君曰」；`022`「信乃解其縛，東鄉對，西鄉對，師事之」。**他的出身、籍贯，这十六段里没有**。

---

### 成安君陈馀 ○

名陈馀，封成安君，这一仗赵方拿主意的是他。`018` 用一句「儒者也」交代他：常称义兵不用诈谋奇计。

他不听广武君的计，理由是「十則圍之，倍則戰」，以及不愿意被诸侯说怯。

> **依据**：`018`「成安君，儒者也，常稱義兵不用詐謀奇計」「不聽廣武君策」；`021`「斬成安君泜水上」。**他与张耳旧日的交情，这十六段里没有**。

---

### 背水陈 ○

「陈」是阵。「背水陈」是把阵摆在河的前面，背后没有退路。

《兵法》的常法是「右倍山陵，前左水澤」——背后靠山，前面临水。背水正好相反，所以赵军在壁上大笑。

> **依据**：`020`「信乃使萬人先行，出，背水陳。趙軍望見而大笑」；`023`「兵法右倍山陵，前左水澤」。**「背水阵」作为一个阵名，是后人的说法**；`020` 只写这三个字。

---

### 赤帜 ○

汉军的旗帜是赤色。`019` 让两千人「人持一赤幟」，`021` 记他们「立漢赤幟二千」。

两千面旗插上赵壁，赵军回头看见的不是人数，是颜色。

> **依据**：`019`「人持一赤幟」；`021`「皆拔趙旗，立漢赤幟二千」。**汉军为什么尚赤，这十六段里没有**。

---

### 传飧与会食 ○

「飧」是饭食。「傳飧」是分发饭食。「會食」是一起吃饭。

`019` 记韩信让副将传飧，说的却是「今日破趙會食」——饭先发下去，吃的日子定在破赵之后。

> **依据**：`019`「令其裨將傳飧，曰：『今日破趙會食！』諸將皆莫信，詳應曰：『諾』」。**「会食」是否另有一层军令的意思，后人有异说**。

---

### 泜水与鄗下 ○

成安君死的地方。`021` 记「斬成安君泜水上」，`026` 广武君追述时作「軍敗鄗下，身死泜上」。

两个地名，一处是战场，一处是他身死之处。

> **依据**：`021`「斬成安君泜水上，禽趙王歇」；`026`「軍敗鄗下，身死泜上」。**二地的今地，属后世地理考证**。

## 七、设计说明

> **这一节编译器跳过，不渲染。** 放「为什么这么写」。

**八个情节点，覆盖 `014`–`029`。** 前三段写对面的判断：号二十万、广武君的计、成安君不用。第四段是布置，第五、六段是打，第七段是回来解释，第八段是把败军之将请成先生。

**布置一段（情节点 4）占全篇最重。** `019` 里有三件事必须讲清：两千轻骑、人持一赤帜、破赵会食。这三件是胜负的全部内容；不先讲，后面的胜就成了运气。

**背水不是蛮干，理由在 `024`。** 韩信自己说得很清楚：这一军不是他素来抚练的，是「驅市人而戰之」；精兵早在 `015` 被汉王调走了。给了活路就会跑，所以只能背水。**这句解释放在诸将发问之后，是照底本的次序**，不是补上去的。

**`023` 的问答是这一篇的出口。** 诸将问的是兵法，韩信答的也是兵法：不是他违背了兵法，是诸将没有看全。**「陷之死地而後生」不是他的发明，是他引的**。

**人物次序照底本。** `022` 记广武君被缚、解缚、师事之，在 `023` 诸将发问之前。这一篇没有把两件事调换顺序，也没有把「师事」挪到最后当收束；**收束是 `029`：燕从风而靡，请立张耳为赵王**。

**标记全 ◆，训释退到背景卡。** 「背水陈」是不是阵名、「传飧」是什么意思、汉军为什么尚赤——三条都是后人训释，标 ○；年份、地理、井陉的今地标 ○ 外证。正文只用这十六段里的东西。
