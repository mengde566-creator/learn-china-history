> 原文 004–013，十段，近千字。
> 一个在项羽帐下说话没人听的人，跑到汉王这边，还是没人知道他。
> **他逃走的那一两天，丞相骑马追了出去；追回来之后，汉王为他筑了一个坛。**

## 二、情节点

### 情节点 1 · 刑场

> 他犯的是哪一条法，没有留下来。
>
> 按军法，当斩。同案的十三个人已经斩完了，轮到他。
>
> 「坐法當斬，其輩十三人皆已斬，次至信，信乃仰視，適見滕公」
>
> ——他犯了法当斩。同辈十三人都已经斩了，次序轮到他。韩信抬起头，正好看见滕公。
>
> 他喊了一句：
>
> 「上不欲就天下乎？何為斬壯士！」
>
> ——汉王不是想要取天下吗？为什么要斩壮士！
>
> 滕公觉得这话不寻常，又看他相貌壮伟，没有杀他。谈过之后，很喜欢他，去跟汉王说了。
>
> 汉王让他做治粟都尉。管粮的官。汉王还是没有看出他有什么特别。

| 标记 | ◆ |
| 原文 | `004` 坐法當斬，其輩十三人皆已斬，次至信，信乃仰視，適見滕公，曰：「上不欲就天下乎？何為斬壯士！」 |
| 依据 | `004`「滕公奇其言，壯其貌，釋而不斬。與語，大說之」「上拜以為治粟都尉，上未之奇也」 |

| 说明 | 十三个已经斩了。**他是在刀落过十三次之后才开口的** |
| 说明 | 「上不欲就天下乎」——在刑场上，他问的是「天下」。**这一句救了他，证据是「奇其言」** |
| 说明 | 救他的是两样：言、貌。**汉王那边只给了一个小官：上未之奇也** |

---

### 情节点 2 · 追

> 韩信和萧何谈过几次。萧何觉得他不寻常。这件事，韩信自己也知道。
>
> 到南郑以后，诸将在路上逃跑的有几十个。韩信估量萧何已经向汉王说过好几次，汉王不用他，于是也走了。
>
> 「何聞信亡，不及以聞，自追之。」
>
> ——萧何听说韩信走了，来不及上报，自己去追。
>
> 有人去跟汉王说：丞相跑了。
>
> 汉王大怒。那样子，像失去了左右手。
>
> 过了一两天，萧何回来求见。汉王又怒又喜，骂他：
>
> 「若亡，何也？」
>
> ——你也跑，为什么？
>
> 萧何说：
>
> 「臣不敢亡也，臣追亡者。」
>
> ——我不敢跑。我去追跑的人。
>
> 汉王问：你追的是谁。萧何答：韩信。

| 标记 | ◆ |
| 原文 | `005` 信度何等已數言上，上不我用，即亡。何聞信亡，不及以聞，自追之。 |
| 依据 | `005`「不及以聞，自追之」「上大怒，如失左右手」「臣不敢亡也，臣追亡者」 |

| 说明 | 「不及以聞」——来不及上报。**追一个人，是连上报都等不及的事** |
| 说明 | 汉王骂的是「若亡」：他以为连丞相也跑了。**「如失左右手」是他当时的反应** |
| 说明 | 萧何的回答只有八个字：不敢跑，追跑的人。**他没有先说是谁** |

---

### 情节点 3 · 国士无双

> 汉王又骂他：
>
> 「諸將亡者以十數，公無所追；追信，詐也。」
>
> ——跑掉的将军有几十个，你一个都不追；追韩信，是骗我。
>
> 萧何的回答里有一句，后来一直被人引用：
>
> 「諸將易得耳。至如信者，國士無雙。」
>
> ——那些将军容易得。至于韩信这样的人，国士里没有第二个。
>
> 然后他把两种打算分开摆出来：
>
> 「王必欲長王漢中，無所事信；必欲爭天下，非信無所與計事者。」
>
> ——汉王若一定要长久地在汉中称王，用不上韩信；若一定要争天下，除了韩信，没有能一起谋事的人。
>
> 汉王说：我也想向东去，怎么能一直闷在这里。
>
> 萧何说：
>
> 「王計必欲東，能用信，信即留；不能用，信終亡耳。」
>
> ——汉王的打算若真是向东，能用韩信，韩信就留下；不能用，韩信终究要走。
>
> 汉王说：看你的面子，让他做个将军。
>
> 萧何说：只做将军，他一定不留。
>
> 汉王说：那就做大将。
>
> 萧何说：好极了。

| 标记 | ◆ |
| 原文 | `006` 何曰：「諸將易得耳。至如信者，國士無雙。 |
| 依据 | `006`「諸將易得耳。至如信者，國士無雙」「王計必欲東，能用信，信即留」 |

| 说明 | 「國士無雙」四个字是萧何说的。**「国士」是一国之中可当大事的人；「无双」是没有第二个** |
| 说明 | 他给的是一道二选一：长久汉中，或者争天下。**没有第三条** |
| 说明 | 汉王的两次加官，都是被萧何推上去的：将军不够，大将才留得住 |

---

### 情节点 4 · 坛

> 汉王答应拜将，就想把韩信叫来。
>
> 萧何拦住他：
>
> 「王素慢無禮，今拜大將如呼小兒耳，此乃信所以去也。」
>
> ——汉王平日轻慢，不讲礼数。如今拜大将，像叫一个小孩。这正是韩信要走的原因。
>
> 他给出该怎么做：
>
> 「擇良日，齋戒，設壇場，具禮，乃可耳。」
>
> ——挑一个好日子，斋戒，筑坛场，把礼数备齐，才行。
>
> 汉王答应了。
>
> 诸将都高兴，人人都以为自己要当大将。
>
> 「至拜大將，乃韓信也，一軍皆驚。」
>
> ——到了拜大将的时候，站出来的是韩信，全军都吃了一惊。

| 标记 | ◆ |
| 原文 | `007` 何曰：「王素慢無禮，今拜大將如呼小兒耳，此乃信所以去也。 |
| 依据 | `007`「擇良日，齋戒，設壇場，具禮，乃可耳」「至拜大將，乃韓信也，一軍皆驚」 |

| 说明 | 萧何要的不只是官位，是**一个所有人都看得见的礼**。坛是为此筑的 |
| 说明 | 「人人各自以為得大將」——诸将都不知道是谁。**「一軍皆驚」是这一段的最后一句** |
| 说明 | 拜将的地点、坛的形制，这十段里没有 |

---

### 情节点 5 · 第一问

> 拜完礼，韩信坐下。
>
> 汉王开口：「丞相几次说起将军。将军拿什么教我？」
>
> 韩信先谢过，然后问了一句：
>
> 「今東鄉爭權天下，豈非項王邪？」
>
> ——如今向东去争天下的权，难道是项王吗？
>
> 汉王说：是。
>
> 韩信再问：
>
> 「大王自料勇悍仁彊孰與項王？」
>
> ——大王自己估量，勇、悍、仁、强，比项王怎么样？
>
> 汉王没有立刻回答。过了很久，他说：「不如他。」
>
> 韩信拜了两拜，向汉王道贺：
>
> 「惟信亦為大王不如也。然臣嘗事之，請言項王之為人也。」
>
> ——我韩信也认为大王不如他。可是我曾经在他手下做事，请让我说一说项王是怎么样的人。
>
> 一句话说完，他要把对手一件一件拆开。

| 标记 | ◆ |
| 原文 | `008` 信謝，因問王曰：「今東鄉爭權天下，豈非項王邪？」 |
| 依据 | `008`「漢王默然良久，曰：『不如也』」「惟信亦為大王不如也」 |

| 说明 | 第一句问的是对手：争天下，争的是项王。**他先把题目定下来** |
| 说明 | 第二句问的是自己这一头。**「默然良久」是汉王的回答之前的那一段沉默** |
| 说明 | 「惟信亦為大王不如也」——他先承认，再开口。**这一句是他敢往下说的位置** |

---

### 情节点 6 · 匹夫之勇与妇人之仁

> 第一件，项王的勇。
>
> 「項王喑噁叱吒，千人皆廢，然不能任屬賢將，此特匹夫之勇耳。」
>
> ——项王发怒呵斥，上千人都被压得动不了。可是他不肯把兵交给得力的将领。这只是一个人的勇。
>
> 第二件，项王的仁。
>
> 「項王見人恭敬慈愛，言語嘔嘔，人有疾病，涕泣分食飲，至使人有功當封爵者，印刓敝，忍不能予，此所謂婦人之仁也。」
>
> ——项王见人恭敬慈爱，说话絮絮不休；有人病了，他流着泪分自己的饮食给人。可是到了有人立功该封爵的时候，印都磨坏了，他还攥着舍不得给。这就是所谓妇人的仁。
>
> 两件放在一起才成一对：一个不肯把兵交出去，一个不肯把爵交出去。

| 标记 | ◆ |
| 原文 | `009` 項王喑噁叱吒，千人皆廢，然不能任屬賢將，此特匹夫之勇耳。 |
| 依据 | `009`「此特匹夫之勇耳」「此所謂婦人之仁也」 |

| 说明 | 「匹夫之勇」不是说他不能打，是说他不会用人。**后面「不能任屬賢將」才是判语** |
| 说明 | 「印刓敝」——印都磨旧了。**东西在他手里，他舍不得给出去** |
| 说明 | 两句都是有褒有贬：先承认他勇、他仁，再说这两样都不够用 |

---

### 情节点 7 · 天下的位置

> 第三件不是脾气，是位置。
>
> 「項王雖霸天下而臣諸侯，不居關中而都彭城。有背義帝之約，而以親愛王，諸侯不平。」
>
> ——项王虽然称霸天下、让诸侯臣服，却不住在关中，把都城放在彭城。他背了义帝的约定，把自己亲近喜爱的人封王，诸侯不服。
>
> 第四件，是他一路走过去留下的东西。
>
> 「項王所過無不殘滅者，天下多怨，百姓不親附，特劫於威彊耳。名雖為霸，實失天下心。故曰其彊易弱。」
>
> ——项王所过之处，没有不被摧残毁灭的，天下人多怨恨他，百姓不亲近他，只是被威势劫住罢了。名义上虽然称霸，实际上已经失掉天下人心。所以说，他的强是容易变弱的。
>
> 四件说完，才轮到汉王。

| 标记 | ◆ |
| 原文 | `010` 項王所過無不殘滅者，天下多怨，百姓不親附，特劫於威彊耳。 |
| 依据 | `009`「不居關中而都彭城」「以親愛王，諸侯不平」；`010`「名雖為霸，實失天下心」「故曰其彊易弱」 |

| 说明 | 前两件说的是他怎么待身边人，后两件说的是他怎么待天下。**四件是两组** |
| 说明 | 「特劫於威彊耳」——百姓不是服，是被吓住。**这一句是「其彊易弱」的理由** |
| 说明 | 断语在 `010` 段末，办法在下一句。**中间没有过渡，他直接往下说** |

---

### 情节点 8 · 反其道

> 断语之后就是办法。他先说的是三个「反其道」：
>
> 「今大王誠能反其道：任天下武勇，何所不誅！以天下城邑封功臣，何所不服！以義兵從思東歸之士，何所不散！」
>
> ——如今大王真能反过来做：任用天下勇武的人，有什么打不掉！拿天下的城邑封功臣，有谁不服！带着想东归的将士、以义兵出征，有什么冲不散！
>
> 三条对着项王的三条。接着他说到眼前，说到秦地那三个王。
>
> 「且三秦王為秦將，將秦子弟數歲矣，所殺亡不可勝計，又欺其眾降諸侯，至新安，項王詐阬秦降卒二十餘萬，唯獨邯、欣、翳得脫，秦父兄怨此三人，痛入骨髓。」
>
> ——三秦王本来是秦将，带秦家子弟好几年，死伤数不清。他们又骗部下投降诸侯，到新安，项王用诈把二十多万秦降卒坑杀了，只有邯、欣、翳三个人脱身。秦地的父兄恨这三个人，恨到骨头里。
>
> 而汉王进武关的时候，跟秦人约的只有三条法。
>
> 「大王之入武關，秋豪無所害，除秦苛法，與秦民約，法三章耳，秦民無不欲得大王王秦者。」
>
> ——大王进武关，一点东西都没有伤犯，废掉秦的苛法，跟秦民约定，只有法三章。秦民没有不想让大王在秦地称王的。
>
> 说到这里，他给了结论：
>
> 「三秦可傳檄而定也。」
>
> ——三秦只要传一道檄文，就可以定下来。
>
> 汉王大喜，说自己得到韩信太晚。他听了韩信的计划，部署诸将要打的地方。
>
> 这年八月，汉王举兵从陈仓东出，定了三秦。

| 标记 | ◆ |
| 原文 | `012` 今大王舉而東，三秦可傳檄而定也。 |
| 依据 | `010`「今大王誠能反其道」；`011`「大王之入武關，秋豪無所害」；`012`「三秦可傳檄而定也」；`013`「八月，漢王舉兵東出陳倉，定三秦」 |

| 说明 | 「反其道」是三句排比，一句对一条短处。**不是安抚，是换一种做法** |
| 说明 | 说到三秦王，话就从项王挪到秦地：**这一段的落点是「秦民」** |
| 说明 | 「傳檄而定」是他说的话，不是后来发生的事。**发生的事在下一段：八月，出陈仓** |

## 四、背景卡

### 郎中 ○

郎中是侍从性质的官，在君王身边当值、听候差遣。

`004` 记韩信在项羽手下做郎中。这个位置离项羽不远，所以他「數以策幹項羽」——有说话的机会。

> **依据**：`004`「羽以為郎中。數以策幹項羽，羽不用」。**郎中的具体职掌、俸秩，这十段里没有**；「侍从武官」是后人的解释。

---

### 连敖 ○

「连敖」是楚的官名。这个官有多大、管什么事，后人有几说，没有定论。

`004` 只记他「為連敖」，接着就「坐法當斬」——从做官到犯法，中间一句都没有。

> **依据**：`004`「未得知名，為連敖」。**「连敖」二字的训释，后世注家说法不一**，这里不作定论。

---

### 治粟都尉 ○

治粟都尉是管粮的官。汉王在斩他之后给了他这个位置。

`004` 紧接着写了五个字：「上未之奇也」。官给了，人还是没有看出来。

> **依据**：`004`「上拜以為治粟都尉，上未之奇也」。**这一官的品秩，这十段里没有**。

---

### 国士无双 ○

「国士」是一国之中可当大事的人。「无双」是没有第二个。

这句话是萧何说的，说的不是韩信会打仗，是「至如信者」——像他这样的人，找不出第二个。汉王当时问的是「追信，詐也」，萧何答的是这四个字。

> **依据**：`006`「諸將易得耳。至如信者，國士無雙」。**「国士」的训释是后人的读法**；`006` 只有这四个字。

---

### 坛场与斋戒 ○

坛是土筑的高台。斋戒是行礼之前的洁净：不饮酒、不食荤、不与妻妾同处。

萧何要的是「擇良日，齋戒，設壇場，具禮」——日子、洁净、台子、礼数，四样齐了才拜。汉王照办了。

> **依据**：`007`「擇良日，齋戒，設壇場，具禮，乃可耳」「至拜大將，乃韓信也，一軍皆驚」。**坛的形制、地点，这十段里没有**。

---

### 三秦王 ○

秦地分为三，由三个秦降将分王：雍王章邯、塞王司马欣、翟王董翳。

`011` 只作「邯、欣、翳」。这三个人带秦家子弟出去，又骗他们降了诸侯；到新安，降卒被项王坑杀，只有这三个人脱身。秦地父兄恨的是这一笔。`014` 里出现「塞王欣、翟王翳亡漢降楚」，就是司马欣与董翳。

> **依据**：`011`「唯獨邯、欣、翳得脫」「秦父兄怨此三人，痛入骨髓」；`014`「塞王欣、翟王翳亡漢降楚」。**「雍王章邯」的名号不在这十段里**，三王的封号见于后文。

## 七、设计说明

> **这一节编译器跳过，不渲染。** 放「为什么这么写」。

**八个情节点，覆盖 `004`–`013`。** 第一段是刑场，第二到第四是追信、国士无双、筑坛拜将，第五到第八是登坛之后那段议论。前情（从项梁到连敖）留在门口，因为那三段要交代的只有一件事：他一直在说话，一直没有人听。

**汉中对占四段，`008`–`012` 逐条引。** 这是韩信第一次把天下摆开来分析，也是这一篇真正的重心。分法是照着底本的次序：先问对手（`008`），再说项王四件短处（`009`–`010`，前两件是他待人，后两件是他待天下），最后给反其道的三条和对秦地的判断（`010`–`012`）。**没有压缩成两句，也没有替他添一条底本没有的计策。**

**「不如也」是这四段里的枢纽。** 汉王默然良久才承认不如项王，韩信先跟着承认，然后才有资格说下去。这一步如果省了，后面的四件就成了背后说人短处；留着，它们是当面拆解。

**拜将的礼办得比官大。** 萧何要「擇良日，齋戒，設壇場，具禮」，汉王照办；诸将人人自以为得大将——**这支军队没有人知道要拜的是谁**。所以「一軍皆驚」不只是一句惊讶，是拜将这一幕的落点。

**收在「定三秦」。** `013` 是汉中对的结果：八月出陈仓，三秦定。**这一篇的最后一句话是行动，不是议论。**

**标记全 ◆。** 官职的训释（郎中、连敖、治粟都尉）、坛场斋戒的形制、三秦王的封号，全部退到背景卡标 ○；公元纪年与地理标 ○ 外证。正文只写这十段里有的东西。
