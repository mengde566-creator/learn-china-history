# 胯下

| | |
|---|---|
| 封面 | — |
| 地点 | 淮阴 · 城下 |
| 原文 | 001–003 |

> 原文 001–003，三段，近二百字。
> 一个穷人，先失了一处吃饭的地方，又从一位老妇人手里接了几十天的饭，最后从一条裤裆底下爬过去。
> **他先「怒」，后「孰視之」——两个动作之间，他没有说一句话。**

---

## 二、情节点

### 情节点 1 · 亭长家的饭

> 韩信先在别人家里吃闲饭。日子一长，讨厌他的人越来越多。
>
> 下乡的南昌亭长收留过他。他就在那里吃了好几个月。
>
> 亭长的妻子到最后不再忍了。
>
> 「亭長妻患之，乃晨炊蓐食。食時信往，不為具食。」
>
> ——亭长的妻子受不了了，就清早把饭做好，在床上吃完。到了吃饭的时辰韩信过去，他们没有给他摆饭。
>
> 没有一句话。韩信明白了这是什么意思，发了怒，从此再没有踏进那家的门。

| 标记 | ◆ |
| 原文 | `001` 常數從其下鄉南昌亭長寄食，數月，亭長妻患之，乃晨炊蓐食。食時信往，不為具食。 |
| 依据 | `001`；`001`「信亦知其意，怒，竟絕去」 |

| 说明 | 「晨炊蓐食」是四个字的一顿饭：清早做饭，在床上吃完。**赶在他来之前吃完**——没有人吵，也没有人说明 |
| 说明 | 亭长一个字都没有。决定是妻子做的，走的是韩信。**「信亦知其意」：他没有问，也没有人告诉他** |
| 说明 | 「怒，竟絕去」——怒和走连着写。**他没有讨一个说法，也没有再回去** |

---

### 情节点 2 · 城下

> 寄食的路断了以后，他到淮阴城下的河边钓鱼。
>
> 河边有几位老妇人在漂洗。那是一桩要连着做几十天的活。
>
> 「信釣於城下，諸母漂，有一母見信饑，飯信，竟漂數十日。」
>
> ——韩信在城下钓鱼，几位老妇人在漂洗。其中一位见他饥饿，拿饭给他吃，一直给到那几十天漂完。
>
> 饭不是一次给的。她漂了多少天，饭就分了多少天。

| 标记 | ◆ |
| 原文 | `002` 信釣於城下，諸母漂，有一母見信饑，飯信，竟漂數十日。 |
| 依据 | `002` |

| 说明 | 「諸母漂」是几个人，「有一母」是其中的一个。**给饭的是一个人，不是一群人** |
| 说明 | 「竟漂數十日」——漂洗有尽头，饭按这个尽头算。**几十天是这件事的长度，不是她给饭的次数** |

---

### 情节点 3 · 吾必有以重报母

> 韩信高兴了。他对那位老妇人说：
>
> 「吾必有以重報母。」
>
> ——我将来一定有可以重重报答您的东西。
>
> 老妇人发了火。
>
> 「大丈夫不能自食，吾哀王孫而進食，豈望報乎！」
>
> ——一个大丈夫，连自己都养不活。我是可怜你这位王孙才给你饭吃，难道是图你报答？
>
> 她把那句许诺退了回来。

| 标记 | ◆ |
| 原文 | `002` 信喜，謂漂母曰：「吾必有以重報母。」 |
| 依据 | `002`「母怒曰：『大丈夫不能自食，吾哀王孫而進食，豈望報乎！』」 |

| 说明 | 「重報」是他自己加的分量：不是报，是重报。**说这句话的时候，他手里一样东西都没有** |
| 说明 | 老妇人的话里有三个身份：大丈夫、王孙、和她自己。**她骂的是第一个，可怜的是第二个，给饭的是第三个** |
| 说明 | 「豈望報乎」是反问。她说完，这一段就断了——**他没有回话** |

---

### 情节点 4 · 屠中少年

> 淮阴的屠户里有一个少年，当众羞辱韩信。
>
> 他先给的是一句评语：
>
> 「若雖長大，好帶刀劍，中情怯耳。」
>
> ——你虽然长得高大，又喜欢佩刀带剑，心里其实是怕的。
>
> 然后他把话挑明，当着市上的人给韩信两条路：
>
> 「信能死，刺我；不能死，出我袴下。」
>
> ——韩信，你要是不怕死，就刺我；要是怕死，就从我裤裆底下钻过去。
>
> 他叫韩信的名字，要他当场回答。

| 标记 | ◆ |
| 原文 | `003` 淮陰屠中少年有侮信者，曰：「若雖長大，好帶刀劍，中情怯耳。」 |
| 依据 | `003`「眾辱之曰：『信能死，刺我；不能死，出我袴下』」 |

| 说明 | 「中情怯耳」说的是心里。刀剑挂在外头，怕不怕在里头——**这一句不骂他穷，是说他虚** |
| 说明 | 两条路都不好走：一条是杀人，一条是钻过去。**说这话的人站在市上，四周都是看客** |
| 说明 | 少年用的是「若」（你），转述的人用的是「信」（韩信）——**同一句话里换了称呼** |

---

### 情节点 5 · 孰视之

> 市上的人都看着。
>
> 他没有拔剑。
>
> 他先看了那个少年。
>
> 「於是信孰視之，俛出袴下，蒲伏。」
>
> ——于是韩信把他看了很久，然后低下头，从他裤裆底下钻过去，伏在地上爬了过去。
>
> 「孰視之」是「熟视之」：看得久，也看得定。看的那一会儿，他没有说话，也没有动手。
>
> 低头、过去、伏地爬行——这三个动作都是他自己做的，没有人按他下去。

| 标记 | ◆ |
| 原文 | `003` 於是信孰視之，俛出袴下，蒲伏。 |
| 依据 | `003`「於是信孰視之，俛出袴下，蒲伏」；`003` 承上「信能死，刺我；不能死，出我袴下」 |

| 说明 | 顺序是「視」→「俛」→「出」→「蒲伏」。**停顿在最前面**：先看清，然后才动 |
| 说明 | 「俛」是低头，「蒲伏」是伏地爬行。**底本用了两个动作写他过去的方式，不是一笔带过** |
| 说明 | 这一眼和后面的动作之间没有一个字的解释。**他想什么，不写** |

---

### 情节点 6 · 一市人皆笑

> 他爬完了那一段。
>
> 「一市人皆笑信，以為怯。」
>
> ——满市的人都笑韩信，认为他胆怯。
>
> 笑的人笑的是「怯」。他刚才那一眼看了多久、看的是什么，记下来的只有他们笑、他们认为他怯。
>
> 市人给他的判语，就只有这一个字。

| 标记 | ◆ |
| 原文 | `003` 一市人皆笑信，以為怯。 |
| 依据 | `003`「一市人皆笑信，以為怯」；`003`「中情怯耳」——少年先这样说，市人后来这样认 |

| 说明 | 「以為怯」是一市人的判断，不是记这件事的人的判断。**两句话：一句记他们笑，一句记他们怎么想** |
| 说明 | 少年挑他时说的是「中情怯耳」，市人笑他时用的是同一个字。**这个字从一句话变成了所有人的结论** |

## 四、背景卡

### 袴下 ○

「袴」是裤子。「袴下」就是从裤裆底下过去。

`003` 两处都作「袴下」；后来追述这件事的时候，`054` 作「胯下」——同一个动作，两种写法。这不是错字，是转写。

> **依据**：`003`「出我袴下」「俛出袴下，蒲伏」；`054`「召辱己之少年令出胯下者以為楚中尉」。**两种写法指的是同一个动作**。

---

### 王孙 ○

老妇人叫他「王孙」。这是当时对年轻人的客气称呼，犹言「公子」——不是说他真是王孙。

她面前的人穷到在河边钓鱼充饥。她还是这样叫他。

> **依据**：`002`「吾哀王孫而進食」。**「王孙」在此是称呼，不是家世**；解作敬称是后人的训释。

---

### 漂 ○

「漂」是漂洗。所漂的具体是什么，`002` 只写了这个字。后人多解作丝絮，因为这是当时妇女常做的活计。

这活有期限，所以「竟漂數十日」是在说这件事做了多久。

> **依据**：`002`「諸母漂」「竟漂數十日」。**所漂何物，`002` 不说**；「丝絮」是后人的解释。

---

### 下乡与南昌 ○

「下乡」是淮阴的乡名，「南昌」是其中的亭名。`001` 连起来写「下鄉南昌亭長」，是一个人的职务：南昌亭的亭长，属下乡。

亭长的家，就是韩信寄食的那一家。

> **依据**：`001`「常數從其下鄉南昌亭長寄食」。**亭长的姓名，`001` 不记**；「下乡」「南昌」的地望是后人的考订。

---

### 那个少年 ○

他从裤裆底下过去的那个人，后来还出现过一次。

韩信做了楚王，回到楚地，把这个当年辱过他的少年召来，给了他一个楚中尉的官。他对诸将相说：这是个壮士；当年他辱我的时候，我难道不能杀他？杀他没有名目，所以我忍下来，忍到了今天。

> **依据**：`054`「召辱己之少年令出胯下者以為楚中尉」「此壯士也。方辱我時，我寧不能殺之邪？殺之無名，故忍而就於此」。**这段话在他做楚王之后，本篇三段里没有。**

---

### 贫无行 ○

「无行」不是没有行为，是品行上没有什么可称道的。`001` 用这两个字交代他早年的处境。

不是有人害他。是乡里不肯举荐他，而他确实也没有别的出路。

> **依据**：`001`「貧無行，不得推擇為吏」。**「行」读作品行，是后人的训释**；落点是一样的：乡里不认他。

## 七、设计说明

> **这一节编译器跳过，不渲染。** 放「为什么这么写」。

**六个情节点，覆盖 `001`–`003`。** 三段原文近二百字，拆成六段：寄食、钓鱼、许诺、挑衅、钻过去、满市的人笑。八处原文块，全部是人有声有色或有动作的那一句。

**「怒」和「孰視之」是这一篇的两头。** `001` 记他第一次反应是「怒，竟絕去」——不留一句话就走。`003` 记他最有名的动作，前面排了「孰視之」三个字。**这一篇不解释那一眼**：不写他在权衡，不写他在忍，只把「先看，然后才动」的顺序摆出来。

**「胯下」不写成传奇。** 没有「大丈夫能屈能伸」这类话，也没有把钻过去写成计策。写法是把四个动作拆开——低头、过去、伏地、爬——让读者看见每一步都是他自己做的，没有人按他。市人的反应只记两句：他们笑，他们认为他怯。**这是他们的判断，不是这一篇的判断。**

**`054` 只进背景卡，不进正文。** 本篇的范围是 `001`–`003`；少年后来被召为楚中尉，是他在做楚王之后的事，正文不越界。那一张卡存在的理由：读者读完会想知道那个人后来怎样，而答案是有的——只是不在这里。

**三处标记全 ◆，推断退到背景卡。** 「孰视之」通「熟视之」、「王孙」是敬称、「漂」是漂洗——三条都是后人训释，写在背景卡里标 ○。正文的白话只写动作和顺序。
