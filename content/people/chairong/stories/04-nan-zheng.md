# 04-nan-zheng · 三征南唐

| | |
|---|---|
| **封面** | — |
| **地点** | 下蔡 · 寿州 · 滁州 · 紫金山 · 迎銮江口 |
| **原文** | 018–026 |

> 九段。显德二年冬，他出师淮南。诏书里说这是「吊伐」，不是耀武。
> 三年正月他亲征，大将李穀先破淮贼。
> 李景提出割六州之地求和，他不允：「志在尽取江北诸郡。」
> 四年紫金山一仗，紫金山下连破数寨；五年他临江耀兵，直抵南岸。
> 最后李景上表乞降。

## 二、正文

### 情节点 1 · 出師

> 显德二年十一月乙未朔，朝廷让宰臣李穀做淮南道前军行营都部署，负责庐、寿等州行府的事务；让许州节度使王彦超做行营副部署；命韩令坤等十二将各带征行之号随行。
>
> 己亥，晓谕淮南州县，诏书说：朕继承基业、统御天下，正该恭己临朝、修明文德，岂愿兴兵动众、专耀武功！只是这昏乱之邦，不得不举吊伐之义。淮甸小丑敢拒大邦，乘唐室衰微、黄巢乱后，飞扬跋扈近六十年，盗据一方，僭称伪号。

| 标记 | ◆ |
| 原文 | `018` 十一月乙未朔，以宰臣李穀为淮南道前军行营都部署，知庐、寿等州行府事；以许州节度使王彦超为行营副部署；命侍卫马军都指挥使韩令坤等一十二将，各带征行之号以从焉。`019` 朕自缵承基构，统御寰瀛，方当恭己临朝，诞修文德，岂欲兴兵动众，专耀武功！顾兹昏乱之邦，须举吊伐之义。 |
| 依据 | `018`、`019` |

| 说明 | 诏书的第一句是「岂欲兴兵动众，专耀武功」——**先说自己不想打，再说为什么不得不打**。这是五代檄文的常套，也是他给这场战争定的名分 |
|

---

### 情节点 2 · 親征

> 显德三年春正月乙未朔，他不受朝贺。
>
> 丁酉，李穀奏破淮贼于上窑。戊戌，发丁夫十万城京师罗城。庚子，诏取此月八日幸淮南。
>
> 二月丙寅，驾临下蔡。前济州马军都指挥使康俨被斩于路旁，罪名是修桥道不谨慎。戊辰，庐寿巡检使司超奏报在盛唐破淮贼三千，擒获伪吉州刺史高弼来献，诏令释放。
>
> 兵部尚书张昭上奏，说奉诏编集兵法，分为十卷。

| 标记 | ◆ |
| 原文 | `020` 显德三年春正月乙未朔，帝不受朝贺。前司空苏禹珪卒。丁酉，李穀奏，破淮贼于上窑。`021` 二月丙寅，幸下蔡。斩前济州马军都指挥使康俨于路左，坐桥道不谨也。朗州节度使王进逵奏，领兵入淮南界。戊辰，庐寿巡检使司超奏，破淮贼三千于盛唐，获都监伪吉州刺史高弼以献。诏释之。兵部尚书张昭奏，准诏撰集兵法，分为十卷 |
| 依据 | `020`、`021` |

| 说明 | 「斩康俨于路左，坐桥道不谨」——因为修桥不谨慎就杀一个都指挥使。**这条记载比任何战功都更能说明他治军的尺度** |
|

### 情节点 3 · 滁州

> 小注引《默记》说：李景听说世宗亲到淮上，因滁州是控扼之地、又可援救寿州，便命皇甫晖、姚凤领兵十万扼守。
>
> 太祖以周师数千与皇甫晖相遇于清流关隘路，周师大败；皇甫晖整全师入憩滁州城下，次日再出。
>
> 太祖兵聚关下，担心皇甫晖的兵再来，问诸村人，村人说有镇州赵学究可问。

| 标记 | ◆ |
| 原文 | `022` 《默记》：李景闻世宗亲至淮上，而滁州其控扼，且援寿州，命大将皇甫晖、监军姚凤提兵十万扼其地。太祖以周师数千与晖遇于清流关隘路，周师大败 |
| 依据 | `022` |

| 说明 | 这一段全在小注里，正文不载滁州之战的胜负。**底本给小注留了叙述空间，正文只记朝廷的日程与诏令** |
|

---

### 情节点 4 · 不允割地

> 起初李景派钟谟、李德明奉表到行阙，使者面奏：本国主愿把寿、濠、泗、楚、光、海六州之地割归大朝。
>
> 他一心要拿下整个江北，不答应这个请求。
>
> 使人见王师急攻寿阳，李德明奏：「愿陛下宽臣数日之诛，容臣自往江南，取本国表，尽献江北之地。」

| 标记 | ◆ |
| 原文 | `023` 初，李景遣钟谟、李德明奉表至行阙，使人面奏云：“本国主愿割寿、濠、泗、楚、光、海六州之地，归于大朝。”帝志在尽取江北诸郡，不允其请。 |
| 依据 | `023` |

| 说明 | 「志在尽取江北诸郡」七个字，把这场战争的目标写死了：**不是要六州，是要整个江北**。于是后面三征就都成了同一件事的延续 |
|

---

### 情节点 5 · 紫金山

> 显德四年三月庚寅早晨，他率诸军驻扎在紫金山脚下，命「今上」带亲军上山攻贼，接连打破数寨，斩获数千人，截断贼军来路，使其首尾不能相救。
>
> 是夜，贼将朱元、朱仁裕、孙璘各举寨来降，降其众万余人。翌日尽陷诸寨，杀获甚众，擒贼大将建州节度使许文稹、前湖南节度使边镐等。
>
> 显德五年三月壬午朔，驾临泰州；丁亥又到广陵；辛卯到迎銮江口。癸巳，他临江望见有贼船数十艘，便命「今上」率战船追击，贼军退走，「今上」直抵对岸，烧了营栅才回。

| 标记 | ◆ |
| 原文 | `024` 三月庚寅旦，帝率诸军驻于紫金山下，命今上率亲军登山击贼，连破数寨，斩获数千，断其来路`025` 三月壬午朔，幸泰州。丁亥，复幸广陵。辛卯，幸迎銮江口。遣右武卫大将军李继勋率舟师至江岛以观寇。癸巳，帝临江望见贼船数十艘，命今上帅战棹以追之，贼军退去，今上直抵南岸，焚其营栅而回。 |
| 依据 | `024`、`025` |

| 说明 | 紫金山是南唐的主力覆灭处；迎銮江口是兵锋抵江之处。**两段之间隔了一年，底本把它们并在一篇里，是因为它们说的是同一件事：一点点把江北拿干净** |
|

---

### 情节点 6 · 乞降

> 显德五年八月庚辰，延州奏报溠溪水涨，冲坏州城，淹死百余人。己丑，致仕的太子太师宋彦筠去世。
>
> 辛丑，江南的李景上表乞降，诏书不许。

| 标记 | ◆ |
| 原文 | `026` 八月庚辰，延州奏，溠溪水涨，坏州城，溺死者百余人。己丑，太子太师致仕宋彦筠卒。辛丑，江南李景上表乞降，诏书不允。 |
| 依据 | `026` |

| 说明 | 「乞降，诏书不允」四个字收尾。**他连投降都不立刻接受**——因为江北还没有全部交割 |
|

## 四、背景卡

### 淮南道行營

`018` 以李穀为「淮南道前军行营都部署」。行营都部署是出征时的前线统帅。

**这是后周第一次把淮南作为独立的战区来组织。**

> **依据**：`018`「以宰臣李穀为淮南道前军行营都部署」。

---

### 上窯

`020` 李穀破淮贼于上窑。上窑在寿州附近，是淮河沿线要地。

**亲征的第一份捷报。**

> **依据**：`020`「李穀奏，破淮贼于上窑」。

---

### 清流關

`022` 小注记「太祖以周师数千与晖遇于清流关隘路」。清流关在滁州西，是江淮之间的险要。

**赵匡胤成名的一战，底本把它放在小注里。**

> **依据**：`022`「与晖遇于清流关隘路」。

---

### 紫金山

`024` 他驻军紫金山下。紫金山在寿州城外，南唐援军在此结寨。

**南唐援寿州的主力在这里被击破。**

> **依据**：`024`「帝率诸军驻于紫金山下」。

---

### 迎鑾江口

`025` 他「幸迎銮江口」。迎銮在扬州附近江边。

**到了这里，后周的兵锋已经抵长江。**

> **依据**：`025`「辛卯，幸迎銮江口」。

## 七、设计说明

> **这一篇写「一场拖了三年的战争，目标一直没变」。**
>
> 九段底本跨三个年头：出师、亲征、滁州、割地、紫金山、临江、乞降。我按「出师—亲征—受降」三段铺，中间用「不允割地」把那句「志在尽取江北诸郡」立在正中。
>
> 两处取舍：
> 一是滁州。这场仗在北宋的叙事里很重要（赵匡胤成名战），但《旧五代史》正文不载，只有《默记》小注。我照录小注，映射表里标 `—`：**能读，不能当本卷正文用。**
> 二是「乞降，诏书不允」。我把这一句放在最后，不加解释——**打完了还不接降书，比接降书更能说明他要什么。**
