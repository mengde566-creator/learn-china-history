# 03-zheng-dun · 整军与求言

| | |
|---|---|
| **封面** | — |
| **地点** | 开封 · 大内 |
| **原文** | 011–017 |

> 七段。高平之后他做了三件事：把军队重新挑一遍，把官帽发下去时写明举主，把耳朵打开。
> 求言诏里有一句：「朕躬之有阙失，得以尽言；时政之有瑕疵，勿宜有隐。」
> 又是两年，他废了三万三百三十六所寺院。

## 二、正文

### 情节点 1 · 大閱

> 显德元年十月，是日大阅，他亲临。
>
> 自从高平一役，他看见诸军不够严整，临阵就退；到这时命「今上」把全军重新简阅，挑出武艺超绝的署为殿前诸班，于是军中有了散员、内殿直、铁骑、控鹤这些名号。
>
> 又命各军主将自己挑选，从龙捷、虎捷以下逐一点过，老弱的去掉；各军士伍，没有不精当的。
>
> 从此兵甲之盛，近代无比，也省下了一笔冗食的开销。
>
> 小注引《五代会要》说他对侍臣讲：「侍卫兵士老少相半，强懦不分，盖徇人情，不能选练……况百户农夫，未能赡一甲士，且兵在精不在众。」

| 标记 | ◆ |
| 原文 | `011` 是日大阅，帝亲临之。帝自高平之役，睹诸军未甚严整，遂有退却，至是命今上一概简阅，选武艺超绝者，署为殿前诸班，因是有散员、散指挥使、内殿直、散都头、铁骑、控鹤之号。复命总戎者，自龙捷、虎捷以降，一一选之，老弱羸小者去之，诸军士伍，无不精当。由是兵甲之盛，近代无比，且减冗食之费焉。 |
| 依据 | `011` |

| 说明 | 「兵在精不在众」这句话在小注里，正文只写结果。**底本把原因留给注、把结果留给正文**，这是旧五代史常见的分工 |
|

### 情节点 2 · 舉主

> 显德二年春正月辛未朔，他不受朝贺。
>
> 辛卯，下诏：在朝的文班官员，各举一名能胜任县令、录事的人；即便是姻族近亲，也不必避嫌。授官之日，各自署上举主的姓名。
>
> 若举非其人，自然有连坐之责——诏书正是为此而设。

| 标记 | ◆ |
| 原文 | `012` 显德二年春正月辛未朔，帝不受朝贺。辛卯，诏：“在朝文班，各举堪为令录者一人，虽姻族近亲，亦无妨嫌。授官之日，各署举主姓名 |
| 依据 | `012` |

| 说明 | 这一道诏的厉害处不在「举人」，在「各署举主姓名」：**你举的人，名字和你写在一起** |

### 情节点 3 · 求言

> 他下诏说：善于理事的人不能全功，善于处身的人不能无过。像尧、舜、禹、汤那样的上圣，文、武、成康那样的至明，尚且要听逆耳之言、求苦口之药，何况后人。
>
> 又说我承先帝之灵，居至尊之位，涉道犹浅，经事未深，常惧昏蒙，不能负荷；自临宸极已过周星，刑政取舍、国家措置之间，岂能尽当。
>
> 于是下诏：内外文武臣僚，今后凡有所见所闻，都许上章论谏。朕自身有过失，可以尽言；时政有瑕疵，不要隐瞒。

| 标记 | ◆ |
| 原文 | `013` 善操理者不能有全功，善处身者不能无过失。虽尧、舜、禹、汤之上圣，文、武、成康之至明，尚犹思逆耳之言，求苦口之药`015` 应内外文武臣僚，今后或有所见所闻，并许上章论谏。若朕躬之有阙失，得以尽言；时政之有瑕疵，勿宜有隐。 |
| 依据 | `013`、`015` |

| 说明 | 「涉道犹浅，经事未深」八个字，是一个二十九岁的皇帝自己说的。**不是套话，因为紧接着他把「勿宜有隐」写进了诏书的执行条款** |
|

---

### 情节点 4 · 廢寺

> 他说：佛教本是圣人的妙道，助世劝善，好处很多。前代以来都有条贯，近年却乱了规矩；近来各州奏报，屡有僧徒犯法，因为没有科禁，私自剃度的僧尼越来越多、越来越杂，私创的寺院也渐多，乡村里这一弊更甚。
>
> 于是诸道府州县镇村坊，凡有敕额寺院一切仍旧，无敕额者一并停废，功德佛像及僧尼并入合留寺院安置。
>
> 这一年诸道呈上帐籍：存下的寺院共二千六百九十四所，废掉的共三万三百三十六所，在籍僧尼六万一千二百人。

| 标记 | ◆ |
| 原文 | `016` 释氏贞宗，圣人妙道，助世劝善，其利甚优。前代以来，累有条贯，近年已降，颇紊规绳。近览诸州奏闻，继有缁徒犯法，盖无科禁，遂至尤违，私度僧尼，日增猥杂，创修寺院，渐至繁多，乡村之中其弊转甚。漏网背军之辈，苟剃削以逃刑；行奸为盗之徒，托住持而隐恶。将隆教法，须辨否臧，宜举旧章，用革前弊。诸道府州县镇村坊，应有敕额寺院，一切仍旧，其无敕额者，并仰停废，所有功德佛像及僧尼，并腾并于合留寺院内安置。天下诸县城郭内，若无敕额寺院，只于合停废寺院内，选功德屋宇最多者，或寺院僧尼各留一所，若无尼住，只留僧寺院一所。`017` 是岁，诸道供到帐籍，所存寺院凡二千六百九十四所，废寺院凡三万三百三十六，僧尼系籍者六万一千二百人。 |
| 依据 | `016`、`017` |

| 说明 | 三个数字并排：存 2694、废 30336、僧尼 61200。**底本不写他为什么这么做，只把账目报出来** |
|

## 四、背景卡

### 殿前諸班

`011` 说选武艺超绝者「署为殿前诸班」，有散员、散指挥使、内殿直、散都头、铁骑、控鹤等名号。

**这是后周禁军精锐的编制，也是宋代殿前司的来处。**

> **依据**：`011`「署为殿前诸班，因是有散员、散指挥使、内殿直、散都头、铁骑、控鹤之号」。

---

### 令錄

`012` 举「堪为令录者」。令是县令，录是录事参军，都是亲民之官。

**这道诏要的是基层官，不是朝中高位。**

> **依据**：`012`「各举堪为令录者一人」。

---

### 舉主

`012` 说「各署举主姓名」。举主是推荐人，被举者犯事，举主要连坐。

**底本只写「各署举主姓名」，连坐的规矩在后文。**

> **依据**：`012`「授官之日，各署举主姓名」。

---

### 敕額

`016` 说「应有敕额寺院，一切仍旧，其无敕额者，并仰停废」。敕额是朝廷赐的寺额。

**有额者留，无额者废——判据是朝廷承认与否，不是香火盛衰。**

> **依据**：`016`「应有敕额寺院，一切仍旧，其无敕额者，并仰停废」。

## 七、设计说明

> **这一篇写「他怎么把一场败仗变成一套制度」。**
>
> 高平之后他做的三件事，底本分别给了三段：简军（`011`）、举官（`012`）、求言（`013`–`015`），最后落到废寺（`016`、`017`）。**前两件是补强，第三件是自省，第四件是收缩。**
>
> 我把「求言诏」放在第三位，因为它是这一篇里唯一由皇帝说自己不足的地方：「涉道犹浅，经事未深」。**一个刚打赢仗、刚杀了七十多个将校的人，写下这八个字**，比任何政绩都更能说明他想要什么。
>
> 一处分寸：废佛的数量很大，但底本没写动机。我在映射表里把「为了铸钱充军费」标成 ○——**那是后人的解释，不是这一卷的话。**
