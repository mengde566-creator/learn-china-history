# 05-bei-fa · 北伐

| | |
|---|---|
| **封面** | — |
| **地点** | 沧州 · 乾宁军 · 益津关 · 瓦桥关 |
| **原文** | 027–029 |

> 三段。显德六年三月，枢密使王朴死了；同月，他下诏亲征北境。
> 四月到沧州，宁州刺史王洪以城降；他乘龙舟顺流而北，首尾数十里，至益津关。
> 五月驻瓦桥关，瀛州刺史高彦晖以城归顺。
> 关南平：得州三、县十七、户一万八千三百六十。王师数万，不亡一矢。
> 然后他与诸将议攻幽州，诸将都以为不可。

## 二、正文

### 情节点 1 · 詔幸滄州

> 显德六年三月庚申，枢密使王朴去世。
>
> 甲子，诏以北境未复，取本月内幸沧州。
>
> 让宣徽南院使吴延祚出任权东京留守，兼判开封府事，又让宣徽北院使昝居润做副使；让三司使张美做大内都部署。命诸将各领马步兵。

| 标记 | ◆ |
| 原文 | `027` 三月庚申，枢密使王朴卒。甲子，诏以北境未复，取此月内幸沧州。以宣徽南院使吴延祚为权东京留守，判开封府事；以宣徽北院使昝居润为副使；以三司使张美为大内都部署。 |
| 依据 | `027` |

| 说明 | 王朴之死与北伐诏在同一个月，相隔四天。**底本把这两件事排在一起，没有一句议论** |
|

---

### 情节点 2 · 乾寧軍

> 夏四月辛卯，车驾驻在沧州，让原左谏议大夫薛居正出任刑部侍郎。当天，他率诸军北征。
>
> 壬辰，到达乾宁军，伪宁州刺史王洪举城投降。
>
> 丁酉，他坐龙舟，率水师顺流北上，船队首尾数十里。辛丑，抵达益津关。

| 标记 | ◆ |
| 原文 | `028` 夏四月辛卯，车驾次沧州，以前左谏议大夫薛居正为刑部侍郎。是日，帝率诸军北征。壬辰，至乾宁军，伪宁州刺史王洪以城降。丁酉，驾御龙舟，率舟师顺流而北，首尾数十里。辛丑，至益津关。 |
| 依据 | `028` |

| 说明 | 「驾御龙舟，率舟师顺流而北，首尾数十里」——这不是疑兵，是带着水师走河路。**北伐的供应线就架在这条水道上** |
|

---

### 情节点 3 · 關南平

> 五月初一乙巳，他驻在瓦桥关。李重进等诸将陆续到达行在；而瀛州守将高彦晖举城归顺。
>
> 关南平定，共计得三州、十七县、一万八千三百六十户。
>
> 这一仗，王师数万，不曾折一支箭，边界城邑都望风而降。
>
> 丙午，他与诸将议攻幽州，诸将都以为未可，他不听。是夜他身体不适，才作罢。

| 标记 | ◆ |
| 原文 | `029` 五月乙巳朔，帝驻跸于瓦桥关。侍卫亲军都指挥使李重进及诸将相继至行在，瀛州刺史高彦晖以本城归顺。关南平，凡得州三、县十七、户一万八千三百六十。是役也，王师数万，不亡一矢，边界城邑皆望风而下。丙午，帝与诸将议攻幽州，诸将皆以为未可，帝不听。是夜，帝不豫，乃止。 |
| 依据 | `029` |

| 说明 | 「不亡一矢」是底本给北伐的定评；紧接着「诸将皆以为未可，帝不听」——**他想再往前一步，是身体把他拦住了** |
|

## 四、背景卡

### 瓦橋關

`029` 他驻跸于此。瓦桥关在今河北雄县，是关南三关之一（瓦桥、益津、淤口）。

**三关一得，燕南的门户就开了；但幽州还在门后。**

> **依据**：`029`「帝驻跸于瓦桥关」。

---

### 乾寧軍

`028` 至乾宁军。乾宁军在今河北青县，是后周北境的水陆要冲。

**宁州刺史王洪在此以城降。**

> **依据**：`028`「至乾宁军，伪宁州刺史王洪以城降」。

---

### 不亡一矢

`029` 说「王师数万，不亡一矢」。这是说未发一箭而城邑自下。

**底本用这句话夸北伐之顺，也用下一句说它止于何处。**

> **依据**：`029`「是役也，王师数万，不亡一矢」。

---

### 幽州

`029` 议攻幽州而诸将不可。幽州即今北京，当时是契丹南京。

**他此行的目标；也是他没走完的一步。**

> **依据**：`029`「诸将皆以为未可，帝不听」。

## 七、设计说明

> **这一篇写「他一生里最顺的一仗，和它的边界」。**
>
> 三段底本全是行程与受降，没有一场硬仗。我照原样铺：出诏、至沧州、下乾宁军、入瓦桥关、关南平。**「不亡一矢」是底本的评语，我把它单独放在一行的末尾。**
>
> 最后一句「诸将皆以为未可，帝不听」，是全篇的转折。底本写得极短：诸将不同意，他不听，当夜不豫，才止。**顺风走到这里，是被身体拦下的，不是被敌人拦下的。**
>
> 一处分寸：所得三州，底本只说「州三、县十七」，不列州名。常见的说法是莫、瀛、易，但本卷不载，我在映射表里标 `—`。
