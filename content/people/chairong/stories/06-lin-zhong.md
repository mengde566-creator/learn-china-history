## 二、正文

### 情节点 1 · 六月

> 六月初一乙亥，潞州李筠奏报攻下辽州，擒获伪刺史张丕旦。
>
> 丙子，以皇女薨辍朝三日。
>
> 癸未，立魏王符彦卿的女儿为皇后，命有司择日备礼册命。长子宗训加特进、左卫上将军，封梁王；次子宗让则加左骁卫上将军，封燕国公。
>
> 己丑，宰臣范质、王溥并参知枢密院事；以枢密使魏仁浦为中书侍郎、平章事、集贤殿大学士。

| 标记 | ◆ |
| 原文 | `030` 六月乙亥朔，潞州李筠奏，攻下辽州，获伪刺史张丕旦。丙子，以皇女薨辍朝三日。戊寅，凤翔奏，节度使李晖卒。郑州奏，河决原武，诏宣徽南院使吴延祚发近县丁夫二万人以塞之。庚辰，命宣徽北院使昝居润判开封府事。晋州节度使杨廷璋奏，率兵入河东界，招降堡寨一十三所。癸未，立魏王符彦卿女为皇后，仍令所司择日备礼册命。以皇长子宗训为特进左卫上将军，封梁王；以第二子宗让为左骁卫上将军，封燕国公。 |
| 依据 | `030` |

| 说明 | 立后、封王、调宰辅，全在六月这半个月里。**底本按日排下来，读的时候才知道这是收尾的节奏** |

### 情节点 2 · 點檢做

> 他北征时，凡供军之物都令自京递送行在。
>
> 一天，忽然从地里得到一块木头，长二三尺，像人举物之形，上面全题着「点检做」，看的人不知何物。
>
> 到这时，「今上」始受殿前都点检之命。第二年春，果然由此职以副人望，于是「点检做」之言成了神符。

| 标记 | ◆ |
| 原文 | `031` 帝之北征也，凡供军之物，皆令自京递送行在。一日，忽于地中得一木，长二三尺，如人之揭物者，其上卦全题云：“点检做”，观者莫测何物也。至是，今上始受点检之命，明年春，果自此职以副人望，则“点检做”之言乃神符也。 |
| 依据 | `031` |

| 说明 | 底本把这块木头写成「神符」，是因为它后来应验了。**一句预言被写进史书，往往不是因为它准，是因为它应验之后才有人记** |
|

### 情节点 3 · 崩

> 癸巳，他在万岁殿驾崩，享年三十九岁。
>
> 甲午，宣遗制，命梁王在柩前即位，服纪月日都依旧制。当天群臣奉梁王在殿东楹即位，中外发哀。
>
> 这年八月，窦俨上谥号睿武孝文皇帝，庙号称世宗。十一月初一，葬在庆陵。

| 标记 | ◆ |
| 原文 | `032` 癸巳，帝崩于万岁殿，圣寿三十九。甲午，宣遗制，梁王于柩前即皇帝位，服纪月日一依旧制。是日，群臣奉梁王即位于殿东楹，中外发哀。其年八月，翰林学士、判太常寺事窦俨上谥曰睿武孝文皇帝，庙号世宗。十一月壬寅朔，葬于庆陵。 |
| 依据 | `032` |

| 说明 | 「中外发哀」四个字之后，底本立刻转到谥号与陵墓。**没有一句写他未竟的事**——那件事留给后面的史臣 |
|

### 情节点 4 · 十年之志

> 小注说：世宗志在四方，常怕自己在位太短、功业不成。因王朴精于术数，一天从容问他，朕还能有多少年。
>
> 王朴答：陛下存心为苍生，天高听卑，自当蒙福；臣用所学推算，三十年以后的事不敢说。
>
> 世宗大喜，说：若真如你所言，朕便拿十年开拓天下，十年养百姓，再十年致太平，够了。
>
> 后来他从瓦桥关回师，还没到关就晏驾了；在位只有五年零六个月——五六是三十的成数，那是王朴婉转的说法。

| 标记 | ◆ |
| 原文 | `033` 世宗志在四方，常恐运祚速而功业不就，以王朴精究术数，一旦从容问之曰：“朕当得几年？”对曰“陛下用心，以苍生为念，天高听卑，自当蒙福。臣固陋，辄以所学推之，三十年后非所知也。”世宗喜曰：“若如卿言，寡人当以十年开拓天下，十年养百姓，十年致太平足矣。”其后自瓦桥关回戈，未到关而晏驾，计在位止及五年余六个月，五六乃三十之成数也，盖朴婉而言之。 |
| 依据 | `033` |

| 说明 | 「十年开拓天下，十年养百姓，十年致太平」——这三句话是全篇最出名的一段，**但它在小注里，是后人追记的**。我照录并标明来处 |
|

---

### 情节点 5 · 未到關

> 世宗末年大举攻取幽州，契丹听说他亲征，君臣恐惧，沿边城垒望风而降，在幽州的蕃部也连夜逃走。
>
> 车驾至瓦桥关，探逻得实，他很高兴，以为大功必集，登高阜观六师。不久有父老百余辈持牛酒来献，他问此地何名，答道：「历世相传，谓之病龙台。」
>
> 他默然，随即上马驰去。当夜圣体不豫，次日病亟，下诏回戈，未到关而晏驾。

| 标记 | ◆ |
| 原文 | `034` 世宗末年，大举以取幽州，契丹闻其亲征，君臣恐惧，沿边城垒皆望风而下，凡蕃部之在幽州者，亦连宵遁去。车驾至瓦桥关，探逻是实，甚喜，以为大勋必集，登高阜，因以观六师。顷之，有父老百余辈持牛酒以献，世宗问曰：“此地何名？”对曰：“历世相传，谓之病龙台。”默然，遽上马驰去。是夜，圣体不豫，翌日病亟，有诏回戈，未到关而晏驾。 |
| 依据 | `034` |

| 说明 | 「病龙台」三个字与他的死连在一起，底本写得像谶语。**叙事上极有效，史实上无从核实**——它同样出自小注 |
|

---

### 情节点 6 · 史臣曰

> 史臣说：世宗出身微贱，格外韬晦；等到天命有归，继承大业，不久就破了高平之阵，过一年又收复秦、凤，江北燕南，取之如拾草芥，神武雄略，是一代英主。
>
> 又说他留心政事，早晚不倦，揭发隐伏、辨明奸伪，多能得当；臣下有过，一定当面驳正。
>
> 然而天性过于明察，用刑过于严峻，事情过了又常常自悔；到末年渐用宽典，知道用兵太频、怜悯百姓劳苦，是有意于康济的。
>
> 最后一句：「而降年不永，美志不就，悲夫！」

| 标记 | ◆ |
| 原文 | `035` 史臣曰：世宗顷在仄微，尤务韬晦，及天命有属，嗣守鸿业，不日破高平之阵，逾年复秦、凤之封，江北、燕南，取之如拾芥，神武雄略，乃一代之英主也。加以留心政事，朝夕不倦，摘伏辩奸，多得其理。臣下有过，必面折之，常言太祖养成二王之恶，以致君臣之义，不保其终，故帝驾驭豪杰，失则明言之，功则厚赏之，文武参用，莫不服其明而怀其恩也。所以仙去之日，远近号慕。然禀性伤于太察，用刑失于太峻，及事行之后，亦多自追悔。逮至末年，渐用宽典，知用兵之频并，悯黎民之劳苦，盖有意于康济矣。而降年不永，美志不就，悲夫！ |
| 依据 | `035` |

| 说明 | 这一段是《旧五代史》的史论，不是事迹。**它给了三个判断：英主、太峻、美志不就**。整篇故事就收在这三个判断上 |
|

## 四、背景卡

### 殿前都點檢

`031` 说「今上始受点检之命」。殿前都点检是殿前司最高军职，统禁军。

**几个月后，赵匡胤正是以这个职位发动陈桥兵变。**

> **依据**：`031`「至是，今上始受点检之命」。

---

### 點檢做

`031` 的木头题字。三个字，被写成神符。

**底本自己解释了它为什么被记住：次年果然应验。**

> **依据**：`031`「则『点检做』之言乃神符也」。

---

### 萬歲殿

`032` 他崩于此殿。万岁殿是后周宫城正殿之一。

**三十九岁，死在北伐回师的当月。**

> **依据**：`032`「帝崩于万岁殿，圣寿三十九」。

---

### 病龍臺

`034` 小注记父老说此地名「病龙台」。他听后默然驰去，当夜不豫。

**一个地名成了死亡预告，这是典型的谶应写法。**

> **依据**：`034`「历世相传，谓之病龙台」。

---

### 慶陵

`032` 他葬于庆陵。陵在郑州新郑一带。

**后周世宗的陵，至今仍在。**

> **依据**：`032`「十一月壬寅朔，葬于庆陵」。

## 七、设计说明

> **这一篇写「一个人在还来得及的时候死了」。**
>
> 六段底本：立后封王、点检做、崩、十年之志、未到关、史臣曰。前两段是安排后事，第三段是死，后三段是别人对他一生的解释。
>
> 我把「十年开拓天下，十年养百姓，十年致太平」放在死后，而不是放在他活着的时候——**因为这段话本来就是后人追记的**，放在最后才不冒充他在场时的宣言。
>
> 三处都标了出处：十年之志、病龙台、「点检做」的神符，全在篇末小注里。正文只有「癸巳，帝崩于万岁殿，圣寿三十九」这一句。**史书把最戏剧性的部分放在注里，这是我们要标清楚的**。
