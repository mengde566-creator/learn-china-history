# 01-yang-zi · 养子入嗣

| | |
|---|---|
| **封面** | — |
| **地点** | 邢州 · 邺城 · 澶州 · 开封 |
| **原文** | 001–007 |

> 七段。一个本姓柴氏的孩子，被郭威养成了儿子。
> 郭家当时正落魄，看中他的不是门第，是「谨厚」。
> 后来郭威做了皇帝，他先守邺城，再去澶州，最后在柩前接过了那个位子。

## 二、正文

### 情节点 1 · 本姓柴氏

> 世宗睿武孝文皇帝，讳荣，是太祖的养子，也是圣穆皇后的侄子。
>
> 他本姓柴氏，父亲柴守礼，以太子少保致仕。
>
> 篇末小注引《隆平集》说：柴翁曾经独居一室，人都以为他管着阴间的事。有一天他笑个不停，妻子问他，他不答。柴翁好酒，妻子把他灌醉，他才说：「上帝有命，郭郎为天子。」
>
> 注家说，这位柴翁就是柴守礼的父亲，史书失了他的名字。

| 标记 | ◆ |
| 原文 | `001` 世宗睿武孝文皇帝，讳荣，太祖之养子，盖圣穆皇后之侄也。本姓柴氏，父守礼，太子少保致仕。《隆平集》：柴翁者，尝独居室，人以为司冥事。一日，笑不止，妻问其故，不答。翁嗜饮，妻醉之以酒，乃曰：“上帝有命，郭郎为天子。”考柴翁即守礼之父，史佚其名。 |
| 依据 | `001` |

| 说明 | 底本正文只有一句半，剩下的全是小注。**「上帝有命，郭郎为天子」这句出自《隆平集》，不是《旧五代史》原文**——写故事时要用它，就得说清来处 |
|

---

### 情节点 2 · 谨厚

> 他生于唐天祐十八年，辛巳岁，九月二十四日丙午，地点在邢州别墅。
>
> 年未童冠，因侍奉圣穆皇后，得以在太祖左右。
>
> 那时太祖无子，家道沦落；看他谨厚，就把种种杂事交给他。他悉心经度，资用得以周济。太祖很怜爱他，便养为己子。

| 标记 | ◆ |
| 原文 | `002` 帝以唐天祐十八年，岁在辛巳，九月二十四日丙午，生于邢州之别墅。年未童冠，因侍圣穆皇后，在太祖左右。时太祖无子，家道沦落，然以帝谨厚，故以庶事委之。帝悉心经度，资用获济，太祖甚怜之，乃养为己子。 |
| 依据 | `002` |

| 说明 | 「以帝谨厚」四个字是这一段的关键：**收养的理由不是血缘，是这个孩子能把事办住**。落难的郭家先需要一个会理家的人，才需要一个儿子 |
|

---

### 情节点 3 · 守鄴城

> 后汉初年，太祖以佐命之功为枢密副使，他始授左监门卫将军。
>
> 小注引《国老谈苑》说：他在后汉做诸卫将军时，在京畿游历，去拜见一位县令。县令正聚着邑客赌博，没有见他。这件事他记下了。
>
> 即位以后，那位县令因差派民夫时贪赃数百匹，宰相范质把案卷呈了上来。他说地方官贪赃到这个地步，依法该处死。范质回说，受所监临的财物有罪，但法不至死。他厉声道：法律是自古帝王所定，本为防奸；朕立法杀赃吏，不算酷刑。范质说，陛下要杀便杀，若交付有司，臣不敢署敕。他这才贷了那人一死。
>
> 二年，太祖镇守邺城，他改任天雄军牙内都指挥使，兼领贵州刺史，加检校右仆射。三年冬天，太祖入朝平定内难，留他守邺城。

| 标记 | ◆ |
| 原文 | `003` 汉初，太祖以佐命功为枢密副使，帝始授左监门卫将军。《国老谈苑》云：周世宗在汉为诸卫将军，尝游畿甸，谒县令，忘其姓名，令方聚邑客蒱博，弗得见，世宗颇衔之。及即位，令因部夫犯赃数百匹，宰相范质以具狱上奏，世宗曰：“亲民之官，赃状狼籍，法当处死。”质奏曰：“受所监临财物有罪，上赃虽多，法不至死。”世宗怒，厉声曰：“法者自古帝王之所制，本以防奸，朕立法杀赃吏，非酷刑也。”质曰：“陛下杀之则可，若付有司，臣不敢署敕。”遂贷其命。二年，太祖镇鄴，改天雄军牙内都指挥使，领贵州刺史、检校右仆射。三年冬，太祖入平内难，留帝守鄴城。 |
| 依据 | `003` |

| 说明 | 「留帝守鄴城」六个字，是郭威把后方交给他的意思。**这一篇里，他从被养的孩子变成了守家的人** |
|

### 情节点 4 · 澶州

> 广顺元年正月，太祖登基。他请求入朝觐见，忽然梦见走到河边却渡不过去。随后朝廷授他做澶州节度使，加检校太保，封为太原郡侯。
>
> 他在镇为政清肃，盗贼不敢犯境。
>
> 先前澶州的里巷湫隘、公署毁坏，他当即拓宽街肆、增修廨宇，吏民都赖其利。
>
> 二年正月，兖州慕容彦超造反，他几次上表请求带兵出征，太祖很赞许。后来曹英等东讨几个月没有战功，太祖打算亲征，召群臣商议。冯道说正当盛夏，车驾不宜冲冒暑气。太祖说：寇不可轻慢；若朕不能去，就让澶州那个儿子去打贼，才办得了朕的事。当时枢密使王峻不愿让他掌兵，所以太祖亲征。六月，兖州平定。

| 标记 | ◆ |
| 原文 | `004` 广顺元年正月，太祖践祚，帝恳求入觐，忽梦至河而不得渡，寻授澶州节度使、检校太保，封太原郡侯。帝在镇，为政清肃，盗不犯境。先是，澶之里巷湫隘，公署毁圯，帝即广其街肆，增其廨宇，吏民赖之。`005` 二年正月，兗州慕容彦超反，帝累表请征行，太祖嘉之。及曹英等东讨，数月无功，太祖欲亲征，召群臣议其事，宰臣冯道奏以方当盛夏，车驾不宜冲冒。太祖曰：“寇不可玩。如朕不可行，当使澶州兒子击贼，方办吾事。”时枢密王峻意不欲帝将兵，故太祖亲征。六月，兗州平。 |
| 依据 | `004`、`005` |

| 说明 | 「当使澶州兒子击贼」是太祖当着群臣给这个养子下的定评。**底本把它写进正文，不是闲笔**：两年后他就成了能「击贼」的那个人 |
|

### 情节点 5 · 柩前即位

> 十二月，他加官同平章事、检校太傅。三年正月入朝觐见；三月，朝廷授他开封尹兼功德使，封晋王。
>
> 显德元年正月庚辰这一天，他又加官开府仪同三司、兼侍中、检校太尉，仍旧做开封尹兼功德使，并判内外兵马事。
>
> 当时太祖寝疾弥留，士庶忧沮；听说他总领内外兵柄，都以为惬当。
>
> 壬辰，太祖驾崩，秘不发丧。丙申，宫中传出太祖遗制，命晋王荣在灵柩前即位。群臣便奉他在柩前做了皇帝。

| 标记 | ◆ |
| 原文 | `006` 十二月，加检校太傅、同平章事。三年正月，帝入觐。三月，授开封尹兼功德使，封晋王。`007` 显德元年正月庚辰，加开府仪同三司、检校太尉、兼侍中，依前开封尹兼功德使，判内外兵马事。时太祖寝疾弥留，士庶忧沮，及闻帝总内外兵柄，咸以为惬。《隆平集》：曹翰隶世宗幕下，世宗镇澶渊，以为牙校。及尹开封，翰犹在澶渊，闻周祖寝疾，不俟召来见世宗，密言曰：“王为冢嗣，不侍医药，何以副天下望？”世宗悟，入侍禁中，以府事命翰总决。壬辰，太祖崩，秘不发丧。丙申，内出太祖遗制：“晋王荣可于柩前即位。”群臣奉帝即皇帝位。 |
| 依据 | `006`、`007` |

| 说明 | 「咸以为惬」三个字是底本替群臣说的：**这个位子交给他，当时没有争议**。而下一段高平之战，正好是这份人望的第一次兑现 |
|

## 四、背景卡

### 圣穆皇后

`001` 称他为「圣穆皇后之侄」。圣穆皇后是郭威的结发之妻柴氏，早死，后周建立后追谥。

**他既是郭家的养子，也是柴家的侄子——这两重身份后来都成了他即位的凭据。**

> **依据**：`001`「盖圣穆皇后之侄也」。

---

### 左监门卫将军

`003` 记后汉初授此职。左监门卫是南衙诸卫之一，将军是环卫官，多为寄禄。

**这是他第一个官衔，不是实职。**

> **依据**：`003`「帝始授左监门卫将军」。

---

### 澶州

`004` 授澶州节度使。澶州在黄河边，五代时为军事重镇，后来的澶渊之盟也在这里。

**他的第一块地盘。底本记他在此「为政清肃，盗不犯境」，又修街肆、增廨宇。**

> **依据**：`004`「寻授澶州节度使」「广其街肆，增其廨宇」。

---

### 判内外兵马事

`007` 太祖病危时加此职。判是兼领，内外兵马事即禁军与诸镇兵权。

**一个养子，在皇帝还活着的时候拿到了全部兵权——这是后周权力交接的实况。**

> **依据**：`007`「判内外兵马事」。

---

### 柩前即位

`007` 太祖遗制「晋王荣可于柩前即位」。在灵柩前即位，是五代常见的匆忙程序。

**它说明这次交接没有经过任何推让或廷议。**

> **依据**：`007`「内出太祖遗制：『晋王荣可于柩前即位。』群臣奉帝即皇帝位」。

## 七、设计说明

> **这一篇写「他凭什么坐上那个位子」。**
>
> 底本给的答案很朴素：谨厚、经度、守邺、澶州治绩、太祖一句「当使澶州兒子击贼」。**没有一件是惊天动地的事**，全是把一个家、一座城交给他，他办住了。
>
> 结构上我把「养子」放在第一层，把「即位」放在最后一层，中间是他逐步拿到实职的四个台阶：左监门卫将军（衔）、天雄军牙内都指挥使（兵）、澶州节度使（地）、开封尹兼功德使（京）。
>
> 一处分寸：柴翁「上帝有命，郭郎为天子」那段小注很吸引人，但它是《隆平集》的传闻。我照录在正文里，却在映射表里明确标 `—`：**能讲，不能当依据。**
