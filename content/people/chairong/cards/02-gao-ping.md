# 复习卡 · 故事 02 · 高平

> 原则：**问动机，不问年代。**

---

## 故事 02 · 高平（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：这一战，胜负是在哪一刻翻转的？**

答：**东厢溃乱之后，他亲自上阵那一刻。**

| 阶段 | 事 | 底本 |
|---|---|---|
| 接战 | 刘崇东西列阵，官军分左右厢 | `009` |
| 溃 | 樊爱能、何徽望贼而遁，步军解甲 | `009` |
| 转 | 帝自率亲骑，临阵督战 | `009` |
| 胜 | 贼军大败，追至涧边又溃 | `009` |
| 诛 | 将校七十余人伏诛 | `010` |

| | |
|---|---|
| 依据 | `009`「樊爱能、何徽望贼而遁……帝乃自率亲骑，临阵督战」 |
| 标记 | ◆ 出自原文 |
| 考点 | 底本写的是先溃后胜，没有把胜利写成必然 |

---

### 卡 2 · 动机

**问：他为什么连何徽也杀？**

答：**因为他有功夫，却先跑了。**

```
高平之役 → 两军成列 → 爱能望风而退，何徽步兵溃乱
                ↓
        帝遣近臣宣谕止遏，莫肯从命
                ↓
  至潞州录其奔遁者，自军使以上并斩之
                ↓
   何徽有平阳守御之功 → 欲贷其罪 → 竟不可
```

| | |
|---|---|
| 依据 | `010`「帝以何徽有平阳守御之功，欲贷其罪，竟不可」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「竟不可」三个字说明他曾犹豫；杀是决定，不是冲动 |

---

### 卡 3 · 证据

**问：这一战之后，军中的规矩变了吗？**

答：**变了：骄将堕兵开始怕了。**

| 变化 | 底本 |
|---|---|
| 录奔遁者，斩军使以上 | `010` |
| 「由是骄将堕兵，无不知惧」 | `010` |

| | |
|---|---|
| 依据 | `010`「帝至潞州，录其奔遁者……由是骄将堕兵，无不知惧」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这句话是底本对后果的判断，不是他的自述 |

---

> **这一篇的读法：** 高平不只是一场胜仗，是他立规矩的地方。<br>
> **七十余颗人头落地之后，这支军队才肯听一个三十四岁的新皇帝。**
