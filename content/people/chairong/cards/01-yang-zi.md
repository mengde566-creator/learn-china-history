# 复习卡 · 故事 01 · 养子入嗣

> 原则：**问动机，不问年代。**

---

## 故事 01 · 养子入嗣（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：这一篇里，他一共拿到了几样东西？**

答：**四样，一样比一样实。**

| 时间 | 得到什么 | 底本 |
|---|---|---|
| 后汉初 | 左监门卫将军（环卫官，多为寄禄） | `003` |
| 太祖镇邺 | 天雄军牙内都指挥使，领贵州刺史 | `003` |
| 广顺元年 | 澶州节度使，封太原郡侯 | `004` |
| 广顺三年 | 开封尹兼功德使，封晋王 | `006` |

**先是衔，再是兵，再是地，最后是京尹。**

| | |
|---|---|
| 依据 | `003`、`004`、`006` |
| 标记 | ◆ 出自原文 |
| 考点 | 四步里只有第三步是「地方」，另三步都在权力中心附近 |

---

### 卡 2 · 动机

**问：郭威为什么收养他？**

答：**因为他能把事办住。**

```
太祖无子，家道沦落 → 以帝谨厚，委以庶事
              ↓
        悉心经度，资用获济
              ↓
        太祖甚怜之，乃养为己子
```

| | |
|---|---|
| 依据 | `002`「以帝谨厚，故以庶事委之。帝悉心经度，资用获济，太祖甚怜之，乃养为己子」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「谨厚」不是夸性格，是说他可靠——收养的起点是家务，不是恩情 |

---

### 卡 3 · 证据

**问：即位那天，底本写了几件事？**

答：**三件：遗制、柩前即位、群臣奉立。**

| 事 | 底本 |
|---|---|
| 太祖崩，秘不发丧 | `007` |
| 内出遗制「晋王荣可于柩前即位」 | `007` |
| 群臣奉帝即皇帝位 | `007` |

| | |
|---|---|
| 依据 | `007`「壬辰，太祖崩，秘不发丧。丙申，内出太祖遗制：『晋王荣可于柩前即位』。群臣奉帝即皇帝位」 |
| 标记 | ◆ 出自原文 |
| 考点 | 底本没有写任何推让或争论——这次交接没有悬念 |

---

> **这一篇的读法：** 一个落难家庭的养子，靠「谨厚」被留下，靠治绩被看见。<br>
> **他即位前没有一件名场面，全是把事办住。**
