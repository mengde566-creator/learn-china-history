# 复习卡 · 故事 04 · 三征南唐

> 原则：**问动机，不问年代。**

---

## 故事 04 · 三征南唐（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：这三年，目标变过吗？**

答：**没有。一直是「尽取江北」。**

| 阶段 | 事 | 底本 |
|---|---|---|
| 出师 | 李穀为行营都部署，诏称吊伐 | `018`、`019` |
| 亲征 | 幸下蔡，破淮贼于上窑 | `020`、`021` |
| 滁州 | 《默记》记皇甫晖十万扼守 | `022` |
| 割地 | 李景愿割六州，帝不允 | `023` |
| 决战 | 紫金山连破数寨 | `024` |
| 临江 | 直抵南岸，焚栅而回 | `025` |
| 乞降 | 李景上表，诏书不允 | `026` |

| | |
|---|---|
| 依据 | `023`「帝志在尽取江北诸郡，不允其请」 |
| 标记 | ◆ 出自原文 |
| 考点 | 六州与江北，差的就是「全部」两个字 |

---

### 卡 2 · 动机

**问：为什么连投降都不立刻接受？**

答：**因为江北还没交割完。**

| 事 | 底本 |
|---|---|
| 李景乞降 | `026`「江南李景上表乞降」 |
| 诏书不允 | `026`「诏书不允」 |

| | |
|---|---|
| 依据 | `026` |
| 标记 | ◆ 出自原文 |
| 考点 | 「不允」是事实，原因底本不写——「未交割」是推说 |

---

### 卡 3 · 证据

**问：这一篇里，哪些是正文，哪些是小注？**

答：**滁州与皇甫晖在小注，其余在正文。**

| 内容 | 出处性质 | 底本 |
|---|---|---|
| 出师、亲征、割地、紫金山、临江 | 《旧五代史》正文 | `018`–`026` |
| 皇甫晖、姚凤十万扼滁州 | 《默记》小注 | `022` |

| | |
|---|---|
| 依据 | `022` 段首即「《默记》：……」 |
| 标记 | ◆ 出自原文 |
| 考点 | 小注也是底本的一部分，但不是《旧五代史》正文 |

---

> **这一篇的读法：** 一场打了三年的仗，目标从第一天就写死了。<br>
> **他要的不是六州，是长江以北全部。**
