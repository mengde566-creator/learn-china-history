# 复习卡 · 故事 05 · 北伐

> 原则：**问动机，不问年代。**

---

## 故事 05 · 北伐（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：这四十二天，他从哪里走到哪里？**

答：**沧州 → 乾宁军 → 益津关 → 瓦桥关。**

| 地点 | 事 | 底本 |
|---|---|---|
| 沧州 | 四月辛卯，车驾次沧州，当日率诸军北征 | `028` |
| 乾宁军 | 壬辰，宁州刺史王洪以城降 | `028` |
| 益津关 | 辛丑，至益津关 | `028` |
| 瓦桥关 | 五月乙巳，驻跸；关南平 | `029` |

| | |
|---|---|
| 依据 | `028`、`029` |
| 标记 | ◆ 出自原文 |
| 考点 | 一路都是受降，没有一场硬仗 |

---

### 卡 2 · 动机

**问：关南已平，他为什么还要议攻幽州？**

答：**因为门开了，但幽州还在门后。**

```
关南平，得州三、县十七
        ↓
丙午，议攻幽州
        ↓
诸将皆以为未可，帝不听
        ↓
是夜，帝不豫，乃止
```

| | |
|---|---|
| 依据 | `029`「诸将皆以为未可，帝不听。是夜，帝不豫，乃止」 |
| 标记 | ◆ 出自原文 |
| 考点 | 拦住他的是身体，不是诸将的意见 |

---

### 卡 3 · 证据

**问：「王师数万，不亡一矢」可信吗？**

答：**这是史臣对这次北伐的评语。**

| 说法 | 底本 |
|---|---|
| 关南平，得州三、县十七、户一万八千三百六十 | `029` |
| 「是役也，王师数万，不亡一矢」 | `029` |
| 「边界城邑皆望风而下」 | `029` |

| | |
|---|---|
| 依据 | `029` |
| 标记 | ◆ 出自原文 |
| 考点 | 受降不等于没有战斗，但底本只记受降 |

---

> **这一篇的读法：** 这是他一生最顺的四十二天。<br>
> **顺到最后一步，他自己不肯停。**
