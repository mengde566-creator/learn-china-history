# 复习卡 · 故事 03 · 整军与求言

> 原则：**问动机，不问年代。**

---

## 故事 03 · 整军与求言（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：这一篇的四件事，哪一件是他自己认错？**

答：**求言诏。**

| 事 | 性质 | 底本 |
|---|---|---|
| 大阅简军 | 补强 | `011` |
| 诏举令录、署举主 | 补强 | `012` |
| 求言：「朕躬之有阙失，得以尽言」 | 自省 | `013`–`015` |
| 废无额寺院 | 收缩 | `016`、`017` |

| | |
|---|---|
| 依据 | `015`「若朕躬之有阙失，得以尽言」 |
| 标记 | ◆ 出自原文 |
| 考点 | 前三件都在「补」，第四件在「减」 |

---

### 卡 2 · 动机

**问：他为什么在求言诏里写「涉道犹浅，经事未深」？**

答：**因为他刚杀完人，知道自己会错。**

```
高平诛七十余将（`010`）
        ↓
大阅简军（`011`）
        ↓
诏举令录、署举主（`012`）
        ↓
求言：朕躬有过，得以尽言（`015`）
```

| | |
|---|---|
| 依据 | `014`「涉道犹浅，经事未深，常惧昏蒙，不克负荷」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这句话是皇帝自述，不是史臣评语 |

---

### 卡 3 · 证据

**问：废寺的判据是什么？**

答：**有没有敕额。**

| 判据 | 处置 | 底本 |
|---|---|---|
| 有敕额寺院 | 一切仍旧 | `016` |
| 无敕额者 | 停废，佛像僧尼并入合留寺院 | `016` |
| 结果 | 存 2694 所，废 30336 所，僧尼 61200 人 | `017` |

| | |
|---|---|
| 依据 | `016`「应有敕额寺院，一切仍旧，其无敕额者，并仰停废」 |
| 标记 | ◆ 出自原文 |
| 考点 | 不是按香火盛衰，是按朝廷认不认 |

---

> **这一篇的读法：** 他把一场败仗拆成三件事：兵要精选、官要举主、话要能说。<br>
> **最后一件最不像政绩，却是他给自己留的退路。**
