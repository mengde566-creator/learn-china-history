# 复习卡 · 故事 06 · 临终

> 原则：**问动机，不问年代。**

---

## 故事 06 · 临终（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：六月这半个月，他做了哪几件事？**

答：**四件：立后、封王、调宰辅、得木。**

| 事 | 底本 |
|---|---|
| 立符彦卿女为皇后 | `030` |
| 宗训封梁王，宗让封燕国公 | `030` |
| 范质、王溥参知枢密院事，魏仁浦为相 | `030` |
| 地中得木，题「点检做」 | `031` |

| | |
|---|---|
| 依据 | `030`、`031` |
| 标记 | ◆ 出自原文 |
| 考点 | 四件事都是交接准备，只有「点检做」不在他的安排里 |

---

### 卡 2 · 动机

**问：他为什么总说「恐运祚速而功业不就」？**

答：**因为他算过时间。**

```
问王朴：朕当得几年？
        ↓
王朴：三十年后非所知也
        ↓
帝：十年开拓天下，十年养百姓，十年致太平
        ↓
在位止五年余六个月
```

| | |
|---|---|
| 依据 | `033`「十年开拓天下，十年养百姓，十年致太平足矣」「在位止及五年余六个月」 |
| 标记 | ◆ 出自原文 |
| 考点 | 他给自己排了三十年，实际只拿到五年半 |

---

### 卡 3 · 证据

**问：史臣对他的评价，哪一句是批评？**

答：**「禀性伤于太察，用刑失于太峻」。**

| 评价 | 底本 |
|---|---|
| 英主：「神武雄略，乃一代之英主也」 | `035` |
| 批评：「用刑失于太峻」 | `035` |
| 惋惜：「降年不永，美志不就，悲夫」 | `035` |

| | |
|---|---|
| 依据 | `035` |
| 标记 | ◆ 出自原文 |
| 考点 | 三条并排，最后一条是史臣的私人叹息 |

---

> **这一篇的读法：** 立后、封王、调相，全在为七岁的儿子铺路。<br>
> **铺完了，他自己没看到第二年春天。**
