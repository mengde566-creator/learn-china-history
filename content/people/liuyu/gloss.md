# 刘裕 · 直译

> **这一份和故事里的白话不是一回事。**
>
> 故事里的白话是给人读的：可以顺着现代汉语的语序重排、可以补主语、可以把两句并成一句。
> 这一份是**直译**：跟着原文的字序和句法走，不替它顺句子、不替它补它没说的主语。
>
> **所以它读起来会比故事里的白话生硬——这是有意的。**
> 故事里的白话告诉你「发生了什么」，这一份告诉你「原文是这么说的」。
>
> 四条写法：
>
> 1. **不补主语。** 原文承前省略，直译也省略。
> 2. **术语随文注。** 官名、地名第一次出现时，用（　）就地解释。
> 3. **不合并、不拆分。** 原文一个句号，直译一个句号。
> 4. **年号照原文。** 公元年份是后世系年，直译不加。
>
> 段号与 `source.md` 一一对应。**没有直译的段就是还没做**——不是「不需要」。

| 004 | 五年春，孫恩頻攻句章，高祖屢摧破之，恩復走入海。三月，恩北出海鹽，高祖追而翼之，築城於海鹽故治。賊日來攻城，城內兵力甚弱，高祖乃選敢死之士數百人，咸脫甲冑，執短兵，並鼓譟而出，賊震懼奪氣，因其懼而奔之，並棄甲散走，斬其大帥姚盛。雖連戰剋勝，然眾寡不敵，高祖獨深慮之。一夜，偃旗匿眾，若已遁者。明晨開門，使羸疾數人登城。賊遙問劉裕所在。曰：「夜已走矣。」賊信之，乃率眾大上。高祖乘其懈怠，奮擊，大破之。恩知城不可下，乃進向滬瀆。高祖復棄城追之。海鹽令鮑陋遣子嗣之以吳兵一千，請為前驅。高祖曰：「賊兵甚精，吳人不習戰，若前驅失利，必敗我軍。可在後為聲援。」不從。是夜，高祖多設伏兵，兼置旗鼓，然一處不過數人。明日，賊率眾萬餘迎戰。前驅既交，諸伏皆出，舉旗鳴鼓。賊謂四面有軍，乃退。嗣之追奔，為賊所沒。高祖且戰且退，賊盛，所領死傷且盡。高祖慮不免，至向伏兵處，乃止，令左右脫取死人衣。賊謂當走反停，疑猶有伏。高祖因呼更戰，氣色甚猛，賊眾以為然，乃引軍去。高祖徐歸，然後散兵稍集。五月，孫恩破滬瀆，殺吳國內史袁山松，死者四千人。是月，高祖復破賊於婁縣。 | 五年春，孙恩屡次攻句章，高祖屡次击破他，孙恩又走入海。三月，孙恩北出海盐，高祖追而侧击他，在海盐旧治筑城。贼天天来攻城，城内兵力很弱，高祖于是选敢死之士数百人，都脱去甲胄，手执短兵，一齐鼓噪而出；贼震惧夺气，高祖趁着他们的恐惧而奔击，贼都弃甲散走，斩其大帅姚盛。虽然连战得胜，但众寡不敌，高祖独自深以为虑。一天夜里，他偃旗藏众，像已经逃走的样子。明早开门，使羸弱有病的几个人登城。贼远远地问刘裕在哪里，回答说：夜里已经走了。贼信了，就率众大批上城。高祖乘其懈怠奋击，大破贼。孙恩知道城攻不下，就进向沪渎。高祖又弃城追他。海盐令鲍陋遣儿子嗣之带吴兵一千，请求为前驱。高祖说：贼兵很精，吴人不习战，若前驱失利，必败我军，可放在后面作声援。不听。这一夜，高祖多设伏兵，又置旗鼓，但一处不过数人。明日贼率众万余迎战。前驱一交战，诸伏都出，举旗鸣鼓，贼以为四面都有军，于是退。嗣之追奔，被贼吞没。高祖且战且退，贼势盛，所领死伤将尽。高祖虑不能免，到原先设伏兵处就停下，令左右脱取死人的衣服。贼以为他该走反而停住，疑心还有伏兵。高祖于是呼叫再战，气色甚猛，贼众以为然，就引军而去。高祖慢慢回来，然后散兵渐渐集合。五月，孙恩破沪渎，杀吴国内史袁山松，死者四千人。这个月，高祖又在娄县破贼。 |
| 005 | 六月，恩乘勝浮海，奄至丹徒，戰士十餘萬。劉牢之猶屯山陰，京邑震動。高祖倍道兼行，與賊俱至。於時眾力既寡，加以步遠疲勞，而丹徒守軍莫有鬭志。恩率眾數萬，鼓譟登蒜山，居民皆荷擔而立。高祖率所領奔擊，大破之，投巘赴水死者甚眾。恩以彭排音敗自載，僅得還船。雖被摧破，猶恃其眾力，徑向京師。樓船高大，值風不得進，旬日乃至白石。尋知劉牢之已還，朝廷有備，遂走向鬱洲。八月，以高祖為建武將軍、下邳太守，領水軍追討至鬱洲，復大破恩。恩南走。十一月，高祖追恩於滬瀆，及海鹽，又破之。三戰並大獲，俘馘以萬數。恩自是饑饉疾疫，死者太半，自浹口奔臨海。 | 六月，孙恩乘胜浮海，忽然到丹徒，战士十余万。刘牢之还屯在山阴，京城震动。高祖倍道兼行，与贼同时到达。当时众力既寡，加上步行的远来疲劳，而丹徒守军没有斗志。孙恩率众数万，鼓噪登蒜山，居民都挑着担子站着。高祖率所领奔击，大破之，投崖赴水死的人很多。孙恩用彭排挡着，才得以上船。虽被摧破，还仗着人多，直向京师。楼船高大，遇风不能进，十天才到白石。不久知道刘牢之已经回来、朝廷有备，就走向郁洲。八月，以高祖为建武将军、下邳太守，领水军追讨到郁洲，又大破孙恩。孙恩南走。十一月，高祖追孙恩到沪渎，到海盐，又破他。三战都大获，俘馘以万计。孙恩从此饥馑疾疫，死者大半，从浃口奔临海。 |
| 006 | 初高祖家貧，嘗負刁逵社錢三萬，經時無以還。逵執錄甚嚴，王謐造逵見之，密以錢代還，由是得釋。高祖名微位薄，盛流皆不與相知，唯謐交焉。桓玄將篡，謐手解安帝璽紱，為玄佐命功臣。及義旗建，眾並謂謐宜誅，唯高祖保持之。劉毅嘗因朝會，問謐璽紱所在，謐益懼。及王愉父子誅，謐從弟諶謂謐曰：「王駒無罪，而義旗誅之，此是剪除勝己，以絕民望。兄既桓氏黨附，名位如此，欲求免得乎？」駒，愉小字也。謐懼，奔於曲阿。高祖牋白大將軍，深相保謐，迎還復位。光祿勳卞承之、左衞將軍褚粲、游擊將軍司馬秀役使官人，為御史中丞王禎之所糾察，謝牋言辭怨憤。承之造司宜藏。高祖與大將軍牋，白「粲等備位大臣，所懷必盡。執憲不允，自應據理陳訴，而橫興怨忿，歸咎有司。宜加裁當，以清風軌」。並免官。 | 起初高祖家贫，曾欠刁逵社钱三万，过期没有东西可还。刁逵拘执他很严，王谧到刁逵处见到他，暗中用钱代还，因此得释。高祖名微位薄，名流都不与他相知，只有王谧与他交往。桓玄将要篡位时，王谧亲手解下安帝的玺绂，做了桓玄的佐命功臣。义旗建立后，众人都说王谧该杀，只有高祖保护他。刘毅曾在朝会上问王谧玺绂在哪里，王谧更怕。到王愉父子被诛，王谧的从弟王谌对王谧说：王驹无罪，而义旗诛他，这是剪除胜己之人，以绝民望；兄既附于桓氏，名位如此，想求免得了吗？驹是王愉的小字。王谧害怕，逃到曲阿。高祖写笺向大将军陈白，极力保王谧，把他迎还复位。光禄勋卞承之、左卫将军褚粲、游击将军司马秀役使官人，被御史中丞王祯之纠察，谢笺言词怨愤。承之造司宜藏。高祖与大将军笺，陈白「褚粲等备位大臣，所怀必尽；执宪不允，自应据理陈诉，却横兴怨忿，归咎有司，宜加裁当，以清风轨」，都被免官。 |
| 007 | 元興元年正月，驃騎將軍司馬元顯西伐荊州刺史桓玄，玄亦率荊楚大眾，下討元顯。元顯遣鎮北將軍劉牢之拒之，高祖參其軍事。次溧洲。玄至，高祖請擊之，不許，將遣子敬宣詣玄請和。高祖與牢之甥東海何無忌並固諫，不從。遂遣敬宣詣玄。玄剋京邑，殺元顯，以牢之為會稽內史。懼而告高祖曰：「便奪我兵，禍其至矣。今當北就高雅於廣陵舉事，卿能從我去乎？」答曰：「將軍以勁卒數萬，望風降服。彼新得志，威震天下。三軍人情，都已去矣，廣陵豈可得至邪！裕當反服還京口耳。」牢之叛走自縊死。何無忌謂高祖曰：「我將何之？」高祖曰：「鎮北去必不免，卿可隨我還京口。桓玄必能守節北面，我當與卿事之；不然，與卿圖之。今方是玄矯情任算之日，必將用我輩也。」桓玄從兄脩以撫軍鎮丹徒，以高祖為中兵參軍，軍、郡如故。 | 元兴元年正月，骠骑将军司马元显西伐荆州刺史桓玄，桓玄也率荆楚大众，东下讨元显。元显派镇北将军刘牢之抵御，高祖参其军事。驻扎溧洲。桓玄到，高祖请求出击，不许；牢之将派儿子敬宣去桓玄处请和。高祖与牢之外甥东海何无忌一起固谏，不听。于是派敬宣去见桓玄。桓玄攻下京邑，杀元显，以牢之为会稽内史。牢之害怕，告高祖说：就这样夺我的兵，祸事到了。现在该北上高雅处，在广陵举事，你能跟我去吗？回答说：将军带着几万劲卒，望风降服；他刚得志，威震天下，三军人情都已散去，广陵哪里到得了！裕只该反服回京口罢了。牢之叛走自缢而死。何无忌对高祖说：我往哪里去？高祖说：镇北这一去必不能免，你可随我回京口。桓玄若能守节北面，我就与你事奉他；不然，就与你图他。如今正是桓玄矫情任算的时候，必将用我们这些人。桓玄的从兄桓脩以抚军镇丹徒，以高祖为中兵参军，军、郡如故。 |
| 008 | 桓玄為楚王，將謀篡盜。玄從兄衞將軍謙屏人問高祖曰：「楚王勳德隆重，四海歸懷。朝廷之情，咸謂宜有揖讓，卿意以為何如？」高祖既志欲圖玄，乃遜辭答曰：「楚王，宣武之子，勳德蓋世。晉室微弱，民望久移，乘運禪代，有何不可。」謙喜曰：「卿謂可爾，便當是真可爾。」十二月，桓玄篡帝位，遷天子於尋陽。桓脩入朝，高祖從至京邑。玄見高祖，謂司徒王謐曰：「昨見劉裕，風骨不恆，蓋人傑也。」每遊集，輒引接慇懃，贈賜甚厚。高祖愈惡之。或說玄曰：「劉裕龍行虎步，視瞻不凡，恐不為人下，宜蚤為其所。」玄曰：「我方欲平蕩中原，非劉裕莫可付以大事。關、隴平定，然後當別議之耳。」玄乃下詔曰：「劉裕以寡制眾，屢摧妖鋒。汎海窮追，十殄其八。諸將力戰，多被重創。自元帥以下至於將士，並宜論賞，以敍勳烈。」 | 桓玄做楚王，将要图谋篡位。桓玄的从兄卫将军桓谦屏退旁人对高祖说：楚王勋德隆重，四海归心，朝廷之情都说该有揖让，你的意思以为如何？高祖既已立志图桓玄，就逊辞回答说：楚王是宣武之子，勋德盖世；晋室微弱，民望久已转移，乘运禅代，有什么不可。桓谦高兴地说：你说可以，那就真可以了。十二月，桓玄篡帝位，把天子迁到寻阳。桓脩入朝，高祖随他到京邑。桓玄见到高祖，对司徒王谧说：昨天见到刘裕，风骨不寻常，是个人杰。每次游集，都拉他相近，馈赠赏赐很厚。高祖越发厌恶他。有人对桓玄说：刘裕龙行虎步，视瞻不凡，怕不肯居人之下，该早早安排。桓玄说：我正要平定中原，非刘裕没人可把大事托付；关、陇平定之后，再另议。桓玄于是下诏说：刘裕以少制众，屡摧妖锋；泛海穷追，十殄其八；诸将力战，多受重创；自元帅以下至于将士，都该论赏，以叙勋烈。 |
| 009 | 先是高祖東征盧循，何無忌隨至山陰，勸於會稽舉義。高祖以為玄未據極位，且會稽遙遠，事濟為難，俟其篡逆事著，徐於京口圖之，不憂不剋。至是桓脩還京，高祖託以金創疾動，不堪步從，乃與無忌同船共還，建興復之計。於是與弟道規、沛郡劉毅、平昌孟昶、任城魏詠之、高平檀憑之、琅邪諸葛長民、太原王元德、隴西辛扈興、東莞童厚之，並同義謀。時桓脩弟弘為征虜將軍、青州刺史，鎮廣陵。道規為弘中兵參軍，昶為州主簿。乃令毅潛往就昶，聚徒於江北，謀起兵殺弘。長民為豫州刺史刁逵左軍府參軍，謀據歷陽相應。元德、厚之謀於京邑聚眾攻玄，並剋期齊發。 | 先是高祖东征卢循，何无忌随到山阴，劝他在会稽举义。高祖以为桓玄还没有据极位，而且会稽遥远，事成很难；等他篡逆的事显露，慢慢在京口图他，不愁不成。到这时桓脩还京，高祖假托金创发病，不能步行跟随，就与无忌同船共还，建兴复之计。于是与弟弟道规、沛郡刘毅、平昌孟昶、任城魏咏之、高平檀凭之、琅邪诸葛长民、太原王元德、陇西辛扈兴、东莞童厚之，一同为义谋。当时桓脩的弟弟桓弘为征虏将军、青州刺史，镇广陵；道规为桓弘中兵参军，孟昶为州主簿。于是令刘毅暗中去孟昶处，聚徒于江北，谋起兵杀桓弘；诸葛长民为豫州刺史刁逵左军府参军，谋据历阳相应；王元德、童厚之谋在京邑聚众攻桓玄：都约定时日一齐发动。 |
| 010 | 玄自聞軍起，憂懼無復為計。或曰：「劉裕等眾力甚弱，豈辦之有成，陛下何慮之甚。」玄曰：「劉裕足為一世之雄；劉毅家無擔石之儲，摴蒲一擲百萬；何無忌，劉牢之甥，酷似其舅。共舉大事，何謂無成。」 | 桓玄自从听说军起，忧惧得不再有主意。有人说：刘裕等众力很弱，哪能成事，陛下何必忧得这么重。桓玄说：刘裕足为一世之雄；刘毅家里没有一担一石的存粮，樗蒲一掷就是百万；何无忌是刘牢之的外甥，极像他舅舅。一同举大事，怎么能说成不了。 |
| 011 | 三月戊午朔，遇吳甫之於江乘。甫之，玄驍將也，其兵甚銳。高祖躬執長刀，大呼以衝之，眾皆披靡，即斬甫之。進至羅落橋，皇甫敷率數千人逆戰。寧遠將軍檀憑之與高祖各御一隊，憑之戰敗見殺，其眾退散。高祖進戰彌厲，前後奮擊，應時摧破，即斬敷首。初高祖與何無忌等共建大謀，有善相者相高祖及無忌等並當大貴，其應甚近，惟雲憑之無相。高祖與無忌密相謂曰：「吾等既為同舟，理無偏異。吾徒咸皆富貴，則檀不應獨殊。」深不解相者之言。至是而憑之戰死，高祖知其事必捷。 | 三月戊午朔，在江乘遭遇吴甫之。甫之是桓玄的骁将，他的兵很锐。高祖亲自握长刀，大呼着冲他，众都披靡，当即斩了甫之。进到罗落桥，皇甫敷率数千人迎战。宁远将军檀凭之与高祖各领一队，凭之战败被杀，他的众退散。高祖进战更猛，前后奋击，应时摧破，即斩皇甫敷的头。当初高祖与何无忌等共建大谋，有个善相的人相高祖及无忌等都说当大贵，应验很近，只说凭之无相。高祖与无忌私下相谓：我们既为同舟，理无偏异；我们都富贵了，檀就不该独异。深深不解相者的话。到这时凭之战死，高祖知道这件事必定成功。 |
| 012 | 玄聞敷等並沒，愈懼。使桓謙屯東陵口，卞範之屯覆舟山西，眾合二萬。己未旦，義軍食畢，棄其餘糧，進至覆舟山東，使丐士張旗幟於山上，以為疑兵。玄又遣武騎將軍庾禕之，配以精卒利器，助謙等。高祖躬先士卒以奔之，將士皆殊死戰，無不一當百，呼聲動天地。時東北風急，因命縱火，煙爓張天，鼓譟之音震京邑。謙等諸軍，一時土崩。玄始雖遣軍置陣，而走意已決，別使領軍將軍殷仲文具舟於石頭，仍將子姪浮江南走。 | 桓玄听说皇甫敷等都覆没，更怕了。使桓谦屯东陵口，卞范之屯覆舟山西，众合二万。己未一早，义军吃过饭，丢弃余粮，进到覆舟山东，使乞丐模样的人在山上张设旗帜，作为疑兵。桓玄又派武骑将军庾祎之，配以精卒利器，去助桓谦等。高祖身先士卒而奔击，将士都殊死战，无不一当百，呼声动天地。当时东北风急，他就命纵火，烟焰张天，鼓噪之音震动京邑。桓谦等诸军一时土崩。桓玄起初虽派军置阵，而逃走之意已经定了，另使领军将军殷仲文在石头备船，就带着子侄浮江南走。 |
| 013 | 庚申，高祖鎮石頭城，立留臺官，焚桓溫神主於宣陽門外，造晉新主，立於太廟。遣諸將帥追玄，尚書王嘏率百官奉迎乘輿。司徒王謐與眾議推高祖領揚州，固辭。乃以謐為錄尚書事，領揚州刺史。於是推高祖為使持節、都督揚、徐、兗、豫、青、冀、幽、並八州諸軍事、領軍將軍、徐州刺史。 | 庚申，高祖镇石头城，立留台官，在宣阳门外焚烧桓温的神主，另造晋室的新主，立在太庙。派诸将帅追桓玄，尚书王嘏率百官奉迎乘舆。司徒王谧与众人议推高祖领扬州，高祖固辞。于是以王谧为录尚书事、领扬州刺史。众人于是推高祖为使持节、都督扬、徐、兖、豫、青、冀、幽、并八州诸军事、领军将军、徐州刺史。 |
| 014 | 先是朝廷承晉氏亂政，百司縱弛，桓玄雖欲釐整，而眾莫從之。高祖以身範物，先以威禁內外，百官皆肅然奉職，二三日間，風俗頓改。且桓玄雖以雄豪見推，而一朝便有極位，晉氏四方牧守及在朝大臣，盡心伏事，臣主之分定矣。高祖位微於朝，眾無一旅，奮臂草萊之中，倡大義以復皇祚。由是王謐等諸人時失民望，莫不愧而憚焉。 | 先是朝廷承晋氏乱政，百官纵弛，桓玄虽想厘整，而众人不肯从。高祖以自身作样子，先用威禁约束内外，百官都肃然奉职，两三天里，风俗顿时改变。而且桓玄虽以雄豪被推，一朝便得极位，晋室四方牧守和在朝大臣都尽心伏事，君臣之分已经定了。高祖位在朝中很低，众人却已经这样看他。 |

| 016 | 五年二月，大掠淮北，執陽平太守劉千載、濟南太守趙元，驅略千餘家。三月，公抗表北討，以丹陽尹孟昶監中軍留府事。四月，舟師發京都，泝淮入泗。五月，至下邳，留船艦輜重，步軍進琅邪。所過皆築城留守。鮮卑梁父、莒城二戍並奔走。 | 五年二月，大掠淮北，执阳平太守刘千载、济南太守赵元，驱略千余家。三月，公上表抗言北伐，以丹阳尹孟昶监中军留府事。四月，舟师从京都出发，溯淮入泗。五月，到下邳，留下船舰辎重，步军进琅邪。所经过的地方都筑城留守。鲜卑的梁父、莒城两处戍守都奔走。 |
| 017 | 慕容超聞王師將至，其大將公孫五樓說超：「宜斷據大峴，刈除粟苗，堅壁清野以待之。彼僑軍無資，求戰不得，旬月之間，折棰以笞之耳。」超不從，曰：「彼遠來疲勞，勢不能久，但當引令過峴，我以鐵騎踐之，不憂不破也。豈有預芟苗稼，先自䠞弱邪。」初公將行，議者以為賊聞大軍遠出，必不敢戰，若不斷大峴，當堅守廣固，刈粟清野，以絕三軍之資，非唯難以有功，將不能自反。公曰：「我揣之熟矣。鮮卑貪，不及遠計，進利剋獲，退惜粟苗。謂我孤軍遠入，不能持久，不過進據臨朐，退守廣固。我一得入峴，則人無退心，驅必死之眾，向懷貳之虜，何憂不剋。彼不能清野固守，為諸君保之。」公既入峴，舉手指天曰：「吾事濟矣！」 | 慕容超听说王师将到，他的大将公孙五楼劝超：该断据大岘，割除粟苗，坚壁清野来等他。对方是侨军，没有资粮，求战不得，十天一月之间，折根鞭子抽他就可以了。超不听，说：他们远来疲劳，势不能久；只该放他们过岘，我用铁骑踩他，不怕不破。哪有先割自己的庄稼、先自己弄弱的道理。当初公将出发，议者以为贼听说大军远出，一定不敢战；若不守大岘，就会坚守广固、割粟清野，以绝三军之粮，不只难以有功，怕是不能自己回去。公说：我揣摩得很熟了。鲜卑贪，看不到远处；进则图掳获，退则惜粟苗。他以为我孤军远入，不能持久，不过进据临朐，退守广固。我一得入岘，人就没有退心；带着必死之众，冲向怀有贰心的敌人，愁什么不克。他们不能清野固守，我为诸位担保。公既入岘，举手指天说：我的事成了！ |
| 018 | 六月，慕容超遣五樓及廣寧王賀賴盧先據臨朐城。既聞大軍至，留羸老守廣固，乃悉出。臨朐有巨蔑水，去城四十里。超告五樓曰：「急往據之，晉軍得水，則難擊也。」五樓馳進。龍驤將軍孟龍符領騎居前，奔往爭之，五樓乃退。 | 六月，慕容超派公孙五楼及广宁王贺赖卢先据临朐城。听说大军到了，就留下羸老守广固，全军都出来。临朐有巨蔑水，离城四十里。超告五楼：快去占据，晋军得了水就难打。五楼驰进。龙骧将军孟龙符领骑兵在前，奔往争夺，五楼于是退。 |
| 019 | 眾軍步進，有車四千兩，分車為兩翼，方軌徐行，車悉張幔，御者執矟。又以輕騎為遊軍。軍令嚴肅，行伍齊整。未及臨朐數里，賊鐵騎萬餘，前後交至。公命兗州刺史劉藩、弟并州刺史道憐、諮議參軍劉敬宣、陶延壽、參軍劉懷玉、慎仲道、索邈等，齊力擊之。日向昃，公遣諮議參軍檀韶直趨臨朐。詔率建威將軍向彌、參軍胡藩馳往，即日陷城，斬其牙旗，悉虜超輜重。超聞臨朐已拔，引眾走，公親鼓之，賊乃大奔。超遁還廣固。獲超馬、偽輦、玉璽、豹尾等，送於京師。斬其大將段暉等十餘人，其餘斬獲千計。 | 众军步进，有车四千辆，分车为两翼，并轨徐行，车都张着幔，驾车的人拿着矟。又以轻骑为游军。军令严肃，行伍齐整。离临朐还有数里，贼的铁骑一万余前后交至。公命兖州刺史刘藩、弟弟并州刺史道怜、谘议参军刘敬宣、陶延寿、参军刘怀玉、慎仲道、索邈等迎击，大破之。 |
| 020 | 明日，大軍進廣固，即屠大城，超退保小城。於是設長圍守之，圍高三丈，外穿三重塹。停江、淮轉輸，館穀於齊土。撫納降附，華戎歡悅，援才授爵，因而任之。七月，詔加公北青、冀二州刺史。超大將垣遵、遵弟苗並率眾歸順。公方治攻具，城上人曰：「汝不得張綱，何能為也。」綱者，超偽尚書郎，其人有巧思。會超遣綱稱藩於姚興，乞師請救。興偽許之，而實憚公，不敢遣。綱從長安還，泰山太守申宣執送之。及升綱於樓車，以示城內，城內莫不失色。於是使綱大治攻具。超求救不獲，綱反見虜，轉憂懼。乃請稱藩，求割大峴為界，獻馬千疋。不聽，圍之轉急。河北居民荷戈負糧至者，日以千數。 | 明日，大军进广固，即屠大城，慕容超退保小城。于是设长围守他，围高三丈，外面穿三重壕堑。停江淮的转运，取齐地的粮。抚纳降附，华戎欢悦，有才的授爵，就着当地情况任用。七月，诏加公北青、冀二州刺史。超的大将垣遵、垣遵的弟弟垣苗都率众归顺。公正在治攻具，城上人说：你得不到张纲，能做什么。张纲是慕容超的伪尚书郎，这个人有巧思。正好超派张纲去姚兴处称藩，乞师请救。姚兴假意答应，其实怕公，不敢派。张纲从长安回来，泰山太守申宣执送他。到把张纲升到楼车上，给城内看，城内没有不失色的。于是使张纲大治攻具。超求救不得，张纲反被俘，转忧惧，于是请求称藩，求割大岘为界，献马千匹。不听，围得更急。河北居民扛着兵器背着粮来的，一天以千计。 |
| 021 | 錄事參軍劉穆之，有經略才具，公以為謀主，動止必諮焉。時姚興遣使告公云：「慕容見與隣好，又以窮告急，今當遣鐵騎十萬，逕據洛陽。晉軍若不退者，便當遣鐵騎長驅而進。」公呼興使答曰：「語汝姚興，我定燕之後，息甲三年，當平關、洛。今能自送，便可速來。」穆之聞有羌使，馳入，而公發遣已去。以興所言並答，具語穆之。穆之尤公曰：「常日事無大小，必賜與謀之。此宜善詳之，云何卒爾便答。公所答興言，未能威敵，正足怒彼耳。若燕未可拔，羌救奄至，不審何以待之？」公笑曰：「此是兵機，非卿所解，故不語耳。夫兵貴神速，彼若審能遣救，必畏我知，寧容先遣信命。此是其見我伐燕，內已懷懼，自張之辭耳。」 | 录事参军刘穆之，有经略才具，公以为谋主，一举一动必定问他。当时姚兴派使者告公说：慕容与我为邻好，又因穷来告急；如今要遣铁骑十万，直据洛阳。晋军若不退，就要遣铁骑长驱而进。公叫来姚兴的使者，答：告诉你家姚兴，我定了燕之后，息甲三年，就平关、洛。如今他能自己送来，就快点来。刘穆之听说有羌使，驰入，而公已经把他打发走了。公把姚兴所言和自己的答话都告诉穆之。穆之怪公说：平常事无大小，必定赐与商量；这件事该好好斟酌，怎么突然便答。公所答的话，不能威敌，正足以激怒他。若燕未可拔，羌救忽然来到，不知拿什么对。公笑说：这是兵机，不是你能懂的，所以没说。用兵贵神速，他若真能派救兵，一定怕我知道，怎会先遣信命；这是他见我伐燕，心里已经怀惧，自己张大之辞罢了。 |
| 022 | 六年二月丁亥，屠廣固。超踰城走，征虜賊曹喬胥獲之，殺其王公以下，納口萬餘，馬二千疋，送超京師，斬於建康市。 | 六年二月丁亥，屠广固。慕容超翻城逃走，征虏贼曹乔胥获住他。杀其王公以下，纳口万余、马二千匹，把超送到京师，斩于建康市。 |
| 023 | 公之北伐也，徐道覆仍有窺窬之志，勸盧循乘虛而出，循不從。道覆乃至番禺說循曰：「本住嶺外，豈以理極於此，正以劉公難與為敵故也。今方頓兵堅城之下，未有旋日。以此思歸死士，掩襲何、劉之徒，如反掌耳。不乘此機而保一日之安，若平齊之後，小息甲養眾，不過一二年間，必璽書徵君。若劉公自率眾至豫章，遣銳師過嶺，雖復將軍神武，恐必不能當也。今日之機，萬不可失。既剋都邑，傾其根本，劉公雖還，無能為也。」循從之，乃率眾過嶺。是月，寇南康、廬陵、豫章，諸郡守皆委任奔走。於時平齊問未至，即馳使徵公。公之初剋齊也，欲停鎮下邳，清盪河、洛，既而被徵使至，即日班師。 | 公北伐的时候，徐道覆仍有窥窬之志，劝卢循乘虚而出，卢循不听从。徐道覆于是到番禺劝卢循说：我们本住岭外，难道以为道理极于此地？正因为刘公难与为敌。如今他正顿兵于坚城之下，未有回师之日；用这些思归的死士，掩袭何、刘那几个人，如反掌一般。不乘这个机会而只保一日的安稳，若等他平齐之后稍稍息甲养众，不过一二年，必定以玺书征召你；若刘公亲自率众到豫章，派锐师过岭，就算将军神武，恐怕也必定不能抵挡。今日的机会，万不可失。既已攻下都邑，倾覆他的根本，刘公就算回来，也无能为力。卢循听从了他，就率众过岭。这个月，寇南康、庐陵、豫章，各郡守都弃任奔走。当时平齐的消息还没到，朝廷即刻驰使征召公。公刚攻克齐地时，想停留在下邳，清荡河、洛；不久征使到了，当日班师。 |
| 024 | 毅敗問至，內外洶擾。於時北師始還，多創痍疾病。京師戰士，不盈數千。賊既破江、豫二鎮，戰士十餘萬，舟車百里不絕。奔敗還者，並聲其雄盛。孟昶、諸葛長民懼寇漸逼，欲擁天子過江，公不聽，昶固請不止。公曰：「今重鎮外傾，強寇內逼，人情危駭，莫有固志。若一旦遷動，便自瓦解土崩，江北亦豈可得至！設令得至，不過延日月耳。今兵士雖少，自足以一戰。若其克濟，則臣主同休；苟厄運必至，我當以死衞社稷，橫屍廟門，遂其由來以身許國之志，不能遠竄於草間求活也。我計決矣，卿勿復言！」昶恐其不濟，乃為表曰：「臣裕北討，眾並不同，唯臣贊裕行計，致使強賊乘間，社稷危逼，臣之罪也。今謹引分以謝天下。」封表畢，乃仰藥而死。 | 刘毅败报传到，内外汹扰。当时北方的兵刚回来，多带创伤疾病；京城的战士不满数千。贼既破江、豫二镇，战士十余万，舟车百里不绝。逃败回来的人，都称说他们的雄盛。孟昶、诸葛长民怕贼渐渐逼近，想拥着天子过江；公不听，孟昶固请不止。公说：如今重镇在外倾覆，强寇在内逼迫，人情危骇，没有固志；一旦迁动，就自己瓦解土崩，江北哪里到得了！就算到了，也不过拖延日月罢了。如今兵士虽少，自足以一战；若其克济，则臣主同休；若厄运必至，我当以死卫社稷，横尸庙门，遂我向来以身许国的志向，不能远远窜到草间求活。我的计已经定了，你不要再说！孟昶怕事不济，就上表说：臣刘裕北伐，众人都不赞同，唯有臣赞成刘裕行计，致使强贼乘间，社稷危逼，这是臣的罪；如今谨引分以谢天下。封好表，就仰药而死。 |
| 025 | 於是大開賞募，投身赴義者，一同登京城之科。發居民治石頭城，建牙戒嚴。時議者謂宜分兵守諸津要。公以為：「賊眾我寡，若分兵屯，則人測虛實。且一處失利，則沮三軍之心。今聚眾石頭，隨宜應赴，既令賊無以測多少，又於眾力不分。若徒旅轉集，徐更論之耳。」移屯石頭，乃柵淮斷查浦。既而羣賊大至，公策之曰：「賊若於新亭直進，其鋒不可當，宜且迴避，勝負之事，未可量也。若回泊西岸，此成擒耳。」 | 于是大开赏募，投身赴义的，一律按登京城之科。发动居民整治石头城，建牙戒严。当时议者说该分兵守各处津要。公以为：贼众我寡，若分兵屯守，人就测出虚实；而且一处失利，就沮三军之心。如今聚众石头，随宜应赴，既令贼无法测我多少，又使众力不分。若徒旅转集，这一点自然就明白了。 |
| 026 | 道覆欲自新亭、白石焚舟而上。循多疑少決，每欲以萬全為慮，謂道覆曰：「大軍未至，孟昶便望風自裁，大勢言之，自當計日潰亂。今決勝負於一朝，既非必定之道，且殺傷士卒，不如按兵待之。」公於時登石頭城以望循軍，初見引向新亭，公顧左右失色。既而回泊蔡洲。道覆猶欲上，循禁之。自是眾軍轉集，修治越城，築查浦、藥園、廷尉三壘，皆守以實眾。冠軍將軍劉敬宣屯北郊，輔國將軍孟懷玉屯丹陽郡西，建武將軍王仲德屯越城，廣武將軍劉懷默屯建陽門外。使寧朔將軍索邈領鮮卑具裝虎班突騎千餘匹，皆被練五色，自淮北至於新亭。賊並聚觀，咸畏憚之；然猶冀京邑及三吳有應之者。遣十餘艦來拔石頭柵，公命神弩射之，發輒摧陷，循乃止不復攻柵。設伏兵於南岸，使羸老悉乘舟艦向白石。公憂其從白石步上，乃率劉毅、諸葛長民北出拒之，留參軍徐赤特戍南岸，命堅守勿動。公既去，賊焚查浦步上，赤特軍戰敗，死沒有百餘人。赤特棄餘眾，單舸濟淮。賊遂率數萬屯丹陽郡。公率諸軍馳歸。眾憂賊過，咸謂公當徑還拒戰。公先分軍還石頭，眾莫之曉。解甲息士，洗浴飲食之，乃出列陳於南塘。以赤特違處分，斬之。命參軍褚叔度、朱齡石率勁勇千餘人過淮。羣賊數千，皆長刀矛鋋，精甲曜日，奮躍爭進。齡石所領多鮮卑，善步矟，並結陳以待之。賊短兵弗能抗，死傷者數百人，乃退走。會日莫，眾亦歸。 | 徐道覆想从新亭、白石焚舟而上。卢循多疑少决，每想以万全为虑，对徐道覆说：大军未到，孟昶就望风自裁；从大势说，自当计日溃乱。如今一战定胜负，已不是必定的道理；况且杀伤士卒，不如按兵等他。公这时登石头城望卢循的军，初见他们引向新亭，公回头看左右，脸色都变了。不久回泊蔡洲。徐道覆还想上，卢循禁止他。从此众军转集，修治越城，筑查浦、药园、廷尉三垒，都用实兵守。冠军将军刘敬宣屯北郊，辅国将军孟怀玉屯丹阳郡西，建武将军王仲德屯越城，广武将军刘怀默屯建阳门外。使宁朔将军索邈领鲜卑具装虎班突骑一千余匹，都披着五色的练，从淮北到新亭。贼都聚观，都畏惮他们；但还希望京邑及三吴有响应的人。派十余舰来拔石头的栅，公命神弩射它，一发就摧陷，卢循于是停止，不再攻栅。贼在南岸设伏兵，使羸老都乘舟舰向白石。公怕他们从白石步上，就率刘毅、诸葛长民北出拒他，留参军徐赤特戍南岸，命他坚守勿动。公既去，贼焚查浦步上，赤特军战败，死没有一百余人。赤特丢下余众，单舸渡淮。贼于是率数万屯丹阳郡。公率诸军驰归，众人担心贼已过去，都说公该径直还击。公先分军还石头，众人都不明白。解甲息士，让他们洗浴饮食，然后出列阵于南塘。以赤特违犯处分，斩了他。命参军褚叔度、朱龄石率劲勇一千余人过淮。群贼数千，都持长刀矛鋋，精甲曜日，奋跃争进。 |
| 027 | 循方治兵旅舟艦，設諸攻備。公欲御以長算，乃屯軍雷池。賊揚聲不攻雷池，當乘流逕下。公知其欲戰，且慮賊戰敗，或於京江入海，遣王仲德以水艦二百於吉陽下斷之。十二月，循、道覆率眾數萬，方艦而下，前後相抗，莫見舳艫之際。公悉出輕利鬭艦，躬提幡鼓，命眾軍齊力擊之。又上步騎於西岸。右軍參軍庾樂生乘艦不進，斬而徇之。於是眾軍並踴騰爭先。軍中多萬鈞神弩，所至莫不摧陷。公中流蹙之，因風水之勢，賊艦悉泊西岸。岸上軍先備火具，乃投火焚之，煙爓張天，賊眾大敗，追奔至夜乃歸。循等還尋陽。初分遣步軍，莫不疑怪，及燒賊艦，眾乃悅服。召王仲德，請還為前驅。留輔國將軍孟懷玉守雷池。循聞大軍上，欲走向豫章，乃悉力柵斷左里。大軍至左里，將戰，公所執麾竿折，折幡瀋水，眾並怪懼。公歡笑曰：「往年覆舟之戰，幡竿亦折，今者復然，賊必破矣。」即攻柵而進。遁兵雖殊死戰，弗能禁。諸軍乘勝奔之，循單舸走。所殺及投水死，凡萬餘人。納其降附，宥其逼略。遣劉藩、孟懷玉輕軍追之。循收散卒，尚有數千人，逕還廣州。道覆還保始興。公旋自左里。天子遣侍中、黃門勞師於行所。 | 卢循正在整治兵旅舟舰，设各种攻备。公想以长算制敌，就屯军在雷池。贼扬言不攻雷池，要乘流直下。公知道他们想战，又怕贼战败后从京江入海，派王仲德以水舰二百在吉阳下断他。十二月，卢循、徐道覆率众数万，方舰而下，前后相抗，看不见舳舻的头尾。公把轻利斗舰全放出去，亲自提着幡鼓，命众军齐力击他；又让步骑上西岸。右军参军庾乐生乘舰不进，斩了徇示。于是众军都踊跃争先。军中多「万钧神弩」，所到没有不摧陷的。公在中流逼蹙他们，顺着风水的势，贼舰都泊向西岸；岸上的军先备好火具，就投火焚烧，烟焰张天，贼众大败。追奔到夜里才回。卢循等还寻阳。当初分遣步军，众人没有不疑怪的；到烧了贼舰，众人才悦服。召回王仲德，请他回来作前驱，留辅国将军孟怀玉守雷池。卢循听说大军向上游来，想走向豫章，于是全力栅断左里。大军到左里，将要战，公所执的麾竿折断，折幡沉入水中，众人都觉怪异恐惧。公欢笑说：往年覆舟之战，幡竿也折；今天又这样，贼必定破。就攻栅而进。卢循的兵虽然殊死战，不能禁。诸军乘胜奔击，卢循单舸逃走。所杀和投水死的共一万余人。纳其降附，宽宥被逼略的人。遣刘藩、孟怀玉轻军追他。卢循收散卒，还有数千人，径还广州。徐道覆还保始兴。公从左里旋师。天子遣侍中、黄门在行在慰劳军队。 |
| 028 | 初公平齊，仍有定關、洛之意，值盧循侵逼，故其事不諧。荊、雍既平，方謀外略。會羌主姚興死，子泓立，兄弟相殺，關中擾亂，公乃戒嚴北討。加領征西將軍、司豫二州刺史。以世子為徐、兗二州刺史。下書曰：「吾倡大義，首自本州，克復皇祚，遂建勳烈，外夷勍敵，內清姦軌，皆邦人州黨竭誠盡力之效也。情若風霜，義貫金石。今當奉辭西斾，有事關、河，弱嗣叨蒙，復忝今授，情事纏綿，可謂深矣。頃軍國務殷，刑辟未息，眷言懷之，能不多歎。其犯罪繫五歲以還，可一原遣。文武勞滿未蒙榮轉者，便隨班序報。」 | 当初公平定齐地，就仍有安定关、洛的意思；碰上卢循侵逼，所以这件事没有办成。荆、雍既已平定，才谋向外经略。碰上羌主姚兴死，儿子姚泓立，兄弟相杀，关中扰乱，公于是戒严北讨。加领征西将军、司豫二州刺史；以世子为徐、兖二州刺史。下书说：我倡大义，从本州起头，克复皇祚，于是建立勋烈；外夷强敌，内清奸轨，都是邦人州党竭诚尽力之效。情若风霜，义贯金石。如今当奉辞西斾，有事关、河；弱嗣叨蒙，又忝今授，情事缠绵，可谓深了。近来军国务殷，刑辟未息，眷言怀之，能不多叹。那些犯罪系狱五年以来的，可一概原遣；文武劳满未蒙荣转的，就随班序报。 |

| 040 | 史臣曰：漢氏載祀四百，比祚隆周，雖復四海橫潰，而民繫劉氏，惵惵黔首，未有遷奉之心。魏武直以兵威服眾，故能坐移天曆，鼎運雖改，而民未忘漢。及魏室衰孤，怨非結下。晉藉宰輔之柄，因皇族之微，世擅重權，用基王業。至於宋祖受命，義越前模。晉自社廟南遷，祿去王室，朝權國命，遞歸台輔。君道雖存，主威久謝。桓溫雄才葢世，勳高一時，移鼎之業巳成，天人之望將改。自斯以後，晉道彌昏，道子開其禍端，元顯成其末釁，桓玄藉運乘時，加以先父之業，因基革命，人無異心。高祖地非桓、文，眾無一旅，曾不浹旬，夷凶翦暴，祀晉配天，不失舊物，誅內清外，功格區宇。至於鍾石變聲，柴天改物，民巳去晉，異於延康之初，功實靜亂，又殊咸熙之末。所以恭皇高遜，殆均釋負。若夫樂推所歸，謳歌所集，魏、晉采其名，高祖收其實矣。盛哉！ | 史臣说：汉氏享有祀四百年，比祚隆周；虽又四海横溃，而民心系在刘氏，惵惵黔首，未有迁奉之心。魏武只用兵威服众，所以能坐移天历；鼎运虽改，而民未忘汉。到魏室衰孤，怨不结于下。晋藉宰辅之柄，因皇族之微，世擅重权，用基王业。 |
| 041 | 皇帝臣裕，敢用玄牡，昭告皇天后帝。晉帝以卜世告終，歷數有歸，欽若景運，以命於裕。夫樹君宰世，天下為公，德充帝王，樂推攸集。越俶唐、虞，降暨漢、魏，靡不以上哲格文祖，元勳陟帝位，故能大拯黔首，垂訓無窮。晉自東遷，四維不振，宰輔焉依，為日巳久。難棘隆安，禍成元興，遂至帝主遷播，宗祀堙滅。裕雖地非齊、晉，眾無一旅，仰憤時難，俯悼橫流，投袂一麾，則皇祀克復。及危而能持，顛而能扶，姦宄具殲，僭偽必滅。誠興廢有期，否終有數。至於大造晉室，撥亂濟民，因藉時來，實屍其重。加以殊俗慕義，重譯來庭，正朔所暨，咸服聲教。至乃三靈垂象，山川告祥，人神協祉，歲月滋著。是以羣公卿士，億兆夷人，僉曰皇靈降鑒於上，晉朝款誠於下，天命不可以久淹，宸極不可以暫曠。遂逼羣議，恭茲大禮。猥以寡德，託於兆民之上，雖仰畏天威，略是小節，顧深永懷，祗懼若霣。敬簡元辰，升壇受禪，告類上帝，用酬萬國之情。克隆天保，永祚於有宋。惟明靈是饗。 | 皇帝臣刘裕，谨用玄牡，昭告皇天后帝。晋帝以卜世告终，历数有归，钦若景运，以命于裕。树立君长、主宰世间，天下为公；德充帝王，众望所推就集。远从唐、虞，下及汉、魏，无不是以上哲格于文祖，元勋升上帝位，所以能大拯黔首，垂训无穷。晋自东迁，四维不振，倚靠宰辅，为日已久。祸难起于隆安，祸成于元兴，遂至帝主迁播，宗祀堙灭。裕虽地非齐、晋之比，众无一旅，仰愤时难，俯悼横流，投袂一麾，而皇祀克复。及危而能持，颠而能扶，奸宄尽歼，僭伪必灭。诚然兴废有期，否终有数。至于大造晋室、拨乱济民，因借时来，实尸其重。加以殊俗慕义，重译来庭，正朔所暨，都服声教。乃至三灵垂象，山川告祥，人神协祉，岁月滋著。所以群公卿士、亿兆夷人，都说皇灵降鉴于上，晋朝款诚于下；天命不可久淹，宸极不可暂旷。于是逼于群议，恭行此大礼。猥以寡德，托于兆民之上，虽仰畏天威，略是小节，顾深永怀，祗惧若霣。敬简元辰，升坛受禅，告类上帝，用酬万国之情。克隆天保，永祚于有宋。惟明灵是飨。 |
