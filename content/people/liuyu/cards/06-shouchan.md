## 故事 06 · 受禅（8 张）

### 卡 1 · 结构 ★

**问：禅让的程序，在这八段里分几步？**

| 步 | 段 | 内容 |
|---|---|---|
| 1 | `033` | 前朝下诏禅位 |
| 2 | `034` | 新朝上表陈让；表不获通 |
| 3 | `034` | 二百七十人及宋台群臣劝进；仍不许 |
| 4 | `034` | 太史令陈符瑞；群臣固请；乃从 |
| 5 | `035` | 南郊设坛，柴燎告天，即皇帝位 |
| 6 | `036` | 封前朝君为零陵王，定其礼数 |

**每一步都不能省。** 少了哪一步，这件事就不叫禅让。

### 卡 2 · 细节 ★

**问：「表不獲通」这四个字，为什么值得停一下？**

答：**因为推让的对象已经不在原位了。**

`034` 记：王奉表陈让，而「晉帝已遜琅邪王第，表不獲通」。

新朝皇帝的表，是上给前朝天子的。前朝天子已经搬出宫去，表就递不进去。**推让的对象消失了，推让的动作还在。**

| | |

| 依据 | `034`「晉帝已遜琅邪王第，表不獲通」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一个动作在什么条件下会失去对象 |

### 卡 3 · 人物

**问：「皇帝臣裕」这四个字怎么读？**

答：**两个身份压在同一句里。**

`041` 的开头：「皇帝臣裕，敢用玄牡，昭告皇天后帝。」

对着天，他称「臣」；对人，他已经是「皇帝」。祭天的策文里，这个自称同时成立。

| 标记 | ◆ 出自原文 |

### 卡 4 · 因果

**问：给零陵王的待遇，为什么列得那么细？**

答：`036` 逐条写：全食一郡、载天子旍旗、乘五时副车、行晋正朔、郊祀礼乐用晋典，还有「上書不為表，答表勿稱詔」。

这些条目有两个作用：**一是不让他掉出礼制，二是不让他再碰到皇权。**「上书不称表」是称呼的降格，不是待遇的取消。

| | |
|---|---|
| 依据 | `036`「載天子旍旗，乘五時副車，行晉正朔」；「上書不為表，答表勿稱詔」 |
| 标记 | ◆ 出自原文 |
| 考点 | 保留得越完整，界线越清楚 |

### 卡 5 · 人物 ★

**问：临终那份名单，为什么值得读三遍？**

答：**因为他把四个人分了三种。**

| 人 | 评语 | 处置 |
|---|---|---|
| 檀道济 | 「有幹略，而無遠志」 | 可用，不必防 |
| 徐羡之、傅亮 | 「當無異圖」 | 可托 |
| 谢晦 | 「若有同異，必此人也」 | 要防，且给了安置的办法 |

名单最后还有一条：后世若有幼主，朝事一委宰相，母后不烦临朝。

| | |
|---|---|
| 依据 | `037`「檀道濟雖有幹略，而無遠志」；「徐羨之、傅亮當無異圖」；「若有同異，必此人也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三个评语，三种用法 |

### 卡 6 · 细节

**问：虎魄枕那件事，能说明什么？**

答：**说明他把「好东西」换算成了「有用的东西」。**

`039` 记：宁州献虎魄枕，光色甚丽；那时将北征，虎魄能治金创，他很高兴，「命擣碎分付諸將」。

同一段还有：局脚床改直脚床、银涂钉改铁钉、诸主出适不过二十万、常着连齿木屐、从者不过十余人。

### 卡 7 · 陷阱 ★

**问：「田舍公得此，以為過矣」是夸他吗？**

答：**底本没有替这句话定性。**

说话的是孝武帝，刘裕的孙子，正带着群臣看他祖父住过的旧室：床头有土鄣，壁上挂着葛灯笼、麻绳拂子。侍中袁顗称颂俭素之德，孝武不答，只说了这一句。

「田舍公」是庄稼汉。**它可以是赞叹，也可以是嫌弃，取决于说话的人。** 底本只记「不答，獨曰」，不加评断。

| | |
|---|---|
| 依据 | `039`「牀頭有土鄣，壁上掛葛燈籠、麻繩拂」；「孝武不答，獨曰：『田舍公得此，以為過矣』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 同一句话可以有两种读法 |

### 卡 8 · 对照

**问：史臣曰和前面七段，是什么关系？**

答：**前面是记事，最后一段是判断。**

`040` 从「漢氏載祀四百」讲起，论魏以兵威服众、晋藉宰辅之柄，一路讲到禅代的根据。它不提供新的事实，只提供一套看法。

所以这一篇的读法是：**七段看发生了什么，一段看写史的人怎么想。**

| | |
|---|---|
| 依据 | `040`「史臣曰」；「魏武直以兵威服眾」 |
| 标记 | ◆ 出自原文 |
| 考点 | 纪末的论赞不是记事 |
