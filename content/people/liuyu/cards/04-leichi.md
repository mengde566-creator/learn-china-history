# 复习卡 · 故事 04 · 雷池

> 原则：**问决定，不问数字。**
> 这一篇的每一个决定，都是在兵比对方少的时候做的。

---

## 故事 04 · 雷池（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇的五段，哪一段是「决定」，哪一段是「接住」？**

| 段 | 性质 | 一句话 |
|---|---|---|
| `023` | 敌人决定 | 徐道覆说动卢循，乘虚而下 |
| `024` | 他决定 | 不迁都，不避 |
| `025` | 他决定 | 不分兵，聚众石头 |
| `026` | 他接住 | 贼回泊蔡洲，赤特战败，他斩将、息士、列阵 |
| `027` | 他决定 | 屯雷池、断吉阳、亲自击鼓 |

三次决定，两次都在兵最少的时候做。

| | |
|---|---|
| 依据 | `023`「循從之，乃率眾過嶺」；`024`「我計決矣」；`025`「今聚眾石頭」 |
| 标记 | ◆ 出自原文 |
| 考点 | 主动与被动各占几段 |

---

### 卡 2 · 人物 ★

**问：「若一旦遷動，便自瓦解土崩」——他给的理由是什么？**

答：**三层，一层比一层实。**

| 层 | 原话 |
|---|---|
| 人心 | `024`「人情危駭，莫有固志」 |
| 后果 | `024`「若一旦遷動，便自瓦解土崩」 |
| 去处 | `024`「江北亦豈可得至！設令得至，不過延日月耳」 |

最后一句最狠：逃也逃不掉。他不是在讲气节，是在算退路的账。

| | |
|---|---|
| 依据 | `024` |
| 标记 | ◆ 出自原文 |
| 考点 | 三条理由的次序：人心 → 崩解 → 无处可去 |

---

### 卡 3 · 因果

**问：为什么不分兵守津要？**

答：**两个理由，都写在 `025` 里。**

| 理由 | 原话 |
|---|---|
| 分兵会露虚实 | 「若分兵屯，則人測虛實」 |
| 一处失利动全军 | 「一處失利，則沮三軍之心」 |

所以他选了「聚眾石頭，隨宜應赴」——把兵放在一处，靠自己的调度去补各个缺口。

| | |
|---|---|
| 依据 | `025` |
| 标记 | ◆ 出自原文 |
| 考点 | 集中兵力的代价是别处空了，他认这个代价 |

---

### 卡 4 · 人物

**问：孟昶的死，在叙事上起什么作用？**

答：**它把「退」这个选项变成了一个死人的事。**

孟昶主张过江，被拒；他自己上表，把「唯臣贊裕行計」的罪揽下，然后仰药而死。

底本紧接着的下文是「於是大開賞募」。**中间空着**：没有哀悼，没有解释，也没有一句他对此的反应。

| | |
|---|---|
| 依据 | `024`「唯臣贊裕行計」；「封表畢，乃仰藥而死」 |
| 标记 | ◆ 出自原文 |
| 考点 | 沉默也是叙事 |

---

### 卡 5 · 细节 ★

**问：「公顧左右失色」这六个字，为什么值得单拎出来？**

答：**因为它写的是别人的脸，不是他的。**

`026` 记他登石头城望循军，看见船转向新亭，「公顧左右失色」，然后贼回泊蔡洲。

底本通篇没有一句写他本人的恐惧或镇定。这一句只提供两个信息：他回头看了；看的时候，左右的脸已经变了。

| | |
|---|---|
| 依据 | `026`「初見引向新亭，公顧左右失色」 |
| 标记 | ◆ 出自原文 |
| 考点 | 视角停在他的动作上，不在他的心里 |

---

### 卡 6 · 因果

**问：斩了徐赤特之后，他为什么先让兵洗浴饮食？**

答：**因为刚跑回来的兵不能直接列阵。**

`026` 的次序是：驰归 → 先分军还石头 → 解甲息士 → 洗浴饮食之 → 乃出列陈于南塘 → 斩赤特。

注意斩将在这串动作之后，不是之前。**先让活着的人缓过来，再处理违令的人。**

| | |
|---|---|
| 依据 | `026`「解甲息士，洗浴飲食之，乃出列陳於南塘。以赤特違處分，斬之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 次序：息士 → 列阵 → 斩将 |

---

### 卡 7 · 因果

**问：雷池这一战，他是怎么把贼舰逼到西岸的？**

答：**三步。**

| 步 | 原话 |
|---|---|
| 1 | 「公悉出輕利鬭艦」——用轻快的舰接战 |
| 2 | 「公中流蹙之，因風水之勢」——在中流逼压，借风水 |
| 3 | 「賊艦悉泊西岸」→ 岸上军投火 |

**关键不是弩，是水势。** 弩在 `027` 里是「所至莫不摧陷」，但把敌人送到西岸的，是船和流。

| | |
|---|---|
| 依据 | `027` |
| 标记 | ◆ 出自原文 |
| 考点 | 火攻的前提是船已经挤在一处 |

---

### 卡 8 · 对照

**问：幡竿折了，他为什么笑？**

答：**因为两年前也折过一次。**

`027` 记：左里将战，他手里的麾竿折了，幡沉进水里，众人怪惧。他笑说「往年覆舟之戰，幡竿亦折，今者復然，賊必破矣」。

覆舟山那一战在 `012`：东北风急，纵火，桓谦土崩。**同一个兆头，他用第二次来讲给第一次没在场的人听。**

| | |
|---|---|
| 依据 | `027`「往年覆舟之戰，幡竿亦折，今者復然，賊必破矣」；`012`「因命縱火，煙爓張天」 |
| 标记 | ◆ 出自原文 |
| 考点 | 他记得自己的战例，并且会用它安抚人 |
