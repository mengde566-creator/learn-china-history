# 复习卡 · 故事 01 · 京口寒门

> 原则：**问动机，不问年代。**
> 目标是理解这段记载的分量，不是记年表。所以题目问「为什么」，不问「哪一年」。

---

## 故事 01 · 京口寒门（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：六段里，哪一段不在编年的线上？它为什么被放在最后？**

答：**第六段（社钱三万）是追叙。**

前五段的顺序是跟着战事走的：孙无终司马 → 觇贼 → 句章 → 海盐 → 蒜山。第六段开头一个字是「初」，写的是更早的事：

| 段 | 写法 | 时间 |
|---|---|---|
| `002`–`005` | 按年、按月记战事 | 隆安三年、四年、五年 |
| `006` | 「初高祖家貧」 | 追叙，时在那几年之前 |

把它放在最后，全篇的重心就变了：前面看你打了什么，最后看你原来站在哪里。

| | |
|---|---|
| 依据 | `006`「初高祖家貧，嘗負刁逵社錢三萬」；`002`「安帝隆安三年十一月」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「初」字是追叙的记号；顺序本身就是内容 |

---

### 卡 2 · 人物 ★

**问：为什么说「名微位薄，盛流皆不與相知」是这一篇最重的一句？**

答：因为它把前面五段的功劳换了一个尺度来量。

前面量他的是战功：斩大帅、破数万、俘获以万计。第六段量他的是门第：名位都低，名流没有一个人和他来往。**替他还钱的是一个名流**——他凭战功进不去的那一层，靠一笔债碰上了。

| | |
|---|---|
| 依据 | `006`「高祖名微位薄，盛流皆不與相知，唯謐交焉」；`004`「斬其大帥姚盛」；`005`「俘馘以萬數」 |
| 标记 | ◆ 出自原文 |
| 考点 | 战功与门第是两把尺子；这一篇用的是第二把 |

---

### 卡 3 · 因果

**问：句章城那么小，他凭什么守住？**

答：底本给了两件事，不是一件。

| 做法 | 原文 |
|---|---|
| 自己站在前面 | `003`「高祖常被堅執銳，為士卒先」 |
| 部队不抢掠 | `003`「唯高祖法令明整，所至莫不親賴焉」 |

第二条尤其难得：同一段写着东伐诸将「御軍無律，士卒暴掠」，只有他这一支例外。

| | |
|---|---|
| 依据 | `003`「句章城既卑小，戰士不盈數百人」；「高祖常被堅執銳，為士卒先」；「唯高祖法令明整，所至莫不親賴焉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 守城靠两样：主将靠前，军纪不坏 |

---

### 卡 4 · 因果

**问：海盐那一段，他用了几次「骗」？**

答：三次，一次比一次险。

| # | 做法 | 结果 |
|---|---|---|
| 1 | 偃旗匿众，让病人登城 | 贼信「夜里已走」，大上，被破 |
| 2 | 多设伏兵，摆旗鼓，一处不过数人 | 贼以为四面有军，退 |
| 3 | 退到伏兵处，令左右脱取死人衣 | 贼「謂當走反停，疑猶有伏」，去 |

第三次最险：那时「所領死傷且盡」，已经没有别的办法了。

| | |
|---|---|
| 依据 | `004`「偃旗匿眾，若已遁者」；「多設伏兵，兼置旗鼓」；「令左右脫取死人衣」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三次都是应急，不是算计好的 |

---

### 卡 5 · 因果

**问：蒜山那一战的关键是哪四个字？**

答：**「與賊俱至」。**

他离得远，兵少，还带着疲惫的步卒；可他从陆上急行，和从海上来的贼同时到了山下。到了就打，不等后援。

| | |
|---|---|
| 依据 | `005`「高祖倍道兼行，與賊俱至」 |
| 标记 | ◆ 出自原文 |
| 考点 | 关键在时间，不在兵力 |

---

### 卡 6 · 人物

**问：鲍陋不听他的话，代价是什么？**

答：**赔上了儿子的命。**

`004` 记：海盐令鲍陋派儿子嗣之带一千吴兵请为前驱。刘裕说贼兵精、吴人不习战，前驱一失利就要败全军，请放在后面作声援——不听。第二天伏兵齐出时，前驱既交，贼退，嗣之追奔，被贼吞掉。

这不是报复，是连锁：前驱追出去，阵形就乱了。

| | |
|---|---|
| 依据 | `004`「海鹽令鮑陋遣子嗣之以吳兵一千，請為前驅」；「嗣之追奔，為賊所沒」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「前驅失利，必敗我軍」——他事先说过 |

---

### 卡 7 · 陷阱 ★

**问：这一篇里，他有没有表现过「谋略」？**

答：**有过布置，但没有一件是事前的谋划。**

六段里他的动作大多是即时的：冲、守、脱甲、急行。`004` 里有两处看得出预判：「偃旗匿眾，若已遁者」是先把人藏起来，等对方信了再打；「多設伏兵，兼置旗鼓」是前一晚就摆好的。两处都是为了第二天这一仗，不是替后面几步算的。`003` 的「法令明整」也只是治军的结果。

先算对方的性格、再定打不打——这种谋略，在这一篇里还没有出现。

| | |
|---|---|
| 依据 | `004`「偃旗匿眾，若已遁者」；「多設伏兵，兼置旗鼓」；`002`「高祖便進與戰」；`005`「倍道兼行」 |
| 标记 | ○ 合理推演 |
| 考点 | 区分「被记下来的动作」与「后人加给他的形象」 |

### 卡 8 · 对照

**问：这一篇开始时他是什么身份，结束时又是什么身份？**

| 时 | 身份 | 出处 |
|---|---|---|
| 起 | 冠军孙无终司马 | `002` |
| 中 | 刘牢之府参军事，戍句章 | `002`、`003` |
| 末 | 建武将军、下邳太守 | `005` |

末一项是打完蒜山、追到郁洲之后给的。**官职是他自己打出来的**——同一段里没有一句提到别人举荐。

| | |
|---|---|
| 依据 | `002`「初為冠軍孫無終司馬」；`003`「使高祖戍句章城」；`005`「以高祖為建武將軍、下邳太守」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三段官职，一条上升线 |
