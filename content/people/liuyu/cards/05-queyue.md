# 复习卡 · 故事 05 · 却月阵

> 原则：**问阵法，也问人。**
> 这一篇一半是兵器，一半是一个人的死。

---

## 故事 05 · 却月阵（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：同一场仗，为什么会有两种写法？**

| 书 | 写法 | 一句话 |
|---|---|---|
| 〈武帝紀〉 | 编年，一句一战 | `030`「索虜步騎十萬，營據河津。公命諸軍濟河擊破之」 |
| 〈朱超石傳〉 | 列传，记阵法与人 | `103`–`107` 记车、弩、矟、斩将 |

本纪不问「怎么打」，列传不问「为什么打」。**两本并读，这件事才立起来。**

| | |
|---|---|
| 依据 | `030`；`103`「為卻月陣，兩頭抱河」 |
| 标记 | ◆ 出自原文 |
| 考点 | 编年与列传各记什么 |

---

### 卡 2 · 细节 ★

**问：「卻月」是什么形状？为什么是这个形状？**

答：**缺月，两头贴着河岸。**

`103` 记「為卻月陣，兩頭抱河，車置七仗士」。两端抵水，中间凸向岸上——**侧翼交给河，正面交给车和弩。**

对面调来了铁骑，骑兵要绕。这个形状没有地方可绕。

| | |
|---|---|
| 依据 | `103`「為卻月陣，兩頭抱河，車置七仗士」 |
| 标记 | ◆ 出自原文 |
| 考点 | 形状本身就是战术 |

---

### 卡 3 · 因果

**问：为什么先放软弓小箭？**

答：**为了让对面贴上来。**

`105` 的次序：先软弓小箭 → 虏「以眾少兵弱，四面俱至」→ 托跋嵩三万骑来 → 「肉薄攻營」→ 于是百弩俱发。

弩的射程和上弦都有限，**敌人不贴到营边，弩就白摆**。软弓是诱饵。

| | |
|---|---|
| 依据 | `105`「超石先以軟弓小箭射虜，虜以眾少兵弱，四面俱至」；「遂肉薄攻營」 |
| 标记 | ◆ 出自原文 |
| 考点 | 弱，是演出来的 |

---

### 卡 4 · 因果

**问：「弩不能制」之后，他怎么还在打？**

答：**因为还有第二手。**

`106` 记超石出发时就另带了铁锤和一千多张矟，这时「斷矟長三四尺，以鎚鎚之」，一矟穿三四个人。

这是把长兵器改成短投掷物。**弩挡不住人潮，就用短矟在最近的距离打。**

| | |
|---|---|
| 依据 | `106`「別齎大鎚並千餘張矟」；「一矟輒洞貫三四虜」 |
| 标记 | ◆ 出自原文 |
| 考点 | 第二手是出发时就备好的 |

---

### 卡 5 · 人物

**问：这一仗是谁打的？**

答：**底本记了三层人。**

| 层 | 谁 | 做什么 |
|---|---|---|
| 决策 | 刘裕 | 命诸军济河，遣丁旿立阵 |
| 执行 | 丁旿 | 七百人拉车百乘，摆阵，竖白毦 |
| 接战 | 朱超石 | 二千人、大弩百张、断矟 |

刘裕在这一篇里没有亲自动手。**他做的是调度。**

| | |
|---|---|
| 依据 | `103`「高祖乃遣白直隊主丁旿」；`104`「高祖先命超石」 |
| 标记 | ◆ 出自原文 |
| 考点 | 主帅的位置在「遣」字上 |

---

### 卡 6 · 因果 ★

**问：长安已经拿下，他为什么回去？**

答：**因为刘穆之死了。**

`031` 只给一个原因：「公欲息駕長安，經略趙、魏，會穆之卒，乃歸。」

他留下的是：桂阳公义真为安西将军、雍州刺史，「留腹心將佐以輔之」（`031`）。**第二年，这些将佐互相杀起来**（`032`）。

| | |
|---|---|
| 依据 | `031`「會穆之卒，乃歸」；`032`「沈田子殺安西司馬王鎮惡」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一个后方的人，决定了一个王朝的边界 |

---

### 卡 7 · 细节

**问：进了长安，他先收哪三样东西？**

答：**彝器、浑仪、土圭。**

`030` 记：「公先收其彝器、渾儀、土圭之屬，獻於京師；其餘珍寶珠玉，以班賜將帥。」

三样都是礼器与仪器——**证明正统的东西**。珠宝分给将士。同段接着写「謁漢高帝陵，大會文武於未央殿」。

| | |
|---|---|
| 依据 | `030` |
| 标记 | ◆ 出自原文 |
| 考点 | 先收什么，说明他要的是什么 |

---

### 卡 8 · 陷阱

**问：这一篇的最后一句是「大败」，那这一篇算胜还是败？**

答：**两件事都在同一篇里，底本不改写。**

| 胜 | 败 |
|---|---|
| 却月阵斩阿薄干 | `032` 沈田子杀王镇恶，诸将杀王脩，关中乱 |
| 王镇恶克长安，生擒姚泓 | `032` 义真被追，大败 |
| 入长安，收彝器，谒汉陵 | `031` 刘裕东归，留儿子义真守关中 |

他打赢了黄河，守不住长安。**这一篇的结尾不是凯旋，是「乃歸」。**

| | |
|---|---|
| 依据 | `106`「臨陣斬阿薄干首」；`030`「王鎮惡剋長安」；`031`「乃歸」；`032`「大敗」 |
| 标记 | ◆ 出自原文 |
| 考点 | 胜与败写在同一篇里 |
