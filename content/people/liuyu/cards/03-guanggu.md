# 复习卡 · 故事 03 · 广固

> 原则：**问判断，不问年代。**
> 这一篇的关键不是谁兵多，是两个人怎么算对方。

---

## 故事 03 · 广固（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里有两次「赌对方的性格」，分别在哪一段？**

| 次 | 在哪 | 赌什么 | 结果 |
|---|---|---|---|
| 1 | `017` 大岘 | 鲜卑「貪」，「退惜粟苗」 | 慕容超果然没有清野 |
| 2 | `021` 姚兴 | 真能来的不会先送信 | 没有下文（`020` 的「不敢遣」是拒救南燕，另是一事） |

两次都不是赌自己强，是赌对方舍不得。

| | |
|---|---|
| 依据 | `017`「鮮卑貪，不及遠計，進利剋獲，退惜粟苗」；`021`「寧容先遣信命」；`020`「偽許之，而實憚公，不敢遣」 |
| 标记 | ◆ 出自原文 |
| 考点 | 判断的落点是对方的性格，不是兵力 |

---

### 卡 2 · 人物 ★

**问：慕容超为什么不肯割粟苗？**

答：**他自己的话是「豈有預芟苗稼，先自䠞弱邪」。**

`017` 记他的理由有两条：一是以为晋军「遠來疲勞，勢不能久」；二是不肯先把自己的庄稼割掉。把兵放进来打，是他主动选的。

**他选的是保住青州一年的收成，用战场来换。** 结果是战场摆在广固城下。

| | |
|---|---|
| 依据 | `017`「彼遠來疲勞，勢不能久」；「豈有預芟苗稼，先自䠞弱邪」 |
| 标记 | ◆ 出自原文 |
| 考点 | 他放弃的不是一策，是一整年的粮 |

---

### 卡 3 · 因果

**问：进了大岘，他为什么说「吾事濟矣」？**

答：**因为过了大岘，兵就没有退路。**

`017` 他自己的解释是「我一得入峴，則人無退心」——一旦进了隘口，全军只能往前。带着这样的人去打一个心里有贰的对手，胜负就简单了。

这不是说大岘本身有多险，是说他需要一个让部下不能回头的动作。

| | |
|---|---|
| 依据 | `017`「我一得入峴，則人無退心」；「公既入峴，舉手指天曰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 地形在这里的作用是断退路，不是挡敌人 |

---

### 卡 4 · 人物

**问：四千辆车在临朐做什么？**

答：**当墙用。**

`019` 记：车四千辆，分两翼，方轨徐行，车悉张幔，御者执矟，又以轻骑为游军。军令严肃，行伍齐整。

对面的铁骑一万余前后交至，撞在这道车墙上。**同一段后面也记了敌人的死伤：「斬其大將段暉等十餘人，其餘斬獲千計」。**

| | |
|---|---|
| 依据 | `019`「有車四千兩，分車為兩翼」；「方軌徐行，車悉張幔，御者執矟」 |
| 标记 | ◆ 出自原文 |
| 考点 | 车是墙，不是运粮的 |

---

### 卡 5 · 因果 ★

**问：城上那句「汝不得張綱，何能為也」，为什么反而成了突破口？**

答：**因为它把张纲这个人指出来了。**

刘裕接着做的事是：张纲从长安回来被申宣执送，把他升到楼车上给城里看，然后「使綱大治攻具」。

挑衅变成情报，情报变成攻具。**城里的人看见自己最巧的匠人在对面，于是「莫不失色」。**

| | |
|---|---|
| 依据 | `020`「汝不得張綱，何能為也」；「升綱於樓車，以示城內，城內莫不失色」；「使綱大治攻具」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一句话泄漏了一个人 |

---

### 卡 6 · 因果

**问：长围能围下去，靠的是什么？**

答：**粮。**

`020` 记两件事：「停江、淮轉輸，館穀於齊土」——不吃后方的转运，吃齐地的粮；「撫納降附，華戎歡悅，援才授爵，因而任之」——让本地人肯替他做事。

同段还记「河北居民荷戈負糧至者，日以千數」。

| | |
|---|---|
| 依据 | `020`「停江、淮轉輸，館穀於齊土」；「撫納降附，華戎歡悅」 |
| 标记 | ◆ 出自原文 |
| 考点 | 围城先要围住自己的粮 |

---

### 卡 7 · 陷阱

**问：他对姚兴的使者答得很硬，是不是因为看不起后秦？**

答：**不是。他后来自己说了理由：兵贵神速。**

`021` 他的原话是「夫兵貴神速，彼若審能遣救，必畏我知，寧容先遣信命」，结论是「此是其見我伐燕，內已懷懼，自張之辭耳」。

**他不是在轻视对手，是在判断这封信本身不可信。** 而 `020` 已经写着姚兴「不敢遣」。

| | |
|---|---|
| 依据 | `021`「夫兵貴神速」；「自張之辭耳」；`020`「實憚公，不敢遣」 |
| 标记 | ◆ 出自原文 |
| 考点 | 硬话背后是一条判断依据 |

---

### 卡 8 · 对照

**问：刘穆之敢怪他，说明了什么？**

答：`021` 记穆之「尤公曰」：平常事无大小都要商量，这件事该好好斟酌，怎么突然就答了；万一燕没拔下来、羌的救兵到了，怎么对付。

他答：「此是兵機，非卿所解，故不語耳。」然后把自己的判断讲完。

**一个敢当面怪主帅的幕僚，和一个愿意把理由讲回去的主帅**——这一段的重量在关系里，不在战事里。

| | |
|---|---|
| 依据 | `021`「穆之尤公曰」；「此是兵機，非卿所解，故不語耳」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「尤」是当面责备；他没换人，也没改口 |
