# 复习卡 · 故事 02 · 覆舟山

> 原则：**问动机，不问年代。**
> 目标是理解这一段的选择，不是记年表。

---

## 故事 02 · 覆舟山（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇前四段和后四段，写法的区别是什么？**

答：**前四段他在答话，后四段他在做事。**

| 段 | 事 | 动作 |
|---|---|---|
| `007` | 刘牢之问他跟不跟着走 | 答「裕當反服還京口耳」 |
| `008` | 桓谦问他禅代的事 | 答「有何不可」 |
| `008` | 桓玄当面夸他 | 不答，「高祖愈惡之」 |
| `010` | 桓玄评他 | 别人转述 |
| `011`–`014` | 打仗、进城、理政 | 全是动作 |

底本就按这个顺序写，不是后人的编排。

| | |
|---|---|
| 依据 | `007`「裕當反服還京口耳」；`008`「乘運禪代，有何不可」；`008`「高祖愈惡之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 前三段是应对，后四段是决断 |

---

### 卡 2 · 人物 ★

**问：他对桓谦说「有何不可」，为什么不是变节？**

答：**因为底本在同一句之前写了他真正的想法。**

`008` 的句子顺序是：先「高祖既志欲圖玄」，再「乃遜辭答曰」，然后才是「乘運禪代，有何不可」。

**「遜辭」是底本给他的定性**：这是敷衍的话。同一段里，答完这句话，桓谦「喜曰」，桓玄「引接慇懃」，而刘裕「愈惡之」。

| | |
|---|---|
| 依据 | `008`「高祖既志欲圖玄，乃遜辭答曰」；「高祖愈惡之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 判断一句话的性质，要看底本在它前后的用词 |

---

### 卡 3 · 因果

**问：桓玄为什么不杀他？**

答：**因为他还用得上，而且他认为来得及。**

`008` 记：有人劝桓玄早做安排，桓玄答「我方欲平蕩中原，非劉裕莫可付以大事。關、隴平定，然後當別議之耳」。

这句话里有一个前提：刘裕会等他平完中原。事实是，刘裕没有等——两个月后，他在京口起兵。

| | |
|---|---|
| 依据 | `008`「非劉裕莫可付以大事」；「關、隴平定，然後當別議之耳」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「然後當別議之」是他给自己留的时间表 |

---

### 卡 4 · 因果

**问：进覆舟山之前，他为什么把剩下的粮食丢掉？**

答：**「棄其餘糧」四个字，写的是不再回头。**

`012` 记：己未一早，义军吃完饭，「棄其餘糧」，进到覆舟山东。接着是疑兵、纵火、殊死战。

带粮是为了走，丢粮是为了不走。**当天对面有两万人，他这边的人数这一段没有记。**

| | |
|---|---|
| 依据 | `012`「己未旦，義軍食畢，棄其餘糧，進至覆舟山東」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动作的方向：他把退路处理掉了 |

---

### 卡 5 · 人物

**问：檀凭之的死，为什么被他读成好兆头？**

答：**因为相者当年说过「惟雲憑之無相」。**

`011` 记：几个同谋都该大贵，只有檀凭之没有相。刘裕与何无忌私下不解，说同舟不该有偏异。到罗落桥凭之战死，刘裕「知其事必捷」。

这是底本自己给的一条线：他相信那个预言，所以把同伴的死当成了预言的完成。

| | |
|---|---|
| 依据 | `011`「有善相者相高祖及無忌等並當大貴」；「惟雲憑之無相」；「至是而憑之戰死，高祖知其事必捷」 |
| 标记 | ◆ 出自原文 |
| 考点 | 底本记的是他的判断，不是那个预言的真假 |

---

### 卡 6 · 因果

**问：覆舟山一战，他凭什么赢？**

答：**两样东西，都不是兵。**

| 靠什么 | 原文 |
|---|---|
| 山上的假旗 | `012`「使丐士張旗幟於山上，以為疑兵」 |
| 东北风 | `012`「時東北風急，因命縱火」 |

再加一件：他自己先冲，「將士皆殊死戰」。

反过来看桓玄那边：`012` 明写他「走意已決」，船早就备在石头。**这一仗在开打前就有人准备输了。**

| | |
|---|---|
| 依据 | `012`「使丐士張旗幟於山上」；「因命縱火，煙爓張天」；「而走意已決」 |
| 标记 | ◆ 出自原文 |
| 考点 | 胜负的一半写在敌人的准备里 |

---

### 卡 7 · 陷阱 ★

**问：进城之后他做的第一件事，是安抚百姓吗？**

答：**不是。是立留台、烧神主、造新主。**

`013` 的次序是：镇石头城 → 立留台官 → 焚桓温神主于宣阳门外 → 造晋新主立于太庙 → 遣将追玄 → 百官奉迎乘舆。

前四件都是政治的：先把朝廷的架子搭起来，把桓氏的痕迹清掉，再说明这个朝廷姓晋。**百姓不在这一段的叙述里。**

| | |
|---|---|
| 依据 | `013`「立留臺官，焚桓溫神主於宣陽門外，造晉新主，立於太廟」 |
| 标记 | ◆ 出自原文 |
| 考点 | 次序本身就是表态 |

---

### 卡 8 · 对照

**问：桓玄和刘裕，在这一篇里各说过一句评价对方的话吗？**

答：**说过，而且都准。**

| 谁 | 话 | 应验在哪 |
|---|---|---|
| 桓玄 | `008`「風骨不恆，蓋人傑也」 | 两个月后京口起兵 |
| 桓玄 | `010`「劉裕足為一世之雄」 | 同 |
| 刘裕 | `007`「鎮北去必不免」 | 刘牢之自缢 |

三句话都是判断，不是记载。底本把它们都留下了。

| | |
|---|---|
| 依据 | `008`；`010`；`007`「鎮北去必不免」 |
| 标记 | ◆ 出自原文 |
| 考点 | 敌人的评价是这一篇里最硬的材料 |
