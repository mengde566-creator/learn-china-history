# 复习卡 · 故事 03 · 椎杀晋鄙

> 原则：**问动机，不问年代。**

---

## 故事 03 · 椎杀晋鄙（5 张）

---

### 卡 1 · 因果 ★

**问：兵符已经合了，晋鄙为什么还不交兵？**

答：**因为他怀疑的不是符，是「单车来代之」。**

晋鄙合符后「疑之，举手视公子」说：「今吾拥十万之众，屯于境上，国之重任，今单车来代之，何如哉？」符可以证明命令的程式，不能解释为什么只来一个人。晋鄙的怀疑是边将的职责。

| 标记 | ◆ 出自原文 |
| 考点 | 不是「抗命」，是「复请」的前一刻 |

---

### 卡 2 · 细节 ★

**问：朱亥用的是什么？为什么写「袖」？**

答：**四十斤铁椎，藏在袖中。**

「朱亥袖四十斤铁椎，椎杀晋鄙」——袖是动词，藏在袖里。椎是捶击的重器，近身才用。史书只给重量与动作，不写军中的反应。

| | |
|---|---|
| 依据 | `045` |
| 标记 | ○ 训释 |
| 考点 | 「袖」是藏，不是穿 |

---

### 卡 3 · 因果 ★

**问：夺军之后，公子为什么先下令遣返父子兄弟同军者？**

答：**为了让留下来的人能打。**

命令说：「父子俱在军中，父归；兄弟俱在军中，兄归；独子无兄弟，归养。」十万人先减员，再「得选兵八万人」。同军亲属在阵上会互相牵顾，遣返是整军的第一步。

---

### 卡 4 · 结果

**问：邯郸之围是怎么解的？**

答：**秦军解去，遂救邯郸，存赵。**

底本只写结果：「秦军解去，遂救邯郸，存赵。」没有写战况、伤亡或秦军退路。赵王与平原君迎于界，平原君负韊矢为前导。

| | |
|---|---|
| 依据 | `047`–`049` |
| 标记 | ◆ 出自原文 |
| 考点 | 结果明确，过程从简 |

---

### 卡 5 · 判断

**问：侯生的死与解围，在底本里是什么关系？**

答：**并置，不排因果。**

「公子与侯生决，至军，侯生果北乡自刭。」一句收在救赵之后。公子在邯郸成功，侯生在大梁自刎；史书没有说侯生之死换来做胜，也没有说公子知道。

| | |
|---|---|
| 依据 | `050` |
| 标记 | ○ 合理推演 |
| 考点 | 不要把两件事写成因果 |
