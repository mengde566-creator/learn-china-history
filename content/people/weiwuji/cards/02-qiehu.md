# 复习卡 · 故事 02 · 窃符

> 原则：**问动机，不问年代。**

---

## 故事 02 · 窃符（6 张）

---

### 卡 1 · 结构 ★

**问：從邯鄲被圍到侯生自剄，底本走了幾步？**

答：**六步。**

| 步 | 发生了什么 |
|---|---|
| `024`–`028` | 秦围邯郸；魏王使晋鄙救赵，又留军壁鄴 |
| `029`–`030` | 平原君使者责公子；公子请王不听 |
| `031` | 公子约车骑百餘乘，欲赴秦军 |
| `032`–`034` | 夷门辞行，侯生只说「勉之」；公子复返 |
| `035`–`038` | 侯生献窃符之计；如姬盗符 |
| `039`–`043` | 朱亥同行；侯生约以死送 |

| | |
|---|---|
| 依据 | `024`–`043` |
| 标记 | ◆ 出自原文 |
| 考点 | 兵符不是这一篇拿到的唯一东西；侯生的死约也在这一篇 |

---

### 卡 2 · 因果 ★

**问：魏王为什么「留军壁鄴」？**

答：**因为秦使者的那句话。**

秦王使使者告魏王：「吾攻赵旦暮且下，而诸侯敢救者，已拔赵，必移兵先击之。」魏王恐，使人止晋鄙，留军壁鄴，名为救赵，实持两端以观望。

| | |
|---|---|
| 依据 | `027`–`028` |
| 标记 | ◆ 出自原文 |
| 考点 | 「名为救赵，实持两端」是史书判语 |

---

### 卡 3 · 动机 ★

**问：侯生为什么在夷门只說「勉之」，不献计？**

答：**因为公子当时还没到肯听计的地步。**

公子带百餘乘要去赴秦军，是以客与赵同死，不是求策。侯生先用冷淡把他逼回来；公子复返，他才屏人献计。原文借侯生之口说：「今有难，无他端而欲赴秦军，譬若以肉投餒虎……以是知公子恨之复返也。」

| | |
|---|---|
| 依据 | `032`–`034` |
| 标记 | ◆ 出自原文 |
| 考点 | 「勉之」是试探，不是拒绝 |

---

### 卡 4 · 条件

**问：竊符的計畫為什麼能成立？**

答：**兩個條件：兵符在王臥內，如姬能進王臥內。**

侯生说「晋鄙之兵符常在王卧内，而如姬最幸，出入王卧内，力能窃之」。如姬又受过公子的恩：她父仇三年未报，公子使客斩其仇头。所以她「愿为公子死，无所辞」。

| | |
|---|---|
| 依据 | `035`–`037` |
| 标记 | ◆ 出自原文 |
| 考点 | 制度条件与私人恩义，缺一不可 |

---

### 卡 5 · 伏笔

**问：既然合了符，为什么还要朱亥同行？**

答：**因为晋鄙可以「复请」。**

侯生说：「公子即合符，而晋鄙不授公子兵而复请之，事必危矣。」符能证明命令，不能保证边将交兵；所以备一个力士，晋鄙不听就击杀。公子哭的正是「必当杀之」。

| | |
|---|---|
| 依据 | `039`–`041` |
| 标记 | ◆ 出自原文 |
| 考点 | 兵符不是万能；边将的请示权是漏洞 |

---

### 卡 6 · 判断

**问：侯生的自刎，在這一篇裡是什麼性質？**

答：**是他自己定的「送行」，也是對「士為知己者死」的兌現。**

他不能同行，便说「請數公子行日，以至晉鄙軍之日，北鄉自剄，以送公子」。公子到军之日，他果然自刭。这不是魏王或公子的命令，是他自己选的死期。

| | |
|---|---|
| 依据 | `043` |
| 标记 | ○ 合理推演 |
| 考点 | 不要写成「被逼自杀」；底本写的是自刭 |
