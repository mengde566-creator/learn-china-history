# 复习卡 · 故事 01 · 公子与看门人

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。

---

## 故事 01 · 公子与看门人（6 张）

---

### 卡 1 · 结构 ★

**问：这一篇从博局写到朱亥，一共换了几个场面？**

答：**六个，顺序就是底本的顺序。**

| 场面 | 发生了什么 |
|---|---|
| `006`–`010` | 博局：北境举烽，公子说赵王田猎 |
| `011`–`012` | 夷门：侯嬴年七十，不受厚遗 |
| `013`–`014` | 虚左：公子亲迎，侯生直上上坐 |
| `015`–`017` | 市中：侯生久立，微察公子 |
| `018`–`022` | 上坐：遍赞宾客，侯生自述用意 |
| `023` | 朱亥：侯生举荐，朱亥不谢 |

| | |
|---|---|
| 依据 | `006`–`023` |
| 标记 | ◆ 出自原文 |
| 考点 | 六个场面都在大梁；没有一场仗 |

---

### 卡 2 · 因果 ★

**问：魏王为什么「畏公子之贤能」？**

答：**因为公子比魏王更早、更准地知道邻国的事。**

北境举烽，魏王释博欲召大臣；公子说「赵王田猎耳，非为寇也」。后来传报果然是田猎。公子给出的理由是「臣之客有能深得赵王阴事者」。魏王由此畏其贤能，不敢任以国政。

| | |
|---|---|
| 依据 | `006`–`010` |
| 标记 | ◆ 出自原文 |
| 考点 | 魏王怕的不是赵寇，是公子的情报网 |

---

### 卡 3 · 细节 ★

**问：「虚左」是什么？侯生为什么「不讓」？**

答：「虚左」是空出车上左边的尊位。公子把尊位空出来，亲自去接一个看门人。侯生「摄敝衣冠，直上载公子上坐，不讓」，原文自己给了理由：「欲以观公子」。这是一场当众的试探。

| | |
|---|---|
| 依据 | `013`「虚左，自迎夷门侯生」；`014`「不讓，欲以觀公子」 |
| 标记 | ○ 训释 |
| 考点 | 「左」是尊位；「不讓」是有意，不是失礼 |

---

### 卡 4 · 动机 ★

**问：侯生为什么要在市中站那么久？**

答：**为了让市人看见公子受得起这种礼。**

侯生后来自己说破：「然嬴欲就公子之名，故久立公子车骑市中，过客以观公子，公子愈恭。市人皆以嬴为小人，而以公子为长者能下士也。」他把自己放在「小人」的位置上，换公子的「长者」之名。

| | |
|---|---|
| 依据 | `021`–`022` |
| 标记 | ◆ 出自原文 |
| 考点 | 这是设计好的试探，不是偶发失礼 |

---

### 卡 5 · 伏笔

**问：朱亥在這一篇做了什么？**

答：**只露了一面，没有行动。**

侯生在市中下车见的客人就是朱亥；侯生后来又说「臣所过屠者朱亥，此子贤者，世莫能知，故隐屠闲耳」。公子多次去请，朱亥「故不复谢」，公子觉得奇怪。他的铁椎要到第三篇才落下。

| | |
|---|---|
| 依据 | `016`、`023` |
| 标记 | ◆ 出自原文 |
| 考点 | 本篇只举荐，不行动 |

---

### 卡 6 · 判断

**问：这一篇里，公子到底做成了什么？**

答：**三件事：一套情报网、一次当众的礼、一个可用的伏笔。**

博局证明门客能递回赵王的阴事；迎侯生证明他受得起市人的围观与随从的窃骂；朱亥被举荐，成为下一场夺军的备手。没有打仗，也没有政令。

| | |
|---|---|
| 依据 | `009`、`017`、`021`–`023` |
| 标记 | ○ 合理推演 |
| 考点 | 不要把「养士」当成道德姿态，它在這些篇裡是情報與人力 |
