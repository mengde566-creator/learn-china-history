# 复习卡 · 故事 04 · 五城

> 原则：**问动机，不问年代。**

---

## 故事 04 · 五城（6 张）

---

### 卡 1 · 细节 ★

**问：「自功之色」是什麼樣的神色？**

答：**自以为有功的得意。**

赵孝成王与平原君计，以五城封公子；公子听说，「意骄矜而有自功之色」。史书明写这四个字，没有替他讳。下一段门客的谏言，正是针对这张脸。

| | |
|---|---|
| 依据 | `053` |
| 标记 | ◆ 出自原文 |
| 考点 | 救赵成功后的第一反应是得意 |

---

### 卡 2 · 因果 ★

**问：門客把這件事拆成了哪兩本賬？**

答：**對趙有功，對魏未為忠臣。**

门客说：「矫魏王令，夺晋鄙兵以救赵，于赵则有功矣，于魏则未为忠臣也。」同一件事，赵这边记功，魏这边记罪。公子「自骄而功之」，只看了前一本。

| | |
|---|---|
| 依据 | `054` |
| 标记 | ◆ 出自原文 |
| 考点 | 两本账不是后人的评价，是当时门客的话 |

---

### 卡 3 · 细节 ★

**问：趙王引公子走西階，公子為什麼從東階上？**

答：**西階是賓位，東階是主位；公子自居臣位。**

赵王「埽除自迎，执主人之礼，引公子就西阶」；公子「侧行辞让，从东阶上」，又「自言罪过，以负于魏，无功于赵」。让阶这个动作，比言语更能说明他对「有功」的态度。

| | |
|---|---|
| 依据 | `055` |
| 标记 | ○ 训释 |
| 考点 | 西宾东主；让阶是自降身份 |

---

### 卡 4 · 结果

**问：五城最後獻成了嗎？**

答：**沒有。趙王「口不忍獻五城」，只以鄗為湯沐邑。**

赵王陪酒到傍晚，因公子退让，始终不忍说出献城的话。公子竟留赵；赵以鄗为汤沐邑，魏仍以信陵的租税奉给公子。

| | |
|---|---|
| 依据 | `056`–`057` |
| 标记 | ◆ 出自原文 |
| 考点 | 大封停在半途，公子在两边都有食邑 |

---

### 卡 5 · 动机

**問：平原君為什麼譏笑公子「妄人」？**

答：**因為公子步行去訪博徒、賣漿者。**

平原君说：「始吾闻夫人弟公子天下无双，今吾闻之，乃妄从博徒卖浆者游，公子妄人耳。」他嫌的不是交游，是交游对象的身份。公子则说平原君之游「徒豪举耳，不求士也」。

| | |
|---|---|
| 依据 | `058`–`061` |
| 标记 | ◆ 出自原文 |
| 考点 | 两人对「士」的定义不同 |

---

### 卡 6 · 结果

**問：平原君免冠謝罪之後，人心回來了嗎？**

答：**沒有。門下士一半改歸公子。**

「平原君乃免冠谢，固留公子。平原君门下闻之，半去平原君归公子，天下士复往归公子，公子倾平原君客。」礼数挽回了面子，挽不回门客。
