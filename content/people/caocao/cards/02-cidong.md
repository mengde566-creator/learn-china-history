# 复习卡 · 场景 02 · 曹操刺董

> 原则：**先分清这句话出自哪本书，再问为什么。**
> 这一篇的题库有**版本题**——同一件事，两本书给了两种人。

---

## 场景 02 · 曹操刺董（12 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：董卓为什么给曹操这个官？**

答：因为**这个官是要他站到董卓那边去**。

董卓上表举他做骁骑校尉，还想跟他议事。「议事」两个字是重点——他要的不是一个挂名的下属，是一个能用的人。

**「他要一个能用的人」这一步是推的。**《武帝纪》只记了两句：「卓表太祖为骁骑校尉，欲与计事」和「太祖乃变易姓名，间行东归」——前一句是董卓给官，后一句是他走了。

曹操为什么不接，正文未展开，裴注引《魏书》已记他认为董卓终会覆败；见卡12。

| | |
|---|---|
| 依据 | `012`「卓表太祖为骁骑校尉，欲与计事」。**想要一个能用的人，是推的**：`012` 只说「欲与计事」，为什么给这个官，底本不写 |
| 标记 | ○ 合理推演 |
| 考点 | 这一问问的是**董卓要什么**。曹操不就拜的解释另见裴注引《魏书》，不要漏掉卡12的证据 |

---

### 卡 2 · 版本题 ★

**问：《武帝纪》正文、裴注与小说，怎样分别讲离开董卓？**

答：**正文记表官后东归；注引《魏书》另记不就拜；小说写屈身事董、借刀行刺。**

| 来源 | 经过 |
|---|---|
| 《武帝纪》正文 | 董卓上表举曹操为骁骑校尉，欲与计事；曹操改名换姓，走小路东归 |
| 裴注引《魏书》 | 曹操认为董卓终将覆败，于是不就拜，逃归乡里 |
| 《三国演义》第四回 | 曹操自称屈身事董是为了乘间行刺；借王允的刀，镜中被发觉，改作献刀，再借试马脱身 |

小说中的画像通缉，不是史传中牟被捕的已证实原因；史传的正文与注也不能合并称作“接没接一概不交代”。

| | |
|---|---|
| 依据 | `012`；`212`（裴注引《魏书》）；`401`–`404`、`407`、`409`（《三国演义》第四回） |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 考点 | 对照来源，不把小说当成补齐史书空白的现场 |

---

### 卡 3 · 陷阱题 ⚠️

**问：「曹操刺董」——这件事在哪本书里？**

答：**本篇持宝刀刺董的经过出自《三国演义》；《武帝纪》相应正文没有这段行刺。**

**这句话说的是本篇底本收的《武帝纪》正文**——不是《武帝纪》全书的结论。正文那一段里没有行刺这件事。裴松之注另记曹操私入张让室、被发觉后舞戟逾垣；这件事的**对象是张让，不是董卓**：

> 太祖尝私入中常侍张让室，让觉之；乃舞手戟于庭，逾垣而出。才武绝人，莫之能害。

本篇的刺董情节出自小说，不能据史传选段未载便证明曹操一生从无任何行刺行为；私入张让室的具体目的，这条注也未明说。

| | |
|---|---|
| 依据 | `205`「太祖尝私入中常侍张让室，让觉之；乃舞手戟于庭，逾垣而出」（裴松之注引孙盛《异同杂语》）——记的是闯张让室，不是董卓；本篇底本收的《武帝纪》正文里没有行刺董卓这件事 |
| 标记 | ◆ 出自原文 |
| 考点 | 篇名不等于史实，私入张让室也不直接等于已经证实的刺董或行刺目的 |

### 卡 4 · 因果

**问：演义里曹操那一刀，为什么没刺出去？**

答：**因为董卓从衣镜里看见了他。**

董卓胖，坐不久，倒下身去、脸朝里躺下。曹操拔出刀——**董卓仰面往衣镜里一看，照见背后有人拔刀**，回身就问：「孟德何为？」

曹操慌忙持刀跪下：「操有宝刀一口，献上恩相。」

**他败在一个镜子上。** 不是被谁出卖，不是走漏了风声。

| | |
|---|---|
| 依据 | `403`「不想董卓仰面看衣镜中，照见曹操在背后拔刀，急回身问曰：『孟德何为？』」；`404`「操惶遽，乃持刀跪下曰：『操有宝刀一口，献上恩相。』」（《三国演义》第四回） |
| 标记 | ◇ 出自小说《三国演义》 |
| 考点 | 这一刀败在**一面镜子**上：不是被谁出卖，也不是走漏了风声。演义给的失败原因是偶然的 |

### 卡 5 · 人物

**问：小说里，吕布出门、镜中被见与献刀，是什么次序？**

答：**董卓遣吕布取马，随后镜中发现曹操拔刀；吕布已到阁外时，曹操慌忙献刀。**

`407`记董卓让吕布挑一匹西凉好马赐给曹操。`403`记董卓从衣镜看见背后拔刀，回身喝问；`404`紧接着记吕布已牵马到阁外，曹操惶遽，持刀跪下。

不能把镜中发现删掉，只说“吕布一回来，曹操就得跪下”；也不能补写曹操听见马声、没看到董卓睁眼，或把刀举过头顶。

| | |
|---|---|
| 依据 | `407`；`403`；`404`（《三国演义》第四回） |
| 标记 | ◇ 出自小说《三国演义》 |
| 考点 | 按小说实际动作接读，不添现场细节 |

---

### 卡 6 · 经过

**问：献刀后，曹操怎样离开相府和京城？**

答：**他借试马离开相府，没有回寓所；狱卒去唤时，得到他已出东门的回报。**

董卓领他出阁看马，曹操请求试骑，牵马出相府而去。后来董卓听李儒的建议，派四个狱卒去唤他，回报说他不曾回寓、已经乘马出东门。随后才有遍行文书、画影图形的捉拿。

这些是小说的行动次序。哪一步是全程“最险”的地方，叙述没有作这种比较；也不能用这段没有追及，断言全回没有追捕。

| | |
|---|---|
| 依据 | `404` 试马出相府；`409` 去寓所唤人、回报及通缉（《三国演义》第四回） |
| 标记 | ◇ 出自小说《三国演义》 |
| 考点 | 相府脱身、出城与事后通缉分清先后 |

### 卡 7 · 史实

**问：中牟解拘，正文与注怎样记放人的经过？**

答：**正文记有人认出曹操并替他求解；注引《世语》点出求释者是功曹，向县令请求释放。**

`213` 说明功曹认为天下将乱，不宜拘押天下雄俊，因而“白令释之”。求情者和作出处置的县令不能混成一个人。

本篇这条注没有写功曹姓名，也不宜把“中牟那一夜”当作已载的具体时间：`013`、`213` 本身都没有注明昼夜。

| | |
|---|---|
| 依据 | `013`「邑中或窃识之，为请得解」；`213`「因白令释之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 求释与释放分清主体，未定昼夜不补成现场 |

### 卡 8 · 存疑题 △

**问：吕伯奢那一夜，出了什么事？**

答：**三种记载，三个方向。《武帝纪》正文一个字都不提。**

同一段注（`212`）里收着三说：

| 出处 | 经过 | 方向 |
|---|---|---|
| 《魏书》 | 伯奢不在，他的儿子与宾客「共劫太祖，取马及物」 | **自卫** |
| 《世语》 | 伯奢出行，五子备宾主之礼；曹操「自以背卓命，疑其图己，手剑夜杀八人而去」 | **起疑** |
| 孙盛《杂记》 | 「闻其食器声，以为图己，遂夜杀之」，杀完「既而凄怆曰：『甯我负人，毋人负我！』」 | **负人** |

**被动、起疑、负人——三个方向。** 死的数目也跟着说法走：「数人」或者「八人」。**这一篇不替他挑一种。**

| | |
|---|---|
| 依据 | `212`（裴松之注引《魏书》，同一段里还收着《世语》、孙盛《杂记》两说）；`012`「太祖乃变易姓名，间行东归」——**正文只有这一句，不提吕伯奢** |
| 标记 | △ 两说以上并存 |
| 考点 | 读者记得住的那一句「宁我负人」出自孙盛《杂记》的那一说（孙盛《杂记》），底本写作「甯」。三说并置，不裁 |

### 卡 9 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**年份没有——年号那句（`015`）属下一篇；月份只有 `014` 的「冬十二月」。**

底本自己给的坐标是年号加月份——「冬十二月」（`014`）和「是岁中平六年也」（`015`）；**可后一句属下一篇的范围**，是那一篇的收尾。这一篇的正文只给次序：

- 金城之叛、征他为典军校尉、灵帝崩、何进召董卓（`011`）
- 「卓未至而进见杀」——**六个字就是先后**（`012`）
- 卓到、废立、表官、变易姓名东归（`012`）
- 出关、过中牟（`013`）
- 至陈留，散家财（`014`）

**「中平六年就是 189 年」是后世的换算**，底本里没有公元纪年。所以这张卡标的是 ○ 外证，不是 ◆。

| | |
|---|---|
| 依据 | `011`–`014` 的记事次序；年号那一句在下一篇的范围里。**这几段里没有公元纪年；月份只有 `014` 的「冬十二月」** |
| 标记 | ○ 外证 |
| 考点 | 底本给次序、不给年份时，**别替它补一个坐标**。看到年份先分清：这是底本里的，还是外面加进来的 |

### 卡 10 · 衔接

**问：这一篇怎样接到《陈留起兵》？**

答：**史传中的曹操获释后到了陈留，拿出家财、招集义兵，准备讨董。**

小说的持刀行刺与史传的东归聚兵，各按自己的来源阅读。结尾接到陈留，下一篇继续读卫兹的资助、兵数与己吾起兵；不能说一支讨董军已经由相府那一刀直接变成。

| | |
|---|---|
| 依据 | `013` 中牟解拘；`014` 至陈留散家财、合义兵；`401`–`404`（小说） |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 考点 | 承接人物行动，保留来源之间的边界 |

### 卡 11 · 人物

**问：何进召外将时，裴注记曹操怎样评价？**

答：**曹操听后发笑，认为治宦官之罪只需诛元恶，不必召外将；若要尽诛，事情会泄露而败。**

这番话见裴注引《魏书》，挂在何进召董卓的记事下。正文接着记董卓未至，何进已被杀。可以接读他的预判与随后发生的事，不能把这种接读扩大为他已经预知全部后果。

| | |
|---|---|
| 依据 | `211`（裴注引《魏书》）；`011` 召董卓；`012` 何进被杀 |
| 标记 | ◆ 出自原文 |
| 考点 | 分清人物预判与后来已发生的事件 |

### 卡 12 · 开放题

**问：曹操为什么没有接受董卓的任用？正文和注怎样记？**

答：**正文记东归，裴注引《魏书》另给了不就拜的理由。**

《武帝纪》`012` 记董卓表他为骁骑校尉、欲与计事，随后他变易姓名东归。裴注引《魏书》在 `212` 则记他认为董卓终将覆败，所以不接受拜授、逃归乡里。

两层记载应分别归属。注引别书的说法可以提供一种解释，不能悄悄替代正文。

| | |
|---|---|
| 依据 | `012`；`212`「太祖以卓终必覆败，遂不就拜，逃归乡里」为裴注引《魏书》 |
| 标记 | ◆ 出自原文 |
| 考点 | 正文未展开的动机，在注引别书中有一种解释，不能扩大成史书全无记载 |
