# 复习卡 · 场景 02 · 曹操刺董

> 原则：**先分清这句话出自哪本书，再问为什么。**
> 这一篇的题库有**版本题**——同一件事，两本书给了两种人。

---

## 场景 02 · 曹操刺董（12 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：董卓为什么给曹操这个官？**

答：因为**这个官是要他站到董卓那边去**。

董卓上表举他做骁骑校尉，还想跟他议事。「议事」两个字是重点——他要的不是一个挂名的下属，是一个能用的人。

**「他要一个能用的人」这一步是推的。**《武帝纪》只记了两句：「卓表太祖为骁骑校尉，欲与计事」和「太祖乃变易姓名，间行东归」——前一句是董卓给官，后一句是他走了。

**曹操那一头——他为什么不接——本篇不回答。** 那是卡 12 问的那件事。

| | |
|---|---|
| 依据 | `012`「卓表太祖为骁骑校尉，欲与计事」。**想要一个能用的人，是推的**：`012` 只说「欲与计事」，为什么给这个官，底本不写 |
| 标记 | ○ 合理推演 |
| 考点 | 这一问问的是**董卓要什么**。曹操为什么不接，是另一个问题——史书不回答（卡 12） |

---

### 卡 2 · 版本题 ★

**问：这件事，《三国志》和《三国演义》讲得不一样。不一样在哪儿？**

答：**差在一口刀上。**

| | 《武帝纪》正文 | 《三国演义》第四回 |
|---|---|---|
| 那个官 | 董卓「表」他为骁骑校尉，欲与计事 | 一样 |
| 他接没接 | **不交代**，下一句就是他改名换姓走了 | **接了**。他自己说「近日操屈身以事卓者，实欲乘间图之耳」 |
| 那一刀 | **没有** | 借王允的七星宝刀，进相府，衣镜，献刀，跑了 |
| 事后 | 改名换姓，走小路往东走（`012`） | 吕布说破、李儒献策、差四个狱卒去唤、画影图形捉拿（`409`） |
| 落点 | 陈留，散家财，合义兵，**将以诛卓**（`014`） | 一样 |

**演义要的是一个忠臣**——他屈身事贼是为了找机会动手；**正史给的是一个自己拉起队伍的人。**

| | |
|---|---|
| 依据 | `012` `014`（《武帝纪》）；`402` `409`（《三国演义》第四回）。**《武帝纪》正文里没有行刺这件事** |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 考点 | 同一个官，两本书两种处理。要能说出**哪一句出自哪一本**，而不是只记住一个「曹操刺董」 |

### 卡 3 · 陷阱题 ⚠️

**问：「曹操刺董」——这件事在哪本书里？**

答：**在《三国演义》里。史书那边没有。**

**这句话说的是本篇底本收的《武帝纪》正文**——不是《武帝纪》全书的结论。正文那一段里没有行刺这件事。裴松之注里倒是有一件曹操行刺的事，但**闯的是宦官张让的屋子，不是董卓的**：

> 太祖尝私入中常侍张让室，让觉之；乃舞手戟于庭，逾垣而出。才武绝人，莫之能害。

**这个陷阱值得踩一次**：篇名叫「曹操刺董」，而正史里的曹操一次都没刺过。

| | |
|---|---|
| 依据 | `205`「太祖尝私入中常侍张让室，让觉之；乃舞手戟于庭，逾垣而出」（裴松之注引孙盛《异同杂语》）——记的是闯张让室，不是董卓；本篇底本收的《武帝纪》正文里没有行刺董卓这件事 |
| 标记 | ◆ 出自原文 |
| 考点 | 篇名不等于史实。「曹操刺董」是小说给的名字——正史里的曹操，一次都没刺过 |

### 卡 4 · 因果

**问：演义里曹操那一刀，为什么没刺出去？**

答：**因为董卓从衣镜里看见了他。**

董卓胖，坐不久，倒下身去、脸朝里躺下。曹操拔出刀——**董卓仰面往衣镜里一看，照见背后有人拔刀**，回身就问：「孟德何为？」

曹操跪下，把刀举过头顶：「操有宝刀一口，献上恩相。」

**他败在一个镜子上。** 不是被谁出卖，不是走漏了风声。

| | |
|---|---|
| 依据 | `403`「不想董卓仰面看衣镜中，照见曹操在背后拔刀，急回身问曰：『孟德何为？』」；`404`「操惶遽，乃持刀跪下曰：『操有宝刀一口，献上恩相。』」（《三国演义》第四回） |
| 标记 | ◇ 出自小说《三国演义》 |
| 考点 | 这一刀败在**一面镜子**上：不是被谁出卖，也不是走漏了风声。演义给的失败原因是偶然的 |

### 卡 5 · 人物

**问：那天董卓为什么让吕布出去？这一走，改变了什么？**

答：**董卓让他去挑一匹西凉来的好马，赐给曹操。**

吕布一走，屋里只剩董卓和曹操两个人——**这正是曹操要的**。

但吕布回来得也快：`404`「时吕布已牵马至阁外」，曹操正是听见、看见他到了，才「惶遽」跪下献刀。后来也是吕布先说破：`409`「适来曹操似有行刺之状，及被喝破，故推献刀。」

**吕布不在场的这一小会儿，是这一篇全部的戏剧空间。**

| | |
|---|---|
| 依据 | `407`「卓顾谓布曰：『吾有西凉进来好马，奉先可亲去拣一骑赐与孟德。』布领令而去」；`409`「布对卓曰：『适来曹操似有行刺之状，及被喝破，故推献刀。』」（《三国演义》第四回） |
| 标记 | ◇ 出自小说《三国演义》 |
| 考点 | 戏在**吕布出去又回来**这一小会儿里：他一走，屋里只剩两个人；他一回来，曹操就得跪下去 |

### 卡 6 · 人物

**问：他真正脱身的地方，是相府还是别处？**

答：**是别处——他出了东门，没有回寓所。**

吕布说破之后，董卓说「吾亦疑之」。李儒献策：曹操没有妻小在京，一个人住寓所；差人去唤，肯来就是献刀，推托不来就是行刺。

董卓差四个狱卒去唤。去了良久，回报：「操不曾回寓，乘马飞出东门。」门吏问他，他丢下一句「丞相差我有紧急公事」。

**四个狱卒，不是追兵。** 收口是一张画像：`409`「卓遂令遍行文书，画影图形，捉拿曹操」。**这一回里没有人追上他。**

| | |
|---|---|
| 依据 | `409`「即差狱卒四人往唤操」「操不曾回寓，乘马飞出东门」「卓遂令遍行文书，画影图形，捉拿曹操：擒献者，赏千金，封万户侯；窝藏者同罪」（《三国演义》第四回）。**去的是狱卒，演义里没有人追他** |
| 标记 | ◇ 出自小说《三国演义》 |
| 考点 | 最险的一处不在相府，在**出了东门、没有回寓所**这一步。演义把追捕写成了文书和画像，不是追兵 |

### 卡 7 · 史实

**问：中牟那一夜，是谁放了他？他为什么要放？**

答：**中牟县的功曹。**

正文只有一句：「出关，过中牟，为亭长所疑，执诣县，邑中或窃识之，为请得解」——**「或」是不定的人**，没说谁。

注里那一句点出了职位和理由：

> 中牟疑是亡人，见拘于县。时掾亦已被卓书；唯功曹心知是太祖，以世方乱，不宜拘天下雄俊，因白令释之。

**他放人的理由是当着县令说的**（「因白令释之」）：天下正乱，不该拘押天下的雄俊。他心里还有没有别的缘故，这一段不写。**放他的不是恩典，是天下的乱。**

| | |
|---|---|
| 依据 | `013`「邑中或窃识之，为请得解」；`213`「唯功曹心知是太祖，以世方乱，不宜拘天下雄俊，因白令释之」（裴松之注引《世语》）。**功曹叫什么名字，这几段里没有** |
| 标记 | ◆ 出自原文 |
| 考点 | 正文的「或」和注里的「功曹」是一件事的两层：正文不点名，注里点名还给理由。**出面求情的，只有他一个**（`205` 里桥玄也替曹操说过话，那是另一回事） |

### 卡 8 · 存疑题 △

**问：吕伯奢那一夜，出了什么事？**

答：**三种记载，三个方向。《武帝纪》正文一个字都不提。**

同一段注（`212`）里收着三说：

| 出处 | 经过 | 方向 |
|---|---|---|
| 《魏书》 | 伯奢不在，他的儿子与宾客「共劫太祖，取马及物」 | **自卫** |
| 《世语》 | 伯奢出行，五子备宾主之礼；曹操「自以背卓命，疑其图己，手剑夜杀八人而去」 | **起疑** |
| 孙盛《杂记》 | 「闻其食器声，以为图己，遂夜杀之」，杀完「既而凄怆曰：『甯我负人，毋人负我！』」 | **负人** |

**被动、起疑、负人——三个方向。** 死的数目也跟着说法走：「数人」或者「八人」。**这一篇不替他挑一种。**

| | |
|---|---|
| 依据 | `212`（裴松之注引《魏书》，同一段里还收着《世语》、孙盛《杂记》两说）；`012`「太祖乃变易姓名，间行东归」——**正文只有这一句，不提吕伯奢** |
| 标记 | △ 两说以上并存 |
| 考点 | 读者记得住的那一句「宁我负人」出自**最晚出、最像小说的那一说**（孙盛《杂记》），底本写作「甯」。三说并置，不裁 |

### 卡 9 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**年份没有——年号那句（`015`）属下一篇；月份只有 `014` 的「冬十二月」。**

底本自己给的坐标是年号加月份——「冬十二月」（`014`）和「是岁中平六年也」（`015`）；**可后一句属下一篇的范围**，是那一篇的收尾。这一篇的正文只给次序：

- 金城之叛、征他为典军校尉、灵帝崩、何进召董卓（`011`）
- 「卓未至而进见杀」——**六个字就是先后**（`012`）
- 卓到、废立、表官、变易姓名东归（`012`）
- 出关、过中牟（`013`）
- 至陈留，散家财（`014`）

**「中平六年就是 189 年」是后世的换算**，底本里没有公元纪年。所以这张卡标的是 ○ 外证，不是 ◆。

| | |
|---|---|
| 依据 | `011`–`014` 的记事次序；年号那一句在下一篇的范围里。**这几段里没有公元纪年；月份只有 `014` 的「冬十二月」** |
| 标记 | ○ 外证 |
| 考点 | 底本给次序、不给年份时，**别替它补一个坐标**。看到年份先分清：这是底本里的，还是外面加进来的 |

### 卡 10 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**篇名问的是「他刺了吗」，史书给的答案不是刀，是兵。**

演义给了他一把刀，让他进了相府、看见了衣镜、跪下去献刀；史书给的是另一条路——只记他改名换姓，往东走，然后在陈留散尽家财，聚起一支兵：「将以诛卓」。

**两条路最后落在同一件事上。**

| | |
|---|---|
| 依据 | `014`「太祖至陈留，散家财，合义兵，将以诛卓」；`401`–`404`（《三国演义》第四回） |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 考点 | 篇名问的是刀，两本书的答案最后都落在**兵**上——同一个落点，两条路 |

### 卡 11 · 人物

**问：开篇有一个人比他先说话，说的是他会败。他是谁，凭什么？**

答：**曹操自己。他笑的是何进召外兵那一步。**

裴松之把《魏书》这一条注挂在 `011`「进乃召董卓，欲以胁太后」下面：

> 太祖闻而笑之曰：「阉竖之官，古今宜有，但世主不当假之权宠，使至于此。既治其罪，当诛元恶，一狱吏足矣，何必纷纷召外将乎？欲尽诛之，事必宣露，吾见其败也。」

**「一狱吏足矣」是办法，「吾见其败也」是判断**——两句都说在董卓进门之前。下一句就是「卓未至而进见杀」：**何进死在召来的人进门之前。**

| | |
|---|---|
| 依据 | `211`（裴松之注引《魏书》）；`011`「进乃召董卓，欲以胁太后」；`012`「卓未至而进见杀」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的开头不是洛阳，是**一次决策**。董卓的兵是何进自己召来的——曹操笑的就是这一步，而他是对的 |

### 卡 12 · 开放题

**问：你觉得他为什么不接那个官？**

答：**史书不回答这个问题。**

《武帝纪》只记他走了，不记他为什么走（`012` 两句相邻，中间没有交代）。演义替他答了——说他接下这个官，就是为了靠近董卓（`402`）。**但那是一本十四世纪的小说的答案。**

**这一篇把这个问题留在「—」里，是有意的**：不是产品不知道，是**史书不知道**——而知道自己不知道什么，和知道答案一样重要。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 这一篇最重要的一个「—」：**史书不知道他为什么不接**。知道自己不知道什么，和知道答案一样重要 |
