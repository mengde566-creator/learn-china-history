# 复习卡 · 场景 01 · 曹操刺董

> 原则：**问动机，不问年代。**
> 这一篇的题库有一半是**版本题**——同一个 189 年，两本书给了两种人。

---

## 场景 01 · 曹操刺董（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：董卓给了曹操一个官，他为什么不要？**

答：因为**这个官是要他站到董卓那边去**。

董卓上表举他做骁骑校尉，还想跟他议事。「议事」两个字是重点——他要的不是一个挂名的下属，是一个能用的人。

**但「他不要」这件事，史书没有直说。**《武帝纪》只记了两句：「卓表太祖为骁骑校尉，欲与计事」和「太祖乃变易姓名，间行东归」。中间没有一句话交代他接没接、为什么走。

| | |
|---|---|
| 依据 | `002`「卓表太祖为骁骑校尉，欲与计事」；`003`「太祖乃变易姓名，间行东归」。**「不要」是这两句相邻推出来的** |
| 标记 | ○ 合理推演 |

---

### 卡 2 · 版本题 ★

**问：这件事，《三国志》和《三国演义》讲得不一样。不一样在哪儿？**

答：**差在一个「接」字。**

| | 《三国志·武帝纪》 | 《三国演义》第四回 |
|---|---|---|
| 那个官 | 董卓「表」他为骁骑校尉 | 一样 |
| 接了没有 | **不交代**，下一句就是他改名换姓走了 | **接了**。他自己说「近日操屈身以事卓者，实欲乘间图之耳」 |
| 那一刀 | **没有** | 借王允的七星宝刀，进相府，衣镜，献刀，跑了 |
| 后来 | 改名换姓，从小路往东走 | 中牟被擒，陈宫释曹，往陈留去 |
| 落点 | 陈留，散家财，合义兵，**将以诛卓** | 一样 |

**演义要的是一个忠臣**（他后来对陈宫说「吾祖宗世食汉禄，若不思报国，与禽兽何异」）；**正史给的是一个自己拉起队伍的人。**

| | |
|---|---|
| 依据 | `002` `003` `008`（《武帝纪》）；`201`–`209`（《三国演义》第四回） |
| 标记 | ◆ 出自原文 |

### 卡 3 · 陷阱题 ⚠️

**问：「曹操刺董」——这件事在哪本书里？**

答：**在《三国演义》里。史书里没有。**

《三国志·武帝纪》全文没有行刺这件事。裴松之注里倒是有一件曹操行刺的事，但**闯的是宦官张让的屋子，不是董卓的**：

> 太祖尝私入中常侍张让室，让觉之；乃舞手戟于庭，逾垣而出。才武绝人，莫之能害。

而真有其人、行刺董卓未遂被杀的，是**伍孚**——不是曹操。

**这个陷阱值得踩一次**：篇名叫「曹操刺董」，而史书里他一次都没刺过。

| | |
|---|---|
| 依据 | 《武帝纪》《裴注》均无行刺董卓事；`101`（裴注引孙盛《异同杂语》）记的是闯张让室 |
| 标记 | ◆ 出自原文 |

### 卡 4 · 因果

**问：演义里曹操那一刀，为什么没刺出去？**

答：**因为董卓在镜子里看见了他。**

董卓胖，坐不久，倒下身去、脸朝里躺下。曹操拔出刀——**董卓仰面往衣镜里一看，照见背后有人拔刀**，回身就问：「孟德何为？」

曹操跪下，把刀举过头顶：「操有宝刀一口，献上恩相。」

**他败在一个镜子上。** 不是被谁出卖，不是走漏了风声。

| | |
|---|---|
| 依据 | `203`「不想董卓仰面看衣镜中，照见曹操在背后拔刀，急回身问曰：『孟德何为？』」；`204`「操惶遽，乃持刀跪下曰：『操有宝刀一口，献上恩相。』」 |
| 标记 | ◇ 出自小说 |

### 卡 5 · 人物

**问：那天董卓为什么让吕布出去？这一走，改变了什么？**

答：**董卓让他去挑一匹西凉来的好马，赐给曹操。**

吕布一走，屋里只剩董卓和曹操两个人——**这正是曹操要的**。

但吕布回来得也快：「时吕布已牵马至阁外」，曹操正是听见/看见他到了，才「惶遽」跪下献刀。后来也是吕布先说破：「适来曹操似有行刺之状，及被喝破，故推献刀。」

**吕布不在场的这一小会儿，是这一篇全部的戏剧空间。**

### 卡 6 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**篇名问的是「他刺了吗」，史书给的答案不是刀，是兵。**

演义给了他一把刀，让他进了相府、看见了衣镜、跪下去献刀；史书里他没接那个官，改名换姓往东走，然后在陈留散尽家财，聚起一支兵——「将以诛卓」。

**两条路最后落在同一件事上。**

|---|---|
| 依据 | `008`「太祖至陈留，散家财，合义兵，将以诛卓」；`201`–`209`（《三国演义》第四回） |
| 标记 | ◆ 出自原文 |

### 卡 7 · 时间线

**问：从董卓进洛阳，到曹操在陈留起兵，中间隔了多久？**

答：**不到一年。**

- 189 年，董卓进洛阳，废少帝、立献帝
- 同一年，董卓表曹操为骁骑校尉
- 同一年，曹操改名换姓，从小路往东走
- 陈留起兵在**这一年的十二月**——「冬十二月，始起兵于己吾，**是岁中平六年也**」

底本自己给了年号：中平六年，就是 189 年。

### 卡 8 · 开放题

**问：你觉得他为什么不接那个官？**

答：**史书不回答这个问题。**

《武帝纪》只记他走了，不记他为什么走。演义替他答了——说他接下这个官，就是为了靠近董卓（`202`）。**但那是一本十四世纪的小说的答案。**

**这一篇把这个问题留在「—」里，是有意的**：不是产品不知道，是**史书不知道**——而知道自己不知道什么，和知道答案一样重要。
