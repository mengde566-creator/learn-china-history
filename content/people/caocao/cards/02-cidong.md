# 复习卡 · 场景 02 · 曹操刺董

> 原则：**先分清这句话出自哪本书，再问为什么。**
> 这一篇的题库有一半是**版本题**——同一件事，两本书给了两种人。

---

## 场景 02 · 曹操刺董（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：董卓为什么给曹操这个官？**

答：因为**这个官是要他站到董卓那边去**。

董卓上表举他做骁骑校尉，还想跟他议事。「议事」两个字是重点——他要的不是一个挂名的下属，是一个能用的人。

**「他要一个能用的人」这一步是推的。**《武帝纪》只记了两句：「卓表太祖为骁骑校尉，欲与计事」和「太祖乃变易姓名，间行东归」——前一句是董卓给官，后一句是他走了。

**曹操那一头——他为什么不接——本篇不回答。** 那是卡 8 问的那件事。

| | |
|---|---|
| 依据 | `002`「卓表太祖为骁骑校尉，欲与计事」。**想要一个能用的人，是推的**：`002` 只说「欲与计事」，为什么给这个官，底本不写 |
| 标记 | ○ 合理推演 |
| 考点 | 这一问问的是**董卓要什么**。曹操为什么不接，是另一个问题——史书不回答（卡 8） |

---

### 卡 2 · 版本题 ★

**问：这件事，《三国志》和《三国演义》讲得不一样。不一样在哪儿？**

答：**差在一个「接」字。**

| | 《三国志·武帝纪》 | 《三国演义》第四回 |
|---|---|---|
| 那个官 | 董卓「表」他为骁骑校尉 | 一样 |
| 接了没有 | **不交代**，下一句就是他改名换姓走了 | **接了**。他自己说「近日操屈身以事卓者，实欲乘间图之耳」 |
| 那一刀 | **没有** | 借王允的七星宝刀，进相府，衣镜，献刀，跑了 |
| 后来 | 改名换姓，从小路往东走 | 中牟被擒，陈宫释曹，往陈留去（《三国演义》第四回后半，不在本篇这几段里） |
| 落点 | 陈留，散家财，合义兵，**将以诛卓** | 一样 |

**演义要的是一个忠臣**——他在中牟对陈宫说，祖宗世食汉禄，不思报国与禽兽无异（这一句在《三国演义》第四回中牟那一段，不在本篇这几段里）；**正史给的是一个自己拉起队伍的人。**

| | |
|---|---|
| 依据 | `002` `003` `008`（《武帝纪》）；`201`–`209`（《三国演义》第四回） |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 考点 | 同一个官，两本书两种处理。要能说出**哪一句出自哪一本**，而不是只记住一个「曹操刺董」 |

### 卡 3 · 陷阱题 ⚠️

**问：「曹操刺董」——这件事在哪本书里？**

答：**在《三国演义》里。史书那边没有。**

**这句话说的是本篇底本收的《武帝纪》正文**——不是《武帝纪》全书的结论。这一段里没有行刺这件事。裴松之注里倒是有一件曹操行刺的事，但**闯的是宦官张让的屋子，不是董卓的**：

> 太祖尝私入中常侍张让室，让觉之；乃舞手戟于庭，逾垣而出。才武绝人，莫之能害。

**这个陷阱值得踩一次**：篇名叫「曹操刺董」，而本篇底本里他一次都没刺过。

| | |
|---|---|
| 依据 | `101`「太祖尝私入中常侍张让室，让觉之；乃舞手戟于庭，逾垣而出」——记的是闯张让室，不是董卓；本篇底本收的《武帝纪》正文里没有行刺董卓这件事 |
| 标记 | ◆ 出自原文 |
| 考点 | 篇名不等于史实。「曹操刺董」是小说给的名字——这一篇底本里的曹操，一次都没刺过 |

### 卡 4 · 因果

**问：演义里曹操那一刀，为什么没刺出去？**

答：**因为董卓在镜子里看见了他。**

董卓胖，坐不久，倒下身去、脸朝里躺下。曹操拔出刀——**董卓仰面往衣镜里一看，照见背后有人拔刀**，回身就问：「孟德何为？」

曹操跪下，把刀举过头顶：「操有宝刀一口，献上恩相。」

**他败在一个镜子上。** 不是被谁出卖，不是走漏了风声。

| | |
|---|---|
| 依据 | `203`「不想董卓仰面看衣镜中，照见曹操在背后拔刀，急回身问曰：『孟德何为？』」；`204`「操惶遽，乃持刀跪下曰：『操有宝刀一口，献上恩相。』」 |
| 标记 | ◇ 出自小说《三国演义》 |
| 考点 | 这一刀败在**一面镜子**上：不是被谁出卖，也不是走漏了风声。演义给的失败原因是偶然的 |

### 卡 5 · 人物

**问：那天董卓为什么让吕布出去？这一走，改变了什么？**

答：**董卓让他去挑一匹西凉来的好马，赐给曹操。**

吕布一走，屋里只剩董卓和曹操两个人——**这正是曹操要的**。

但吕布回来得也快：`204`「时吕布已牵马至阁外」，曹操正是听见/看见他到了，才「惶遽」跪下献刀。后来也是吕布先说破：`209`「适来曹操似有行刺之状，及被喝破，故推献刀。」

**吕布不在场的这一小会儿，是这一篇全部的戏剧空间。**

| | |
|---|---|
| 依据 | `207`「卓顾谓布曰：『吾有西凉进来好马，奉先可亲去拣一骑赐与孟德。』布领令而去」；`209`「布对卓曰：『适来曹操似有行刺之状，及被喝破，故推献刀。』」 |
| 标记 | ◇ 出自小说《三国演义》 |
| 考点 | 戏在**吕布出去又回来**这一小会儿里：他一走，屋里只剩两个人；他一回来，曹操就得跪下去 |

### 卡 6 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**篇名问的是「他刺了吗」，史书给的答案不是刀，是兵。**

演义给了他一把刀，让他进了相府、看见了衣镜、跪下去献刀；史书给的是另一条路——只记他改名换姓，往东走，然后在陈留散尽家财，聚起一支兵：「将以诛卓」。

**两条路最后落在同一件事上。**

| | |
|---|---|
| 依据 | `008`「太祖至陈留，散家财，合义兵，将以诛卓」；`201`–`209`（《三国演义》第四回） |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 考点 | 篇名问的是刀，两本书的答案最后都落在**兵**上——同一个落点，两条路 |

### 卡 7 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**只有一个：中平六年十二月。**

底本自己给的坐标，是年号加月份——「冬十二月，始起兵于己吾，是岁中平六年也」。

- 中平六年，董卓进洛阳，废少帝、立献帝
- 同一年，董卓表曹操为骁骑校尉
- 同一年，曹操改名换姓，从小路往东走
- 十二月，他在陈留起兵

**「中平六年，就是 189 年」这一步是后世的换算**，底本里没有公元纪年。所以这一张卡标的是 ○ 外证，不是 ◆。

| | |
|---|---|
| 依据 | `008`「冬十二月，始起兵于己吾，是岁中平六年也」。**年号换公元是后世系年，底本无公元纪年**；前面那三行由 `001` `002` `003` 的记事与 `008` 的年号排出来 |
| 标记 | ○ 外证 |
| 考点 | 底本只给**年号和月份**；公元年是后世的换算。看到年份先分清：这是底本里的，还是外面加进来的坐标 |

### 卡 8 · 开放题

**问：你觉得他为什么不接那个官？**

答：**史书不回答这个问题。**

《武帝纪》只记他走了，不记他为什么走。演义替他答了——说他接下这个官，就是为了靠近董卓（`202`）。**但那是一本十四世纪的小说的答案。**

**这一篇把这个问题留在「—」里，是有意的**：不是产品不知道，是**史书不知道**——而知道自己不知道什么，和知道答案一样重要。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 这一篇最重要的一个「—」：**史书不知道他为什么不接**。知道自己不知道什么，和知道答案一样重要 |
