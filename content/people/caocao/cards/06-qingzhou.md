# 复习卡 · 场景 06 · 青州兵

> 原则：**先把两个数分开，再问那个名号。**
> 这一篇只有一段原文，连标点不到四十个字——**这一段里没有一句对话，也没有一场仗。**

---

## 场景 06 · 青州兵（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 数字题 ★

**问：这一篇给了两个数：三十余万，百余万口。这是一笔人吗？**

答：**不是一笔。一个是卒，一个是男女。**

`027` 把受降的人数写成两笔：先「受降卒三十余万」，再「男女百余万口」。

一个数的是兵（卒），一个数的是人（男女）。**这一段从来没有把这两个数加在一起**，也没有给过第三个合计数。

读者最容易做的一件事，就是把它们并成一个大数——那是我们自己加的。

| | |
|---|---|
| 依据 | `027`「受降卒三十余万，男女百余万口」——**两笔：一笔是卒，一笔是男女** |
| 标记 | ◆ 出自原文 |
| 考点 | 记住两个词：**卒**和**口**。两个数各自算各自的，底本没有合计数 |

---

### 卡 2 · 名字题 ★

**问：「青州兵」这个名字，是这批人自己叫起来的吗？**

答：**不是。名号是收编的人给的。**

`027` 的收尾是：「收其精锐者，号为青州兵。」**「号为」两个字，是别人给的名号**——这一段里没有一句他们自称的话，也没有一句他们说的话。

更要紧的是那个「青州」。这伙人是从青州来的，可**本篇没有一句话直说青州兵就是这批青州黄巾编成的**。那一层是把两篇的原文并起来读出来的：上一篇（见 `05-yanzhou`）管他们叫青州黄巾，这一篇给收编之后的号是青州兵。

| | |
|---|---|
| 依据 | `027`「收其精锐者，号为青州兵」；**"青州"这个来路见 `05-yanzhou`——那一篇的原文里写作青州黄巾**；两处都没有"青州兵就是这批青州黄巾编成的"这句话 |
| 标记 | ○ 合理推演 |
| 考点 | 名号是给的，来路是拼的。**这一段给出的是「号为」两个字，不是一支队伍的来历** |

---

### 卡 3 · 陷阱题 ⚠️

**问：「受降卒三十余万」——这三十多万人是被杀了吗？**

答：**不是。那个字是「受」。**

`027` 的四个字是「受降卒」——**受是接受**。这一段里没有交战，也没有一个杀字：追、乞降、受降、收编，四步全是记事。

**这个陷阱值得踩一次**：一个「降」字挨着两个大数目，最容易读成一场屠杀；而这一段里最狠的动词，只是那个「收」。

| | |
|---|---|
| 依据 | `027`「受降卒三十余万」「收其精锐者」——**「受」是接受，「收」是收编；这一段里没有一个杀字** |
| 标记 | ◆ 出自原文 |
| 考点 | 「受」不是「杀」。**读数字之前先读动词** |

---

### 卡 4 · 人物

**问：这一段里，曹操一共做了几个动作？**

答：**四个：追、受、收、号。**

`027` 里他这一头的动词，按次序是：「追黄巾至济北」的追、「受降卒三十余万」的受、「收其精锐者」的收、「号为青州兵」的号。

对面只有一个动作：「乞降」。

**两个人没有说过一句话，事情却走完了。**

| | |
|---|---|
| 依据 | `027`「追黄巾至济北」「受降卒三十余万」「收其精锐者，号为青州兵」——**四个动词都是他这一头的，对面只有「乞降」** |
| 标记 | ◆ 出自原文 |
| 考点 | 四个动作一个方向：**追 → 受 → 收 → 号**。这一篇的骨架就是这四个字 |

---

### 卡 5 · 因果

**问：他们为什么会在济北降？**

答：**因为他是追到济北的。**

`027` 的两句紧挨着：「追黄巾至济北。」「乞降。」——**先追，后降**，中间没有一个字。

顺序是清楚的：他追到哪儿，他们在哪儿降。**至于他们为什么肯降，这一段不回答**——那一步是这一篇最大的空白，见卡 8。

| | |
|---|---|
| 依据 | `027`「追黄巾至济北。乞降。」——**"因为"这一步是推的**：`027` 只把追和降排在一起，不写他们为什么降 |
| 标记 | ○ 合理推演 |
| 考点 | 次序在这一段里，原因不在这里。**先追后降是原文给的，为什么降是原文不肯给的** |

---

### 卡 6 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**一个：冬。**

`027` 全段只有一个时令字——「冬，受降卒三十余万」。**前面没有年，后面没有月。**

「公元 192 年」和「初平三年」都是后人排出来的坐标，不在这一段里。这一类数字标「○ 外证」：它不是这一段里的字，是外面加进来的。

| | |
|---|---|
| 依据 | `027` 只有「冬」一个时令字，全段无年号、无公元纪年。**公元 192 年（初平三年）是后世系年，属外证** |
| 标记 | ○ 外证 |
| 考点 | 时间只有一个字。**受降落在冬天，此外的长度一律不知道** |

---

### 卡 7 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**挑出能打的，给一个名号——这一篇就收在这一句上。**

`027` 的落点是「收其精锐者，号为青州兵」：从三十多万降卒里挑出精锐，给这批人一个号。

前面那两句交代人是怎么来的、有多少；最后这一句交代他们从此刻起叫什么。

**一场没有仗的收编，收在一个名号上。**

| | |
|---|---|
| 依据 | `027`「收其精锐者，号为青州兵」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的转折不是一场胜仗，是**一个名号**；从此以后他们叫青州兵 |

---

### 卡 8 · 开放题 ★

**问：他们为什么肯降？**

答：**这一段不回答。**

`027` 只有「乞降」两个字：谁先提的、为什么提、提之前发生过什么，一个字都没有。

**这是这一篇最要紧的一处沉默**，也是读者最想问的一句。产品能给的只有那两个字，和它们前面的那个「追」。

把它留在「—」里是有意的：不是没有答案，是**这一段没有答案**。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 三十多万人放下兵器的那一刻，史书只留下两个字。**知道自己不知道什么，和知道答案一样重要** |

### 这一篇的难点

**这一段里，没有一个人说过话。** `027` 全是记事的字：追、乞降、受降、收编、给名号。

所以这一篇的卡只问三件事：**那两个数是不是一笔**、**那个名号是谁给的**、**哪一处是这一段不肯写的**。
