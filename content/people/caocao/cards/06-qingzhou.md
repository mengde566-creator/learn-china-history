# 复习卡 · 场景 06 · 青州兵

> 原则：**先把两个数分开，再问那个名号，最后看它两年后是什么成色。**
> 这一篇用四段原文：`025`–`027`、`029`。**受降那一段里没有一句对话，也没有一场仗**；
> 补进来的三段的记事同样密——刘岱的死是一句话，寿张那一仗是九个字。

---

## 场景 06 · 青州兵（11 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 数字题 ★

**问：这一篇给了两个数：三十余万，百余万口。这是一笔人吗？**

答：**不是一笔。一个是卒，一个是男女。**

`027` 把受降的人数写成两笔：先「受降卒三十余万」，再「男女百余万口」。

一个数的是兵（卒），一个数的是人（男女）。**`027` 从来没有把这两个数加在一起**，也没有给过第三个合计数。

读者最容易做的一件事，就是把它们并成一个大数——那是我们自己加的。

| | |
|---|---|
| 依据 | `027`「受降卒三十余万，男女百余万口」——**两笔：一笔是卒，一笔是男女** |
| 标记 | ◆ 出自原文 |
| 考点 | 记住两个词：**卒**和**口**。两个数各自算各自的，底本没有合计数 |

---

### 卡 2 · 名字题 ★

**问：「青州兵」这个名字，是这批人自己叫起来的吗？**

答：**不是。名号是收编的人给的。**

`027` 的收尾是：「收其精锐者，号为青州兵。」**「号为」两个字，是别人给的名号**——这一段里没有一句他们自称的话，也没有一句他们说的话。

更要紧的是那个「青州」。这伙人是从青州来的（`025` 管他们叫「青州黄巾」），而 `027` 给收编之后的号是「青州兵」。**两处都落在「青州」两个字上，可底本没有一句话直说青州兵就是这批青州黄巾编成的。**

| | |
|---|---|
| 依据 | `027`「收其精锐者，号为青州兵」；`025`「青州黄巾众百万入兖州」——**两段都没有"青州兵就是这批青州黄巾编成的"这句话** |
| 标记 | ○ 合理推演 |
| 考点 | 名号是给的，来路是拼的。**`027` 给出的是「号为」两个字，不是一支队伍的来历** |

---

### 卡 3 · 陷阱题 ⚠️

**问：「受降卒三十余万」——这三十多万人是被杀了吗？**

答：**不是。那个字是「受」。**

`027` 的四个字是「受降卒」——**受是接受**。受降那一段里没有交战，也没有一个杀字：追、乞降、受降、收编，四步全是记事。

**这个陷阱值得踩一次**：一个「降」字挨着两个大数目，最容易读成一场屠杀；而这一段里最狠的动词，只是那个「收」。

| | |
|---|---|
| 依据 | `027`「受降卒三十余万」「收其精锐者」——**「受」是接受，「收」是收编；受降那一段里没有一个杀字** |
| 标记 | ◆ 出自原文 |
| 考点 | 「受」不是「杀」。**读数字之前先读动词** |

---

### 卡 4 · 人物

**问：劝刘岱不要打这支队伍的人，后来怎么样了？**

答：**他死在打这支队伍的路上。**

`025` 里他劝刘岱：这支队伍「军无辎重，唯以钞略为资」，撑不久，「后选精锐，据其要害，击之可破也」。刘岱不听，出去打，果然被杀。

`026` 里他和州吏万潜等人到东郡迎曹操；曹操进兵寿张东，**「信力战斗死，仅而破之」**——他力战死在那一仗里。

| | |
|---|---|
| 依据 | `025`「鲍信谏曰」「岱不从，遂与战，果为所杀」；`026`「信力战斗死，仅而破之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一段谏词、一场战死：**劝人别打的人，最后死在打这一仗上** |

---

### 卡 5 · 因果

**问：他们为什么会在济北降？**

答：**因为他是追到济北的。**

`027` 的两句紧挨着：「追黄巾至济北。」「乞降。」——**先追，后降**，中间没有一个字。

顺序是清楚的：他追到哪儿，他们在哪儿降。**至于他们为什么肯降，`027` 不写**——那一步是这一篇最大的空白，见卡 8。

| | |
|---|---|
| 依据 | `027`「追黄巾至济北。乞降。」——**"因为"这一步是推的**：`027` 只把追和降排在一起，不写他们为什么降 |
| 标记 | ○ 合理推演 |
| 考点 | 次序在这一段里，原因不在这里。**先追后降写在 `027` 里；为什么降，`027` 一个字不写** |

---

### 卡 6 · 时间线

**问：这一篇的时间落在哪儿？**

答：**一个「冬」，和一个更晚的年份。**

受降那一段（`027`）只有一个时令字：「冬，受降卒三十余万」。**前面没有年，后面没有月。**

这一篇往后还有一站：`029` 的濮阳，在底本里排在受降之后。**两个年份（192 年、194 年）都是后人排出来的坐标**，这几段里一个都没有。这一类数字标 **○ 外证**。

（`025` 开头那个「夏四月」是朝廷里那件事的时间——王允和吕布杀董卓——不是这支队伍的。）

| | |
|---|---|
| 依据 | `027`「冬」；`029` 的记事在底本里排在 `027` 之后。**公元 192 年、194 年都是后世系年，属外证** |
| 标记 | ○ 外证 |
| 考点 | 底本给的只有一个「冬」；**往后那一站隔了两年，是排出来的** |

---

### 卡 7 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**收下三十多万，给一个名号；后来这个名号在濮阳一冲就散。**

`027` 的落点是「收其精锐者，号为青州兵」：从降卒里挑出精锐，给这批人一个号。

`029` 是它的下一幕：吕布的骑兵「先以骑犯青州兵。青州兵奔」——**曹操的阵跟着乱，他坠马烧手**。

**一场收编收在一个名号上，而这个名号的分量，要看两年后那一仗。**

| | |
|---|---|
| 依据 | `027`「收其精锐者，号为青州兵」；`029`「先以骑犯青州兵。青州兵奔」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇落在一个名号上，**名号的成色在两年后那一仗里** |

---

### 卡 8 · 开放题 ★

**问：他们为什么肯降？**

答：**`027` 不回答。**

那里只有两个字：「乞降」。谁先提的、为什么提、提之前发生过什么，一个字都没有。

**这是这一篇最要紧的一处沉默。** 能给的只有那两个字，和它们前面的那个「追」（`027`）——还有 `026` 里那一仗：寿张东，曹操「仅而破之」，鲍信死在那里。**打得勉强，降得爽快，中间那一步，这几段不写。**

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 三十多万人放下兵器的那一刻，史书只留下两个字。**知道自己不知道什么，和知道答案一样重要** |

---

### 卡 9 · 对照题

**问：鲍信说这支队伍「可破」，也说刘岱「不可敌」——这两句矛盾吗？**

答：**不矛盾：一句说现在，一句说以后。**

`025` 里他的原话次序分明：**现在**「不可敌也」（贼众百万、百姓震恐、士卒无斗志），**以后**「其势必离散，后选精锐，据其要害，击之可破也」——先固守，等他们散，再挑精锐去打。

**两个人的处置可以比，但不要接成一条计策。** 刘岱不听劝，出去打了，被杀（`025`「岱不从，遂与战，果为所杀」）；曹操这一头，`027` 记的是另一串动作：**追黄巾至济北、受降卒三十余万、收其精锐者、号为青州兵**。

**结果看起来相合，不等于用了鲍信那一套**：`027` 里没有一句写他守过、等过，也没有写他挑的是「要害」。

| | |
|---|---|
| 依据 | `025`「不可敌也」「其势必离散，后选精锐，据其要害，击之可破也」；`027`「追黄巾至济北」「受降卒三十余万」「收其精锐者，号为青州兵」 |
| 标记 | ○ 合理推演 |
| 考点 | 一段谏词里有两个时间：**现在不能打，以后可以打**——刘岱死在第一个。**曹操后来追击受降、收编精锐，是另一串动作，不是这一条的兑现**：结果相合，不等于用了同一条计策 |

---

### 卡 10 · 收尾题

**问：这支青州兵在底本里第一次露面打的是什么仗，打成什么样？**

答：**濮阳。先散的是他们。**

`029` 里，吕布「先以骑犯青州兵。青州兵奔」——**这支队伍一冲就散，曹操的阵跟着乱**。

他「驰突火出，坠马，烧左手掌」，靠司马楼异扶上马才退走。**「号为青州兵」这五个字之后，底本再提到他们，就是这一仗。**

| | |
|---|---|
| 依据 | `029`「布出兵战，先以骑犯青州兵。青州兵奔，太祖陈乱，驰突火出，坠马，烧左手掌。司马楼异扶太祖上马，遂引去」 |
| 标记 | ◆ 出自原文 |
| 考点 | **收编之后再见，他们先散**；曹操差点死在同一仗里 |

---

### 卡 11 · 沉默题

**问：这一篇里，最要紧的沉默是哪几处？**

答：**三处：为什么降、怎么挑、为什么追。**

一是**他们为什么降**——`027` 只有「乞降」两个字；二是**怎么挑的精锐、挑了多少、剩下的人去哪儿了**——`027` 只有「收其精锐者」五个字；三是**曹操为什么要追**——`027` 只记追，不记打算。

三处都在映射表里标着「—」。**这四段把动作写全了，理由一个不给。**

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 三处沉默：**为什么降、怎么挑、为什么追** |

### 这一篇的难点

**受降那一段里，没有一个人说过话。** `027` 全是记事的字：追、乞降、受降、收编、给名号。话在别处：`025` 里是鲍信的谏词（全篇唯一一段成段的分析），`029` 里是曹操对吕布的判语。

所以这一篇的卡只问四件事：**那两个数是不是一笔**、**那个名号是谁给的**、**一段谏词里的两个时间**、**这个名号两年后是什么成色**。
