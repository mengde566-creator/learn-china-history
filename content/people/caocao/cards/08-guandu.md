# 复习卡 · 场景 08 · 官渡

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 场景 08 · 官渡（11 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：夜袭淳于琼之前，曹操怎样作出决定？**

答：**许攸献计，荀攸、贾诩赞成；曹操留曹洪守营，亲率五千步骑夜往，天亮到达。**

`044`还记相持已久、兵少粮尽的处境。注引《曹瞒传》则补许攸报出粮辎所在及屯军无严备。

“绍营北四十里”是淳于琼宿营相对袁营的位置，不是已经注明的曹操夜袭行程，也不能直接算成救援必然来不及的时间。正文恰好还记救骑已经接近。

| | |
|---|---|
| 依据 | `044` 粮乏、献计、劝行、留守与夜往；`244` 注引《曹瞒传》 |
| 标记 | ○ 合理推演 |
| 考点 | 接清决策经过，不用未载路程替代战术解释 |

---

### 卡 2 · 因果 ★

**问：救骑接近时，曹操怎样应对？**

答：**他不接受左右分兵抵拒的建议，仍急攻淳于琼营。**

`044`接着记士卒殊死战、大破琼等。可以将这次选择看作集中兵力进攻的关键，但“胜负在这一刻已定”是事后读法；它没有证明从此再无变数，也没有穷尽取胜的一切因素。

| | |
|---|---|
| 依据 | `044`「请分兵拒之」「贼在背后，乃白」「士卒皆殊死战」 |
| 标记 | ○ 合理推演 |
| 考点 | 记住关键决策，不把阅读判断写成必胜保证 |

---

### 卡 3 · 出处题 ⚠️

**问：本篇《武帝纪》正文与裴注，怎样记乌巢火攻？**

答：**正文概述夜袭与破琼，裴注引《曹瞒传》具体写围屯放火、焚烧粮谷。**

正文`044`还有一次徐晃、史涣截击运粮车、“尽烧其车”，是夜袭之前的另一件事。不能把烧车与注里焚粮合成一次，也不能从本篇概述未详就扩大成整部《三国志》正文全不记火。

| | |
|---|---|
| 依据 | `044`；`244` 裴注引《曹瞒传》 |
| 标记 | ◆ 出自原文 |
| 考点 | 分清两次攻击及各自出处 |

---

### 卡 4 · 时间线

**问：从截粮车到破营，哪几步不能倒放？**

答：**先截击运粮车；再有许攸献计、曹操夜往；到营进攻时救骑接近，随后才破淳于琼等。**

《武帝纪》的线索是：徐晃、史涣截车焚车 → 许攸献计，荀攸、贾诩劝行 → 留曹洪守营，五千步骑夜往 → 淳于琼出阵、退保营 → 袁绍救骑近，左右请分兵 → 士卒殊死战，大破琼等。

裴注引《曹瞒传》另记围屯放火、焚毁粮谷，没有展开救骑一节。两条可对读，不能先把营全破完，再把正文救骑到来当作后来的一场危机。

| | |
|---|---|
| 依据 | `044` 截车、献计、夜往、攻营、救骑、破琼；`244` 注引《曹瞒传》围屯焚粮 |
| 标记 | ◆ 出自原文 |
| 考点 | 分清先后，也分清正文与注各自展开到哪一步 |

### 卡 5 · 人物

**问：这一仗里留下了名字的人，分几批？**

答：两批，出自两支笔。

**正文里的名字**：许攸、淳于琼、荀攸、贾诩、曹洪、徐晃、史涣，以及 `045` 里的张郃、高览、袁谭。

**注里的名字**：督将眭元进、骑督韩莒子、吕威璜、赵叡——`244` 说的是斩了他们**等首**（不止这四个），不是一份列完了的名单；正文里没有这四个人。

还有一个不在名单上的人：**袁绍**。`044` 还记袁绍进临官渡、起土山地道、射营、运粮与派骑救琼，不只有救援一个动作；到了 `045`，他是有话的，对长子袁谭说：「就彼攻琼等，吾攻拔其营，彼固无所归矣！」

| | |
|---|---|
| 依据 | `044`、`045`（正文）；`244`（裴注引《曹瞒传》）。**袁绍那句台词在 `045`，不在 `044`** |
| 标记 | ○ 合理推演 |
| 考点 | 「分两批」是数出来的，`044` `045` `244` 里没有这一句——所以标推演。同一夜的事，两支笔。**注里多出来的名字，是另一本书给的** |

---

### 卡 6 · 地理

**问：「绍营北四十里」告诉了我们什么？**

答：**告诉淳于琼一部宿营相对袁绍大营的距离与方向。**

`044`明记北四十里；`244`注记粮辎在故市、乌巢。二者可对读，但它们没有给曹操出营至袭击目标的精确路程，也没有说明救骑走了多久。

“北”是正文已有的方位，不能再说方位全属外证。地名对应今日何处，则需要另作地理考证。

| | |
|---|---|
| 依据 | `044`「宿绍营北四十里」；`244`「在故市、乌巢」 |
| 标记 | ◆ 出自原文 |
| 考点 | 参照点、方向、距离说清，不移成另一条路线 |

---

### 卡 7 · 一句话

**问：这一仗里，曹操说出口的话是哪一句？**

答：**「贼在背后，乃白！」**——敌人到了背后，再告诉我。

六个字。这六段正文里他另有别的话：`040` 里评袁绍的那一整段是在营中说的，`042` 里那几句是望着敌骑下的令，`044` 里「却十五日为汝破绍，不复劳汝矣」是对运粮的民夫说的——**乌巢那一夜，他在阵前喊出来的是这一句**。

| | |
|---|---|
| 依据 | `044`「公怒曰：『贼在背后，乃白！』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 前有淳于琼的营，后有袁绍的救兵，左右请分兵——这句话表现此刻坚持进攻的选择，不用于概括他一生全部性格 |

### 卡 8 · 陷阱题 ★

**问：淳于琼是怎么死的？**

答：**正文概述破琼斩将；注引《曹瞒传》另保存割鼻、问答与被杀的较详说法。**

`244`（裴松之注引《曹瞒传》）接着往下写：「割得将军淳于仲简鼻，未死，杀士卒千余人，皆取鼻，牛马割唇舌，以示绍军」。后来有人夜里抓到他，要送到曹操帐下，曹操问他一句「何为如是」——他答：

> 「胜负自天，何用为问乎！」

曹操本来不想杀他（`244`「公意欲不杀」）。是许攸一句话要了他的命——`244`「明旦鉴于镜，此益不忘人」：让他明天早上照镜子，就更忘不掉这件事了。

**同一件事，正文一个「斩」字，注里一整段。**收束是陈寿给的，代价是吴人的书留下来的。

| | |
|---|---|
| 依据 | `044`「大破琼等，皆斩之」；`244`「割得将军淳于仲简鼻，未死，杀士卒千余人，皆取鼻，牛马割唇舌，以示绍军」「仲简曰：『胜负自天，何用为问乎！』」「公意欲不杀」「许攸曰：『明旦鉴于镜，此益不忘人。』」（裴松之注引《曹瞒传》） |
| 标记 | ◆ 出自原文 |
| 考点 | 正文的「皆斩之」不写出代价，注里那一整段才写。**别把「曹操杀了淳于琼」当成一句话**：割鼻、杀千余人、许攸那句定生死的话，都在这九段里，各有各的主人 |

### 卡 9 · 存疑 ★

**问：他到底有多少兵？**

答：**两说。正文说不满一万，给这部书作注的人说不止。**

`043`（正文）：「时公兵不满万，伤者十二三。」

裴松之不信这个数。他的按语里算了一笔账：魏武起兵时就有五千人（`243`「魏武初起兵，已有众五千」），裴松之认为他历战多胜、败不过十之二三；破黄巾时又收了三十多万降卒（`243`「一破黄巾，受降卒三十余万」）。他又反问：几千人怎么可能和营连数十里的十几万人相持几个月（`243`「安有以数千之兵，而得逾时相抗者哉？」）。

他的断语是：**写史的人想拿「以少」显奇，不是实录**（`243`「将记述者欲以少见奇，非其实录也」）。

两说都在，谁也不压谁——**质疑这个数的人，正是给这部书作注的那个人。**

| | |
|---|---|
| 依据 | `043`「时公兵不满万，伤者十二三」；`243`「魏武初起兵，已有众五千」「一破黄巾，受降卒三十余万」「安有以数千之兵，而得逾时相抗者哉？」「将记述者欲以少见奇，非其实录也」——**`243` 是裴松之自己的按语，就在本篇九段里**，这一条只用它的说法作对照 |
| 标记 | △ 存疑 |
| 考点 | 同一个数字，正文和注家各执一说。**这不是「谁对谁错」的题**：一方是陈寿写下来的数，一方是替陈寿作注的人的反驳，两边都摆着，读者自己判断。要注意的是裴松之那一段在底本里的编号是 `243`，**它就在本篇声明的范围里**（`040`–`045`、`242`–`244`） |

### 卡 10 · 人物 ★

**问：许攸为什么投曹操？**

答：**`044` 给的理由只有六个字：贪财，袁绍满足不了他。**

正文把贪财、袁绍不能满足与来奔相接；没有一场具体讨价还价的记录。`044` 在这一句之后紧接着记他的动作：「来奔，因说公击琼等」——来投、献计，写在同一句里。

他拿什么当投名状？粮在哪儿——这一层在注里：`244` 记的是他自己把地方报出来，`244`「今袁氏辎重有万余乘，在故市、乌巢」。

| | |
|---|---|
| 依据 | `044`「绍谋臣许攸贪财，绍不能足，来奔，因说公击琼等」；`244`「今袁氏辎重有万余乘，在故市、乌巢」（裴松之注引《曹瞒传》） |
| 标记 | ○ 合理推演 |
| 考点 | `044` 把动机和动作压在一句话里。**这一篇最锋利的地方是人，不是火**——贪财、不能足是正文的解释，不再虚构谈价的现场或排除所有其他考虑 |

### 卡 11 · 开放题

**问：正文和注，给的是同一夜的两个版本。这两层该怎么摆？**

答：先分清三层：

| 层 | 写了什么 |
|---|---|
| 正文 `040` `041` `042` `043` `044` `045` | 十余万对不满万、运粮车、夜行、急击、救兵、「贼在背后，乃白」、皆斩之、张郃高览来降、绍众大溃 |
| 注 `244` | 跣出迎之、问粮、故市与乌巢、围屯、放火、营中惊乱、尽燔粮谷宝货、四将首级、淳于琼的下场 |
| 后世 | 「200 年」这个公元纪年（底本里没有） |

正文的作者是晋人陈寿；注引的《曹瞒传》是吴人的书，**对曹操不客气**。

两层可并读，互补或有差别处都说明出处；不能把不同记载悄悄合成唯一完整现场。

推得出来的（比如他为什么敢走这一趟）标 ○，给链条；推不出来的（那一夜他在马上想什么）标 —，**就让它空着**。

| | |
|---|---|
| 依据 | `044`（正文）与 `244`（裴注引《曹瞒传》）；两处「烧」各是一件事 |
| 标记 | ○ 合理推演 |
| 考点 | 这一篇真正要教的是**分层**：正文一层、注一层、后世一层。混成一层，故事更好看，但它就不是史料了 |
