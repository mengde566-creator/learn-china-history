# 复习卡 · 场景 08 · 官渡

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 场景 08 · 官渡（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：曹操为什么敢拿五千人去打淳于琼的一万多人？**

答：因为**他算的是那四十里路**。

淳于琼的营，在袁绍大营北边四十里。袁绍要来救，得先派人走完这四十里；曹操要做的，是在救兵走完之前把营打完。

他不是比淳于琼能打，是**比袁绍的救兵快**。

| | |
|---|---|
| 依据 | `011`「宿绍营北四十里」；`011`「自将步骑五千人夜往，会明至」；`011`「绍遣骑救琼」 |
| 标记 | ○ 合理推演 |
| 考点 | 底本不解释他为什么敢。**「四十里」是这一仗里唯一能算的东西**，也是他全部的底气 |

---

### 卡 2 · 因果 ★

**问：这一夜，胜负是在哪一刻定下来的？**

答：**在曹操不肯分兵的那一刻。**

左右说敌人的骑兵靠近了，请分兵去挡。曹操的回答是「贼在背后，乃白」——敌人到了背后，再告诉我。

他带出来的只有五千人，对面一万多，背后又有袁绍的救兵。**分兵就是把两头都变薄。**他选了不回头，士卒才殊死战。

| | |
|---|---|
| 依据 | `011`「左右或言：『贼骑稍近，请分兵拒之。』公怒曰：『贼在背后，乃白！』」；`011`「士卒皆殊死战，大破琼等，皆斩之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这是这一篇的骨头。**他不是不怕背后，是不肯把正面让开** |

---

### 卡 3 · 陷阱题 ⚠️

**问：「火烧乌巢」这件事，是《三国志》正文写的吗？**

答：**不是。**

《武帝纪》正文写这一仗，止于「大破琼等，皆斩之」——**一个火字也没有**。围屯、放火、燔粮、斩四将首级，出自裴松之注引的《曹瞒传》。

还有一处容易并错：正文里的「尽烧其车」，烧的是袁绍的**运粮车**，不是那处营屯的囤粮。**两处「烧」不是一件事。**

| | |
|---|---|
| 依据 | `011`（正文，无火）；`012`（正文，「尽烧其车」）；`103`（裴注引《曹瞒传》，「尽燔其粮谷宝货」） |
| 标记 | ◆ 出自原文 |
| 考点 | 记忆里的「火烧乌巢」，一半来自注，一半来自后人讲的故事。**先分清哪一句是哪本书的** |

### 卡 4 · 时间线

**问：把这五件事按发生的顺序排好。**

A. 许攸来投，说去打淳于琼
B. 袁绍的运粮车几千乘到了，徐晃、史涣截住，车全烧了
C. 曹操围住那处营屯，放火，营中大乱
D. 淳于琼等看见曹操兵少，出到营门外
E. 曹操留曹洪守营，带五千步骑连夜出发

答：**B → A → E → D → C**

| | |
|---|---|
| 依据 | `012` → `011` → `011` → `011` → `103` |
| 标记 | ◆ 出自原文 |
| 考点 | **别按编号顺序排。** `011` 的编号排在 `012` 前面，正文里却是烧车在前、夜袭在后——**顺序按事情走，不按编号走** |

---

### 卡 5 · 人物

**问：这一仗里留下了名字的人，分几批？**

答：两批，出自两支笔。

**正文里的名字**：许攸、淳于琼、荀攸、贾诩、曹洪、徐晃、史涣。

**注里的名字**：督将眭元进、骑督韩莒子、吕威璜、赵叡——他们是首级被斩的名单，正文里没有这四个人。

还有一个不在名单上的人：**袁绍**。他派了救兵，正文只写了五个字「绍遣骑救琼」，他没有说过一句话。

| | |
|---|---|
| 依据 | `011`、`012`（正文）；`103`（裴注引《曹瞒传》） |
| 标记 | ◆ 出自原文 |
| 考点 | 同一夜的事，两支笔。**注里多出来的名字，是另一本书给的** |

---

### 卡 6 · 地理

**问：淳于琼守的那个地方，在哪儿？**

答：**离袁绍的大营四十里，北边。**就这一句。

三段原文里没有地名。「官渡」和「乌巢」都是后世的称法——**它们不在 `011` `012` `103` 里**，属于外证。

但曹操敢打，靠的正是这个距离：四十里，是袁绍救兵要走的路，也是他全部的时间。

| | |
|---|---|
| 依据 | `011`「宿绍营北四十里」；地名不在三段原文内，属外证 |
| 标记 | ○ 外证 |
| 考点 | 要记住的不是地名，是**距离**。地名是后人加的，距离是当时就有的 |

---

### 卡 7 · 一句话

**问：这一仗里，曹操说出口的话是哪一句？**

答：**「贼在背后，乃白！」**——敌人到了背后，再告诉我。

六个字。三段原文里，他只有这一句。

| | |
|---|---|
| 依据 | `011`「公怒曰：『贼在背后，乃白！』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 前有淳于琼的营，后有袁绍的救兵，左右请分兵——**这六个字里有这个人全部的赌性** |

---

### 卡 8 · 开放题

**问：正文和注，给的是同一夜的两个版本。这两层该怎么摆？**

答：先分清三层：

| 层 | 写了什么 |
|---|---|
| 正文 `011` `012` | 运粮车、夜行、急击、救兵、「贼在背后，乃白」、皆斩之 |
| 注 `103` | 围屯、放火、营中惊乱、尽燔粮谷宝货、四将首级 |
| 后世 | 「官渡」「乌巢」这两个地名 |

正文的作者是晋人陈寿；注引的《曹瞒传》是吴人的书，**对曹操不客气**。

两层都留着，不合并——合并了，就再也看不出哪一句是谁说的。

推得出来的（比如他为什么敢走这一趟）标 ○，给链条；推不出来的（那一夜他在马上想什么）标 —，**就让它空着**。

| | |
|---|---|
| 依据 | `011`、`012`（正文）与 `103`（裴注引《曹瞒传》）；两处「烧」各是一件事 |
| 标记 | ○ 合理推演 ＋ — 史书的沉默 |
| 考点 | 这一篇真正要教的是**分层**：正文一层、注一层、后世一层。混成一层，故事更好看，但它就不是史料了 |
