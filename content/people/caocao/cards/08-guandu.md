# 复习卡 · 场景 08 · 官渡

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 场景 08 · 官渡（11 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：曹操为什么敢拿五千人去打淳于琼的一万多人？**

答：因为**他算的是那四十里路**。

淳于琼的营，在袁绍大营北边四十里。袁绍要来救，得先派人走完这四十里；曹操要做的，是在救兵走完之前把营打完。

他不是比淳于琼能打，是**比袁绍的救兵快**。

| | |
|---|---|
| 依据 | `044`「宿绍营北四十里」；`044`「自将步骑五千人夜往，会明至」；`044`「绍遣骑救琼」 |
| 标记 | ○ 合理推演 |
| 考点 | 底本不解释他为什么敢。**「四十里」是这一仗里唯一能算的东西**，也是他全部的底气 |

---

### 卡 2 · 因果 ★

**问：这一夜，胜负是在哪一刻定下来的？**

答：**在曹操不肯分兵的那一刻。**

左右说敌人的骑兵靠近了，请分兵去挡。曹操的回答是「贼在背后，乃白！」——敌人到了背后，再告诉我。

他带出来的只有五千人，对面一万多，背后又有袁绍的救兵。**分兵就是把两头都变薄。**他呵斥的是请他分兵的左右；这一句之后，五千人「皆殊死战」——`044` 只把这两句挨着写，没有说前者是后者的原因。

| | |
|---|---|
| 依据 | `044`「左右或言：『贼骑稍近，请分兵拒之。』公怒曰：『贼在背后，乃白！』」；`044`「士卒皆殊死战，大破琼等，皆斩之」 |
| 标记 | ○ 合理推演 |
| 考点 | 「在哪一刻定下来」本身就是读出来的，`044` 没有这一句——所以这张卡标推演。它是这一篇的骨头：**他不是不怕背后，是不肯把正面让开** |

---

### 卡 3 · 陷阱题 ⚠️

**问：「火烧乌巢」这件事，是《三国志》正文写的吗？**

答：**不是。**

本篇声明的那六段正文（`040` `041` `042` `043` `044` `045`）写到「大破琼等，皆斩之」为止，**一个火字也没有**——那六段说的是运粮车、夜行、急击、救兵、呵斥和受降。围屯、放火、燔粮、斩四将首级，出自裴松之注引的《曹瞒传》，也就是本篇的 `244`。

还有一处容易并错：`044` 里的「尽烧其车」，烧的是袁绍的**运粮车**；`244` 里「尽燔其粮谷宝货」，烧的是那处营屯的囤粮。**两处「烧」不是一件事。**

| | |
|---|---|
| 依据 | `044`（正文，无火）；`044`（正文，「尽烧其车」）；`244`（裴注引《曹瞒传》，「尽燔其粮谷宝货」） |
| 标记 | ○ 合理推演 |
| 考点 | 这一步是把正文读到收段、再拿 `244` 比出来的读法，不是哪一段里的某一句话——所以这张卡标推演。记忆里的「火烧乌巢」，一半来自注，一半来自后人讲的故事。**先分清哪一句是哪本书的** |

### 卡 4 · 时间线

**问：把这五件事按发生的顺序排好。**

A. 许攸来投，说去打淳于琼
B. 袁绍的运粮车几千乘到了，徐晃、史涣截住，车全烧了
C. 曹操围住那处营屯，放火，营中大乱
D. 淳于琼等看见曹操兵少，出到营门外
E. 曹操留曹洪守营，带五千步骑连夜出发

答：**B → A → E → D → C**

| | |
|---|---|
| 依据 | `044` → `044` → `044` → `044` → `244` |
| 标记 | ◆ 出自原文 |
| 考点 | **别按编号顺序排。** 夜袭在 `044`，围屯放火在 `244`——编号是分段落的，不是分先后的。这几件事里，烧运粮车在前、劫乌巢在后；夜行军在前、放火在后。**顺序按事情走，不按编号走** |

### 卡 5 · 人物

**问：这一仗里留下了名字的人，分几批？**

答：两批，出自两支笔。

**正文里的名字**：许攸、淳于琼、荀攸、贾诩、曹洪、徐晃、史涣。

**注里的名字**：督将眭元进、骑督韩莒子、吕威璜、赵叡——`244` 说的是斩了他们**等首**（不止这四个），不是一份列完了的名单；正文里没有这四个人。

还有一个不在名单上的人：**袁绍**。他派了救兵，正文只写了五个字「绍遣骑救琼」，他没有说过一句话。

| | |
|---|---|
| 依据 | `044`（正文）；`244`（裴注引《曹瞒传》） |
| 标记 | ○ 合理推演 |
| 考点 | 「分两批」是数出来的，`044` `244` 里没有这一句——所以标推演。同一夜的事，两支笔。**注里多出来的名字，是另一本书给的** |

---

### 卡 6 · 地理

**问：淳于琼守的那个地方，在哪儿？**

答：**离袁绍的大营四十里，北边。**就这一句。

「官渡」在正文里（`040`「分兵守官渡」、`044`「绍复进临官渡」），**不是外证**。「乌巢」在注里：`244` 写袁绍的辎重「有万余乘，在故市、乌巢」。这两个地名指的是今天的哪儿、相距多远，七段都不写。

但曹操敢打，靠的正是这个距离：四十里，是袁绍救兵要走的路，也是他全部的时间。

| | |
|---|---|
| 依据 | `044`「宿绍营北四十里」；`040`「分兵守官渡」；`044`「绍复进临官渡」；`244`「今袁氏辎重有万余乘，在故市、乌巢」（裴松之注引《曹瞒传》）。**方位不在七段里**——它属外证 |
| 标记 | ○ 外证 |
| 考点 | 要记住的不是方位，是**距离**。两个地名都在底本里，可它们对应今天的哪儿，底本一个字不写——那是后人的坐标 |

### 卡 7 · 一句话

**问：这一仗里，曹操说出口的话是哪一句？**

答：**「贼在背后，乃白！」**——敌人到了背后，再告诉我。

六个字。`040` `041` `042` `043` `044` `045` 这六段正文里，只有这一句是他说出口的话。

| | |
|---|---|
| 依据 | `044`「公怒曰：『贼在背后，乃白！』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 前有淳于琼的营，后有袁绍的救兵，左右请分兵——**这六个字里有这个人全部的赌性** |

### 卡 8 · 陷阱题 ★

**问：淳于琼是怎么死的？**

答：**正文只说「皆斩之」（`044`），注里才写全。**

`244`（裴松之注引《曹瞒传》）接着往下写：「割得将军淳于仲简鼻，未死，杀士卒千余人，皆取鼻，牛马割唇舌，以示绍军」。后来有人夜里抓到他，要送到曹操帐下，曹操问他一句「何为如是」——他答：

> 「胜负自天，何用为问乎！」

曹操本来不想杀他（`244`「公意欲不杀」）。是许攸一句话要了他的命——`244`「明旦鉴于镜，此益不忘人」：让他明天早上照镜子，就更忘不掉这件事了。

**同一件事，正文一个「斩」字，注里一整段。**收束是陈寿给的，代价是吴人的书留下来的。

| | |
|---|---|
| 依据 | `044`「大破琼等，皆斩之」；`244`「割得将军淳于仲简鼻，未死，杀士卒千余人，皆取鼻，牛马割唇舌，以示绍军」「仲简曰：『胜负自天，何用为问乎！』」「公意欲不杀」「许攸曰：『明旦鉴于镜，此益不忘人。』」（裴松之注引《曹瞒传》） |
| 标记 | ◆ 出自原文 |
| 考点 | 正文的「皆斩之」不写出代价，注里那一整段才写。**别把「曹操杀了淳于琼」当成一句话**：割鼻、杀千余人、许攸那句定生死的话，都在这七段里，各有各的主人 |

### 卡 9 · 存疑 ★

**问：他到底有多少兵？**

答：**两说。正文说不满一万，给这部书作注的人说不止。**

`043`（正文）：「时公兵不满万，伤者十二三。」

裴松之不信这个数。他的按语里算了一笔账：魏武起兵时就有五千人（`243`「魏武初起兵，已有众五千」），此后百战百胜，败仗不过十之二三；破黄巾时又收了三十多万降卒（`243`「一破黄巾，受降卒三十余万」）。他又反问：几千人怎么可能和营连数十里的十几万人相持几个月（`243`「安有以数千之兵，而得逾时相抗者哉？」）。

他的断语是：**写史的人想拿「以少」显奇，不是实录**（`243`「将记述者欲以少见奇，非其实录也」）。

两说都在，谁也不压谁——**质疑这个数的人，正是给这部书作注的那个人。**

| | |
|---|---|
| 依据 | `043`「时公兵不满万，伤者十二三」；`243`「魏武初起兵，已有众五千」「一破黄巾，受降卒三十余万」「安有以数千之兵，而得逾时相抗者哉？」「将记述者欲以少见奇，非其实录也」——**`243` 是裴松之自己的按语，不在本篇七段里**，这一条只用它的说法作对照 |
| 标记 | △ 存疑 |
| 考点 | 同一个数字，正文和注家各执一说。**这不是「谁对谁错」的题**：一方是陈寿写下来的数，一方是替陈寿作注的人的反驳，两边都摆着，读者自己判断。要注意的是裴松之那一段在底本里的编号是 `243`，**它不在本篇声明的范围里** |

### 卡 10 · 人物 ★

**问：许攸为什么投曹操？**

答：**`044` 给的理由只有六个字：贪财，袁绍满足不了他。**

不是弃暗投明，是价钱没谈拢。`044` 在这一句之后紧接着记他的动作：「来奔，因说公击琼等」——来投、献计，写在同一句里。

他拿什么当投名状？粮在哪儿——这一层在注里：`244` 记的是他自己把地方报出来，`244`「今袁氏辎重有万余乘，在故市、乌巢」。

| | |
|---|---|
| 依据 | `044`「绍谋臣许攸贪财，绍不能足，来奔，因说公击琼等」；`244`「今袁氏辎重有万余乘，在故市、乌巢」（裴松之注引《曹瞒传》） |
| 标记 | ○ 合理推演 |
| 考点 | `044` 把动机和动作压在一句话里。**这一篇最锋利的地方是人，不是火**——许攸不是来投明主的。「价钱没谈拢」是从「绍不能足」推出来的白话，`044` 没有这么说 |

### 卡 11 · 开放题

**问：正文和注，给的是同一夜的两个版本。这两层该怎么摆？**

答：先分清三层：

| 层 | 写了什么 |
|---|---|
| 正文 `040` `041` `042` `043` `044` `045` | 十余万对不满万、运粮车、夜行、急击、救兵、「贼在背后，乃白」、皆斩之、张郃高览来降、绍众大溃 |
| 注 `244` | 跣出迎之、问粮、故市与乌巢、围屯、放火、营中惊乱、尽燔粮谷宝货、四将首级、淳于琼的下场 |
| 后世 | 「200 年」这个公元纪年（底本里没有） |

正文的作者是晋人陈寿；注引的《曹瞒传》是吴人的书，**对曹操不客气**。

两层都留着，不合并——合并了，就再也看不出哪一句是谁说的。

推得出来的（比如他为什么敢走这一趟）标 ○，给链条；推不出来的（那一夜他在马上想什么）标 —，**就让它空着**。

| | |
|---|---|
| 依据 | `044`（正文）与 `244`（裴注引《曹瞒传》）；两处「烧」各是一件事 |
| 标记 | ○ 合理推演 |
| 考点 | 这一篇真正要教的是**分层**：正文一层、注一层、后世一层。混成一层，故事更好看，但它就不是史料了 |
