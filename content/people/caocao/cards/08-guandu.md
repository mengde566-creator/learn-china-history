# 复习卡 · 场景 08 · 官渡

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 场景 08 · 官渡（9 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：曹操为什么敢拿五千人去打淳于琼的一万多人？**

答：因为**他算的是那四十里路**。

淳于琼的营，在袁绍大营北边四十里。袁绍要来救，得先派人走完这四十里；曹操要做的，是在救兵走完之前把营打完。

他不是比淳于琼能打，是**比袁绍的救兵快**。

| | |
|---|---|
| 依据 | `044`「宿绍营北四十里」；`044`「自将步骑五千人夜往，会明至」；`044`「绍遣骑救琼」 |
| 标记 | ○ 合理推演 |
| 考点 | 底本不解释他为什么敢。**「四十里」是这一仗里唯一能算的东西**，也是他全部的底气 |

---

### 卡 2 · 因果 ★

**问：这一夜，胜负是在哪一刻定下来的？**

答：**在曹操不肯分兵的那一刻。**

左右说敌人的骑兵靠近了，请分兵去挡。曹操的回答是「贼在背后，乃白！」——敌人到了背后，再告诉我。

他带出来的只有五千人，对面一万多，背后又有袁绍的救兵。**分兵就是把两头都变薄。**他呵斥的是请他分兵的左右；这一句之后，五千人「皆殊死战」——`044` 只把这两句挨着写，没有说前者是后者的原因。

| | |
|---|---|
| 依据 | `044`「左右或言：『贼骑稍近，请分兵拒之。』公怒曰：『贼在背后，乃白！』」；`044`「士卒皆殊死战，大破琼等，皆斩之」 |
| 标记 | ○ 合理推演 |
| 考点 | 「在哪一刻定下来」本身就是读出来的，`044` 没有这一句——所以这张卡标推演。它是这一篇的骨头：**他不是不怕背后，是不肯把正面让开** |

---

### 卡 3 · 陷阱题 ⚠️

**问：「火烧乌巢」这件事，是《三国志》正文写的吗？**

答：**不是。**

本篇声明的两段正文（`044` `044`）写到「大破琼等，皆斩之」为止，**一个火字也没有**——那两段说的是夜行、急击、救兵、呵斥。围屯、放火、燔粮、斩四将首级，出自裴松之注引的《曹瞒传》，也就是本篇的 `244`。

还有一处容易并错：`044` 里的「尽烧其车」，烧的是袁绍的**运粮车**；`244` 里「尽燔其粮谷宝货」，烧的是那处营屯的囤粮。**两处「烧」不是一件事。**

| | |
|---|---|
| 依据 | `044`（正文，无火）；`044`（正文，「尽烧其车」）；`244`（裴注引《曹瞒传》，「尽燔其粮谷宝货」） |
| 标记 | ○ 合理推演 |
| 考点 | 这一步是把 `044` `044` 读到收段、再拿 `244` 比出来的读法，不是原文里的某一句话——所以这张卡标推演。记忆里的「火烧乌巢」，一半来自注，一半来自后人讲的故事。**先分清哪一句是哪本书的** |

### 卡 4 · 时间线

**问：把这五件事按发生的顺序排好。**

A. 许攸来投，说去打淳于琼
B. 袁绍的运粮车几千乘到了，徐晃、史涣截住，车全烧了
C. 曹操围住那处营屯，放火，营中大乱
D. 淳于琼等看见曹操兵少，出到营门外
E. 曹操留曹洪守营，带五千步骑连夜出发

答：**B → A → E → D → C**

| | |
|---|---|
| 依据 | `044` → `044` → `044` → `044` → `244` |
| 标记 | ◆ 出自原文 |
| 考点 | **别按编号顺序排。** `044` 的编号排在 `044` 前面，正文里却是烧车在前、夜袭在后——**顺序按事情走，不按编号走** |

### 卡 5 · 人物

**问：这一仗里留下了名字的人，分几批？**

答：两批，出自两支笔。

**正文里的名字**：许攸、淳于琼、荀攸、贾诩、曹洪、徐晃、史涣。

**注里的名字**：督将眭元进、骑督韩莒子、吕威璜、赵叡——`244` 说的是斩了他们**等首**（不止这四个），不是一份列完了的名单；正文里没有这四个人。

还有一个不在名单上的人：**袁绍**。他派了救兵，正文只写了五个字「绍遣骑救琼」，他没有说过一句话。

| | |
|---|---|
| 依据 | `044`、`044`（正文）；`244`（裴注引《曹瞒传》） |
| 标记 | ○ 合理推演 |
| 考点 | 「分两批」是数出来的，`044` `044` `244` 里没有这一句——所以标推演。同一夜的事，两支笔。**注里多出来的名字，是另一本书给的** |

---

### 卡 6 · 地理

**问：淳于琼守的那个地方，在哪儿？**

答：**离袁绍的大营四十里，北边。**就这一句。

这三段里没有地名。「乌巢」见于裴松之注引《曹瞒传》的上下文（不在本篇裁出的 `244` 段内），**「官渡」才是后世的通称**——两个都是底本之外的坐标，属于外证。

但曹操敢打，靠的正是这个距离：四十里，是袁绍救兵要走的路，也是他全部的时间。

| | |
|---|---|
| 依据 | `044`「宿绍营北四十里」；这三段里一个地名都没有，乌巢与官渡都属外证 |
| 标记 | ○ 外证 |
| 考点 | 要记住的不是地名，是**距离**。地名是后人加的，距离是原文里就有的 |

---

### 卡 7 · 一句话

**问：这一仗里，曹操说出口的话是哪一句？**

答：**「贼在背后，乃白！」**——敌人到了背后，再告诉我。

六个字。三段原文里，他只有这一句。

| | |
|---|---|
| 依据 | `044`「公怒曰：『贼在背后，乃白！』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 前有淳于琼的营，后有袁绍的救兵，左右请分兵——**这六个字里有这个人全部的赌性** |

---

### 卡 8 · 人物 ★

**问：许攸为什么投曹操？**

答：**`044` 给的理由只有六个字：贪财，袁绍满足不了他。**

不是弃暗投明，是价钱没谈拢。`044` 在这一句之后紧接着记他的动作：「来奔，因说公击琼等」——来投、献计，写在同一句里。

他拿什么当投名状？粮在哪儿——这一层在三段之外：裴注引《曹瞒传》里，是他自己说出「袁氏辎重万余乘，在故市、乌巢」，那一句不在本篇裁出的 `244` 段内。

| | |
|---|---|
| 依据 | `044`「绍谋臣许攸贪财，绍不能足，来奔，因说公击琼等」；`244`（裴注引《曹瞒传》）；「今袁氏辎重万余乘，在故市、乌巢」那一句在裴注的上下文里，不在本篇裁出的 `244` 段内 |
| 标记 | ◆ 出自原文 |
| 考点 | `044` 把动机和动作压在一句话里。**这一篇最锋利的地方是人，不是火**——许攸不是来投明主的 |

### 卡 9 · 开放题

**问：正文和注，给的是同一夜的两个版本。这两层该怎么摆？**

答：先分清三层：

| 层 | 写了什么 |
|---|---|
| 正文 `044` `044` | 运粮车、夜行、急击、救兵、「贼在背后，乃白」、皆斩之 |
| 注 `244` | 围屯、放火、营中惊乱、尽燔粮谷宝货、四将首级 |
| 后世 | 「官渡」「乌巢」这两个地名 |

正文的作者是晋人陈寿；注引的《曹瞒传》是吴人的书，**对曹操不客气**。

两层都留着，不合并——合并了，就再也看不出哪一句是谁说的。

推得出来的（比如他为什么敢走这一趟）标 ○，给链条；推不出来的（那一夜他在马上想什么）标 —，**就让它空着**。

| | |
|---|---|
| 依据 | `044`、`044`（正文）与 `244`（裴注引《曹瞒传》）；两处「烧」各是一件事 |
| 标记 | ○ 合理推演 |
| 考点 | 这一篇真正要教的是**分层**：正文一层、注一层、后世一层。混成一层，故事更好看，但它就不是史料了 |
