# 复习卡 · 场景 04 · 荥阳之败

> 原则：**问动机，不问年代。**
> 这一篇的底本是两段：一段是他站在十几万人面前说的话，一段是他自己带兵出去又败回来的经过。
> **他不缺道理，也不缺胆子。他缺的是别人跟他一起走。**

---

## 场景 04 · 荥阳之败（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机 ★

**问：十几万人按兵不动，曹操为什么一个人带兵往西去？**

答：**这一段不回答。**

《武帝纪》把两件事挨着写：`017` 以「邈等不能用」收尾，`018` 开口就是「遂引兵西」。中间没有一个字的过渡——没有他为什么不再等，也没有别人怎么看他走。

他讲的那一整套里，核心是「示天下形势」：把兵摆开、占住险要，让天下看见有人在讨董卓。十几万人不动，他动——**这一步读得出来，那一句没有写。**

**这一篇最重的一个「—」就是它。** 不是产品不知道，是史书不知道。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | `017` 和 `018` 之间是**空白**。他会说什么，两段写全了；他怎么想的，一个字没有 |

---

### 卡 2 · 因果 ★

**问：他带着少数人打了一整天，几乎死在那儿。为什么对面也退了？**

答：**因为徐荣算了一笔账。**

`018` 的收尾是徐荣那一头：他看见曹操带的兵少，打了一整天，于是判断酸枣那边不容易攻，也带兵回去了。

这一句里没有曹操的功劳。徐荣退兵的理由只有一个——酸枣还有十几万人。**他打赢了眼前这一仗，就走了。**

| | |
|---|---|
| 依据 | `018`「荣见太祖所将兵少，力战尽日，谓酸枣未易攻也，亦引兵还」 |
| 标记 | ○ 合理推演 |
| 考点 | 退兵的是徐荣，理由在酸枣那十几万人身上——**这一败的收尾，是他没等来的那支兵替他收的** |

---

### 卡 3 · 陷阱题 ⚠️

**问：「与战不利」——这一仗，是曹操输了吗？**

答：**这四个字说的是曹操这一头，不是整件事。**

`018` 的写法是：曹操这一边「与战不利，士卒死伤甚多」，他本人中箭、马伤、连夜跑掉；徐荣那一边「力战尽日」，然后「亦引兵还」。

**两边都没有赢。** 曹操丢了人和马，徐荣没有拿下酸枣，也没有追。

**陷阱在这儿**：读者记住的是「曹操大败」，而这一段给的是两个人都停了手——他只是先撑不住的那一个。

| | |
|---|---|
| 依据 | `018`「与战不利，士卒死伤甚多」；`018`「力战尽日，谓酸枣未易攻也，亦引兵还」 |
| 标记 | ○ 合理推演 |
| 考点 | 「不利」和「败」不是一回事。两句话里各有一半，**合起来读才知道停手的是双方** |

---

### 卡 4 · 人物 ★

**问：这一篇里，那个把马让给他的人，留下了什么？**

答：**三个字。**

`018` 写的是「从弟洪以马与太祖」——一个亲属关系，一个单名，一个动作。没有官职，没有表字，没有一句话。

后来的人都叫他曹洪，那是别的传里补的名字。**在这一段里，他是那个把马给出去的人，仅此而已。**

他为什么让，这一段一个字不写；他后来做了什么，也不在这一篇里。

| | |
|---|---|
| 依据 | `018`「从弟洪以马与太祖，得夜遁去」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「从弟洪」三个字里，只有一个动作是写出来的。**让马的理由和后来的事，都不在这两段里** |

---

### 卡 5 · 出处题 ★

**问：这一篇的两段，是一本书里的吗？**

答：**是。都在《三国志·魏书·武帝纪》正文里。**

`017` 记的是他在酸枣说的话：十几万人天天摆酒、不图进取，他把该打的仗一条一条讲了一遍，没有人听。

`018` 记的是他做的事：往西去，在荥阳汴水碰上徐荣，打了一天，中箭逃走。

**两段都在正文里，没有一条出自裴松之的注，也没有一条出自小说。** 这一篇的标记只用四档：◆ ○ — ⓘ。

| | |
|---|---|
| 依据 | `017` `018`（《武帝纪》正文） |
| 标记 | ◆ 出自原文 |
| 考点 | 曹操那十篇里，不是每一篇都有第二个出处。**这一篇只有一个出处，却有一个写不出来的空白** |

### 卡 6 · 时间线

**问：把这一篇的六件事按顺序排好。**

A. 他在汴水遇上徐荣，中箭，马伤
B. 十几万人在酸枣天天摆酒，谁也不往前走
C. 他往西走，要占成皋
D. 他把该打的仗一条一条讲了一遍
E. 徐荣判断酸枣不容易攻，带兵回去
F. 他的堂弟把马让给他，他连夜跑掉

答：**B → D → C → A → F → E**

| | |
|---|---|
| 依据 | `017`「日置酒高会，不图进取」→`017`「太祖责让之，因为谋曰」→`017`「邈等不能用」→`018`「遂引兵西，将据成皋」→`018`「遇卓将徐荣，与战不利」→`018`「得夜遁去」→`018`「亦引兵还」 |
| 标记 | ◆ 出自原文 |
| 考点 | 顺序就是两段的顺序：**先说他讲了什么，再说他做了什么**。中间那句「邈等不能用」是这两段的接缝 |

---

### 卡 7 · 情节 ★

**问：这一篇用一句话说，说什么？**

答：**他不是被敌人打败的，是被自己人放在那儿打的。**

他站在十几万人面前，把该打的仗怎么打一条一条讲完了。`017` 的落点是四个字：邈等不能用。

然后他自己带兵走了。五千人也好、多少人也罢，两段里没有数目——只写着对面看见他兵少。

他中箭，马也伤了，堂弟把马让给他，他连夜跑掉。**那十几万人一直没动。**

| | |
|---|---|
| 依据 | `017`「太祖责让之，因为谋曰：『诸君听吾计……』」；`017`「邈等不能用」；`018`「遂引兵西」；`018`「荣见太祖所将兵少，力战尽日」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的对手不止徐荣。**「邈等不能用」四个字，和「与战不利」四个字，是同一件事的两头** |

---

### 卡 8 · 陷阱题 ⚠️

**问：徐荣后来怎么样了？五千人还剩多少？**

答：**两段都不回答。**

`018` 写到「亦引兵还」为止，徐荣此后的战功和结局一个字没有；死伤只留下「士卒死伤甚多」六个字，没有数目。

要小心的是数目本身。曹操带多少人去打，这两段里没有；「五千人」出自裴松之注引的《世语》，那是他在陈留起兵时的人数，属于另一篇（见 `03-chenliu`）。**拿那个数目去补这一仗，就是替史料编一个它没写的数字。**

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 这一篇最容易混进来的是**别处的数字**。两段里的数目只有一个：「十余万」——那是别人的人 |

### 这一篇的难点

**两段原文里，说出口的话只有他一个人的。** `017` 那一整段是他的话，
`018` 全是记事：往西、遇敌、不利、中箭、夜遁、敌退。

所以这一篇的卡不问台词，问两件事：**他讲的那一套为什么没人听**，
和**哪一处是史料不肯写的**。
