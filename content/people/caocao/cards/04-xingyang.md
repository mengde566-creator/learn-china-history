# 复习卡 · 场景 04 · 荥阳之败

> 原则：**问动机，不问年代。**
> 这一篇的底本是七段：十路兵怎么起来的（`015`–`019`）、这一仗怎么打的（`020`）、
> 败完之后他去了哪儿（`021`）。
> **他不缺道理，也不缺胆子。他缺的是别人跟他一起走。**

---

## 场景 04 · 荥阳之败（10 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机 ★

**问：其他诸军不进，曹操怎样解释自己西进的机会？**

答：**他认为董卓焚宫、迁帝，已使局势震动，正是出兵的机会。**

`020` 先记他向诸将分析局势，随后引兵向西。张邈派卫兹分兵相随，因此不是只有他一人出发。

这套战机判断是曹操当场所说，不能直接当作对局势的客观保证。他后来战败，也不能反过来抹掉他已经说明的出兵理由。

败后他还有另一套据险部署的建议，两次发言需要按先后区分。

| | |
|---|---|
| 依据 | `020`「今焚烧宫室，劫迁天子」至「不可失也」；「邈遣将卫兹分兵随太祖」 |
| 标记 | ◆ 出自原文 |
| 考点 | 区分人物已说出的理由、战果与未记下的其他心理；保留卫兹相随的事实 |

---

### 卡 2 · 处境 ★

**问：诸军为什么不敢先向董卓进兵？**

答：**正文把“卓兵强”接在各部驻地之后，说明袁绍等不敢先进的处境。**

随后曹操向诸将陈说战机，再西进；张邈另派卫兹分兵相随。不能把某一时刻的迟疑扩大成所有人从此一兵不动。

| | |
|---|---|
| 依据 | `020`「卓兵强，绍等莫敢先进」「邈遣将卫兹分兵随太祖」 |
| 标记 | ◆ 出自原文 |
| 考点 | 读出已有承接，不把原因说成全被省掉 |

---

### 卡 3 · 因果 ★

**问：徐荣打赢汴水一仗，为什么也退兵？**

答：**正文记他见曹操兵少而力战尽日，判断酸枣不容易攻，于是也引兵还。**

这段把眼前抵抗与对酸枣的判断接起来，没有说徐荣已掌握酸枣十余万人的准确情报，也不能只把那个人数当成已证实的唯一退兵原因。徐荣退兵不改变曹操此战失利的结果。

| | |
|---|---|
| 依据 | `020`「荣见太祖所将兵少，力战尽日，谓酸枣未易攻也，亦引兵还」 |
| 标记 | ◆ 出自原文 |
| 考点 | 保留敌方判断的依据，不补其未载情报 |

---

### 卡 4 · 陷阱题 ⚠️

**问：「与战不利」——这一仗，是曹操输了吗？**

答：**是。这一仗他败了。**

`020` 的写法是：曹操这一边「与战不利，士卒死伤甚多」，他本人中箭、马伤、连夜跑掉；徐荣那一边「力战尽日」，然后「亦引兵还」。

《三国志·魏书·曹洪传》记得更直：曹操为卓将徐荣所败，败退时追兵甚急——那一本不在这一篇的七段里，是外证。

**徐荣没有再往酸枣去，是另一件事。** 曹操这一仗输了；徐荣赢了眼前这一路，却停在这里——**一场仗的胜负，和有没有把全部打算做完，不是一回事。**

**陷阱在这儿**：把「徐荣也退了」读成「两边都没有赢」。曹操丢了人和马、连夜跑掉，那是败；徐荣停手，是他算完账以后的选择。

| | |
|---|---|
| 依据 | `020`「与战不利，士卒死伤甚多」；`020`「力战尽日，谓酸枣未易攻也，亦引兵还」；外证：《三国志·魏书·曹洪传》记曹操为卓将徐荣所败、败退时追兵甚急 |
| 标记 | ○ 合理推演 |
| 考点 | 「徐荣也退了」不等于「这一仗没有输家」。**败的是汴水这一路，停的是不攻酸枣那一步——两件事各归各** |

### 卡 5 · 时间线

**问：把这一篇的八件事按顺序排好。**

A. 他在汴水遇上徐荣，中箭，马伤
B. 诸路兵同时起来，推袁绍为盟主
C. 他往西走，要占成皋
D. 董卓把天子迁到长安，烧了宫室
E. 徐荣判断酸枣不容易攻，带兵回去
F. 他的从弟把马让给他，他连夜跑掉
G. 十几万人在酸枣天天摆酒，他一条一条讲该打的仗
H. 他兵少，去扬州募兵；收了一千多人，进屯河内

答：**B → D → C → A → F → E → G → H**

| | |
|---|---|
| 依据 | `020`「同时俱起兵，众各数万，推绍为盟主」→`020`「卓闻兵起，乃徙天子都长安……遂焚宫室」→`020`「遂引兵西，将据成皋」→`020`「遇卓将徐荣，与战不利」→`020`「得夜遁去」→`020`「亦引兵还」→`020`「日置酒高会」→`021`「至铚、建平，复收兵得千余人，进屯河内」 |
| 标记 | ◆ 出自原文 |
| 考点 | 顺序就是正文的顺序。**「日置酒高会」在败之后，不在败之前** |

### 卡 6 · 人物 ★

**问：从弟洪怎样帮助曹操脱险？**

答：**曹操中箭、坐骑受伤后，从弟洪把马给他，曹操得以连夜逃走。**

`020` 记亲属关系、名字和救援行动，没有给这场相让配对白。曹洪在别篇的事迹可以另查，不必把本段未详写成他只留下三个字。

| | |
|---|---|
| 依据 | `020`「从弟洪以马与太祖，得夜遁去」 |
| 标记 | ◆ 出自原文 |
| 考点 | 按人、事与结果读救援，不制造缺字谜题 |

### 卡 7 · 出处题 ★

**问：这一篇的七段，是哪一本书里的？**

答：**都在《三国志·魏书·武帝纪》里——这一篇的底本，就是这一本。**

`015`–`019` 是起兵那十路的名单，一段排一两个名字；`020` 是这一仗的全部本事，从「同时俱起兵」到「还到龙亢，士卒多叛」；`021` 的头一句是收尾——他收了一千多人，进屯河内。

**没有引小说，也没有引野史**，所以这一篇的标记只用四档：◆ ○ — ⓘ。

有三处要知道：`017`、`019`、`020` 里夹着几个字的说明——「岱，刘繇之兄，事见吴志」「遗字伯业，绍从兄」「信事见子勋传」。**它们跟人名排在同一段里**，收范围的时候是整段收进来的，读者在「原文」页签里会看到。

| | |
|---|---|
| 依据 | `015`–`021`（《武帝纪》）；`017`「事见吴志」、`019`「遗字伯业，绍从兄」、`020`「信事见子勋传」三处夹注随段收入 |
| 标记 | ◆ 出自原文 |
| 考点 | 曹操那十篇里，不是每一篇都只有一个出处。**这一篇七段同出一本书，却有一个写不出来的空白** |

### 卡 8 · 地理

**问：讨董诸将的驻地，正文列清了哪些？**

答：**列了八位将领、五处驻地。**

袁绍屯河内；张邈、刘岱、桥瑁、袁遗屯酸枣；袁术屯南阳；孔伷屯颍川；韩馥在邺。十位起兵者中的王匡、鲍信，在这份驻地列举里未被单独写出。

曹操另记“行奋武将军”，不是这十名名册中的一人；他后来西进，张邈派卫兹相随。不能把酸枣四部与所有十路军混为一处。

| | |
|---|---|
| 依据 | `015`–`020` 起兵名册；`020` 驻地及西进经过 |
| 标记 | ◆ 出自原文 |
| 考点 | 十人名册、八人驻地与曹操另叙，分别清点 |

### 卡 9 · 一句话

**问：这一篇用一句话说，说什么？**

答：**曹操判断有战机，西进失利，回酸枣后提出据险进兵的另一套部署，仍未被采用。**

“日置酒高会”是他败后回到酸枣时的记述，不能倒放到出发前。随后他又赴扬州募兵，获四千余人，返回龙亢时多有叛乱；后来在铚、建平再收千余人，进屯河内。

| | |
|---|---|
| 依据 | `020` 两次陈说、汴水失利、酸枣与募兵；`021` 再收兵 |
| 标记 | ◆ 出自原文 |
| 考点 | 保留先陈说、西进、败归再议、募兵的次序 |

### 卡 10 · 陷阱题 ⚠️

**问：起兵五千、汴水数千、扬州四千余，是同一笔兵数吗？**

答：**不是。数字属于不同阶段、不同来源。**

`020` 对汴水只说所将兵少；裴注引《魏武故事》所载曹操后来的令，自述汴水之战“数千”。起兵五千见`214`《世语》；扬州获四千余人见`020`，随后多叛；再收千余人见`021`。

汴水并非所有史料全无数量线索，但“数千”也不是可以硬定为五千的精确数字。

| | |
|---|---|
| 依据 | `020`–`021`；跨篇补充 `214`、`266` |
| 标记 | ○ 合理推演 |
| 考点 | 来源、阶段、精度分别处理，不把选段未载当全无材料 |

### 这一篇的难点

**七段原文里，说出口的话只有他一个人的。** 他本人的话只有 `020` 那两番；`019` 里另有一句张超的话（荐袁遗，「有冠世之懿，干时之量」），不是他说的。十路兵的名字是名单，徐荣和曹洪都只有一个动作，没有一句台词。

所以这一篇的卡不问台词，问三件事：**他讲的那一套为什么没有人听**、
**哪一处是史料不肯写的**，以及**两边的兵各自屯在哪儿**。

**次序是这一篇的关节。** 把「酸枣摆酒」放在汴水之前，读起来是「他先去骂人，然后自己去打」；正文的次序正好相反——他先往西、先败、先跑回来，才发现那十几万人一直没动。**顺序错了，这一篇的意思就变了。**
