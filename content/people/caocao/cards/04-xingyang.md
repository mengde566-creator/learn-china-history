# 复习卡 · 场景 04 · 荥阳之败

> 原则：**问动机，不问年代。**
> 这一篇的底本是七段：十路兵怎么起来的（`015`–`019`）、这一仗怎么打的（`020`）、
> 败完之后他去了哪儿（`021`）。
> **他不缺道理，也不缺胆子。他缺的是别人跟他一起走。**

---

## 场景 04 · 荥阳之败（10 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机 ★

**问：十几万人按兵不动，曹操为什么一个人带兵往西去？**

答：**这一段不回答。**

`020` 里，他先把那一番话讲完（「大众已合，诸君何疑」），紧接着就是「遂引兵西」——中间没有一个字交代他为什么不再等，也没有别人怎么看他走。

他讲的那一整套里，核心是「示天下形势」：把兵摆开、占住险要，让天下看见有人在讨董卓。十几万人不动，他动——**这一步读得出来，那一句没有写。**

**这是这一篇最重的一个「—」。** 不是产品不知道，是史书不知道。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | `020` 的「太祖曰」和「遂引兵西」之间是**空白**。他会说什么，这一段写全了；他怎么想的，一个字没有 |

---

### 卡 2 · 处境 ★

**问：起兵的是十路，为什么谁也不先走？**

答：**`020` 只给了四个字：卓兵强。**

它把两个判断并排写着——兵强，所以不敢先进。中间那个「为什么」，这一段自己省掉了。

那几路各自屯在哪儿，它倒是写得清清楚楚：袁绍在河内，张邈、刘岱、桥瑁、袁遗在酸枣，袁术在南阳，孔伷在颍川，韩馥在邺。**这几处兵，没有一个动的。**

| | |
|---|---|
| 依据 | `020`「卓兵强，绍等莫敢先进」；`020`「绍屯河内，邈、岱、瑁、遗屯酸枣，术屯南阳，伷屯颍川，馥在邺」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「兵强」和「不敢进」是并排的两句，**把它们连起来读，读出来的才是这一篇的处境** |

---

### 卡 3 · 因果 ★

**问：他在汴水败了，为什么对面也退了？**

答：**因为徐荣算了一笔账。**

`020` 的收尾是徐荣那一头：他看见曹操带的兵少，打了一整天，于是判断酸枣那边不容易攻，也带兵回去了。

这一句里没有曹操的功劳。徐荣退兵的理由只有一个——酸枣还有十几万人。**他打赢了眼前这一仗，就走了。**

| | |
|---|---|
| 依据 | `020`「荣见太祖所将兵少，力战尽日，谓酸枣未易攻也，亦引兵还」 |
| 标记 | ○ 合理推演 |
| 考点 | 退兵的是徐荣，理由在酸枣那十几万人身上——**这一败的收尾，是他没等来的那支兵替他收的** |

---

### 卡 4 · 陷阱题 ⚠️

**问：「与战不利」——这一仗，是曹操输了吗？**

答：**这四个字说的是曹操这一头，不是整件事。**

`020` 的写法是：曹操这一边「与战不利，士卒死伤甚多」，他本人中箭、马伤、连夜跑掉；徐荣那一边「力战尽日」，然后「亦引兵还」。

**两边都没有赢。** 曹操丢了人和马，徐荣没有拿下酸枣，也没有追。

**陷阱在这儿**：读者记住的是「曹操大败」，而这几段给的是两个人都停了手——他只是先撑不住的那一个。

| | |
|---|---|
| 依据 | `020`「与战不利，士卒死伤甚多」；`020`「力战尽日，谓酸枣未易攻也，亦引兵还」 |
| 标记 | ○ 合理推演 |
| 考点 | 「不利」和「败」不是一回事。两句话里各有一半，**合起来读才知道停手的是双方** |

### 卡 5 · 时间线

**问：把这一篇的八件事按顺序排好。**

A. 他在汴水遇上徐荣，中箭，马伤
B. 十路兵同日起来，推袁绍为盟主
C. 他往西走，要占成皋
D. 董卓把天子迁到长安，烧了宫室
E. 徐荣判断酸枣不容易攻，带兵回去
F. 他的从弟把马让给他，他连夜跑掉
G. 十几万人在酸枣天天摆酒，他一条一条讲该打的仗
H. 他兵少，去扬州募兵；收了一千多人，进屯河内

答：**B → D → C → A → F → E → G → H**

| | |
|---|---|
| 依据 | `020`「同时俱起兵，众各数万，推绍为盟主」→`020`「卓闻兵起，乃徙天子都长安……遂焚宫室」→`020`「遂引兵西，将据成皋」→`020`「遇卓将徐荣，与战不利」→`020`「得夜遁去」→`020`「亦引兵还」→`020`「日置酒高会」→`021`「至铚、建平，复收兵得千余人，进屯河内」 |
| 标记 | ◆ 出自原文 |
| 考点 | 顺序就是正文的顺序。**「日置酒高会」在败之后，不在败之前**——上一版把这两件事排倒了 |

---

### 卡 6 · 人物 ★

**问：这一篇里，那个把马让给他的人，留下了什么？**

答：**三个字。**

`020` 写的是「从弟洪以马与太祖」——一个亲属关系，一个单名，一个动作。没有官职，没有表字，没有一句话。

后来的人都叫他曹洪，那是从别处认过来的名字：正文别处有曹操的从弟曹洪（`031`「乃遣曹洪将兵西迎」、`044`「公乃留曹洪守」，后者见 `08-guandu`）。**在这一篇里，他是那个把马给出去的人，仅此而已。**

他为什么让，这几段一个字不写；他后来做了什么，也不在这一篇里。

| | |
|---|---|
| 依据 | `020`「从弟洪以马与太祖，得夜遁去」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「从弟洪」三个字里，只有一个动作是写出来的。**让马的理由和后来的事，都不在这七段里** |

---

### 卡 7 · 出处题 ★

**问：这一篇的七段，是哪一本书里的？**

答：**都在《三国志·魏书·武帝纪》里——这一篇的底本，就是这一本。**

`015`–`019` 是起兵那十路的名单，一段排一两个名字；`020` 是这一仗的全部本事，从「同时俱起兵」到「还到龙亢，士卒多叛」；`021` 的头一句是收尾——他收了一千多人，进屯河内。

**没有引小说，也没有引野史**，所以这一篇的标记只用四档：◆ ○ — ⓘ。

有三处要知道：`017`、`019`、`020` 里夹着几个字的说明——「岱，刘繇之兄，事见吴志」「遗字伯业，绍从兄」「信事见子勋传」。**它们跟人名排在同一段里**，收范围的时候是整段收进来的，读者在「原文」页签里会看到。

| | |
|---|---|
| 依据 | `015`–`021`（《武帝纪》）；`017`「事见吴志」、`019`「遗字伯业，绍从兄」、`020`「信事见子勋传」三处夹注随段收入 |
| 标记 | ◆ 出自原文 |
| 考点 | 曹操那十篇里，不是每一篇都只有一个出处。**这一篇七段同出一本书，却有一个写不出来的空白** |

---

### 卡 8 · 地理

**问：起兵的那十路，各自屯在哪儿？**

答：**`020` 给了五个地方：河内、酸枣、南阳、颍川、邺。**

袁绍在河内；张邈、刘岱、桥瑁、袁遗在酸枣；袁术在南阳；孔伷在颍川；韩馥在邺——**八个名字，五个地方**，没有一处动的。

起兵那十路里，曹操不在这张单子上：他往西去了（`020`「遂引兵西」）；济北相鲍信，这一段没给屯处。

这一仗打在荥阳汴水：他从酸枣往西，要去占成皋，路上碰上的徐荣。

| | |
|---|---|
| 依据 | `020`「是时绍屯河内，邈、岱、瑁、遗屯酸枣，术屯南阳，伷屯颍川，馥在邺」；`020`「遂引兵西，将据成皋」；`020`「到荥阳汴水，遇卓将徐荣」 |
| 标记 | ◆ 出自原文 |
| 考点 | 十路的名字在 `015`–`019`，**屯在哪儿只在 `020` 这一段里**——两处拼起来才是这一篇的图 |

---

### 卡 9 · 一句话

**问：这一篇用一句话说，说什么？**

答：**他不是被敌人打败的，是被自己人放在那儿打的。**

十路兵，十几万人，摆在酸枣天天喝酒。他先讲了一遍：一战而天下定，不可失。没有人动。

他自己带兵往西，在汴水几乎死在那儿。回来一看，他们还在喝。他把每一步该怎么走又讲了一遍，落点是五个字：邈等不能用。

**那十几万人一直没动。** 后来他去扬州募兵，募来的兵又叛了；他收了一千多人，进屯河内。

| | |
|---|---|
| 依据 | `020`「太祖责让之，因为谋曰：『诸君听吾计……』」；`020`「邈等不能用」；`020`「遂引兵西」；`020`「荣见太祖所将兵少，力战尽日」；`021`「至铚、建平，复收兵得千余人，进屯河内」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的对手不止徐荣。**「邈等不能用」和「与战不利」，是同一件事的两头** |

---

### 卡 10 · 陷阱题 ⚠️

**问：他带了多少人去打？「五千人」是这一仗的数吗？**

答：**这一篇不回答，也不能拿五千来补。**

**说到他自己这一仗带了多少兵**，这七段里只有「太祖所将兵少」——一个数目都没有；死伤也只有「士卒死伤甚多」六个字。

「五千人」是他在陈留起兵时的人数，出自裴松之注引的《世语》，属于另一篇（见 `03-chenliu`）。他自己的令里另有一说：汴水这一仗只有数千（`266`，也不在这一篇的范围里）。**拿哪一条来填这一仗，都是替史料编一个它没在这一篇里给的数字。**

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 这一篇最容易混进来的是**别处的数字**。**这一仗他带了多少人，七段里一个数目都没有**——七段里另有「众各数万」（`020`）、「与兵四千余人」（`020`）、「复收兵得千余人」（`021`），都不是这一仗的兵；「十余万」**是酸枣那一边的** |

### 这一篇的难点

**七段原文里，说出口的话只有他一个人的。** 他本人的话只有 `020` 那两番；`019` 里另有一句张超的话（荐袁遗，「有冠世之懿，干时之量」），不是他说的。十路兵的名字是名单，徐荣和曹洪都只有一个动作，没有一句台词。

所以这一篇的卡不问台词，问三件事：**他讲的那一套为什么没有人听**、
**哪一处是史料不肯写的**，以及**两边的兵各自屯在哪儿**。

**上一版排倒了一个次序。** 旧卡把「酸枣摆酒」放在汴水之前，读起来是「他先去骂人，然后自己去打」；正文的次序正好相反——他先往西、先败、先跑回来，才发现那十几万人一直没动。**顺序错了，这一篇的意思就变了。**
