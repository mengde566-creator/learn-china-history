# 复习卡 · 场景 01 · 五色棒

> 原则：**问动机，不问年代。**
> 这一篇的题库里有一半是**出处题**——五色棒这件事，陈寿的正文里一个字都没有。

---

## 场景 01 · 五色棒（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机 ★

**问：一个二十岁的年轻人，为什么敢打死皇帝宠臣的叔父？**

答：**他先立了规矩，人是照着规矩打的。**

他到任先修门，再造五色棒，挂在衙门左右各十几根。棒子挂出来，就是一句写在门口的话：犯禁的，就在这儿打。

几个月后，蹇硕的叔父夜里出门。他打死了这个人。

`206` 把三件事排在一处：立棒、写下「不避豪强」、杀叔父。**中间不写他犹豫过。**

可「他当时怎么想的」，底本一个字不回答。上面那层意思是推出来的——底本给的是四个字和一个间隔：`206`「不避豪强」，`206`「后数月」。

| | |
|---|---|
| 依据 | `206`「造五色棒，县门左右各十余枚，有犯禁者，不避豪强，皆棒杀之」；`206`「后数月，灵帝爱幸小黄门蹇硕叔父夜行，即杀之」 |
| 标记 | ○ 合理推演 |
| 考点 | 记住**顺序**：规矩先立，人后打。敢不敢不是胆量问题——他把话挂在了门口 |

---

### 卡 2 · 出处题 ★

**问：五色棒这件事，写在哪一本书里？**

答：**写在裴松之的注里，注引的是《曹瞒传》。陈寿的正文里一个字都没有。**

正文写到洛阳这一段，只有一句：「年二十，举孝廉为郎，除洛阳北部尉，迁顿丘令，征拜议郎。」四个官职连排，棒子、杀人、「京师敛迹」，全不在里面。

所以这一篇的「原文」页签分两节：正文一段，注一段，**各挂各的书名**。

| | |
|---|---|
| 依据 | `006`「年二十，举孝廉为郎，除洛阳北部尉，迁…」（《武帝纪》正文）；`206`（裴松之注引《曹瞒传》） |
| 标记 | ◆ 出自原文 |
| 考点 | 同一页上有两支笔。**要能说出哪一句是陈寿写的，哪一句出自别人的书** |

---

### 卡 3 · 陷阱题 ⚠️

**问：曹操打死的，是蹇硕吗？**

答：**不是。是蹇硕的叔父。**

`206` 那一句很容易读错：「灵帝爱幸小黄门蹇硕叔父夜行」——得宠的是蹇硕，夜里出门的是他叔父。

蹇硕本人在这一段里一次都没有露面。他后来做了什么，底本也不写。

**陷阱在这儿**：读过之后记住的往往是「曹操打死了蹇硕」，而这一篇里最有力气报复他的那个人，一个字都没有留下。

| | |
|---|---|
| 依据 | `206`「灵帝爱幸小黄门蹇硕叔父夜行，即杀之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 谁在得宠、谁的叔父、谁没有出面——三件事一件都不能混 |

---

### 卡 4 · 开放题 ★

**问：「共称荐之，故迁为顿丘令」——这是升，还是降？**

答：**史书不回答。**

`206` 的结尾是：皇帝身边的人恨他，动不了他，于是一起荐举他，于是他调任顿丘令。

「荐举」是个好字眼，「迁」也是个偏好的字。可就凭这几个字，判不出这是明升还是暗降。`006` 把「迁顿丘令」和前面的「除洛阳北部尉」排在同一串里，同样不加一字。

**这一问留在「—」里是有意的**：不是产品不知道，是**史书不知道**。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 同一个调动可以有三种读法：升、降、挪开。原文只留下一个「迁」字 |

---

### 卡 5 · 因果

**问：「京师敛迹，莫敢犯者」是怎么来的？**

答：**一个人被打死，一座城收了手。**

`206` 的次序是：造棒、立规矩、杀叔父、京师敛迹。四件事一句接一句，中间没有一句解释。

值得盯住的是前面那半句——**「不避豪强」**。洛阳是都城，犯禁的人背后多半站着人；他先把这四个字写进规矩里，再动手。

至于「收手」是怕他，还是怕他立的那套规矩，底本不写。

| | |
|---|---|
| 依据 | `206`「有犯禁者，不避豪强，皆棒杀之」；`206`「京师敛迹，莫敢犯者」 |
| 标记 | ○ 合理推演 |
| 考点 | 这一篇真正的主角是**规矩**，不是那一棒 |

---

### 卡 6 · 人物

**问：皇帝身边的人恨他，为什么动不了他？**

答：**因为挨打的那个人，犯的禁是真的。**

`206` 只有一句：「近习宠臣咸疾之，然不能伤。」恨写在底本里，动不了也写在底本里；**为什么动不了**，底本不写。

推得出来的一层是：人是照着他到任就立下的规矩打的，而那条规矩挂在门口，谁都看见过。

他们最后用的办法是荐举他——`206`「于是共称荐之」。这是底本里唯一记下的一次反击，它到底算不算反击，底本不说。

| | |
|---|---|
| 依据 | `206`「近习宠臣咸疾之，然不能伤」；`206`「于是共称荐之，故迁为顿丘令」 |
| 标记 | ○ 合理推演 |
| 考点 | 恨和动不了是两层。**底本只给了结果，没给原因**——这正是「迁顿丘令」判不出升降的原因 |

---

### 卡 7 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**一个词，和一个空白。**

`206` 写「后数月」——立棒和打死人之间隔了几个月，没给数目。

`006` 把洛阳北部尉、顿丘令、议郎连排，一年也不写；`008` 的济南相与前面之间，同样没有任何时间。

「174 年」是后人换算出来的，三段原文里没有一个公元纪年，这一类数字属于外证。

所以这一篇排得出来的次序只有一条：**立棒 → 数月 → 打死人 → 京师敛迹 → 那些人荐举他 → 迁顿丘令。** 之外的长度，一律不知道。

| | |
|---|---|
| 依据 | `206`「后数月」；`006` 与 `008` 均无系年；174 年为后世换算，属外证 |
| 标记 | ○ 外证 |
| 考点 | 这一篇的时间只有两个刻度：**几个月**，和**没有** |

---

### 卡 8 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**二十岁，他立了五色棒，打死的是皇帝宠臣的叔父；规矩立住了，人走了。**

洛阳那一头收在「京师敛迹，莫敢犯者」，济南那一头收在「郡界肃然」。两段出自两支笔，落点却几乎一样。

同一套办法，他用了两回：洛阳打的是犯禁的人，济南罢的是贪赃的官。

**他赢了自己立下的那条规矩，然后被那条规矩送走了。**

| | |
|---|---|
| 依据 | `206`「京师敛迹，莫敢犯者」；`206`「于是共称荐之，故迁为顿丘令」；`008`「郡界肃然」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的转折不是打死了谁，是**打死了之后他被荐举出去** |

### 这一篇的难点

**三段原文里，被人说出口的话一句都没有。** `006` 是官名连排，`008` 是记事，`206` 是旁白。

所以这一篇的卡不问台词，只问两件事：**这件事在哪本书里**，和**哪一处是史书不肯说的**。
