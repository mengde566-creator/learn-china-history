# 复习卡 · 场景 01 · 五色棒

> 原则：**先问这一句写在哪本书里，再问他为什么敢。**
> 这一篇的题库里有**出处题**——五色棒这件事，陈寿的正文里一个字都没有；
> 他丢官、上书、回家读书，又都在裴松之注引的《魏书》里。

---

## 场景 01 · 五色棒（13 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 出处题 ★

**问：五色棒这件事，写在哪一本书里？**

答：**写在裴松之的注里，注引的是《曹瞒传》。陈寿的正文里一个字都没有。**

正文写到洛阳这一任，只有一句：「年二十，举孝廉为郎，除洛阳北部尉，迁顿丘令。」官名连排，棒子、打死人、「京师敛迹」，全不在里面。

这两处都摊在「原文」页签上：正文六段、注四段，**各挂各的书名**。

| | |
|---|---|
| 依据 | `006`「年二十，举孝廉为郎，除洛阳北部尉，迁顿丘令」（《武帝纪》正文）；`206`（裴松之注引《曹瞒传》） |
| 标记 | ◆ 出自原文 |
| 考点 | 同一页上有两支笔。**要能说出哪一句是陈寿写的，哪一句出自别人的书** |

---

### 卡 2 · 人物题 ★

**问：他年少的时候，谁看好他？**

答：**两个人：梁国的桥玄、南阳的何颙。**

`004` 的落点是「故世人未之奇也」——那时候没有人觉得他有什么出奇。紧接着 `005` 开口就是「惟梁国桥玄、南阳何颙异焉」：**「惟」是只有**。

桥玄还对他说了一句话：「天下将乱，非命世之才不能济也，能安之者，其在君乎！」

**旁人不觉得他出众，桥玄与何颙却另眼相看。**桥玄留下了这句话，何颙在这一段里没有发言。

| | |
|---|---|
| 依据 | `004`「故世人未之奇也」；`005`「惟梁国桥玄、南阳何颙异焉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这两段连起来才是这一篇的开头。**「未之奇」和「异焉」是同一件事的两面** |

---

### 卡 3 · 动机 ★

**问：棒杀蹇硕叔父之前，曹操怎样执行禁令？**

答：**《曹瞒传》先记设棒、惩治犯禁，再记数月后棒杀蹇硕叔父。**

`206` 写在官署门旁悬挂五色棒，有犯禁者，不避豪强，皆棒杀之。数月后，蹇硕叔父夜行，也被杀。

这是注引书对执行禁令的叙述，没有写他在门口张贴“不避豪强”的文字，也没有注明棒杀时恰好二十岁。二十岁是正文举孝廉的年龄；数月的先后可知，具体到任与执法日期不详。

| | |
|---|---|
| 依据 | `006`「年二十」；`206` 设棒、犯禁与「后数月」 |
| 标记 | ◆ 出自原文 |
| 考点 | 执行禁令有记载，不添告示文字或锁死事件年龄 |

---

### 卡 4 · 陷阱题 ⚠️

**问：曹操打死的，是蹇硕吗？**

答：**不是。是蹇硕的叔父。**

`206` 那一句很容易读错：「灵帝爱幸小黄门蹇硕叔父夜行」——得宠的是蹇硕，夜里出门的是他叔父。

蹇硕本人在这十段里一次都没有露面。他后来做了什么，这几段也不写。

**陷阱在这儿**：读过之后记住的往往是「曹操打死了蹇硕」，而这一篇里最有力气报复他的那个人，一个字都没有留下。

| | |
|---|---|
| 依据 | `206`「灵帝爱幸小黄门蹇硕叔父夜行，即杀之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 谁在得宠、谁的叔父、谁没有出面——三件事一件都不能混 |

---

### 卡 5 · 因果

**问：「京师敛迹，莫敢犯者」接在哪件事之后？**

答：**《曹瞒传》把它接在棒杀蹇硕叔父之后，写京师中人收敛、不敢犯禁。**

前面已写惩处犯禁者不避豪强，后面又记近习宠臣恨他、转而共同荐举。可以顺着这条线读出严厉执法带来的震慑与反弹；这不等于全城每个人的心情都已记录，也不是门口确有一篇告示。

| | |
|---|---|
| 依据 | `206`「京师敛迹，莫敢犯者」「近习宠臣咸疾之」 |
| 标记 | ○ 合理推演 |
| 考点 | 把记载的效果与编者概括区分 |

---

### 卡 6 · 开放题 ★

**问：共同荐举他的人，为什么反而恨他？**

答：**《曹瞒传》明记近习宠臣恨他，却不能加害，于是共同荐举，随后迁顿丘令。**

这条记载已给出荐举与厌恶相连的经过，不能说排挤的意味全无。至于两个职位的秩级、任职权力怎样比较，不能只凭“迁”字把这次调任直接判作降职。

| | |
|---|---|
| 依据 | `206`「近习宠臣咸疾之，然不能伤，于是共称荐之，故迁为顿丘令」；`006`「迁顿丘令」 |
| 标记 | ◆ 出自原文 |
| 考点 | 调任的叙述背景与官阶升降，是两个问题 |

---

### 卡 7 · 人物题

**问：他丢过官吗？丢在谁身上？**

答：**丢过。丢在一个亲戚身上。**

`207`：「太祖从妹夫强侯宋奇被诛，从坐免官。后以能明古学，复征拜议郎。」

宋奇是他的从妹夫，爵位是强侯。宋奇被诛，他连坐免官。后来凭「能明古学」这一条，又被征为议郎。

**免的是哪个官，这一句不说**；宋奇为什么被诛，也不说。

| | |
|---|---|
| 依据 | `207`「太祖从妹夫强侯宋奇被诛，从坐免官。后以能明古学，复征拜议郎」 |
| 标记 | ◆ 出自原文 |
| 考点 | **「复」字是回来的路**：他能明古学，凭这一条又进了朝 |

---

### 卡 8 · 人物题

**问：他复起之后，替谁说过话？灵帝听了吗？**

答：**替窦武、陈蕃。灵帝不能用。**

`207`：先前大将军窦武、太傅陈蕃谋划诛除宦官，反被他们害了。他上书，陈述窦武等人正直却被陷害，奸邪盈朝，善人壅塞——「其言甚切；灵帝不能用」。

后来因为灾异，他又上书切谏，说三公的举奏专意回避贵戚。这一回「天子感悟」，那些因谣言被征的人都拜为议郎。

| | |
|---|---|
| 依据 | `207`「先是大将军窦武、太傅陈蕃谋诛阉官，反为所害」「太祖上书陈武等正直而见陷害，奸邪盈朝，善人壅塞，其言甚切；灵帝不能用」「奏上，天子感悟，以示三府责让之，诸以谣言征者皆拜议郎」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两次上书，两种结果。**第一次「不能用」，第二次「天子感悟」——收尾却是「遂不复献言」** |

---

### 卡 9 · 因果

**问：第二次上书以后，他为什么不再献言？**

答：**注引《魏书》明写：政教日乱，他知道不能匡正，于是不再献言。**

前一次“天子感悟”与此后的“政教日乱”并不矛盾：一次奏疏获回应，没有保证朝政从此改好。这里已有叙述者给出的判断，不能把“不再献言”的理由全说成后人推测。此后的称疾、归乡另有相应记载，也不必全部压成同一时刻。

| | |
|---|---|
| 依据 | `207`「太祖知不可匡正，遂不复献言」；`009`、`209` |
| 标记 | ◆ 出自原文 |
| 考点 | 一次上书的回应与后来局势的变化分开读 |

### 卡 10 · 数字题 ★

**问：济南的祠，有多少座？**

答：**六百多座。**

`008` 写济南相这一任，只有「禁断淫祀」四个字；数目在后面——`208`：「青州诸郡转相仿效，济南尤盛，至六百余祠。」

这些祠的来路也在这里：城阳景王刘章有功于汉，他的封国给他立祠，青州各郡转相仿效。祠多起来以后，「贾人或假二千石舆服导从作倡乐，奢侈日甚，民坐贫穷，历世长吏无敢禁绝者」。

他到了：「太祖到，皆毁坏祠屋，止绝官吏民不得祠祀。」

| | |
|---|---|
| 依据 | `208`「青州诸郡转相仿效，济南尤盛，至六百余祠」「贾人或假二千石舆服导从作倡乐，奢侈日甚，民坐贫穷，历世长吏无敢禁绝者」「太祖到，皆毁坏祠屋，止绝官吏民不得祠祀」 |
| 标记 | ◆ 出自原文 |
| 考点 | **「禁断淫祀」四个字的实景是六百多座祠**——四个字和一堆数字，是同一件事的两头 |

---

### 卡 11 · 对照题

**问：洛阳严惩犯禁者与济南整顿长吏，怎样对照？**

答：**两处都记严厉整顿及其效果，出处和具体行动不同。**

洛阳一事见裴注引《曹瞒传》，记犯禁不避豪强、京师敛迹；济南一事见《武帝纪》正文，记长吏依附贵戚、贪赃污秽，因此奏免八人，禁断淫祀，郡界肃然。

罢免的总体理由并非没有写。没有逐一列出的，是八人的姓名、每一人的案情及选择细目；不能把缺少名单说成完全不知道为什么罢免。

| | |
|---|---|
| 依据 | `206`；`008`「长吏多阿附贵戚，赃污狼藉，于是奏免其八」；`208` |
| 标记 | ○ 合理推演 |
| 考点 | 对照制度行动，不抹掉正文已经说明的缘由 |

---

### 卡 12 · 收尾题 ★

**问：这一篇的最后一屏，是什么？**

答：**一个「不就」，和一座城外的屋子。**

`009`：「久之，征还为东郡太守；不就，称疾归乡里。」——朝廷征他回去做东郡太守，他没有就，称病回了乡里。

**为什么不就，这一句不说。** `209` 把这一步接上：「太祖不能违道取容。数数干忤，恐为家祸，遂乞留宿卫」「筑室城外，春夏习读书传，秋冬弋猎，以自娱乐」。

立规矩、打人、被荐出去、丢官、上书、不再献言，最后是一个「不就」——**他回家读书去了**。

| | |
|---|---|
| 依据 | `009`「久之，征还为东郡太守；不就，称疾归乡里」；`209`「筑室城外，春夏习读书传，秋冬弋猎，以自娱乐」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇不结束在「郡界肃然」上，结束在**城外那间屋子**里 |

### 卡 13 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**有年龄、年号和相对间隔；各任职的精确日期并不齐全。**

`006` 给了「年二十」——他二十岁举孝廉，这是年龄，单凭它定不了公元年份。`206` 给了「后数月」——立棒和打死人之间隔了几个月，没给数目。

`008` 另有「光和末，黄巾起」，可据汉朝年号换算为公元184年。其余任职转换多按先后排列：`006`、`007` 连排官名，`009` 用「久之」，各步相隔多久不详。

「174 年」是后人换算出来的，十段原文里没有一个公元纪年，这一类数字属于外证。

所以这一篇排得出来的次序只有一条：正文从少年、举孝廉、洛阳北部尉、顿丘令、议郎接到济南与不就归乡。注另补立棒数月后棒杀，以及宋奇被诛连坐免官、复征议郎等经过。两层按出处接读，不把两次议郎压成同一次。

**次序排得出，不等于每两件事之间隔多久都知道。** 约174年须结合 `110` 建安二十五年卒、年六十六，按传统虚岁回推生年，再算二十岁所在之年。它不是 `006` 直接写出的年代，也不能把后面的棒杀、迁官一并定在那一年。

| | |
|---|---|
| 依据 | `006` 年二十；`008` 光和末；`206` 后数月；`009` 久之；`110` 建安二十五年卒、年六十六。公元纪年为换算 |
| 标记 | ○ 外证 |
| 考点 | 分清年龄、年号、相对间隔与公元换算 |

### 这一篇的难点

**十段原文里，被人说出口的话只有一句：桥玄那句「能安之者，其在君乎」（`005`）。** 蹇硕的叔父那一晚的「夜行」（`206`）是旁白里带出来的，不算说话。

所以这一篇的卡不问台词，只问三件事：**这件事在哪一本书里**（正文还是注）、**哪一处是史书不肯说的**（升还是降、为什么敢、为什么不去），和**六百多座祠是怎么变成四个字的**。
