# 复习卡 · 场景 01 · 五色棒

> 原则：**先问这一句写在哪本书里，再问他为什么敢。**
> 这一篇的题库里有一半是**出处题**——五色棒这件事，陈寿的正文里一个字都没有；
> 他丢官、上书、回家读书，又都在裴松之注引的《魏书》里。

---

## 场景 01 · 五色棒（13 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 出处题 ★

**问：五色棒这件事，写在哪一本书里？**

答：**写在裴松之的注里，注引的是《曹瞒传》。陈寿的正文里一个字都没有。**

正文写到洛阳这一任，只有一句：「年二十，举孝廉为郎，除洛阳北部尉，迁顿丘令。」官名连排，棒子、打死人、「京师敛迹」，全不在里面。

这两处都摊在「原文」页签上：正文六段、注四段，**各挂各的书名**。

| | |
|---|---|
| 依据 | `006`「年二十，举孝廉为郎，除洛阳北部尉，迁顿丘令」（《武帝纪》正文）；`206`（裴松之注引《曹瞒传》） |
| 标记 | ◆ 出自原文 |
| 考点 | 同一页上有两支笔。**要能说出哪一句是陈寿写的，哪一句出自别人的书** |

---

### 卡 2 · 人物题 ★

**问：他年少的时候，谁看好他？**

答：**两个人：梁国的桥玄、南阳的何颙。**

`004` 的落点是「故世人未之奇也」——那时候没有人觉得他有什么出奇。紧接着 `005` 开口就是「惟梁国桥玄、南阳何颙异焉」：**「惟」是只有**。

桥玄还对他说了一句话：「天下将乱，非命世之才不能济也，能安之者，其在君乎！」

这一篇的第一屏就是这两句：**没人看好他，只有一个人看好他。**

| | |
|---|---|
| 依据 | `004`「故世人未之奇也」；`005`「惟梁国桥玄、南阳何颙异焉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这两段连起来才是这一篇的开头。**「未之奇」和「异焉」是同一件事的两面** |

---

### 卡 3 · 动机 ★

**问：一个二十岁的年轻人，为什么敢打死皇帝宠臣的叔父？**

答：**他先立了规矩，人是照着规矩打的。**

他到任先修门，再造五色棒，挂在衙门左右各十几根。棒子挂出来，就是一句写在门口的话：犯禁的，就在这儿打。

几个月后，蹇硕的叔父夜里出门。他打死了这个人。

`206` 把三件事排在一处：立棒、写下「不避豪强」、杀叔父。**中间不写他犹豫过。**

可**他当时怎么想的**，这一段一个字不回答。上面那层意思是推出来的——底本给的是四个字和一个间隔：`206`「不避豪强」，`206`「后数月」。

| | |
|---|---|
| 依据 | `206`「造五色棒，县门左右各十余枚，有犯禁者，不避豪强，皆棒杀之」「后数月，灵帝爱幸小黄门蹇硕叔父夜行，即杀之」 |
| 标记 | ○ 合理推演 |
| 考点 | 记住**顺序**：规矩先立，人后打。敢不敢不是胆量问题——他把话挂在了门口 |

---

### 卡 4 · 陷阱题 ⚠️

**问：曹操打死的，是蹇硕吗？**

答：**不是。是蹇硕的叔父。**

`206` 那一句很容易读错：「灵帝爱幸小黄门蹇硕叔父夜行」——得宠的是蹇硕，夜里出门的是他叔父。

蹇硕本人在这十段里一次都没有露面。他后来做了什么，这几段也不写。

**陷阱在这儿**：读过之后记住的往往是「曹操打死了蹇硕」，而这一篇里最有力气报复他的那个人，一个字都没有留下。

| | |
|---|---|
| 依据 | `206`「灵帝爱幸小黄门蹇硕叔父夜行，即杀之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 谁在得宠、谁的叔父、谁没有出面——三件事一件都不能混 |

---

### 卡 5 · 因果

**问：「京师敛迹，莫敢犯者」是怎么来的？**

答：**一个人被打死，一座城收了手。**

`206` 的次序是：造棒、立规矩、杀叔父、京师敛迹。四件事一句接一句，中间没有一句解释。

值得盯住的是前面那半句——**「不避豪强」**。洛阳是都城，犯禁的人背后多半站着人；他先把这四个字写进规矩里，再动手。

至于「收手」是怕他，还是怕他立的那套规矩，这几段里没有。

| | |
|---|---|
| 依据 | `206`「有犯禁者，不避豪强，皆棒杀之」「京师敛迹，莫敢犯者」 |
| 标记 | ○ 合理推演 |
| 考点 | 这一篇真正的主角是**规矩**，不是那一棒 |

---

### 卡 6 · 开放题 ★

**问：「共称荐之，故迁为顿丘令」——这是升，还是降？**

答：**史书不回答。**

`206` 的结尾是：皇帝身边的人恨他，动不了他，于是一起荐举他，于是他调任顿丘令。

「荐举」是个好字眼，「迁」也是个偏好的字。可就凭这几个字，判不出这是明升还是暗降。`006` 把「迁顿丘令」和前面的「除洛阳北部尉」排在同一串里，同样不加一字。

**这一问留在「—」里是有意的**：不是这里不知道，是**史书不知道**。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 同一个调动可以有三种读法：升、降、挪开。原文只留下一个「迁」字 |

### 卡 7 · 人物题

**问：他丢过官吗？丢在谁身上？**

答：**丢过。丢在一个亲戚身上。**

`207`：「太祖从妹夫强侯宋奇被诛，从坐免官。后以能明古学，复征拜议郎。」

宋奇是他的从妹夫，爵位是强侯。宋奇被诛，他连坐免官。后来凭「能明古学」这一条，又被征为议郎。

**免的是哪个官，这一句不说**；宋奇为什么被诛，也不说。

| | |
|---|---|
| 依据 | `207`「太祖从妹夫强侯宋奇被诛，从坐免官。后以能明古学，复征拜议郎」 |
| 标记 | ◆ 出自原文 |
| 考点 | **「复」字是回来的路**：他能明古学，凭这一条又进了朝 |

---

### 卡 8 · 人物题

**问：他复起之后，替谁说过话？灵帝听了吗？**

答：**替窦武、陈蕃。灵帝不能用。**

`207`：先前大将军窦武、太傅陈蕃谋划诛除宦官，反被他们害了。他上书，陈述窦武等人正直却被陷害，奸邪盈朝，善人壅塞——「其言甚切；灵帝不能用」。

后来因为灾异，他又上书切谏，说三公的举奏专意回避贵戚。这一回「天子感悟」，那些因谣言被征的人都拜为议郎。

| | |
|---|---|
| 依据 | `207`「先是大将军窦武、太傅陈蕃谋诛阉官，反为所害」「太祖上书陈武等正直而见陷害，奸邪盈朝，善人壅塞，其言甚切；灵帝不能用」「奏上，天子感悟，以示三府责让之，诸以谣言征者皆拜议郎」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两次上书，两种结果。**第一次「不能用」，第二次「天子感悟」——收尾却是「遂不复献言」** |

---

### 卡 9 · 因果

**问：第二次上书成了，他为什么不再说了？**

答：**因为他知道匡正不了。**

`207` 的收尾是：「是后政教日乱，豪猾益炽，多所摧毁；太祖知不可匡正，遂不复献言。」

「天子感悟」是真的，「政教日乱」也是真的。两句话紧挨着，这几段不解释它们怎么能并排——**「说了没用」这一层是读出来的**。

这一篇里他此后的动作，是一连串的退：`009`「不就，称疾归乡里」，`209`「常讬疾病，辄告归乡里」，最后是「筑室城外」。

| | |
|---|---|
| 依据 | `207`「太祖知不可匡正，遂不复献言」；`009`「不就，称疾归乡里」；`209`「常讬疾病，辄告归乡里」「筑室城外」 |
| 标记 | ○ 合理推演 |
| 考点 | 「感悟」是那一次的结果，**「不复献言」是他对下一次的判断** |

### 卡 10 · 数字题 ★

**问：济南的祠，有多少座？**

答：**六百多座。**

`008` 写济南相这一任，只有「禁断淫祀」四个字；数目在后面——`208`：「青州诸郡转相仿效，济南尤盛，至六百余祠。」

这些祠的来路也在这里：城阳景王刘章有功于汉，他的封国给他立祠，青州各郡转相仿效。祠多起来以后，「贾人或假二千石舆服导从作倡乐，奢侈日甚，民坐贫穷，历世长吏无敢禁绝者」。

他到了：「太祖到，皆毁坏祠屋，止绝官吏民不得祠祀。」

| | |
|---|---|
| 依据 | `208`「青州诸郡转相仿效，济南尤盛，至六百余祠」「贾人或假二千石舆服导从作倡乐，奢侈日甚，民坐贫穷，历世长吏无敢禁绝者」「太祖到，皆毁坏祠屋，止绝官吏民不得祠祀」 |
| 标记 | ◆ 出自原文 |
| 考点 | **「禁断淫祀」四个字的实景是六百多座祠**——四个字和一堆数字，是同一件事的两头 |

---

### 卡 11 · 对照题

**问：洛阳打的是人，济南罢的是官、拆的是祠——这是同一件事吗？**

答：**同一套办法：到了一个地方，先立规矩，再把不合规矩的清掉。**

洛阳那一头收在「京师敛迹，莫敢犯者」，济南那一头收在「郡界肃然」——**两段的落点几乎一样**，写的人却不是同一个：`008` 是陈寿的正文，`206` 是裴松之注引的《曹瞒传》。

济南还有一层洛阳没有的：`208` 说那些长吏「历前相不见举」，`008` 说「奏免其八」——**八个是数目，为什么恰好是这八个，这几段里没有。**

| | |
|---|---|
| 依据 | `206`「京师敛迹，莫敢犯者」；`008`「郡界肃然」「奏免其八」；`208`「历前相不见举」 |
| 标记 | ○ 合理推演 |
| 考点 | **两处落点几乎一样，底本出自两支笔**——不要以为它们是同一本书里的一段 |

---

### 卡 12 · 收尾题 ★

**问：这一篇的最后一屏，是什么？**

答：**一个「不就」，和一座城外的屋子。**

`009`：「久之，征还为东郡太守；不就，称疾归乡里。」——朝廷征他回去做东郡太守，他没有就，称病回了乡里。

**为什么不就，这一句不说。** `209` 把这一步接上：「太祖不能违道取容。数数干忤，恐为家祸，遂乞留宿卫」「筑室城外，春夏习读书传，秋冬弋猎，以自娱乐」。

立规矩、打人、被荐出去、丢官、上书、不再献言，最后是一个「不就」——**他回家读书去了**。

| | |
|---|---|
| 依据 | `009`「久之，征还为东郡太守；不就，称疾归乡里」；`209`「筑室城外，春夏习读书传，秋冬弋猎，以自娱乐」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇不结束在「郡界肃然」上，结束在**城外那间屋子**里 |

---

### 卡 13 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**两个词，和几段空白。**

`006` 给了「年二十」——他二十岁举孝廉，这是全篇唯一能定年的刻度。`206` 给了「后数月」——立棒和打死人之间隔了几个月，没给数目。

此外全是空白：`006` 和 `007` 把洛阳北部尉、顿丘令、议郎连排，一年也不写；`008` 的济南相与前面之间，同样没有任何时间；`009` 只有一个「久之」。

「174 年」是后人换算出来的，十段原文里没有一个公元纪年，这一类数字属于外证。

所以这一篇排得出来的次序只有一条：**少年 → 二十岁 → 立棒 → 数月 → 打死人 → 京师敛迹 → 荐举 → 迁顿丘令 → 议郎 → 免官 → 上书 → 济南 → 不就 → 归乡里。** 之外的长度，一律不知道。

| | |
|---|---|
| 依据 | `006`「年二十」；`206`「后数月」；`009`「久之」；174 年为后世换算，属外证 |
| 标记 | ○ 外证 |
| 考点 | 这一篇的时间只有两个刻度：**「年二十」和「后数月」**，其余都是空白 |

### 这一篇的难点

**十段原文里，被人说出口的话只有两句。** 一句是桥玄那句「能安之者，其在君乎」（`005`），一句是蹇硕的叔父那一晚的「夜行」（`206`）——后者还是旁白里带出来的。

所以这一篇的卡不问台词，只问三件事：**这件事在哪一本书里**（正文还是注）、**哪一处是史书不肯说的**（升还是降、为什么敢、为什么不去），和**六百多座祠是怎么变成四个字的**。
