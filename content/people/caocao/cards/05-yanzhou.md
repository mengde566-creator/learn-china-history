# 复习卡 · 场景 05 · 领兖州

> 原则：**先看清那个动词，再问这块地盘是怎么来的。**
> 这一篇用四段原文：`023`–`026`。**他被迎上兖州牧这一步，一仗都没有打**；
> 前面那一段里，他倒是真带兵进过东郡（`023`「引兵入东郡」）。

---

## 场景 05 · 领兖州（12 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 陷阱题 ⚠️

**问：领兖州牧与打平兖州，是同一步吗？**

答：**不是。刘岱死后，鲍信与州吏迎曹操领州；迎任后还要面对黄巾与后来的争夺。**

`026` 先记迎领，随即进兵寿张东，鲍信战死，曹操仅而破之。这不是一场攻取州牧职位的战争，却也不等于全州已经不战而定。

| | |
|---|---|
| 依据 | `025`–`026` |
| 标记 | ◆ 出自原文 |
| 考点 | 任职的来路与控制地方的战事分清 |

---

### 卡 2 · 对照题 ★

**问：东郡太守和兖州牧，这两个位子的来路有什么不一样？**

答：**一个是「表」，一个是「迎」。**

`023` 给的是：「袁绍因表太祖为东郡太守，治东武阳。」——**谁举的、举的是什么官，都写在字面上，做这件事的人是袁绍。**

`026` 给的是：「信乃与州吏万潜等至东郡迎太祖领兖州牧。」——**只有两个动词：迎，领。**

**同一个人的两块地盘，底本用了两种写法。** 前一处给了程序，后一处只给了动作——差的那一截，就是这一篇最要紧的空白。

| | |
|---|---|
| 依据 | `023`「袁绍因表太祖为东郡太守」；`026`「迎太祖领兖州牧」 |
| 标记 | ◆ 出自原文 |
| 考点 | **表 vs 迎。** 读这两句要问同一件事：这块地盘是谁给的、按什么规矩给的 |

---

### 卡 3 · 补读 ★

**问：州中为什么选择曹操？注里还有什么说明？**

答：**正文记鲍信、万潜等迎领；裴注引《世语》另记陈宫游说州中。**

`225` 陈宫以州无主、王命断绝为由，建议曹操往牧；向别驾、治中称曹操有命世之才，迎来可安生民，鲍信等也认可。

这是一条注引别书的解释，不能冒作正文原话，也不能还原每位州吏未说出的私心；但不能再说全无具名者、选择曹操的理由一点也没有。

| | |
|---|---|
| 依据 | `026`；跨篇补充 `225` 裴注引《世语》 |
| 标记 | ◆ 出自原文 |
| 考点 | 正文有迎任主体，注有游说及理由，各归出处 |

---

### 卡 4 · 出处题

**问：刘岱的兖州刺史身份，是否只是读者猜的？**

答：**不是。《武帝纪》前文起兵名册已明写“兖州刺史刘岱”。**

本篇`025`沿用他的名字，没有重写官职。接上`017`便能核明身份；不必因为眼前几句省略官衔，就把身份降成无据推测。

| | |
|---|---|
| 依据 | `025`；跨篇补充 `017`「兖州刺史刘岱」 |
| 标记 | ◆ 出自原文 |
| 考点 | 当篇省称与前文已交代，是两回事 |

---

### 卡 5 · 人物

**问：鲍信在这几段里做了几件事？**

答：**三件，件件都落在这块地盘上。**

一件是**拦**：他拦住要出兵的刘岱，把一套完整的办法说了一遍——先固守，等贼散，再挑精锐、占要害。刘岱不听，出去打了，果然被杀（`025`）。

一件是**迎**：刘岱一死，他和州吏万潜等人到东郡去迎曹操（`026`）。

一件是**死**：迎来的那个人领了兖州，进兵寿张东，**「信力战斗死，仅而破之」**（`026`）。

**劝不住的那个人死了，他去把曹操请了来；随后他在这次寿张东战斗中死去。**

| | |
|---|---|
| 依据 | `025`「鲍信谏曰」「岱不从，遂与战，果为所杀」；`026`「信乃与州吏万潜等至东郡迎太祖」「信力战斗死，仅而破之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三件事串起来是一个圈：**谏、迎、死**。迎任后紧接战事，鲍信战死，不写成拿生命交换职位 |

---

### 卡 6 · 因果

**问：刘岱为什么死？**

答：**他不听鲍信先守待机的建议，出战而被杀。**

鲍信说的是：贼人多、百姓吓住了、兵没有斗志，正面打不过。可他们一伙一伙跟着走，军中没有辎重，全靠抢东西过日子——鲍信判断久之会散开。到那时候再挑精锐、占住要害，一击就能破（`025`）。

刘岱出去打了。这几段用一句收掉他：跟对方交战，果然被杀。

**「果」是写史的人的口气。** 它不是鲍信的预言，是结果出来之后回头加的一个字。

| | |
|---|---|
| 依据 | `025`「观贼众群辈相随，军无辎重，唯以钞略为资」「其势必离散」「后选精锐，据其要害，击之可破也」「岱不从，遂与战，果为所杀」 |
| 标记 | ○ 合理推演 |
| 考点 | 这几段里唯一成段的判断是鲍信的。**判断在前，人在后死**——这就是「果」字的分量 |

### 卡 7 · 时间线

**问：这一篇的时间给了几个刻度？**

答：**`023` 的二年春、夏四月、秋七月、三年春，加 `025` 的夏四月。**

- `023`「二年春」——绍、馥立虞为帝那一年；黑山贼入东郡、他做东郡太守也在这一年
- `023`「夏四月」——董卓回到长安
- `023`「秋七月」——袁绍胁韩馥，取冀州
- `023`「三年春」——他驻顿丘，于毒来攻东武阳
- `025`「夏四月」——王允和吕布杀董卓

**这几段里没有一个公元年份。** **公元 191、192 年**是后人拿年号排出来的坐标，属外证。

| | |
|---|---|
| 依据 | `023`「二年春」「夏四月」「秋七月」「三年春」、`025`「夏四月」。**公元 191、192 年是后世系年，这几段无公元纪年，属外证** |
| 标记 | ○ 外证 |
| 考点 | 底本给的是**年号和月份**；让读者有坐标的是外面那一层。两样不能混着记 |

---

### 卡 8 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**一个州没了主人，而曹操是被叫去的。**

朝廷那边自己杀成一团（`025` 开头三句）；黑山贼打进东郡，他带兵进去打了一仗，袁绍表他做东郡太守——曹操已有东郡太守的任职；然后青州黄巾一百万人进了兖州，刘岱不听劝，出去打，死了；州里的人到东郡，把他迎了来。

迎任本身不是攻下州牧职位——上一任出去打，死了；州里的人把他请了来。

| | |
|---|---|
| 依据 | `023`「袁绍因表太祖为东郡太守」；`025`「青州黄巾众百万入兖州」「岱不从，遂与战，果为所杀」；`026`「信乃与州吏万潜等至东郡迎太祖领兖州牧」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的转折不是一场胜仗，是**一句话：迎太祖领兖州牧**。而它后面跟着的那一句，是别人战死 |

---

### 卡 9 · 收尾题 ★

**问：把他迎来的鲍信，后来怎样了？**

答：**在寿张东力战而死。正文还记寻不到他的遗体，众人刻木像祭哭。**

`026` 记迎领与战死；后续`027`接“购求信丧不得，众乃刻木如信形状，祭而哭焉”。这句是《武帝纪》正文，不应包进《魏书》注文。

任职在前，战死在后，不能把两步写成以鲍信的命换来州牧之位。

| | |
|---|---|
| 依据 | `026`；跨篇补充 `027` 寻尸与刻木祭哭 |
| 标记 | ◆ 出自原文 |
| 考点 | 记住迎领者的后续，不虚构生命与官位的交易 |

---

### 卡 10 · 地名题

**问：他做太守的治所，和州里来迎他的地方，是不是同一个？**

答：**同一个郡：东郡；治所在东武阳。**

`023`「袁绍因表太祖为东郡太守，治东武阳。」

`026`「信乃与州吏万潜等至东郡迎太祖领兖州牧。」

**州里的人往东郡去找他，不是偶然**：那是他做太守的郡。这几段只给地名，不给理由。

| | |
|---|---|
| 依据 | `023`「治东武阳」；`026`「至东郡迎太祖」——**两处都是东郡**；"不是偶然"这一步是读出来的 |
| 标记 | ○ 合理推演 |
| 考点 | **东郡是这一篇的枢纽**：他先在那里站住，州里的人又到那里去请他 |

---

### 卡 11 · 朝廷题

**问：朝廷失序与州中迎任，怎样接读？**

答：**正文并记长安失序与兖州危局；注引《世语》又明说陈宫以“王命断绝”游说。**

王允参与杀董卓，后来王允被杀、吕布败逃、李傕等擅政；不能说两位杀董卓者都已被杀。兖州则是黄巾进入、刘岱战死，州中另迎曹操。

这些材料帮助理解迎任背景，却不等于只凭长安那三句就能证明朝廷与地方每一项法定程序怎样失效。

| | |
|---|---|
| 依据 | `025`–`026`；`225` 裴注引《世语》 |
| 标记 | ○ 合理推演 |
| 考点 | 分清正文并叙、注中人物说明与制度推断 |

---

### 卡 12 · 出处题 ⚠️

**问：开头那些公元年份，是从哪儿来的？**

答：**是后人加的坐标，不是这几段里的字。**

这一篇用了四段原文：`023`–`026`，《三国志·魏书·武帝纪》正文。本篇据史传选录，没有采用小说段落；这不等于断言小说全未讲这一段经历。

这几段里没有公元纪年，只有 `023` 的「二年春」「夏四月」「秋七月」「三年春」和 `025` 的「夏四月」这样的时间字。公元年份需换算；东郡太守、兖州牧等官衔已在本篇文字中——它们标成 **○ 外证**，意思是：不在这段文字里，别拿它去核这段文字。

| | |
|---|---|
| 依据 | 本篇原文范围 `023`–`026`（《武帝纪》正文）；公元年份为后世系年，属外证 |
| 标记 | ○ 外证 |
| 考点 | 底本给的是**一段记事**；让读者有坐标的是外面那一层。两样不能混着记 |

### 这一篇的难点

**这一篇里，被迎的人一句话都没有说。** 四段原文里唯一成段的话是鲍信的谏词（`025`），其余全是记事：刘岱的死是一句话，寿张东是九个字。

所以这一篇的卡只问四件事：**那个动词是迎还是取**、**东郡和兖州这两个位子的来路差在哪儿**、**哪一处是这几段不肯写的**、**把他迎来的那个人后来怎么了**。
