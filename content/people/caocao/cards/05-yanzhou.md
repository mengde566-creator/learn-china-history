# 复习卡 · 场景 05 · 领兖州

> 原则：**先看清「迎」这个字，再问为什么。**
> 这一篇的题库里有两道**沉默题**——谁举的他、按什么程序，底本只用一个字交代完。

---

## 场景 05 · 领兖州（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 陷阱题 ⚠️

**问：曹操的兖州，是他打下来的吗？**

答：**不是。这一段里的第一个动作是「迎」。**

`025` 的末句写着：迎他的是鲍信和州吏万潜，地点是东郡。

| | |
|---|---|
| 谁去迎 | 鲍信，和州吏万潜等 |
| 在哪儿迎 | 东郡 |
| 迎他去做什么 | 领兖州牧 |

**「迎」和「取」是两个字。** 这一段里他一次仗都没有打，动手的是刘岱，死的是刘岱。他打黄巾，是下一段的事，不在这一篇里。

| | |
|---|---|
| 依据 | `025–026`、「信乃与州吏万潜等至东郡迎太祖领兖州牧」；同段「刘岱欲击之」「遂与战，果为所杀」 |
| 标记 | ◆ 出自原文 |
| 考点 | 记住那个动词：**迎**。默认的印象是"他打下一块地盘"，这一段给的却是"他被叫去接一块地盘" |

---

### 卡 2 · 出处题 ★

**问：迎立这一段里，刘岱的官职写了吗？**

答：**没有。这一段从头到尾只叫他「刘岱」，最后叫了一声「岱」。**

他守的是兖州——这是读者从上下文推出来的：贼进的是兖州，他出兵去打，他死后兖州没了主人。可**这一段一个字都没交代他的官职**。

兖州的长官是谁、官名叫什么，这一段不回答。

| | |
|---|---|
| 依据 | `025` 两处都只有名字：「刘岱欲击之」「岱不从」。官职与州名，这一段不载 |
| 标记 | ◆ 出自原文 |
| 考点 | **名字在，身份不在。** 读史书要先分清"这一段写了什么"和"我从别处知道什么" |

---

### 卡 3 · 人物

**问：鲍信在这一段里做了两件事。他是什么人？**

答：**先谏刘岱，后迎曹操。** 两件事他都是主动的那一方。

他拦住要出兵的刘岱，把一套完整的办法说了一遍：先守住，等贼散，再挑精锐、占要害。刘岱不听，出去打了，果然被杀。**接下来去找曹操的，正是他。**

可这一段只给了他一个名字。**他当时是什么官、为什么是他去，这一段都不写。**

| | |
|---|---|
| 依据 | `026`、「鲍信谏曰」；「信乃与州吏万潜等至东郡迎太祖领兖州牧」。**他具体任何职，这一段不载** |
| 标记 | ◆ 出自原文 |
| 考点 | 这两件事隔着一场败仗。**劝不住的那个人死了，劝的人活了，然后他去把曹操请了来** |

---

### 卡 4 · 因果

**问：刘岱为什么死？**

答：**因为他没有听那套办法。**

鲍信说的是：贼人多、百姓吓住了、兵没有斗志，正面打不过。可他们一伙一伙跟着走，军中没有辎重，全靠抢东西过日子——**日子一久必然散开**。到那时候再挑精锐、占住要害，一击就能破。

刘岱出去打了。底本用一句收掉他：跟对方交战，果然被杀。

**「果」是写史的人的口气。** 它不是鲍信的预言，是结果出来之后回头加的一个字。

| | |
|---|---|
| 依据 | `025`「观贼众群辈相随，军无辎重，唯以钞略为资」「其势必离散」「后选精锐，据其要害，击之可破也」「岱不从，遂与战，果为所杀」 |
| 标记 | ○ 合理推演 |
| 考点 | 这一段里唯一成段的判断是鲍信的。**判断在前，人在后死**——这就是「果」字的分量 |

---

### 卡 5 · 开放题 ★

**问：曹操为什么肯来接兖州？**

答：**史书不回答这个问题。**

`025` 从「迎」直接到「领」，中间一句话都没有。他推辞过没有、提过条件没有、心里愿意不愿意——这一段一个字不写。

**这是这一篇最要紧的一处沉默。** 读者最想问的就是这一句，而底本给的只有两个动词：迎，领。

**把它留在「—」里是有意的**：不是没有答案，是**这一段没有答案**。想知道举他那一边怎么想，只能去问鲍信；他本人那一头，空着。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 两道沉默题里的第一道。**知道自己不知道什么，和知道答案一样重要** |

---

### 卡 6 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**一个都没有。**

`025` 这一段里没有年号、没有月份、没有「后数月」这类间隔。三件事是连排的：

- 青州黄巾入兖州，杀任城相郑遂，转入东平
- 刘岱出兵，战死
- 鲍信与州吏万潜等到东郡，迎曹操领兖州牧

**中间隔了多久，底本一个字不写。**

「公元 192 年」是后人拿年号排出来的，这一段里没有它——所以那个年份标「○ 外证」，不标 ◆。

| | |
|---|---|
| 依据 | `025` 全段无年份、无月份。**公元 192 年是后世系年，底本无公元纪年，属外证** |
| 标记 | ○ 外证 |
| 考点 | 这一段的时间只有**顺序**：贼来、人死、他被迎。长度一律不知道 |

---

### 卡 7 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**一个州没了主人，而曹操是被叫去的。**

贼有一百万人，进了兖州；兖州的守臣不听劝，出去打，死了；州里的人到东郡，把他迎了来。

他接下的就是这块地方。**这一段里他没打一仗，却从此有了一块自己的地盘。**

| | |
|---|---|
| 依据 | `025–026`、「青州黄巾众百万入兖州」；「岱不从，遂与战，果为所杀」；「信乃与州吏万潜等至东郡迎太祖领兖州牧」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的转折不是一场胜仗，是**一句话：迎太祖领兖州牧** |

---

### 卡 8 · 出处题 ⚠️

**问：开头那些公元年份，是从哪儿来的？**

答：**是后人加的坐标，不是原文里的字。**

这一篇只有一段原文：`025`，《三国志·魏书·武帝纪》正文。演义不写这件事，所以这一段里没有一条出自小说。

底本里没有公元纪年。**年份、官衔这类东西，是从这一段外面加进来的**——产品把它们标成「○ 外证」，意思是：它不在原文里，别拿它去核原文。

| | |
|---|---|
| 依据 | 本篇原文范围只有 `025`（《武帝纪》正文）；公元年份为后世系年，属外证 |
| 标记 | ◆ 出自原文 |
| 考点 | 底本给的是**一段记事**；让读者有坐标的是外面那一层。两样不能混着记 |

### 这一篇的难点

**这一段里，被迎的人一句话都没有说。** 唯一成段的台词是鲍信的谏词，其余全是记事。

所以这一篇的卡只问三件事：**那个动词是迎还是取**、**哪一处是这一段不肯写的**、**哪几个数字是从外面加进来的**。
