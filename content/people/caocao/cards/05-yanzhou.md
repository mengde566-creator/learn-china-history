# 复习卡 · 场景 05 · 领兖州

> 原则：**先看清那个动词，再问这块地盘是怎么来的。**
> 这一篇用四段原文：`023`–`026`。**他被迎上兖州牧这一步，一仗都没有打**；
> 前面那一段里，他倒是真带兵进过东郡（`023`「引兵入东郡」）。

---

## 场景 05 · 领兖州（12 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 陷阱题 ⚠️

**问：曹操的兖州，是他打下来的吗？**

答：**不是。这一步的动词是「迎」。**

`026` 写着：鲍信和州吏万潜等人，到东郡去迎他领兖州牧。

| | |
|---|---|
| 谁去迎 | 鲍信，和州吏万潜等 |
| 在哪儿迎 | 东郡 |
| 迎他去做什么 | 领兖州牧 |

**「迎」和「取」是两个字。** 他带兵进东郡是打进去的（`023`「引兵入东郡，击白绕于濮阳，破之」），可兖州不是——**州里的人把他请了来，而这块地方是别人打烂的**。

| | |
|---|---|
| 依据 | `023`、`026`——「引兵入东郡，击白绕于濮阳，破之」；「信乃与州吏万潜等至东郡迎太祖领兖州牧」 |
| 标记 | ◆ 出自原文 |
| 考点 | 记住那个动词：**迎**。默认的印象是"他打下一块地盘"，这几段给的却是"他被叫去接一块地盘"。**他真打进去的是东郡，可东郡太守那个位子也不是打来的，是袁绍表的** |

---

### 卡 2 · 对照题 ★

**问：东郡太守和兖州牧，这两个位子的来路有什么不一样？**

答：**一个是「表」，一个是「迎」。**

`023` 给的是：「袁绍因表太祖为东郡太守，治东武阳。」——**谁举的、举的是什么官，都写在字面上，做这件事的人是袁绍。**

`026` 给的是：「信乃与州吏万潜等至东郡迎太祖领兖州牧。」——**只有两个动词：迎，领。**

**同一个人的两块地盘，底本用了两种写法。** 前一处给了程序，后一处只给了动作——差的那一截，就是这一篇最要紧的空白。

| | |
|---|---|
| 依据 | `023`「袁绍因表太祖为东郡太守」；`026`「迎太祖领兖州牧」 |
| 标记 | ◆ 出自原文 |
| 考点 | **表 vs 迎。** 读这两句要问同一件事：这块地盘是谁给的、按什么规矩给的 |

---

### 卡 3 · 沉默题 ★

**问：他凭什么被挑中？**

答：**这几段不回答。**

`026` 从「迎」直接到「领」，中间不留一个字：没有策书，没有具名的人，也没有一句他本人的话。

补进来的 `023` 让这处空白更清楚：**东郡那一次是有程序的（「袁绍因表」），兖州这一次只有一个「迎」。**

**把它留在「—」里是有意的**：不是没有答案，是**这几段没有答案**。想知道举他那一边怎么想，只能去问鲍信；他本人那一头，空着。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 这一篇最要紧的一张。**知道自己不知道什么，和知道答案一样重要** |

---

### 卡 4 · 出处题

**问：这几段里，刘岱的官职写了吗？**

答：**没有。这几段只叫他「刘岱」，最后叫了一声「岱」。**

他守的是兖州——这是读者从上下文推出来的：贼进的是兖州，他出兵去打，他死后州里的人到东郡迎曹操。可**这几段一个字都没交代他的官职**。

| | |
|---|---|
| 依据 | `025` 两处都只有名字：「刘岱欲击之」「岱不从」。官职与州名，这一段不载 |
| 标记 | ◆ 出自原文 |
| 考点 | **名字在，身份不在。** 读史书要先分清"这几段写了什么"和"我从别处知道什么" |

---

### 卡 5 · 人物

**问：鲍信在这几段里做了几件事？**

答：**三件，件件都落在这块地盘上。**

一件是**拦**：他拦住要出兵的刘岱，把一套完整的办法说了一遍——先固守，等贼散，再挑精锐、占要害。刘岱不听，出去打了，果然被杀（`025`）。

一件是**迎**：刘岱一死，他和州吏万潜等人到东郡去迎曹操（`026`）。

一件是**死**：迎来的那个人领了兖州，进兵寿张东，**「信力战斗死，仅而破之」**（`026`）。

**劝不住的那个人死了，他去把曹操请了来；然后他死在替这块地盘打的第一仗里。**

| | |
|---|---|
| 依据 | `025`「鲍信谏曰」「岱不从，遂与战，果为所杀」；`026`「信乃与州吏万潜等至东郡迎太祖」「信力战斗死，仅而破之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三件事串起来是一个圈：**谏、迎、死**。他迎来的那个人，收下了他的命 |

---

### 卡 6 · 因果

**问：刘岱为什么死？**

答：**因为他没有听那套办法。**

鲍信说的是：贼人多、百姓吓住了、兵没有斗志，正面打不过。可他们一伙一伙跟着走，军中没有辎重，全靠抢东西过日子——**日子一久必然散开**。到那时候再挑精锐、占住要害，一击就能破（`025`）。

刘岱出去打了。这几段用一句收掉他：跟对方交战，果然被杀。

**「果」是写史的人的口气。** 它不是鲍信的预言，是结果出来之后回头加的一个字。

| | |
|---|---|
| 依据 | `025`「观贼众群辈相随，军无辎重，唯以钞略为资」「其势必离散」「后选精锐，据其要害，击之可破也」「岱不从，遂与战，果为所杀」 |
| 标记 | ○ 合理推演 |
| 考点 | 这几段里唯一成段的判断是鲍信的。**判断在前，人在后死**——这就是「果」字的分量 |

---

### 卡 7 · 时间线

**问：这一篇的时间给了几个刻度？**

答：**`023` 的二年春、夏四月、秋七月、三年春，加 `025` 的夏四月。**

- `023`「二年春」——绍、馥立虞为帝那一年；黑山贼入东郡、他做东郡太守也在这一年
- `023`「夏四月」——董卓回到长安
- `023`「秋七月」——袁绍胁韩馥，取冀州
- `023`「三年春」——他驻顿丘，于毒来攻东武阳
- `025`「夏四月」——王允和吕布杀董卓

**这几段里没有一个公元年份。** **公元 191、192 年**是后人拿年号排出来的坐标，属外证。

| | |
|---|---|
| 依据 | `023`「二年春」「夏四月」「秋七月」「三年春」、`025`「夏四月」。**公元 191、192 年是后世系年，这几段无公元纪年，属外证** |
| 标记 | ○ 外证 |
| 考点 | 底本给的是**年号和月份**；让读者有坐标的是外面那一层。两样不能混着记 |

---

### 卡 8 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**一个州没了主人，而曹操是被叫去的。**

朝廷那边自己杀成一团（`025` 开头三句）；黑山贼打进东郡，他带兵进去打了一仗，袁绍表他做东郡太守——**这是他名下的第一块地方**；然后青州黄巾一百万人进了兖州，刘岱不听劝，出去打，死了；州里的人到东郡，把他迎了来。

**他领下这个州的时候，一仗都没有打**——上一任出去打，死了；州里的人把他请了来。

| | |
|---|---|
| 依据 | `023`「袁绍因表太祖为东郡太守」；`025`「青州黄巾众百万入兖州」「岱不从，遂与战，果为所杀」；`026`「信乃与州吏万潜等至东郡迎太祖领兖州牧」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的转折不是一场胜仗，是**一句话：迎太祖领兖州牧**。而它后面跟着的那一句，是别人战死 |

---

### 卡 9 · 收尾题 ★

**问：把他迎来的那个人，后来怎么样了？**

答：**死在他领兖州之后的第一仗里。**

`026` 的两句紧挨着：「信乃与州吏万潜等至东郡迎太祖领兖州牧。」「遂进兵击黄巾于寿张东。信力战斗死，仅而破之。」

**来迎的是「信」，死在寿张东的也是「信」**——中间只隔一句。

| | |
|---|---|
| 依据 | `026`「信乃与州吏万潜等至东郡迎太祖」「信力战斗死，仅而破之」——**两句里是同一个「信」** |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇收在这里：**他领到的那块地方，是拿鲍信的命换来的**。迎立那一步是喜事，底下垫着一条命 |

---

### 卡 10 · 地名题

**问：他做太守的治所，和州里来迎他的地方，是不是同一个？**

答：**同一个郡：东郡；治所在东武阳。**

`023`「袁绍因表太祖为东郡太守，治东武阳。」

`026`「信乃与州吏万潜等至东郡迎太祖领兖州牧。」

**州里的人往东郡去找他，不是偶然**：那是他做太守的郡。这几段只给地名，不给理由。

| | |
|---|---|
| 依据 | `023`「治东武阳」；`026`「至东郡迎太祖」——**两处都是东郡**；"不是偶然"这一步是读出来的 |
| 标记 | ○ 合理推演 |
| 考点 | **东郡是这一篇的枢纽**：他先在那里站住，州里的人又到那里去请他 |

---

### 卡 11 · 朝廷题

**问：开头那三句写的是长安，跟兖州有什么关系？**

答：**这几段一个字都不点这层关系，可它是这一篇的根。**

`025` 的开头三句：司徒王允与吕布共杀卓 → 卓将李傕、郭汜等杀允攻布，布败，东出武关 → 傕等擅朝政。

**杀董卓的人，被董卓的部将杀了；朝政落到李傕手里。** 从这儿往下，一直到州里的人到东郡迎曹操，**这几段里没有一句朝廷出面管过兖州**。

| | |
|---|---|
| 依据 | `025`「司徒王允与吕布共杀卓」「卓将李傕、郭汜等杀允攻布，布败，东出武关」「傕等擅朝政」。**顾不上兖州**这一层是把这三句的次序读出来的，那三句自己不点 |
| 标记 | ○ 合理推演 |
| 考点 | 朝廷这条线不落在兖州任何一个地名上。**「迎」这个字的来路，在这里** |

---

### 卡 12 · 出处题 ⚠️

**问：开头那些公元年份，是从哪儿来的？**

答：**是后人加的坐标，不是这几段里的字。**

这一篇用了四段原文：`023`–`026`，《三国志·魏书·武帝纪》正文。演义不写这件事，所以这一篇里没有一条出自小说。

这几段里没有公元纪年，只有 `023` 的「二年春」「夏四月」「秋七月」「三年春」和 `025` 的「夏四月」这样的时间字。**年份、官衔这类东西，是从这几段外面加进来的**——它们标成 **○ 外证**，意思是：不在这段文字里，别拿它去核这段文字。

| | |
|---|---|
| 依据 | 本篇原文范围 `023`–`026`（《武帝纪》正文）；公元年份为后世系年，属外证 |
| 标记 | ○ 外证 |
| 考点 | 底本给的是**一段记事**；让读者有坐标的是外面那一层。两样不能混着记 |

### 这一篇的难点

**这一篇里，被迎的人一句话都没有说。** 四段原文里唯一成段的话是鲍信的谏词（`025`），其余全是记事：刘岱的死是一句话，寿张东是九个字。

所以这一篇的卡只问四件事：**那个动词是迎还是取**、**东郡和兖州这两个位子的来路差在哪儿**、**哪一处是这几段不肯写的**、**把他迎来的那个人后来怎么了**。
