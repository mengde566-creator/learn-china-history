# 复习卡 · 场景 09 · 赤壁

> 原则：**先问这句话出自哪本书，再问谁烧的船。**
> 这一篇的题库有**出处题**——正史里的赤壁只有二十二个字；
> 退兵那一条路、他唯一一次当面开口，都在裴松之注引的《山阳公载记》里。

---

## 场景 09 · 赤壁（11 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 出处题 ★

**问：赤壁那一场火，烧了曹操的船。放火的人是谁？**

答：**最眼熟的那一说是黄盖的火船——那是《三国演义》里的。别的书里还有两说，方向彼此相反。**

| 出处 | 说 |
|---|---|
| 《三国演义》第四十九回 | 黄盖的火船撞进水寨，曹军的船全着了（`405`） |
| 裴松之注引《山阳公载记》 | 「公船舰为备所烧」——**刘备烧的**（`265`） |
| 《吴书·吴主传》 | 曹操自己给孙权写信说「孤烧船自退，横使周瑜虚获此名」——**是他自己烧的** |

**《武帝纪》正文 `065` 一个都不说。** 它只有「与备战，不利。于是大疫，吏士多死者，乃引军还」——没有船，没有火，没有风。

| | |
|---|---|
| 依据 | `065`「公至赤壁，与备战，不利。于是大疫，吏士多死者，乃引军还」——**正文里没有火，也没有船**；演义那一段见卡 5，另两说见 `265` 与《吴书·吴主传》 |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 内部 | 三种说法的并置，系统层另有一问专门交代。这张卡只要求记住**方向相反、而且都不在正文里**；收进 `265` 之后，第二种说法落到了编号上 |
| 考点 | 一个问题，三种方向相反的记载。要知道它们**各自出自哪一本书**，而不是只记住「火烧赤壁」 |

### 卡 2 · 数字题 ★

**问：赤壁这一仗，正文一共给了多少字？**

答：**二十二个汉字。**

「公至赤壁，与备战，不利。于是大疫，吏士多死者，乃引军还。」

从到赤壁，到引军还，就这一句。**其中说交战的只有九个字**：「公至赤壁，与备战，不利。」

| | |
|---|---|
| 依据 | `065`「公至赤壁，与备战，不利。于是大疫，吏士多死者，乃引军还」——**二十二个汉字，说交战的九个** |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的体量感从这里来：**一场决定天下三分的仗，正文给了二十二个字** |

---

### 卡 3 · 因果 ★

**问：曹操退兵，是因为「不利」，还是因为大疫？**

答：**底本把两件事并排写在一句里，哪一个是主要原因，它不说。**

`065` 的次序是：与备战、不利、于是大疫、吏士多死者、乃引军还。**「于是」把疫接在不利后面，可它不点因果。**

后世讲这一仗，有的重战败，有的重疾病，各执一端。

| | |
|---|---|
| 依据 | `065`「公至赤壁，与备战，不利。于是大疫，吏士多死者，乃引军还」——不利与大疫并列在一句里，谁主谁次，底本不点 |
| 标记 | △ 史书未载，后世有争议 |
| 考点 | 这一篇最容易替古人作答的地方。**两件事并排写，不等于有因果** |

---

### 卡 4 · 陷阱题 ⚠️

**问：这一仗，正文用哪两个字记它？**

答：**「不利」。**

`065` 全篇没有「败」，也没有「走」——写他退兵，用的是「乃引军还」。

**先说清记的是哪两个字，再谈它是不是避讳。** 把「不利」读成不肯认输，是读出来的判断：`065` 只记这两个字，不记他当时怎么想。

| | |
|---|---|
| 依据 | `065`「公至赤壁，与备战，不利」——**全篇没有「败」字**；用「不利」是不是有意避讳，底本不写 |
| 标记 | ○ 合理推演 |
| 考点 | 一场改写历史的败仗，正文里只有「不利」两个字。**先看清它写的是什么，再谈它为什么这么写** |

### 卡 5 · 出处题 ★

**问：演义那一段，写了哪些正文里没有的东西？**

答：**船的数量、船的处境、火的样子——三样都是演义给的。**

| 演义给的 | 那一句 |
|---|---|
| 船的数量 | 「二十只火船，撞入水寨」 |
| 船的处境 | 「又被铁环销住，无处逃避」 |
| 火的样子 | 「但见三江面上，火逐风飞，一派通红，漫天彻地」 |

`065` 里这三样一样都没有。**这三句引文，让赤壁在读者心里变成了另一件事。**

| | |
|---|---|
| 依据 | `405`「二十只火船，撞入水寨。曹寨中船只一时尽着；又被铁环销住，无处逃避……但见三江面上，火逐风飞，一派通红，漫天彻地」（《三国演义》第四十九回） |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 内部 | 「黄盖」这个名字**不在 `405` 这一段里**，它在这一回别的文字里；卡 1 的表格说的是整回，这张卡说的是裁进来的这一段 |
| 考点 | 同一件事，两本书的分工很清楚：**正文给结果，演义给场面。** 要能说出场面里的哪一句是演义新加的 |

### 卡 6 · 人物题

**问：这一篇里，荆州是怎么换的主人的？**

答：**八月刘表死，九月曹操到新野，刘琮就降了。**

「八月，表卒，其子琮代，屯襄阳，刘备屯樊。」「九月，公到新野，琮遂降，备走夏口。」

**接手和交出去写在两句里，中间没有一场仗。** 刘备没有被抓住，他往夏口走了。

| | |
|---|---|
| 依据 | `064`「八月，表卒，其子琮代，屯襄阳，刘备屯樊」「九月，公到新野，琮遂降，备走夏口」 |
| 标记 | ◆ 出自原文 |
| 考点 | **他这一路是走下来的**：七月出发、八月表卒、九月受降——「琮遂降」的「遂」是紧接着 |

### 卡 7 · 人物题

**问：进了江陵之后，他做了哪三件事？**

答：**一道令、一份功次、一批人。**

| 做的事 | 原文 |
|---|---|
| 一道令 | 「下令荆州吏民，与之更始」 |
| 一份功次 | 「乃论荆州服从之功，侯者十五人」 |
| 一批人 | 「以刘表大将文聘为江夏太守，使统本兵，引用荆州名士韩嵩、邓义等」 |

**「使统本兵」是其中最实的一笔**：降将不解兵，还带自己原来的队伍。

| | |
|---|---|
| 依据 | `064`「公进军江陵，下令荆州吏民，与之更始。乃论荆州服从之功，侯者十五人，以刘表大将文聘为江夏太守，使统本兵，引用荆州名士韩嵩、邓义等」 |
| 标记 | ◆ 出自原文 |
| 考点 | 收一个州，用的是这一套安排，不是接着追人。**「引用」两个字，是他这一路唯一一件与打仗无关的动作** |

### 卡 8 · 地名题

**问：退兵走的是哪条路？**

答：**华容道。**

正文只有「乃引军还」四个字；路在裴松之注引的《山阳公载记》里。

「公船舰为备所烧，引军从华容道步归，遇泥泞，道不通，天又大风，悉使羸兵负草填之，骑乃得过。」

**骑兵过得去，是因为羸兵背着草填了路——陷在泥里的也是他们。**

| | |
|---|---|
| 依据 | `265`「引军从华容道步归，遇泥泞，道不通，天又大风，悉使羸兵负草填之，骑乃得过。羸兵为人马所蹈藉，陷泥中，死者甚众」；`065`「乃引军还」 |
| 标记 | ◆ 出自原文 |
| 内部 | 这一段出自**注**（裴松之注引《山阳公载记》），不是陈寿正文——◆ 的这一档含注，书名跟着编号一起显示 |
| 考点 | 正文一笔带过的那四个字，注里有一整段路：**泥、风、草、陷在泥里的人** |

### 卡 9 · 收尾题

**问：赤壁之后他回到谯，第一件事做的是什么？下的那道令又说了什么？**

答：**第一件事是作轻舟、治水军；那道令说的是死在疫里的吏士。**

「十四年春三月，军至谯，作轻舟，治水军。」

「自顷已来，军数征行，或遇疫气，吏士死亡不归，家室怨旷，百姓流离，而仁者岂乐之哉？不得已也。其令死者家无基业不能自存者，县官勿绝廪，长吏存恤抚循，以称吾意。」

**同一年，他置扬州郡县长吏，开芍陂屯田。**

| | |
|---|---|
| 依据 | `066`「作轻舟，治水军」「辛未，令曰：『自顷已来，军数征行，或遇疫气，吏士死亡不归，家室怨旷，百姓流离』……」「置扬州郡县长吏，开芍陂屯田」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的收尾不在赤壁：**练水军、抚恤死在疫里的人家、开屯田**，三件事都在 `066` 里 |

### 卡 10 · 时间线

**问：这一篇跨了多久？**

答：**从建安十三年的秋七月，到十四年的十二月。**

`064` 从「秋七月」起头；`065` 里有「十二月」；`066` 从「十四年春三月」接到「十二月，军还谯」。**这一年半里，赤壁只占其中一句。**

「建安十三年」和「公元 208 年」都是后世系年——**这几段里一个年号、一个公元纪年都没有。**

| | |
|---|---|
| 依据 | `064`「秋七月」；`065`「十二月」；`066`「十四年春三月」「十二月，军还谯」——**公元 208 年与 209 年为后世换算，属外证** |
| 标记 | ○ 外证 |
| 考点 | 底本不给公元年份。看到年份先分清：**这是原文里的，还是外面加进来的坐标** |

---

### 卡 11 · 沉默题

**问：这一篇里，最要紧的沉默是哪几处？**

答：**四处：因何退兵、死了多少人、赤壁在哪儿、刘琮为什么降。**

一是**因何退兵**——`065` 把「不利」和「大疫」并排写，不点因果；二是**死了多少人**——只有「吏士多死者」，没有数；三是**赤壁在哪儿**——只有两个字地名；四是**刘琮为什么降**——只有「琮遂降」三个字。

四处都在映射表里标着「—」。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 四处沉默：**因何退兵、死了多少、在哪儿、为什么降**——这几段把动作写全了，理由一个不给 |

### 这一篇的难点

**五段原文里，被人说出口的话只有两处。** `065` 是记事，`405` 是场面——场面里有动作，没有对话，**连放火的人名都不在里面**。

话在两处：一处是 `265` 里败退路上那句「刘备，吾俦也」；一处是 `066` 那道令。**两处都在正文之外**（注、以及正文后半），而且两处都是他自己说的。

所以这一篇的卡只问四件事：**这件事在哪本书里**、**那二十二个字写的是什么**、**他这一路赢得多容易**、**他回去之后做了什么**。
