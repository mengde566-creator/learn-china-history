# 复习卡 · 场景 09 · 赤壁

> 原则：**先问这句话出自哪本书，再问谁烧的船。**
> 这一篇比较《武帝纪》《周瑜传》正文与裴注引书；小说场面另列。
> 先把交战、献策和退兵的行动读清，再分辨各处出处。

---

## 场景 09 · 赤壁（11 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 出处题 ★

**问：黄盖火攻与曹操烧船自退，各见哪一处史料？**

答：**《周瑜传》正文记黄盖火攻；曹操自称烧船撤退的书信，见该传裴注引《江表传》。**

| 出处 | 说 |
|---|---|
| 《周瑜传》正文（`113`、`114`） | 黄盖提出火攻，备火船诈降，放船纵火，曹军败退 |
| 《周瑜传》裴注引《江表传》（`312`） | 另记火攻的十艘船、东南风等细节 |
| 《周瑜传》另一处裴注引《江表传》（`313`） | 转述曹操致孙权书信，自称烧船自退；信里没有“余船”二字 |
| 《吴主传》正文（外证） | 记曹军被击破后，曹操烧其余船撤退 |
| 裴注引《山阳公载记》（`265`） | 记曹操船舰为刘备所烧 |

《武帝纪》这一段只概述交战不利、大疫与撤军，没有展开船与火的经过；黄盖火攻的具体记述在《周瑜传》正文。

| | |
|---|---|
| 依据 | `065`（《武帝纪》正文）；`113`、`114`（《周瑜传》正文）；`312`、`313`（该传两处裴注引《江表传》）；`265`（裴注引《山阳公载记》）；烧余船见《吴主传》正文（外证） |
| 标记 | ◆ 出自原文 |
| 考点 | 分清陈寿正文、裴注引书、转述的书信，以及不同记载各自说了什么 |

### 卡 2 · 概述题 ★

**问：《武帝纪》怎样概述赤壁交战与退军？**

答：**交战不利，继以大疫、吏士多死，曹操引军还。**

这段从“公至赤壁”到“乃引军还”共二十二个汉字，写交战的部分尤其简短。简短的是《武帝纪》这一处概述，不是所有史书给赤壁的全部文字；《周瑜传》另有较详叙述。

| | |
|---|---|
| 依据 | `065`「公至赤壁，与备战，不利。于是大疫，吏士多死者，乃引军还」；`113`–`114` |
| 标记 | ◆ 出自原文 |
| 考点 | 认识记述重心的差别，不把一传的短写当作整段历史只有这些材料 |

---

### 卡 3 · 因果 ★

**问：战事不利与疾病，材料怎样放在退兵之前？**

答：**《武帝纪》先记交战不利，再记大疫、吏士多死，随后引军还；不是完全没有退兵背景。**

另一处《周瑜传》`113`在初次交战前便说曹军已有疾病，接着记初战败退。两传叙述重心和顺序不同，不能只凭“于是”就断言疾病一定战后才开始，也不能据这几句量出战败、火攻与疾病各占多少原因。

| | |
|---|---|
| 依据 | `065`；`113`《周瑜传》已有疾病与初战败退 |
| 标记 | ○ 合理推演 |
| 考点 | 保留退兵背景，比较两传而不强排唯一主因 |

---

### 卡 4 · 用词比较

**问：《武帝纪》与《周瑜传》怎样写曹军的失利？**

答：**《武帝纪》用“不利”概述；《周瑜传》明确记初战败退及火攻后的败退。**

两处都是《三国志》正文。不能只看《武帝纪》这一句便说“史书正文没有败退”；也不能凭用词较轻，就认定作者或曹操必然在故意掩饰。

| | |
|---|---|
| 依据 | `065`「与备战，不利」；`113`「初一交战，公军败退」；`114`「军遂败退，还保南郡」 |
| 标记 | ○ 合理推演 |
| 考点 | 限定所比较的传与句子，先读其所记，再评价笔法 |

### 卡 5 · 出处题 ★

**问：史传的火攻与所引小说场面，怎样区分？**

答：**火攻并非小说独有；铁环锁船、二十只火船等具体写法属于所引小说段落。**

《周瑜传》正文写黄盖献策，备数十艘船，先报诈降，再放船纵火，延烧岸营。《江表传》下注另说十艘轻利舰、东南风。

所引《三国演义》写二十只火船、铁环销住船只、隔江炮响及漫天大火。读小说可看它怎样铺写场面，不能把这些细节一并当作史传原话。

| | |
|---|---|
| 依据 | `113`、`114`（《周瑜传》正文）；`312`（裴注引《江表传》）；`405`（《三国演义》第四十九回） |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 考点 | 同有火攻，不等于船数、风向与场面细节完全相同 |

### 卡 6 · 人物题

**问：这一篇里，荆州是怎么换的主人的？**

答：**八月刘表死，九月曹操到新野，刘琮就降了。**

「八月，表卒，其子琮代，屯襄阳，刘备屯樊。」「九月，公到新野，琮遂降，备走夏口。」

**这段《武帝纪》以刘琮投降、刘备退走、曹操进江陵概括进程，没有展开其中战事。** 刘备没有被抓住，他往夏口走了。

| | |
|---|---|
| 依据 | `064`「八月，表卒，其子琮代，屯襄阳，刘备屯樊」「九月，公到新野，琮遂降，备走夏口」 |
| 标记 | ◆ 出自原文 |
| 考点 | 本纪按月份接写七月出发、八月表卒、九月受降；「遂」连接到新野与刘琮投降，不证明其间绝无交涉或其他行动。选段没有展开全部战事 |
| 内部 | 这一段只说《武帝纪》`064` 的概括。刘琮投降，与曹军在荆州一路没有交战，是两回事：《三国志·曹纯传》记他从征荆州，追刘备于长阪，获其二女辎重，收其散卒，随后进降江陵。长阪之战不在本篇范围内，但**不能用这一段摘录的空白把它排除掉** |

### 卡 7 · 人物题

**问：进了江陵之后，他做了哪三件事？**

答：**一道令、一份功次、一批人。**

| 做的事 | 原文 |
|---|---|
| 一道令 | 「下令荆州吏民，与之更始」 |
| 一份功次 | 「乃论荆州服从之功，侯者十五人」 |
| 一批人 | 「以刘表大将文聘为江夏太守，使统本兵，引用荆州名士韩嵩、邓义等」 |

**「使统本兵」是其中最实的一笔**：降将不解兵，还带自己原来的队伍。

| | |
|---|---|
| 依据 | `064`「公进军江陵，下令荆州吏民，与之更始。乃论荆州服从之功，侯者十五人，以刘表大将文聘为江夏太守，使统本兵，引用荆州名士韩嵩、邓义等」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一段还写下令更始、论功封侯与任用旧部，不能只把「引用」说成唯一非战斗行动 |

### 卡 8 · 地名题

**问：退兵走的是哪条路？**

答：**华容道。**

正文只有「乃引军还」四个字；路在裴松之注引的《山阳公载记》里。

「公船舰为备所烧，引军从华容道步归，遇泥泞，道不通，天又大风，悉使羸兵负草填之，骑乃得过。」

**骑兵过得去，是因为羸兵背着草填了路——陷在泥里的也是他们。**

| | |
|---|---|
| 依据 | `265`「引军从华容道步归，遇泥泞，道不通，天又大风，悉使羸兵负草填之，骑乃得过。羸兵为人马所蹈藉，陷泥中，死者甚众」；`065`「乃引军还」 |
| 标记 | ◆ 出自原文 |
| 内部 | 这一段出自**注**（裴松之注引《山阳公载记》），不是陈寿正文——◆ 的这一档含注，书名跟着编号一起显示 |
| 考点 | 正文一笔带过的那四个字，注里有一整段路：**泥、风、草、陷在泥里的人** |

### 卡 9 · 收尾题

**问：退兵之后，回谯与合肥的安排怎样接着读？**

答：**建安十四年三月回谯造轻舟、治水军；七月军至合肥、发布抚恤令；其后置长吏、开屯田，十二月再回谯。**

抚恤令追述近来屡次征行与疫气，要求对死者家中无基业、不能自存的继续给廪食、存问抚恤。它不是三月一回谯便在当地发布的令，也不能把受恤者缩成只在赤壁一战死亡的人。

| | |
|---|---|
| 依据 | `066` 三月军至谯、七月军合肥与辛未令、十二月军还谯 |
| 标记 | ◆ 出自原文 |
| 考点 | 日期、地点和令中所指范围分清，恢复战争后的持续安排 |

### 卡 10 · 时间线

**问：这一篇跨了多久？**

答：**从建安十三年的秋七月，到十四年的十二月。**

`064` 从「秋七月」起头；`065` 里有「十二月」；`066` 从「十四年春三月」接到「十二月，军还谯」。**这一年半里，赤壁只占其中一句。**

建安年号是接本纪前文的纪年，`063`已有十三年，`066`续十四年，并非后人新造。换成208、209年才是公元换算。另须注意，完整编号`066`末尾还续十五年求贤令与铜雀台；本篇主线叙到十四年，不等于该编号全文也到此为止。

| | |
|---|---|
| 依据 | `064`「秋七月」；`065`「十二月」；`066`「十四年春三月」「十二月，军还谯」——**公元 208 年与 209 年为后世换算，属外证** |
| 标记 | ○ 外证 |
| 考点 | 底本不给公元年份。看到年份先分清：**这是原文里的，还是外面加进来的坐标** |

### 卡 11 · 辨析

**问：赤壁相关材料里，哪些已有记载、哪些还不能确定？**

答：**交战不利、疾病与退军有记录；火攻与退路在其他传、注中也有材料。**

`065`不是退兵理由全空，`113`、`114`《周瑜传》正文又展开疾病、初战、黄盖火攻；`265`是华容退路的注引记载，各归出处。

尚不能仅凭这些选段确定的，有伤亡精确总数、各项原因的权重，以及所有参战者的内心。刘琮投降缘由、地名今址在本段未展开，也不能扩大成所有文献从无解释。

| | |
|---|---|
| 依据 | `065`；`113`–`114`；`265` |
| 标记 | ○ 合理推演 |
| 考点 | 先把已有材料读全，再界定未详之处 |

### 这一篇的难点

《武帝纪》短写与《周瑜传》较详记述同时属于史书正文；疾病、火攻、退路与合肥先后的材料归属须分别说明。不能把简略等同于史书全部未载，也不能把小说场面当作唯一可读的火攻经过。
