# 复习卡 · 场景 09 · 赤壁

> 原则：**先问这句话出自哪本书，再问谁烧的船。**
> 这一篇的题库里有一半是**出处题**——正史里的赤壁只有二十二个字，没有火。

---

## 场景 09 · 赤壁（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 核心题 ★

**问：赤壁那一场火，烧了曹操的船。放火的人是谁？**

答：**最眼熟的那一说是黄盖的火船——那是《三国演义》里的。而别的书里还有两说，方向彼此相反。**

| 出处 | 说 |
|---|---|
| 《三国演义》第四十九回 | 黄盖的火船撞进水寨，曹军的船全着了 |
| 裴松之注引《山阳公载记》 | 船舰是**刘备**烧的 |
| 《吴书·吴主传》 | **曹操自己**烧了剩下的船，退了兵 |

**《武帝纪》正文 `013` 一个都不说。** 读者以为的赤壁多半来自演义，所以主内容展示的就是那一说（标 `◇`）；产品要做的是**在依据里把三说摆开**，不替他选一个。

| | |
|---|---|
| 依据 | `013`「公至赤壁，与备战，不利。于是大疫，吏士多死者，乃引军还」——**正文里没有火，也没有船**；演义那一段见卡 3 与卡 7，另两说见裴松之注与《吴书·吴主传》，**不在本篇底本范围内**，此处只作对照 |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 内部 | 三种说法的并置，本场景的系统层另有一问专门交代。这张卡只要求记住**方向相反、而且都不在正文里** |
| 考点 | 一个问题，三种方向相反的记载。要知道它们**各自出自哪一本书**，而不是只记住「火烧赤壁」 |

---

### 卡 2 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**正史给了二十二个字，演义给了一场火。**

《武帝纪》那一段从头到尾是：「公至赤壁，与备战，不利。于是大疫，吏士多死者，乃引军还。」没有船，没有火，也没有风。

演义的第四十九回给的是一整场火：二十只火船撞入水寨，船被铁环销住，三江面上火逐风飞。**一个是记事，一个是场面。**

| | |
|---|---|
| 依据 | `013`；`205`（《三国演义》第四十九回） |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 考点 | 这一篇的全部张力在**两段原文的长短差**上：一句「不利」对上五十回的大戏 |

---

### 卡 3 · 出处题 ★

**问：「不载」的空白在哪儿？正史这一段，没有写什么？**

答：**没有船，没有火，没有风，也没有一个人开口。**

`013` 三句、二十二个字：到了赤壁、跟刘备打了一仗、不利、大疫、吏士死了很多、引军还。**它没有说怎么输的，没有说输了多少，也没有说是谁的主意。**

而这场仗在另一本书里，从第四十三回写到第五十回。裁进本篇的只到火船撞入水寨为止——**连放火的人名都不在里面**。

| | |
|---|---|
| 依据 | `013`「公至赤壁，与备战，不利。于是大疫，吏士多死者，乃引军还」；`205`「二十只火船，撞入水寨……但见三江面上，火逐风飞，一派通红，漫天彻地」 |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 考点 | 「正史没写」不是一句空话，要能一件一件点出来：**船、火、风、人数、人名**，五样都没有 |

---

### 卡 4 · 因果

**问：曹操自己不说是被打败的。他写的是什么？**

答：**「不利」。两个字。**

`013` 全篇没有「败」，也没有「走」——它写的是「不利」，再接一句「于是大疫，吏士多死者，乃引军还」。

**这是底本的用词。** 把「不利」读成不肯认输，是读出来的判断；`013` 只记这两个字，不记他为什么用它。

| | |
|---|---|
| 依据 | `013`「公至赤壁，与备战，不利。于是大疫，吏士多死者，乃引军还」——**全篇没有「败」字**；用「不利」是不是有意避讳，底本不写 |
| 标记 | ○ 合理推演 |
| 考点 | 一场改写历史的败仗，正文里只有「不利」两个字。**先看清它写的是什么，再谈它为什么这么写** |

---

### 卡 5 · 陷阱题 ⚠️

**问：曹操是自己决定退兵的吗？什么时候决定的？**

答：**不知道。这一段只有「乃引军还」四个字。**

`013` 写的是他回去了，没有写这道令是谁下的、什么时候下的，也没有写他有没有犹豫过。

**陷阱在这儿**：演义里这一段是完整的场面——谁递的令、谁断后、走哪条路，全都有。读过之后回头再看正文，很容易以为那些都在正文里。**它们不在。**

| | |
|---|---|
| 依据 | `013`「乃引军还」——退兵是原文写下的动作；**这道令怎么下的，底本不载**。演义那一段里的断后、选路，都出自另一本书 |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 「他退兵了」和「他决定退兵」是两件事。**原文只给了前一件** |

---

### 卡 6 · 陷阱题 ⚠️

**问：这一仗，曹操是因为大疫才退的兵吗？**

答：**底本把「不利」和「大疫」并排写，哪一个是主要原因，它不说。**

`013` 的次序是：与备战、不利、于是大疫、吏士多死者、乃引军还。**「于是」两个字把疫放在了不利的后面，可它不点因果。**

那个年代行军，疫病死的常常比打仗多；但**「疫是主因」这句话，是后世的判断，不是这一段写的。**

| | |
|---|---|
| 依据 | `013`「公至赤壁，与备战，不利。于是大疫，吏士多死者，乃引军还」——不利与大疫并列在一句里，谁主谁次，底本不点 |
| 标记 | △ 史书未载，后世有争议 |
| 考点 | 这一篇最容易替古人作答的地方。**两件事并排写，不等于有因果** |

---

### 卡 7 · 版本题 ★

**问：演义那一段，写了哪些正文里没有的东西？**

答：**船的数量、船的处境、火的样子——三样都是演义给的。**

- 船的数量：「二十只火船，撞入水寨」
- 船的处境：「又被铁环销住，无处逃避」
- 火的样子：「但见三江面上，火逐风飞，一派通红，漫天彻地」

`013` 里这三样一样都没有。**这三句引文，让赤壁在读者心里变成了另一件事。**

| | |
|---|---|
| 依据 | `205`「二十只火船，撞入水寨。曹寨中船只一时尽着；又被铁环销住，无处逃避……但见三江面上，火逐风飞，一派通红，漫天彻地」（《三国演义》第四十九回） |
| 标记 | ◇ 出自小说《三国演义》，不是史书 |
| 考点 | 同一件事，两本书的分工很清楚：**正文给结果，演义给场面。** 要能说出场面里的哪一句是演义新加的 |

---

### 卡 8 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**没有刻度。**

`013` 从头到尾不带年月：没有月份，没有日子，也没有「相持」这类说明长度的词。它只把几件事连排：到了赤壁、与备战、不利、大疫、引军还。

「建安十三年」和「公元 208 年」都是后世系年——**这一段里一个年号、一个公元纪年都没有。**

| | |
|---|---|
| 依据 | `013` 无系年，全篇不带年月；公元 208 年为后世换算，属外证 |
| 标记 | ○ 外证 |
| 考点 | 底本不给年份。看到年份先分清：**这是原文里的，还是外面加进来的坐标** |

### 这一篇的难点

**两段原文里，被人说出口的话一句都没有。** `013` 是记事，`205` 是场面——场面里有动作，没有对话。

所以这一篇的卡不问台词，只问两件事：**这件事在哪本书里**，和**哪一处是史书不肯说的**。
