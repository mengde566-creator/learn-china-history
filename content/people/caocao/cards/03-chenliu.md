# 复习卡 · 场景 03 · 陈留起兵

> 原则：**问判断，不问场面。**
> 这一篇的九段里，正文给的是动作，注给的是路上的那一夜——
> 卡问的是：哪一句是谁写的、哪一处有三种说法。

---

## 场景 03 · 陈留起兵（10 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 出处 ★

**问：这一篇的九段，是一本书里的吗？**

答：**不是。九段分两档：五段正文，四段注。**

| 编号 | 哪一档 | 写的是 |
|---|---|---|
| `011`–`015` | 《三国志·魏书·武帝纪》正文，陈寿写的 | 召外兵、废立与表官、变易姓名东归、中牟被执、至陈留散家财、十二月己吾起兵、是岁中平六年 |
| `211`、`212` | 裴松之注引《魏书》 | 他笑召外兵那句话；吕伯奢那一夜（同一段里还收着《世语》、孙盛《杂记》两说） |
| `213`、`214` | 裴松之注引《世语》 | 中牟的功曹放他；陈留孝廉卫兹出钱，众五千人 |

**注也是史料，只是不在正文里。** 读者该分得清哪一句是陈寿写的、哪一句是别史里转引来的——两档各自写着书名，不并排挂在同一个「原文」底下。

| | |
|---|---|
| 依据 | `011`–`015`（《武帝纪》正文）；`211`、`212`（裴松之注引《魏书》）；`213`、`214`（裴松之注引《世语》） |
| 标记 | ◆ 出自原文 |
| 考点 | 正文给动作，注给那一夜和三种说法——**这是这一篇全部的结构** |

---

### 卡 2 · 因果 ★

**问：他为什么不接董卓给的官？**

答：**正文不给理由，注才给。**

`012` 只有两个动作：「卓表太祖为骁骑校尉，欲与计事」——名号是董卓那一头给的；「太祖乃变易姓名，间行东归」——他改了姓名，走小路往东回。**为什么，一个字没有。**

缘由在 `212` 的《魏书》一说里：「太祖以卓终必覆败，遂不就拜，逃归乡里」——他认定董卓终究要覆败。

同一段的《世语》和孙盛《杂记》都不写这个官，只写路上那一夜。

| | |
|---|---|
| 依据 | `012`「卓表太祖为骁骑校尉，欲与计事」「太祖乃变易姓名，间行东归」；`212`（裴松之注引《魏书》）「太祖以卓终必覆败，遂不就拜，逃归乡里」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动作在正文，理由在注里——这一篇反复出现的形状 |

---

### 卡 3 · 细节 ★

**问：中牟那一夜，是谁放了他？**

答：**正文一句话，注里一整夜。**

正文 `013`：「出关，过中牟，为亭长所疑，执诣县，邑中或窃识之，为请得解。」——**「或」是不定的人**，连身份都没给。

注 `213` 才点出三个人：

- 掾：「时掾亦已被卓书」——手里已经接到董卓的文书；
- 功曹：「唯功曹心知是太祖」，说了那句「以世方乱，不宜拘天下雄俊」；
- 令：功曹「白令」，放人的是县令。

**三个人的名字，一个字都没有。**

| | |
|---|---|
| 依据 | `013`「出关，过中牟，为亭长所疑，执诣县，邑中或窃识之，为请得解」；`213`「时掾亦已被卓书；唯功曹心知是太祖，以世方乱，不宜拘天下雄俊，因白令释之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 正文写「或」，注里写「功曹」——同一件事，两档的详略不一样 |

---

### 卡 4 · 版本 △★

**问：吕伯奢那一夜，三种说法各是什么？**

答：**三种都在同一段注里，指向三个方向。**

| 出处 | 怎么写的 | 方向 |
|---|---|---|
| `212`《魏书》 | 「其子与宾客共劫太祖，取马及物，太祖手刃击杀数人」 | 他们先动手，他是自卫 |
| `212`《世语》 | 「太祖自以背卓命，疑其图己，手剑夜杀八人而去」 | 他自己起了疑 |
| `212` 孙盛《杂记》 | 「太祖闻其食器声，以为图己，遂夜杀之」 | 他听见声音就动了手 |

**三种都是注，没有一种是陈寿的正文**——正文 `012` 只有「太祖乃变易姓名，间行东归」，一个字不提吕伯奢。

| | |
|---|---|
| 依据 | `212`（裴松之注引《魏书》，同一段收《世语》、孙盛《杂记》两说）；`012`「太祖乃变易姓名，间行东归」 |
| 标记 | △ 史书未载，后世有争议 |
| 考点 | 全库最该用 △ 的一处：**三说并置，不替他裁** |

---

### 卡 5 · 陷阱题 ⚠️

**问：「宁我负人，毋人负我」是史书写定的吗？**

答：**不是。**

- 底本写作「甯」：「甯我负人，毋人负我」——甯、宁是同一个字的两种写法。
- 它是**孙盛《杂记》一家**的说法，收在裴松之的注里（`212`），也是三说里最晚出的一种。
- 同一段注里，《魏书》说的是自卫，《世语》说的是起疑——那两说都没有这一句。

正文 `012`「太祖乃变易姓名，间行东归」——**这一夜，正文一个字不提。**

| | |
|---|---|
| 依据 | `212`（裴松之注引《魏书》，同一段收孙盛《杂记》「甯我负人，毋人负我」）；`012`「太祖乃变易姓名，间行东归」 |
| 标记 | △ 史书未载，后世有争议 |
| 考点 | 读者记得最牢的那一句，恰恰是三种说法里最晚出的一种 |

### 卡 6 · 数字

**问：这一篇给了几个数目？**

答：**只有一个：五千人。**

| 数目 | 哪一段 | 写的是什么 |
|---|---|---|
| 五千人 | `214` | 「众有五千人」——凑起来的人 |
| 「数骑」 | `212` | 「从数骑过故人成皋吕伯奢」——几个骑从，不给数 |
| 「数人」／「八人」 | `212` | 吕伯奢那一夜，两说各给一个数，第三说不给 |
| 「家财」 | `014`、`214` | 两处都只有两个字，多少钱不写 |
| 「十余万」 | `011` | 那是边章、韩遂的叛众，不是他的兵 |

**「众」不是「军」。** `214` 用的是「众有五千人」，`014` 用的是「合义兵」——两处都没有「军」字：编制、粮、带队的人，这九段里一个都没有。

| | |
|---|---|
| 依据 | `214`「众有五千人」；`212`「从数骑过故人成皋吕伯奢」；`014`「散家财，合义兵」；`011`「众十余万」 |
| 标记 | ◆ 出自原文 |
| 考点 | 唯一的数目是五千；别处只有「数」字，没有数 |

### 卡 7 · 一处空白

**问：曹操散过家财，卫兹也拿出家财。这是一笔钱，还是两笔？**

答：**底本不回答。**

`014` 写「散家财」，`214` 写「以家财资太祖」。一个说他自己散，一个说别人拿出来——**谁也没说这是同一笔，也没说是两笔。**

两段挨着收在同一篇里，很容易读成一件事：他散家财、卫兹资助他、凑起五千人。可那是顺读，**不是底本的交代。**

| | |
|---|---|
| 依据 | `014`「散家财」；`214`「陈留孝廉卫兹以家财资太祖」 |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 这一篇最好的问题，就是这一个 |

### 卡 8 · 时间线

**问：这一篇的时间，是从哪儿到哪儿？**

答：**从「进乃召董卓」到「是岁中平六年也」——都在同一年里。**

| 刻度 | 哪一段 | 写的是什么 |
|---|---|---|
| 「进乃召董卓」 | `011` | 事情的起头；那一年灵帝崩，太子即位 |
| 「卓未至而进见杀」 | `012` | 何进死在董卓到之前 |
| 「冬十二月，始起兵于己吾」 | `014` | 这一年最后一件写下来的事 |
| 「是岁中平六年也」 | `015` | 年份——底本自己给的 |
| 「初平元年春正月」 | `015` | 下一个年号的头一行，往下归 `04-xingyang` |

**中平六年就是公元 189 年**——公元纪年是后世的换算，这九段里只有年号和月份。

| | |
|---|---|
| 依据 | `011`「进乃召董卓」；`012`「卓未至而进见杀」；`014`「冬十二月，始起兵于己吾」；`015`「是岁中平六年也」「初平元年春正月」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一年之内走完的弧线；年号是底本给的，公元是后人加的 |

---

### 卡 9 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**他在这一年的最后几个月里，从洛阳走回陈留，起了一支兵。**

- 不接董卓给的官，改了姓名，走小路往东（`012`）；
- 过中牟被执，功曹放了他（`013`、`213`）；
- 成皋那一夜，三说并置（`212`）；
- 到陈留，散家财，合义兵（`014`）；
- 卫兹出钱，众五千人（`214`）；
- 十二月，起兵于己吾；是岁中平六年（`014`、`015`）。

| | |
|---|---|
| 依据 | `012`「太祖乃变易姓名，间行东归」；`014`「太祖至陈留，散家财，合义兵，将以诛卓」「冬十二月，始起兵于己吾」；`015`「是岁中平六年也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇讲的不是"他起兵了"，是**他为什么走、怎么走的** |

---

### 卡 10 · 开放题

**问：卫兹为什么肯把家财拿出来？**

答：**底本不回答。**

`214` 只记了他做的事：以家财资太祖、使起兵、众有五千人。**为什么，一个字没有。**

这一篇把它留在「—」里，是有意的：不是产品不知道，是**这九段里没有**——而知道自己不知道什么，和知道答案一样重要。

| 考点 | 开放题，答案是"没有答案"：`214` 只记他做了什么 |

### 这一篇的难点

**九段里，正文的五个动作和注里的三样东西，错开得整整齐齐。** 正文给的是他被怎么对待、他做了什么：表官、变易姓名、出关被执、至陈留、散家财、起兵。注补的是正文不肯写的：他为什么不接、中牟县里那一夜是谁放的他、成皋那一夜到底发生了什么。

**所以这一篇的卡只问三件事**：哪一句是谁写的、哪一处有三种说法、哪一处底本干脆不回答。

**最容易记错的一处是「宁我负人」。** 它是孙盛《杂记》一家的说法，被裴松之收在注里；那一夜的另外两说，一说他是自卫，一说他只是起了疑。**读者记得最牢的那一句，是三说里最晚出的一种**——卡 4 和卡 5 合起来守这一处。

**还有一处是钱。** `014` 散家财、`214` 卫兹资太祖，两段并列收着，谁也没说是一笔还是两笔。**这一篇不替它们合**（卡 7）。
