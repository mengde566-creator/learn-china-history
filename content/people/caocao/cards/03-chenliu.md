# 复习卡 · 场景 03 · 陈留起兵

> 原则：**问判断，不问场面。**
> 这一篇的八段里，正文只有两段，注有六段——
> 卡问的是：哪一句是谁写的、卫兹那个人的钱为什么在注里、起兵的引信是谁点的。

---

## 场景 03 · 陈留起兵（10 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 出处 ★

**问：本篇主要八段，正文与注文怎样区分？**

答：**都见于《三国志》带注文本，主要八段分为两段本纪正文、六段裴注；所引原书与作者层次不同。**

| 编号 | 哪一档 | 写的是 |
|---|---|---|
| `014`、`015` | 《三国志·魏书·武帝纪》正文，陈寿写的 | 至陈留、散家财、合义兵、十二月己吾起兵、是岁中平六年 |
| `214` | 裴松之注引《世语》 | 陈留孝廉卫兹以家财资助，众五千人 |
| `215`–`219` | 裴松之注引《英雄记》 | 桥瑁的伪书、韩馥与刘子惠、孔伷、王匡、袁遗 |

这八段中，正文记曹操至陈留、散家财、合义兵与起兵；注另补卫兹资助、桥瑁移书、冀州商议和人物小传。本篇结尾还引用正文020作为补充参照，把主线接到次年正月的诸将起兵；不把这条补充混算进主要选录的八段。

| | |
|---|---|
| 依据 | `014`、`015`（《武帝纪》正文）；`214`（裴松之注引《世语》）；`215`–`219`（裴松之注引《英雄记》）；`020`为正文补充参照 |
| 标记 | ◆ 出自原文 |
| 考点 | 八段里六段是注——补充116正文、316裴注另外区分，不混入原八段统计 |

### 卡 2 · 因果 ★

**问：起兵的钱和人，正文与注分别记了什么？**

答：**正文记曹操散家财合义兵，裴注引《世语》另记卫兹以家财资助，部众五千。**

两处分别交代了曹操投入自家财产与卫兹的资助，材料没有完整账目、征募名册或各自占比。可以并读资金来路，不必把两家的财产争成同一笔或两份完整军费。

`116`《卫臻传》与`316`裴注《先贤行状》另补两人共同议事、兴兵主张；后者记合兵三千，不与《世语》的五千硬合成同一笔数。

| | |
|---|---|
| 依据 | `014`、`214`；补充`116`正文、`316`裴注《先贤行状》 |
| 标记 | ◆ 出自原文 |
| 考点 | 保留两个出资主体，不虚构账目 |

### 卡 3 · 陷阱题 ⚠️

**问：那封号召起兵的三公移书，是三公写的吗？**

答：**不是。那是桥瑁伪造的。**

`215` 写的是「东郡太守桥瑁诈作京师三公移书与州郡」——**书是桥瑁写的，署名是三公的名，收信的是各州郡。**「诈作」两个字，是这一段里唯一的交代。

书里的话是拿朝廷的口气说的：

| 书上写的 | 白话 |
|---|---|
| 「见逼迫，无以自救，企望义兵，解国患难。」 | 被逼迫着，没法自救，只能盼着义兵起来，解国家的患难 |

这封文书用三公受逼的口气号召救难。材料接着记韩馥收书商议、允许袁绍举兵；不能据此断言所有州郡都因这封书才起兵，也不能把文书中的话当作曹操的台词。

| | |
|---|---|
| 依据 | `215`（裴松之注引《英雄记》）「东郡太守桥瑁诈作京师三公移书与州郡，陈卓罪恶，云『见逼迫，无以自救，企望义兵，解国患难。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 读者最容易记成「朝廷下诏讨董卓」——**署名是三公，写的人是桥瑁** |

### 卡 4 · 细节 ★

**问：桥瑁是谁？**

答：**东郡太守，桥玄的族子。**

- 职位与那件事：`215`「东郡太守桥瑁诈作京师三公移书与州郡」——**做这件事的时候，他是东郡太守**；
- 底细：`218`「瑁字元伟，玄族子。先为兖州刺史，甚有威惠」——**字、家世、前任，一句话三样**。

**桥玄这个名字在 `02-cidong` 里出现过**——那是许子将之前先看好曹操的那个人。这一层是照两处的字认的，不是 `218` 写的。

| | |
|---|---|
| 依据 | `215`「东郡太守桥瑁诈作京师三公移书与州郡」；`218`「瑁字元伟，玄族子。先为兖州刺史，甚有威惠」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一封伪书、七个字的名字——**写这封书的人，正史里只有注给他立了个小传** |

### 卡 5 · 一句话 ★

**问：裴注保存了曹操怎样评价袁遗的话？**

答：**“长大而能勤学者，惟吾与袁伯业耳。”袁伯业就是袁遗。**

`219` 同条先记袁遗后来的任职败亡，末附这句评价，并说明“语在文帝典论”。它不是陈留起兵现场的台词，评语的具体说出时间也未在这句里标明，不能直接定作“多年以后”。

| | |
|---|---|
| 依据 | `219`「太祖称」「语在文帝典论」 |
| 标记 | ◆ 出自原文 |
| 考点 | 注里附有评语，不等于同场发生的对话 |

### 卡 6 · 数字

**问：五千与五百，分别记的是什么？**

答：**五千是卫兹资助起兵后所记部众数；五百是王匡调发赴京师的强弩。**

两个数出自不同人物、不同经过，不是可以直接相加的同一支讨董队伍。`217` 的强弩属于军事语境，也不能只因文字没有一个“军”字，就否认与兵力有关。

| | |
|---|---|
| 依据 | `214`「众有五千人」；`217`「发强弩五百西诣京师」 |
| 标记 | ◆ 出自原文 |
| 考点 | 先认清数的对象，再谈能否合算 |

### 卡 7 · 因果

**问：桥瑁伪造的移书，想让州郡做什么？**

答：**移书列董卓罪恶，以三公受逼、无法自救的口气，盼州郡起义兵解救国难。**

这份内容可以说明它的号召作用；文书是桥瑁诈作，不能当作三公真实下达的命令。韩馥收到后与从事商议，后来允许袁绍举兵。至于桥瑁是否另有未说出的私心，本段没有完整交代。

| | |
|---|---|
| 依据 | `215`「陈卓罪恶」「企望义兵，解国患难」及韩馥商议经过 |
| 标记 | ○ 合理推演 |
| 考点 | 文书表达的目的可读，个人全部心思仍未尽录 |

### 卡 8 · 时间线

**问：这一篇的时间，是从哪儿到哪儿？**

答：**起兵主线在中平六年冬，选录还接着次年正月与注中的前后事。**

| 刻度 | 哪一段 | 写的是什么 |
|---|---|---|
| 「太祖至陈留」 | `014` | 这一年他到了陈留，散家财、合义兵 |
| 「冬十二月，始起兵于己吾」 | `014` | 这一年最后一件写下来的事 |
| 「是岁中平六年也」 | `015` | 年份——底本自己给的 |
| 「初平元年春正月」 | `015` | 下一个年号的头一行，往下归 `04-xingyang` |

**`014` 起头那一句是合叙**：何太后死在这一年，弘农王被杀在下一年的正月——《后汉书·孝献帝纪》：「丙子，**董卓杀皇太后何氏**」（中平六年九月）、「癸酉，**董卓杀弘农王**」（初平元年春正月）。因此不能说整个选录的每件事都在中平六年。

**`215`–`219` 那几段是注，写的是名单上那几个人的来历，和他们后来的任职、败亡**——名字写进讨董那份名单，是下一年的正月。

**中平六年就是公元 189 年**——公元纪年是后世的换算，这八段里只有年号和月份。

| | |
|---|---|
| 依据 | `014`「太祖至陈留，散家财，合义兵，将以诛卓」「冬十二月，始起兵于己吾」；`015`「是岁中平六年也」「初平元年春正月」；`014`「卓遂杀太后及弘农王」是合叙——**两件杀戮分在两年**——《后汉书·孝献帝纪》：「丙子，**董卓杀皇太后何氏**」（中平六年九月）、「癸酉，**董卓杀弘农王**」（初平元年春正月），那一段不在本篇底本里 |
| 标记 | ○ 外证 |
| 考点 | 主线与选录跨度分开；年号是底本给的，公元是后人加的。**合叙的一句，不能照句序当同一个月的事** |

### 卡 9 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**他到了陈留，散家财、合义兵；裴注另记陈留人卫兹以家财资助。十二月，他在己吾起兵；次年正月，关东诸将起兵讨董。**

- 至陈留，散家财，合义兵（`014`）；
- 卫兹以家财资助，众五千人（`214`）；
- 十二月，起兵于己吾；是岁中平六年（`014`、`015`）；
- 桥瑁伪造三公移书，向州郡号召救难（`215`）；
- 韩馥接到移书，刘子惠说「今兴兵为国」（`215`）；
- 次年正月，诸将起兵，推袁绍为盟主；曹操行奋武将军（`015`、`020`）。诸将的小传留在可展开的背景中。

| | |
|---|---|
| 依据 | `014`「太祖至陈留，散家财，合义兵，将以诛卓」「冬十二月，始起兵于己吾」；`214`「陈留孝廉卫兹以家财资太祖，使起兵，众有五千人」；`215`（裴松之注引《英雄记》）；`015`、`020`接次年正月起兵与盟主 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇讲的不是"他起兵了"，是**钱的来路、名单上还有谁** |

### 卡 10 · 开放题

**问：讨董起兵中，曹操与桥瑁各做了什么？**

答：**曹操散家财、合义兵，在己吾起兵；桥瑁则伪作三公移书，向州郡号召救难。**

`014` 概述曹操自己起兵的行动。`215`另记桥瑁的移书、韩馥与从事商议、允许袁绍举兵。材料分别保存各人的行动，不把桥瑁的号召说成曹操所为，也不由此推断曹操从未另外号召他人。

**这一篇不替他把这件事收拢到自己身上**，也不替他答「他有没有争这个头」。

| | |
|---|---|
| 依据 | `014`「太祖至陈留，散家财，合义兵，将以诛卓」「冬十二月，始起兵于己吾」；`215`（裴松之注引《英雄记》） |
| 标记 | ○ 合理推演 |
| 考点 | 开放题：`014` 只写他的四个动作，桥瑁的伪移书与曹操合义兵是不同人的行动；不能由未录号召文字证明曹操从未号召 |

### 这一篇的难点

**八段里六段是注，这是这一篇唯一要记的形状。** 正文只给四个动作：至陈留、散家财、合义兵、十二月起兵。卫兹那笔钱的来路（`214`）、那封引信（桥瑁的伪书，`215`）、名单上那几个人的小传（`216`–`219`），全在裴松之的注里。**谁把注当成"补充材料"，这一篇就丢了一半。**

**最容易记错的是那封伪书。** 读者心里的版本多半是朝廷下诏讨董卓——`215` 写的是桥瑁诈作三公移书，**署名是三公，写的人是东郡太守**（卡 3 守这一处）。

数目须分材料与阶段：《世语》记起兵部众五千，《先贤行状》记卫兹合兵三千从征，王匡的五百强弩属前事，不能相加或强定同一兵额。

**△ 这一篇一条都不用。** 上一轮的 △ 全在吕伯奢那一夜，那一段归 `02-cidong`；旧选注引材料之外，新增116、316对读卫兹，兵数、行事与所录言语须逐项归属——**这一篇的难点不在异说，在"谁写的、谁做的"**。
