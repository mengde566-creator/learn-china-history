# 复习卡 · 场景 03 · 陈留起兵

> 原则：**问判断，不问场面。**
> 这一篇的八段里，正文只有两段，注有六段——
> 卡问的是：哪一句是谁写的、卫兹那个人的钱为什么在注里、起兵的引信是谁点的。

---

## 场景 03 · 陈留起兵（10 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 出处 ★

**问：这一篇的八段，是一本书里的吗？**

答：**不是。八段分两档：两段正文，六段注。**

| 编号 | 哪一档 | 写的是 |
|---|---|---|
| `014`、`015` | 《三国志·魏书·武帝纪》正文，陈寿写的 | 至陈留、散家财、合义兵、十二月己吾起兵、是岁中平六年 |
| `214` | 裴松之注引《世语》 | 陈留孝廉卫兹以家财资助，众五千人 |
| `215`–`219` | 裴松之注引《英雄记》 | 桥瑁的伪书、韩馥与刘子惠、孔伷、王匡、袁遗 |

**正文给的是动作，注补的是人。** 这一篇的八段里，**六段是注**——这个比例本身就是这一篇要说的事：起兵这件事，正史写了「至、散、合、起」四个动作（他自己散的家财就在里面），卫兹那笔钱的来路、名单上那几个人的小传，全在注里。

| | |
|---|---|
| 依据 | `014`、`015`（《武帝纪》正文）；`214`（裴松之注引《世语》）；`215`–`219`（裴松之注引《英雄记》） |
| 标记 | ◆ 出自原文 |
| 考点 | 八段里六段是注——**这是这一篇全部的结构** |

---

### 卡 2 · 因果 ★

**问：他起兵的钱和兵，是从哪儿来的？**

答：**正文说的是他自己散家财，注说的是卫兹以家财资助。**

正文 `014` 只有「散家财，合义兵」六个字——散的是自家的钱，聚起来的兵要拿去诛卓。**钱够不够、人从哪儿来，正文一个字没有。**

注 `214` 记的是卫兹这一头：「陈留孝廉卫兹以家财资太祖，使起兵，众有五千人。」一个名字、一个身份、一个数目。

两段并列收着，**谁也没说卫兹那笔钱和他自己散的家财是一笔还是两笔**。

| | |
|---|---|
| 依据 | `014`「太祖至陈留，散家财，合义兵，将以诛卓」；`214`（裴松之注引《世语》）「陈留孝廉卫兹以家财资太祖，使起兵，众有五千人」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动作在正文；卫兹那个人和他的钱在注里——**这一篇的形状** |

---

### 卡 3 · 陷阱题 ⚠️

**问：那封号召起兵的三公移书，是三公写的吗？**

答：**不是。那是桥瑁伪造的。**

`215` 写的是「东郡太守桥瑁诈作京师三公移书与州郡」——**书是桥瑁写的，署名是三公的名，收信的是各州郡。**「诈作」两个字，是这一段里唯一的交代。

书里的话是拿朝廷的口气说的：

| 书上写的 | 白话 |
|---|---|
| 「见逼迫，无以自救，企望义兵，解国患难。」 | 被逼迫着，没法自救，只能盼着义兵起来，解国家的患难 |

**一封伪造的文书，是起兵的引信。** 这句话是替朝廷说的，没有一个字是曹操说的。

| | |
|---|---|
| 依据 | `215`（裴松之注引《英雄记》）「东郡太守桥瑁诈作京师三公移书与州郡，陈卓罪恶，云『见逼迫，无以自救，企望义兵，解国患难。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 读者最容易记成「朝廷下诏讨董卓」——**署名是三公，写的人是桥瑁** |

---

### 卡 4 · 细节 ★

**问：桥瑁是谁？**

答：**东郡太守，桥玄的族子。**

- 职位与那件事：`215`「东郡太守桥瑁诈作京师三公移书与州郡」——**做这件事的时候，他是东郡太守**；
- 底细：`218`「瑁字元伟，玄族子。先为兖州刺史，甚有威惠」——**字、家世、前任，一句话三样**。

**桥玄这个名字在 `02-cidong` 里出现过**——那是许子将之前先看好曹操的那个人。这一层是照两处的字认的，不是 `218` 写的。

| | |
|---|---|
| 依据 | `215`「东郡太守桥瑁诈作京师三公移书与州郡」；`218`「瑁字元伟，玄族子。先为兖州刺史，甚有威惠」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一封伪书、七个字的名字——**写这封书的人，正史里只有注给他立了个小传** |

---

### 卡 5 · 一句话 ★

**问：这一篇里，曹操自己开口说过什么？**

答：**只有一句，而且是夸人的。**

`219` 记的是《典论》里的一句话：「太祖称『长大而能勤学者，惟吾与袁伯业耳。』」——**长大了还能勤学的，只有我和袁伯业两个。**

袁伯业就是袁遗。**这一篇八段里，曹操没有一句自己的话**：散家财、合义兵、起兵于己吾，全是动作。他唯一一次开口，是多年以后评价名单上的另一个人。

**这一句出自《典论》，`219` 是转引**——`219` 自己在末尾交代了「语在文帝典论」。

| | |
|---|---|
| 依据 | `219`（裴松之注引《英雄记》）「太祖称『长大而能勤学者，惟吾与袁伯业耳。』语在文帝典论」 |
| 标记 | ◆ 出自原文 |
| 考点 | 全篇他只有这一句话，说的是别人——**名字出现在下一年的正月，夸人的话出现在更晚** |

---

### 卡 6 · 数字

**问：这一篇给了几个数目？**

答：**两个：五千人，和五百。**

| 数目 | 哪一段 | 写的是什么 |
|---|---|---|
| 五千人 | `214` | 「众有五千人」——卫兹以家财资助凑起来的人 |
| 五百 | `217` | 「匡于徐州发强弩五百西诣京师」——王匡调发的强弩 |
| 「十二月」 | `014` | 起兵的月份，不是数目 |
| 「中平六年」 | `015` | 年号，不是数目 |

**别人带了多少兵，一个数目都没有**：韩馥、孔伷、桥瑁、袁遗，四段里一个数不载。**「众」不是「军」**——`214` 用的是「众有五千人」，`014` 用的是「合义兵」，两处都没有「军」字。

| | |
|---|---|
| 依据 | `214`「众有五千人」；`217`「匡于徐州发强弩五百西诣京师」；`014`「冬十二月，始起兵于己吾」「合义兵」 |
| 标记 | ◆ 出自原文 |
| 考点 | 全篇只有两个数目，一个是他这边的，一个是王匡那边的 |

---

### 卡 7 · 一处空白

**问：桥瑁为什么要伪造那封三公移书？**

答：**底本不回答。**

`215` 只记了「诈作」两个字——**做了什么写得很清楚，为什么一个字没有。** 同样空着的还有几处：韩馥为什么先想到袁氏和董卓（`215` 只记他问出口的那一句）、卫兹为什么肯拿钱（`214` 只记他拿了）、那五千人怎么来的（`214` 只有五个字）。

**这一篇的「—」集中在数目和动机上**，不在事实上——事实注都写了。

| | |
|---|---|
| 依据 | `215`「东郡太守桥瑁诈作京师三公移书与州郡」；`214`「陈留孝廉卫兹以家财资太祖」 |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 做了什么是史料，为什么做不是——**八段里没有一处替他们补动机** |

### 卡 8 · 时间线

**问：这一篇的时间，是从哪儿到哪儿？**

答：**主体在中平六年这一年里，最后五个字把它关上。**

| 刻度 | 哪一段 | 写的是什么 |
|---|---|---|
| 「太祖至陈留」 | `014` | 这一年他到了陈留，散家财、合义兵 |
| 「冬十二月，始起兵于己吾」 | `014` | 这一年最后一件写下来的事 |
| 「是岁中平六年也」 | `015` | 年份——底本自己给的 |
| 「初平元年春正月」 | `015` | 下一个年号的头一行，往下归 `04-xingyang` |

**`014` 起头那一句是合叙**：何太后死在这一年，弘农王被杀在下一年的正月——《后汉书·孝献帝纪》：「丙子，**董卓杀皇太后何氏**」（中平六年九月）、「癸酉，**董卓杀弘农王**」（初平元年春正月）。**这一篇的时间线只算这一年之内的事。**

**`215`–`219` 那几段是注，写的是名单上那几个人的来历，和他们后来的任职、败亡**——名字写进讨董那份名单，是下一年的正月。

**中平六年就是公元 189 年**——公元纪年是后世的换算，这八段里只有年号和月份。

| | |
|---|---|
| 依据 | `014`「太祖至陈留，散家财，合义兵，将以诛卓」「冬十二月，始起兵于己吾」；`015`「是岁中平六年也」「初平元年春正月」；`014`「卓遂杀太后及弘农王」是合叙——**两件杀戮分在两年**——《后汉书·孝献帝纪》：「丙子，**董卓杀皇太后何氏**」（中平六年九月）、「癸酉，**董卓杀弘农王**」（初平元年春正月），那一段不在本篇底本里 |
| 标记 | ◆ 出自原文 |
| 考点 | 一年之内走完的弧线；年号是底本给的，公元是后人加的。**合叙的一句，不能照句序当同一个月的事** |

### 卡 9 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**他到了陈留，散家财、合义兵；裴注另记陈留人卫兹以家财资助。十二月，他在己吾起兵；次年正月，关东诸将起兵讨董。**

- 至陈留，散家财，合义兵（`014`）；
- 卫兹以家财资助，众五千人（`214`）；
- 十二月，起兵于己吾；是岁中平六年（`014`、`015`）；
- 桥瑁伪造三公移书，那封书是引信（`215`）；
- 韩馥接到移书，刘子惠说「今兴兵为国」（`215`）；
- 孔伷、王匡、桥瑁、袁遗：名字在次年的讨董名单上（`216`–`219`）。

| | |
|---|---|
| 依据 | `014`「太祖至陈留，散家财，合义兵，将以诛卓」「冬十二月，始起兵于己吾」；`214`「陈留孝廉卫兹以家财资太祖，使起兵，众有五千人」；`215`（裴松之注引《英雄记》）；`216`–`219`（同） |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇讲的不是"他起兵了"，是**钱的来路、名单上还有谁** |

---

### 卡 10 · 开放题

**问：起兵的引信，为什么不是他点的？**

答：**底本把这件事写在别人身上。**

`014` 里曹操的动作是至、散、合、起——**四个动作，没有一个是"号召"**。号召那一步在 `215`：桥瑁伪作三公移书发到各州郡，韩馥接到之后才动，刘子惠说「今兴兵为国」——**起兵是许多人一起做的事。**

**这一篇不替他把这件事收拢到自己身上**，也不替他答「他有没有争这个头」。

| | |
|---|---|
| 依据 | `014`「太祖至陈留，散家财，合义兵，将以诛卓」「冬十二月，始起兵于己吾」；`215`（裴松之注引《英雄记》） |
| 标记 | ○ 合理推演 |
| 考点 | 开放题：`014` 只写他的四个动作，**「号召」两个字不在他身上** |

### 这一篇的难点

**八段里六段是注，这是这一篇唯一要记的形状。** 正文只给四个动作：至陈留、散家财、合义兵、十二月起兵。卫兹那笔钱的来路（`214`）、那封引信（桥瑁的伪书，`215`）、名单上那几个人的小传（`216`–`219`），全在裴松之的注里。**谁把注当成"补充材料"，这一篇就丢了一半。**

**最容易记错的是那封伪书。** 读者心里的版本多半是朝廷下诏讨董卓——`215` 写的是桥瑁诈作三公移书，**署名是三公，写的人是东郡太守**（卡 3 守这一处）。

**另一处是数目。** 五千人是卫兹凑起来的（`214`），王匡那五百强弩是往京师送的（`217`）；**别人带了多少兵，八段里一个数都没有**（卡 6）。

**△ 这一篇一条都不用。** 上一轮的 △ 全在吕伯奢那一夜，那一段归 `02-cidong`；`215`–`219` 是《英雄记》一家之言，没有第二种记载并置——**这一篇的难点不在异说，在"谁写的、谁做的"**。
