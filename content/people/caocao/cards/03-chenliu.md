# 复习卡 · 场景 03 · 陈留起兵

> 原则：**问动机，不问年代。**
> 这一篇的底本只有两句，而**两句里都出现了钱**——它们是不是同一笔，底本不说。

---

## 场景 03 · 陈留起兵（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 钱 ★

**问：这一篇里，曹操散过家财，卫兹也拿出家财。这是一笔钱，还是两笔？**

答：**底本不回答。**

`008` 写「散家财」，`104` 写「以家财资太祖」。一个说他自己散，一个说别人拿——**谁也没说这是同一笔，也没说是两笔。**

两句挨着收在同一篇里，很容易读成一件事：他散家财、卫兹资助他、凑起五千人。可那是顺读，**不是底本的交代**。

这一篇最好的问题，就是这一个。

| | |
|---|---|
| 依据 | `008`「散家财」；`104`「陈留孝廉卫兹以家财资太祖」 |
| 标记 | — 史书未载，且推不出来 |
| 考点 | `008` 说他散家财，`104` 说卫兹拿家财资他——**两段并列收着，谁也没说这是一笔还是两笔**。这一篇最该带走的就是这一处空白 |

---

### 卡 2 · 版本题 ★

**问：这一篇的两句话，是一本书里的吗？**

答：**不是。**

| | 《三国志·魏书·武帝纪》正文 | 裴松之注引《世语》 |
|---|---|---|
| 编号 | `008` | `104` |
| 说的是 | 他到了陈留，散家财，合义兵，要诛董卓；十二月在己吾起兵 | 陈留孝廉卫兹以家财资他，让他起兵，众有五千人 |
| 给了什么 | 时间、地点、去处 | 一个名字、一个身份、一个数目 |
| 谁写的 | 陈寿，三世纪末 | 《世语》里的记载；裴松之把它抄进了注 |

**注也是史料，只是不在正文里。** 读者该分得清哪一句是陈寿写的，哪一句是别史里转引来的——两段各自写着书名，不并排挂在同一个「原文」底下。

| | |
|---|---|
| 依据 | `008`（《武帝纪》正文）；`104`（裴松之注引《世语》） |
| 标记 | ◆ 出自原文 |
| 考点 | 「正文没有写钱，注里写了」——这是这一篇全部的结构 |

---

### 卡 3 · 陷阱题 ⚠️

**问：卫兹出钱凑起来的这五千人，当时就是一支军队吗？**

答：**底本用的是「众」，不是「军」。**

一句写「合义兵」，一句写「众有五千人」——**两处都没有「军」字**。

五千人要发粮、要编队、要有官带；这两句话里，编制、粮、带队的人一个都没有。底本只给了一个数目。

**读者最容易在这里顺读**：把「五千人」直接读成「五千兵」。人在底本里是「众」——聚起来的一群人。

| | |
|---|---|
| 依据 | `008`「合义兵」；`104`「众有五千人」 |
| 标记 | ○ 合理推演 |
| 考点 | 底本写的是「众」；编制、粮、带队的人，一个字都没有 |

---

### 卡 4 · 人物

**问：这一篇给了卫兹什么？**

答：**六个字，和一笔钱。**

`104` 那句话里，关于他本人的只有「陈留孝廉卫兹」六个字：一个地方、一个出身、一个名字。钱是他拿的——「以家财资太祖」。

他多大年纪、家里还有谁、出钱之后做了什么，**底本一个字不载**。

他在底本里出场极少：这一句之后，要再往后翻，才又见到他的名字。

| | |
|---|---|
| 依据 | `104`「陈留孝廉卫兹以家财资太祖，使起兵，众有五千人」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「陈留」和「孝廉」都是**底本自己写的字**，不是后世补的出身 |

---

### 卡 5 · 地理

**问：陈留和己吾，是什么关系？**

答：**己吾是陈留郡里的一个县。起兵在县里，不在郡治。**

`008` 先说他到了陈留，后说在己吾起兵。两个地名之间隔着三件事：散家财、合义兵、将以诛卓。

**为什么是这两个地方，底本不写。** 它只给地名，不给理由：一个郡，一个县，中间没有一句话解释。

| | |
|---|---|
| 依据 | `008`「太祖至陈留」「始起兵于己吾」；陈留在洛阳东边、己吾是它的属县，**这一层是外证** |
| 标记 | ○ 合理推演 |
| 考点 | 地名能核，选址的理由不能核——两件事别混 |

---

### 卡 6 · 时间线

**问：从散家财到十二月起兵，中间隔了多久？**

答：**底本不写。**

`008` 把「散家财，合义兵，将以诛卓」和「冬十二月，始起兵于己吾」写在同一句里，中间没有交代；`104` 补的是钱和人，也没有补时间。

这一篇能给的刻度只有两个：**中平六年**——年份是底本自己给的；**十二月**——起兵的月份。

中间那一段是空的。**空着也是内容**：底本没有为它编一个过程。

| | |
|---|---|
| 依据 | `008`「冬十二月，始起兵于己吾，是岁中平六年也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 中平六年就是公元 189 年，**公元纪年是后世的换算**，底本不写 |

---

### 卡 7 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**两句原文，两个出钱的人，一个数目。**

一句是陈寿的：他到了陈留，散家财，合义兵，将以诛卓；十二月，在己吾起兵。

一句是裴松之从《世语》里引的：陈留孝廉卫兹以家财资他，让他起兵，众有五千人。

**这一篇的戏眼是钱。** 而这两句话里钱出现了两次，谁也没把它们连起来——数目只有一个：五千。

| | |
|---|---|
| 依据 | `008`「太祖至陈留，散家财，合义兵，将以诛卓」；`104`「陈留孝廉卫兹以家财资太祖，使起兵，众有五千人」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两句话、两笔钱、一个数目。**钱的来路分两段写，人只有一个数** |

---

### 卡 8 · 开放题

**问：卫兹为什么肯把家财拿出来？**

答：**底本不回答。**

`104` 只记了他做的事：拿家财、资太祖、使起兵、众有五千人。**为什么，一个字没有。**

这一篇把这个问题留在「—」里，是有意的：不是产品不知道，是**那两句话里没有**——而知道自己不知道什么，和知道答案一样重要。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 开放题，而答案是「没有答案」：`104` 只记他做了什么，为什么，一个字没有 |
