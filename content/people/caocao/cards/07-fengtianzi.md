# 复习卡 · 场景 07 · 迎天子都许

> 原则：**先分清谁在做，再问为什么。**
> 这四段写的全是动作。这一篇的卡，问的是**谁先开口**，以及**哪一处史书不肯说**。

---

## 场景 07 · 迎天子都许（10 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 处境 ★

**问：这一篇开头，天子在哪儿？**

答：**在往东逃的路上。**

`031` 给他的是四个动作：长安乱、东迁、败于曹阳、渡河幸安邑。

这四个动作排在一句话里，写在这段的中段——**前面是曹操在东边打完吕布，后面才是曹操要迎他**。这一篇从这里起头：先给处境，再给那个要迎他的人。

| | |
|---|---|
| 依据 | `031`「是岁，长安乱，天子东迁，败于曹阳，渡河幸安邑」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的起点不是曹操，是天子那一头——**先有处境，才有迎** |

---

### 卡 2 · 因果 ★

**问：曹洪那一路，为什么没进去？**

答：**因为董承和苌奴守住了险要。**

`031` 的原文是「卫将军董承与袁术将苌奴拒险，洪不得进」——**不是打输了，是没过去**。这一句里没有一场仗，只有两个动作：他们守住险要，他进不去。

`031` 给这两个人的，一个是官名（卫将军），一个是主上（袁术的将）。**他们怎么并到一处守险的，一个字不写。**

| | |
|---|---|
| 依据 | `031`「卫将军董承与袁术将苌奴拒险，洪不得进」 |
| 标记 | ◆ 出自原文 |
| 考点 | 曹洪是这一篇里唯一动过兵的人，而**他的兵没有打出去**——第一次西迎，到险要为止 |

---

### 卡 3 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**六个，加两个「是岁」。**

- 春正月，太祖军临武平（`031`）
- 二月，进军讨破汝南、颍川黄巾（`031`）
- 夏六月，迁镇东将军，封费亭侯（`031`）
- 秋七月，杨奉、韩暹以天子还洛阳（`031`）
- 九月，车驾出轘辕而东（`033`）
- 冬十月，公征奉（`034`）

两个「是岁」不一样：`031` 头上那个是建安元年的前一年，`034` 尾上那个就是建安元年。

再往前数，这四段里只有年号没有公元：**196 年是后世的系年**。

| | |
|---|---|
| 依据 | `031`「建安元年春正月」「二月」「夏六月」「秋七月」；`033`「九月」；`034`「冬十月」「是岁」。**公元 196 年是后世的系年——四段里只有年号、月份和各段的起讫，没有公元纪年** |
| 标记 | ○ 外证 |
| 考点 | 六个刻度是底本给的；**公元年是外面加进来的坐标**。看到年份先分清这一点 |

---

### 卡 4 · 人物 ★

**问：这一篇里，围着天子的有哪几拨人？**

答：**五拨，都只有动作。**

- **送他回洛阳的**：杨奉、韩暹（`031`）
- **挡在路上、不让曹操的人过去的**：董承、苌奴（`031`）
- **劝曹操迎的**：荀彧、程昱（`031`）
- **把他接进洛阳、又接到许的**：曹操（`032`、`033`）
- **劝曹操把都城定在许的**：董昭（`033`）

五拨人之间没有一句话。**`031` 给的是动作，不是关系。**

| | |
|---|---|
| 依据 | `031`「荀彧、程昱劝之，乃遣曹洪将兵西迎，卫将军董承与袁术将苌奴拒险」；`031`「杨奉、韩暹以天子还洛阳」；`032`「太祖遂至洛阳」；`033`「董昭等劝太祖都许」 |
| 标记 | ○ 合理推演 |
| 考点 | 「五拨」是数出来的，四段里没有这一句。**要能说出每一拨各出自哪一句** |

---

### 卡 5 · 出处 ★

**问：这一篇的四段，是一本书里的吗？**

答：**是。`031`–`034` 都是《三国志·魏书·武帝纪》的正文，陈寿写的。**

这一篇没有注，也没有小说——四段同出一本书。相邻两篇不是这样：`03-chenliu` 的第二段来自裴松之注引的《世语》，`08-guandu` 有一段来自注引的《曹瞒传》。

**所以这一篇只有一支笔。**

| | |
|---|---|
| 依据 | `031`–`034`（都是《武帝纪》正文，陈寿） |
| 标记 | ◆ 出自原文 |
| 考点 | 同一页上可能有几支笔。**这一篇只有一支**：四段都是陈寿写的 |

---

### 卡 6 · 陷阱题 ⚠️

**问：「迎天子」这件事，是从曹操那一头开始的吗？**

答：**不是。天子那一头也在动。**

`031` 的次序是：先写「是岁，长安乱，天子东迁，败于曹阳，渡河幸安邑」，隔了两句，才写「太祖将迎天子」。

**两条线并排在同一段里**——他在东边刚把吕布赶走，天子在西边一路往东败。天子不是坐着等人来接的。

| | |
|---|---|
| 依据 | `031`「是岁，长安乱，天子东迁，败于曹阳，渡河幸安邑」；`031`「太祖将迎天子」 |
| 标记 | ◆ 出自原文 |
| 考点 | 天子也在路上。**这一点决定这一篇从哪儿起头**——不是从决定起头，是从处境起头 |

---

### 卡 7 · 陷阱题 ⚠️

**问：把朝廷搬到许，是谁先开口的？**

答：**董昭那一头。**

`033` 写的是「董昭等劝太祖都许」——劝的主语是董昭，「等」说明不止一个人。

天子点没点头、曹操怎么答应的，四段里一个字不写。往下紧接着的一句就是「九月，车驾出轘辕而东」。

| | |
|---|---|
| 依据 | `033`「洛阳残破，董昭等劝太祖都许」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的转折是都许，**先开口的不是曹操，也不是天子**——这一处最容易讲反 |

---

### 卡 8 · 数字 ★

**问：这一年，天子给了他哪些名号？**

答：**八个。**

- 兖州牧（`031`，前一年冬十月）
- 建德将军（`031`，二月之后）
- 镇东将军、费亭侯（`031`，夏六月）
- 大将军、武平侯（`033`，九月）
- 司空、行车骑将军（`034`，冬十月之后）

**名号换了三轮，分在三段里。**「八个」和它们的月份是数着读出来的。

| | |
|---|---|
| 依据 | `031`「冬十月，天子拜太祖兖州牧」「天子拜太祖建德将军，夏六月，迁镇东将军，封费亭侯」；`033`「以太祖为大将军，封武平侯」；`034`「天子拜公司空，行车骑将军」 |
| 标记 | ○ 合理推演 |
| 考点 | 迎天子这件事，落到纸面上是一串名号。**要能按月份把它们排回去** |

---

### 卡 9 · 一句话 ★

**问：如果用一句话说这一篇，说什么？**

答：**第一次派人，被挡在险要外；第二次自己进洛阳，把朝廷接到许，年底把大将军让给袁绍，开始屯田。**

`031` 给的是第一次：派曹洪带兵西迎，被董承和苌奴挡在险要外面。

`032`–`034` 给的是后面：进洛阳、卫京都、假节钺、录尚书事、都许、大将军、武平侯、征杨奉、让绍、司空、车骑将军、屯田。

**两次是同一个动作**，中间没有过渡句——`031`「洪不得进」之后，天子还洛阳要等到秋七月。

| | |
|---|---|
| 依据 | `031`「乃遣曹洪将兵西迎……洪不得进」；`032`「太祖遂至洛阳，卫京都，暹遁走」；`033`「九月，车驾出轘辕而东」；`034`「公乃固辞，以大将军让绍」「始兴屯田」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两次是同一个动作。**第一次他到的是险要外面，第二次他进的是洛阳城** |

---

### 卡 10 · 开放题

**问：曹操为什么要把天子迎来？**

答：**四段不回答这个问题。**

`031` 只有五个字：「太祖将迎天子」。他要迎，是写下来的；迎来做什么，一个字没有。

`032`–`034` 写的是他拿到了什么——节钺、录尚书事、大将军、武平侯、司空、车骑将军。**拿到什么是结果，不是理由。**

诸将疑的是什么、他为什么把大将军让出去，四段也都不答。这一篇把这些问题留在「—」里，是有意的：不是产品不知道，是**这四段里没有**。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 这一篇最重要的一个「—」：**动作全在，理由全不在**。知道自己不知道什么，和知道答案一样重要 |

### 这一篇的难点

**四段原文里，被人原样说出口的话一句都没有。** `031` 全是记事：谁在哪儿败了、派谁去迎、谁挡住了、谁把天子送回来、谁劝他把都城放在许；`034` 也一样，连杨奉想拦车驾都只写成「欲要之，不及」。

所以这一篇的卡不问台词，只问三件事：**这句话是谁做的**、**时间给了几个刻度**，和**哪一处是史书不肯说的**。
