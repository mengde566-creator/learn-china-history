# 复习卡 · 场景 07 · 迎天子都许

> 原则：**先分清谁在做，再问为什么。**
> 两段原文写的全是动作。这一篇的卡，问的是**谁先开口**，以及**哪一处史书不肯说**。

---

## 场景 07 · 迎天子都许（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：董昭为什么劝曹操把都城定在许？**

答：**因为洛阳残破了。**

`031` 把「洛阳残破」写在「董昭等劝太祖都许」前面，两件事连在同一句里。这是语序给的由头——**不是他嘴里说出来的理由**。

他为什么劝、劝了几次，这两段一个字不写。留「—」的是曹操那一头，见卡 8。

| | |
|---|---|
| 依据 | `033`、「洛阳残破，董昭等劝太祖都许」。**由头是从语序读出来的，不是他说的**—— 只记「劝」这个动作，理由不载 |
| 标记 | ○ 合理推演 |
| 考点 | 这一问问的是**董昭那一头**。曹操为什么迎天子，是另一个问题，史书不回答（卡 8） |

---

### 卡 2 · 陷阱题 ⚠️

**问：天子是自己回到洛阳的吗？**

答：**不是。是杨奉、韩暹把他送回去的。**

`031` 写的是「杨奉、韩暹以天子还洛阳」——天子是这句话的宾语。**他是被将领们带着走的一个人。**

同在这一段里，曹操到洛阳、韩暹遁走、天子把节钺交给他。一连串动作里，天子自己做的只有一件：`031`「天子假太祖节钺」。

| | |
|---|---|
| 依据 | `031–032`、「秋七月，杨奉、韩暹以天子还洛阳」；「太祖遂至洛阳，卫京都，暹遁走」；「天子假太祖节钺，录尚书事」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇里，天子做的只有一件事：**把节钺交出去**。其余的动作全是别人在动 |

---

### 卡 3 · 因果

**问：曹洪那一路，为什么没进去？**

答：**因为董承和苌奴守住了险要。**

`031` 的最后一句是「卫将军董承与袁术将苌奴拒险，洪不得进」——**不是打输了，是没过去**。这一句里没有一场仗，只有两个动作：他们守住险要，他进不去。

`031` 给这两个人的，一个是官名（卫将军），一个是主上（袁术手下的将）。**他们怎么并到一处守险的，一个字不写。**

| | |
|---|---|
| 依据 | `031`「卫将军董承与袁术将苌奴拒险，洪不得进」 |
| 标记 | ◆ 出自原文 |
| 考点 | 曹洪是这一篇里唯一动过兵的人，而**他的兵没有打出去**——第一次西迎，到险要为止 |

---

### 卡 4 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**两个月份，和一片空白。**

- 秋七月，杨奉、韩暹把天子送回洛阳
- 九月，车驾出轘辕往东

中间那一串——曹操到洛阳、卫京都、韩暹遁走、天子假节钺、录尚书事、洛阳残破、董昭等人劝都许——`031` 全挤在一段里，不给日子。

再往前数，这两段连年份都没有：**公元 196 年是后世的系年**，这两段里连年号也没有。

| | |
|---|---|
| 依据 | `033`、「秋七月」；「九月，车驾出轘辕而东」；**公元 196 年是后世的系年，这两段里连年号也没有** |
| 标记 | ○ 外证 |
| 考点 | 「秋七月」和「九月」是底本给的；**公元年是外面加进来的坐标**。看到年份先分清这一点 |

---

### 卡 5 · 人物

**问：这一篇里，围着天子的有哪几拨人？**

答：**三拨，都只有动作。**

- **送他回洛阳的**：杨奉、韩暹
- **挡在路上、不让曹操的人过去的**：董承、苌奴
- **把他接走往东的**：曹操

另外两个只留下名字的：劝曹操迎的是荀彧、程昱；劝他都许的是董昭。

三拨人之间没有一句话。**`031` `031` 给的是动作，不是关系。**

| | |
|---|---|
| 依据 | `031–033`、「荀彧、程昱劝之，乃遣曹洪将兵西迎，卫将军董承与袁术将苌奴拒险」；「杨奉、韩暹以天子还洛阳」「太祖遂至洛阳」「董昭等劝太祖都许」 |
| 标记 | ○ 合理推演 |
| 考点 | 「三拨」是数出来的，两段里没有这一句。**要能说出每一拨各出自哪一句** |

---

### 卡 6 · 出处

**问：这一篇的两段，是一本书里的吗？**

答：**是。`031` `031` 都是《三国志·魏书·武帝纪》的正文，陈寿写的。**

这一篇没有注，也没有小说——两段同出一本书。相邻两篇不是这样：`03-chenliu` 的第二段来自裴松之注引的《世语》，`08-guandu` 有一段来自注引的《曹瞒传》。

**所以这一篇只有一支笔。**

| | |
|---|---|
| 依据 | `031`；`031`（都是《武帝纪》正文，陈寿） |
| 标记 | ◆ 出自原文 |
| 考点 | 同一页上可能有几支笔。**这一篇只有一支**：两段都是陈寿写的 |

---

### 卡 7 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**他派了一次人，没过去；他自己走了一趟，把朝廷搬走了。**

`031` 给的是第一次：派曹洪带兵西迎，被董承和苌奴挡在险要外面。

`031` 给的是他自己到洛阳：卫京都、韩暹遁走、天子假节钺、录尚书事、董昭等人劝都许、九月车驾出轘辕而东，末尾是大将军、武平侯。

**两段是同一个动作的两次**，中间没有过渡句——`031`「洪不得进」之后，下一段一开头就是 `031`「秋七月」。

| | |
|---|---|
| 依据 | `031`「乃遣曹洪将兵西迎……洪不得进」；`032`「太祖遂至洛阳，卫京都，暹遁走」；`033`「九月，车驾出轘辕而东」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两次是同一个动作。**第一次他到的是险要外面，第二次他进的是洛阳城** |

---

### 卡 8 · 开放题

**问：曹操为什么要把天子迎来？**

答：**史书不回答这个问题。**

`031` 只有五个字：「太祖将迎天子」。他要迎，是写下来的；迎来做什么，一个字没有。

`031` 写他到了洛阳之后拿到了什么——节钺、录尚书事、大将军、武平侯。**拿到什么是结果，不是理由。**

诸将疑的是什么，他也不答。这一篇把这个问题留在「—」里，是有意的：不是产品不知道，是**那两段里没有**。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 这一篇最重要的一个「—」：**动作全在，理由全不在**。知道自己不知道什么，和知道答案一样重要 |

### 这一篇的难点

**两段原文里，被人原样说出口的话一句都没有。** `031` `031` 全是记事：派谁去、谁挡住了、谁把天子送回来、谁劝他把都城放在许。连天子的话都没有一句。

所以这一篇的卡不问台词，只问两件事：**这句话是谁做的**，和**哪一处是史书不肯说的**。
