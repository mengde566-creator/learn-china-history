# 复习卡 · 场景 07 · 迎天子都许

> 原则：**先分清谁在做，再问为什么。**
> 本纪四段串联迎奉、都许与授官，裴注234补足屯田。区分材料归属、政治建议和未录的私人考虑。

---

## 场景 07 · 迎天子都许（10 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 处境 ★

**问：这一篇开头，天子在哪儿？**

答：**在往东逃的路上。**

`031` 给他的是四个动作：长安乱、东迁、败于曹阳、渡河幸安邑。

这四个动作排在一句话里，写在这段的中段——**前面是曹操在东边打完吕布，后面才是曹操要迎他**。这一篇从这里起头：先给处境，再给那个要迎他的人。

| | |
|---|---|
| 依据 | `031`「是岁，长安乱，天子东迁，败于曹阳，渡河幸安邑」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的起点不是曹操，是天子那一头——**先有处境，才有迎** |

---

### 卡 2 · 因果 ★

**问：曹洪第一次西迎，为什么不得进？**

答：**正文记董承与袁术将苌奴拒守险要，曹洪不能前进。**

这里没有展开交战经过，不能由“不得进”直接断定打了一场败仗，也不能反过来断言一兵未战。本篇随后还记曹操讨黄巾、征杨奉，并非只有曹洪一路动过兵。

| | |
|---|---|
| 依据 | `031`「拒险，洪不得进」；`034` 征杨奉 |
| 标记 | ◆ 出自原文 |
| 考点 | 没有展开战况，不等于已经证明未战 |

---

### 卡 3 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**六个，加两个「是岁」。**

- 春正月，太祖军临武平（`031`）
- 二月，进军讨破汝南、颍川黄巾（`031`）
- 夏六月，迁镇东将军，封费亭侯（`031`）
- 秋七月，杨奉、韩暹以天子还洛阳（`031`）
- 九月，车驾出轘辕而东（`033`）
- 冬十月，公征奉（`034`）

两个「是岁」不一样：`031` 头上那个是建安元年的前一年，`034` 尾上那个就是建安元年。

再往前数，这四段里只有年号没有公元：**196 年是后世的系年**。

| | |
|---|---|
| 依据 | `031`「建安元年春正月」「二月」「夏六月」「秋七月」；`033`「九月」；`034`「冬十月」「是岁」。**公元 196 年是后世的系年——四段里只有年号、月份和各段的起讫，没有公元纪年** |
| 标记 | ○ 外证 |
| 考点 | 六个刻度是底本给的；**公元年是外面加进来的坐标**。看到年份先分清这一点 |

---

### 卡 4 · 人物 ★

**问：这一篇里，围着天子的有哪几拨人？**

答：**可按迎送、阻迎、劝迎、入洛与劝都许分看。**

- **送他回洛阳的**：杨奉、韩暹（`031`）
- **挡在路上、不让曹操的人过去的**：董承、苌奴（`031`）
- **劝曹操迎的**：荀彧、程昱（`031`）
- **到洛阳卫京都，随后奉迎都许的**：曹操（`032`、`033`）
- **劝曹操把都城定在许的**：董昭（`033`）

杨奉、韩暹使天子还洛阳，曹操随后到洛阳。正文有官职、隶属与劝说关系，只是没有把每次交谈展开成直接引语。

| | |
|---|---|
| 依据 | `031`「荀彧、程昱劝之，乃遣曹洪将兵西迎，卫将军董承与袁术将苌奴拒险」；`031`「杨奉、韩暹以天子还洛阳」；`032`「太祖遂至洛阳」；`033`「董昭等劝太祖都许」 |
| 标记 | ○ 合理推演 |
| 考点 | 「五拨」是数出来的，四段里没有这一句。**要能说出每一拨各出自哪一句** |

---

### 卡 5 · 出处 ★

**问：迎奉都许和许下屯田的细节，分别见于哪层材料？**

答：**迎奉、都许、授官和兴屯田见《武帝纪》正文；缺粮、许下募民和积谷的补充见裴松之注引《魏书》。**

`031`–`034`是陈寿本纪正文。末段另用`234`，其中收谷百万斛及州郡置田官属于注引材料。本篇没有采用小说。

两层材料可以对读，不能把裴注的补充说成陈寿在正文中逐项写出的细节，也不能说本纪没有写就等于史书都没有。

| | |
|---|---|
| 依据 | `031`–`034`；`234`裴松之注引《魏书》 |
| 标记 | ◆ 出自原文 |
| 考点 | 正文与注引别书分开，补充材料确实可查 |

---

### 卡 6 · 陷阱题 ⚠️

**问：「迎天子」这件事，是从曹操那一头开始的吗？**

答：**不是。天子那一头也在动。**

`031` 的次序是：先写「是岁，长安乱，天子东迁，败于曹阳，渡河幸安邑」，隔了两句，才写「太祖将迎天子」。

**两条线并排在同一段里**——他在东边刚把吕布赶走，天子在西边一路往东败。天子不是坐着等人来接的。

| | |
|---|---|
| 依据 | `031`「是岁，长安乱，天子东迁，败于曹阳，渡河幸安邑」；`031`「太祖将迎天子」 |
| 标记 | ◆ 出自原文 |
| 考点 | 天子也在路上。**这一点决定这一篇从哪儿起头**——不是从决定起头，是从处境起头 |

---

### 卡 7 · 补读 ⚠️

**问：本纪点名谁建议都许？别传补充了什么？**

答：**《武帝纪》点名董昭等劝曹操都许；《董昭传》还有一场讨论。**

本纪`033`先写洛阳残破，再记劝都许。《董昭传》建安元年段记董昭分析洛阳诸将各有异意、留驻不便，曹操回应这也是自己的本意，并询问杨奉会不会为累。

因此不能把本纪这一句扩成“只有董昭最先想到，曹操此前毫无此意”，也不能说曹操怎样回应在所有记载中都没有。

| | |
|---|---|
| 依据 | `033`；补充`120`《董昭传》正文 |
| 标记 | ○ 合理推演 |
| 考点 | 本纪点名建议者，不等于断定想法的唯一最初来源 |

### 卡 8 · 数字 ★

**问：这两年，史书记下哪些授官封爵？**

答：**八个名目，分在两年——头一个在前一年。**

- **195 年（前一年）冬十月**：兖州牧（`031`）
- **196 年（建安元年）**：建德将军（`031`，二月之后）、镇东将军、费亭侯（`031`，夏六月）、大将军、武平侯（`033`，九月）、司空、行车骑将军（`034`，冬十月之后）

这八个名目性质不同：**兖州牧、建德将军、镇东将军、大将军、司空是官**；**费亭侯、武平侯是封爵**；**行车骑将军是兼行**——「行」是代理，不是另授一个将军。**官、爵、兼行，不能并成「换了八次官职」。**

| | |
|---|---|
| 依据 | `031`「冬十月，天子拜太祖兖州牧」「天子拜太祖建德将军，夏六月，迁镇东将军，封费亭侯」；`033`「以太祖为大将军，封武平侯」；`034`「天子拜公司空，行车骑将军」——**兖州牧那一个在 195 年冬十月，其余都在 196 年** |
| 标记 | ○ 外证 |
| 考点 | 两年、八个名目：**要能按年份和月份排回去，也能分清官、封爵和兼行** |

---

### 卡 9 · 一句话 ★

**问：如果用一句话说这一篇，说什么？**

答：**先派曹洪西迎受阻，后来入洛并奉迎都许；让大将军给袁绍，同年又兴屯田、募民积粮。**

`031` 给的是第一次：派曹洪带兵西迎，被董承和苌奴挡在险要外面。

`032`–`034` 给的是后面：进洛阳、卫京都、假节钺、录尚书事、都许、大将军、武平侯、征杨奉、让绍、司空、车骑将军、屯田。

屯田的缺粮背景和许下募民见裴注`234`，不是本纪正文逐项展开的细节。

这是先派曹洪、后曹操赴洛阳的两步；中间还叙黄巾战事与天子还洛阳——`031`「洪不得进」之后，天子还洛阳要等到秋七月。

| | |
|---|---|
| 依据 | `031`「乃遣曹洪将兵西迎……洪不得进」；`032`「太祖遂至洛阳，卫京都，暹遁走」；`033`「九月，车驾出轘辕而东」；`034`「公乃固辞，以大将军让绍」「始兴屯田」；`234`裴注引《魏书》 |
| 标记 | ◆ 出自原文 |
| 考点 | 第一次是曹洪受阻，第二次是曹操入洛；人物与步骤不混 |

### 卡 10 · 补读

**问：迎奉天子的理由，只能从后来得到的官爵猜吗？**

答：**不必。《荀彧传》保存了劝迎的政治论证。**

该传建安元年段记荀彧主张奉主上以从民望、秉至公以服雄杰、扶弘义以致英俊；曹操随后赴洛阳、奉迎都许。这段在天子已经返洛的背景下记述，不能搬成曹洪首次西迎前两人的同场逐字劝辞，也不是曹操全部私人想法。

让大将军给袁绍也并非毫无语境：本纪`034`先写袁绍耻位在曹操之下、不肯受太尉，随后写曹操固辞、以大将军让绍。已有缘由和行动的承接，不必抹成理由全空。

| | |
|---|---|
| 依据 | `031`、`034`；补充`119`《荀彧传》正文 |
| 标记 | ○ 合理推演 |
| 考点 | 人物建议、叙述语境与个人全部心思分开读 |

### 这一篇的难点

**四段原文里，被人原样说出口的话一句都没有。** `031` 全是记事：谁在哪儿败了、派谁去迎、谁挡住了、谁把天子送回来、谁劝他把都城放在许；`034` 也一样，连杨奉想拦车驾都只写成「欲要之，不及」。

所以这一篇的卡不问台词，只问三件事：**这句话是谁做的**、**时间给了几个刻度**，和**哪一处是史书不肯说的**。
