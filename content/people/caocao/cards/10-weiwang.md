# 复习卡 · 场景 10 · 魏王

> 原则：**先问名号从哪儿来，再问那篇诏书给了什么，最后问结尾那一段是谁在说话。**
> 这一篇的题库里有两类题最要紧：一类是**出处题**（十七段里大半是诏书和遗令的原文），
> 一类是**沉默题**（谁下的令、为什么辞让、九锡是哪九样，全掉在缝里）。

---

## 场景 10 · 魏王（13 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 出处题 ★

**问：魏公、魏王这两个名号，是谁给的？**

答：**天子。一次是派人来策命，一次是下诏进爵。**

`074` 写的是：一天、一个使者、一样信物、一个爵位。

> 「五月丙申，天子使御史大夫郗虑持节策命公为魏公。」（`074`）

`097` 更短，全段只有十一个字：

> 「夏五月，天子进公爵为魏王。」（`097`）

**两个动作的主语都是天子**：一个是「使」，一个是「进」。两句里，他都在被策命、被进爵的那一头。

| | |
|---|---|
| 依据 | `074`「五月丙申，天子使御史大夫郗虑持节策命公为魏公」；`097`「夏五月，天子进公爵为魏王」 |
| 标记 | ◆ 出自原文 |
| 考点 | 记住**主动权在哪一头**：封是天子的使者来封的，进也是天子进的。这是这一篇最要紧的制度事实 |

---

### 卡 2 · 出处题

**问：赞拜不名、入朝不趋、剑履上殿——这三样是什么？照谁的旧例？**

答：**是天子给的礼遇，照汉初萧何的旧例。**

> 「天子命公赞拜不名，入朝不趋，剑履上殿，如萧何故事。」（`074`）

三样说的都是他见天子时的体面：报名不称名、上朝不用小步快走、上殿可以带剑穿鞋。

**同一年还有一步**：割河内、东郡、钜鹿、广平、赵的十四县，以益魏郡——**名号先在土地上垫起来**，第二年五月才有「魏公」。

| | |
|---|---|
| 依据 | `074`「天子命公赞拜不名，入朝不趋，剑履上殿，如萧何故事」；`074`「割河内之荡阴、朝歌、林虑，东郡之卫国、顿丘、东武阳、发干，钜鹿之瘿陶、曲周、南和，广平之任城，赵之襄国、邯郸、易阳以益魏郡」 |
| 标记 | ◆ 出自原文 |
| 内部 | 这份先例是什么、为什么用，`074` 都不写；三样各自的仪注是后世训释 |
| 考点 | **先有礼遇和疆域，后有爵位。** 别把这一年读成一句话——它是两步 |

---

### 卡 3 · 数字题 ★

**问：从公到王，正文一共用了几个字？**

答：**八个字。**

> 「夏五月，天子进公爵为魏王。」（`097`）

全段十一个字：**「夏五月」三个字是时间，说这件事的是后面八个字——天子进公爵为魏王。**

紧接着下一段也是十一个字：**「魏王上书三辞，诏三报不许。」**（`098`）

**两件事合起来不到二十个字。** 下面是南征、是崩、是遗令。

| | |
|---|---|
| 依据 | `097`「夏五月，天子进公爵为魏王」；`098`「魏王上书三辞，诏三报不许」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的体量感从这里来：**一步登位的正文，比那篇诏书的任何一段都短**。对照 `078`、`079` 两段加起来六百多字 |

### 卡 4 · 出处题

**问：封魏公那篇诏书，除了夸他，到底给了什么？**

答：**三样：十郡、一个爵位、一套加礼。**

> 「今以冀州之河东、河内、魏郡、赵国、中山、常山、钜鹿、安平、甘陵、平原凡十郡，封君为魏公。」（`080`）

> 「其以丞相领冀州牧如故。」（`080`）

> 「又加君九锡，其敬听朕命。」（`080`）

**十郡是土，魏公是爵，九锡是礼。** 中间那一句最实：**爵位升到公，丞相和冀州牧都照旧。**

**九样是哪九样，这几段看不到**——一样一样开下去的文字在本篇这几段之后。

| | |
|---|---|
| 依据 | `080`「今以冀州之河东、河内、魏郡、赵国、中山、常山、钜鹿、安平、甘陵、平原凡十郡，封君为魏公」「其以丞相领冀州牧如故」「又加君九锡，其敬听朕命」 |
| 标记 | ◆ 出自原文 |
| 考点 | 诏书的结构：**先数功（`078`、`079`），后给赏（`080`）**。要能说出给的是三样，不是一样 |

### 卡 5 · 因果题

**问：诏书里那一句「此又君之功也」，一共出现了几处？**

答：**十处。加上开头那句「此君之忠于本朝也」，一共十一处。**

一件一件数下去：董卓、黄巾、韩暹杨奉、袁术、吕布张杨眭固张绣、袁绍与官渡、河北四州、乌丸、刘表、马超成宜、鲜卑丁零。

**数功在前，给赏在后。** 一句一收尾，排到「君有定天下之功，重之以明德」，才轮到十郡、魏公、九锡。

| | |
|---|---|
| 依据 | `078`「此君之忠于本朝也」「此又君之功也」；`079`「此又君之功也」「君有定天下之功，重之以明德」——**十一处是数出来的**：`078` 里五处，`079` 里六处 |
| 标记 | ○ 合理推演 |
| 内部 | 「十一处」是并读两段数出来的，不是哪一段里的某一句话——所以这张卡标推演 |
| 考点 | 记住**这个句式的密度**：它不是修辞，是一份功劳清单的刻度 |

### 卡 6 · 陷阱题 ⚠️

**问：魏王之后，他称帝了吗？**

答：**这几段里没有即位这回事。**

`097` 给他的最高名号是魏王。`110` 记的是「王崩于洛阳」，然后是「谥曰武王」——**这几段里最高的名号是王，死后是武王，没有一句写他即位**。

所以**他没有称帝**这句话，凭这几段站得住。

**陷阱在这儿**：称帝的是他儿子。而那是《魏书·文帝纪》里的事，**不在本篇这十七段里**——这几段里没有这个人，也没有「皇帝」两个字。

| | |
|---|---|
| 依据 | `097`「夏五月，天子进公爵为魏王」；`110`「庚子，王崩于洛阳，年六十六」；`111`「谥曰武王。二月丁卯，葬高陵」 |
| 标记 | ○ 合理推演 |
| 内部 | **硬拦截**：本条回答里不得出现「文帝」「追尊」「受禅」作为他的事 |
| 考点 | **没有即位**是这几段能证的；**他想不想**这几段不答——那是下一张卡。两件事不能混 |

### 卡 7 · 开放题

**问：他到底想没想过那个位子？**

答：**这几段不回答。**

从 `074` 到 `112`，只记他受礼遇、受策命、进爵、南征、崩、遗令，加上一段别人的评。**他有没有这个念头，一个字都没有。**

**这一问留在「—」里是有意的**：不是产品不知道，是**这几段不知道**——知道自己不知道什么，和知道答案一样重要。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 内部 | 映射表里这一行是「—」。**注意 `112` 的「总御皇机」是评语里的说法，不是即位的记载**——别拿它当证据 |
| 考点 | 这一篇最重要的一个「—」：**没有即位能证，他想不想不能证**。上一张卡证的是前一件，这一张问的是后一件 |

### 卡 8 · 人物题

**问：来策命的那个使者，是谁？**

答：**御史大夫郗虑，持节而来。**

`074` 一句话给了他三样东西：官名（御史大夫）、信物（节）、差事（策命公为魏公）。

**他是这一篇里最早被写出名字的活人**——天子没有名字，普富卢、呼厨泉、去卑、锺繇都要到 `099` 才出现。

那一句里三个位置：天子在下令，郗虑在奉节宣读，曹操在受策命。**三个人谁都没有说话。**

| | |
|---|---|
| 依据 | `074`「五月丙申，天子使御史大夫郗虑持节策命公为魏公」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇里第一个有名字的人。要能说出**他手里拿的是「节」——那是天子使者的凭信** |

### 卡 9 · 人物题

**问：`099` 里来的那两个单于，是谁？**

答：**代郡乌丸行单于普富卢，匈奴南单于呼厨泉。**

| 谁 | 从哪儿来 | 后来怎么着 |
|---|---|---|
| 普富卢（代郡乌丸行单于） | 与他的侯王来朝 | 这一段没写 |
| 呼厨泉（匈奴南单于） | 将他的名王来朝 | 待以客礼，**遂留魏**；使右贤王去卑监其国 |

**一个这一头空着，一个来了就没让他回去。** 同一段里还有两件事：天子命王女为公主，食汤沐邑；八月，以大理锺繇为相国。

| | |
|---|---|
| 依据 | `099`「代郡乌丸行单于普富卢与其侯王来朝」「天子命王女为公主，食汤沐邑」「秋七月，匈奴南单于呼厨泉将其名王来朝，待以客礼，遂留魏，使右贤王去卑监其国。八月，以大理锺繇为相国」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一句话里四个动作。要能说出**「遂留魏」三个字的分量**：来的不只一趟朝见 |

### 卡 10 · 收尾题 ★

**问：这一篇的最后一段，是谁在说话？**

答：**写传的人。那一段是「评曰」，不是记事。**

> 「评曰：汉末，天下大乱，雄豪并起」（`112`）

接着那一句说的是对面的分量：袁绍占着四个州，强盛，没有人挡得住。然后才转到他：

> 「太祖运筹演谋，鞭挞宇内，揽申、商之法术，该韩、白之奇策，官方授材，各因其器，矫情任算，不念旧恶，终能总御皇机，克成洪业者，惟其明略最优也。」（`112`）

最后一句是断语：

> 「抑可谓非常之人，超世之杰矣。」（`112`）

**这一篇到这里才收住。** 不收这一段，结尾就停在遗令上。

| | |
|---|---|
| 依据 | `112`「评曰：汉末，天下大乱，雄豪并起」「太祖运筹演谋，鞭挞宇内，揽申、商之法术，该韩、白之奇策，官方授材，各因其器，矫情任算，不念旧恶，终能总御皇机，克成洪业者，惟其明略最优也」「抑可谓非常之人，超世之杰矣」 |
| 标记 | ◆ 出自原文 |
| 内部 | 「评曰」是作者的话，和史料的沉默是两回事。`112` 只署「评」，不署名 |
| 考点 | **能背出那句断语**，并且能说清它和纪事的区别：纪事记动作，这一段给评价 |

### 卡 11 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**四个年份，一片空白。**

`074` 是「十七年春正月」——礼遇和益魏郡那一年；`095` 是「二十一年春二月」——亲耕籍田那一年；`110` 是「二十五年春正月」——崩于洛阳那一年。中间还有一个「十八年」，在 `074` 里（进军濡须口那一年）。

**这四个年序都不带年号**：没有「建安」两个字，也没有公元纪年。**公元 212 年到 220 年**是后世的换算，属外证，不是这几段里的字。

所以这一篇排得出来的，只有十七段自己的先后：**台阶 → 策命 → 亲耕 → 进爵 → 来朝 → 南征 → 崩 → 遗令 → 评曰**。中间隔多久，一律不知道。

| | |
|---|---|
| 依据 | `074`「十七年春正月」「十八年春正月」；`095`「二十一年春二月」；`110`「二十五年春正月」——**均无年号，公元年份是后世的换算，属外证** |
| 标记 | ○ 外证 |
| 考点 | 这几段给的是**年序**，不给年号。看到年份先分清：这是原文里的，还是外面加进来的坐标 |

### 卡 12 · 沉默题

**问：这一篇最要紧的沉默是哪几处？**

答：**四处：谁下的令、为什么辞让、九锡是哪九样、那个谁都不能替他答的问题。**

一是**是谁下的令**——`074` 只写一个「割」字，不写主语；二是**他为什么辞让三次**——`098` 只有十一个字，不写理由；三是**九锡是哪九样**——`080` 只到「又加君九锡」这一句；四是**他到底想不想称帝**——`097` 给到魏王，`111` 给到武王，再往上没有。

四处都在映射表里标着「—」。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 四处沉默：**谁下的令、为什么辞、九锡是哪九样、他想不想**——这几段把动作写全了，理由和名录一个不给 |

### 卡 13 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**天子一步一步把他送到魏王，他自己留下一道遗令，最后一段留给别人去评。**

送的那几步都在原文里：赞拜不名、剑履上殿、割州县以益魏郡（`074`）；策命为魏公（`074`）；进爵魏王（`097`）。他这一头只有两次开口的痕迹：上书三辞（`098`），和那道遗令（`111`）。

**这一篇的最后一段话不是功业，是安排**：不要久遵古礼，葬完除服，屯戍的不许离部，各官署各办自己的事，入殓用平时的衣服、不放金玉珍宝。

**再往后一段，是别人的八个字**：非常之人，超世之杰。

| | |
|---|---|
| 依据 | `074`「天子命公赞拜不名，入朝不趋，剑履上殿，如萧何故事」；`097`「天子进公爵为魏王」；`111`「遗令曰：『天下尚未安定，未得遵古也』」；`112`「抑可谓非常之人，超世之杰矣」 |
| 标记 | ◆ 出自原文 |
| 考点 | 收尾的一句：**名号是天子和土地一步步给的，最后留下的是他自己安排的一道遗令，和别人的一句评** |

### 这一篇的难点

**十七段原文里，被引出声音的地方有四处，其中两处是文书。** `075`–`080` 是天子在诏书里说话，`111` 是他自己的遗令，`112` 是作者出面下的判词；剩下的都是记事，最长的记事也不过一两句。

所以这一篇的卡只问三件事：**名号是从谁那儿来的**、**那篇诏书到底给了什么**、**哪几处是这几段不肯说的**。

**「他到底想不想称帝」在一篇讲魏王的题目里绕不开**，所以卡 6 和卡 7 分开放：一张证没有即位，一张把想不想留在沉默里。**两张卡说的不是一件事**，答题时不能混。
