# 复习卡 · 场景 10 · 魏王

> 原则：**先问名号从哪儿来，再问遗令交代了什么。**
> 这一篇的题库有一半是**沉默题**——三段加起来一百多字，问得出的事多，答得出的少。

---

## 场景 10 · 魏王（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 出处题 ★

**问：魏公、魏王这两个名号，是谁给的？**

答：**天子。一次是派人来策命，一次是下诏进爵。**

`074` 写的是：一天、一个使者、一样信物、一个爵位。

> 「五月丙申，天子使御史大夫郗虑持节策命公为魏公。」（`074`）

这句话里做主的是天子的使者，不是他。

`097` 更短：

> 「夏五月，天子进公爵为魏王。」（`097`）

**「进」这个动作也是天子做的。**两句里，他都在被策命、被进爵的那一头。

| | |
|---|---|
| 依据 | `074`「五月丙申，天子使御史大夫郗虑持节策命公为魏公」；`097`「夏五月，天子进公爵为魏王」 |
| 标记 | ◆ 出自原文 |
| 考点 | 记住**主动权在哪一头**：封是天子的使者来封的，进也是天子进的。这是这一篇最要紧的制度事实 |

---

### 卡 2 · 遗令 ★

**问：他留下的遗令，一共交代了几件事？**

答：**五句，全是安排。**

`110` 把五句连排在一处：

> 「天下尚未安定，未得遵古也。葬毕，皆除服。其将兵屯戍者，皆不得离屯部。有司各率乃职。敛以时服，无藏金玉珍宝。」（`111`）

分头看是五件事：不按古礼办，理由是他自己给的；葬完就脱丧服；带兵屯守的人，都不许离开驻地；各官署各办自己的事；入殓穿平时的衣服，不放金玉珍宝。

**五句朝一个方向：丧事从简，事情照办。**没有一句风景，也没有一句功业。

他从头到尾只说了一个理由，就是那第一句：「天下尚未安定」。

| | |
|---|---|
| 依据 | `111`、「遗令曰：『天下尚未安定，未得遵古也。葬毕，皆除服。其将兵屯戍者，皆不得离屯部。有司各率乃职。敛以时服，无藏金玉珍宝』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 记住**五句的方向**：简的是丧事，不停的是职事与屯戍——连军队都不许离开驻地 |

---

### 卡 3 · 陷阱题 ⚠️

**问：魏王之后，他称帝了吗？**

答：**这三段里没有即位这回事。**

`097` 给他的最高名号是魏王。`110` 记的是「王崩于洛阳」，然后是「谥曰武王」——**全篇最高的名号是王，死后是武王，没有一句写他即位**（`110`）。

所以**他没有称帝**这句话，凭这三段站得住。

**陷阱在这儿**：称帝的是他儿子。而那是《魏书·文帝纪》里的事，**不在本篇这三段里**——这三段里没有这个人，也没有「皇帝」两个字。

| | |
|---|---|
| 依据 | `097`「夏五月，天子进公爵为魏王」；`110`「庚子，王崩于洛阳，年六十六」……「谥曰武王」 |
| 标记 | ○ 合理推演 |
| 考点 | **没有即位**是这三段能证的；**他想不想**这三段不答——那是下一张卡。两件事不能混 |

---

### 卡 4 · 开放题

**问：他到底想没想过那个位子？**

答：**这三段不回答。**

`074`–`110` 只记他受策命、进爵、崩、葬。他有没有这个念头，一个字都没有。

**这一问留在「—」里是有意的**：不是产品不知道，是**史书不知道**——知道自己不知道什么，和知道答案一样重要。

| | |
|---|---|
| 依据 | |
| 标记 | — 史书未载，且推不出来 |
| 考点 | 这一篇最重要的一个「—」：**没有即位能证，他想不想不能证**。上一张卡证的是前一件，这一张问的是后一件 |

---

### 卡 5 · 人物

**问：来策命的那个使者，是谁？**

答：**御史大夫郗虑，持节而来。**

`074` 一句话给了他三样东西：官名（御史大夫）、信物（节）、差事（策命公为魏公）。

**他是这一篇里唯一被写出名字的活人**——天子没有名字，带兵屯守的、各官署的，都没有名字。

那一句里三个位置：天子在下令，郗虑在奉节宣读，曹操在受策命。**三个人谁都没有说话。**

| | |
|---|---|
| 依据 | `074`「五月丙申，天子使御史大夫郗虑持节策命公为魏公」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇只有一句话里有活人的名字。要能说出**他手里拿的是「节」——那是天子使者的凭信** |

---

### 卡 6 · 因果

**问：遗令为什么写得这么细？**

答：**因为他给的理由是「天下尚未安定」——丧事要从简，事情不能停。**

遗令五句：三句是减法——不遵古礼、葬毕除服、敛以时服且无藏金玉珍宝；一句是加法——有司各率乃职；一句是禁令——将兵屯戍者不得离屯部。

**丧事从简**这一层是原文给的，理由也在原文里；**他不放心，所以先替别人定下来**这一层是推的——三段里没有一句话说到他的顾虑。

| | |
|---|---|
| 依据 | `111`、「遗令曰：『天下尚未安定，未得遵古也。葬毕，皆除服。其将兵屯戍者，皆不得离屯部。有司各率乃职。敛以时服，无藏金玉珍宝』」——**五句的方向是并读这五句推出来的；他为什么这么安排，这一句不写** |
| 标记 | ○ 合理推演 |
| 考点 | 分清两层：**理由是他自己说的，顾虑是我们推的** |

---

### 卡 7 · 时间线

**问：这一篇里，时间给了几个刻度？**

答：**三个日子，和一片空白。**

`074` 给的是「五月丙申」——策命为魏公的那一天。

`097` 只给到月：「夏五月」——进爵魏王。

`110` 给了两个：「庚子」崩于洛阳，「二月丁卯」葬高陵。

三段通篇不记年份：没有年号，也没有公元纪年。**公元 213 – 220 年**是后世的换算，属外证，不是这三段里的字。

所以这一篇排得出来的，只有三段的先后：**策命为魏公 → 进爵魏王 → 崩、葬**。中间隔多久，一律不知道。

| | |
|---|---|
| 依据 | `074`「五月丙申」；`097`「夏五月」；`110`「庚子」「二月丁卯」——**三段均无系年，公元年份是后世的换算，属外证** |
| 标记 | ○ 外证 |
| 考点 | 底本给的是**日、月、日**，年份一个都没有。看到年份先分清：这是三段里的，还是外面加进来的坐标 |

---

### 卡 8 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**天子策命他为魏公，又进爵为魏王；再往后，只剩一道遗令和一座高陵。**

往上走的那两步，底本写下来只有两句话。第三步没有了——`110` 给他的是「王崩于洛阳」，然后是「谥曰武王。二月丁卯，葬高陵」。

**这一篇的最后一段话不是功业，是安排**：不要久丧，葬完除服，屯戍的不许离部，各官署各办自己的事，入殓用平时的衣服、不放金玉珍宝。

十篇到这里收尾。他这一生最高的名号，是魏王。

| | |
|---|---|
| 依据 | `074`「天子使御史大夫郗虑持节策命公为魏公」；`097`「天子进公爵为魏王」；`110`「王崩于洛阳」……「谥曰武王。二月丁卯，葬高陵」 |
| 标记 | ◆ 出自原文 |
| 考点 | 收尾的一句：**往上走的两步是天子给的，最后留下的是他自己安排的一道遗令** |

### 这一篇的难点

**三段原文里，活人说过的话一句都没有。** `074` 是记事，`097` 是八个字，`110` 除了遗令，只剩崩、谥、葬三个动作。

所以这一篇的卡不问台词。它问两件事：**名号是从谁那儿来的**，和**哪几处是这三段不肯说的**。

遗令是唯一一段连着的话，而且是他自己说的——所以卡 2 把它整段摊开，一句一句对。
