# 复习卡 · 场景 10 · 魏王

> 原则：**先问名号从哪儿来，再问那篇诏书给了什么，最后问结尾那一段是谁在说话。**
> 这一篇兼读授爵、魏国官制、晚年战事、遗令和史家评语；把有材料可查的制度与仍未能判定的私人动机分开。

---

## 场景 10 · 魏王（13 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 出处题 ★

**问：魏公、魏王这两个名号，记载怎样授予？**

答：**以天子名义策命、进爵：先使郗虑持节策命魏公，后进爵魏王。**

这是记载中的授爵形式与制度名义，不能只凭句子的主语，就断定当时实际政治主动权全在天子一人，或曹操没有参与推动。

| | |
|---|---|
| 依据 | `074` 策命魏公；`097` 进爵魏王 |
| 标记 | ◆ 出自原文 |
| 考点 | 制度名义与实际权力，不由一个语法主语直接等同 |

---

### 卡 2 · 出处题

**问：入朝礼遇、魏郡扩域与受封魏公，先后怎样？**

答：**建安十七年先受入朝礼遇、扩大魏郡；十八年五月才封魏公。**

礼遇包括赞拜不名、入朝不趋、剑履上殿，照萧何旧例。十四县来自河内、东郡、钜鹿、广平、赵五郡国。十八年正月濡须进军、四月还邺，五月策命。

这是记载可核的先后，不能把同段选录误读成所有事情都在同一年。

| | |
|---|---|
| 依据 | `074`。 |
| 标记 | ◆ 出自原文 |
| 考点 | 读清074内部跨年，不只看到段号相同 |

---

### 卡 3 · 衔接 ★

**问：进爵魏王之后，辞让怎样记？**

答：**建安二十一年夏五月进爵；魏王三次上书辞让，诏三次答复不许。**

正文给出文书往返的提要。裴注297、298还保存策命与答辞，不应说所有诏答文字都不存在。私人考虑与文书礼辞仍须分开。

| 考点 | 年序、正文提要与注文文书相接 |

### 卡 4 · 出处题

**问：封魏公的诏书，给了什么制度内容？**

答：**以十郡封魏公，加九锡，并准魏国置丞相以下百官；曹操仍以汉丞相领冀州牧。**

九锡第一项车马已从080开始，其余在081、082续列。魏国官制见082，依汉初诸侯王之制。

魏公不只是改了称呼：文书还授予封土、礼物与置官制度；不能将这些可查内容说成底本一个字也没讲。

| | |
|---|---|
| 依据 | `080`–`082`。 |
| 标记 | ◆ 出自原文 |
| 考点 | 汉朝官职、魏公爵位、魏国官署分开 |

### 卡 5 · 因果题

**问：诏书里那一句「此又君之功也」，一共出现了几处？**

答：**十处。加上开头那句「此君之忠于本朝也」，一共十一处。**

一件一件数下去：董卓、黄巾、韩暹杨奉、袁术、吕布张杨眭固张绣、袁绍与官渡、河北四州、乌丸、刘表、马超成宜、鲜卑丁零。

**数功在前，给赏在后。** 一句一收尾，排到「君有定天下之功，重之以明德」，才轮到十郡、魏公、九锡。

| | |
|---|---|
| 依据 | `078`「此君之忠于本朝也」「此又君之功也」；`079`「此又君之功也」「君有定天下之功，重之以明德」——**十一处是数出来的**：`078` 里五处，`079` 里六处 |
| 标记 | ○ 合理推演 |
| 内部 | 「十一处」是并读两段数出来的，不是哪一段里的某一句话——所以这张卡标推演 |
| 考点 | 看清封赏文书以列功衔接授赏的组织方式，不把褒辞当成逐项独立核实 |

### 卡 6 · 辨析 ⚠️

**问：曹操生前为魏王，为什么本纪开头又称武皇帝？**

答：**生前止于魏王，帝号属于后来追尊，两种称呼有时间层次。**

《武帝纪》记进爵魏王、王崩、谥武王；《文帝纪》记曹丕先嗣魏王，后来即皇帝位，并追尊曹操为武皇帝。因此开篇称太祖武皇帝，不应倒写成曹操生前已经即帝位。

| | |
|---|---|
| 依据 | `001`、`097`、`110`–`111`；外证《三国志·魏书·文帝纪》即位及追尊段 |
| 标记 | ○ 外证 |
| 考点 | 生前爵位、死后谥号与后来追尊分别读 |

### 卡 7 · 补读

**问：关于进一步称帝，裴注保存了哪些说法？**

答：**不是一个字都没有，既有劝进，也有回应与互相不同的记载。**

`309`同条先引《魏略》孙权称说天命、陈群桓阶劝进，又引《魏氏春秋》夏侯惇劝说与曹操“若天命在吾，吾为周文王矣”的回应；另列《曹瞒传》《世语》的不同说法，并附孙盛批评。

这些可以说明传世材料怎样记劝进与表态；不能把其中一种直接当作曹操完整私心的终审结论，也不能因有分歧便抹掉所有记录。

| | |
|---|---|
| 依据 | 跨篇补充 `309`，同条多书及孙盛评论 |
| 标记 | ○ 合理推演 |
| 考点 | 表态可查，私人意图仍须审慎；异说与评论不混 |

### 卡 8 · 人物题

**问：来策命魏公的使者是谁，带了什么？**

答：**御史大夫郗虑，持节而来策命曹操为魏公。**

`074`概述使者身份、凭信与差事；随后`075`–`082`是策命文书。文书以天子口吻颁布，裴注`282`记潘勖之辞，不能把奉使、宣读与起草当作同一身份。

### 卡 9 · 人物题

**问：`099` 里来的那两个单于，是谁？**

答：**代郡乌丸行单于普富卢，匈奴南单于呼厨泉。**

| 谁 | 从哪儿来 | 后来怎么着 |
|---|---|---|
| 普富卢（代郡乌丸行单于） | 与他的侯王来朝 | 这一段没写 |
| 呼厨泉（匈奴南单于） | 将他的名王来朝 | 待以客礼，**遂留魏**；使右贤王去卑监其国 |

**普富卢此后行止本段未录，呼厨泉则明记留魏。** 不据此确定他终身不能返回。 同一段里还有两件事：天子命王女为公主，食汤沐邑；八月，以大理锺繇为相国。

| | |
|---|---|
| 依据 | `099`「代郡乌丸行单于普富卢与其侯王来朝」「天子命王女为公主，食汤沐邑」「秋七月，匈奴南单于呼厨泉将其名王来朝，待以客礼，遂留魏，使右贤王去卑监其国。八月，以大理锺繇为相国」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一句话里四个动作。要能说出**「遂留魏」三个字的分量**：来的不只一趟朝见 |

### 卡 10 · 收尾题 ★

**问：这一篇的最后一段，是谁在说话？**

答：**陈寿在本纪篇末集中作评价，也在评论中回顾局面。**

> 「评曰：汉末，天下大乱，雄豪并起」（`112`）

接着那一句说的是对面的分量：袁绍占着四个州，强盛，没有人挡得住。然后才转到他：

> 「太祖运筹演谋，鞭挞宇内，揽申、商之法术，该韩、白之奇策，官方授材，各因其器，矫情任算，不念旧恶，终能总御皇机，克成洪业者，惟其明略最优也。」（`112`）

最后一句是断语：

> 「抑可谓非常之人，超世之杰矣。」（`112`）

**这一篇到这里才收住。** 不收这一段，结尾就停在遗令上。

| | |
|---|---|
| 依据 | `112`「评曰：汉末，天下大乱，雄豪并起」「太祖运筹演谋，鞭挞宇内，揽申、商之法术，该韩、白之奇策，官方授材，各因其器，矫情任算，不念旧恶，终能总御皇机，克成洪业者，惟其明略最优也」「抑可谓非常之人，超世之杰矣」 |
| 标记 | ◆ 出自原文 |
| 内部 | 「评曰」是作者的话，和史料的沉默是两回事。`112` 只署「评」，不署名 |
| 考点 | **能背出那句断语**，并且能说清它和纪事的区别：按年纪事与篇末评论的侧重不同，不把评论中的史事抹掉 |

### 卡 11 · 时间线

**问：本篇如何从魏公、魏王走到最后的战事与身后？**

答：**十七年受礼遇，十八年封魏公，二十一年进魏王，二十四年南征关羽，二十五年去世。**

二十四年先有汉中进退，再有于禁军没、曹仁被围、徐晃救援；曹操从洛阳南征未至，徐晃已解围。次年正月回洛阳、庚子卒，二月丁卯葬高陵。

建安年号承本纪上下文，公元212、213、216、219、220年才是现代换算。选段省略年号，不能当作这些月日无从分年。

| | |
|---|---|
| 依据 | `074`、`095`–`099`、`105`–`111`；建安年号承本纪。 |
| 标记 | ○ 外证 |
| 考点 | 不把两次回邺与相隔数年的战事挤在同一年 |

### 卡 12 · 辨析

**问：正文提要没展开的事，是否就都无材料可查？**

答：**不是。先分清正文、注文文书与没有交代的私人考虑。**

九锡与魏国置官在080–082；282记潘勖作策辞，并引《魏书》等保存魏公辞让和群臣劝进；进爵魏王的策命与答辞见297、298；更进一步的劝进与表态异说见309。

有文书不等于私人用意全部确定；正文没有展开，也不能改说所有史书都无记录。

### 卡 13 · 一句话

**问：如果用一句话说这一篇，说什么？**

答：**曹操以天子名义受封魏公、进爵魏王，晚年仍有战事；他留下遗令，陈寿留下评语。**

生前的魏王、死后谥武王与后来追尊武皇帝有时间层次；本篇不把名义授爵当作全部权力关系，也不把陈寿的称赞冒充曹操自评。

诏书列功之后，战事仍在继续；遗令的第一句也仍是天下尚未安定。

| | |
|---|---|
| 依据 | `074`、`080`–`082`、`097`、`105`–`112`；追尊外证见卡6。 |
| 标记 | ◆ 出自原文 |
| 考点 | 时序清楚，主体各归其位 |

### 这一篇的难点

本篇22段原文跨建安十七年至二十五年，兼有记事、策书、命令、遗令与史家评价。魏公策书的作者、名义颁布者、使者不是同一层次；魏国相国与汉朝丞相也不能只按字面排序。

卡片既要让读者记住行动和制度变化，也要分清人物表态与完整私心。未答比例、段数字数及检验通过，都不作为史书全无心理或内容已无遗漏的证据。
