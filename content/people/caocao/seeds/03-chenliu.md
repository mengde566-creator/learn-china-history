## 五、系统层（9 条）

> **不是问历史人物，是问产品本身。**
> 无 AI 时这一类尤其重要——它是唯一能告诉用户"为什么有些问题没有答案"的入口。

---

**Q：这一篇的两句话，是哪本书里的？**

```
ⓘ 008 是《三国志·魏书·武帝纪》正文，陈寿写的。
  104 是裴松之注引的《世语》——它是注里引的别史，不是陈寿的正文。
  两段都是史料，可它们不是一本书里的两句话。
```

| 标记 | ⓘ |
| 依据 | `014`（《武帝纪》正文）；`214`（裴松之注引《世语》） |

---

**Q：这两段都提到钱。是一笔还是两笔？**

```
ⓘ 两段各说了一笔钱：
  008「散家财」—— 散的是他自己家里的。
  104「以家财资太祖」—— 拿钱出来的是陈留的孝廉卫兹。
  两段并列收着，谁也没说这是一笔还是两笔。
  产品不替它们合。
```

| 标记 | ⓘ |
| 依据 | `014`「散家财」；`214`「以家财资太祖」。**末句「产品不替它们合」是产品说明，不涉史料** |

---

**Q：卫兹是「以家财」资他——是全部家财吗？**

```
ⓘ「家财」两个字说的是这笔钱是自家的，
  没有说多少，也没有说是全部。
  他拿出来的占几成，底本不回答。
```

| 标记 | ⓘ |
| 依据 | `214`「以家财资太祖」 |

---

**Q：这两句话到底给了什么？**

```
ⓘ 一个出钱的人（卫兹）、一个身份（陈留孝廉）、
  一个数目（五千人）、一个地方（己吾）、
  一个月份（十二月）、一个年份（中平六年）、
  一个去处（诛卓）。
  其余一律标「—」：钱是多少、人从哪儿来、归谁带、他为什么肯拿。
```

| 标记 | ⓘ |
| 依据 | `014`「太祖至陈留，散家财，合义兵，将以诛卓」「冬十二月，始起兵于己…」；`214`「陈留孝廉卫兹以家财资太祖，使起兵，众有五千人」 |

---

**Q：这一篇为什么只有两段原文？**

```
ⓘ 陈寿写陈留起兵，写了两句：
  一句说他散家财、合义兵、要诛董卓，
  一句说十二月在己吾起兵。
  钱从哪儿来，正文一个字没有——补上这一句的是裴松之引的《世语》。
  中间准备了多久、怎么准备的，两边都不写。
```

| 标记 | ⓘ |
| 依据 | `014`；`214` |

---

**Q：这一篇为什么停在起兵那一刻？**

```
ⓘ 两段原文止于「始起兵于己吾」。
  兵往哪儿去、打成什么样，这两句不写。
  所以这一篇的最后一个动作，就是起兵。
```

| 依据 | `014`「始起兵于己吾」 |
