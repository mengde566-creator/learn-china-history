# 01 · 复习卡

> 原则：**问动机，不问年代。**
> 目标是理解这个人，不是记住年号。所以题目问「为什么」「凭什么」，不问「哪一年」。

---

## 场景 01 · 南归（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 因果 ★

**问：他为什么决意南归？**

答：**因为一卦。**

要出来做事，他先用蓍草占了一卦。同学党怀英得「坎」，留下事了金；他得「离」，从此决意南归。

要注意的是：**这一卷记的是结果，不是推理过程。** 它没有解释「离」为什么意味着南归，也没有记他说过一句理由。一卦分开两个人，这一卷就写到这里。

| | |
|---|---|
| 依据 | `001`「少師蔡伯堅，與党懷英同學，號辛、党」；`002`「懷英遇《坎》，因留事金，棄疾得《離》，遂決意南歸」 |
| 标记 | ◆ 出自原文 |
| 考点 | 分清「占了一卦」和「为什么走」：前者是记载，后者这一卷一个字没有 |

---

### 卡 2 · 因果 ★

**问：印丢了，耿京为什么先要杀他？**

答：**因为义端是他招进来的。**

`003` 记：义端聚众千余，是他说降了，归到耿京部下。`004` 记：义端一夜窃印而逃，耿京大怒，要杀他。

**两段之间没有一句话解释这个连带责任**，但顺序把因果摆得很清楚：人是他招的，出了事他担。

| | |
|---|---|
| 依据 | `003`「僧義端者，喜談兵，棄疾間與之遊」；`003`「及在京軍中，義端亦聚眾千餘，說下之，使隸京」；`004`「義端一夕竊印以逃，京大怒，欲殺棄疾」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两段连读才出因果。单看 `004`，会觉得耿京迁怒 |

---

### 卡 3 · 辨析 ★

**问：「给我三天」这句话，重点在「三天」还是在「不获就死」？**

答：**在后半句。**

原话是：「匄我三日期，不獲，就死未晚。」

前半句要一个期限，后半句把自己的命押在这个期限上。**没有后半句，前半句只是讨价还价。**

| | |
|---|---|
| 依据 | `004`「匄我三日期，不獲，就死未晚」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「匄」是求。他求的不是宽限，是一个可以拿命担保的期限 |

---

### 卡 4 · 陷阱题 ⚠️

**问：印是什么印？**

答：**这一卷不回答。**

`004` 只说「竊印以逃」。军中大印、节度使印、还是别的印，一个字没有交代。

**不要让「印」这个字骗过去**：它在句子里只是个宾语。义端要拿它做什么、要投谁，同样不载。

| | |
|---|---|
| 依据 | `004`「義端一夕竊印以逃」 |
| 标记 | — 史书未载 |
| 考点 | 一个具体的物件最容易让人以为知道细节。这里只知道「有印」，其余全空 |

---

### 卡 5 · 因果

**问：他抓到义端，为什么不押回来？**

答：**因为他判断义端要去奔告金帅。**

`004` 的顺序是：揣僧必以虚实奔告金帅 → 急追 → 获之 → 斩其首 → 归报。**杀在归报之前。**

史书只给了动作的顺序。**为什么不押、当时怎么想，这一卷不写。** 说「怕路上生变」，那是替它补一层理由。

| | |
|---|---|
| 依据 | `004`「揣僧必以虛實奔告金帥，急追獲之」；`004`「棄疾斬其首歸報」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动作顺序可以推因果，但不能推心理。标 ◆ 的只能说它写了什么 |

---

### 卡 6 · 辨析 ★

**问：「青兕」是史书对他的评语吗？**

答：**不是。那是义端求饶时说的话。**

`004` 的原句是：义端曰「我識君真相，乃青兕也，力能殺人，幸勿殺我」。

**说话的人是义端，场合是求饶。** 这一卷既没有说他真是青兕，也没有说不是。「兕是犀类」是后人对字的训释，属于另一层。

| | |
|---|---|
| 依据 | `004`「我識君真相，乃青兕也，力能殺人，幸勿殺我」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一句台词被后人当成评语，是这类材料最常见的串味 |

---

### 卡 7 · 边界

**问：他为什么不放义端一命？**

答：**这一卷不回答。**

记载里有他的判断（义端会去告密）、他的动作（追、获、斩）、他的回报（归报）。**中间没有一句话讲理由。**

读者可以自己给理由，但那是读者给的，不是这一卷给的。

| | |
|---|---|
| 依据 | `004` 全段；记动作与回报，不记理由 |
| 标记 | — 史书未载 |
| 考点 | 最难的不是「史书没写什么」，是「写了什么之后不再写」 |

---

### 卡 8 · 结构

**问：这四段原文，各做了什么？**

答：**一段身份，一段选择，一段入军，一段见事。**

| 段 | 做的事 |
|---|---|
| `001` | 名字、籍贯、师承、并称 |
| `002` | 一卦分开两条路：留金与南归 |
| `003` | 入耿京军，为掌书记，劝南向；义端来归 |
| `004` | 窃印、三日之期、追获、斩首、京益壮之 |

四段读完，这个人的来历、他的选择、他第一次被考验，都齐了。**后面的三十三段，大半是官职迁转。** 这一篇的作用，是把「官」前面那个人立起来。

| | |
|---|---|
| 依据 | `001`–`004` |
| 标记 | ◆ 出自原文 |
| 考点 | 传记的开头常常只做一件事：把后面所有官职背后的那个人交代清楚 |

---

## 这一篇最容易被问住的地方

| 问题 | 为什么不答 |
|---|---|
| 印是什么印 | `004` 只写「印」 |
| 三天怎么追的 | 只有「急追獲之」四字 |
| 义端为什么偷印 | 只有「竊印以逃」四字 |
| 他杀义端时想什么 | 只有「斬其首歸報」五字 |
