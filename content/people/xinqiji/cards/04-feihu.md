# 04 · 复习卡

> 原则：**问动机，不问年代。**

---

## 场景 04 · 飞虎军（9 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 因果 ★

**问：他为什么要另建一支军？**

答：**因为现有的兵调不动。**

`016` 的两句是关键：至调大军，千里讨捕，胜负未决——**从千里外调兵，胜负都还没打就先赔了**；伤威损重，为害非细。

所以他要的不是更多的兵，是一支「就近、能听指挥」的兵。

| | |
|---|---|
| 依据 | `016`「至調大軍，千里討捕，勝負未決，傷威損重，為害非細」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这道奏疏里的理由是「来不及」，不是「不够多」 |

---

### 卡 2 · 因果 ★

**问：他说百姓为什么要去当盗？**

答：**五层害压下来。**

「郡以聚斂害之，縣以科率害之，吏以乞取害之，豪民以兼并害之，盜賊以剽奪害之。」

接着一句是全篇最重的问题：「民不為盜，去將安之？」

| | |
|---|---|
| 依据 | `014`「郡以聚斂害之，縣以科率害之，吏以乞取害之，豪民以兼并害之，盜賊以剽奪害之」；`014`「民不為盜，去將安之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 五层里有两层是官（郡、县），一层是吏，一层是豪民，最后一层才是盗贼 |

---

### 卡 3 · 辨析

**问：「夫民為國本，而貪吏迫使為盜」——这句话在说什么？**

答：**在说盗贼是怎么被造出来的。**

他先把百姓定为「国本」，再说他们是「被贪吏逼成的盗」。**这不是求情，是把责任往前推了一层。**

后面那个比喻更狠：今年剿除，明年剗荡，像砍树，日刻月削，不损则折。

| | |
|---|---|
| 依据 | `014`「夫民為國本，而貪吏迫使為盜，今年剿除，明年剗盪，譬之木焉，日刻月削，不損則折」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「剿」解决的是当下的盗，「使」解决的是下一个盗。他在说后者 |

---

### 卡 4 · 辨析 ★

**问：飞虎军有什么特别？为什么一定要「专听帅臣节制调度」？**

答：**因为这一句才是这道奏疏真正要的东西。**

`016` 的完整请求是：照广东摧锋、荆南神劲、福建左翼的先例，别创一军，以湖南飞虎为名，止拨属三牙、密院，**专听帅臣节制调度**。

军名是新起的，建制是照旧例的；**新的只有那一句「专听帅臣」。**

| | |
|---|---|
| 依据 | `016`「乞依廣東摧鋒、荊南神勁、福建左翼例，別剙一軍，以湖南飛虎為名，止撥屬三牙、密院，專聽帥臣節制調度」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一道奏疏里最要紧的常是最不像请求的那半句 |

---

### 卡 5 · 因果

**问：军还没建完，为什么枢府要拦？**

答：**这一卷只说有拦，不说为什么。**

`018` 八个字：「時樞府有不樂之者」，接着是「數沮撓之」「卒不能奪」。

**不乐的是谁、拦了几次、拦的理由，全都没有。** 能确定的只有结果：没拦住。

| | |
|---|---|
| 依据 | `018`「時樞府有不樂之者，數沮撓之，棄疾行愈力，卒不能奪」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「有人不高兴」是记载，「为什么不高兴」不是 |

---

### 卡 6 · 辨析 ★

**问：御前金字牌下来，命他「日下住罢」。他停了吗？**

答：**没有。他收起来，然后催工期。**

`019` 四步：弃疾受而藏之 → 出责监办者，期一月飞虎营栅成，违坐军制 → 如期落成 → 开陈本末，绘图缴进 → 上遂释然。

**没有抗辩，没有申辩，也没有停。** 他先把事办完，再把成品交上去。

| | |
|---|---|
| 依据 | `019`「棄疾受而藏之，出責監辦者，期一月飛虎營柵成，違坐軍制」；`019`「如期落成，開陳本末，繪圖繳進，上遂釋然」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「受而藏之」四个字是这个人的一生里最像他的一句话：不争，但也不停 |

---

### 卡 7 · 陷阱题 ⚠️

**问：二十万片瓦，两天就凑齐了。瓦是从哪来的？**

答：**从居民家里取的，一户两片。**

`020` 的原句：令厢官自官舍、神祠外，应居民家取沟瓦二，不二日皆具，僚属叹伏。

**记载只写取，不写还。** 这一卷没有说后来补偿了，也没有说没补偿。

| | |
|---|---|
| 依据 | `020`「令廂官自官舍、神祠外，應居民家取溝𭅞瓦二，不二日皆具，僚屬歎伏」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一件「干才」的故事，同时是一次摊派。这一卷两样都记，评论一句没有 |

---

### 卡 8 · 因果

**问：军建成之后，评价是什么？**

答：**十一个字：雄镇一方，为江上诸军之冠。**

`020` 的最后一句。**「江上诸军之冠」是很高的评价**——长江沿线那么多军，这一支排第一。

而它是在一道停工令之后建成的。

| | |
|---|---|
| 依据 | `020`「軍成，雄鎮一方，為江上諸軍之冠」 |
| 标记 | ◆ 出自原文 |
| 考点 | 评价与过程要连起来读：违令、赶工、落成、冠于诸军 |

---

### 卡 9 · 边界

**问：建军的钱，是从哪里出的？**

答：**这一卷只记支出，不记来源。**

`017` 记了：缗钱五万，于广西买马五百匹；`018` 记了：经度费钜万计。

**这些钱从哪一项出、批了多少，全没有。** 后来御史说他聚敛，也没有给账。

| | |
|---|---|
| 依据 | `017`「先以緡錢五萬於廣西買馬五百匹」；`018`「經度費鉅萬計」 |
| 标记 | — 史书未载 |
| 考点 | 有数字不等于有账本。这里只有花出去的数，没有进来的数 |

---

## 这一篇的三条红线

| 红线 | 为什么 |
|---|---|
| 数目照原文，不四舍五入 | 步军二千、马军五百、钱五万、马五百、瓦二十万，都能核 |
| 不替枢府说理由 | `018` 只写「有不樂之者」 |
| 不把取瓦写成恩政 | 记的是取，不是还 |
