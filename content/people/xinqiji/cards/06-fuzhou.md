# 06 · 复习卡

> 原则：**问动机，不问年代。**

---

## 场景 06 · 备安库（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 因果 ★

**问：福州那句话，是在什么位置上说的？**

答：**在他还不是帅臣的时候。**

`024` 开头是「棄疾為憲時，嘗攝帥」——他那时是提点刑狱，代理过帅事。

所以那句「福州前枕大海，為賊之淵，上四郡民頑獷易亂，帥臣空竭，急緩奈何」**是他站在宪司的位置上，替帅臣操心。**

| | |
|---|---|
| 依据 | `024`「棄疾為憲時，嘗攝帥」；`024`「帥臣空竭，急緩奈何」 |
| 标记 | ◆ 出自原文 |
| 考点 | 位置决定话的分量：同一个人，在宪司说和在帅司说，不是一回事 |

---

### 卡 2 · 辨析

**问：「帅臣空竭」四个字在说什么？**

答：**说库房是空的。**

不是兵少，不是城破，是**没有钱粮可以调度**。

他叹的下一句是「急缓奈何」——真出了事，拿什么应对。这两句放在一起，才是那句叹气的内容。

| | |
|---|---|
| 依据 | `024`「帥臣空竭，急緩奈何」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「空竭」是财政，不是军备。看错这一层，就把整篇读成了募兵 |

---

### 卡 3 · 陷阱题 ⚠️ ★

**问：五十万缗，一年之内是怎么积起来的？**

答：**这一卷不说。**

`024` 只给结果：「未期歲，積鏹至五十萬緡，牓曰『備安庫』。」

**省了哪一项、动了哪一笔、有没有加税，一个字没有。** 后来台臣劾他「用钱如泥沙」，也没有给账。

| | |
|---|---|
| 依据 | `024`「未期歲，積鏹至五十萬緡，牓曰『備安庫』」 |
| 标记 | — 史书未载 |
| 考点 | 数字越具体，越容易让人以为知道来路。这里只有结果 |

---

### 卡 4 · 因果 ★

**问：备安库的钱，他打算怎么用？**

答：**秋天米贱时买两万石。**

`025` 的逻辑是一整圈：闽中土狭民稠，歉年要从广南买米；如今连熟，宗室与军人入仓请米，出仓就粜出去；等秋天米贱，用备安钱籴两万石。

**所以它不是藏钱，是一笔平粜的本钱。**

| | |
|---|---|
| 依据 | `025`「候秋賈賤，以備安錢糴二萬石，則有備無患矣」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「备安」备的是荒年，不是财富。籴贱粜贵，是常平仓的老办法 |

---

### 卡 5 · 辨析 ★

**问：他想造一万副甲，造了吗？**

答：**没有。**

`025` 用的是「又欲造萬鎧」——**「欲」是想。**

下一段 `026` 开头两个字把这件事关掉了：「事未行。」

| | |
|---|---|
| 依据 | `025`「又欲造萬鎧，招強壯補軍額，嚴訓練」；`026`「事未行」 |
| 标记 | ◆ 出自原文 |
| 考点 | 想与做成，在这一卷里是两个词。读漏一个「欲」，就会把打算当成政绩 |

---

### 卡 6 · 因果 ★

**问：弹章的三句，次序为什么是那样？**

答：**因为前两句是铺垫，第三句才是罪名。**

`026` 的三句是：用钱如泥沙、杀人如草芥、旦夕望端坐「闽王殿」。

**理财、用刑、政治。** 前两句说的是做事的方式，第三句说他有二心。

| | |
|---|---|
| 依据 | `026`「臺臣王藺劾其用錢如泥沙，殺人如草芥，旦夕望端坐『閩王殿』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 弹章也讲结构。最重的一句放在最后 |

---

### 卡 7 · 辨析

**问：「闽王殿」三个字，为什么能杀人？**

答：**因为它把一件事变成了另一件事。**

「用钱如泥沙」说他不会理财，「杀人如草芥」说他刻薄，「端坐闽王殿」说他**想割据**。

前两条可以辩，第三条不能辩——**辩就是承认自己在意那个位置。**

| | |
|---|---|
| 依据 | `026`「旦夕望端坐『閩王殿』」 |
| 标记 | ○ 合理推演 |
| 考点 | 「闽王」用的是五代旧国号，这是后人对这一句的理解；这一卷只给三个字，不解释它在影射什么 |

---

### 卡 8 · 辨析

**问：他被弹劾之后，辩了吗？**

答：**没有。他「丐祠归」。**

`026` 最后四个字：「遂丐祠歸。」

丐祠是自请宫观官，等于自请退出实权位置。**整段里没有他的一句申辩。**

| | |
|---|---|
| 依据 | `026`「遂丐祠歸」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一卷写他四次落职，一次也没有写过他的辩解。沉默是它给他的固定写法 |

---

## 这一篇的三条红线

| 红线 | 为什么 |
|---|---|
| 五十万缗只给结果 | 来历不载，账单更不载 |
| 「欲造」不等于「造了」 | 下一段两个字把这件事关掉了 |
| 弹辞照原文三句 | 次序是弹章的结构，不能重排 |
