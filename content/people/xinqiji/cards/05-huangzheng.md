# 05 · 复习卡

> 原则：**问动机，不问年代。**

---

## 场景 05 · 江右荒政（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 因果 ★

**问：他到任第一件事，为什么是贴榜？**

答：**因为荒年的头两个乱象是对着来的：一头囤，一头抢。**

榜上八个字：「閉糴者配，彊糴者斬。」

**闭籴管卖米的，彊籴管买米的。** 一边一个处置，两种人都不许动。

| | |
|---|---|
| 依据 | `021`「始至，榜通衢曰：『閉糴者配，彊糴者斬』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 八个字分两半读。少读一半，就成了只会杀人的酷吏 |

---

### 卡 2 · 辨析

**问：「閉糴者配」的「配」是什么意思？**

答：**发配。**

不是配给米，是把人发配到远处去。**和后半句的「斩」放在一起，才看得出这是两道刑，不是一个处置的两半。**

| | |
|---|---|
| 依据 | `021`「閉糴者配，彊糴者斬」 |
| 标记 | ◆ 出自原文 |
| 考点 | 古汉语的一字之差，能把一道禁令读成一道恩政 |

---

### 卡 3 · 因果 ★

**问：为什么是「借钱给商人去买米」，而不是「官府自己去买」？**

答：**因为官府一出手就是定价。**

`021` 的办法是：尽出公家官钱、银器；召官吏、儒生、商贾、市民各举有幹实者，量借钱物，**不取子钱**，限期月底到城下发糶。

结果记了八个字：「連檣而至，其直自減。」

| | |
|---|---|
| 依据 | `021`「召官吏、儒生、商賈、市民各舉有幹實者，量借錢物」；`021`「連檣而至，其直自減，民賴以濟」 |
| 标记 | ◆ 出自原文 |
| 考点 | 价是「自减」的，不是被压下去的。办法是让米进城，不是定价 |

---

### 卡 4 · 辨析

**问：借钱给他的都是些什么人？**

答：**名单是刻意写的。**

官吏、儒生、商贾、市民——四类人。**儒生不办商，市民不入官，可这四类都在名单里。**

判据只有一条：有幹实者。能不能办事，比什么身份都要紧。

| | |
|---|---|
| 依据 | `021`「召官吏、儒生、商賈、市民各舉有幹實者」 |
| 标记 | ◆ 出自原文 |
| 考点 | 名单的宽度就是这套办法的宽度 |

---

### 卡 5 · 因果 ★

**问：信州来讨米，他给多少？**

答：**米船的三成。**

`022`：时信守谢源明乞米救助，幕属不从，弃疾曰「均為赤子，皆王民也」，即以其米舟十之三予信。

**注意「幕属不从」四个字**：这一句是顶着下属说的。

| | |
|---|---|
| 依据 | `022`「時信守謝源明乞米救助，幕屬不從」；`022`「即以米舟十之三予信」 |
| 标记 | ◆ 出自原文 |
| 考点 | 比例给了，理由没给。这一卷不写他算过哪一笔 |

---

### 卡 6 · 陷阱题 ⚠️

**问：为什么是三成，不是四成、五成？**

答：**这一卷不回答。**

只记了「十之三」这一个数。**理由、盘算、够不够，一个字没有。**

给它补一条算术，就是替一段记载做决策。

| | |
|---|---|
| 依据 | `022`「即以米舟十之三予信」 |
| 标记 | — 史书未载 |
| 考点 | 比例给了，依据没给。这种地方最容易写出漂亮的废话 |

---

### 卡 7 · 辨析

**问：荒政办成了，他得到了什么？**

答：**进一秩，然后落职。**

`022` 的最后一句：「帝嘉之，進一秩，以言者落職，久之，主管沖佑觀。」

**嘉奖和落职写在同一句里，中间没有解释。** 这是这一卷写他一生的常用句式：做成一件事，然后被调走。

| | |
|---|---|
| 依据 | `022`「帝嘉之，進一秩，以言者落職，久之，主管沖佑觀」 |
| 标记 | ◆ 出自原文 |
| 考点 | 读这一卷要习惯这个节奏。它不控诉，只并置 |

---

### 卡 8 · 边界

**问：那八个字执行了没有？**

答：**这一卷不回答。**

榜文记下来了，**执行一次也没有记**。有没有人被配、有人被斩，全都不载。

能确定的只有后来的结果：米船接连靠岸，米价自己降下来。

| | |
|---|---|
| 依据 | `021` 榜文；`021`「於是連檣而至」 |
| 标记 | — 史书未载 |
| 考点 | 「立了法」和「用了法」是两件事。这一卷只写了前者 |

---

## 这一篇的三条红线

| 红线 | 为什么 |
|---|---|
| 八个字照原文 | 一配一斩，读错一个字，意思就反了 |
| 三成不给理由 | 只有数字，没有盘算 |
| 嘉奖与落职并读 | 这一卷的句式，不能拆成因果 |
