# 03 · 复习卡

> 原则：**问动机，不问年代。**

---

## 场景 03 · 美芹十论（9 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 辨析

**问：他上书同年就被采纳了吗？**

答：**没有。答复是「议不行」。**

`009` 的原句只有八个字：「以講和方定，議不行。」

**理由给了（和议刚定），结果是未施行。** 这一卷没有说它被驳倒，也没有说无人议过；谁议过、议到哪一步，不写。

| | |
|---|---|
| 依据 | `009`「以講和方定，議不行」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「未施行」不等于「无人议过」；这一卷只记结果和理由 |

---

### 卡 2 · 因果 ★

**问：那十六个字，说的是哪四件事？**

答：**理、势、技、地。**

「言逆順之理，消長之勢，技之長短，地之要害，甚備。」

翻译过来是：谁顺谁逆的道理、谁消谁长的形势、技击的长短、地势的要害。**这是用兵要算的四笔账，也是他上书的目录。**

| | |
|---|---|
| 依据 | `009`「言逆順之理，消長之勢，技之長短，地之要害，甚備」 |
| 标记 | ◆ 出自原文 |
| 考点 | 十六个字概括四篇长文。记住结构，比记住书名有用 |

---

### 卡 3 · 辨析

**问：他「不为迎合」，具体是不迎合谁？**

答：**不迎合皇帝想听的那一套。**

`009` 把三件事排在一句里：虞允文当国、帝锐意恢复、他论南北形势。接着是「持論勁直，不為迎合」。

**皇帝想恢复，他讲的未必是皇帝想听的话。** 至于讲了什么、哪里不合，这一卷不载。

| | |
|---|---|
| 依据 | `009`「時虞允文當國，帝銳意恢復」；`009`「持論勁直，不為迎合」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「不迎合」是一个判断，不是一句话的记录。这一卷没有说他具体驳了什么 |

---

### 卡 4 · 陷阱题 ⚠️

**问：那十篇论文的原文，这里能看到吗？**

答：**看不到。**

`009` 只留了篇名与十六个字的内容大要，**一句正文也没有抄**。

要读全文，得去他的集子——那是另一个出处、另一本书。

| | |
|---|---|
| 依据 | `009`「作《九議》并《應問》三篇、《美芹十論》獻于朝」 |
| 标记 | — 史书未载 |
| 考点 | 「有这部书」和「这一段抄了这部书」是两回事 |

---

### 卡 5 · 因果

**问：上书之后，他被派到哪里？**

答：**滁州。而且那里刚过兵。**

`010`：迁司农寺主簿，出知滁州。州罹兵燼，井邑凋殘。

接着是四件事：宽征薄赋、招流散、教民兵、议屯田。

| | |
|---|---|
| 依据 | `010`「遷司農寺主簿，出知滁州」；`010`「州罹兵燼，井邑凋殘」 |
| 标记 | ◆ 出自原文 |
| 考点 | 从「议不行」到「知滁州」，这一卷只隔一个句号。它不解释，也不用解释 |

---

### 卡 6 · 辨析 ★

**问：四件事里，哪一件只是「议」？**

答：**屯田。**

原文是「寬征薄賦，招流散，教民兵，議屯田」——前三件是动词，第四件带一个「议」字。

**这个字不是随手写的。** 它说明屯田只到商量这一步。

| | |
|---|---|
| 依据 | `010`「棄疾寬征薄賦，招流散，教民兵，議屯田」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一个「议」字，把办成的事和打算办的事分开 |

---

### 卡 7 · 辨析

**问：「慷慨有大略」是谁说的话？**

答：**是叶衡荐他时说的话。**

`010`：留守叶衡雅重之，衡入相，力荐弃疾慷慨有大略。

**这是举荐语，不是史书的评语。** 这一卷把它放在「力薦」之下，用法和「人服其警切」是同一类。

| | |
|---|---|
| 依据 | `010`「留守葉衡雅重之，衡入相，力薦棄疾慷慨有大畧」 |
| 标记 | ◆ 出自原文 |
| 考点 | 别人的话被抄进传记，读的时候要知道是谁在说、在什么场合说 |

---

### 卡 8 · 边界

**问：赖文政是什么人？**

答：**这一卷只有一个称呼：剧盗。**

`011` 八个字：「平劇盜賴文政有功」。他是谁、为什么聚众、这一仗怎么打的，都没有。

**能核到的只有一句：平了，他因此加了官。**

| | |
|---|---|
| 依据 | `011`「平劇盜賴文政有功，加祕閣修撰」 |
| 标记 | — 史书未载 |
| 考点 | 「剧盗」是官方的称呼，不是一个人的生平 |

---

### 卡 9 · 结构

**问：这四段的次序，说明了什么？**

答：**说明「上书」在履历里只占一句。**

| 段 | 内容 |
|---|---|
| `008` | 通判建康 |
| `009` | 召对、十论九议、议不行 |
| `010` | 滁州、江东参议、叶衡力荐 |
| `011` | 江西提刑、平赖文政、京西、江陵 |

**`009` 是最重要的一段，也是最短的一段。** 一个人的主张在传记里占多大位置，是由写传的人决定的，不是由主张本身决定的。

| | |
|---|---|
| 依据 | `008`–`011` |
| 标记 | ◆ 出自原文 |
| 考点 | 读传记要看比例：哪件事写得多，哪件事只给一句 |

## 这一篇的三条红线

| 红线 | 为什么 |
|---|---|
| 十论不引正文 | 这一卷没抄，抄了就成了替它编 |
| 召对不编对话 | `009` 没有一句皇帝与他的对话 |
| 赖文政不展开 | 只有八个字，展开的都是外来的 |
