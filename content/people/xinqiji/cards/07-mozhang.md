# 07 · 复习卡

> 原则：**问动机，不问年代。**

---

## 场景 07 · 稼轩（9 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 因果 ★

**问：「未受命而卒」五个字，重在哪一处？**

答：**重在前三个字。**

命令已经下到他这里（进枢密都承旨），他没有等到受命就死了。

**如果他从未被任命，这句话只是平淡的官历；正因为命令已经到了，这五个字才是一道没合上的门。**

| | |
|---|---|
| 依据 | `029`「進樞密都承旨，未受命而卒」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「未受命」不是「未任命」。差一个词，一个人的最后时刻就变了样 |

---

### 卡 2 · 辨析

**问：他死后，朝廷做了什么？**

答：**给了三件东西。**

`029` 的次序是：赐对衣、金带；守龙图阁待制致仕；特赠四官。

**前两件是丧仪的恩典，第三件是把官阶再加四级。** 一个人死了，官还在往上加。

| | |
|---|---|
| 依据 | `029`「賜對衣、金帶，守龍圖閣待制致仕，特贈四官」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三件事都不在他生前。问答里问这一句，答话的人只能说他不知道 |

---

### 卡 3 · 因果 ★

**问：他给绍兴诏书写的跋，叹的是什么？**

答：**叹这道诏书来早了、也来晚了。**

`031` 的原句：使此诏出于绍兴之前，可以无事雠之大耻；使此诏行于隆兴之后，可以卒不世之大功。今此诏与雠敌俱存也，悲夫！

**同一道诏书，早出就成了功，晚出也成了功；偏偏出在和议之后，于是它和仇敌一起留到了今天。**

| | |
|---|---|
| 依据 | `031`「使此詔出於紹興之前，可以無事讎之大恥；使此詔行於隆興之後，可以卒不世之大功。今此詔與讎敵俱存也，悲夫」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一段用的是假设句式。他不是在骂人，是在算时间差 |

---

### 卡 4 · 辨析 ★

**问：长沙看考卷，他认错了一次，也认对了一次。哪一次是哪一次？**

答：**《春秋》卷认错，《礼记》卷认对。**

`032` 记：他索亚榜《春秋》卷两易之，拆开名字是赵鼎——与南宋初那位宰相同名，他怒而掷卷。

再看《礼记》卷，他说「观其议论，必豪杰士也」，拆开是赵方。

**两笔写在同一段里，一笔是误认，一笔是识人。**

| | |
|---|---|
| 依据 | `032`「啓名則趙鼎也」；`032`「棄疾曰：『觀其議論，必豪傑士也，此不可失。』啓之，乃趙方也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 传记把这两笔放在一起，不是随手。识人的人也会认错人 |

---

### 卡 5 · 因果 ★

**问：「稼轩」这个号，是从哪句话来的？**

答：**从「人生在勤，当以力田为先」。**

`033` 的整段是一套看法：北方人不求于人而自养，所以没有太富太贫的人家；南方多末作以病农，兼并之患兴，贫富就不齐了。

**所以他把自己的轩，用「稼」命名。**

| | |
|---|---|
| 依据 | `033`「人生在勤，當以力田為先」；`033`「故以『稼』名軒」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「稼轩」不是风雅号，出处是一段关于农事的议论 |

---

### 卡 6 · 因果

**问：吳交如死了，他为什么说「是廉介之士也」？**

答：**因为他把「穷」当成了证据。**

`034`：同僚吴交如死，无棺敛。他说：「身為列卿而貧若此，是廉介之士也！」

**做到列卿，穷到没有棺材——在他看来，这就够了。**

然后他厚赙，又向执政说，诏赐银绢。

| | |
|---|---|
| 依据 | `034`「同僚吳交如死，無棺斂」；`034`「身為列卿而貧若此，是廉介之士也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这是一个用贫穷判断品格的人。这一卷记了他的判断，没有替他辩 |

---

### 卡 7 · 因果 ★

**问：朱熹下葬时没有人去，为什么？**

答：**因为伪学之禁正严。**

`035`：熹歿，偽學禁方嚴，門生故舊至無送葬者。

**「至无送葬者」——到了一定程度，连门生故旧都不去。** 而他写了文章去哭。

| | |
|---|---|
| 依据 | `035`「熹歿，偽學禁方嚴，門生故舊至無送葬者」；`036`「棄疾為文往哭之曰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 九个字写尽一场党禁。不是没有人难过，是没有人敢去 |

---

### 卡 8 · 陷阱题 ⚠️ ★

**问：他临终前喊了什么？**

答：**这一卷不回答。**

`029` 记到「未受命而卒」为止，**没有一句临终的话**。

后世另有说他临终大呼的记载，出处是地方志，不是《宋史》这一卷。这一页的每一条依据都要指到这一卷的编号，指不到就答不出来。

| | |
|---|---|
| 依据 | `029`「進樞密都承旨，未受命而卒」；临终之语不见于此卷 |
| 标记 | — 史书未载 |
| 考点 | 传得最广的一句话，恰恰不在书上。这一条要练的是：先问「它在哪一段」 |

---

### 卡 9 · 辨析 ★

**问：这一卷怎么评价他的词？**

答：**一句，还是史书的评语：雅善长短句，悲壮激烈，有《稼轩集》行世。**

全卷关于词的，只有这一句。**一首也没有引。**

词是另一个领域的材料；把它搬进史传故事里，读者会以为那是这一卷说的。

| | |
|---|---|
| 依据 | `036`「棄疾雅善長短句，悲壯激烈，有《稼軒集》行世」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「有这部集子」和「这一段抄了它」是两件事。这一卷只做了前者 |

---

## 这一篇的三条红线

| 红线 | 为什么 |
|---|---|
| 临终之语不引 | 不在这一卷里，来源是后世方志 |
| 词只给一句 | 这一卷只给了这一句 |
| 认错与认对一起读 | `032` 把两笔写在同一段里 |
