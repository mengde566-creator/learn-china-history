# 02 · 复习卡

> 原则：**问动机，不问年代。**

---

## 场景 02 · 缚张安国（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 陷阱题 ⚠️ ★

**问：他带了多少人去金营？**

答：**这一卷不回答。**

`006` 写的是：与众谋曰……乃约统制王世隆及忠义人马全福等径趋金营。**有名字，没有数目。**

「五十骑」是后世讲这段故事时加上去的。这一页不顺着它答，也不否认它——这一卷原就没有那个数。

| | |
|---|---|
| 依据 | `006`「乃約統制王世隆及忠義人馬全福等徑趨金營」 |
| 标记 | — 史书未载 |
| 考点 | 最像常识的那个数字，恰恰不在原文里。判断依据只能是「这一段写没写」 |

---

### 卡 2 · 陷阱题 ⚠️

**问：金营里有多少人？**

答：**这一卷不回答。**

`006` 只记「安國方與金將酣飲」与「金將追之不及」。**营里有多少兵，一个字没有。**

「五万人大营」同样是后世加的。它和「五十骑」是一对：两个数字互相撑住了那个画面，而这个画面不是这一卷画的。

| | |
|---|---|
| 依据 | `006`「安國方與金將酣飲，即眾中縛之以歸，金將追之不及」 |
| 标记 | — 史书未载 |
| 考点 | 两个不载的数字，会合成一个看起来很有据的印象 |

---

### 卡 3 · 因果 ★

**问：他为什么先「与众谋」，而不是直接走？**

答：**因为这一步不是他一个人能办的。**

`006` 的顺序是：还至海州 → 与众谋曰 → 乃约王世隆、马全福等 → 径趋金营。

**「谋」在前，「约」在中，「趋」在后。** 记载把这三步分开写，说明同去的人不是跟班。

| | |
|---|---|
| 依据 | `006`「棄疾還至海州，與眾謀曰」；`006`「乃約統制王世隆及忠義人馬全福等徑趨金營」 |
| 标记 | ◆ 出自原文 |
| 考点 | 演义把这一趟写成单人独骑，原文写的是商量、约人、同去 |

---

### 卡 4 · 辨析

**问：他问的第一句是「我该怎么办」吗？**

答：**不是。他问的是「何以复命」。**

原话：「我緣主帥來歸朝，不期事變，何以復命？」

「怎么办」是策略问题，「何以复命」是交代问题。**他先想的是：我怎么回去交这一趟差。**

| | |
|---|---|
| 依据 | `006`「我緣主帥來歸朝，不期事變，何以復命」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一句话问什么，能看出这个人当时站在哪个位置上 |

---

### 卡 5 · 因果

**问：抓到张安国，为什么不当场杀？**

答：**因为杀他不是这一趟的事。**

`006` 是「缚之以归」，`007` 才是「献俘行在，斩安国于市」。**处置的地点在行在，不在营里。**

这一卷把「缚」和「斩」分在两段，中间隔着回程。**为什么这样办，这一卷不写**；能确定的是：刀不是他落的。

| | |
|---|---|
| 依据 | `006`「即眾中縛之以歸」；`007`「獻俘行在，斬安國於市」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「缚」是他的动作，「斩」是朝廷的处置。混成一句，就把两件事并成一件 |

---

### 卡 6 · 辨析

**问：这件事之后他升官了吗？**

答：**没有。仍授前官。**

`007` 的四个字是「仍授前官」，接着是「改差江阴佥判」——换了一个差事，官阶没动。

读者容易以为这种功劳会换来升迁。**这一卷给的答复是：没有。**

| | |
|---|---|
| 依据 | `007`「仍授前官，改差江陰僉判」 |
| 标记 | ◆ 出自原文 |
| 考点 | 记载里最冷的一处常常是官职那一栏。「仍授前官」比任何评论都硬 |

---

### 卡 7 · 因果 ★

**问：为什么这一卷在这里写「时年二十三」？**

答：**因为这是全卷唯一一次给他记年龄。**

`007` 的最后一句：「棄疾時年二十三。」

它不写在开头，写在斩安国之后。**这一卷用一句话把一份履历和一个年纪钉在一起**：做完这件事的时候，他二十三岁。

| | |
|---|---|
| 依据 | `007`「棄疾時年二十三」 |
| 标记 | ◆ 出自原文 |
| 考点 | 位置本身是信息。年龄记在哪个动作之后，就与那个动作绑在一起 |

---

### 卡 8 · 边界

**问：张安国为什么杀耿京？**

答：**这一卷不回答。**

`006` 只有一句：「會張安國、邵進已殺京降金。」

谁主谋、谈了什么条件、部下怎么跟着走的，**全都没有**。张安国在这一卷里从头到尾没有一句台词。

| | |
|---|---|
| 依据 | `006`「會張安國、邵進已殺京降金」 |
| 标记 | — 史书未载 |
| 考点 | 一个叛徒的动机，是最容易被写出来的部分，也是最不该由我们写出来的部分 |

---

## 这一篇的三条红线

| 红线 | 为什么 |
|---|---|
| 不接兵数 | 两个数字都不在原文里 |
| 不让张安国说话 | 他一个字也没有留下 |
| 不把「缚」写成「杀」 | 刀是朝廷落的，不是他落的 |
