# 01 · 复习卡 · 闻鸡起舞

> 原则：**问动机，不问年代。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 因果 ★

**问：为什么说闻鸡起舞是两个人的事？**

答：原文先写「蹴琨覺」——祖逖把刘琨踢醒，然后才说「此非惡聲也」，接着「因起舞」。刘琨不是后来才被写进去的旁观者；这一夜他就在同一床被子里。

| | |
|---|---|
| 依据 | `005`「共被同寢」；`006`「中夜聞荒雞鳴，蹴琨覺曰：『此非惡聲也。』因起舞」 |
| 标记 | ◆ 出自原文 |
| 考点 | 读清动作的先后：踢醒 → 说话 → 起舞 |

---

### 卡 2 · 细节

**问：那一夜，荒野的鸡叫之后，谁被弄醒了？**

答：刘琨。原文写「蹴琨覺」，觉是醒；踢他，是要他醒。

| | |
|---|---|
| 依据 | `006`「蹴琨覺曰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 蹴是踢，觉是醒 |

---

### 卡 3 · 陷阱 ⚠️

**问：原文写了刘琨也起身舞剑吗？**

答：没有明写。原文只有「因起舞」三个字，没有分写主语。说祖逖起身是稳的；说刘琨也舞，是后世的读法。

| | |
|---|---|
| 依据 | `006`「因起舞」；`005` 记两人共被同寝 |
| 标记 | ○ 合理推演 |
| 考点 | 分清原文写了的（刘琨被踢醒）与后人补的（两人同舞） |

---

### 卡 4 · 人物

**问：刘琨在这一篇里是什么身份？**

答：司空，与祖逖同任司州主簿。两人交情很好，共被同寝。

| | |
|---|---|
| 依据 | `005`「與司空劉琨俱為司州主簿，情好綢繆，共被同寢」 |
| 标记 | ◆ 出自原文 |
| 考点 | 司空是官，司州主簿是两人同任的职 |

---

### 卡 5 · 辨析

**问：察孝廉、举秀才皆不行，能说明祖逖看不起这些科目吗？**

答：不能。原文只记「皆不行」三个字，没有记原因。看不上、在等更好的机会、还是别有所待，底本都不回答。

| | |
|---|---|
| 依据 | `004` 只记「皆不行」 |
| 标记 | — 史书未载 |
| 考点 | 不拿三个字推出一整套心理 |

---

### 卡 6 · 时间

**问：「年二十四」能直接当成公元某年吗？**

答：不能。原文只记年岁，没有公元纪年；公元年份是后世换算的。而且「年二十四」是记他做司州主簿前后，不是生日。

| | |
|---|---|
| 依据 | `004`「年二十四」 |
| 标记 | ○ 外证 |
| 考点 | 年岁是原文，公元年是后人系年 |

---

### 卡 7 · 背景

**问：「世吏二千石」是在说祖逖本人做过二千石的官吗？**

答：不是。说的是祖上世代有人做二千石的官，是家世。祖逖自己在这里记下的第一个官职，是司州主簿。

| | |
|---|---|
| 依据 | `001`「世吏二千石，為北州舊姓」；`005` 司州主簿 |
| 标记 | ○ 合理推演 |
| 考点 | 家世与本人官职分开 |

---

### 卡 8 · 结构

**问：这一篇为什么从家世、性情写起，不直接写半夜鸡叫？**

答：因为半夜鸡叫只有二十四个字，撑不起一个人。前面的五段交代他从哪里来、是什么性情、和谁同寝；有了这些，那一夜的动作才不是孤立的轶事。

| | |
|---|---|
| 依据 | `001`–`007` 的次序：家世 → 少孤 → 性情 → 读书 → 主簿 → 闻鸡 → 相避 |
| 标记 | ○ 合理推演 |
| 考点 | 七段的排列本身就是一种解释 |
