# 02 · 复习卡 · 避地淮泗

> 原则：**问选择，不问年号。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 因果 ★

**问：几百家流亡的人为什么推祖逖做行主？**

答：因为他把车马让给同行的老疾、自己步行，药物衣粮与众人共用，又多有权略。原文把这三件事连在一起，最后落到「少長咸宗之，推逖為行主」。

| | |
|---|---|
| 依据 | `010`「以所乘車馬載同行老疾，躬自徒步，藥物衣糧與眾共之，又多權略，是以少長咸宗之，推逖為行主」 |
| 标记 | ◆ 出自原文 |
| 考点 | 推举的理由写在动作里，不是写在头衔里 |

---

### 卡 2 · 陷阱 ⚠️

**问：元帝真的任命祖逖做徐州刺史了吗？**

答：没有实任。原文写「擬用」——打算用；接着「尋徵軍諮祭酒」，又改任了别的官。

| | |
|---|---|
| 依据 | `011`「元帝擬用為徐州刺史，尋徵軍諮祭酒」 |
| 标记 | ◆ 出自原文 |
| 考点 | 拟与除拜不是一回事 |

---

### 卡 3 · 人物

**问：东海王越给祖逖官，他为什么没有到任？**

答：因为母亲去世。「母喪不之官」——不是不肯做，是丧服未除。

| | |
|---|---|
| 依据 | `009`「東海王越以逖為典兵參軍、濟陰太守，母喪不之官」 |
| 标记 | ◆ 出自原文 |
| 考点 | 推辞与丧服是两回事 |

---

### 卡 4 · 辨析

**问：祖逖护着那些抢富室的宾客义徒，能说他是义军首领吗？**

答：不能只凭这一篇说。原文记这些人「多為盜竊，攻剽富室」，祖逖「擁護救解之」，谈者因此轻视他。他护的是投在自己门下的部曲；这一篇没有把他们写成义军。

| | |
|---|---|
| 依据 | `012`「賓客義徒皆暴傑勇士」；`013`「此輩多為盜竊，攻剽富室」「談者以此少逖」 |
| 标记 | ○ 合理推演 |
| 考点 | 部曲、宾客、义军不是当然的同义词 |

---

### 卡 5 · 细节

**问：南下的路上，谁坐车，谁走路？**

答：老人病人坐车，祖逖自己步行。

| | |
|---|---|
| 依据 | `010`「以所乘車馬載同行老疾，躬自徒步」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「老疾」是两类人：老人与病人 |

---

### 卡 6 · 因果

**问：祖逖为什么护着被官吏绳之以法的人？**

答：这一篇没有解释。它只记「或為吏所繩，逖輒擁護救解之」，紧接着是「談者以此少逖，然自若也」。

| | |
|---|---|
| 依据 | `013` 只记行为与反应 |
| 标记 | — 史书未载 |
| 考点 | 行为有记载，动机没有 |

---

### 卡 7 · 背景

**问：「行主」是朝廷的官吗？**

答：不是。是几百家流亡的人推出来的领头人。原文用推字，不是除拜。

| | |
|---|---|
| 依据 | `010`「推逖為行主」 |
| 标记 | ○ 合理推演 |
| 考点 | 推与任命的差别 |

---

### 卡 8 · 结构

**问：这一篇的地点顺序是什么？**

答：洛阳 → 淮泗 → 泗口 → 丹徒京口。每换一个地方，他的身份也换一层：朝廷命官 → 行主 → 南渡的侨人。

| | |
|---|---|
| 依据 | `008` 洛；`010` 淮泗；`011` 泗口、京口 |
| 标记 | ○ 合理推演 |
| 考点 | 地点推进就是身份推进 |
