# 05 · 复习卡 · 意甚怏怏

> 原则：**问关系，不问结局。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 因果 ★

**问：祖逖为什么「意甚怏怏」？**

答：朝廷将要派戴若思来做都督。祖逖认为他是吴人，虽有才望，却没有宏大的志向和远见；自己已经剪除荆棘、收得河南，戴若思却要从容来统辖他。所以不痛快。

| | |
|---|---|
| 依据 | `041`「逖以若思是吳人，雖有才望，無弘致遠識，且已翦荊棘，收河南地，而若思雍容，一旦來統之，意甚怏怏」 |
| 标记 | ◆ 出自原文 |
| 考点 | 不是被罢官，是多了一个上司 |

---

### 卡 2 · 陷阱 ⚠️

**问：戴若思到任了吗？**

答：这一篇没有记。`041` 说「將遣」——将要派；此后没有再提他，也没有记祖逖与他见面。

| | |
|---|---|
| 依据 | `041` 只记「會朝廷將遣戴若思為都督」 |
| 标记 | — 史书未载 |
| 考点 | 「將遣」不是已到 |

---

### 卡 3 · 人物

**问：王敦为什么怕祖逖？**

答：原文只说「王敦久懷逆亂，畏逖不敢發」——他久怀逆乱，因为怕祖逖，不敢发动。怕的具体是什么，底本没有展开。

| | |
|---|---|
| 依据 | `046`「王敦久懷逆亂，畏逖不敢發，至是始得肆意焉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一个畏字，写的是别人的忌惮 |

---

### 卡 4 · 辨析

**问：妖星出现、术士说「九月當死」，能说明祖逖的病是星象注定的吗？**

答：不能。原文把术士的话记在死前，是史传常见的写法；它同时写了「感激發病」——病的来由是忧愤，不是星象。

| | |
|---|---|
| 依据 | `042`「感激發病」；`044` 戴洋、陈训之言；`045`「逖亦見星」 |
| 标记 | ○ 合理推演 |
| 考点 | 记载了术士的话，不等于认可术士的因果 |

---

### 卡 5 · 细节

**问：祖逖死在哪里，多大年纪？**

答：雍丘，五十六岁。

| | |
|---|---|
| 依据 | `045`「俄卒於雍丘，時年五十六」 |
| 标记 | ◆ 出自原文 |
| 考点 | 雍丘也是他镇守的地方 |

---

### 卡 6 · 因果

**问：祖逖为什么把妻子儿女送到汝南大木山下？**

答：原文写「感激發病，乃致妻孥汝南大木山下」——感慨激愤而发病，于是把家眷送到那里。为什么选大木山，没有解释。

| | |
|---|---|
| 依据 | `042` |
| 标记 | ◆ 出自原文 |
| 考点 | 置家与发病连写，但不是因果的证明 |

---

### 卡 7 · 背景

**问：都督是什么官？朝廷要派戴若思来统辖，祖逖的处境有什么变化？**

答：都督是统辖诸军的统帅。祖逖原是豫州刺史、镇西将军；戴若思若来统辖，他上面就多一层。**`041` 只记「將遣」，没有记到任。**

| | |
|---|---|
| 依据 | `041`「為都督」「來統之」；`039` 镇西将军 |
| 标记 | ○ 合理推演 |
| 考点 | 官号没变，层级变了 |

---

### 卡 8 · 结构

**问：这一篇为什么一场仗都没有？**

答：因为这一篇写的不是打仗，是朝廷与他的关系。`040` 石勒退让，`041` 将遣戴若思，`042` 王敦构隙，`043` 筑垒，`044`–`045` 病与死，`046` 余波。**没有一场战斗，却每一段都在收紧。**

| | |
|---|---|
| 依据 | `040`–`046` |
| 标记 | ○ 合理推演 |
| 考点 | 叙事张力不必来自战场 |
