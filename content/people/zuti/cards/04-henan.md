# 04 · 复习卡 · 黄河以南

> 原则：**问手段，不问杀伐。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 因果 ★

**问：黄河以南是怎么回到晋手里的？**

答：不是靠一场决战。原文给的是几件事连起来：诱杀张平、克谯城、击破石季龙、布囊盛土乱其粮情、汴水截粮、厚待俘人、调停赵固等部。最后才是「黃河以南盡為晉土」。

| | |
|---|---|
| 依据 | `020`、`022`、`028`、`030`–`031`、`033`、`034`、`035` |
| 标记 | ○ 合理推演 |
| 考点 | 结果句要前面几段一起读 |

---

### 卡 2 · 陷阱 ⚠️

**问：布囊里装的是米吗？**

答：不是。装的是土，弄成米的样子。「布囊盛土如米狀」——米是那几个人担在路上的真米，用来让贼相信台上运的也是米。

| | |
|---|---|
| 依据 | `030`「以布囊盛土如米狀」「又令數人擔米」 |
| 标记 | ◆ 出自原文 |
| 考点 | 土与米，两种袋子 |

---

### 卡 3 · 人物

**问：李头为什么被杀？**

答：他说了一句「若得此人為主，吾死無恨」，陈川听到后发怒，杀了他。陈川怒的是哪一层，底本没有解释。

| | |
|---|---|
| 依据 | `026`「頭感逖恩遇，每歎曰：『若得此人為主，吾死無恨。』川聞而怒，遂殺頭」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一句话引来杀身之祸 |

---

### 卡 4 · 因果

**问：陈川为什么依附石勒？**

答：因为害怕。前一段写：冯宠率四百人归祖逖，陈川更怒，派魏硕抢掠豫州，卫策在谷水把被掠的人全部截回；下一段就是「川大懼，遂以眾附石勒」。

| | |
|---|---|
| 依据 | `027`–`028` |
| 标记 | ◆ 出自原文 |
| 考点 | 「大懼」二字承上文而来 |

---

### 卡 5 · 细节

**问：「相守四旬」是多久？两军在做什么？**

答：四十天。两军同在一座大城：贼从南门出入放牧，晋军开东门，就这么相持。

| | |
|---|---|
| 依据 | `029`「同一大城，賊從南門出入放牧，逖軍開東門，相守四旬」 |
| 标记 | ◆ 出自原文 |
| 考点 | 同城而守，不是攻城 |

---

### 卡 6 · 因果

**问：桃豹为什么连夜逃走？**

答：粮被截了。石勒派刘夜堂用一千头驴运粮，祖逖派韩潜、冯铁在汴水全部截获；下一段就是「豹宵遁」。

| | |
|---|---|
| 依据 | `031`–`032` |
| 标记 | ○ 合理推演 |
| 考点 | 断粮与宵遁的先后 |

---

### 卡 7 · 背景

**问：坞主是什么人？**

答：乱世里聚众据险自守的首领。流人坞主是流亡的人推出来的，名义上可以接受朝廷名号，实际上各管一块。

| | |
|---|---|
| 依据 | `019`「流人塢主張平、樊雅等在譙」；`022`「蓬陂塢主陳川，自號甯朔將軍、陳留太守」 |
| 标记 | ○ 合理推演 |
| 考点 | 名号是自号的，地盘是自己的 |

---

### 卡 8 · 结构

**问：这一篇二十一段，为什么能压成八段？**

答：删的是重复的城名、台名和部众数字，事件一个没少。八段各有一个动作：统属、诱杀、夜袭、赠马、附勒、盛土、宵遁、置酒。

| | |
|---|---|
| 依据 | `019`–`039` 的次序 |
| 标记 | ○ 合理推演 |
| 考点 | 压缩删细节，不删因果 |
