# 03 · 复习卡 · 中流击楫

> 原则：**问条件，不问口号。**
> 复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 因果 ★

**问：元帝给了祖逖什么，没给什么？**

答：给了奋威将军、豫州刺史的名号，一千人的粮、三千匹布；没给铠甲兵器，让他自己招募。

| | |
|---|---|
| 依据 | `016`「給千人稟，布三千匹，不給鎧仗，使自招募」 |
| 标记 | ◆ 出自原文 |
| 考点 | 支持是有限度的，限度写在「不給」里 |

---

### 卡 2 · 陷阱 ⚠️

**问：一千人的粮，是给一千名士兵的吗？**

答：原文只写「給千人稟」——一千人的粮，没有说这一千人已经是兵。他渡江时带的是「本流徙部曲百餘家」，到江阴才募到二千多人。

| | |
|---|---|
| 依据 | `016`；`017`「百餘家」；`018`「得二千餘人」 |
| 标记 | ○ 合理推演 |
| 考点 | 粮、户数、兵数不是同一个数 |

---

### 卡 3 · 人物

**问：元帝为什么「未遑北伐」？**

答：原文只说他「方拓定江南」——正在开拓平定江南，来不及北伐。具体在忙什么，这五段没有展开。

| | |
|---|---|
| 依据 | `014`「時帝方拓定江南，未遑北伐」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「未遑」是没工夫，不是不许 |

---

### 卡 4 · 辨析

**问：「中流擊楫」是一个比喻吗？**

答：原文记的是动作：船到江中，敲着船桨发誓。后世拿「中流擊楫」比喻立志收复失地的决心，那是引申义。

| | |
|---|---|
| 依据 | `017`「中流擊楫而誓曰」 |
| 标记 | ○ 合理推演 |
| 考点 | 先有动作，后有成语 |

---

### 卡 5 · 细节

**问：渡江时带了多少人？**

答：本来的流亡部曲一百多家。家是户，不是人。

| | |
|---|---|
| 依据 | `017`「仍將本流徙部曲百餘家渡江」 |
| 标记 | ◆ 出自原文 |
| 考点 | 百余家 ≠ 百余人 |

---

### 卡 6 · 背景

**问：奋威将军与豫州刺史，哪一个是他的实职？**

答：两个都是元帝这次给的名号。但豫州此时不在他手里；名号先给，地方要自己去取。`019` 以下才开始记他在豫州境内用兵。

| | |
|---|---|
| 依据 | `016` 任命；`019` 以下豫州用兵 |
| 标记 | ○ 合理推演 |
| 考点 | 官号与实土分开 |

---

### 卡 7 · 因果

**问：从一百多家到二千多人，中间发生了什么？**

答：中间是「屯於江陰，起冶鑄兵器」——驻屯、开炉铸造兵器、招募，然后才北上。

| | |
|---|---|
| 依据 | `018`「屯於江陰，起冶鑄兵器，得二千餘人而後進」 |
| 标记 | ◆ 出自原文 |
| 考点 | 五个字「起冶鑄兵器」是扩军的前提 |

---

### 卡 8 · 结构

**问：这一篇五段里，几段是话？**

答：四段。`014` 是进言的前半，`015` 是后半，`016` 是任命，`017` 是誓词；只有 `018` 是动作。所以这一篇的重心在话上，节奏要慢。

| | |
|---|---|
| 依据 | `014`–`018` |
| 标记 | ○ 合理推演 |
| 考点 | 数一数话与动作的比例 |
