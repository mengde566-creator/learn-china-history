# 复习卡 · 故事 05 · 淝水

> 原则：**问动机，不问年代。**

---

## 故事 05 · 淝水（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：这一篇里，谁劝他不要打，谁劝他打？**

答：**太子、道安劝不要打；慕容垂劝打。**

| 人 | 立场 | 底本 |
|---|---|---|
| 太子苻宏 | 吴地得岁、晋主无罪、谢安桓冲是俊才，不可伐 | `027` |
| 道安 | 「太子之言是也，願陛下納之」 | `027` |
| 慕容垂 | 「陛下內斷神謀足矣，不煩廣訪朝臣以亂聖慮」 | `028` |
| 苻坚 | 「吾計決矣，不復與諸卿議也」 | `026` |

**劝他的人三个，他听了第四个。**

| | |
|---|---|
| 依据 | `026`、`027`、`028` |
| 标记 | ◆ 出自原文 |
| 考点 | 同一场戏里，谁说什么、他听谁，底本原原本本记着 |

---

### 卡 2 · 动机

**问：他为什么非要打晋？**

答：**因为他把「天下垂平」当成了自己的责任，而不是时机。**

```
今天下垂平，惟东南未殄
        ↓
朕忝荷大业，巨责攸归
        ↓
岂敢优游卒岁，不建大同之业
        ↓
吾计决矣
```

**「巨责攸归」四个字，是他给自己找的理由。**

| | |
|---|---|
| 依据 | `026`「朕忝荷大業，巨責攸歸，豈敢優遊卒歲，不建大同之業」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动机在他说出口的话里，不必替他想一个更深的 |

---

### 卡 3 · 证据

**问：这场败仗，是从哪一步开始的？**

答：**从他自己下的「麾軍卻陣」开始。**

| 步 | 事 | 底本 |
|---|---|---|
| 1 | 朱序反说谢石，劝其速战 | `031` |
| 2 | 晋使请秦军小退，融麾军却阵 | `031` |
| 3 | 「軍遂奔退，制之不可止」 | `031` |
| 4 | 融马倒被杀；坚中流矢，单骑遁还 | `031` |

**退兵的本意是「因其濟水，覆而取之」，结果一退收不住。**

| | |
|---|---|
| 依据 | `031`「融於是麾軍卻陣，欲因其濟水，覆而取之。軍遂奔退，制之不可止」 |
| 标记 | ◆ 出自原文 |
| 考点 | 败因不是「兵少」，是几十万人同时转身 |

---

> **这一篇的读法：** 这一仗他准备得极足——六十余万戎卒、二十七万骑、运漕万艘。<br>
> 唯一没准备的，是「退」这个动作在几十万人里做不出来。**而这一步是他自己下的令。**
