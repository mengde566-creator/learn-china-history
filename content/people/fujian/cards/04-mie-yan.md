# 复习卡 · 故事 04 · 灭燕

> 原则：**问动机，不问年代。**

---

## 故事 04 · 灭燕（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：这一篇六节，哪一节是「顶点」？**

答：**第五节，入邺宫阅名籍。**

| 节 | 事 | 底本 |
|---|---|---|
| 1 | 霸东授兵，许以「於鄴相見」 | `016`、`017` |
| 2 | 壶关、晋阳，慕容评屯潞川 | `018` |
| 3 | 烧辎重、渭原誓师、破评四十万 | `019`、`020` |
| 4 | 坚率十万到安阳，猛出迎 | `021`、`022` |
| 5 | 入邺宫阅名籍，燕亡 | `023`、`024` |
| 6 | 枋头宴父老、祀孔子、迁豪杰 | `025` |

**前四节是打，第五节是收，第六节是治理。** 顶点之后只有收拾。

| | |
|---|---|
| 依据 | `023`「堅入鄴宮，閱其名籍」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一场战争的顶点常常不是最后一战，是清点战果那一下 |

---

### 卡 2 · 动机

**问：仗还没打，王猛为什么要「部置鮮卑之所」？**

答：**因为他已经在想打完以后怎么办。**

```
坚：於鄴相見
        ↓
猛：但願速敕有司，部置鮮卑之所
        ↓
坚：大悅
```

**八个字，说的是安置俘虏。** 八年后慕容垂、慕容冲起兵，这句话成了伏笔。

| | |
|---|---|
| 依据 | `017`「但願速敕有司，部置鮮卑之所」「堅大悅」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一句关于「善后」的话，往往比一句关于「必胜」的话更值得记 |

---

### 卡 3 · 证据

**问：灭燕之后，苻坚对王猛做了什么？**

答：**把整片关东交给他。**

| 授职 | 内容 | 底本 |
|---|---|---|
| 使持节 | 有权斩杀 | `024` |
| 都督关东六州诸军事 | 关东六州军事 | `024` |
| 车骑大将军 · 开府仪同三司 | 开府置官，仪同三公 | `024` |
| 冀州牧 · 镇邺 | 治所在邺 | `024` |

**这已经不是赏功，是把半个新占的国土交出去。**

| | |
|---|---|
| 依据 | `024`「以王猛為使持節、都督關東六州諸軍事、車騎大將軍、開府儀同三司、冀州牧、鎮鄴」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一份任命书里，每一个头衔都是一个权力 |

---

> **这一篇的读法：** 六万兵、四十万敌、九百九十余万口——数目都在这几段里。<br>
> 但最要紧的一句是「部置鮮卑之所」：**胜局还没定，他已经知道下一场祸在哪。**
