# 复习卡 · 故事 02 · 云龙门

> 原则：**问动机，不问年代。**

---

## 故事 02 · 云龙门（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：这一篇的五段，哪一段不在「那一夜」？**

答：**开头两段和最后两段都在那一夜前后，只有中间一段是现场。**

| 段 | 时间 | 底本 |
|---|---|---|
| 赞、翼劝进 | 苻生即位后 | `006` |
| 弑生、让位苻法 | 那一夜之前 | `007` |
| 潜入云龙门 | 那一夜 | `008` |
| 即位改元 | 次日之后 | `009` |
| 东堂恸哭 | 即位之后 | `010` |

**底本把政变写成一条线，但没有一处写「几更天」。**

| | |
|---|---|
| 依据 | `007`「堅遂弑生」；`008`「潛入雲龍門」；`009`「以升平元年僭稱大秦天王」 |
| 标记 | ◆ 出自原文 |
| 考点 | 同一夜的事可以拆成四五段，底本只按因果排，不按钟点排 |

---

### 卡 2 · 动机

**问：他杀了苻生，为什么先把位子让给苻法？**

答：**因为底本写的是「讓」，而苻法真的不敢接。**

```
坚弑生 → 以伪位让兄法
            ↓
      法自以庶孽，不敢当
            ↓
 坚与母虑众心未服，难居大位
            ↓
        群僚固请 → 乃从之
```

**三个动作连在一起：让、不敢、固请。** 底本没有写这是真心还是姿态。

| | |
|---|---|
| 依据 | `007`「以偽位讓其兄法。法自以庶孽，不敢當」；`009`「群僚固請，乃從之」 |
| 标记 | ○ 合理推演 |
| 考点 | 「让位」在底本里是一个动作，不是一句评价；动机不写，读者自己判 |

---

### 卡 3 · 证据

**问：他母亲杀苻法这件事，底本给了理由吗？**

答：**给了，只有一条。**

| 说法 | 底本 |
|---|---|
| 苻法年长而贤 | `010`「以法長而賢」 |
| 又得众心 | `010`「又得眾心」 |
| 怕他终成变故 | `010`「懼終為變」 |

**三条理由都在同一句里，之后就是「遣殺之」。** 苻坚的反应只有「慟哭嘔血」，没有一个字评母亲。

| | |
|---|---|
| 依据 | `010`「堅母以法長而賢，又得眾心，懼終為變，至此，遣殺之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 谁动的手、谁哭的，底本分得很清楚——别把这两件事算到一个人头上 |

---

> **这一篇的读法：** 真正的惊险不在云龙门里，在门开之后。<br>
> 让位、受位、杀兄三件事挨着发生，**而他只在东堂哭了一场。**
