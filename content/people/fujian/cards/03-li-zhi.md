# 复习卡 · 故事 03 · 立威

> 原则：**问动机，不问年代。**

---

## 故事 03 · 立威（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：为什么把「始平之獄」放在最前面，它的编号却在最后？**

答：**因为它是后面所有杀戮的依据。**

| 段 | 事 | 底本 |
|---|---|---|
| `015` | 王猛始平令鞭杀一吏，被征下狱，殿上答「治乱邦以法」 | 357–358 ○ |
| `011` | 樊世辱猛、扬言悬其头于城门 | 359–360 ○ |
| `012` | 苻坚设问、樊世争婚、斩于西厩 | 359–360 ○ |
| `013` | 强德陈尸于市，邓羌协规，数旬诛二十余人 | 359–360 ○ |
| `014` | 坚叹「吾今始知天下之有法也」 | 359–360 ○ |

**先听那句话，再看它落地。**

| | |
|---|---|
| 依据 | `015`「治亂邦以法」；`014`「吾今始知天下之有法也」 |
| 标记 | ○ 合理推演 |
| 考点 | 编号顺序是材料顺序，故事顺序可以按因果重排 |

---

### 卡 2 · 动机

**问：樊世是被一句狂言杀掉的吗？**

答：**不是。他是被一个女婿杀掉的。**

```
坚问：吾欲以杨璧尚主，璧何如人也？
            ↓
世勃然：杨璧，臣之婿也，婚已久定
            ↓
猛让之：是为二天子，安有上下
            ↓
世怒起将击猛 → 丑言大骂
            ↓
     坚由此发怒，命斩之于西厩
```

**设问在前，激怒在后。** 苻坚等的是一个能当众发作的由头。

| | |
|---|---|
| 依据 | `012`「吾欲以楊璧尚主，璧何如人也」「婚已久定」「堅由此發怒，命斬之於西廄」 |
| 标记 | ○ 合理推演 |
| 考点 | 「由此」两个字是底本的关节：怒是被这一场引出来的 |

---

### 卡 3 · 证据

**问：这一篇里，杀人的决定都是谁下的？**

答：**斩樊世是苻坚下的令；杀强德是王猛捕杀的；鞭杀始平小吏是王猛自己干的。**

| 动作 | 谁 | 底本 |
|---|---|---|
| 命斩樊世于西厩 | 苻坚 | `012`「命斬之於西廄」 |
| 捕杀强德，陈尸于市 | 王猛 | `013`「猛捕而殺之，陳屍於市」 |
| 鞭杀始平一吏 | 王猛 | `015`「鞭殺一吏」 |
| 数旬诛贵戚豪强二十余人 | 王猛、邓羌 | `013`「與猛協規齊志」 |

| | |
|---|---|
| 依据 | `012`、`013`、`015` |
| 标记 | ◆ 出自原文 |
| 考点 | 同一场整顿，刀有三把：皇帝、执政、中丞——分开记，才不会算成一笔账 |

---

> **这一篇的读法：** 苻坚要的不是清官，是能替他治住氐豪的人。<br>
> 王猛就是那把刀。**刀口上沾的血，皇帝一次也没碰。**
