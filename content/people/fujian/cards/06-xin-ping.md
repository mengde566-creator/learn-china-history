# 复习卡 · 故事 06 · 新平

> 原则：**问动机，不问年代。**

---

## 故事 06 · 新平（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：败回洛阳之后，他做错了哪几件事？**

答：**底本写了四件，每一件他都看得见，也都没有收回。**

| 事 | 底本 | 后果 |
|---|---|---|
| 许慕容垂巡抚燕岱、拜墓 | `032` | 垂据关东 |
| 复慕容暐之位，待之如初 | `035` | 暐密使劝慕容泓起兵 |
| 遣苻睿讨慕容泓，姚苌为司马 | `034` | 睿败死，姚苌惧诛而叛 |
| 予姚苌天雨之机 | `037` | 「萇軍大振」 |

**四件事没有一件是糊涂：每一件都有他的道理，也都成了别人的机会。**

| | |
|---|---|
| 依据 | `032`「堅許之」；`035`「復其位而待之如初」；`034`「萇懼誅，遂叛」 |
| 标记 | ○ 合理推演 |
| 考点 | 「看得见还是这么做」比「看不见所以做错」更难解释 |

---

### 卡 2 · 动机

**问：他为什么到最后才说「吾不用王景略、陽平公之言」？**

答：**因为这句话是在慕容冲兵临城下时说的，不是在灞上定策时说的。**

```
灞上：吾计决矣，不复与诸卿议也      （383）
        ↓
慕容冲逼长安：吾不用王景略、阳平公之言 （384–385）
```

**同一个人的两句话，中间隔着一年和一整场败仗。**

| | |
|---|---|
| 依据 | `026`「吾計決矣，不復與諸卿議也」；`038`「吾不用王景略、陽平公之言，使白虜敢至於此」 |
| 标记 | ○ 合理推演 |
| 考点 | 后悔是有日期的——它出现在城头上，不在决策时 |

---

### 卡 3 · 证据

**问：他最后拒绝了姚苌什么？**

答：**两样：传国玺，和禅代。**

| 索求 | 他的回答 | 底本 |
|---|---|---|
| 传国玺 | 「五胡次序，無汝羌名」「璽已送晉，不可得也」 | `040` |
| 禅代 | 「禪代者，聖賢之事。姚萇叛賊，奈何擬之古人！」 | `040` |
| 结果 | 骂而求死，缢于新平佛寺，时年四十八 | `040` |

**他到最后还在用符命那套话说理——那套话替他造了王，此刻他拿它骂人。**

| | |
|---|---|
| 依据 | `040`「五胡次序，無汝羌名」「禪代者，聖賢之事。姚萇叛賊，奈何擬之古人」 |
| 标记 | ◆ 出自原文 |
| 考点 | 拒绝的两种说法，一种是门第，一种是名分——都不是求生的条件 |

---

> **这一篇的读法：** 从千骑、十数骑，到最后「獨侍御十數人」。<br>
> 他一路在宽，宽到身边没人。**最后他坐下，叫人开饭。**
