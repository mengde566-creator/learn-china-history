# 复习卡 · 故事 01 · 草付应王

> 原则：**问动机，不问年代。**

---

## 故事 01 · 草付应王（3 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构

**问：这一篇写了五个情节点，其中几件是他自己做的？**

答：**一件。**

| 情节点 | 谁在动 | 底本 |
|---|---|---|
| 生而有神光、背有赤文 | 别人替他记的 | `001` |
| 七岁侍祖父，量其举措 | 他在看，但没做事 | `002` |
| 徐统相面、八岁请师 | 请师是他开口 | `003` |
| 苻健梦天神授龙骧将军 | 别人替他受的 | `004` |
| 要结英豪，王猛等为羽翼 | 他开始结交人 | `005` |

前四段都是别人在说他会怎样。**只有「挥剑捶马」那一下，是他自己的动作。**

| | |
|---|---|
| 依据 | `004`「堅揮劍捶馬，志氣感厲」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一篇写「征兆」的戏，真正的转折往往只有一个动作 |

---

### 卡 2 · 动机

**问：祖父为什么笑他「戎狄異類」还想读书，却又答应了？**

答：**因为「奇而愛之」在更早的一段里就写下了。**

```
生而神光、背有赤文、臂垂过膝
            ↓
      洪奇而爱之，名坚头
            ↓
 八岁请师 → 洪笑他戎狄异类 → 欣而许之
```

**这一笑一许不是矛盾，是同一种偏爱。** 底本没有解释，只把两个动作并排放下。

| | |
|---|---|
| 依据 | `001`「洪奇而愛之，名曰堅頭」；`003`「欣而許之」 |
| 标记 | ○ 合理推演 |
| 考点 | 「欣」字是关键：先笑后喜，态度在同一个句子里转了 |

---

### 卡 3 · 证据

**问：这一篇里哪几句是底本原话，哪几句是后人的解释？**

答：**原话只有那些「」里的话；赤文、神光、龙骧之梦都是当时的记载，不是我们的话。**

| 内容 | 性质 | 底本 |
|---|---|---|
| 「草付臣又土王咸陽」 | 底本记下的符命文字 | `001` |
| 「司隸縛罪人，不縛小兒戲也」 | 他八岁前说的原话 | `003` |
| 「誠如公言，不敢忘德」 | 他答徐统的原话 | `003` |
| 「汝戎狄異類，世知飲酒，今乃求學邪！」 | 苻洪原话 | `003` |

| | |
|---|---|
| 依据 | `001`、`003` |
| 标记 | ◆ 出自原文 |
| 考点 | 符命是「当时人说过的」，不等于「事情是这样的」——两件事不能混 |

---

> **这一篇的读法：** 五段里没有一件政事，全是征兆。<br>
> 而征兆正是苻家聚人的语言——**它不解释一个人为什么成事，只解释旁人为什么肯跟他。**
