# 03-li-zhi · 立威

| | |
|---|---|
| **封面** | — |
| **地点** | 长安 · 始平 · 西厩 |
| **原文** | 011–015 |

> 五段。一个汉人寒士替氐人的皇帝治国，氐人的功臣视他如仇。
> 樊世当众骂他「是我们种地你吃饭」，扬言要把他的头挂在长安城门上。
> 皇帝听完只说了一句：「必須殺此老氐，然後百僚可整。」
> 这句话之后，西厩斩了一个特进，市上陈了一具尸体，几十天里死了二十多个贵戚。
> 皇帝自己叹：我今日才知天下有法。

## 二、正文

### 情节点 1 · 始平之獄

> 那时始平一带多是从枋头西归的人，豪右纵横，劫盗充斥，于是把王猛转去做始平令。
>
> 猛一到任，明法峻刑，澄察善恶，禁勒强豪。他鞭杀了一个吏，百姓上书讼他，有司劾奏，用槛车把他征下廷尉诏狱。
>
> 苻坚亲自问他：「为政之体，德化为先，你到任没几天就杀戮无数，怎么这样酷！」
>
> 猛答：「臣听说治理宁国之邦用礼，治理乱邦用法。陛下不以臣不才，把剧邑交给我，臣谨为明君翦除凶猾。这才杀了一个奸人，剩下的还有上万。若说臣不能穷残尽暴、肃清轨法，臣甘心下鼎镬，以谢辜负；至于酷政之刑，臣实在不敢受。」
>
> 苻坚对群臣说：「王景略真是夷吾、子产一类的人。」
>
> 于是赦了他。

| 标记 | ◆ |
| 原文 | `015` 時始平多枋頭西歸之人，豪右縱橫，劫盜充斥，乃轉猛為始平令。猛下車，明法峻刑，澄察善惡，禁勒強豪。鞭殺一吏，百姓上書訟之，有司劾奏，檻車征下廷尉詔獄。堅親問之，曰：「為政之體，德化為先，蒞任未幾而殺戮無數，何其酷也！」猛曰：「臣聞宰甯國以禮，治亂邦以法。陛下不以臣不才，任臣以劇邑，謹為明君翦除凶猾。始殺一奸，余尚萬數，若以臣不能窮殘盡暴，肅清軌法者，敢不甘心鼎鑊，以謝孤負。酷政之刑，臣實未敢受之。」堅謂群臣曰：「王景略固是夷吾、子產之儔也。」於是赦之。 |
| 依据 | `015` |

| 说明 | 「始殺一奸，余尚萬數」是这段的锋。**他不是在请罪，是在报数**——把一个县令的杀人数报成一项工程的进度。苻坚听懂了，所以赦 |

### 情节点 2 · 樊世之辱

> 王猛受宠越来越深，朝政没有不经他手的。
>
> 特进樊世是氐人豪帅，对苻家有大功，负气倨傲，当众辱骂王猛：
>
> 「我们跟先帝共同兴创事业，都没能参与时政；你一个没有汗马之劳的人，怎么敢专管大任？这是我们种庄稼、你吃饭吗！」
>
> 猛答：「正要让你去做宰夫，哪止种庄稼。」
>
> 樊世大怒：「早晚要把你的头悬在长安城门上；不然，我就不活在这世上了。」
>
> 猛把这话告诉苻坚。苻坚怒道：「必须先杀这个老氐，然后百官才整得起来。」

| 标记 | ◆ |
| 原文 | `011` 王猛親寵愈密，朝政莫不由之。特進樊世，氐豪也，有大勳於苻氏，負氣倨傲，眾辱猛曰：「吾輩與先帝共興事業，而不預時權；君無汗馬之勞，何敢專管大任？是為我耕稼而君食之乎！」猛曰：「方當使君為宰夫，安直耕稼而已。」世大怒曰：「要當懸汝頭于長安城門，不爾者，終不處於世也。」猛言之於堅，堅怒曰：「必須殺此老氐，然後百僚可整。」 |
| 依据 | `011` |

| 说明 | 「方當使君為宰夫」——这是王猛一辈子最刻薄的一句。**底本把它记下来了**：这个人不是温良的能臣，他会当面把人踩下去 |
|

### 情节点 3 · 斬之於西廄

> 不久，樊世入宫奏事。苻坚对王猛说：「我想把杨璧尚公主，杨璧这人怎么样？」
>
> 樊世勃然道：「杨璧是臣的女婿，婚事早已定下，陛下怎么能让他尚公主！」
>
> 王猛责备樊世：「陛下拥有海内，你却敢争婚，这是两个天子，还有上下吗！」
>
> 樊世怒起，要打王猛，左右拦住了。他于是丑言大骂。苻坚由此发怒，命把樊世斩于西厩。
>
> 诸氐纷纷不平，争着说王猛的短处；苻坚怒甚，慢骂，甚至在殿庭上鞭打。
>
> 权翼进言：「陛下宏达大度，善驭英豪，神武卓荦，录功舍过，有汉祖之风。只是慢易之言，应该除去。」
>
> 苻坚笑道：「是朕的过错。」
>
> 从此公卿以下没有不忌惮王猛的。

| 标记 | ◆ |
| 原文 | `012` 俄而世入言事，堅謂猛曰：「吾欲以楊璧尚主，璧何如人也？」世勃然曰：「楊璧，臣之婿也，婚已久定，陛下安得令之尚主乎！」猛讓世曰：「陛下帝有海內，而君敢競婚，是為二天子，安有上下！」世怒起，將擊猛，左右止之。世遂醜言大罵，堅由此發怒，命斬之於西廄。諸氐紛紜，競陳猛短，堅恚甚，慢罵，或有鞭撻於殿庭者。權翼進曰：「陛下宏達大度，善馭英豪，神武卓犖，錄功舍過，有漢祖之風。然慢易之言，所宜除之。」堅笑曰：「朕之過也。」自是公卿以下無不憚猛焉。 |
| 依据 | `012` |

| 说明 | 杀樊世的由头是一个女婿，不是一句狂言。**苻坚先问「璧何如人也」，等的就是他这一句**——底本把设问写出来，这笔账就算不到王猛头上 |
|

### 情节点 4 · 陳屍於市

> 特进强德是苻健皇后的弟弟，酗酒横暴，为百姓之患。王猛捕了他杀掉，把尸首陈在市上。
>
> 中丞邓羌性情鲠直不挠，与王猛协规齐志。几十天里，贵戚豪强被诛死的二十余人。
>
> 于是百官震肃，豪右屏气，路不拾遗，风化大行。

| 标记 | ◆ |
| 原文 | `013` 其特進強德，健妻之弟也，昏酒豪橫，為百姓之患。猛捕而殺之，陳屍於市。其中丞鄧羌，性鯁直不撓，與猛協規齊志，數旬之間，貴戚強豪誅死者二十有餘人。於是百僚震肅，豪右屏氣，路不拾遺，風化大行。 |
| 依据 | `013` |

| 说明 | 「陳屍於市」不是私刑，是示众。**强德是皇后的弟弟，杀他等于告诉所有氐豪：国法比外戚重** |
|

### 情节点 5 · 吾今始知天下之有法

> 苻坚叹道：「我今日才知道天下有法，天子之尊。」
>
> 于是他派人分头巡察四方与戎夷种落，令各地把该报的逐条报上来：年老孤寡、无从自养的，长史断案不公、叫百姓受苦的，品行清正、疾恶如仇、劝人耕织而于风俗有益的，笃学至孝、义烈力田的。

| 标记 | ◆ |
| 原文 | `014` 堅歎曰：「吾今始知天下之有法也，天子之為尊也！」於是遣使巡察四方及戎夷種落，州郡有高年孤寡，不能自存，長史刑罰失中、為百姓所苦，清修疾惡、勸課農桑、有便於俗，篤學至孝、義烈力田者，皆令具條以聞。 |
| 依据 | `014` |

| 说明 | 这句叹是**替他自己叹的**：他先前不知道。一个氐人皇帝，靠一个汉人寒士才第一次看见「法」长什么样——底本用这一句给整篇收了尾 |
|

## 四、背景卡

### 樊世 · 特進

`011` 称他「特進樊世，氐豪也，有大勳於苻氏」。特进是加官，位在诸公之下而礼遇甚重。

**他是氐人集团的代表：有功、有兵、有资历，不服一个汉人。**

> **依据**：`011`「特進樊世，氐豪也，有大勳於苻氏，負氣倨傲」。

---

### 西廄

`012` 记樊世被「斬之於西廄」。厩是马房，西厩是宫中的马厩。

**杀在厩里，不是刑场——不给体面，也不给围观。**

> **依据**：`012`「命斬之於西廄」。

---

### 強德

`013` 说是「健妻之弟」，苻健皇后的弟弟，爵为特进。

**外戚而横暴，是氐豪里最难动的一个。王猛先动他。**

> **依据**：`013`「其特進強德，健妻之弟也，昏酒豪橫，為百姓之患」。

---

### 鄧羌

`013` 记他为中丞，「性鯁直不撓，與猛協規齊志」。后来潞川之战，正是他以司隶为条件讨冲锋（见灭燕篇）。

**这一篇里他是王猛的同道，下一篇里他成了那个讨价还价的猛将。**

> **依据**：`013`「其中丞鄧羌，性鯁直不撓，與猛協規齊志」。

---

### 夷吾 · 子產

`015` 苻坚把王猛比作「夷吾、子產之儔」。夷吾是管仲，子产是郑国执政，都以法治著称。

**这个比法很准：苻坚要的不是清官，是能治国的人。**

> **依据**：`015`「王景略固是夷吾、子產之儔也」。

## 七、设计说明

> **这一篇写「苻坚怎么用一把刀」。**
>
> 刀是王猛。前两篇里王猛还是个名字（`009` 授中书侍郎），到这里他第一次见血：始平令上鞭杀一吏，被押进诏狱；出狱后杀樊世、杀强德。而每一刀下去，苻坚都在旁边——**问话的是他，设局的是他，最后叹天下始有法的也是他。**
>
> 结构上我把始平之狱放在最前（`015`），虽然它的编号在最后。理由：**那是王猛第一次因为「法」被押进牢里，也是苻坚第一次当面听他讲「治乱邦以法」**——后面杀樊世、陈强德尸，都是这句话的执行。读者先听见这句话，再看它落地，比反过来有力。
>
> 两处分寸：
> 一是樊世那句「是為我耕稼而君食之乎」，我照原意译成「我们种地你吃饭」，不添油；王猛那句「方當使君為宰夫」也照译——**这句刻薄，底本没替他遮，我也不遮。**
> 二是杀樊世的由头。底本写苻坚先问「璧何如人也」，樊世一急就跳起来。我不替他解释这是不是圈套，只在设计里点一句「设问是写出来的」，读者自己看得出。
