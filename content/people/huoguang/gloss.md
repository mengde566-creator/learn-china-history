## 故事 01 · 奉車

| 編號 | 原文 | 直譯 |
|---|---|---|
| 001 | 霍光字子孟，票騎將軍去病弟也。父中孺，河東平陽人也，以縣吏給事平陽侯家，與侍者衛少皃私通而生去病。 | 霍光字子孟，是票骑将军霍去病的弟弟。父亲中孺，是河东平阳人，以县吏在平阳侯家做事，与侍者卫少皃私通而生下霍去病。 |
| 002 | 中孺吏畢歸家，娶婦生光，因絕不相聞。 | 中孺差事完毕回家，娶妻生下霍光，于是绝不相闻。 |
| 003 | 久之，少皃女弟子夫得幸於武帝，立為皇后，去病以皇后姊子貴幸。 | 过了很久，少皃的女弟子夫得幸于武帝，立为皇后；霍去病以皇后姐姐之子的身份贵幸。 |
| 004 | 既壯大，乃自知父為霍中孺，未及求問。會為票騎將軍擊匈奴，道出河東，河東太守郊迎，負弩矢先驅，至平陽傳舍，遣吏迎霍中孺。 | 长大之后，才自知父亲是霍中孺，未及求问。恰逢任票骑将军击匈奴，路出河东，河东太守郊迎，他负弩矢先驱，到平阳传舍，派吏去迎霍中孺。 |
| 005 | 中孺趨入拜謁，將軍迎拜，因跪曰：「去病不早自知為大人遺體也。」中孺扶報叩頭，曰：「老臣得託命將軍，此天力也。」 | 中孺趋入拜谒，将军迎拜，于是跪着说：「去病不早自知是大人遗体。」中孺扶报叩头，说：「老臣得托命于将军，这是天力。」 |
| 006 | 去病大為中孺買田宅、奴婢而去。還，復過焉，乃將光西至長安，時年十餘歲，任光為郎，稍遷諸曹、侍中。 | 去病大为中孺买田宅、奴婢而去。回程又经过那里，就把霍光西带到长安，当时十余岁，任霍光为郎，渐迁诸曹、侍中。 |
| 007 | 去病死後，光為奉車都尉、光祿大夫，出則奉車，入侍左右，出入禁闥二十餘年，小心謹慎，未嘗有過，甚見親信。 | 去病死后，霍光为奉车都尉、光禄大夫，出则奉车，入侍左右，出入禁闼二十余年，小心谨慎，未曾有过，甚见亲信。 |
| 008 | 光為人沉靜詳審，長財七尺三寸，白皙，疏眉目，美須髯。每出入下殿門，止進有常處，郎僕射竊識視之，不失尺寸，其資性端正如此。 | 霍光为人沉静详审，身长才七尺三寸，白皙，疏眉目，美须髯。每出入下殿门，止进有常处，郎仆射暗中记看，不失尺寸，他的资性端正如此。 |
| 009 | 初輔幼主，政自己出，天下想聞其風采。 | 初辅幼主，政令由自己出，天下想闻他的风采。 |
| 010 | 殿中嘗有怪，一夜群臣相驚，光召尚符璽郎，郎不肯授光。光欲奪之，郎按劍曰：「臣頭可得，璽不可得也！」光甚誼之。明日，詔增此郎秩二等。眾庶莫不多光。 | 殿中曾有怪事，一夜群臣相惊，霍光召尚符玺郎，郎不肯把玺交给霍光。霍光要夺，郎按剑说：「臣头可得，玺不可得！」霍光很称许他。次日，诏增此郎秩二等。众庶莫不称多霍光。 |

## 故事 02 · 顧命

| 編號 | 原文 | 直譯 |
|---|---|---|
| 011 | 征和二年，衛太子為江充所敗，而燕王旦、廣陵王胥皆多過失。 | 征和二年，卫太子被江充所败，而燕王旦、广陵王胥都多有过失。 |
| 012 | 是時，上年老，寵姬鉤弋趙婕妤有男，上心欲以為嗣，命大臣輔之。察群臣唯光任大重，可屬社稷。 | 这时，皇上年老，宠姬钩弋赵婕妤有男，皇上心想立为嗣，命大臣辅佐他。察看群臣只有霍光可任大重、可属社稷。 |
| 013 | 上乃使黃門畫者畫周公負成王朝諸侯以賜光。 | 皇上就使黄门画者画周公背负成王朝见诸侯，赐给霍光。 |
| 014 | 後元二年春，上游五柞宮，病篤，光涕泣問曰：「如有不諱，誰當嗣者？」上曰：「君未諭前畫意邪？立少子，君行周公之事。」 | 后元二年春，皇上游五柞宫，病重，霍光涕泣问说：「如有不讳，谁当嗣位？」皇上说：「你未明白前一幅画的意思吗？立少子，你行周公之事。」 |
| 015 | 光頓首讓曰：「臣不如金日磾。」日磾亦曰：「臣外國人，不如光。」 | 霍光顿首推让说：「臣不如金日磾。」日磾也说：「臣是外国人，不如霍光。」 |
| 016 | 上以光為大司馬大將軍，日磾為車騎將軍，及太僕上官桀為左將軍，搜粟都尉桑弘羊為御史大夫，皆拜臥內床下，受遺詔輔少主。 | 皇上任霍光为大司马大将军，日磾为车骑将军，以及太仆上官桀为左将军，搜粟都尉桑弘羊为御史大夫，都在卧内床下拜，受遗诏辅少主。 |
| 017 | 明日，武帝崩，太子襲尊號，是為孝昭皇帝。帝年八歲，政事一決於光。 | 次日，武帝崩，太子袭尊号，是为孝昭皇帝。帝年八岁，政事一决于霍光。 |
| 018 | 先是，後元元年，侍中僕射莽何羅與弟重合侯通謀為逆，時，光與金日磾、上官桀等共誅之，功未錄。武帝病，封璽書曰：「帝崩發書以從事。」遺詔封金日磾為秺侯，上官桀為安陽侯，光為博陸侯，皆以前捕反者功封。 | 此前，后元元年，侍中仆射莽何罗与弟重合侯通谋为逆，当时霍光与金日磾、上官桀等共诛之，功未录。武帝病，封玺书说：「帝崩发书以从事。」遗诏封金日磾为秺侯，上官桀为安阳侯，霍光为博陆侯，都以前捕反者之功封。 |
| 019 | 時，衛尉王莽子男忽侍中，揚語曰：「帝崩，忽常在左右，安得遺詔封三子事！群兒自相貴耳。」光聞之，切讓王莽，莽鴆殺忽。 | 当时，卫尉王莽之子王忽侍中，扬言说：「帝崩，忽常在左右，哪来的遗诏封三子之事！群儿自相贵罢了。」霍光听说，切责王莽，王莽鸩杀王忽。 |

## 故事 03 · 燕蓋

| 編號 | 原文 | 直譯 |
|---|---|---|
| 020 | 光與左將軍桀結婚相親，光長女為桀子安妻。有女年與帝相配，桀因帝姊鄂邑蓋主內安女後宮為婕妤，數月立為皇后。 | 霍光与左将军上官桀结姻亲，霍光长女为桀子上官安之妻。安女年与帝相配，上官桀通过帝姊鄂邑盖主把安女纳入后宫为婕妤，数月立为皇后。 |
| 021 | 父安為票騎將軍，封桑樂侯。光時休沐出，桀輒入代光決事。 | 父上官安为票骑将军，封桑乐侯。霍光休沐外出时，上官桀就入内代霍光决事。 |
| 022 | 桀父子既尊盛，而德長公主。公主內行不修，近幸河間丁外人。 | 上官桀父子既尊盛，而感念长公主之德。公主内行不修，近幸河间丁外人。 |
| 023 | 桀、安欲為外人求封，幸依國家故事以列侯尚公主者，光不許。又為外人求光祿大夫，欲令得召見，又不許。 | 桀、安想为丁外人求封，希望依国家旧例以列侯尚公主者，霍光不许。又为外人求光禄大夫，想让他得召见，霍光又不许。 |
| 024 | 長主大以是怨光。而桀、安數為外人求官爵弗能得，亦慚。 | 长公主因此大怨霍光。而桀、安几次为外人求官爵不能得，也惭愧。 |
| 025 | 自先帝時，桀已為九卿，位在光右。及父子並為將軍，有椒房中宮之重，皇后親安女，光乃其外祖，而顧專制朝事，繇是與光爭權。 | 自先帝时，上官桀已为九卿，位在霍光之上。到父子并为将军，有椒房后宫之重，皇后是安女，霍光只是其外祖，却专制朝事，由此与霍光争权。 |
| 026 | 燕王旦自以昭帝兄，常懷怨望。及御史大夫桑弘羊建造酒榷、鹽鐵，為國興利，伐其功，欲為子弟得官，亦怨恨光。 | 燕王旦自以为昭帝之兄，常怀怨望。到御史大夫桑弘羊建酒榷、盐铁，为国兴利，自伐其功，想为子弟得官，也怨恨霍光。 |
| 027 | 於是蓋主、上官桀、安及弘羊皆與燕王旦通謀，詐令人為燕王上書，言：「光出都肄郎羽林，道上稱䟆，太官先置。」 | 于是盖主、上官桀、安及弘羊都与燕王旦通谋，诈令人为燕王上书，说：「霍光出都肄郎羽林，道上称䟆（帝王出行清道），太官先置。」 |
| 028 | 又引：「蘇武前使匈奴，拘留二十年不降，還乃為典屬國，而大將軍長史敞亡功為搜粟都尉，又擅調益莫府校尉。光專權自恣，疑有非常。臣旦願歸符璽，入宿衛，察姦臣變。」 | 又引：「苏武前使匈奴，拘留二十年不降，还才为典属国；而大将军长史敞无功为搜粟都尉，又擅调益莫府校尉。霍光专权自恣，疑有非常。臣旦愿归符玺，入宿卫，察奸臣之变。」 |
| 029 | 候司光出沐日奏之。桀欲從中下其事，桑弘羊當與諸大臣共執退光。書奏，帝不肯下。 | 候霍光出沐之日奏上。上官桀想从中把事交下，桑弘羊当与诸大臣共执退霍光。书奏，帝不肯下。 |
| 030 | 明旦，光聞之，止畫室中不入。上問：「大將軍安在？」左將軍桀時曰：「以燕王告其罪，故不敢入。」 | 次日，霍光听说，止于画室中不入。皇上问：「大将军在哪里？」左将军上官桀当时说：「因燕王告其罪，故不敢入。」 |
| 031 | 有詔召大將軍。光入，免冠頓首謝，上曰：「將軍冠。朕知是書詐也，將軍亡罪。」光曰：「陛下何以知之？」上曰：「將軍之廣明都郎，屬耳；調校尉以來未能十日，燕王何以得知之？且將軍為非，不須校尉。」 | 有诏召大将军。霍光入，免冠顿首谢，皇上说：「将军戴上冠。朕知这封书是诈，将军无罪。」霍光说：「陛下怎么知道？」皇上说：「将军到广明都郎，是近日的事；调校尉以来未满十日，燕王怎么得知？况且将军若为非，不须校尉。」 |
| 032 | 是時，帝年十四，尚書左右皆驚，而上書者果亡，捕之甚急，桀等懼，白上小事不足遂，上不聽。 | 这时，帝年十四，尚书左右都惊；而上书者果然逃亡，捕之甚急，桀等惧，白上这是小事不足追究，皇上不听。 |
| 033 | 後桀黨有譖光者，上輒怒曰：「大將軍忠臣，先帝所屬以輔朕身，敢有毀者坐之。」自是桀等不敢復言，乃謀令長公主置酒請光，伏兵格殺之，因廢帝，迎立燕王為天子。 | 后来桀党有谮霍光者，皇上就发怒说：「大将军是忠臣，先帝所属以辅朕身，敢有毁者坐之。」自是桀等不敢再说，就谋令长公主置酒请霍光，伏兵格杀他，因废帝，迎立燕王为天子。 |
| 034 | 事發覺，光盡誅桀、安、弘羊、外人宗族。燕王、蓋主皆自殺。光威震海內。 | 事觉，霍光尽诛桀、安、弘羊、外人宗族。燕王、盖主都自杀。霍光威震海内。 |
| 035 | 昭帝既冠，遂委任光，訖十三年，百姓充實，四夷賓服。 | 昭帝既冠，就委任霍光，终十三年，百姓充实，四夷宾服。 |

## 故事 04 · 廢昌邑

| 編號 | 原文 | 直譯 |
|---|---|---|
| 036 | 元平元年，昭帝崩，亡嗣。武帝六男獨有廣陵王胥在，群臣議所立，咸特廣陵王。 | 元平元年，昭帝崩，无嗣。武帝六男只有广陵王胥在，群臣议所立，都属意广陵王。 |
| 037 | 王本以行失道，先帝所不用。光內不自安。 | 广陵王本以行为失道，先帝所不用。霍光内心不自安。 |
| 038 | 郎有上書言：「周太王廢太伯立王季，文王舍伯邑考立武王，唯在所宜，雖廢長立少可也。廣陵王不可以承宗廟。」言合光意。 | 郎有上书说：「周太王废太伯立王季，文王舍伯邑考立武王，只看所宜，虽废长立少也可。广陵王不可以承宗庙。」这话合霍光之意。 |
| 039 | 光以其書視丞相敞等，擢郎為九江太守，即日承皇太后詔，遣行大鴻臚事少府樂成、宗正德、光祿大夫吉、中郎將利漢迎昌邑王賀。 | 霍光把此书给丞相敞等看，擢郎为九江太守，即日承皇太后诏，遣行大鸿胪事少府乐成、宗正德、光禄大夫吉、中郎将利汉迎昌邑王贺。 |
| 040 | 賀者，武帝孫，昌邑哀王子也。既至，即位，行淫亂。光憂懣，獨以問所親故吏大司農田延年。 | 贺是武帝之孙、昌邑哀王之子。既至，即位，行淫乱。霍光忧懑，独问所亲故吏大司农田延年。 |
| 041 | 延年曰：「將軍為國柱石，審此人不可，何不建白太后，更選賢而立之？」 | 延年说：「将军为国柱石，审此人不可，何不建白太后，更选贤者而立？」 |
| 042 | 光曰：「今欲如是，於古嘗有此不？」延年曰：「伊尹相殷，廢太甲以安宗廟，後世稱其忠。將軍若能行此，亦漢之伊尹也。」 | 霍光说：「今欲如此，于古尝有此事否？」延年说：「伊尹相殷，废太甲以安宗庙，后世称其忠。将军若能行此，也是汉之伊尹。」 |
| 043 | 光乃引延年給事中，陰與車騎將軍張安世圖計，遂召丞相、御史、將軍、列侯、中二千石、大夫、博士會議未央宮。 | 霍光就引延年给事中，暗中与车骑将军张安世图计，于是召丞相、御史、将军、列侯、中二千石、大夫、博士会议未央宫。 |
| 044 | 光曰：「昌邑王行昏亂，恐危社稷，如何？」群臣皆驚鄂失色，莫敢發言，但唯唯而已。 | 霍光说：「昌邑王行昏乱，恐危社稷，如何？」群臣都惊愕失色，莫敢发言，只唯唯而已。 |
| 045 | 田延年前，離席按劍，曰：「先帝屬將軍以幼孤，寄將軍以天下，以將軍忠賢能安劉氏也。今群下鼎沸，社稷將傾，且漢之傳謚常為孝者，以長有天下，令宗廟血食也。如令漢家絕祀，將軍雖死，何面目見先帝於地下乎？今日之議，不得旋踵。群臣後應者，臣請劍斬之。」 | 田延年上前，离席按剑说：「先帝属将军以幼孤，寄将军以天下，以将军忠贤能安刘氏。今群下鼎沸，社稷将倾，且汉之传谥常为孝者，以长有天下、令宗庙血食。如令汉家绝祀，将军虽死，何面目见先帝于地下？今日之议，不得旋踵。群臣后应者，臣请剑斩之。」 |
| 046 | 光謝曰：「九卿責光是也。天下匈匈不安，光當受難。」於是議者皆叩頭，曰：「萬姓之命在於將軍，唯大將軍令。」 | 霍光谢说：「九卿责霍光，是对的。天下匈匈不安，霍光当受难。」于是议者都叩头说：「万姓之命在于将军，唯大将军令。」 |
| 047 | 光即與群臣俱見白太后，具陳昌邑王不可以承宗廟狀。皇太后乃車駕幸未央承明殿，詔諸禁門毋內昌邑群臣。 | 霍光即与群臣俱见白太后，具陈昌邑王不可以承宗庙之状。皇太后就车驾幸未央承明殿，诏诸禁门毋纳昌邑群臣。 |

| 118 | 然光不學亡術，暗於大理，陰妻邪謀，立女為后，湛溺淫溢之欲，以增顛覆之禍，死財三年，宗族誅夷，哀哉！ | 然而霍光不学无术，暗于大理，阴妻邪谋，立女为后，沉溺淫溢之欲，以增颠覆之祸；死才三年，宗族诛夷，哀哉！ |
