# 复习卡 · 故事 02 · 顧命

> 原则：**问动机，不问年代。**

---

## 故事 02 · 顧命（4 张）

---

### 卡 1 · 结构 ★

**问：这一篇从武帝赐画写到遗诏之疑，走了几步？**

答：**四步。**

| 步 | 发生了什么 |
|---|---|
| `011`–`013` | 卫太子败，燕王、广陵王多过失；武帝画周公负成王赐光 |
| `014`–`015` | 五柞宫问嗣；霍光让金日磾，日磾亦让 |
| `016`–`017` | 四人受遗诏辅少主，昭帝八岁，政事一决于光 |
| `018`–`019` | 遗诏封三侯，王忽质疑，被王莽鸩杀 |

| | |
|---|---|
| 依据 | `011`–`019` |
| 标记 | ◆ 出自原文 |
| 考点 | 托孤与封侯是两件事 |

---

### 卡 2 · 论辩 ★

**问：武帝为什么选霍光？**

答：**因为「可属社稷」。**

「察群臣唯光任大重，可属社稷。」此前赐周公负成王图，已把意思表明；病笃时霍光问嗣，武帝答「立少子，君行周公之事」，才点破。

| | |
|---|---|
| 依据 | `012`–`014` |
| 标记 | ◆ 出自原文 |
| 考点 | 选的是辅政者，不只是顾命大臣 |

---

### 卡 3 · 因果

**问：遗诏封侯为什么有人不信？**

答：**因为封侯依据是捕反者之功，而王忽说当时自己在场。**

「安得遗诏封三子事！群儿自相贵耳。」霍光听说后切责王莽，王莽鸩杀王忽。底本并录质疑，不裁断真伪。

| | |
|---|---|
| 依据 | `018`–`019` |
| 标记 | ◆ 出自原文 |
| 考点 | 「群儿自相贵」是当时最难听的话 |

---

### 卡 4 · 判断

**问：四个人一起受诏，说明什么？**

答：**说明辅政不是霍光一人，后面才有对手与同僚。**

霍光为大司马大将军，金日磾车骑将军，上官桀左将军，桑弘羊御史大夫，皆拜卧内床下。燕盖之谋、废昌邑朝议中的人物，都从这里进场。

| | |
|---|---|
| 依据 | `016` |
| 标记 | ◆ 出自原文 |
| 考点 | 不要写成霍光独受遗诏 |
