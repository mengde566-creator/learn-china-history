# 复习卡 · 故事 03 · 燕盖

> 原则：**问动机，不问年代。**

---

## 故事 03 · 燕盖（4 张）

---

### 卡 1 · 结构 ★

**问：这一篇从联姻写到诛灭，走了几步？**

答：**四步。**

| 步 | 发生了什么 |
|---|---|
| `020`–`021` | 霍、上官联姻，安女为皇后，桀代光决事 |
| `022`–`026` | 为丁外人求封、求官不得；桀、桑弘羊、燕王皆怨 |
| `027`–`032` | 诈为燕王上书；昭帝不肯下，当廷辨伪 |
| `033`–`035` | 桀等谋伏兵废帝；事觉，诛宗族，燕王、盖主自杀 |

| | |
|---|---|
| 依据 | `020`–`035` |
| 标记 | ◆ 出自原文 |
| 考点 | 冲突从求官开始，不是从谋反开始 |

---

### 卡 2 · 因果 ★

**问：上官桀为什么与霍光翻脸？**

答：**因为霍光两次不许为丁外人求封、求官。**

「桀、安欲为外人求封……光不许。又为外人求光禄大夫……又不许。」长公主因此怨光，桀、安也惭；加上资历、外戚之重，遂与光争权。

| | |
|---|---|
| 依据 | `022`–`025` |
| 标记 | ◆ 出自原文 |
| 考点 | 丁外人不是主角，是导火线 |

---

### 卡 3 · 论辩

**问：昭帝怎样拆穿燕王上书？**

答：**用时间与常理两条。**

「将军之广明都郎，属耳；调校尉以来未能十日，燕王何以得知之？且将军为非，不须校尉。」帝年十四，尚书左右皆惊；上书者果亡。

| | |
|---|---|
| 依据 | `031`–`032` |
| 标记 | ◆ 出自原文 |
| 考点 | 不是霍光自辩，是昭帝替他辩 |

---

### 卡 4 · 判断

**问：这一篇的结局为什么写「威震海内」？**

答：**因为诛宗族、两王自杀，霍光的权力到顶。**

「光尽诛桀、安、弘羊、外人宗族。燕王、盖主皆自杀。光威震海内。」下一句却是昭帝亲政后仍委任他十三年；威震与委任并置，落差留到后面。

| | |
|---|---|
| 依据 | `034`–`035` |
| 标记 | ◆ 出自原文 |
| 考点 | 威震海内不是赞语，是事实 |
