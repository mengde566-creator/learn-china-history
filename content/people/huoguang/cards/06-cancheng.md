# 复习卡 · 故事 06 · 骖乘

> 原则：**问动机，不问年代。**

---

## 故事 06 · 骖乘（4 张）

---

### 卡 1 · 结构 ★

**问：这一篇从改茔制写到毒杀许后，走了几步？**

答：**四步。**

| 步 | 发生了什么 |
|---|---|
| `077`–`080` | 霍显改茔制、治第室；霍云称病私出；诸女出入宫禁 |
| `081`–`083` | 宣帝亲政，魏相给事中；两家奴争道 |
| `084` | 封事不关尚书，霍氏甚恶之 |
| `085`–`086` | 霍显使淳于衍毒杀许后；霍光知而不举 |

| | |
|---|---|
| 依据 | `077`–`086` |
| 标记 | ◆ 出自原文 |
| 考点 | 越制从坟地写到宫门 |

---

### 卡 2 · 因果 ★

**问：霍氏为什么开始「知忧」？**

答：**因为宣帝身边的人换了。**

魏相为御史大夫、给事中，平恩侯与金安上出入省中；封事不关尚书，霍山领尚书之权被绕开。家奴争道踢御史门，只是气焰的最后一幕。

| | |
|---|---|
| 依据 | `081`–`084` |
| 标记 | ◆ 出自原文 |
| 考点 | 不是一次冲突，是权力结构变了 |

---

### 卡 3 · 细节

**问：霍光知道毒杀许后后做了什么？**

答：**没有举发，署衍勿论。**

「光大惊，欲自发举，不忍，犹与。会奏上，因署衍勿论。」六个字「不忍，犹与」，把犹豫写尽；这一笔不写成软弱，也不替他开脱。

| | |
|---|---|
| 依据 | `086` |
| 标记 | ◆ 出自原文 |
| 考点 | 毒杀是霍显主谋，霍光事后知情 |

---

### 卡 4 · 判断

**问：「芒刺在背」为什么放在下一篇？**

答：**因为它是宣帝的感觉，不是霍光的罪状。**

这一篇只写宣帝「内不能善」；谒庙骖乘时的畏惮，留到族灭篇开头，与「霍氏之祸萌于骖乘」的俗传接上。

| | |
|---|---|
| 依据 | `081`、`113` |
| 标记 | ○ 合理推演 |
| 考点 | 叙事顺序是有意的 |
