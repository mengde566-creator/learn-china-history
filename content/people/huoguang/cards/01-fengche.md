# 复习卡 · 故事 01 · 奉車

> 原则：**问动机，不问年代。**

---

## 故事 01 · 奉車（4 张）

---

### 卡 1 · 结构 ★

**问：这一篇从霍光的出身写到尚符玺郎，走了几步？**

答：**四步。**

| 步 | 发生了什么 |
|---|---|
| `001`–`003` | 霍中孺与卫少皃生霍去病，归家娶妇生霍光，两家绝不相闻 |
| `004`–`005` | 霍去病出征过河东，迎父相见 |
| `006`–`007` | 去病带霍光入长安为郎，后为奉车都尉、光禄大夫 |
| `008`–`010` | 沉静详审；尚符玺郎拒授玺，霍光反而赏他 |

| | |
|---|---|
| 依据 | `001`–`010` |
| 标记 | ◆ 出自原文 |
| 考点 | 全篇没有功业，只有出身、职位与器量 |

---

### 卡 2 · 因果 ★

**问：霍光为什么能进长安做官？**

答：**因为同父异母的兄长霍去病把他带去的。**

「还，复过焉，乃将光西至长安，时年十余岁，任光为郎。」霍去病是骠骑将军、皇后姊子；霍光的起点是这层亲缘。

| | |
|---|---|
| 依据 | `006` |
| 标记 | ◆ 出自原文 |
| 考点 | 不是察举，不是战功 |

---

### 卡 3 · 细节

**问：尚符玺郎不给玺，霍光为什么反而赏他？**

答：**因为他守的是职分，不是顶撞。**

「光召尚符玺郎，郎不肯授光。光欲夺之，郎按剑曰：『臣头可得，玺不可得也！』光甚谊之。明日，诏增此郎秩二等。」霍光称许的是「玺不可得」这句话。

| | |
|---|---|
| 依据 | `010` |
| 标记 | ◆ 出自原文 |
| 考点 | 众庶由这件事称多霍光 |

---

### 卡 4 · 判断

**问：这一篇为什么收在「众庶莫不多光」？**

答：**因为后面受托孤，靠的正是这个评价。**

「出入禁闼二十余年，小心谨慎，未尝有过，甚见亲信。」这一篇先把「谨慎」立住；武帝后来选他托孤，才有依据。

| | |
|---|---|
| 依据 | `007`、`010` |
| 标记 | ○ 合理推演 |
| 考点 | 不要把这一篇读成家世考；它写的是被信任的资格 |
