# 复习卡 · 故事 05 · 立宣

> 原则：**问动机，不问年代。**

---

## 故事 05 · 立宣（4 张）

---

### 卡 1 · 结构 ★

**问：这一篇从议立写到丧葬，走了几步？**

答：**四步。**

| 步 | 发生了什么 |
|---|---|
| `063`–`067` | 排除广陵王、燕王之后；奏立皇曾孙，是为宣帝 |
| `068`–`070` | 益封霍光；霍氏子弟布满朝廷；归政不受 |
| `071`–`072` | 地节二年病笃；上书请封霍山，拜霍禹右将军 |
| `073`–`076` | 丧葬比照乘舆，谥宣成侯；诏称功如萧相国 |

| | |
|---|---|
| 依据 | `063`–`076` |
| 标记 | ◆ 出自原文 |
| 考点 | 写的是交接，但没有真正交接 |

---

### 卡 2 · 因果 ★

**问：为什么立皇曾孙，而不是广陵王？**

答：**因为广陵王早被排除，皇曾孙是筛选后的近亲。**

「广陵王已前不用，及燕刺王反诛，其子不在议中。近亲唯有卫太子孙号皇曾孙在民间，咸称述焉。」奏书举的是年龄、师受、品行。

| | |
|---|---|
| 依据 | `063`–`065` |
| 标记 | ◆ 出自原文 |
| 考点 | 候选范围是被筛过的 |

---

### 卡 3 · 论辩

**问：霍光归政，宣帝为什么不受？**

答：**因为「不受」才是当时的安全答案。**

「光自后元秉持万机，及上即位，乃归政。上廉让不受，诸事皆先关白光，然后奏御天子。」权力没有交出去，只是换了一种说法。

| | |
|---|---|
| 依据 | `070` |
| 标记 | ◆ 出自原文 |
| 考点 | 谦让与实权并不矛盾 |

---

### 卡 4 · 判断

**问：丧葬规格为什么写得这么细？**

答：**因为规格本身就是政治信号。**

「梓宫、便房、黄肠题凑各一具」「黄屋左纛」「谥曰宣成侯」；诏书又说「功如萧相国」。待遇越高，后面的族灭越显突然。
