# 复习卡 · 故事 07 · 族滅

> 原则：**问动机，不问年代。**

---

## 故事 07 · 族滅（5 张）

---

### 卡 1 · 结构 ★

**问：这一篇从收兵权写到班固赞，走了几步？**

答：**五步。**

| 步 | 发生了什么 |
|---|---|
| `087`–`089` | 外调诸婿，收霍禹印绶兵权，易以许、史子弟 |
| `090`–`097` | 霍禹称病、霍显自怨；毒杀许后事泄，始有邪谋 |
| `098`–`102` | 张赦献策，张章告发；霍云、霍山免官就第 |
| `103`–`107` | 异兆；谋以太后制杀丞相、废天子；事觉族灭 |
| `108`–`118` | 宣帝诏、徐福曲突徙薪、芒刺在背、班固赞 |

| | |
|---|---|
| 依据 | `087`–`118` |
| 标记 | ◆ 出自原文 |
| 考点 | 收—怨—谋—觉，四步不跳 |

---

### 卡 2 · 因果 ★

**问：霍氏为什么从怨恨走到谋反？**

答：**因为毒杀许后的事泄露了。**

霍山说「又闻民间喧言霍氏毒杀许皇后」，霍显把实情告诉三人，三人惊说「此大事，诛罚不小，奈何？」于是始有邪谋。此前只是怨望，此后是自保。

| | |
|---|---|
| 依据 | `096`–`097` |
| 标记 | ◆ 出自原文 |
| 考点 | 谋反的起点是恐惧，不是野心 |

---

### 卡 3 · 论辩

**问：「曲突徙薪」的故事在说谁？**

答：**说的是朝廷赏功的偏差。**

客劝主人改曲突、远徙薪，主人不听；失火后杀牛谢邻人，却不请当初进言的人。徐福屡言霍氏将变，事后只赐帛十匹、为郎，远不如告发者封侯。

| | |
|---|---|
| 依据 | `110`–`113` |
| 标记 | ◆ 出自原文 |
| 考点 | 不是霍氏的故事，是赏罚的故事 |

---

### 卡 4 · 细节

**问：霍氏谋反的计划是什么？**

答：**承太后制杀丞相、平恩侯，废天子立霍禹。**

「谋令太后为博平君置酒，召丞相、平恩侯以下，使范明友、邓广汉承太后制引斩之，因废天子而立禹。」约定未发而事觉。

| | |
|---|---|
| 依据 | `105`–`107` |
| 标记 | ◆ 出自原文 |
| 考点 | 计划借的是太后之名 |

---

### 卡 5 · 判断

**问：班固的赞为什么先褒后贬？**

答：**因为《汉书》要同时记功与罪。**

前半说「拥昭立宣，光为师保，虽周公、阿衡，何以加此」；后半说「不学亡术，暗于大理，阴妻邪谋，立女为后」，死财三年，宗族诛夷。一褒一贬，就是定论。

|---|---|
| 依据 | `116`–`118` |
| 标记 | ◆ 出自原文 |
| 考点 | 「不学亡术」是批评他不约束家人 |
