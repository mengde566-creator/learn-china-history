# 项羽 · 直译

> **这一份和故事里的白话不是一回事。**
>
> 故事里的白话是**给人读的**：可以顺着现代汉语的语序重排、可以补主语、可以把两句并成一句。
> 这一份是**直译**：跟着原文的字序和句法走，不替它顺句子、不替它补它没说的主语。
>
> **所以它读起来会比故事里的白话生硬——这是有意的。** 它要让人看见原文长什么样：
> 哪一句没有主语、哪一处省略了宾语、哪个词在原文里只是一个字。
> 故事里的白话告诉你「发生了什么」，这一份告诉你「原文是这么说的」。
>
> **四条写法**：
>
> 1. **不补主语。** 原文承前省略，直译也省略（用「（他）」标出来源，不用人名填进去）
> 2. **术语随文注。** 官名、礼制、称谓第一次出现时，用（　）就地解释
> 3. **不合并、不拆分。** 原文一个句号，直译一个句号
> 4. **原文栏逐字照抄。** 这一栏直接取自 `source.md`，不用简体转写——读者拿它和「原文」页签对照
>
> 录文本身缺字的地方（如 `012` 的「楚?午之將」、`056` 的「其?臣」、`058` 的「?臣」、`092` 的「?起」），
> 直译不替它补，只在括号里说明。`069` 的「井殺」底本如此，通作「并殺」，照录并注明。
>
> 段号与 `source.md` 一一对应，收 `001`–`093`。**没有直译的段就是还没做**——不是「不需要」。

| 004 | 秦二世元年七月，陳涉等起大澤中。其九月，會稽守通謂梁曰：「江西皆反，此亦天亡秦之時也。吾聞先即制人，後則為人所制。吾欲發兵，使公及桓楚將。」是時桓楚亡在澤中。梁曰：「桓楚亡，人莫知其處，獨籍知之耳。」梁乃出，誡籍持劍居外待。梁復入，與守坐，曰：「請召籍，使受命召桓楚。」守曰：「諾。」梁召籍入。 | 秦二世元年七月，陈涉等在大泽（大泽，大泽乡）中起兵。那一年九月，会稽守（守，郡守）通对项梁说：「江西（江西，长江以西）都反了，这也是上天要灭亡秦的时候。我听说先动手就制服别人，后动手就被别人制服。我想发兵，让你和桓楚率领。」这时桓楚逃亡在泽中。项梁说：「桓楚逃亡，没有人知道他的处所，只有项籍知道罢了。」项梁就出去，告诫项籍拿着剑在外面等着。项梁又进去，和守坐着，说：「请召项籍进来，让他受命去召桓楚。」守说：「好。」项梁召项籍进去。 |
| 005 | 須臾，梁眴籍曰：「可行矣！」於是籍遂拔劍斬守頭。項梁持守頭，佩其印綬。門下大驚，擾亂，籍所擊殺數十百人。一府中皆慴伏，莫敢起。梁乃召故所知豪吏，諭以所為起大事，遂舉吳中兵。使人收下縣，得精兵八千人。梁部署吳中豪傑為校尉、候、司馬。有一人不得用，自言於梁。 | 过了一会儿，项梁向项籍使眼色（眴，使眼色）说：「可以动手了！」于是项籍就拔剑斩下守的头。项梁拿着守的头，佩带他的印绶（印绶，官印和系印的丝带）。门下（门下，守的属吏）大惊，扰乱起来，项籍所击杀的有数十百人（数十百人，约数，几十到上百）。一府之中都畏惧伏地，没有敢起来的。项梁就召集从前所知道的豪吏，告诉他们起大事的意图，于是发动吴中的兵。派人收取下属的县，得到精兵八千人。项梁部署吴中的豪杰做校尉、候、司马（校尉、候、司马，都是军中官职）。有一个人不被任用，自己向项梁说。 |
| 006 | 梁曰：「前時某喪使公主某事，不能辦，以此不任用公。」眾乃皆伏。於是梁為會稽守，籍為裨將，徇下縣。 | 项梁说：「从前某家的丧事让你主持某件事，你不能办，因此不任用你。」众人这才都服。于是项梁做会稽守，项籍做裨将（裨将，副将），巡行下属的县。 |

| 008 | 嬰謝不能，遂彊立嬰為長，縣中從者得二萬人。少年欲立嬰便為王，異軍蒼頭特起。陳嬰母謂嬰曰：「自我為汝家婦，未嘗聞汝先古之有貴者。今暴得大名，不祥。不如有所屬，事成猶得封侯，事敗易以亡，非世所指名也。」嬰乃不敢為王。謂其軍吏曰：「項氏世世將家，有名於楚。今欲舉大事，將非其人，不可。我倚名族，亡秦必矣。」 | 陈婴辞谢说不能，众人就强行立陈婴做首领，县中跟从的得到二万人。年轻人想立陈婴就做王，另建一支苍头（苍头，以青巾包头，指这支军队）特起。陈婴的母亲对陈婴说：「自从我做你家的媳妇，不曾听说你的先辈有显贵的人。如今突然得到大的名声，不吉祥。不如有所归属，事情成功还能得封侯，事情失败容易逃亡，不是世上被指名的人。」陈婴就不敢做王。对他的军吏说：「项氏世代是将家，在楚国有名。如今想举办大事，领将（将，领兵）不是那样的人，不行。我依靠名族，灭亡秦是一定的。」 |

| 020 | 初，宋義所遇齊使者高陵君顯在楚軍，見楚王曰：「宋義論武信君之軍必敗，居數日，軍果敗。兵未戰而先見敗徵，此可謂知兵矣。」王召宋義與計事而大說之，因置以為上將軍，項羽為魯公，為次將，範增為末將，救趙。諸別將皆屬宋義，號為卿子冠軍。行至安陽，留四十六日不進。 | 起初，宋义所遇到的齐国使者高陵君显在楚军中，见楚王说：「宋义议论武信君的军队必定失败，过了几天，军队果然失败。兵还没有交战就先看出失败的征兆，这可以称为懂得用兵了。」楚王召宋义来和他议事而非常喜欢他，于是安置他做上将军，项羽做鲁公、做次将，范增做末将，救援赵。各别将都归属宋义，称号为卿子冠军（卿子冠军，尊号；冠军，在诸军之上）。走到安阳，停留四十六天不前进。 |
| 021 | 項羽曰：「吾聞秦軍圍趙王鉅鹿，疾引兵渡河，楚擊其外，趙應其內，破秦軍必矣。」宋義曰：「不然。夫搏牛之虻不可以破蟣蝨。今秦攻趙，戰勝則兵罷，我承其敝；不勝，則我引兵鼓行而西，必舉秦矣。故不如先?秦趙。夫被堅執銳，義不如公；坐而運策，公不如義。」 | 项羽说：「我听说秦军把赵王围在钜鹿，赶快领兵渡河，楚军攻击它的外边，赵军接应它的里边，破秦军是一定的了。」宋义说：「不是这样。那搏牛的虻（搏牛之虻，叮牛的虻虫）不能破虱子（蟣蝨，虱子和虱卵）。如今秦攻赵，打胜了兵就疲惫，我们趁它的疲敝；不能胜，那么我们就领兵击鼓向西，一定攻下秦了。所以不如先让秦、赵相斗（原文作「先?秦趙」，字有阙）。那披坚甲、执锐兵，我不如您；坐着运筹谋策，您不如我。」 |
| 022 | 因下令軍中曰：「猛如虎，很如羊，貪如狼，彊不可使者，皆斬之。」乃遣其子宋襄相齊，身送之至無鹽，飲酒高會。天寒大雨，士卒凍飢。項羽曰：「將戮力而攻秦，久留不行。今歲饑民貧，士卒食芋菽，軍無見糧，乃飲酒高會，不引兵渡河因趙食，與趙並力攻秦，乃曰『承其敝』。夫以秦之彊，攻新造之趙，其勢必舉趙。 | 于是下令军中說：「猛如虎，狠如羊，贪如狼，倔强不可使唤的，都斩了他们。」就派他的儿子宋襄做齐国的相，亲自送他到无盐，饮酒盛会。天冷下大雨，士卒受冻挨饿。项羽说：「将要合力攻击秦，长久停留不走。如今收成饥荒、百姓贫困，士卒吃芋头和豆子，军中无现存的粮食，却饮酒盛会，不领兵渡河就食于赵，和赵合力攻秦，却说『趁它的疲敝』。那以秦的强，攻击新建立的赵，它的势头必定攻下赵。 |
| 023 | 趙舉而秦彊，何敝之承！且國兵新破，王坐不安席，埽境內而專屬於將軍，國家安危，在此一舉。今不恤士卒而徇其私，非社稷之臣。」項羽晨朝上將軍宋義，即其帳中斬宋義頭，出令軍中曰：「宋義與齊謀反楚，楚王陰令羽誅之。」當是時，諸將皆慴服，莫敢枝梧。皆曰：「首立楚者，將軍家也。今將軍誅亂。」 | 赵被攻下而秦更强，有什么疲敝可趁！况且国家的兵刚被破，王坐不安席，扫尽境内的兵而专门属于将军，国家的安危，在此一举。如今不体恤士卒而营求他的私利，不是社稷之臣。」项羽早晨朝见上将军宋义，就在他的帐中斩下宋义的头，出来号令军中说：「宋义和齐国谋反楚国，楚王暗中命令我诛杀他。」在这个时候，诸将都畏惧服从，没有敢抗拒（枝梧，抗拒）的。都说：「首先立楚的，是将军家。如今将军诛杀乱臣。」 |
| 024 | 乃相與共立羽為假上將軍。使人追宋義子，及之齊，殺之。使桓楚報命於懷王。懷王因使項羽為上將軍，當陽君、蒲將軍皆屬項羽。 | 就一起共同立项羽做假上将军（假上将军，代理上将军）。派人追宋义的儿子，在齐国追上了，杀了他。派桓楚向怀王报命。怀王于是派项羽做上将军，当阳君、蒲将军都归属项羽。 |
| 025 | 項羽已殺卿子冠軍，威震楚國，名聞諸侯。乃遣當陽君、蒲將軍將卒二萬渡河，救鉅鹿。戰少利，陳餘復請兵。項羽乃悉引兵渡河，皆沈船，破釜甑，燒廬舍，持三日糧，以示士卒必死，無一還心。於是至則圍王離，與秦軍遇，九戰，絕其甬道，大破之，殺蘇角，虜王離。涉閒不降楚，自燒殺。當是時，楚兵冠諸侯。 | 项羽已经杀了卿子冠军，威震楚国，名声传到诸侯。就派当阳君、蒲将军带士卒二万渡河，救援钜鹿。交战稍有胜利，陈余又请求出兵。项羽就全部领兵渡河，都沉了船，打破釜甑（釜，锅；甑，蒸饭的瓦器），烧了庐舍，带三天的粮食，以此向士卒表示必死之心，没有一个回来的念头。于是到了就围王离，和秦军相遇，九次交战，断绝他们的甬道，大破秦军，杀苏角，俘虏王离。涉闲不投降楚，自己烧死。在这个时候，楚兵在诸侯中称冠（冠，在诸军之上）。 |
| 026 | 諸侯軍救鉅鹿下者十餘壁，莫敢縱兵。及楚擊秦，諸將皆從壁上觀。楚戰士無不一以當十，楚兵呼聲動天，諸侯軍無不人人惴恐。於是已破秦軍，項羽召見諸侯將，入轅門，無不膝行而前，莫敢仰視。項羽由是始為諸侯上將軍，諸侯皆屬焉。 | 诸侯的军队救钜鹿城下的有十几座营垒（壁，营垒），没有敢发兵的。等到楚攻击秦，诸侯的将领都从营垒上观看。楚的战士没有一个不是以一当十，楚兵的呼喊声震动天空，诸侯军没有一个人不恐惧。于是已经破了秦军，项羽召见诸侯的将领，进入辕门（辕门，把车辕竖起作军门），没有一个不是跪着用膝盖向前，没有敢抬头的。项羽由此开始做诸侯的上将军，诸侯都归属他。 |
| 027 | 章邯軍棘原，項羽軍漳南，相持未戰。秦軍數卻，二世使人讓章邯。章邯恐，使長史欣請事。至咸陽，留司馬門三日，趙高不見，有不信之心。長史欣恐，還走其軍，不敢出故道，趙高果使人追之，不及。欣至軍，報曰：「趙高用事於中，下無可為者。今戰能勝，高必疾妒吾功；戰不能勝，不免於死。願將軍孰計之。」 | 章邯驻军棘原，项羽驻军漳南，相持没有交战。秦军几次退却，二世派人责备（讓，责备）章邯。章邯害怕，派长史欣（长史，官名；欣，司马欣）请示事情。到了咸阳，留在司马门（司马门，宫城的外门）三天，赵高不见他，有不信的心。长史欣害怕，跑回他的军队，不敢走来时的路，赵高果然派人追他，没有追上。欣到军中，报告说：「赵高在朝中用事，下面的人没有能做什么的。如今作战能胜，赵高必定嫉恨我们的功劳；作战不能胜，不免于死。希望将军仔细考虑。」 |

| 061 | 春，漢王部五諸侯兵，凡五十六萬人，東伐楚。項王聞之，即令諸將擊齊，而自以精兵三萬人南從魯出胡陵。四月，漢皆已入彭城，收其貨寶美人，日置酒高會。項王乃西從蕭，晨擊漢軍而東，至彭城，日中，大破漢軍。漢軍皆走，相隨入穀、泗水，殺漢卒十餘萬人。漢卒皆南走山，楚又追擊至靈壁東睢水上。 | 春天，汉王统率五诸侯的兵，共五十六万人，向东伐楚。项王听说，就命令诸将攻击齐，而自己带精兵三万人从鲁地南下，出胡陵。四月，汉军都已进入彭城，收取那里的货宝美人，天天摆酒大宴（高會：盛大的宴会）。项王就从萧县向西，早晨攻击汉军而向东，到彭城，正午，大破汉军。汉军都逃走，一个跟着一个进入穀水、泗水，杀汉卒十几万人。汉卒都向南逃上山，楚又追击到灵壁东边的睢水上。 |
| 062 | 漢軍卻，為楚所擠，多殺，漢卒十餘萬人皆入睢水，睢水為之不流。圍漢王三?。於是大風從西北而起，折木發屋，揚沙石，窈冥晝晦，逢迎楚軍。楚軍大亂，壞散，而漢王乃得與數十騎遁去，欲過沛，收家室而西；楚亦使人追之沛，取漢王家：家皆亡，不與漢王相見。漢王道逢得孝惠、魯元，乃載行。 | 汉军退却，被楚军挤压，多有被杀，汉卒十几万人都进入睢水，睢水因此不能流动。把汉王围了三重（「三」下一字底本作「?」，为一字之阙）。于是大风从西北起来，折断树木、掀开屋顶，扬起沙石，幽暗得白天像夜里，正迎着楚军。楚军大乱，崩坏散开，而汉王才得以和几十骑逃走，想经过沛，收取家室往西；楚也派人追到沛，取汉王的家：家人都逃亡了，不跟汉王相见。汉王在路上遇到孝惠、鲁元，就把他们载在车上走。 |
| 063 | 楚騎追漢王，漢王急，推墮孝惠、魯元車下，滕公常下收載之。如是者三。曰：「雖急不可以驅，奈何棄之？」於是遂得脫。求太公、呂後不相遇。審食其從太公、呂後閒行，求漢王，反遇楚軍。楚軍遂與歸，報項王，項王常置軍中。 | 楚的骑兵追汉王，汉王着急，把孝惠、鲁元推落到车下，滕公（滕公：夏侯婴，汉将）常常下车收取载上他们。像这样有三次。（滕公）说：「虽然急，也不能把车赶得更快，为什么要丢弃他们？」于是终于脱了身。找太公、吕后，没有遇上。审食其跟着太公、吕后走小路（閒行：走小路），找汉王，反而遇上楚军。楚军就和他们一起回去，报告项王，项王常常把他们安置在军中。 |
| 064 | 是時呂後兄周呂侯為漢將兵居下邑，漢王閒往從之，稍稍收其士卒。至滎陽，諸敗軍皆會，蕭何亦發關中老弱未傅悉詣滎陽，復大振。楚起於彭城，常乘勝逐北，與漢戰滎陽南京、索閒，漢敗楚，楚以故不能過滎陽而西。 | 这时吕后的哥哥周吕侯替汉领兵驻在下邑，汉王从小路去跟随他（從之：去投奔他），渐渐收拢他的士卒。到荥阳，各支败军都会合，萧何也把关中衰老幼小、还没有登记服役的人（未傅：未列名籍）全部送到荥阳，重新大振。楚从彭城一路而来，常常乘胜追逐败走的人，与汉在荥阳南边的京、索之间交战，汉打败楚，楚因此不能越过荥阳往西。 |
| 065 | 項王之救彭城，追漢王至滎陽，田橫亦得收齊，立田榮子廣為齊王。漢王之敗彭城，諸侯皆復與楚而背漢。漢軍滎陽，築甬道屬之河，以取敖倉粟。漢之三年，項王數侵奪漢甬道，漢王食乏，恐，請和，割滎陽以西為漢。 | 项王救彭城，追汉王到荥阳，田横也得以收取齐地，立田荣的儿子田广为齐王。汉王在彭城战败，诸侯都又亲附楚而背离汉。汉军驻在荥阳，修筑甬道（甬道：两边筑墙的通道）连接到河，用来取敖仓的粟。汉三年，项王几次侵夺汉的甬道，汉王的粮食缺乏，害怕，请求讲和，割荥阳以西归汉。 |
| 066 | 項王欲聽之。歷陽侯範增曰：「漢易與耳，今釋弗取，後必悔之。」項王乃與範增急圍滎陽。漢王患之，乃用陳平計閒項王。項王使者來，為太牢具，舉欲進之。見使者，詳驚愕曰：「吾以為亞父使者，乃反項王使者。」更持去，以惡食食項王使者。使者歸報項王，項王乃疑範增與漢有私，稍奪之權。 | 项王想听从它（指讲和）。历阳侯范增说：「汉容易对付罢了，如今放手不取，以后一定后悔。」项王就和范增加紧围荥阳。汉王为这件事发愁，就用陈平的计去离间项王。项王的使者来，（汉那边）替他备太牢的食具（太牢：牛、羊、豕三牲齐备），端起来正要进上。看见（项王的）使者，假装惊愕说：「我以为（来的是）亚父的使者，原来倒是项王的使者。」就换着拿走，用粗劣的食物给项王的使者吃。使者回去报告项王，项王就疑心范增与汉有私情，渐渐夺去他的权。 |
| 067 | 範增大怒，曰：「天下事大定矣，君王自為之。願賜骸骨歸卒伍。」項王許之。行未至彭城，疽發背而死。 | 范增大怒，说：「天下的事大体定了，君王自己去做吧。愿把骸骨赐还（骸骨：指自己的身体，乞求辞官还乡的话），让我回到卒伍（卒伍：行伍、军队）里去。」项王答应了。走，还没到彭城，毒疮（疽）在背上发作，就死了。 |
| 068 | 漢將紀信說漢王曰：「事已急矣，請為王誑楚為王，王可以閒出。」於是漢王夜出女子滎陽東門被甲二千人，楚兵四面擊之。紀信乘黃屋車，傅左纛，曰：「城中食盡，漢王降。」楚軍皆呼萬歲。漢王亦與數十騎從城西門出，走成皋。項王見紀信，問：「漢王安在？」曰：「漢王已出矣。」項王燒殺紀信。 | 汉将纪信劝说汉王说：「事情已经急了，请让我冒充大王去欺骗楚军（誑：欺骗），大王可以趁空隙出去。」于是汉王夜里放出女子，在荥阳东门穿上甲，二千人，楚兵四面攻击她们。纪信乘坐黄屋车（黃屋車：以黄缯为车盖，是王者的仪仗），车左附着大纛（左纛：插在车左的大旗），说：「城中粮食尽了，汉王来降。」楚军都高呼万岁。汉王也和几十骑从城西门出去，逃到成皋。项王见到纪信，问：「汉王在哪里？」回答说：「汉王已经出去了。」项王烧死纪信。 |
| 069 | 漢王使御史大夫周苛、樅公、魏豹守滎陽。周苛、樅公謀曰：「反國之王，難與守城。」乃共殺魏豹。楚下滎陽城，生得周苛。項王謂周苛曰：「為我將，我以公為上將軍，封三萬戶。」周苛罵曰：「若不趣降漢，漢今虜若，若非漢敵也。」項王怒，烹周苛，井殺樅公。 | 汉王派御史大夫周苛、枞公、魏豹守荥阳。周苛、枞公商议说：「反国的王（反國之王：背叛过自己一方的王），难以和他一同守城。」就一同杀了魏豹。楚攻下荥阳城，活捉周苛。项王对周苛说：「做我的将，我让你做上将军，封三万户。」周苛骂道：「你不赶快降汉，汉今天就要俘虏你，你不是汉的对手。」项王发怒，烹了周苛，并把枞公一并杀了（「井殺」，底本如此，通作「并殺」）。 |
| 070 | 漢王之出滎陽，南走宛、葉，得九江王布，行收兵，復入保成皋。漢之四年，項王進兵圍成皋。漢王逃，獨與滕公出成皋北門，渡河走脩武，從張耳、韓信軍。諸將稍稍得出成皋，從漢王。楚遂拔成皋，欲西。漢使兵距之鞏，令其不得西。 | 汉王出荥阳，向南逃到宛、叶，得到九江王黥布，一边走一边收兵，又入保成皋。汉四年，项王进兵围成皋。汉王逃，只与滕公出成皋北门，渡河逃到脩武，往从张耳、韩信的军队。诸将渐渐得以出成皋，跟随汉王。楚就攻下成皋，想往西。汉派兵在巩地抵挡他，使他没有能往西。 |
| 071 | 是時，彭越渡河擊楚東阿，殺楚將軍薛公。項王乃自東擊彭越。漢王得淮陰侯兵，欲渡河南。鄭忠說漢王，乃止壁河內。使劉賈將兵佐彭越，燒楚積聚。項王東擊破之，走彭越。漢王則引兵渡河，復取成皋，軍廣武，就敖倉食。項王已定東海來，西，與漢俱臨廣武而軍，相守數月。 | 这时，彭越渡河攻击楚的东阿，杀楚将军薛公。项王就亲自向东攻击彭越。汉王得到淮阴侯的兵，想渡河向南。郑忠劝说汉王，才停下来，在河内筑垒。派刘贾领兵帮助彭越，烧楚的积聚。项王向东击破他们，赶走彭越。汉王就领兵渡河，又取得成皋，驻军广武，就近取敖仓的粮食。项王平定东海回来，向西，与汉都靠近广武驻军，相守几个月。 |
| 072 | 當此時，彭越數反梁地，絕楚糧食，項王患之。為高俎，置太公其上，告漢王曰：「今不急下，吾烹太公。」漢王曰：「吾與項羽俱北面受命懷王，曰『約為兄弟』，吾翁即若翁，必欲烹而翁，則幸分我一桮羹。」項王怒，欲殺之。項伯曰：「天下事未可知，且為天下者不顧家，雖殺之無益，祇益禍耳。」項王從之。 | 正当这时，彭越几次在梁地反，断绝楚的粮食，项王为这件事发愁。（他）做了一张高俎（俎：放牲体或食物的礼器，也指案板），把太公放在上面，告诉汉王说：「现在不赶快下来（下：指下城投降），我就烹了太公。」汉王说：「我和项羽都向北面接受怀王的命令，说『约为兄弟』，我的父亲就是你的父亲，一定要烹你的父亲，就希望分我一杯羹（桮羹：一杯肉汤）。」项王发怒，想杀太公。项伯说：「天下的事还不知道归谁，况且做天下的人不顾家，虽然杀了他也没有好处，只会增加祸患罢了。」项王听从了他。 |
| 073 | 楚漢久相持未決，丁壯苦軍旅，老弱罷轉漕。項王謂漢王曰：「天下匈匈數歲者，徒以吾兩人耳，原與漢王挑戰決雌雄，毋徒苦天下之民父子為也。」漢王笑謝曰：「吾寧鬥智，不能鬥力。」項王令壯士出挑戰。漢有善騎射者樓煩，楚挑戰三合，樓煩輒射殺之。項王大怒，乃自被甲持戟挑戰。 | 楚汉长久相持没有决出胜负，壮丁苦于军旅，老弱疲于转运粮饷（轉漕：水陆转运粮食）。项王对汉王说：「天下汹汹不安几年了，只因为有我们两个人罢了，我愿意和汉王挑战，决一雌雄，不要白白苦了天下的百姓父子。」汉王笑着推辞说：「我宁可斗智，不能斗力。」项王命令壮士出去挑战。汉有一个善于骑马射箭的人叫楼烦，楚挑战三次，楼烦总是把他们射死。项王大怒，就自己披甲持戟出来挑战。 |
| 074 | 樓煩欲射之，項王瞋目叱之，樓煩目不敢視，手不敢發，遂走還入壁，不敢復出。漢王使人閒問之，乃項王也。漢王大驚。於是項王乃即漢王相與臨廣武閒而語。漢王數之，項王怒，欲一戰。漢王不聽，項王伏弩射中漢王。漢王傷，走入成皋。 | 楼烦想射他，项王瞪眼呵斥他，楼烦眼不敢看，手不敢放箭，就逃走回到营垒里，不敢再出来。汉王派人暗中打听他（閒問：趁间隙探问），原来是项王。汉王大惊。于是项王就靠近汉王，彼此隔着广武涧（廣武閒：广武涧）说话。汉王数落他（數之：一一列举），项王发怒，想打一仗。汉王不听，项王埋伏的弩手射中了汉王。汉王受伤，退入成皋。 |
| 075 | 項王聞淮陰侯已舉河北，破齊、趙，且欲擊楚，乃使龍且往擊之。淮陰侯與戰，騎將灌嬰擊之，大破楚軍，殺龍且。韓信因自立為齊王。項王聞龍且軍破，則恐，使盱台人武濊涉往說淮陰侯。淮陰侯弗聽。是時，彭越復反，下梁地，絕楚糧。項王乃謂海春侯大司馬曹咎等曰：「謹守成皋，則漢欲挑戰，慎勿與戰，毋令得東而已。 | 项王听说淮阴侯已经攻取河北，破了齐、赵，而且想攻击楚，就派龙且去攻击他。淮阴侯和他交战，骑将灌婴攻击他，大破楚军，杀龙且。韩信因此自立为齐王。项王听说龙且的军破了，就害怕，派盱台人武濊涉去劝说淮阴侯。淮阴侯不听。这时，彭越又反，攻下梁地，断绝楚的粮食。项王就对海春侯大司马曹咎等说：「谨慎守住成皋，那么汉即使想挑战，千万不要和他交战，不让他得往东而已。 |
| 076 | 我十五日必誅彭越，定梁地，復從將軍。」乃東，行擊陳留、外黃。 | 我十五天必定诛杀彭越，平定梁地，再回来跟从将军。」就向东，进击陈留、外黄。 |
