# 二十万人

| | |
|---|---|
| 封面 | — |
| 地点 | 棘原 · 漳南 · 咸阳 · 洹水 · 新安 |
| 原文 | 027–033 |

> 原文 027–033，七段，六百余字。
> 秦军最后的主力投降了。营中有二十多万人，夜里在说话。
> **这一篇只写了他们被杀的那一夜，没有写那一夜有多长。**

## 二、情节点

### 情节点 1 · 相持

> 章邯驻在棘原，项籍驻在漳南，两军相持，还没有交战。
>
> 秦军几次退却，二世派人来责备章邯。章邯害怕，派长史欣去请示。

| 标记 | ◆ |
| 原文 | `027` 章邯軍棘原，項羽軍漳南，相持未戰。秦軍數卻，二世使人讓章邯。章邯恐，使長史欣請事。 |
| 依据 | `027` |

| 说明 | 「相持未戰」和「秦軍數卻」排在一段里。**没有交战，却在退**——这两个事实放在一起，比一场败仗难看 |
|---|---|
| 说明 | 二世「讓」他——是责备，不是问。章邯的反应是「恐」，然后派人去。**去的人不是他自己** |
|

---

### 情节点 2 · 司马门

> 长史欣到了咸阳，在司马门留了三天，赵高不见他。赵高对他有不信之心。
>
> 长史欣害怕，跑回自己的军中，不敢走来时的路。赵高果然派人追他，没有追上。

| 标记 | ◆ |
| 原文 | `027` 至咸陽，留司馬門三日，趙高不見，有不信之心。長史欣恐，還走其軍，不敢出故道，趙高果使人追之，不及。 |
| 依据 | `027` |

| 说明 | 一个在前线带兵的人，回到都城见不到掌权的人。**「留司馬門三日」是一句话，不是一件事**——三天里的每一天都没有记载 |
|---|---|
| 说明 | 「不敢出故道」——来路不能走，说明他已经把自己当成被追的人了。**赵高「果」使人追之**：这个「果」字证实了他一路上的判断 |
|

---

### 情节点 3 · 欣报

> 长史欣回到军中，报告说：
>
> 「趙高用事於中，下無可為者。今戰能勝，高必疾妒吾功；戰不能勝，不免於死。願將軍孰計之。」
>
> ——赵高在朝中用事，下面的人做不成事。如今打仗能胜，赵高必定嫉妒我们的功劳；打不胜，免不了一死。希望将军仔细考虑。

| 标记 | ◆ |
| 原文 | `027` 欣至軍，報曰：「趙高用事於中，下無可為者。今戰能勝，高必疾妒吾功；戰不能勝，不免於死。願將軍孰計之。」 |
| 依据 | `027` |

| 说明 | 胜也是死，败也是死。**这不是抱怨，是一份算术**——两头的答案一样。说完这一句，后面的信才有地方落 |
|---|---|

---

### 情节点 4 · 陈馀的书

> 陈馀也送了一封信给章邯：
>
> 「白起為秦將，南征鄢郢，北阬馬服，攻城略地，不可勝計，而竟賜死。蒙恬為秦將，北逐戎人，開榆中地數千里，竟斬陽周。」
>
> ——白起做秦将，南征鄢郢，北上坑了马服的兵，攻城略地，数不清，最后却被赐死。蒙恬做秦将，北逐戎人，开辟榆中数千里，最后被斩于阳周。
>
> 信里问：这是为什么？功劳多，秦不能尽封，就借法律杀他们。如今将军做秦将三年，损失的兵以十万计，而诸侯起兵越来越多。赵高一向谄媚，如今事情急了，也怕二世杀他，所以想借法律杀将军来抵责，另派人代替将军，好脱自己的祸。
>
> 「夫將軍居外久，多內卻，有功亦誅，無功亦誅。」
>
> ——将军在外日久，朝内多怨隙，有功也杀，无功也杀。
>
> 信里又劝他：不如回兵与诸侯合纵，约定共攻秦，分割土地，南面称王——比起身伏斧质、妻子被杀，哪一样好？

| 标记 | ◆ |
| 原文 | `028` 陳餘亦遺章邯書曰：「白起為秦將，南征鄢郢，北阬馬服，攻城略地，不可勝計，而竟賜死。蒙恬為秦將，北逐戎人，開榆中地數千里，竟斬陽周。何者？功多，秦不能盡封，因以法誅之。……」 |
| 依据 | `028`「何者？功多，秦不能盡封，因以法誅之」；`029`「夫將軍居外久，多內卻，有功亦誅，無功亦誅」 |

| 说明 | 一封信里有两个死人：白起、蒙恬。**两个都是秦自己杀的**——这封信的说服力全在这两个名字上 |
|---|---|
| 说明 | 「有功亦誅，無功亦誅」八个字，把长史欣那份算术写成了结论。**写信的人不是秦人，是赵将陈馀** |
|

---

### 情节点 5 · 狐疑

> 章邯狐疑不定，暗中派候始成去见项籍，想订约。约还没有订成，项籍派蒲将军日夜引兵渡过三户，驻在漳南，与秦军交战，又破了秦军。
>
> 项籍带全部兵在汙水上攻击秦军，大破秦军。

| 标记 | ◆ |
| 原文 | `030` 章邯狐疑，陰使候始成使項羽，欲約。約未成，項羽使蒲將軍日夜引兵度三戶，軍漳南，與秦戰，再破之。項羽悉引兵擊秦軍汙水上，大破之。 |
| 依据 | `030` |

| 说明 | 「約未成」三个字后面没有解释。**一边在谈，一边在打**——打完了，约才谈成。这个次序底本写得很清楚 |
|---|---|

---

### 情节点 6 · 洹水

> 章邯又派人去见项籍，想订约。项籍召集军吏商量：
>
> 「糧少，欲聽其約。」
>
> ——粮少，想接受他的约。
>
> 军吏都说：「善。」
>
> 项籍就和章邯约在洹水南岸的殷虚上相见。盟约之后，章邯见了项籍，流下眼泪，对项籍说起赵高。
>
> 项籍就立章邯为雍王，留在楚军中；派长史欣做上将军，带秦军做前锋。到了新安。

| 标记 | ◆ |
| 原文 | `031` 項羽召軍吏謀曰：「糧少，欲聽其約。」軍吏皆曰：「善。」 |
| 依据 | `031`「項羽乃與期洹水南殷虛上。已盟，章邯見項羽而流涕，為言趙高」；`031`「使長史欣為上將軍，將秦軍為前行。到新安」 |

| 说明 | 接受投降的理由不是宽大，是「糧少」。**两个字，一个军吏会议，一句「善」** |
|---|---|
| 说明 | 盟完，章邯哭了。**这是全篇唯一一次有人哭**——哭的人是把二十万人带出来的那一个 |
|

---

### 情节点 7 · 窃语

> 诸侯的吏卒，从前服徭役、戍边经过秦中，秦中的吏卒对他们多半不好。等到秦军投降诸侯，诸侯的吏卒就乘胜把他们当奴仆使唤，随意折辱秦军的吏卒。
>
> 秦军的吏卒大多私下说：
>
> 「章將軍等詐吾屬降諸侯，今能入關破秦，大善；即不能，諸侯虜吾屬而東，秦必盡誅吾父母妻子。」
>
> ——章将军等人骗我们降了诸侯。如今能入关破秦，很好；如果不能，诸侯俘虏我们往东去，秦一定把我们的父母妻子全杀了。
>
> 诸侯军中渐渐听到这些话，告诉了项籍。

| 标记 | ◆ |
| 原文 | `032` 秦吏卒多竊言曰：「章將軍等詐吾屬降諸侯，今能入關破秦，大善；即不能，諸侯虜吾屬而東，秦必盡誅吾父母妻子。」 |
| 依据 | `032`「諸侯吏卒異時故繇使屯戍過秦中，秦中吏卒遇之多無狀」；`032`「諸侯微聞其計，以告項羽」 |

| 说明 | 他们怕的不是打仗，是家里。**父母妻子在秦，这一句把二十万人的处境说完了** |
|---|---|
| 说明 | 前面那句「奴虜使之，輕折辱秦吏卒」是这一句的来路。**先有折辱，后有窃语**——底本把次序写得很清楚 |
|

---

### 情节点 8 · 夜击

> 项籍于是召黥布、蒲将军商量：
>
> 「秦吏卒尚眾，其心不服，至關中不聽，事必危，不如擊殺之，而獨與章邯、長史欣、都尉翳入秦。」
>
> ——秦军的吏卒还多，心里不服；到了关中不听号令，事情一定危险。不如攻击杀死他们，只和章邯、长史欣、都尉翳入秦。
>
> 于是楚军在夜里发起攻击：
>
> 「於是楚軍夜擊阬秦卒二十餘萬人新安城南。」
>
> ——于是楚军在夜里发起攻击，在新安城南把秦卒二十多万人杀死。

| 标记 | ◆ |
| 原文 | `033` 項羽乃召黥布、蒲將軍計曰：「秦吏卒尚眾，其心不服，至關中不聽，事必危，不如擊殺之，而獨與章邯、長史欣、都尉翳入秦。」 |
| 依据 | `033`「於是楚軍夜擊阬秦卒二十餘萬人新安城南」 |

| 说明 | 理由只有一句：心不服。**「至關中不聽」是将来可能发生的事**——底本不给别的依据，也不给会议的结果 |
|---|---|
| 说明 | 「阬」字，后人常训作活埋，也有别的讲法，具体情形与人数各家说法不一。**这一篇的白话只照「击杀」写，不写方式**；`033` 只给「二十餘萬人」这一个数 |
|

## 四、背景卡

### 司马门 ○

宫城的外门。`027` 记长史欣「留司馬門三日」——**他在门外等了三天，赵高不见**。

一个前线派来的长史，在门外等三天，这件事本身就是答复。

> **依据**：`027`「至咸陽，留司馬門三日，趙高不見」。**司马门是不是求见的必经之处、三日是不是定制，本篇这七段里没有。**

---

### 长史欣 ○

章邯的长史，名欣。`027` 里他做了三件事：去咸阳请示、跑了、回来报告。

**他与项梁有旧**：`052` 说「長史欣者，故為櫟陽獄掾，嘗有德於項梁」——当年项梁在栎阳被逮，请蕲县狱掾曹咎写信给栎阳狱掾司马欣，事情才了结（`002`，在 `01-qibing`）。**姓司马、做过狱掾、这笔「德」，都要读到 `052` 才写明；`027` 从头到尾只称他「長史欣」。**

> **依据**：`027`「使長史欣請事」「長史欣恐，還走其軍」；`052`「長史欣者，故為櫟陽獄掾，嘗有德於項梁」；`002`「乃請蘄獄掾曹咎書抵櫟陽獄掾司馬欣，以故事得已」。**他这三天里想了什么，本篇这七段里没有。**

---

### 殷虚 ○

洹水南岸的废墟，即殷的故都。`031` 记项籍与章邯「期洹水南殷虛上」——**盟约在废墟上订**。

> **依据**：`031`「項羽乃與期洹水南殷虛上」。**「殷虛」是不是商代故都、当时是什么样子，`031` 不解释；那一层是后人的考证。**

---

### 阬 ○

`033` 用的是「阬」字。本义是坑、是坑陷；用在这里，后人一般读作坑杀。**具体怎么做的，各家讲法不一，`033` 一个字也没有。**

**这一篇的白话只写「击杀」**，不写活埋、不写器械、不写过程；人数照原文的「二十餘萬人」，不另作推算。

> **依据**：`033`「於是楚軍夜擊阬秦卒二十餘萬人新安城南」。**地点只到「新安城南」，范围有多大、那一夜有多长，本篇这七段里没有。**

---

### 诸侯吏卒 ○

`032` 给了一条很长的因果：这些人从前服徭役、戍边经过秦中，被秦中吏卒「多無狀」地对待过；如今秦军投降，他们反过来「奴虜使之」。

**这笔账是旧的。**底本把两头的待遇并排写出来，不评谁对。

> **依据**：`032`「諸侯吏卒異時故繇使屯戍過秦中，秦中吏卒遇之多無狀，及秦軍降諸侯，諸侯吏卒乘勝多奴虜使之」。**「無狀」具体指什么，`032` 不写。**

## 七、设计说明

> **这一节编译器跳过，不渲染。** 放「为什么这么写」。

**八个情节点，前四段没有一场仗。** `027` 拆成三段落：相持、司马门、欣报——三件都是文件、等待和回话。`028`–`029` 是另一封信。到 `030` 才重新有兵。

**两条线并行**：一条是章邯在朝里被逼（司马门、赵高的信、陈馀的书），一条是营中二十万人的处境（`032` 的折辱与窃语）。两线在 `033` 合上。

**核心那一句，白话按「击杀」写。** `033` 用的是「阬」，后世多解作活埋，也有别讲；人数只照原文的「二十餘萬人」。**不写方式、不写过程、不做数字推算**，争议只在说明和背景卡里点一句。

**章邯哭的那一下留着。** `031`「已盟，章邯見項羽而流涕」——这是全篇唯一一次有人哭，而且哭的人是带着二十万人来降的那一个。**底本不写他为什么哭**，白话也不替他解释。

**收在新安城南。** 下一篇从函谷关开始：`034` 关上有兵，进不去。**这一篇的最后一句话，是下一篇第一句话的反面**——那边是「不得入」，这边是「入秦」。
