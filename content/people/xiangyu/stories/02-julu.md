> 原文 014–026，十三段，七百余字。
> 叔父战死之后，楚国的兵交到宋义手里。大军停在安阳，四十六天不动。
> **然后是一个早晨，一次帐中的斩首，和一条没有退路的河。**

## 二、情节点

### 情节点 1 · 田假

> 过了几个月，项梁引兵攻亢父，又与齐国的田荣、司马龙且合兵救东阿，在东阿大破秦军。
>
> 田荣随即带兵回去，赶走了他的王田假。田假逃到楚国，田假的相田角逃到赵国；田角之弟田閒本是齐将，留在赵国不敢回去。田荣立田儋的儿子田市为齐王。
>
> 项梁破了东阿的秦军，追着秦军打，几次派使者去催齐国发兵，想一起向西。田荣说：
>
> 「楚殺田假，趙殺田角、田閒，乃發兵。」
>
> ——楚国杀了田假，赵国杀了田角、田閒，我才发兵。
>
> 项梁说：
>
> 「田假為與國之王，窮來從我，不忍殺之。」
>
> ——田假是盟国的王，走投无路来投奔我，我不忍心杀他。
>
> 赵国也不肯杀田角、田閒来和齐国做交易，齐国于是不肯发兵助楚。
>
> 项梁派沛公和项籍另攻城阳，屠了城；向西在濮阳东破秦军，秦兵退入濮阳。沛公、项籍于是攻定陶，定陶攻不下来，走了；向西略地到雝丘，大破秦军，斩了李由；回兵攻外黄，外黄攻不下来。

| 标记 | ◆ |
| 原文 | `014` 居數月，引兵攻亢父，與齊田榮、司馬龍且軍救東阿，大破秦軍於東阿。 |
| 依据 | `014`「田榮曰：『楚殺田假，趙殺田角、田閒，乃發兵』」；`015`「田假為與國之王，窮來從我，不忍殺之」；`015`「項梁使沛公及項羽別攻城陽，屠之」 |

| 说明 | 一个走投无路来投奔的人，成了别人的条件。**项梁的理由只有「不忍」两个字**——他没有算这笔账值不值 |
|---|---|
| 说明 | 同一段里还有一场屠城：「別攻城陽，屠之」。**杀了李由、屠了城阳，加起来就是「益輕秦」三个字的来路**。底本在这两件事之间不着一字 |
|

### 情节点 2 · 宋义谏

> 项梁从东阿起兵向西，北上到了定陶，又一次破了秦军；项籍等人又斩了李由。项梁越来越轻视秦军，脸上有骄色。
>
> 宋义劝他：
>
> 「戰勝而將驕卒惰者敗。今卒少惰矣，秦兵日益，臣為君畏之。」
>
> ——打了胜仗、将领骄傲、士卒懈怠的，会失败。如今士卒已经有些懈怠了，秦兵一天天增加，我替您害怕。
>
> 项梁不听。他派宋义出使齐国。宋义在路上遇到齐国的使者高陵君显，问他是不是要去见武信君，高陵君显说「然」。宋义说：
>
> 「臣論武信君軍必敗。公徐行即免死，疾行則及禍。」
>
> ——我料武信君的军队必败。您走慢一点就能免死，走快了就赶上祸事。

| 标记 | ◆ |
| 原文 | `016` 項梁起東阿，西，北比至定陶，再破秦軍，項羽等又斬李由，益輕秦，有驕色。 |
| 依据 | `016`「戰勝而將驕卒惰者敗。今卒少惰矣，秦兵日益，臣為君畏之」；`016`「臣論武信君軍必敗。公徐行即免死，疾行則及禍」 |

| 说明 | 宋义把话说得很直：「戰勝而將驕卒惰者敗」。**他说的不是秦军强，是楚军自己松了**——而项梁「弗聽」 |
|---|---|
| 说明 | 被派去齐国的人，在路上劝齐国的使者慢点走。**同一句话，对项梁说是谏，对高陵君显说是保命** |
|

### 情节点 3 · 定陶

> 秦军果然倾全部兵力增援章邯，在定陶大破楚军。项梁死了。
>
> 沛公、项籍离开外黄去攻陈留，陈留坚守，攻不下来。两个人商量：
>
> 「今項梁軍破，士卒恐。」
>
> ——如今项梁的军队被打败，士卒害怕。
>
> 于是和吕臣的兵一起向东。吕臣驻彭城东，项籍驻彭城西，沛公驻砀。
>
> 章邯破了项梁的军队，认为楚地的兵不值得担心，就渡过黄河去击赵，大破赵军。这时候赵歇为王，陈余为将，张耳为相，都退进钜鹿城。章邯令王离、涉閒围钜鹿，章邯驻在城的南面，筑起甬道运粮。陈余为将，带几万人驻在钜鹿北面——这就是所谓河北之军。

| 标记 | ◆ |
| 原文 | `017` 秦果悉起兵益章邯，擊楚軍，大破之定陶，項梁死。 |
| 依据 | `017`「今項梁軍破，士卒恐」；`018`「章邯已破項梁軍，則以為楚地兵不足憂，乃渡河擊趙，大破之」 |

| 说明 | 「項梁死」三个字，前面没有一句铺垫。**上一段他还在「益輕秦，有驕色」，这一段就结束了** |
|---|---|
| 说明 | 「秦果悉起兵益章邯」——「果」字是回头看的：宋义说过必败，果然败了。**章邯随即得出一个结论：楚地的兵不值得担心**。这个结论把秦军主力送去了北边 |
|

### 情节点 4 · 卿子冠军

> 楚兵在定陶大败之后，怀王害怕了，从盱台到彭城，把项籍、吕臣的兵并过来自己带。以吕臣为司徒，吕臣的父亲吕青为令尹；以沛公为砀郡长，封武安侯，带砀郡的兵。
>
> 从前宋义在路上遇到的齐国使者高陵君显，正在楚军中。他去见楚王，说：
>
> 「宋義論武信君之軍必敗，居數日，軍果敗。兵未戰而先見敗徵，此可謂知兵矣。」
>
> ——宋义说武信君的军队必败，过了几天，军队果然败了。兵还没交战就先看出败象，这可以算懂得用兵了。
>
> 楚王召宋义来议事，非常高兴，于是任命他为上将军；项籍为鲁公、次将，范增为末将，去救赵。各路别将都归宋义节制，号称卿子冠军。
>
> 大军走到安阳，停了四十六天不前进。

| 标记 | ◆ |
| 原文 | `020` 初，宋義所遇齊使者高陵君顯在楚軍，見楚王曰：「宋義論武信君之軍必敗，居數日，軍果敗。兵未戰而先見敗徵，此可謂知兵矣。」 |
| 依据 | `019`「懷王恐，從盱台之彭城，並項羽、呂臣軍自將之」；`020`「因置以為上將軍，項羽為魯公，為次將，範增為末將」「行至安陽，留四十六日不進」 |

| 说明 | 宋义升上去的理由，是**他预言了别人的失败**。这句话由高陵君显说出来，比他自己说有力得多 |
|---|---|
| 说明 | 一个「留」字加一个数字：四十六日。**没有理由，没有会议记录，只有一个停下来的事实**——而后面所有的杀机都长在这四十六天上 |
|

### 情节点 5 · 坐而运策

> 项籍说：
>
> 「吾聞秦軍圍趙王鉅鹿，疾引兵渡河，楚擊其外，趙應其內，破秦軍必矣。」
>
> ——我听说秦军把赵王围在钜鹿，赶快引兵渡河：楚军从外面打，赵军在里面接应，破秦军是一定的。
>
> 宋义说：
>
> 「不然。夫搏牛之虻不可以破蟣蝨。」
>
> ——不对。叮牛的虻虫，打不破虱子。
>
> 他说秦攻赵，胜了兵就疲，楚可以趁它的疲敝；不胜，就引兵西行，一定能拿下秦。所以不如先让秦赵相斗。然后他说：
>
> 「夫被堅執銳，義不如公；坐而運策，公不如義。」
>
> ——披坚甲、执利兵，冲在前面，我不如您；坐下来运筹谋算，您不如我。
>
> 于是下令军中：
>
> 「猛如虎，很如羊，貪如狼，彊不可使者，皆斬之。」
>
> ——猛得像虎、狠得像羊、贪得像狼、强悍而不听使唤的，都斩了。
>
> 他派儿子宋襄去做齐国的相，亲自送到无盐，饮酒高会。天寒大雨，士卒又冷又饿。

| 标记 | ◆ |
| 原文 | `021` 項羽曰：「吾聞秦軍圍趙王鉅鹿，疾引兵渡河，楚擊其外，趙應其內，破秦軍必矣。」 |
| 依据 | `021`「夫被堅執銳，義不如公；坐而運策，公不如義」；`022`「猛如虎，很如羊，貪如狼，彊不可使者，皆斬之」 |

| 说明 | 宋义的两句话挨着：一句是兵法（搏牛之虻），一句是分工（被坚执锐 / 坐而运策）。**第二句是把项籍定在「冲锋的人」这个位置上** |
|---|---|
| 说明 | 下令斩「猛如虎」的人，然后自己送儿子去做齐相、饮酒高会。**同一天的雨里，士卒冻饥。**底本把这两件事并排放在一段里，不作评语 |
|

### 情节点 6 · 斩宋义

> 项籍说：
>
> 「將戮力而攻秦，久留不行。今歲饑民貧，士卒食芋菽，軍無見糧，乃飲酒高會，不引兵渡河因趙食，與趙並力攻秦，乃曰『承其敝』。」
>
> ——要合力攻秦，却久久停着不走。今年饥荒，百姓穷困，士卒吃芋头和豆子，军中没有现成的粮食，却饮酒高会；不引兵渡河、就食于赵，与赵合力攻秦，反而说「承其敝」。
>
> 秦强，攻新造的赵，其势必举赵；赵举而秦更强，还有什么疲敝可乘？况且国兵新破，王坐不安席，扫境内之兵专属于将军，国家安危，在此一举。
>
> 「今不恤士卒而徇其私，非社稷之臣。」
>
> ——如今不体恤士卒，却营求私利，不是社稷之臣。
>
> 项籍早晨去朝见上将军宋义，就在他的帐中斩下了宋义的头。出来号令军中：
>
> 「宋義與齊謀反楚，楚王陰令羽誅之。」
>
> ——宋义与齐国谋反楚国，楚王暗中命我诛杀他。
>
> 当时诸将都慴服，没有敢支吾的。都说：
>
> 「首立楚者，將軍家也。今將軍誅亂。」
>
> ——最先立楚王的，是将军家。如今将军诛杀乱臣。
>
> 于是一起立项籍为假上将军。派人去追宋义的儿子，追到齐国，杀了。派桓楚向怀王报命。怀王就派项籍为上将军，当阳君、蒲将军都归项籍。

| 标记 | ◆ |
| 原文 | `023` 項羽晨朝上將軍宋義，即其帳中斬宋義頭，出令軍中曰：「宋義與齊謀反楚，楚王陰令羽誅之。」 |
| 依据 | `022`「將戮力而攻秦，久留不行」；`023`「今不恤士卒而徇其私，非社稷之臣」；`024`「乃相與共立羽為假上將軍」 |

| 说明 | 他给的理由有两层：一层是士卒冻饥、久留不行，一层是「宋義與齊謀反楚」。**前一层底本记了，后一层底本不交代真假**——只记他出帐之后这样号令 |
|---|---|
| 说明 | 诸将那句话把合法性递了回来：「首立楚者，將軍家也」。**杀人的是他，认这件事的是众人** |
|

### 情节点 7 · 破釜沉舟

> 项籍杀了卿子冠军之后，威震楚国，名闻诸侯。他派当阳君、蒲将军带两万兵渡河，救钜鹿。战事稍有利，陈余又来请兵。
>
> 项籍于是带全部兵渡河：
>
> 「皆沈船，破釜甑，燒廬舍，持三日糧，以示士卒必死，無一還心。」
>
> ——把船全都凿沉，把锅甑全都打破，把房屋全都烧掉，只带三天的粮，以此向士卒表示必死之心，没有一个打算回来。
>
> 到了就围住王离，与秦军接战，打了九仗，断绝秦军的甬道，大破秦军，杀了苏角，俘虏了王离。涉閒不肯降楚，自己烧死了。这时候，楚兵在诸侯之中最强。

| 标记 | ◆ |
| 原文 | `025` 項羽乃悉引兵渡河，皆沈船，破釜甑，燒廬舍，持三日糧，以示士卒必死，無一還心。 |
| 依据 | `025`「乃遣當陽君、蒲將軍將卒二萬渡河」「九戰，絕其甬道，大破之，殺蘇角，虜王離」；`025`「涉閒不降楚，自燒殺」 |

| 说明 | 沉船、破釜、烧屋，三件事都做在渡河之后。**「持三日糧」是最要紧的一句**：三天之内打不赢，就没有第四天 |
|---|---|
| 说明 | 二万人先过河，战少利，才「悉引兵渡河」。**这不是一场豪赌，是先试过一手才把全部押上去** |
|

### 情节点 8 · 壁上观

> 来救钜鹿的诸侯军有十几座营垒，没有一座敢出兵。等到楚军出击秦军，诸侯的将领都站在营垒的墙上看着。
>
> 楚军战士没有一个不是以一当十，楚兵的呼喊声震动天空，诸侯军没有一个人不心里发慌。
>
> 破了秦军之后，项籍召见诸侯的将领。进辕门的时候：
>
> 「無不膝行而前，莫敢仰視。」
>
> ——没有一个不是跪着用膝盖往前挪，没有敢抬头的。
>
> 项籍从此开始做诸侯的上将军，诸侯都归他统属。

| 标记 | ◆ |
| 原文 | `026` 於是已破秦軍，項羽召見諸侯將，入轅門，無不膝行而前，莫敢仰視。 |
| 依据 | `026`「諸侯軍救鉅鹿下者十餘壁，莫敢縱兵。及楚擊秦，諸將皆從壁上觀」；`026`「楚戰士無不一以當十，楚兵呼聲動天」 |

| 说明 | 「從壁上觀」——他们不是没到，是到了不敢动。**这一篇的旁观者从头到尾站在墙上** |
|---|---|
| 说明 | 「膝行而前」是跪着往前挪。**上一段他们还在墙上看，这一段他们连头都不敢抬。**同一批人，中间隔着一场仗 |
|

## 四、背景卡

### 卿子冠军 ○

宋义的名号。`020` 记「號為卿子冠軍」。**「卿子」是尊称，「冠军」是冠于诸军之上**——这两个字是名号，不是官名。

名号给了宋义，兵也给了他：诸别将都属他。

> **依据**：`020`「因置以為上將軍，項羽為魯公，為次將，範增為末將，救趙。諸別將皆屬宋義，號為卿子冠軍」。**「卿子」二字的准确含义，本篇这十三段里没有解释。**

---

### 安阳 ○

大军停下来的地方。`020` 只写「行至安陽，留四十六日不進」——**四十六天，一个数字，没有理由**。

这四十六天里发生了三件事：宋义送儿子去齐国、饮酒高会；士卒冻饥；项籍杀了宋义。

> **依据**：`020`「行至安陽，留四十六日不進」；`022`「天寒大雨，士卒凍飢」。**安阳在何处、为什么停在这里，本篇这十三段里没有。**

---

### 破釜沉舟 ○

「沈」是沉，「釜」是锅，「甑」是蒸饭的瓦器。`025` 记的是渡河之后四件事：沉船、破釜甑、烧庐舍、持三日粮。

**这四件事是同时做的，目的写在最后一句：「以示士卒必死，無一還心」。**

> **依据**：`025`「皆沈船，破釜甑，燒廬舍，持三日糧，以示士卒必死，無一還心」。**一共沉了几条船、破了多少釜甑，本篇这十三段里没有。**

---

### 甬道 ○

章邯筑的运粮通道。`018` 记「築甬道而輸之粟」——**两边有墙的通道，粮车走在里面，人不出来**。

`025` 记楚军「絕其甬道」，断的就是这条线。**钜鹿城下的秦军，靠它吃饭。**

> **依据**：`018`「章邯軍其南，築甬道而輸之粟」；`025`「九戰，絕其甬道」。**甬道有多长、怎么筑的，本篇这十三段里没有。**

---

### 辕门与膝行 ○

「辕门」是把战车的辕木竖起来作门，军营的门。`026` 记诸侯将「入轅門，無不膝行而前，莫敢仰視」。

**跪着用膝盖走，是当时表示极度畏服的姿态。**这一句是他们自己做的，不是项籍要求的。

> **依据**：`026`「項羽召見諸侯將，入轅門，無不膝行而前，莫敢仰視」。**「辕门」的形制、膝行的礼数，`026` 都不解释；这两层是后人的训释。**

## 七、设计说明

> **这一节编译器跳过，不渲染。** 放「为什么这么写」。

**八个情节点，一条直线：一个人的死，换另一个人的死，再换一条河。** `014`–`015` 是项梁最后的顺境；`016` 有人谏，`017` 项梁死；`018` 秦军北上；`019`–`020` 兵权换手，大军停在安阳；`021`–`022` 两个人争方向；`023`–`024` 帐中之斩；`025`–`026` 渡河与墙上的旁观者。

**四十六天是这一篇的支点。** `020` 只给这一个数字，`021` 给宋义的理由，`022` 给同一段时间里士卒的冻饥。两边都不加评语——**读者自己会把「飲酒高會」和「士卒凍飢」放在一起**。

**破釜沉舟那一段，白话只写四个动作，不解释「决心」。** 决心是原文最后一句自己说的（「以示士卒必死，無一還心」）；把它提前写进白话，等于替司马迁作总结。

**「杀宋义」这一段的两种说法都摆出来了**：项籍给士卒的理由（久留不行、不恤士卒）来自 `022`，他出帐之后号令的理由（与齐谋反）来自 `023`。**后一条真假，底本不说**——所以正文只写「号令」，不写「其实」。

**收在「膝行而前」。** 下一篇是章邯投降、二十万人被杀；再往后才是鸿门。**这一篇结束时，诸侯都不敢抬头；下一篇开始，秦军最后的主力要交出武器。**
