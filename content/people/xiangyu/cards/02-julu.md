# 复习卡 · 故事 02 · 破釜沉舟

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 02 · 破釜沉舟（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：定陶之后，兵权是怎么换手的？**

答：**三步：先被收走，再被交出去，最后自己拿回来。**

| 步 | 段 | 发生了什么 |
|---|---|---|
| 1 | `017` | 定陶大败，项梁死 |
| 2 | `019` | 怀王害怕，从盱台到彭城，把项羽、吕臣的兵并过来自己带 |
| 3 | `020` | 高陵君显称宋义知兵；怀王用宋义为上将军，项羽为次将 |
| 4 | `023` | 项羽在帐中斩宋义 |
| 5 | `024` | 诸将共立羽为假上将军；怀王因使项羽为上将军 |

**`019` 那一步最容易被略过**：楚军的名义主将是怀王，不是项羽。他的兵是从别人手里接回来的。

| | |
|---|---|
| 依据 | `019`「懷王恐，從盱台之彭城，並項羽、呂臣軍自將之」；`020`「因置以為上將軍，項羽為魯公，為次將」；`024`「乃相與共立羽為假上將軍」「懷王因使項羽為上將軍」 |
| 标记 | ◆ 出自原文 |
| 考点 | 兵权经过怀王之手；项羽不是直接从项梁那里接的 |

---

### 卡 2 · 因果 ★

**问：宋义凭什么被用为上将军？**

答：**凭他预言了别人的失败。**

| 谁 | 说了什么 | 效果 |
|---|---|---|
| `016` | 宋义对项梁说「戰勝而將驕卒惰者敗」 | 项梁「弗聽」 |
| `016` | 宋义在路上对高陵君显说「臣論武信君軍必敗」 | 后来「軍果敗」 |
| `020` | 高陵君显对楚王说「兵未戰而先見敗徵，此可謂知兵矣」 | 楚王用他为上将军 |

**这套说辞由别人说出来，比他自陈有力得多。** 而它成立的条件，是定陶那一败——`017` 的「秦果悉起兵益章邯」正是那个「果」字。

| | |
|---|---|
| 依据 | `016`「戰勝而將驕卒惰者敗」「臣論武信君軍必敗」；`017`「秦果悉起兵益章邯」；`020`「兵未戰而先見敗徵，此可謂知兵矣」 |
| 标记 | ◆ 出自原文 |
| 考点 | 升迁理由是一句预言，不是一场胜仗 |

---

### 卡 3 · 陷阱题 ⚠️

**问：宋义在安阳停四十六天，理由是什么？**

答：**底本没有给停军的理由。**

`020` 只给一句话：「留四十六日不進。」**没有理由，没有会议，没有记录。**

`021`–`022` 里有他的说法（秦赵相斗、承其敝），但那是**项籍质问他之后**的话。**事后解释不等于当时停军的理由**，底本也没有把这两件事接起来。

| | |
|---|---|
| 依据 | `020`「行至安陽，留四十六日不進」；`021` 才是他后来的说法 |
| 标记 | — 史书未载 |
| 考点 | 把 `021` 的辩解当成 `020` 的理由，是替底本补了一个因果 |

---

### 卡 4 · 动机 ★

**问：项羽杀宋义，给的理由是什么？**

答：**两套，而且不是同一套。**

| 场合 | 段 | 理由 |
|---|---|---|
| 对宋义本人（数罪） | `022` | 「將戮力而攻秦，久留不行」；士卒食芋菽、军无见粮，却饮酒高会 |
| 对军中（出帐之后） | `023` | 「宋義與齊謀反楚，楚王陰令羽誅之」 |
| 对诸将（他们没有反驳） | `023` | 诸将只说：「首立楚者，將軍家也。今將軍誅亂。」 |

**前一套是「不恤士卒」，后一套是「谋反」。** 后一套真假，底本一字不载。诸将认的也不是这两条，是「将军家」的资格。

| | |
|---|---|
| 依据 | `022`「久留不行」「士卒食芋菽，軍無見糧」；`023`「今不恤士卒而徇其私，非社稷之臣」「宋義與齊謀反楚，楚王陰令羽誅之」「首立楚者，將軍家也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两套理由分开读；不要把它们合成一个动机，也不要替底本裁「谋反」的真假 |

---

### 卡 5 · 细节 ★

**问：「破釜沉舟」到底做了几件事？**

答：**四件，都在渡河之后，目的写在最后一句。**

| 原文 | 动作 |
|---|---|
| 皆沈船 | 把船全都凿沉 |
| 破釜甑 | 把锅和蒸饭的瓦器全都打破 |
| 燒廬舍 | 把房屋全都烧掉 |
| 持三日糧 | 只带三天的粮食 |

**「持三日糧」是最要紧的一句**：三天之内打不赢，就没有第四天。四件事的目的，原文自己说了：「以示士卒必死，無一還心。」

| | |
|---|---|
| 依据 | `025`「皆沈船，破釜甑，燒廬舍，持三日糧，以示士卒必死，無一還心」 |
| 标记 | ◆ 出自原文 |
| 考点 | 四件事是同时做的；「决心」是原文最后一句说的，不是后人总结的 |

---

### 卡 6 · 对照

**问：先派两万人过河，后来才全军渡河——这个次序说明什么？**

答：**说明这不是一场一上来就押全部的豪赌。**

`025` 的次序是：

```
遣当阳君、蒲将军将卒二万渡河   →   战少利   →   陈余复请兵   →   项羽乃悉引兵渡河
```

**先试过一手，有了「少利」，才把全部押上去。** 沉船破釜发生在第二步，不是在第一步。

| | |
|---|---|
| 依据 | `025`「乃遣當陽君、蒲將軍將卒二萬渡河」「戰少利，陳餘復請兵。項羽乃悉引兵渡河」 |
| 标记 | ○ 合理推演 |
| 考点 | 次序是原文给的；「先试后押」是从这个次序读出来的，底本没有评论 |

---

### 卡 7 · 主题

**问：「壁上观」写的是什么？**

答：**写的是：他们到了，但不敢动。**

| 原文 | 意思 |
|---|---|
| 諸侯軍救鉅鹿下者十餘壁 | 来救的诸侯军有十几座营垒 |
| 莫敢縱兵 | 没有一座敢出兵 |
| 皆從壁上觀 | 都站在营垒的墙上看着 |

然后才是楚军「一以當十」「呼聲動天」，诸侯军「人人惴恐」。**同一批人，战前在墙上看，战后跪着不敢抬头**（`026`「無不膝行而前，莫敢仰視」）。中间隔着一场仗。

| | |
|---|---|
| 依据 | `026`「諸侯軍救鉅鹿下者十餘壁，莫敢縱兵。及楚擊秦，諸將皆從壁上觀」「無不膝行而前，莫敢仰視」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「壁上观」是原文的动作，不是后人的比喻；前后两段的姿态要连起来读 |

---

### 卡 8 · 细节

**问：「卿子冠军」这四个字怎么解？**

答：**名号，不是官名。**

`020` 记「號為卿子冠軍」——**「卿子」是尊称，「冠军」是冠于诸军之上。** 这两层都是后人的训释，`020` 只给这四个字，没有解释。

名号给了宋义，兵也给了他：诸别将都属他。**名号与兵权一起给，一起被夺。**

| | |
|---|---|
| 依据 | `020`「諸別將皆屬宋義，號為卿子冠軍」 |
| 标记 | ○ 训释 |
| 考点 | 名号不是官职；「卿子」的准确含义，本篇没有解释 |
