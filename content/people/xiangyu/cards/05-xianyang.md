# 复习卡 · 故事 05 · 火三月不灭

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 05 · 火三月不灭（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：进咸阳之后，项羽做了几件事？底本是怎么排的？**

答：**四件事，压在同一句里，中间没有因果。**

| 原文 | 事 |
|---|---|
| 屠咸陽 | 屠城 |
| 殺秦降王子嬰 | 杀秦的降王 |
| 燒秦宮室，火三月不滅 | 烧宫室 |
| 收其貨寶婦女而東 | 收货宝妇女，往东 |

`049` 的这一句后面，**没有一句解释**：屠了多少人、火怎么起的、为什么杀子婴，全都不写。**四件事并排，就是底本给的形状。**

| | |
|---|---|
| 依据 | `049`「居數日，項羽引兵西屠咸陽，殺秦降王子嬰，燒秦宮室，火三月不滅；收其貨寶婦女而東」 |
| 标记 | ◆ 出自原文 |
| 考点 | 四件事是并列的；不要替它们补一条「因为……所以……」 |

---

### 卡 2 · 因果 ★

**问：义帝这一篇里，先发生了什么，后发生了什么？**

答：**先被尊，后被迁，最后死在江中。**

| 步 | 段 | 原文 |
|---|---|---|
| 1 | `050` | 怀王答「如約」；「乃尊懷王為義帝」 |
| 2 | `056` | 「使人徙義帝」，理由是「古之帝者地方千里，必居上游」 |
| 3 | `056` | 「乃使使徙義帝長沙郴縣」 |
| 4 | `056` | 「乃陰令衡山、臨江王擊殺之江中」 |

**尊义帝在 `050`，杀义帝在 `056`——同一篇里，前后两个动作**，中间隔着整张分封名单。搬他的理由，底本给了；杀他的理由，底本没给。

| | |
|---|---|
| 依据 | `050`「乃尊懷王為義帝」；`056`「使人徙義帝」「乃使使徙義帝長沙郴縣」「乃陰令衡山、臨江王擊殺之江中」 |
| 标记 | ◆ 出自原文 |
| 考点 | 先尊后杀的两个动作都在本篇；中间的名单不是闲笔，是这一段的时间 |

---

### 卡 3 · 细节 ★

**问：所谓「十八王」，这个数字是底本写的吗？**

答：**不是。底本一段一段记封号，数出来是十八个。**

名单在 `051`–`055`：汉、雍、塞、翟、西魏、河南、韩、殷、代、常山、九江、衡山、临江、辽东、燕、胶东、齐、济北。

**项羽自己不在其中。** `055` 另起一行：「項王自立為西楚霸王，王九郡，都彭城。」

| | |
|---|---|
| 依据 | `051`–`055` 逐段记封号；`055`「項王自立為西楚霸王，王九郡，都彭城」 |
| 标记 | ○ 合理推演 |
| 考点 | 「十八」是数出来的，底本没有这个数；数名单也是读史的一种动作，但要说明它是数出来的 |

---

### 卡 4 · 陷阱题 ⚠️

**问：屠咸阳死了多少人？**

答：**底本不载。**

`049` 只有一个「屠」字。**人数、范围、死的是谁，一个字都没有。** 也不要拿别处的数字来补这一处。

| | |
|---|---|
| 依据 | `049`「項羽引兵西屠咸陽」 |
| 标记 | — 史书未载 |
| 考点 | 「屠」是原文的字；它不携带人数。「不载」不等于「没有发生」，只是这一段没有记 |

---

### 卡 5 · 动机

**问：项羽为什么把都城定在彭城？**

答：**底本没有把理由写出来。**

`055` 只记：「項王自立為西楚霸王，王九郡，都彭城。」**定都在彭城，是一个结果。**

前面 `049` 有他自己说的话：「富貴不歸故鄉，如衣繡夜行，誰知之者！」——**这是他拒绝留在关中时给的理由**，和定都彭城方向一致；但底本没有把这两处接起来。

| | |
|---|---|
| 依据 | `049`「富貴不歸故鄉，如衣繡夜行，誰知之者」；`055`「都彭城」 |
| 标记 | ○ 合理推演 |
| 考点 | 两处都在原文里；「所以定都彭城是为了回乡」是我们的连线，底本没有连 |

---

### 卡 6 · 细节 ★

**问：分封的理由，底本放在哪里？**

答：**放在封号前面，用几句旧事交代。**

| 受封者 | 段 | 理由 |
|---|---|---|
| 司马欣 | `052` | 「故為櫟陽獄掾，嘗有德於項梁」 |
| 董翳 | `052` | 「本勸章邯降楚」 |
| 黥布 | `053` | 「常冠軍」 |
| 吴芮 | `053` | 「率百越佐諸侯，又從入關」 |
| 共敖 | `053` | 「將兵擊南郡，功多」 |

**先写受封者的旧事，再写封号**——给谁封，理由就在那几句旧事里。这不是一张任意的名单。

| | |
|---|---|
| 依据 | `052`「故立司馬欣為塞王」「立董翳為翟王」；`053`「故立布為九江王，都六」「故立芮為衡山王」「因立敖為臨江王」 |
| 标记 | ◆ 出自原文 |
| 考点 | 理由前置是底本的写法；读名单时要连着前面那几句读 |

---

### 卡 7 · 对照 ★

**问：田荣没有封，陈馀封了三个县——底本怎么解释这两处？**

答：**两处理由都写出来了，而且方向相反。**

| 人 | 段 | 原文 | 意思 |
|---|---|---|---|
| 田荣 | `054` | 「數負項梁，又不肯將兵從楚擊秦，以故不封」 | 几次辜负项梁，不肯出兵——不封 |
| 陈馀 | `055` | 「棄將印去，不從入關，然素聞其賢，有功於趙」「故因環封三縣」 | 丢了将印、没入关，但素来有贤名、有功于赵——封三县 |

**同样是「没有跟楚军走」，一个不封，一个封了。** 差别写在理由里：田荣是「负项梁」，陈馀是「贤」与「有功于赵」。

| | |
|---|---|
| 依据 | `054`「田榮者，數負項梁，又不肯將兵從楚擊秦，以故不封」；`055`「成安君陳餘棄將印去，不從入關，然素聞其賢，有功於趙，聞其在南皮，故因環封三縣」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两处都给了理由；不要把它们读成同一种处置 |

---

### 卡 8 · 主题

**问：这一篇收在哪里？**

答：**收在「各就国」三个字上。**

`056` 的第一句：「漢之元年四月，諸侯罷戲下，各就國。」

**分封完了，各路兵马在戏下散伙，各自回自己的封国去。** 烧了三个月的咸阳、被分掉的天下、被迁走的义帝，都从这一句开始各自往东往西。

**这一句是全篇的收尾，也是下一篇的起点。**

| | |
|---|---|
| 依据 | `056`「漢之元年四月，諸侯罷戲下，各就國。項王出之國」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「罢戏下」是散伙，不是罢兵；这一句之后，天下已经分完了 |
