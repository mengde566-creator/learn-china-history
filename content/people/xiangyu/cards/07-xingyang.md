### 卡 1 · 结构 ★

**问：篇名是「亚父去」。他去了以后，这一篇还剩多少？**

答：**他只在开头两段，剩下的都在写他走了以后的战场。**

| 段 | 写什么 |
|---|---|
| `066` | 反间：太牢具、详惊愕、使者归报 |
| `067` | 范增大怒、请归、疽发背而死 |
| `068`–`069` | 荥阳城破：纪信烧死、周苛被烹 |
| `072` | 高俎与太公 |
| `073`–`074` | 广武：挑战、楼烦、伏弩 |
| `079` | 鸿沟：中分天下 |

篇名用的是一个人的去向，正文用的是他走以后发生的事。**这一篇的落点是鸿沟，不是疽。**

| | |
|---|---|
| 依据 | `067`「範增大怒……行未至彭城，疽發背而死」；`079`「項王乃與漢約，中分天下」 |
| 标记 | ◆ 出自原文 |
| 考点 | 篇名与结构错开：命名取开头，落点在结尾 |

### 卡 2 · 因果 ★

**问：汉那边做那一桌太牢，是为了什么？**

答：**为了三段话都落在同一个人身上。**

`066` 的次序是这样的：

| 步 | 原话 | 落在哪里 |
|---|---|---|
| 一 | 為太牢具，舉欲進之 | 席面端起来要送 |
| 二 | 詳驚愕曰：吾以為**亞父**使者，乃反項王使者 | 当着使者的面认错人 |
| 三 | 更持去，以惡食食項王使者 | 换粗食 |
| 四 | 使者歸報項王，項王乃疑**範增**與漢有私 | 疑到范增头上 |

**「亚父」这两个字，是做局的人说出来的。** 底本没有写这套计是谁吩咐的——只写了它怎么被做出来。

| | |
|---|---|
| 依据 | `066`「為太牢具，舉欲進之。見使者，詳驚愕曰：『吾以為亞父使者，乃反項王使者。』更持去，以惡食食項王使者。使者歸報項王，項王乃疑範增與漢有私」 |
| 标记 | ◆ 出自原文 |
| 考点 | 四个动作一个方向；「亚父」出现在认错人的那句话里 |

### 卡 3 · 陷阱题 ⚠️

**问：范增是被那条反间计赶走的吗？**

答：**这一段写了计，写了疑，写了他大怒请归；没有写这几件事之间的因果。**

底本给的次序只有这些：

```
066  項王乃疑範增與漢有私，稍奪之權
067  範增大怒，曰：「天下事大定矣，君王自為之。願賜骸骨歸卒伍。」
067  項王許之
067  行未至彭城，疽發背而死
```

| 问 | 这一段有没有写 |
|---|---|
| 计是谁吩咐的 | 没有写，只记「乃用陳平計閒項王」 |
| 他为什么大怒 | 只有「大怒」两个字 |
| 是不是因为被削权 | 没有一句这样说 |
| 疽和气有没有关系 | 没有一句这样说 |

**「稍奪之權」和「大怒」紧挨着，不等于底本说了因果。** 这一段只能答到这里：他请归，项王答应，他死在路上。

| | |
|---|---|
| 依据 | `066`「項王乃疑範增與漢有私，稍奪之權」；`067`「範增大怒，曰：『天下事大定矣，君王自為之。願賜骸骨歸卒伍。』項王許之。行未至彭城，疽發背而死」 |
| 标记 | — 史书未载 |
| 考点 | 记了「计」和「疑」，不等于记了「因」；两段之间没有因果句 |

### 卡 4 · 细节 ★

**问：「疽发背而死」这六个字，写了什么、没写什么？**

答：**写了三个东西：部位、发作、死。** 别的都没有。

| 写了 | 没写 |
|---|---|
| 疽（毒疮） | 什么时候起的 |
| 发背（在背上发作） | 有没有请医、吃什么药 |
| 而死 | 痛不痛、说了什么 |

他死在路上：前一句是「行未至彭城」。

**一个人的死，底本用了六个字。** 这一篇里他最后说的话在前面，不在这一句。

| | |
|---|---|
| 依据 | `067`「行未至彭城，疽發背而死」 |
| 标记 | ◆ 出自原文 |
| 考点 | 六个字的死讯；「行未至彭城」是死亡地点唯一的交代 |

---

### 卡 5 · 人物 ★

**问：纪信替汉王死，这一段写了几步？**

答：**四步：请求、夜出、喊话、被杀。**

| 步 | 原话 |
|---|---|
| 请求 | 事已急矣，請為王誑楚為王，王可以閒出 |
| 夜出 | 漢王夜出女子滎陽東門被甲二千人 |
| 喊话 | 城中食盡，漢王降 |
| 被杀 | 項王燒殺紀信 |

中间还夹着两件事：楚军「皆呼萬歲」，汉王从城西门带几十骑走了。

**东门出去的是女子和纪信，西门出去的是汉王。** 项王问「汉王安在」，答「汉王已出矣」——两句话之后，就是三个字的结果。

| | |
|---|---|
| 依据 | `068`「漢將紀信說漢王曰：『事已急矣，請為王誑楚為王，王可以閒出。』……項王見紀信，問：『漢王安在？』曰：『漢王已出矣。』項王燒殺紀信」 |
| 标记 | ◆ 出自原文 |
| 考点 | 请求的是他自己；「可以閒出」是他给汉王留的那条路 |

### 卡 6 · 对照

**问：纪信和周苛，一个替汉王死，一个被项王烹。两处的写法差在哪？**

答：**纪信那一段有布置，周苛那一段只有对话。**

| | 纪信 `068` | 周苛 `069` |
|---|---|---|
| 起因 | 他自己开口请求 | 城破被活捉 |
| 中间 | 黄屋车、左纛、城中食尽汉王降 | 项王劝降：上将军、三万户 |
| 回答 | 「漢王已出矣」 | 「若不趣降漢，漢今虜若」 |
| 结果 | 項王燒殺紀信 | 項王怒，烹周苛 |

**两个人都没有求。** 一个用假话把时间换出来，一个用骂把话说完。

| | |
|---|---|
| 依据 | `068`「紀信乘黃屋車，傅左纛，曰：『城中食盡，漢王降。』」；`069`「項王怒，烹周苛，井殺樅公」 |
| 标记 | ◆ 出自原文 |
| 考点 | 同一场围城里的两种死法；两段都只记话和结果 |

---

### 卡 7 · 细节 ★

**问：把太公放在高俎上，这一手换来了什么？**

答：**换来了汉王的一句话，和项伯的一段劝。**

| 谁 | 说了什么 |
|---|---|
| 项王 | 今不急下，吾烹太公 |
| 汉王 | 吾翁即若翁，必欲烹而翁，則幸分我一桮羹 |
| 项伯 | 天下事未可知……雖殺之無益，祇益禍耳 |
| 结果 | 項王從之 |

**太公在这一段里没有出声。** 底本只写「置太公其上」——有没有绑、有没有说话，一个字都没有。

| | |
|---|---|
| 依据 | `072`「為高俎，置太公其上，告漢王曰：『今不急下，吾烹太公』」；「項伯曰：『天下事未可知……』項王從之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 高俎是为了让人看见；太公本人一字未载 |

---

### 卡 8 · 主题

**问：这一篇里最重的是哪一句？**

答：**「天下事大定矣，君王自為之。」**

这句话不是骂，也不是求。它后面紧接的是「願賜骸骨歸卒伍」——把话说完，把身体要回去，然后就走。

底下是三个短句：

> 項王許之。行未至彭城，疽發背而死。

**从说话到死，底本用了不到三十个字。**

一个在项羽耳边说了很多年话的人，最后一次开口，说的是「君王自己去做吧」。

| | |
|---|---|
| 依据 | `067`「天下事大定矣，君王自為之。願賜骸骨歸卒伍。」「項王許之。行未至彭城，疽發背而死」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「最重」是读出来的判断；底本对这句话没有加任何评语 |

| 备注 | 这句话到底是什么口气，底本不写；写的人只把它原样放在那里 |
|---|---|

### 卡 9 · 对读 ★

**问：楼烦在 `073` 和 `074` 里各做了一件事。两件事之间多了什么？**

答：**多了一个「乃」。**

| 段 | 楼烦做了什么 |
|---|---|
| `073` | 楚挑戰三合，樓煩輒射殺之 |
| `074` | 項王瞋目叱之，樓煩目不敢視，手不敢發 |

`073` 的最后一句是「項王大怒，乃自被甲持戟挑戰」；`074` 的第一句就是楼烦要射他。

**前面三次，射的是挑战的壮士；第四次，站到对面的是项王本人。** 底本没有写楼烦心里怎么想，只写「目不敢视，手不敢发」，接着「遂走还入壁，不敢复出」。

| | |
|---|---|
| 依据 | `073`「楚挑戰三合，樓煩輒射殺之。項王大怒，乃自被甲持戟挑戰」；`074`「樓煩欲射之，項王瞋目叱之，樓煩目不敢視，手不敢發」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两段之间只隔一句；动作的结果写在他自己身上，不写心理 |
