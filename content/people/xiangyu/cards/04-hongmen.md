# 复习卡 · 故事 04 · 鸿门

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 04 · 鸿门（9 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：鸿门那一席，四个人的座次是怎么排的？**

答：**原文把四个朝向全写下来了。**

| 人 | 朝向 | 原文 |
|---|---|---|
| 项王、项伯 | 东向 | `040`「項王、項伯東嚮坐」 |
| 亚父（范增） | 南向 | `040`「亞父南嚮坐」 |
| 沛公 | 北向 | `041`「沛公北嚮坐」 |
| 张良 | 西向 | `041`「張良西嚮侍」 |

**东向是尊位，南向次之，北向又次，西向是陪侍。** 这一套高下之别是后人对礼制的训释；`040`、`041` 只记朝向，不解释。

座位摆在那里，比任何一句客气话都清楚：**这是主人与来客的席，不是平起平坐的席。**

| | |
|---|---|
| 依据 | `040`「項王、項伯東嚮坐。亞父南嚮坐」；`041`「沛公北嚮坐，張良西嚮侍」 |
| 标记 | ○ 训释 |
| 考点 | 朝向是原文；尊卑是后人的读法。别把「东向为尊」当成原文的话 |

---

### 卡 2 · 因果 ★

**问：项伯为什么连夜赶到沛公军中？**

答：**为了张良，不是为了沛公。**

`036` 两句连着：**「素善留侯張良」**——一向和张良交好；**「欲呼張良與俱去」**——想叫张良跟他一起走。他还说了一句「毋從俱死也」。

**他要带走的是朋友，不是敌人。** 至于他为什么肯为朋友冒这个险，底本不写。

| | |
|---|---|
| 依据 | `036`「素善留侯張良。張良是時從沛公，項伯乃夜馳之沛公軍，私見張良，具告以事，欲呼張良與俱去」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动机是「善张良」；「帮沛公」是后来的结果，不是他出发时的目的 |

---

### 卡 3 · 动机陷阱 ⚠️

**问：项羽为什么不杀沛公？**

答：**底本不解释。**

那一处的原文只有四个字：**「項王默然不應。」** 前面是范增三次举玦，后面是范增起身去安排项庄。**从举玦到舞剑到闯帐到遁席，项羽没有下过一道杀令。**

不要用这些话替他解释：

- 「他骄傲，不屑于杀」——底本没写。
- 「他不想背约」——底本没写。
- 「范增说他『为人不忍』」——**那是范增对项庄说的话**，是范增的判断，不是项羽的自述。

| | |
|---|---|
| 依据 | `041`「範增數目項王，舉所佩玉玦以示之者三，項王默然不應」；`042`–`048` 都没有项羽下令杀沛公的记载 |
| 标记 | — 史书未载 |
| 考点 | 这是全篇最大的空白；四种常见的解释都不是底本的话 |

---

### 卡 4 · 细节

**问：范增举玉玦三次，是什么意思？**

答：**原文只记动作，含义是后人的读法。**

`041`：「舉所佩玉玦以示之者三。」**三次，换来的是「默然不應」四个字。**

玦是环形而有缺口的玉；玦与「决」同音，举玦是催人下决断——**这一层是后人的训释，`041` 不写。** 项王看懂了没有，也只有一个「默然不應」。

| | |
|---|---|
| 依据 | `041`「範增數目項王，舉所佩玉玦以示之者三，項王默然不應」 |
| 标记 | ○ 训释 |
| 考点 | 动作是原文，谐音劝决是训释；「不應」不等于「没看懂」 |

---

### 卡 5 · 细节 ★

**问：樊哙闯进来之后，项羽做了什么？**

答：**六个动作，一路没有拔剑。**

| 步 | 原文 | 动作 |
|---|---|---|
| 1 | `043`「項王按劍而跽曰：『客何為者？』」 | 按着剑，跪直上身，先问来人是谁 |
| 2 | `043`「壯士，賜之卮酒」 | 赐一大杯酒 |
| 3 | `043`「賜之彘肩」 | 赐一条生猪腿 |
| 4 | `044`「壯士，能復飲乎？」 | 再问一句 |
| 5 | `045`「項王未有以應」 | 听他把话说完，没有话答 |
| 6 | `045`「曰：『坐。』」 | 只说一个字 |

**按剑是防备，赐酒赐肉是认这个「壮士」，最后那个「坐」字是全场最重的回应。**

| | |
|---|---|
| 依据 | `043`「項王按劍而跽曰：『客何為者？』」「壯士，賜之卮酒」「賜之彘肩」；`045`「項王未有以應，曰：『坐。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 六个动作全有原文；别把「按剑」写成害怕，也别把「坐」写成服气 |

---

### 卡 6 · 陷阱题 ⚠️

**问：沛公说「秋豪不敢有所近」，是真的吗？**

答：**两句话都在，底本没有裁定。**

| 谁 | 段 | 说了什么 |
|---|---|---|
| 曹无伤 | `034` | 「沛公欲王關中，使子嬰為相，珍寶盡有之」 |
| 沛公 | `038` | 「吾入關，秋豪不敢有所近，籍吏民，封府庫，而待將軍」 |

**一句是告密者的话，一句是当事人对项伯说的话。** 底本把两句都记下来，没有给第三方核实。**不能因为曹无伤是「告密者」就判他说假，也不能因为沛公说得恳切就判他说真。**

| | |
|---|---|
| 依据 | `034`「沛公欲王關中，使子嬰為相，珍寶盡有之」；`038`「吾入關，秋豪不敢有所近，籍吏民，封府庫」 |
| 标记 | — 史书未载 |
| 考点 | 两句都是话；底本不裁，读的人也不要裁 |

### 卡 7 · 主题

**问：这一篇结束在两件礼器上，各是什么下场？**

答：**一个收下，一个摔碎。**

| 礼器 | 段 | 处置 |
|---|---|---|
| 白璧一双（献项王） | `048` | 项王「受璧，置之坐上」——收下，放在席上 |
| 玉斗一双（献亚父） | `048` | 亚父「置之地，拔劍撞而破之」——放地上，拔剑击碎 |

**璧放在座席上，玉斗摔在地上。** 摔完，范增说：「唉！豎子不足與謀。奪項王天下者，必沛公也，吾屬今為之虜矣。」

项王没有接话。**这一篇开始于他的大怒，结束于他的沉默。**

| | |
|---|---|
| 依据 | `048`「項王則受璧，置之坐上。亞父受玉鬥，置之地，拔劍撞而破之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两种处置都是原文；「璧与玉斗象征什么」是后人的读法，别写死 |

---

### 卡 8 · 对读

**问：范增骂的「竖子」，指的是谁？**

答：**原文只写「豎子」两个字，没有点明。**

`048` 的原句是：「唉！豎子不足與謀。」**「竖子」是骂人的话，可以指项庄（没能得手），也可以指项羽（不肯下手）。** 后世多读作骂项羽——**那是一种读法，不是底本的指名。**

可以确定的是后半句：**「奪項王天下者，必沛公也。」** 这是范增自己的判断，底本没有把它当成结论。

| | |
|---|---|
| 依据 | `048`「唉！豎子不足與謀。奪項王天下者，必沛公也，吾屬今為之虜矣」 |
| 标记 | ○ 训释 |
| 考点 | 骂的对象没有写明；范增的话是范增的判断，不是底本的判词 |

### 卡 9 · 因果

**问：沛公为什么可以不辞而别？**

答：**因为樊哙给了他一句台阶，张良替他算了时间。**

| 步 | 段 | 原文 |
|---|---|---|
| 1 | `046` | 沛公：「今者出，未辭也，為之奈何？」 |
| 2 | `046` | 樊哙：「大行不顧細謹，大禮不辭小讓。如今人方為刀俎，我為魚肉，何辭為。」 |
| 3 | `047` | 沛公对张良：「從此道至吾軍，不過二十里耳。度我至軍中，公乃入。」 |

**「人方为刀俎，我为鱼肉」这一句，说在沛公已经出帐之后**，不是当着项羽说的。四十里是两座营的距离，二十里是他估计张良进去的时间。

| | |
|---|---|
| 依据 | `046`「大行不顧細謹，大禮不辭小讓。如今人方為刀俎，我為魚肉，何辭為」；`047`「項王軍在鴻門下，沛公軍在霸上，相去四十里」「從此道至吾軍，不過二十里耳。度我至軍中，公乃入」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这句话是说给自己人听的；两个距离数字各有各的用处 |
