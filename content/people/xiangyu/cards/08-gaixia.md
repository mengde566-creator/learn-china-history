### 卡 1 · 结构 ★

**问：这一篇的七段，分成几块？**

答：**三块：汉那边凑兵、他被围、他自己动手。**

| 块 | 段 | 写什么 |
|---|---|---|
| 一 | `080`–`082` | 追不追、分地、各路会垓下 |
| 二 | `083` | 兵少食尽、四面楚歌、帐中那首诗 |
| 三 | `084`–`086` | 八百骑、一百余骑、二十八骑、三胜 |

第一块的落点是「詣項王」——各路兵马到垓下，是去见他的。第三块的落点是「如大王言」。

**这一篇不收在死，收在一句回答上。**

| | |
|---|---|
| 依据 | `082`「隨劉賈、彭越皆會垓下，詣項王」；`086`「騎皆伏曰：『如大王言』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三块的落点各不相同；最后一块落在回答上，不落在结局上 |

---

### 卡 2 · 因果 ★

**问：鸿沟的约刚订，汉那边为什么回头追？**

答：**因为两个人说了三句话，而汉王听了。**

`080` 的次序：

| 谁 | 说了什么 |
|---|---|
| 张良、陈平 | 漢有天下太半，而諸侯皆附之 |
| 同上 | 楚兵罷食盡，此天亡楚之時也 |
| 同上 | 今釋弗擊，此所謂『養虎自遺患』也 |
| 汉王 | 聽之 |

**「天亡楚」是他们说的，不是叙述者的判词。** 底本只记汉王听了，不写他听了之后怎么想。

| | |
|---|---|
| 依据 | `080`「張良、陳平說曰：『漢有天下太半，而諸侯皆附之。楚兵罷食盡，此天亡楚之時也，不如因其機而遂取之。』」；「今釋弗擊，此所謂『養虎自遺患』也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「天亡楚」出自谋臣之口；「聽之」是这一段给的唯一反应 |

### 卡 3 · 陷阱题 ⚠️

**问：虞姬后来怎样了？**

答：**这一段没有写。**

`083` 给她的字只有两处：

| 处 | 原话 |
|---|---|
| 出场 | 有美人名虞，常幸從 |
| 动作 | 歌數闋，美人和之 |

再往后，这一段就到「項王泣數行下，左右皆泣，莫能仰視」收住了。**她没有第三处。**

后来戏曲里那个自刎的场面，是后世的演法，**不是这七段文字里的东西**。这一段也没有写她说了什么、去了哪里。

| | |
|---|---|
| 依据 | `083`「有美人名虞，常幸從」；`083`「歌數闋，美人和之」；`083`「項王泣數行下，左右皆泣，莫能仰視」 |
| 标记 | — 史书未载 |
| 考点 | 这一段没有写，不等于没有发生；戏里的自刎不属于这一段 |

### 卡 4 · 陷阱题 ⚠️

**问：「此天之亡我，非战之罪也」——这是史书的结论吗？**

答：**不是。这是他对骑兵说的一句话。**

`085` 的引子写得很清楚：

```
項王謂其騎曰：「吾起兵至今八歲矣……
然今卒困於此，此天之亡我，非戰之罪也。」
```

**话头是「谓其骑曰」——听话的人是骑兵，说话的人是他。**

这一篇七段全是叙事，没有一句作者的评语；**「太史公曰」在最后一篇的末尾**。所以本篇能答的只有：这句话是他的，不是司马迁替他下的。

| | |
|---|---|
| 依据 | `085`「謂其騎曰：『吾起兵至今八歲矣，身七十餘戰……然今卒困於此，此天之亡我，非戰之罪也』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 说话的人在原文里写着；本篇没有作者评语 |

| 备注 | 他自己把这句话说了两遍：一遍陈述，一遍在说三胜的时候作理由（`085`「令諸君知天亡我，非戰之罪也」）。**两遍都是他的嘴** |
|---|---|

### 卡 5 · 细节 ★

**问：这一篇里有三个数目，一个比一个小。它们在哪一段？**

答：**都在 `084` 一段里。**

| 数 | 原话 | 什么时候 |
|---|---|---|
| 八百余 | 麾下壯士騎從者八百餘人 | 溃围南出时 |
| 一百余 | 騎能屬者百餘人耳 | 渡淮之后 |
| 二十八 | 至東城，乃有二十八騎 | 到东城时 |

中间隔着两件事：平明汉军才发觉、阴陵那个田父指了错路。

**三个数目往下减，减到二十八，后面还有一次。** `086` 再数，数的是「亡其兩騎耳」——最后剩二十六骑。

| | |
|---|---|
| 依据 | `084`「麾下壯士騎從者八百餘人」；`084`「騎能屬者百餘人耳」；`084`「至東城，乃有二十八騎」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三个数目同在一段；二十八之后还有一次，`086`「亡其兩騎耳」 |

### 卡 6 · 人物 ★

**问：四面楚歌，唱歌的是谁？他怕的又是什么？**

答：**唱歌的是汉军营里的人；他怕的是「楚人之多」。**

`083` 一句两句：

| 原话 | 说明 |
|---|---|
| 夜聞**漢軍**四面皆楚歌 | 声音从汉军那边来 |
| 漢皆已得楚乎？是何**楚人之多**也 | 他问的是楚人为什么这样多 |

**他问的不是「兵少」，是「楚人」。** 兵少、食尽写在这句前面，是叙述者的交代；惊问的是他。

唱的是什么词、什么调，这一段不载。

| | |
|---|---|
| 依据 | `083`「夜聞漢軍四面皆楚歌，項王乃大驚曰：『漢皆已得楚乎？是何楚人之多也！』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「汉军」与「楚歌」并在一句里；他问的对象是楚人 |

---

### 卡 7 · 细节 ★

**问：这一篇最后一句是什么？为什么收在这里？**

答：**「如大王言。」**

`086` 的最后三句：

```
乃謂其騎曰：「何如？」
騎皆伏曰：「如大王言。」
```

在这之前，他做了三件事：大呼驰下斩一将、瞪眼叱退赤泉侯、再驰斩一都尉。**数目减到二十八之后，他还在证明自己没有败。**

**全篇收在一句回答上，不收在死上。** 死不在这一篇里。

| | |
|---|---|
| 依据 | `086`「乃謂其騎曰：『何如？』騎皆伏曰：『如大王言』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 最后一问一答是原文的收尾；死写在下一篇 |

### 卡 8 · 主题

**问：他说「必三胜之」，三胜都记到了吗？**

答：**两胜记到了，第三样没有单独记。**

| 他说要做的 | 原文有没有单独记 |
|---|---|
| 為諸君潰圍 | 有：直夜潰圍南出 |
| 斬將 | 有：遂斬漢一將；復斬漢一都尉 |
| 刈旗 | **没有单独记到** |

`085` 他说的是「為諸君潰圍，斬將，刈旗」；`086` 记下来的是斩将、斩都尉、聚骑、亡两骑。

**一个人给自己定的三件事，底本记了两件半。** 这半件不是他失败，是这一段没有写。

| | |
|---|---|
| 依据 | `085`「為諸君潰圍，斬將，刈旗」；`086`「遂斬漢一將」「復斬漢一都尉，殺數十百人」 |
| 标记 | ◆ 出自原文 |
| 考点 | 他说的话与记下来的事，可以逐项对；缺的那一项属未载 |

### 卡 9 · 对读 ★

**问：`083` 和 `085` 里，他各说了一句「天」。这两句有什么不同？**

答：**一句是问，一句是断。**

| 段 | 原话 | 是对谁说的 |
|---|---|---|
| `083` | 漢皆已得楚乎？是何楚人之多也 | 惊问，在帐中 |
| `085` | 此天之亡我，非戰之罪也 | 对骑兵，说给自己人听 |

前一句还在问「是不是」，后一句已经不问了，直接给出结论。中间隔着八百骑、一百余骑、二十八骑，和一个指错路的田父。

**同一篇里，从「是不是」走到「就是」，用了两段路。**

| | |
|---|---|
| 依据 | `083`「漢皆已得楚乎？是何楚人之多也」；`085`「此天之亡我，非戰之罪也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两句话的对象不同；从疑问到断言，底本不加解释 |
