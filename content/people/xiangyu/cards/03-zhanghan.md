# 复习卡 · 故事 03 · 二十万人

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 03 · 二十万人（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：章邯为什么降？底本给了几个原因？**

答：**没有给一个总原因。它把三组事实并排放着。**

| 线 | 段 | 事实 |
|---|---|---|
| 朝中 | `027` | 长史欣到咸阳，留司马门三日，赵高不见；赵高又派人追他 |
| 书信 | `028`–`029` | 陈馀写信：白起、蒙恬功高而死；「有功亦誅，無功亦誅」 |
| 战场 | `030` | 蒲将军再破秦军；项羽在汙水上大破秦军 |

三条线在 `030` 合上——**「章邯狐疑，陰使候始成使項羽，欲約。」** 狐疑什么，底本不写。

| | |
|---|---|
| 依据 | `027`「留司馬門三日，趙高不見，有不信之心」；`029`「有功亦誅，無功亦誅」；`030`「章邯狐疑，陰使候始成使項羽，欲約」 |
| 标记 | ○ 合理推演 |
| 考点 | 三条线是底本给的；「哪一条是主因」底本没有回答，不要替它排序 |

---

### 卡 2 · 因果 ★

**问：长史欣为什么跑回军中？**

答：**因为他见不到赵高，而赵高对他有「不信之心」。**

`027` 的动作次序是：留司马门三日 → 赵高不见 → 有不信之心 → 长史欣恐 → 还走其军 → 不敢出故道。

**「不敢出故道」这四个字最要紧**：来路不能走，说明他已经把自己当成被追的人。后面那个「果」字证实了他一路上的判断——**赵高果然派人追，没追上。**

| | |
|---|---|
| 依据 | `027`「至咸陽，留司馬門三日，趙高不見，有不信之心。長史欣恐，還走其軍，不敢出故道，趙高果使人追之，不及」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「恐」是原文的词；「有不信之心」的主语是赵高 |

---

### 卡 3 · 细节

**问：「粮少」是项羽接受投降的理由吗？**

答：**那是他对军吏说的理由。**

`031` 的原文是：

> 項羽召軍吏謀曰：「糧少，欲聽其約。」軍吏皆曰：「善。」

**这是一次军吏会议，一句理由，一句「善」。** 粮少是实情还是说辞，底本不裁；除了这一句，也没有给别的理由。

| | |
|---|---|
| 依据 | `031`「項羽召軍吏謀曰：『糧少，欲聽其約。』軍吏皆曰：『善。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 记住说话的人和场合：「粮少」是对军吏说的，不是底本的旁白 |

---

### 卡 4 · 陷阱题 ⚠️

**问：新安城南那二十多万人，是怎么死的？**

答：**原文只给两个词：「擊殺」和「阬」。**

`033` 的原文是：

> 於是楚軍夜擊阬秦卒二十餘萬人新安城南。

**动词是「夜擊」，结果是「阬」；方式、过程、那一夜有多长，一个字都不写。** 人数照原文写「二十餘萬人」，不另作推算。

| | |
|---|---|
| 依据 | `033`「於是楚軍夜擊阬秦卒二十餘萬人新安城南」 |
| 标记 | ○ 训释 |
| 考点 | 「阬」本义是坑陷；具体怎么做，各家讲法不一，`033` 不写——不要把某种讲法写成原文 |

---

### 卡 5 · 动机 ★

**问：项羽为什么决定杀降卒？**

答：**他给黥布、蒲将军的理由是「其心不服」。**

`033` 的原话：

> 秦吏卒尚眾，其心不服，至關中不聽，事必危，不如擊殺之。

三层意思：人还多、心不服、到了关中不听号令。**「至關中不聽」是将来可能发生的事**——底本不给别的依据，也不给会议的结果。

| | |
|---|---|
| 依据 | `033`「秦吏卒尚眾，其心不服，至關中不聽，事必危，不如擊殺之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这是项羽对部下的判断，不是底本认定的原因；「心不服」三个字不能当成结论 |

---

### 卡 6 · 因果 ★

**问：营中的秦卒为什么私下说话？**

答：**先有折辱，后有窃语——底本把次序写得很清楚。**

| 段 | 原文 | 内容 |
|---|---|---|
| `032` 前 | 諸侯吏卒異時故繇使屯戍過秦中，秦中吏卒遇之多無狀 | 旧怨：从前受过秦中吏卒的气 |
| `032` 中 | 及秦軍降諸侯，諸侯吏卒乘勝多奴虜使之，輕折辱秦吏卒 | 新账：如今被当奴仆使唤 |
| `032` 后 | 秦吏卒多竊言曰…… | 于是私下说 |

他们怕的不是打仗，是家里：**「秦必盡誅吾父母妻子。」** 诸侯军中有人听到这些话，报告了项羽——`032` 最后一句就是这一夜的引信。

| | |
|---|---|
| 依据 | `032`「秦中吏卒遇之多無狀」「乘勝多奴虜使之，輕折辱秦吏卒」「秦必盡誅吾父母妻子」「諸侯微聞其計，以告項羽」 |
| 标记 | ◆ 出自原文 |
| 考点 | 因果次序是原文排的；折辱与窃语之间没有别的记载 |

---

### 卡 7 · 陷阱题

**问：章邯「狐疑」，他犹豫的是什么？**

答：**底本只给「狐疑」两个字，没有写内容。**

`030` 的原句是「章邯狐疑，陰使候始成使項羽，欲約」——**一边犹豫，一边已经派人去谈。** 他犹豫的是降、是战、还是条件，底本一字不载。

| | |
|---|---|
| 依据 | `030`「章邯狐疑，陰使候始成使項羽，欲約」 |
| 标记 | — 史书未载 |
| 考点 | 「狐疑」是状态，不是内容；不要用 `027`–`029` 的三条线替他把犹豫填满 |

---

### 卡 8 · 主题

**问：这一篇里唯一一次有人哭，是谁？**

答：**章邯。**

`031` 记：「已盟，章邯見項羽而流涕，為言趙高。」**盟约之后，他见到项羽，流下眼泪，对项羽说起赵高。**

哭的人是带着二十多万人来降的那一个。**底本不写他为什么哭**——是委屈、是怕、是为那二十多万人，一个字都没有。这个空白一直留到 `033`。

| | |
|---|---|
| 依据 | `031`「已盟，章邯見項羽而流涕，為言趙高」 |
| 标记 | ◆ 出自原文 |
| 考点 | 哭与「为言赵高」是两件事；不要替他把哭解释成为部下 |
