# 复习卡 · 故事 01 · 万人敌

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 01 · 万人敌（9 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：从「学书不成」到「斩会稽守」，底本一共走了几步？**

答：**四步，一步一段，顺序就是底本的顺序。**

| 段 | 发生了什么 |
|---|---|
| `002` | 学书不成，学剑又不成，改学兵法，又不肯竟学 |
| `003` | 在吴中看秦始皇渡江，说「彼可取而代也」 |
| `004` | 会稽守要发兵，召项梁；项梁把项籍叫进屋 |
| `005` | 项梁使一个眼色，项籍拔剑斩守头 |

中间没有跳过的准备，也没有一场仗。**「年二十四」只出现在 `001`，此后十五年的事都不在本篇。**

| | |
|---|---|
| 依据 | `002`「學書不成，去學劍，又不成」；`003`「籍曰：『彼可取而代也』」；`004`「梁召籍入」；`005`「籍遂拔劍斬守頭」 |
| 标记 | ◆ 出自原文 |
| 考点 | 顺序即底本顺序；不要用后面的战功来回填这四步 |

---

### 卡 2 · 细节 ★

**问：「万人敌」三个字，说的是什么？**

答：**比的是抵得住多少人，不是一种兵器。**

`002` 里他把书和剑各判了一句：书「足以記名姓而已」，剑「一人敵，不足學」。尺子从头到尾是同一个——**抵得住几个人**。所以「万人敌」就是抵得住一万人，项梁接下来教他的也正是兵法。

| | |
|---|---|
| 依据 | `002`「劍一人敵，不足學，學萬人敵」；紧接「於是項梁乃教籍兵法」 |
| 标记 | ○ 训释 |
| 考点 | 「敌」是对抗、抵挡；把「万人敌」读成一种兵器，就读错了这个字 |

---

### 卡 3 · 因果 ★

**问：项梁为什么能把项籍带进会稽守的房间？**

答：**因为他先递了一个只有项籍能解的由头。**

| 步 | 原文 | 作用 |
|---|---|---|
| 1 | `004`「獨籍知之耳」 | 守要知道桓楚在哪，项梁说只有侄子知道 |
| 2 | `004`「梁乃出，誡籍持劍居外待」 | 他出去，叮嘱侄子持剑在外面等 |
| 3 | `004`「請召籍，使受命召桓楚」 | 他再进来，请守把项籍叫进来 |
| 4 | `005`「梁眴籍曰：『可行矣！』」 | 人进来了，一个眼色，三个字 |

**「獨籍知之耳」是否真是实情，`004` 不点破。** 但出、诫、入、召这个次序是原文给的：刀是他自己叫进屋的。

| | |
|---|---|
| 依据 | `004`「桓楚亡，人莫知其處，獨籍知之耳」「梁乃出，誡籍持劍居外待」「請召籍」；`005`「梁眴籍曰：『可行矣！』」 |
| 标记 | ○ 合理推演 |
| 考点 | 推的是「这句话把项籍送进屋」；不要推成「项梁早就计划杀守」——那一步底本没有 |

---

### 卡 4 · 陷阱题 ⚠️

**问：「学书不成，去学剑，又不成」——他是学不会，还是不肯学？**

答：**底本只写「不成」，不写原因。**

两个「不成」连着来，第三句才是项梁发怒。**是资质不够、是不肯用心、还是别的原因，`002` 一个字都没有。** 后面教兵法那一次，底本写的是「又不肯竟學」——那一次用了「不肯」，前两次没有。

| | |
|---|---|
| 依据 | `002`「學書不成，去學劍，又不成」；「略知其意，又不肯竟學」 |
| 标记 | — 史书未载 |
| 考点 | 两个「不成」和「不肯竟学」不是同一种写法，不能互相解释 |

---

### 卡 5 · 动机

**问：项梁为什么对侄子发怒？**

答：**底本只写「怒之」，理由是空白。**

`002` 的次序是：学书不成 → 去学剑 → 又不成 → 项梁怒之。**怒是记下来的，怒的理由不是。** 可以注意的是他怒在「又不成」之后，而不是第一件不成之后；但这也只是次序，不是理由。

| | |
|---|---|
| 依据 | `002`「項籍少時，學書不成，去學劍，又不成。項梁怒之」 |
| 标记 | — 史书未载 |
| 考点 | 不要把「望子成龙」这类常情写成底本的话 |

---

### 卡 6 · 细节

**问：「籍所击杀数十百人」，到底是多少人？**

答：**原文是「數十百人」，一个约数。**

「数十百」可以读成几十人，也可以读成上百人。**底本没有折算确数，也没有说这些人是谁。** 这是会稽守府里那一场，不是战场。

| | |
|---|---|
| 依据 | `005`「籍所擊殺數十百人。一府中皆慴伏，莫敢起」 |
| 标记 | ○ 训释 |
| 考点 | 「数十百」是约数；把它读成确数，是替原文补了一道算术 |

---

### 卡 7 · 对照 ★

**问：襄城的「皆阬之」，和后来新安城南的那二十多万，是一回事吗？**

答：**不是同一段，也不能互相补。**

`011` 记襄城只有六个字：「已拔，皆阬之。」**人数、方式、理由，一样都没有。** 后来新安城南那一夜是另一篇的事；**把它那一段的数目搬回襄城，就是拿后文补前文。**

| | |
|---|---|
| 依据 | `011`「襄城堅守不下。已拔，皆阬之」 |
| 标记 | — 史书未载 |
| 考点 | 两处「阬」字相同，记载的详略不同；本篇只到「皆阬之」为止 |

---

### 卡 8 · 主题

**问：这一篇里最重的是哪一句？**

答：**「彼可取而代也。」**

六个字：**没有主语，没有条件，没有计划。**「彼」指江上那个人，「取而代之」是把那个位子拿过来。说这话的人还没有起兵，叔父的第一反应是捂住他的嘴，第二反应是「族矣」。

`003` 把两边的反应都写下来了：一个看见位子，一个看见后果。**然后是一句「梁以此奇籍」——他记住了这件事。**

| | |
|---|---|
| 依据 | `003`「籍曰：『彼可取而代也。』梁掩其口，曰：『毋妄言，族矣！』梁以此奇籍」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「最重」是读出来的判断，不是底本的判断；底本只是把它记在 `003`，没有加评语 |

---

### 卡 9 · 对读 ★

**问：会稽守和项梁，谁先动手？**

答：**守先说「先即制人」，项梁先做了。**

`004` 里守把话讲得很明白：「先即制人，後則為人所制。」他要项梁替他带兵。**结果先被制住的是他自己**——`005` 项梁一个眼色，项籍拔剑。

两个人的差别不在话上，在动作上：**守说完就坐着等；项梁说完就出去叮嘱侄子持剑。**

| | |
|---|---|
| 依据 | `004`「吾聞先即制人，後則為人所制」；`005`「須臾，梁眴籍曰：『可行矣！』於是籍遂拔劍斬守頭」 |
| 标记 | ○ 合理推演 |
| 考点 | 「谁先动手」是照着两段的动作次序读出来的；底本没有评论守的判断 |
