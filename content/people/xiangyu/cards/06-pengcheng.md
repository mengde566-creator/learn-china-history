### 卡 1 · 结构 ★

**问：这一篇的篇名是两个数字。这两个数字在底本里隔着多远？**

答：**隔着同一段里的一句话。**

`061` 把两件事写在一起：

| 顺序 | 原话 | 数字 |
|---|---|---|
| 先 | 春，**漢王部五諸侯兵**，凡五十六萬人，東伐楚 | 五十六万 |
| 后 | 項王聞之……**自以精兵三萬人**南從魯出胡陵 | 三万 |

中间只隔一句「項王聞之，即令諸將擊齊」。**先写对面来了多少，再写他带多少回去**——这个顺序是底本给的，篇名就取在这个地方。

| | |
|---|---|
| 依据 | `061`「春，漢王部五諸侯兵，凡五十六萬人，東伐楚。項王聞之，即令諸將擊齊，而自以精兵三萬人南從魯出胡陵」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两个数字同出一段，中间只隔一句；顺序本身是这一段的结构 |

### 卡 2 · 因果 ★

**问：项羽为什么掉头往北打齐，不往西去挡汉？**

答：**因为汉那边送来了两封信，而底本只记他「無西意」。**

`059` 的两封书，一封讲汉，一封讲齐赵：

| 信 | 内容 |
|---|---|
| 汉王的书 | 漢王失職，欲得關中，如約即止，不敢東 |
| 齐、梁反书 | 齊欲與趙並滅楚 |

紧接着的一句是「楚以此故無西意，而北擊齊」。

**写信的是张良，收信的是项王。** 底本只记他因此没有向西的意思——**他当时怎么判断这两封信，这一段没有写**。

| | |
|---|---|
| 依据 | `059`「乃遺項王書曰：『漢王失職，欲得關中，如約即止，不敢東。』又以齊、梁反書遺項王曰：『齊欲與趙並滅楚。』楚以此故無西意，而北擊齊」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「以此故」三个字是底本给的因果；他心里的判断没有记 |

### 卡 3 · 陷阱题 ⚠️

**问：睢水里到底死了多少人？**

答：**这一段没有记总数。**

`061` 记的是穀水、泗水那边「殺漢卒十餘萬人」，`062` 记的是「漢卒十餘萬人皆入睢水」。两处都是十几万，都是约数。

`062` 写到最后，只有五个字的结果：「睢水為之不流。」

**水不流是一个可以看见的结果，不是一个人数。** 底本没有再给一个合计数，也没有写水里捞出多少。**这一段没有记，不等于没有发生**——只是这几段文字里没有那个数。

| | |
|---|---|
| 依据 | `061`「相隨入穀、泗水，殺漢卒十餘萬人」；`062`「漢卒十餘萬人皆入睢水，睢水為之不流」 |
| 标记 | — 史书未载 |
| 考点 | 两个「十餘萬」是两处记载，不是可以相加的两次统计 |

### 卡 4 · 细节 ★

**问：这一篇里有一阵风。它改变了什么？**

答：**它把一圈围住的人吹散了。**

`062` 的四个短句，一句一件事：

| 原话 | 发生了什么 |
|---|---|
| 圍漢王三? | 围了三重 |
| 於是大風從西北而起……逢迎楚軍 | 风正迎着楚军 |
| 楚軍大亂，壞散 | 楚军自己乱了 |
| 而漢王乃得與數十騎遁去 | 汉王带几十骑走了 |

**风不是从项羽那边吹来的，是迎着楚军吹的。** 底本写风，写结果，**不写风为什么在那时起来**。

| | |
|---|---|
| 依据 | `062`「圍漢王三?。於是大風從西北而起，折木發屋，揚沙石，窈冥晝晦，逢迎楚軍。楚軍大亂，壞散，而漢王乃得與數十騎遁去」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「逢迎楚軍」四个字决定了风帮的是谁 |

---

### 卡 5 · 人物 ★

**问：汉王把儿女推下车，底本解释了吗？**

答：**没有解释，只记了动作和另一个人的一句话。**

`063` 从头到尾是这样的：

```
楚騎追漢王
漢王急
推墮孝惠、魯元車下
滕公常下收載之
如是者三
```

**「汉王急」三个字是底本给的全部理由。** 接着开口的是滕公：「雖急不可以驅，奈何棄之？」

**推下去的是父亲，收上来的是别人。** 底本不写汉王当时想什么，也不写孩子说什么。

| | |
|---|---|
| 依据 | `063`「楚騎追漢王，漢王急，推墮孝惠、魯元車下，滕公常下收載之。如是者三。曰：『雖急不可以驅，奈何棄之？』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「如是者三」是原文给的次数；动机不在这一段文字里 |

### 卡 6 · 对照

**问：彭城在这一篇里易手几次？两次的记载一样长吗？**

答：**两次，长短差得很远。**

| 时间 | 谁在城里 | 底本写了什么 |
|---|---|---|
| 四月 | 汉军 | 收其貨寶美人，日置酒高會 |
| 同月 | 楚军打回来 | 晨擊漢軍而東，至彭城，日中，大破漢軍 |

汉军进城那一段只有两句：收货宝美人，天天摆酒。项羽打回来那一段，把**时辰**写足了：晨、日中。

**进了城的人在喝酒，打回来的人在掐时辰。**

| | |
|---|---|
| 依据 | `061`「四月，漢皆已入彭城，收其貨寶美人，日置酒高會。項王乃西從蕭，晨擊漢軍而東，至彭城，日中，大破漢軍」 |
| 标记 | ◆ 出自原文 |
| 考点 | 同一段里两边的写法不同：一边写做什么，一边写什么时候 |

### 卡 7 · 主题

**问：这一篇为什么不评价？**

答：**因为底本把两件分量不同的事写在同一篇里，都没有加评语。**

| 段 | 写的是什么 |
|---|---|
| `061`–`062` | 三万破五十六万，杀十余万，睢水不流 |
| `063` | 一个父亲把儿女推下车，推了三次 |
| `064`–`065` | 追到荥阳，被挡回来，收在请和 |

战果、家事、边界，三样东西在同一篇里。**司马迁一处评语也没有加。**

这一篇的落点是 `065` 的最后一句：「請和，割滎陽以西為漢。」——**三万破了五十六万之后，走到的是谈判桌**。

| | |
|---|---|
| 依据 | `061`「大破漢軍」；`063`「推墮孝惠、魯元車下」；`065`「請和，割滎陽以西為漢」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「不评价」是这一篇的读法，不是底本的判断——底本只是没有写 |

### 卡 8 · 对读 ★

**问：这一篇有两条线。它们在哪一段合上？**

答：**在 `061` 的「項王聞之」。**

| 线 | 段 | 内容 |
|---|---|---|
| 东边 | `057`–`060` | 田荣反、陈余借兵、城阳连战未能下 |
| 西边 | `061` | 五十六万人入彭城 |
| 合上 | `061` | 「項王聞之」——他从此丢下齐地，掉头南下 |

合上以后，东边的事并没有结束：`065` 说田横「亦得收齊」，立田广为齐王。**他往西追汉王，东边就松了手。**

| | |
|---|---|
| 依据 | `060`「項王因留，連戰未能下」；`061`「項王聞之，即令諸將擊齊，而自以精兵三萬人南從魯出胡陵」；`065`「田橫亦得收齊，立田榮子廣為齊王」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两条线在「聞之」两个字上合；合上之后东边仍在动 |
