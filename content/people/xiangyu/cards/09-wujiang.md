### 卡 1 · 结构 ★

**问：这一篇七段，哪几段是叙事，哪几段是评语？**

答：**前五段叙事，后两段是作者的话。**

| 段 | 是什么 | 写什么 |
|---|---|---|
| `087`–`088` | 叙事 | 亭长舣船、拒渡、赐马、短兵、自刎 |
| `089` | 叙事 | 五人分尸、五份封地 |
| `090`–`091` | 叙事 | 鲁最后降、以鲁公礼葬、诸项不诛 |
| `092` | **太史公曰** | 重瞳子、三年灭秦、政由羽出 |
| `093` | **太史公曰** | 背关怀楚、自矜功伐、岂不谬哉 |

**最后两段换了一个说话的人。** 前面是第三人称的叙事，`092` 开头四个字是「太史公曰」。

| | |
|---|---|
| 依据 | `089`「五人共會其體，皆是。故分其地為五」；`092`「太史公曰」；`093`「乃引『天亡我，非用兵之罪也』，豈不謬哉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 说话的人在第 5 段和第 6 段之间换了 |

### 卡 2 · 因果 ★

**问：他为什么不肯渡江？底本给了几句理由？**

答：**一段话，四层。**

`087` 的原话是这样的：

| 层 | 原话 |
|---|---|
| 一 | 天之亡我，我何渡為 |
| 二 | 籍與江東子弟八千人渡江而西，今無一人還 |
| 三 | 縱江東父兄憐而王我，我何面目見之 |
| 四 | 縱彼不言，籍獨不愧於心乎 |

前三层说的是「渡过去也没有用」和「没有脸见人」；最后一层把话收回到自己身上——**「籍独不愧于心乎」**。

| | |
|---|---|
| 依据 | `087`「天之亡我，我何渡為！且籍與江東子弟八千人渡江而西，今無一人還，縱江東父兄憐而王我，我何面目見之？縱彼不言，籍獨不愧於心乎？」 |
| 标记 | ◆ 出自原文 |
| 考点 | 四层是从原文的分句读出来的；最后一层的主语是他自己 |

### 卡 3 · 陷阱题 ⚠️

**问：「天亡我」这三个字，在这一篇里出现了两次。两次是同一个人说的吗？**

答：**不是。**

| 段 | 谁在说 | 原话 |
|---|---|---|
| `087` | **项羽**对乌江亭长 | 天之亡我，我何渡為 |
| `093` | **司马迁**在评 | 乃引「天亡我，非用兵之罪也」，豈不謬哉 |

前一处是他的话，后一处是作者把这句话引回来加了一句判词。

**「岂不谬哉」四个字是司马迁的，不是项羽的。** 这句话要跟上面那一句分开读：一句是自己说的，一句是别人评的。

| | |
|---|---|
| 依据 | `087`「天之亡我，我何渡為」；`093`「乃引『天亡我，非用兵之罪也』，豈不謬哉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 同一层意思，两个说话人；判词在 093，不在 087 |

### 卡 4 · 人物 ★

**问：分尸的五个人，各叫什么、各封了什么？**

答：**五个名字，五个封号，都在 `089`。**

| 名字 | 身份 | 封号 |
|---|---|---|
| 吕马童 | 骑司马 | 中水侯 |
| 王翳 | （先取其头者） | 杜衍侯 |
| 杨喜 | 郎中骑 | 赤泉侯 |
| 杨武 | 郎中 | 吴防侯 |
| 吕胜 | 郎中 | 涅阳侯 |

**这五个人在整篇里只在这里有名字有封号。** 前面 `088` 出现的是吕马童和王翳，杨喜、杨武、吕胜三个名字，是到 `089` 才出来的。

哪一个人得了身体的哪一部分，这一段没有写。

| | |
|---|---|
| 依据 | `089`「郎中騎楊喜，騎司馬呂馬童，郎中呂勝、楊武各得其一體。五人共會其體，皆是。故分其地為五：封呂馬童為中水侯，封王翳為杜衍侯，封楊喜為赤泉侯，封楊武為吳防侯，封呂勝為涅陽侯」 |
| 标记 | ◆ 出自原文 |
| 考点 | 五个人名与五个封号的对应；「各得其一體」之外不再细分 |

### 卡 5 · 细节 ★

**问：鲁为什么最后才降？降了以后，葬他用了什么礼？**

答：**鲁守礼义；葬他用的是鲁公的礼。**

`090` 的三层：

| 层 | 原话 |
|---|---|
| 不降 | 楚地皆降漢，獨魯不下 |
| 原因 | 為其守禮義，為主死節 |
| 怎么降的 | 乃持項王頭視魯，魯父兄乃降 |

汉本来「引天下兵欲屠之」——看见那颗头，鲁的父兄才降。

**「鲁公」是他最早的封号。** 到他死，鲁最后降，所以葬他用鲁公的礼，葬在穀城。

| | |
|---|---|
| 依据 | `090`「項王已死，楚地皆降漢，獨魯不下。漢乃引天下兵欲屠之，為其守禮義，為主死節，乃持項王頭視魯，魯父兄乃降」；「故以魯公禮葬項王穀城」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一个封号绕回原点：封号是鲁公，最后降的是鲁 |

### 卡 6 · 主题

**问：司马迁对项羽的总评，两句原文分别是什么？**

答：**`092` 一句「近古以來未嘗有也」，`093` 一句「豈不謬哉」。**

| 段 | 原话 |
|---|---|
| `092` | 然羽非有尺寸乘埶，起隴畝之中，三年，遂將五諸侯滅秦，分裂天下，而封王侯，政由羽出，號為「霸王」，位雖不終，**近古以來未嘗有也** |
| `093` | 自矜功伐，奮其私智而不師古，謂霸王之業，欲以力徵經營天下，五年卒亡其國，身死東城，尚不覺寤而不自責，**過矣**。乃引「天亡我，非用兵之罪也」，**豈不謬哉** |

**两句各在一段，中间没有转折词。** 前一段写他三年灭秦、政由羽出；后一段写他五年亡国、不自责。

**引这两句，比说「司马迁褒贬皆有」准确。** 底本里没有「褒贬」这两个字。

| | |
|---|---|
| 依据 | `092`「三年，遂將五諸侯滅秦，分裂天下，而封王侯，政由羽出，號為『霸王』，位雖不終，近古以來未嘗有也」；`093`「身死東城，尚不覺寤而不自責，過矣。乃引『天亡我，非用兵之罪也』，豈不謬哉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两句原文分在两段；「褒贬」是后人的归纳，不是底本的说法 |

### 卡 7 · 陷阱题 ⚠️

**问：项羽死的时候多大？**

答：**这一段没有写。**

`087`–`093` 七段里，没有一处记他的年岁：

| 问 | 这一段有没有 |
|---|---|
| 享年多少 | 没有写 |
| 生于哪一年 | 没有写 |
| 起兵时多大 | 没有写（那在别的篇里） |

**能数的只有一件事：上一篇（东城那一段）里他自己报过「起兵至今八岁矣」。** 本篇七段里连这个都没有。

所以这一问在本篇范围内只能回答：这一段没有写。

| | |
|---|---|
| 依据 | `087`–`093` 七段没有一处记年岁；`092` 只有「三年」「五年」两个用来说事的数目 |
| 标记 | — 史书未载 |
| 考点 | 没有写不等于没有这回事；这一段不提供年岁 |

### 卡 8 · 对照

**问：这一篇里，他笑过一次，别人哭过一次。各在哪里？**

答：**一个「笑」，一个「泣之而去」。**

| 谁 | 动作 | 段 |
|---|---|---|
| 项王 | 項王**笑**曰：天之亡我，我何渡為 | `087` |
| 汉王 | 漢王為發哀，**泣**之而去 | `090` |
| （鲁人） | 無記 | — |

**笑是对着亭长说的那句「天要亡我」；泣是对着已经死了的那个人。**

底本没有写这一笑是什么意思，也没有写这一泣是什么意思。

| | |
|---|---|
| 依据 | `087`「項王笑曰：『天之亡我，我何渡為』」；`090`「漢王為發哀，泣之而去」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两处都只有动作，没有解释 |

### 卡 9 · 对读 ★

**问：`092` 与 `093` 的落点各是什么？**

答：**`092` 落在「未嘗有也」，`093` 落在「豈不謬哉」。**

| 段 | 写的方向 | 最后一句 |
|---|---|---|
| `092` | 从重瞳子写到三年灭秦、政由羽出 | 近古以來未嘗有也 |
| `093` | 从背关怀楚写到五年亡国、不自责 | 豈不謬哉 |

前一段的末句是肯定，后一段的末句是反问。**中间隔了一个「及」字**——「及羽背关怀楚」，从这一句起换了方向。

**全篇最后一击不是骂，是引用：** 司马迁把「天亡我，非用兵之罪也」这句话引回来，加四个字。

| | |
|---|---|
| 依据 | `092`「近古以來未嘗有也」；`093`「及羽背關懷楚，放逐義帝而自立，怨王侯叛己，難矣……豈不謬哉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两段各有一个落点；「及」字是转弯的地方 |
