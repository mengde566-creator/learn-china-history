# 趙奢 · 直譯

> **這一份和故事裡的白話不是一回事。**
>
> 故事裡的白話是給人讀的，可以順語序、補主語；這一份跟著原文的字序和句法走，不替它順句子。
>
> **四條寫法**：
>
> 1. 不補主語；原文承前省略，直譯也省略。
> 2. 官名、禮制、地名第一次出現時，用（　）就地解釋。
> 3. 不合并、不拆分；原文一個句號，直譯一個句號。
> 4. 原文欄逐字照抄 `source.md`。

## 故事 01 · 田部吏

| 編號 | 原文 | 直譯 |
|---|---|---|
| 001 | 趙奢者，趙之田部吏也。 | 赵奢，是赵国的田部吏（收田租的属吏）。 |
| 002 | 收租稅而平原君家不肯出租，奢以法治之，殺平原君用事者九人。 | 收租税而平原君家不肯出租，赵奢以法治它，杀了平原君家管事的人九个。 |
| 003 | 平原君怒，將殺奢。 | 平原君发怒，将要杀赵奢。 |
| 004 | 奢因說曰：「君於趙為貴公子，今縱君家而不奉公則法削，法削則國弱，國弱則諸侯加兵，諸侯加兵是無趙也，君安得有此富乎？以君之貴，奉公如法則上下平，上下平則國強，國強則趙固，而君為貴戚，豈輕於天下邪？」 | 赵奢于是劝说道：「您在赵国是贵公子，如今放纵您家而不奉公，法就削弱；法削弱，国就弱；国弱，诸侯就加兵；诸侯加兵，这就是没有赵国了，您哪里还能有这些财富呢？以您的尊贵，奉公守法，就上下公平；上下公平，国就强；国强，赵就稳固，而您是贵戚，难道比天下轻吗？」 |
| 005 | 平原君以為賢，言之於王。 | 平原君认为他贤能，向赵王说了他。 |
| 006 | 王用之治國賦，國賦大平，民富而府庫實。 | 王用他治理国家赋税，国家赋税非常公平，百姓富足而府库充实。 |

## 故事 02 · 閼與（上）

| 編號 | 原文 | 直譯 |
|---|---|---|
| 007 | 秦伐韓，軍於閼與。 | 秦攻伐韩国，驻军在阏与。 |
| 008 | 王召廉頗而問曰：「可救不？」對曰：「道遠險狹，難救。」 | 王召廉颇问说：「可以救吗？」回答说：「道路远而险狭，难救。」 |
| 009 | 又召樂乘而問焉，樂乘對如廉頗言。 | 又召乐乘问他，乐乘回答像廉颇的话一样。 |
| 010 | 又召問趙奢，奢對曰：「其道遠險狹，譬之猶兩鼠鬥於穴中，將勇者勝。」 | 又召问赵奢，赵奢回答说：「那道路远而险狭，比方它就像两只老鼠在洞穴中相斗，将是勇的一方胜。」 |
| 011 | 王乃令趙奢將，救之。 | 王于是命令赵奢为将，去救它。 |
| 012 | 兵去邯鄲三十里，而令軍中曰：「有以軍事諫者死。」 | 军队离开邯郸三十里，就向军中下令说：「有拿军事来谏的处死。」 |
| 013 | 秦軍軍武安西，秦軍鼓譟勒兵，武安屋瓦盡振。 | 秦军驻军在武安西边，秦军鼓噪勒兵，武安的屋瓦都震动。 |
| 014 | 軍中候有一人言急救武安，趙奢立斬之。 | 军中的候（侦察人员）有一人说赶紧救武安，赵奢立刻斩了他。 |
| 015 | 堅壁，留二十八日不行，復益增壘。 | 坚壁，停留二十八天不前进，又更加增筑营垒。 |
| 016 | 秦間來入，趙奢善食而遣之。 | 秦的间谍进来，赵奢好好供他吃食而打发他走。 |
| 017 | 間以報秦將，秦將大喜曰：「夫去國三十里而軍不行，乃增壘，閼與非趙地也。」 | 间谍把这报告秦将，秦将大喜说：「离开本国三十里军队就不前进，却增筑营垒，阏与不是赵国的土地了。」 |

## 故事 03 · 閼與（下）

| 編號 | 原文 | 直譯 |
|---|---|---|
| 018 | 趙奢既已遣秦間，卷甲而趨之，二日一夜至，令善射者去閼與五十里而軍。 | 赵奢既已打发走秦的间谍，卷起甲衣急趋，两天一夜赶到，命令善射的人离阏与五十里驻军。 |
| 019 | 軍壘成，秦人聞之，悉甲而至。 | 军营垒壁筑成，秦人听说，全甲而来。 |
| 020 | 軍士許歷請以軍事諫，趙奢曰：「內之。」 | 军士许历请求拿军事来谏，赵奢说：「让他进来。」 |
| 021 | 許歷曰：「秦人不意趙師至此，其來氣盛，將軍必厚集其陣以待之。不然，必敗。」 | 许历说：「秦人不料赵军到这里，他们来的气势盛，将军必须厚集阵势来等待他们。不然，必定失败。」 |
| 022 | 趙奢曰：「請受令。」 | 赵奢说：「请受教令。」 |
| 023 | 許歷曰：「請就鈇質之誅。」 | 许历说：「请就斧质之诛（受军法处死）。」 |
| 024 | 趙奢曰：「胥後令邯鄲。」 | 赵奢说：「等以后邯郸的命令。」 |
| 025 | 許歷復請諫，曰：「先據北山上者勝，後至者敗。」 | 许历又请求进谏，说：「先占据北山的胜，后到的败。」 |
| 026 | 趙奢許諾，即發萬人趨之。 | 赵奢应诺，立即发一万人急趋那里。 |
| 027 | 秦兵後至，爭山不得上，趙奢縱兵擊之，大破秦軍。 | 秦兵后到，争山不能上去，赵奢纵兵攻击他们，大破秦军。 |
| 028 | 秦軍解而走，遂解閼與之圍而歸。 | 秦军解围而逃走，于是解了阏与之围而回。 |
| 029 | 趙惠文王賜奢號為馬服君，以許歷為國尉。 | 赵惠文王赐赵奢名号为马服君，任许历为国尉。 |
| 030 | 趙奢於是與廉頗、藺相如同位。 | 赵奢于是与廉颇、蔺相如同位。 |

## 故事 04 · 知子

|---|---|---|
| 031 | 後四年，趙惠文王卒，子孝成王立。 | 后四年，赵惠文王去世，儿子孝成王立。 |
| 032 | 七年，秦與趙兵相距長平，時趙奢已死，而藺相如病篤，趙使廉頗將攻秦，秦數敗趙軍，趙軍固壁不戰。 | 七年，秦与赵的军队在长平相距，当时赵奢已死，而蔺相如病重，赵派廉颇为将攻秦，秦屡次打败赵军，赵军固守壁垒不战。 |
| 039 | 趙括自少時學兵法，言兵事，以天下莫能當。 | 赵括从少年时学兵法，谈兵事，认为天下没有能抵当他的人。 |
| 040 | 嘗與其父奢言兵事，奢不能難，然不謂善。 | 曾经与他父亲赵奢谈兵事，赵奢不能难住他，但不称他好。 |
| 041 | 括母問奢其故，奢曰：「兵，死地也，而括易言之。」 | 赵括的母亲问赵奢缘故，赵奢说：「兵，是死地，而赵括轻易地说它。」 |
| 042 | 使趙不將括即已，若必將之，破趙軍者必括也。」 | 假使赵不用赵括为将就算了，如果一定要用他为将，破赵军的一定是赵括。」 |

## 故事 05 · 長平

| 編號 | 原文 | 直譯 |
|---|---|---|
| 033 | 秦數挑戰，廉頗不肯。 | 秦屡次挑战，廉颇不肯。 |
| 034 | 趙王信秦之間。 | 赵王相信秦的反间。 |
| 035 | 秦之間言曰：「秦之所惡，獨畏馬服君趙奢之子趙括為將耳。」 | 秦的间谍说：「秦所憎恶的，只是怕马服君赵奢的儿子赵括为将罢了。」 |
| 036 | 趙王因以括為將，代廉頗。 | 赵王于是用赵括为将，代替廉颇。 |
| 037 | 藺相如曰：「王以名使括，若膠柱而鼓瑟耳。括徒能讀其父書傳，不知合變也。」 | 蔺相如说：「王因为名声用赵括，就像粘住柱而鼓瑟罢了。赵括只会读他父亲的书传，不知道合变。」 |
| 038 | 趙王不聽，遂將之。 | 赵王不听，终于用他为将。 |
| 043 | 及括將行，其母上書言於王曰：「括不可使將。」 | 等到赵括将要出发，他母亲上书对王说：「赵括不可让他为将。」 |
| 044 | 王曰：「何以？」對曰：「始妾事其父，時為將，身所奉飯飲而進食者以十數，所友者以百數，大王及宗室所賞賜者盡以予軍吏士大夫，受命之日，不問家事。 | 王说：「为什么？」回答说：「当初我事奉他父亲，他為将时，亲自捧着饭饮进献给人吃的以十计，所结交的以百计，大王和宗室所赏赐的尽都给了军吏士大夫，接受命令的那天，不问家事。 |
| 045 | 今括一旦為將，東向而朝，軍吏無敢仰視之者，王所賜金帛，歸藏於家，而日視便利田宅可買者買之。 | 如今赵括一旦为将，向东而坐受朝见，军吏没有敢仰视他的，王所赐的金帛，拿回家藏起来，而天天看便利的田宅可以买的就买它。 |
| 046 | 王以為何如其父？父子異心，願王勿遣。」 | 王认为他比他父亲怎么样？父子不同心，希望王不要派他。」 |
| 047 | 王曰：「母置之，吾已決矣。」 | 王说：「母亲放下这事，我已经决定了。」 |
| 048 | 括母因曰：「王終遣之，即有如不稱，妾得無隨坐乎？」王許諾。 | 赵括的母亲于是说：「王终究要派他，如果有什么不称职，我能够不受随坐吗？」王许诺。 |
| 049 | 趙括既代廉頗，悉更約束，易置軍吏。 | 赵括既已代替廉颇，全部更改约束，改换军吏。 |
| 050 | 秦將白起聞之，縱奇兵，詳敗走，而絕其糧道，分斷其軍為二，士卒離心。 | 秦将白起听说，纵奇兵，假装败走（详同佯），而断绝他的粮道，把他的军分断为二，士卒离心。 |
| 051 | 四十餘日，軍餓，趙括出銳卒自博戰，秦軍射殺趙括。 | 四十多天，军饿，赵括派出锐卒亲自搏战，秦军射杀赵括。 |
| 052 | 括軍敗，數十萬之眾遂降秦，秦悉阬之。 | 赵括军败，数十万之众于是降秦，秦全部坑杀他们。 |
| 053 | 趙前後所亡凡四十五萬。 | 赵前后所亡共四十五万。 |
| 054 | 明年，秦兵遂圍邯鄲，歲餘，幾不得脫。 | 第二年，秦兵于是围邯郸，一年多，几乎不能脱。 |
| 055 | 賴楚、魏諸侯來救，乃得解邯鄲之圍。 | 靠楚、魏诸侯来救，才得以解邯郸之围。 |
| 056 | 趙王亦以括母先言，竟不誅也。 | 赵王也因为赵括的母亲先说了，终究没有诛她。 |
