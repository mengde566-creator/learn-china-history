# 复习卡 · 故事 01 · 田部吏

> 原则：**问动机，不问年代。**

---

## 故事 01 · 田部吏（5 张）

---

### 卡 1 · 结构 ★

**問：這一篇從趙奢的身份寫到治國賦，走了幾步？**

答：**四步。**

| 步 | 发生了什么 |
|---|---|
| `001` | 赵奢是赵之田部吏 |
| `002` | 平原君家不肯出租，赵奢依法杀其用事者九人 |
| `003`–`004` | 平原君怒欲杀奢；赵奢以「法削国弱」游说 |
| `005`–`006` | 平原君以为贤，荐于王；王用他治国赋 |

| | |
|---|---|
| 依据 | `001`–`006` |
| 标记 | ◆ 出自原文 |
| 考点 | 没有战争；全是税法与人事 |

---

### 卡 2 · 因果 ★

**問：赵奢为什么要杀平原君家的九个用事者？**

答：**因为平原君家不肯出租，他依法办理。**

「收租税而平原君家不肯出租，奢以法治之，杀平原君用事者九人」。他杀的不是平原君，是管事的九个人；这是执法，不是私斗。

| | |
|---|---|
| 依据 | `002` |
| 标记 | ◆ 出自原文 |
| 考点 | 「用事者」是管事者，不是平原君本人 |

---

### 卡 3 · 论辩 ★

**問：赵奢怎样把「你家不交租」说成「赵国存亡」？**

答：**用一条五步递推链。**

纵容你家而不奉公 → 法削 → 国弱 → 诸侯加兵 → 无赵 → 君安得有此富。最后再反过来：奉公如法 → 上下平 → 国强 → 赵固 → 贵戚不被轻视。

| | |
|---|---|
| 依据 | `004` |
| 标记 | ◆ 出自原文 |
| 考点 | 不是求饶，是把平原君的私富绑在赵国存亡上 |

---

### 卡 4 · 结果

**問：平原君聽了之後做了什麼？**

答：**认为他贤，推荐给赵王；赵王用他治国赋。**

「平原君以为贤，言之于王。王用之治国赋，国赋大平，民富而府库实。」从「将杀奢」到「以为贤」，底本只用一句话。

| | |
|---|---|
| 依据 | `004`–`006` |
| 标记 | ◆ 出自原文 |
| 考点 | 没有写平原君想了多久，也没有写是否记恨 |

---

### 卡 5 · 判断

**問：这一篇为什么放在赵奢五篇的最前面？**

答：**先立住他的本职与执法，再写他后来的将略。**

赵奢的起点是收租的吏，不是将军。这一篇让人看见他面对贵公子时的根据：法。后面阏与之战的「勇」，在这里先以「法」的形式出现。

| | |
|---|---|
| 依据 | `001`–`006` |
| 标记 | ○ 合理推演 |
| 考点 | 不要把这一篇当成阏与之战的序曲；它独立成篇 |
