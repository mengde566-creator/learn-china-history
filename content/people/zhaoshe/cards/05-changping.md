# 复习卡 · 故事 05 · 长平

> 原则：**问动机，不问年代。**

---

## 故事 05 · 长平（6 张）

---

### 卡 1 · 反间 ★

**问：秦国的反间为什么只说「秦怕赵括」，不说赵括能打？**

答：**因为赵王想换掉固壁不战的廉颇，只需要一个理由。**

秦之间言：「秦之所恶，独畏马服君赵奢之子赵括为将耳。」赵王信间，以赵括代廉颇。反间没有证明赵括强，只给了赵王一个「用他可以退秦」的借口。

|---|---|
| 依据 | `032`–`036` |
| 标记 | ◆ 出自原文 |
| 考点 | 反间利用的是赵王想速战的心理 |

---

### 卡 2 · 谏

**问：蔺相如用「胶柱鼓瑟」比喻什么？**

答：**比喻赵括只会照书本，不能应变。**

「王以名使括，若胶柱而鼓瑟耳。括徒能读其父书传，不知合变也。」胶柱是把调弦的柱粘死，音不能变。蔺相如不是说他不读书，是说他不知变。

| | |
|---|---|
| 依据 | `037`–`038` |
| 标记 | ○ 训释 |
| 考点 | 赵王不听 |

---

### 卡 3 · 括母 ★

**问：括母凭什么判断赵括不如父亲？**

答：**凭两代人为将时的做派。**

赵奢为将，亲自捧饭进食者数十人、所友数百人，赏赐尽给军吏士大夫，受命之日不问家事。赵括一旦为将，东向而朝，军吏不敢仰视，王所赐金帛藏在家里，天天买田宅。她说「父子异心」。

| | |
|---|---|
| 依据 | `044`–`046` |
| 标记 | ◆ 出自原文 |
| 考点 | 她谈的是待人、理财，不是兵法 |

---

### 卡 4 · 王决

**问：赵王怎样回应括母的上书？**

答：**只说「母置之，吾已决矣」，没有反驳证据。**

括母退而求「不随坐」，赵王许诺。后来赵括败，赵王「以括母先言，竟不诛也」。她的上书没有救儿子，只救了自己。

| | |
|---|---|
| 依据 | `047`–`048`、`056` |
| 标记 | ◆ 出自原文 |
| 考点 | 决策之门在「已决」两个字上关上 |

---

### 卡 5 · 白起

**问：白起对付赵括用了哪三步？**

答：**纵奇兵、佯败走、绝粮道并分断赵军。**

「秦将白起闻之，纵奇兵，详败走，而绝其粮道，分断其军为二，士卒离心。」赵括悉更约束、易置军吏，正好进入白起的节奏。

| | |
|---|---|
| 依据 | `049`–`050` |
| 标记 | ◆ 出自原文 |
| 考点 | 先是佯败，再断粮，再分军 |

---

### 卡 6 · 数字

**问：长平之战的结果，底本给了哪些数字？**

答：**四十余日、数十万降卒、前后亡四十五万、邯郸岁余。**

「四十余日，军饿」「数十万之众遂降秦，秦悉坑之」「赵前后所亡凡四十五万」「明年，秦兵遂围邯郸，岁余」。这些都是《史记》的记数，不是现代统计。

| | |
|---|---|
| 依据 | `051`–`055` |
| 标记 | ◆ 出自原文 |
| 考点 | 不把记数改写成精确的现代数字 |
