# 复习卡 · 故事 06 · 长城

> 原则：**问它凭什么收他，不问谁害他。**

---

## 故事 06 · 长城（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里有两个「會」，分别管什么？**

答：**一个召他进来，一个把他收下。**

| 段 | 原文 | 管的是什么 |
|---|---|---|
| `067` | 上疾篤，會索虜為邊寇，召道濟入朝 | 皇帝病重，正好有边寇——召他进来 |
| `069` | 已下船矣，會上疾動，召入祖道，收付廷尉 | 皇帝病又动了——把他从送行的场合叫回来收掉 |

**同一个「會」字，两次都跟着皇帝的病走。** 他只是一直在路上：来、到、下船、被叫回。

| | |
|---|---|
| 依据 | `067`「十二年，上疾篤，會索虜為邊寇，召道濟入朝」；`069`「十三年春，將遣道濟還鎮，已下船矣，會上疾動，召入祖道，收付廷尉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「會」是恰逢；两次都写成巧合，而两次的结果完全相反 |

---

### 卡 2 · 细节 ★

**问：「已下船矣」四个字，重在哪里？**

答：**重在一个「已」字。**

朝廷已经决定放他还镇，他已经上了船、下了船，路已经走到这里。**再往前一步，他就不在建康了。**

就在这一刻，诏令改了。底本用「已下船矣」四个字，把差一点写成了一个动作。

| | |
|---|---|
| 依据 | `069`「十三年春，將遣道濟還鎮，已下船矣，會上疾動，召入祖道，收付廷尉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「已」是完成态：不是将要下船，是已经下过船；时间差只有一句话那么长 |

---

### 卡 3 · 边界 ★

**问：他一共被杀了多少人？**

答：**底本分别记三处，不作总数。**

| 处 | 原文 | 记的是什么 |
|---|---|---|
| `083` | 「等八人，並於廷尉伏誅」 | 廷尉一批，他的儿子植、粲、隰、承伯、遵都在这一批里 |
| `085` | 「收道濟子夷、邕、演及司空參軍高進之誅之」 | 寻阳一批，三子加高进之 |
| `088` | 「邕子孺乃被宥」 | 一个被宽宥的孩子 |

**三处各记各的，没有一处给合计。** 这个数不替底本算。

| | |
|---|---|
| 依据 | `083`「等八人，並於廷尉伏誅」；`085`「收道濟子夷、邕、演及司空參軍高進之誅之」；`088`「邕子孺乃被宥」 |
| 标记 | — |
| 考点 | 「等八人」是底本的写法和底本的数；八人之外还有没有别人，卷里也不写——所以这里不给总数 |

---

### 卡 4 · 因果

**问：朝廷为什么疑他、畏他？**

答：**底本列了三样，一样都不虚。**

| 项 | 原文 |
|---|---|
| 威名 | 立功前朝，威名甚重 |
| 腹心 | 左右腹心，並經百戰 |
| 诸子 | 諸子又有才氣 |

三样合起来，才是「朝廷疑畏之」。**单拿出一样，都不足以让一个朝廷动手。**

| | |
|---|---|
| 依据 | `065`「道濟立功前朝，威名甚重，左右腹心，並經百戰，諸子又有才氣，朝廷疑畏之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三样是并列的三个条件；`066` 的「不可復制」把这层疑畏说成了将来的一件事 |

---

### 卡 5 · 细节

**问：「事止元惡，餘無所問」，与后面的收捕名单对得上吗？**

答：**对不上，底本把两句挨着写。**

`082` 诏末说「事止元惡，餘無所問」，`083` 就收了他的儿子与僚属等八人，`084` 收薛彤，`085` 又派人到寻阳收三子与高进之。

**诏书的末句与诏书的执行，中间没有一句话过渡。**

| | |
|---|---|
| 依据 | `082`「事止元惡，餘無所問」；`083`「等八人，並於廷尉伏誅」；`085`「收道濟子夷、邕、演及司空參軍高進之誅之」 |
| 标记 | ○ |
| 考点 | 「餘無所問」是诏书的措辞，不是执行的范围；这一条读法靠三段相连，不靠一句解释 |

---

### 卡 6 · 叙述

**问：这一篇里，诏书占了多少？他自己的话有多少？**

答：**诏书十三段；他的话九个字。**

| 项 | 段 | 字数 |
|---|---|---|
| 诏书 | `070`–`082` | 十三段，自「詔曰」起，至 `082` 末引号收 |
| 他的话 | `087` | 九个字：乃復壞汝萬里之長城 |

**诏书占了大半，他自己只在最后说了一句。** 而且这一句是追叙——「初，道濟見收」，说的是下船那一刻。

| | |
|---|---|
| 依据 | `070`–`082` 为同一道诏书；`087`「初，道濟見收，脫幘投地曰：『乃復壞汝萬里之長城』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 底本把这句话放在所有人的死之后：读者读到它时，长城已经倒了 |

---

### 卡 7 · 结构

**问：八十八段的最后一句，落在谁身上？**

答：**落在一个没有死的人身上。**

`088`：「邕子孺乃被宥，世祖世，為奉朝請。」

**「乃」字是全卷最后一个转折**：前面的收捕一路到底，到这里忽然松了一下——一个孩子被宽宥，后来做了奉朝请。

| | |
|---|---|
| 依据 | `088`「邕子孺乃被宥，世祖世，為奉朝請」 |
| 标记 | ◆ 出自原文 |
| 考点 | 收尾不是平反，是宽宥一个人；这一卷没有给任何人留下辩白的机会 |

---

> **这一篇的读法：** 二十四段，五百余字，一道诏书，九个字。<br>
> 他做成的事不是保住自己，是**在一切都收走之后，还剩一个孩子活着**。
