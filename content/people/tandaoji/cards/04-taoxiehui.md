# 复习卡 · 故事 04 · 讨谢晦

> 原则：**问两夜之间的关系，不问废立的对错。**

---

## 故事 04 · 讨谢晦（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里有几个夜晚？**

答：**一个夜晚，前后两个反应。**

| 位置 | 段 | 谁睡不着 | 结果 |
|---|---|---|---|
| 废立前夜 | `044`–`045` | 谢晦「竦動不得眠」 | 他就寢便熟，谢晦「以此服之」 |
| 讨谢晦时 | `053` | 谢晦「人情兇懼」 | 遂不战自溃 |

**同一个人的两种反应，中间隔着一串官衔。** 那些段不是闲笔，那是两年。

| | |
|---|---|
| 依据 | `045`「晦其夕竦動不得眠，道濟就寢便熟，晦以此服之」；`053`「晦本謂道濟與羨之等同誅，忽聞來上，人情兇懼，遂不戰自潰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「服之」与「兇懼」都记在谢晦名下：一个对着他这个人，一个对着他还活着 |

---

### 卡 2 · 动机 ★

**问：他反对废庐陵王，为什么还是参与了？**

答：**这一篇不替他回答。**

`042` 记他「意不同，屢陳不可，不見納」——反对过，没被听进去。`043` 记他被「諷」入朝，到了才把谋划告诉他。

**反对之后怎么变成同谋，中间没有一段。**

| | |
|---|---|
| 依据 | `042`「道濟意不同，屢陳不可，不見納」；`043`「羨之等謀欲廢立，諷道濟入朝，既至，以謀告之」。转变的缘由，这一段不写 |
| 标记 | — 不回答 |
| 考点 | 「不見納」三个字把他说成了无效的反对者；为什么留下、为什么不再反对，底本不记 |

---

### 卡 3 · 细节 ★

**问：「諷道濟入朝」的「諷」，是什么意思？**

答：**暗示，绕个弯把人请来。**

不是明发诏书，也不是直说我们要废皇帝。先把他请进朝，人到了，再把事情告诉他——**这一步安排，说明对方知道他可能不同意。**

| | |
|---|---|
| 依据 | `043`「羨之等謀欲廢立，諷道濟入朝，既至，以謀告之」。「諷」为暗示，是后世训释 |
| 标记 | ○ 训释 |
| 考点 | 「諷」与「召」不同：一个是暗示，一个是命令；底本选了这个字，说明请他的人有顾虑 |

---

### 卡 4 · 因果 ★

**问：谢晦为什么不战自溃？**

答：**因为他以为檀道济已经死了。**

```
晦本謂道濟與羨之等同誅      ← 他听到的消息：这一批人都被杀了
忽聞來上                    ← 忽然听说他还活着，还带兵上来了
人情兇懼，遂不戰自潰        ← 人心恐惧，仗没打，兵散了
```

**这一句里没有一场仗。** 他到了的消息，比他的兵先到。

| | |
|---|---|
| 依据 | `053`「晦本謂道濟與羨之等同誅，忽聞來上，人情兇懼，遂不戰自潰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「本謂」是谢晦的判断，不是事实；他以为的与实际的差，就是这一仗的全部 |

---

### 卡 5 · 结构

**问：那一夜，他为什么睡在领军府？**

答：**因为废立要在宫里动手。**

领军掌宫城禁兵，领军府就是离宫门最近的衙署。一个掌禁军的（谢晦），一个带外兵的（檀道济），睡在同一个府里——**这一夜是这篇的枢纽，底本只用了十几个字。**

| | |
|---|---|
| 依据 | `044`「將廢之夜，道濟入領軍府就謝晦宿」。领军的职掌为后世训释 |
| 标记 | ◆ 出自原文 |
| 考点 | 底本只记「就謝晦宿」，不记两人说了什么；同宿这件事本身，就是那一夜的安排 |

---

### 卡 6 · 细节

**问：「固辭進封」，辞的是什么？**

答：**辞的是那个公。**

即位之后的封赏是一串：进号征北将军、加散骑常侍、给鼓吹一部、进封武陵郡公、增督五郡诸军事。**「固辭進封」四个字，辞的是武陵郡公。**

辞了几次、为什么辞，底本不记。

| | |
|---|---|
| 依据 | `049`「固辭進封」，前一段是 `048`「進封武陵郡公，食邑四千戶」 |
| 标记 | ○ |
| 考点 | 「固辭」是坚持推辞，不是客气一句；`050` 紧接着又加督五郡，封辞了，权没有辞 |

---

### 卡 7 · 叙述

**问：这一篇里，他为自己说过一句话吗？**

答：**没有。**

`042` 是「屢陳不可」——说了好几次，一个字也没留下来。`049` 是「固辭進封」——辞了，话也没有。全篇他说出口的话，一句都没有被记下。

**底本给他的，全是动作：入朝、就宿、就寢、入守、率军。** 唯一一句完整的话，是两年后别人转述他的死讯。

| | |
|---|---|
| 依据 | `042`「屢陳不可」、`049`「固辭進封」——都只记动作，不记言词 |
| 标记 | ◆ 出自原文 |
| 考点 | 不记言词是这一篇的写法：他在废立里的位置，靠动作与别人的反应写出来 |

---

> **这一篇的读法：** 十四段，二百四十字左右，两年。<br>
> 他做成的事不是打赢了谢晦，是**在同一个夜里睡得着，两年后让对手连仗都不敢打**。
