# 复习卡 · 故事 03 · 东阳

> 原则：**问粮，不问敌。**

---

## 故事 03 · 东阳（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇分几层？**

答：**三层：救、食、还。**

| 层 | 段 | 发生了什么 |
|---|---|---|
| 救 | `036`–`038` | 他出镇一方，朝廷加节，与王仲德救东阳 |
| 食 | `039`–`040` | 救兵未到，敌人烧营走了；他要追，城里没有吃的 |
| 还 | `041` | 还镇广陵 |

**全篇没有一次交战，没有一个敌人露面。** 真正的转折在中间那一层：救兵到了，先要解决的是自己吃什么。

| | |
|---|---|
| 依据 | `038`「加道濟使持節、監征討諸軍事，與王仲德救東陽」；`039`「未及至，虜燒營，焚攻具遁走」；`040`「將追之，城內無食」；`041`「還鎮廣陵」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三层不是按胜负分的，是按他手上有什么分的：一支兵、一城人的粮、一个镇所 |

---

### 卡 2 · 细节 ★

**问：「未及至」三个字，把什么抽掉了？**

答：**把这一趟差事的前提抽掉了。**

朝廷给他加使持节、监征讨诸军事，让他去救东阳。可他还没到，围城的兵已经烧了营、烧了攻具，走了。

**要救的人不用救了，要打的敌人不在了。** 一支为救援而集合的兵，到地方只剩一件事可做：追，或者不追。

| | |
|---|---|
| 依据 | `039`「未及至，虜燒營，焚攻具遁走」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「未及至」是时间差，不是失败；这六段不写这趟救援算不算白跑 |

---

### 卡 3 · 因果 ★

**问：他为什么不追了？**

答：**因为粮在窖里，不在锅里。**

| 原文 | 说的是什么 |
|---|---|
| 將追之，城內無食 | 追的动作已经打算做了 |
| 乃開窖取久穀，窖深數丈 | 粮在，取出来要工 |
| 出穀作米，已經再宿 | 谷出窖、做成米，两夜过去了 |
| 虜去已遠，不復可追，乃止 | 追不上了，停 |

**判断是「不復可追」，决定是「乃止」。** 两句话六个字，中间没有一句解释。

| | |
|---|---|
| 依据 | `040`「將追之，城內無食，乃開窖取久穀，窖深數丈，出穀作米，已經再宿，虜去已遠，不復可追，乃止」 |
| 标记 | ◆ 出自原文 |
| 考点 | 追不上不是敌人的问题，是粮的问题；底本把「食」写在敌情前面 |

---

### 卡 4 · 细节

**问：「窖深數丈」这四个字，为什么放在取谷之后？**

答：**因为它解释的是时间。**

窖是地下藏粮的仓，深几丈，取粮要下到窖底、再运上来，然后「出穀作米」——陈谷不能直接吃，还要加工。**两夜就这么过去了。**

| | |
|---|---|
| 依据 | `040`「乃開窖取久穀，窖深數丈，出穀作米，已經再宿」 |
| 标记 | ○ |
| 考点 | 「再宿」是两夜，是这一篇唯一的时间刻度；它量的不是敌人的速度，是他自己取粮的工 |

---

### 卡 5 · 训释

**问：「使持節」比「持節」高在哪里？**

答：**高在一等授权。**

节是朝廷给的凭信，加节就是加一份授权。使持节、持节、假节是三等，使持节最高——**救一个州，给的是最高一等的节。**

底本只记「加道濟使持節」，不分等第。

| | |
|---|---|
| 依据 | `038`「加道濟使持節、監征討諸軍事」。三等的差别为后世训释 |
| 标记 | ○ 训释 |
| 考点 | 这一篇里他原有的官一个没动，「加」的是节与监征讨诸军事；权力是为这一趟给的 |

---

### 卡 6 · 动机

**问：围城的兵为什么烧营走了？**

答：**这一篇不回答。**

`039` 只有「未及至，虜燒營，焚攻具遁走」十个字。**没有写他们为什么走，也没有写谁追的谁。**

烧营是走，烧攻具是走定了：器械带不走，也不再打算用。

| | |
|---|---|
| 依据 | `039` 只记烧营、焚攻具、遁走三件事。退走的原因，这一段不写 |
| 标记 | — 不回答 |
| 考点 | 敌人退走与救兵到来之间，底本没有写因果；把它读成被吓走的，是替底本加戏 |

---

### 卡 7 · 叙述

**问：这一篇收在哪个字上？**

答：**收在「乃止」。**

不是「大破之」，不是克之，是「乃止」——一个停下来的动作。后面紧接 `041`「還鎮廣陵」，六个字，收兵回镇。

**没有记功，也没有记追不上的责。** 一趟没有打成的救援，就这样完了。

| | |
|---|---|
| 依据 | `040`「不復可追，乃止」；`041`「還鎮廣陵」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「乃止」是决定，不是结果；底本把这个决定单独留在段末，不给它一个评价 |

---

> **这一篇的读法：** 六段，一百一十余字，一场没有打起来的救援。<br>
> 他做成的事不是追上了敌人，是**在追不上之后，让城里的人有粮吃**。
