# 复习卡 · 故事 01 · 京口

> 原则：**问动机，不问年代。**

---

## 故事 01 · 京口（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里，他做过几件事？**

答：**五件，官阶一级一级往上。**

| 次序 | 事 | 得到的 |
|---|---|---|
| 一 | 从高祖入京城，参建武军事 | 一个职名：参军 |
| 二 | 讨平鲁山，禽桓振 | 除辅国参军、南阳太守 |
| 三 | 论建义勋 | 封吴兴县五等侯 |
| 四 | 讨平聚在作唐的郭寄生 | 扬武将军、天门太守 |
| 五 | 从刘道规讨桓谦、荀林 | 无新官，只有一句「所向摧破」 |

底本把这五件按时间排下来。**每一件后面不是地名就是官名，没有一句评语。**

| | |
|---|---|
| 依据 | `004`「參高祖建武軍事」；`005`「討平魯山，禽桓振，除輔國參軍、南陽太守」；`006`「以建義勳，封吳興縣五等侯」；`007`「以道濟為揚武將軍、天門太守討平之」；`008`「又從劉道規討桓謙、荀林等」 |
| 标记 | ◆ 出自原文 |
| 考点 | 五件事的次序就是官阶的次序：无官 → 参军 → 太守 → 侯 → 将军。这一段台阶，是这一篇真正的结构 |

---

### 卡 2 · 细节 ★

**问：「道濟從入京城」六个字，重在哪一个字？**

答：**重在「從」。**

| 字 | 意思 | 为什么重要 |
|---|---|---|
| 從 | 跟随 | 起兵的是高祖，他是跟着走的那一个 |
| 入 | 进入 | 京城是目的地，也是他第一次在史书里出现的地方 |
| 京城 | 建康 | 路的终点，不是他的战功 |

**同是一个句子里，起兵的是高祖，跟进去的是他。**

| | |
|---|---|
| 依据 | `004`「高祖創義，道濟從入京城」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「從」不是谦辞，是位置：这一夜他不在发令的那一头 |

---

### 卡 3 · 动机

**问：高祖为什么把这样一个孤弟带进京城？**

答：**这一篇一个字都没写。**

`004` 只有「道濟從入京城」六个字。没有谁举荐，没有一句话，没有一次单独召见。

**「少孤」「和謹」是他这一边的家境与名声，可这两段与带他进京城之间，底本没有连词。**

| | |
|---|---|
| 依据 | `004` 只记「高祖創義，道濟從入京城」。带他的理由，这一篇不写 |
| 标记 | — 不回答 |
| 考点 | 名声与机会并排出现，不等于因果；这里不替他补一个理由 |

---

### 卡 4 · 训释

**问：吴兴县五等侯，是什么爵？**

答：**县侯，食邑在本县，跟着爵走。**

爵与官是两条线：官管差事，爵管身份。他这一篇拿到吴兴县五等侯，是爵，不是官——**第一个给他东西的地方，给的是身份**。

底本只给「封吳興縣五等侯」六个字，食邑多少，这一篇不记。

| | |
|---|---|
| 依据 | `006`「以建義勳，封吳興縣五等侯」。五等之制为后世训释；食邑数这一篇不载 |
| 标记 | ○ 训释 |
| 考点 | 「五等」是爵的等级，不是官阶；这一篇只给爵名，不给食邑数 |

---

### 卡 5 · 因果

**问：「和謹」与「身先士卒」，是同一个人吗？**

答：**是。底本把他这两面隔了五段，没有解释。**

```
003  奉姊事兄，以和謹致稱      ← 家里的评语
008  率厲文武，身先士卒        ← 阵前的八个字
```

家里的评语是和谨，阵前的写法是「身先士卒」。**一个说他怎么处人，一个说他怎么处兵。**

| | |
|---|---|
| 依据 | `003`「奉姊事兄，以和謹致稱」；`008`「率厲文武，身先士卒，所向摧破」 |
| 标记 | ○ |
| 考点 | 两面都在底本里，把它们读成矛盾是后人的事；底本既不说他变了，也不说这两面互不相容 |

---

### 卡 6 · 细节

**问：「禽桓振」的「禽」，是抓还是杀？**

答：**是擒获，活的。**

同篇 `005` 一处地名、一个人名、两个官职，三件事压在一句里。「禽」与「討平」并排，不另作一句——**底本没有写桓振被擒之后怎样**。

| | |
|---|---|
| 依据 | `005`「討平魯山，禽桓振，除輔國參軍、南陽太守」 |
| 标记 | ○ 训释 |
| 考点 | 「禽」通擒，是活捉；他的结局，这一篇不载，别处的记载不算这一篇的话 |

---

### 卡 7 · 叙述

**问：这一篇里，他说过一句话吗？**

答：**没有。**

001–008 全是动作与官职：幼而从、奉姊事兄、从入京城、讨平鲁山、封侯、讨作唐、身先士卒。**一句引语都没有。**

他在全传里的第一句话，要到洛阳城下才出现——那是下一篇的事。

| | |
|---|---|
| 依据 | `001`–`008` 记的全是动作、官职与别人的转述，无一处引语 |
| 标记 | ◆ 出自原文 |
| 考点 | 「以和謹致稱」是乡里的说法，不是他说的话；史官转述与本人引语，两回事 |

---

> **这一篇的读法：** 八段，一百二十余字，五件差事。<br>
> 底本没有给他一句台词，只给了一条**一级一级往上走的台阶**——走到这一篇末尾，他手里第一次有了可以失去的东西。
