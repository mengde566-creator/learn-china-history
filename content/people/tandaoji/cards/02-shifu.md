# 复习卡 · 故事 02 · 释俘

> 原则：**问那一句话的分量，不问杀了多少人。**

---

## 故事 02 · 释俘（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里，三座城为什么用了三个不同的字？**

答：**因为三座城到手的法子不一样。**

| 城 | 底本的字 | 说的是什么 |
|---|---|---|
| 许昌 | 獲 | 打下来，活捉了守将 |
| 成皋 | 降 | 守将自己走过来 |
| 洛阳 | 歸順 | 连人带城，归附 |

前面是「進剋」，这里是「降」，再往前是「歸順」。**兵没有停，写法一级比一级松。**

| | |
|---|---|
| 依据 | `018`「進剋許昌，獲偽寧朔將軍、潁川太守姚坦」；`019`「至成臯，偽兗州刺史韋華降」；`020`「逕進洛陽，偽平南將軍陳留公姚洸歸順」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三个字都是底本的用字，不是后人的解释；「獲」是活捉，「降」与「歸順」都写人走过来了 |

---

### 卡 2 · 细节 ★

**问：「伐罪弔民」四个字，拆开是什么？**

答：**讨伐有罪的人；抚慰那里的百姓。**

| 字 | 意思 | 为什么重要 |
|---|---|---|
| 伐 | 讨伐 | 说的是这支兵为什么来，不是怎么打 |
| 罪 | 有罪的人 | 罪在守将，不在城里的百姓 |
| 弔 | 慰问、抚恤 | 一个字把四千人的处置定了性 |
| 民 | 百姓 | 与「俘」相对：被俘的是民，不是敌 |

**八个字里没有一个字在讲战术。** 上一段议的是四千人怎么处置，他答的是这支兵为什么来。

| | |
|---|---|
| 依据 | `023`「道濟曰：『伐罪弔民，正在今日』」。「弔」的训释为后世注解 |
| 标记 | ○ 训释 |
| 考点 | 「弔」不是吊的同义替换，是慰问、抚恤；这四个字里没有杀，也没有放 |

---

### 卡 3 · 因果 ★

**问：四千人放走之后，为什么会有「相率歸之」？**

答：**底本只给了结果，理由是读者自己走过去的。**

```
024  皆釋而遣之        ← 全部放走，一个没留
025  相率歸之者甚眾    ← 一个带一个来归附的很多
```

**放走的人回去会说话。** 可他们说了什么，这一篇一个字都没有。

| | |
|---|---|
| 依据 | `024`「皆釋而遣之」、`025`「於是戎夷感悅，相率歸之者甚眾」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「釋而遣之」是放走，不是收编；「歸之」来的是人，不是城 |

---

### 卡 4 · 动机

**问：提京观之议的是谁？他为什么这样提？**

答：**这一篇不回答。**

`022` 全文只有九个字：「議者謂應悉戮以為京觀。」**没有姓名，没有理由，也没有一个人反驳的过程。**

底本要的是那个意见本身——四千条命摆在那里，军中有人这样想。

| | |
|---|---|
| 依据 | `022`「議者謂應悉戮以為京觀」。提意见的人，这一段不记 |
| 标记 | — 不回答 |
| 考点 | 「議者」不是一个人，是一种意见；替它补一个姓名，就把军中的一场分歧写成了两个人的对立 |

---

### 卡 5 · 细节

**问：「凡拔城破壘」的「凡」字，管到哪里？**

答：**管到前面三座城，也管到所有没写出来的城垒。**

「凡」是总账：从许昌到洛阳，凡攻下的城、打破的垒，俘虏合起来四千多人。**四千是这一路的总数，不是一座城的。**

| | |
|---|---|
| 依据 | `021`「凡拔城破壘，俘四千餘人」；前面三处见 `018`–`020` |
| 标记 | ◆ 出自原文 |
| 考点 | 一个「凡」字，把三座城并成一笔账；把它读成许昌一城的俘虏，数目就错了 |

---

### 卡 6 · 结构

**问：这一篇为什么用四个官衔收尾？**

答：**因为北伐这一趟，到他这里已经办完了。**

`026` 破姚绍、`027` 长安平定后为征虏将军、`028` 持节南蛮校尉、`030` 宋国侍中——**北伐到此收尾，一路加官，没有一句战况。**

「持節」第一次出现在他的履历里，就在这一段。那根节，此后跟了他一辈子。

| | |
|---|---|
| 依据 | `026`「進據潼關，與諸軍共破姚紹」；`028`「復以道濟為西中郎司馬、持節、南蠻校尉」；`030`「遷宋國侍中，領世子中庶子，兗州大中正」 |
| 标记 | ◆ 出自原文 |
| 考点 | 收尾是官衔不是战报：这一篇的分量在中段，不在末段 |

---

### 卡 7 · 叙述

**问：这一篇里，他留下了几句话？**

答：**一句，八个字。**

十四段里只有 `023` 是他说的：「伐罪弔民，正在今日。」

前面三座城、四千人、京观之议，全是为了让这八个字有分量；后面两段的结果，是这八个字的回声。**他自己的话，全篇就这一处。**

| | |
|---|---|
| 依据 | `023`「道濟曰：『伐罪弔民，正在今日』」——十四段里唯一一处引语 |
| 标记 | ◆ 出自原文 |
| 考点 | 一句话改变四千人的处置，这十四段不写他怎么说服众人，只写他说了什么、结果怎样 |

---

> **这一篇的读法：** 十四段，二百二十余字，一句人话。<br>
> 他做成的事不是杀了多少人，是**在军中都认为该杀的时候，把这支兵为什么来摆到了桌面上**。
