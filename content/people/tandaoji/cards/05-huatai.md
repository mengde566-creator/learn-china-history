# 复习卡 · 故事 05 · 滑台

> 原则：**问底本写了什么，不问传说讲了什么。**

---

## 故事 05 · 滑台（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇的战事分几段？**

答：**两胜、一败、一退。**

| 段 | 事 | 结果 |
|---|---|---|
| `057` | 受命都督征讨诸军事，率众北讨 | 兵权到手 |
| `058`–`059` | 寿张遇乙旃眷 | 大破之 |
| `060` | 高梁亭，悉颊库结前后邀战 | 分兵击之，即斩悉颊库结 |
| `061` | 进至济上，连战二十余日 | 虏众盛，遂陷滑台 |
| `062` | 于历城收兵 | 全军而反 |

**胜、败、退三段紧挨着，中间没有一句解释。** 两场胜仗之后，这里是唯一一句败。

| | |
|---|---|
| 依据 | `059`「道濟率寧朔將軍王仲德、驍騎將軍段宏奮擊，大破之」；`060`「即斬悉頰庫結」；`061`「連戰二十餘日，前後數十交，虜眾盛，遂陷滑臺」；`062`「道濟於歷城全軍而反」 |
| 标记 | ◆ 出自原文 |
| 考点 | 结构不是先胜后败的教训，是四个动作的次序：打、再打、陷、退 |

---

### 卡 2 · 细节 ★

**问：「全軍而反」四个字，说的是什么？**

答：**说的是一支没有断线的兵。**

「全軍」不是没有损失，是建制还在、人还跟着走。滑台陷了，他从历城把这支兵收住，一路往南，回到南朝的时候还是整的。

**九个字，写在一场败仗后面。** 下一段就进位司空了。

| | |
|---|---|
| 依据 | `062`「道濟於歷城全軍而反」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「全軍」是这支兵的状态，不是战果；底本把它紧接在「遂陷滑臺」之后，不加评语 |

---

### 卡 3 · 边界 ★

**问：唱筹量沙的故事，为什么不写进这一篇？**

答：**因为宋書卷四十三没有这一笔。**

| 项 | 内容 |
|---|---|
| 宋書卷四十三写的 | 连战二十余日、虏众盛、遂陷滑台、于历城全军而反 |
| 唱籌量沙出自 | 《南史·檀道济传》，本库底本不载 |

`056`–`064` 这一段只写敌众我寡的撤退，**没有量沙、没有沙堆、没有以沙充米**。凡涉此说，只能按外证登记，不能挂本卷编号当原文。

| | |
|---|---|
| 依据 | 见《南史·檀道济传》，本库底本不载。`061` 只有「虜眾盛，遂陷滑臺」，`062` 只有「道濟於歷城全軍而反」 |
| 标记 | ○ 外证 |
| 考点 | 外证坐标不进事实层：读者要拿到的是「遂陷滑臺」与「全軍而反」这两个结果，不是一段机智 |

---

### 卡 4 · 因果

**问：滑台为什么陷了？**

答：**底本只给了三个字：虏众盛。**

不是粮尽，不是援不至，也不是某人失期。`061` 一句里排下来：进至济上、连战二十余日、前后数十交、虏众盛、遂陷滑台。**敌人多，城就陷了。**

| | |
|---|---|
| 依据 | `061`「道濟進至濟上，連戰二十餘日，前後數十交，虜眾盛，遂陷滑臺」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「虜眾盛」是底本给的唯一解释；不写谁的责任，也不写他做了什么 |

---

### 卡 5 · 细节

**问：「值虜安平公乙旃眷」的「值」，是什么意思？**

答：**不期而遇。**

不是约好的一场仗，是行军路上撞上了。遇上了就打，一句「大破之」——**没有写阵形，也没有写死伤。**

| | |
|---|---|
| 依据 | `058`「軍至東平壽張縣，值虜安平公乙旃眷」。「值」为遇上，是后世训释 |
| 标记 | ○ 训释 |
| 考点 | 「值」与「邀戰」不同：一个是撞上，一个是对方来挑战；`060` 的「前後邀戰」是另一种情形 |

---

### 卡 6 · 动机

**问：打了败仗，为什么还进位司空？**

答：**这一篇不回答。**

`063` 只有「進位司空，持節、常侍、都督、刺史並如故」。**进位与败仗挨着写，中间没有一句解释。**

司空是三公，位高而不掌实务；可他这一趟回来，兵权一样没少。

| | |
|---|---|
| 依据 | `063`「進位司空，持節、常侍、都督、刺史並如故」。进位的缘由，这一段不写 |
| 标记 | — 不回答 |
| 考点 | 底本把「陷滑臺」「全軍而反」「進位司空」三句排在一起，不加因果；替它补一句虽败犹荣，就是我们的话 |

---

### 卡 7 · 叙述

**问：这一篇里，他说过一句话吗？**

答：**没有。**

九段里全是动作与官衔：率众北讨、奋击、分遣、进至、全军而反、进位、还镇。**没有一句引语，连一句转述他的话都没有。**

他在这一篇里的位置，只能从「分遣段宏及臺隊主沈虔之等奇兵擊之」这样的句子里看出来：**兵是他分出去的。**

| | |
|---|---|
| 依据 | `057`–`064` 记的全是动作、战果与官衔，无一处引语 |
| 标记 | ◆ 出自原文 |
| 考点 | 一个不说话的段落，靠「遣」「率」「分遣」三个动词写指挥；这三笔比任何一句台词都实在 |

---

> **这一篇的读法：** 九段，二百余字，城丢了，兵还在。<br>
> 他做成的事不是守住了滑台，是**在守不住之后，把一支没有断线的队伍带了回来**。
