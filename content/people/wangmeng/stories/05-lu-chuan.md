# 05-lu-chuan · 潞川

| | |
|---|---|
| **封面** | — |
| **地点** | 壶关 · 晋阳 · 潞川 · 邺城 |
| **原文** | 020–030 |

> 十一段。他第一次独立带大军，去打一个国。
> 出发时皇帝亲自送到霸东，说「捷雷不及掩耳」；对面来了四十多万，屯在潞川不敢进。
> 这一篇最见人的地方不是打赢，是**他怎样把一支不肯出力的偏师逼成前锋**。

## 二、正文

### 情节点 1 · 蛟龍猛獸

> 那时慕容垂避害来投苻坚。王猛对苻坚说：
>
> 「慕容垂是燕的宗戚，世雄东夏，宽仁惠下，恩结士庶，燕赵之间都有奉戴他的意思。看他的才略，权智无方；几个儿子也明毅有干艺，是人中之杰。
>
> **蛟龙猛兽，不是可以驯养的东西，不如除掉。**」
>
> 苻坚说：「我正要以义招致英豪，建不世之功。况且他刚来，我以诚待他；现在害他，人家会说我什么！」

| 标记 | ◆ |
| --- | --- |
| 原文 | `020` 是時慕容垂避害奔于堅，王猛言於堅曰：「慕容垂，燕之戚屬，世雄東夏，寬仁惠下，恩結士庶，燕、趙之間咸有奉戴之意。觀其才略，權智無方，兼其諸子明毅有幹藝，人之傑也。蛟龍猛獸，非可馴之物，不如除之。」堅曰：「吾方以義致英豪，建不世之功。且其初至，吾告之至誠，今而害之，人將謂我何！」 |
| 依据 | `020` |

| 说明 | 这一篇从一段「杀不杀」的对话开始，位置很讲究：**他一生的对手，最后是慕容垂**。此刻他看得比苻坚清楚，苻坚不听 |
| --- |

---

### 情节点 2 · 霸東受命

> 太和五年，朝廷又遣猛率杨安、张蚝、邓羌等十将，步骑六万伐燕。
>
> 苻坚亲自送他到霸东，对他说：
>
> 「如今授你精兵，委以重任。你可以从壶关、上党出潞川，这是取胜的时机，所谓捷雷不及掩耳。
>
> 我会亲自率众跟在你后面，在邺城相见。运粮的事已经安排相继送来，你只担心敌人，不必顾后。」

| 标记 | ◆ |
| --- | --- |
| 原文 | `022` 太和五年，又遣猛率楊安、張蠔、鄧羌等十將率步騎六萬伐暐。堅親送猛於霸東，謂曰：「今授卿精兵，委以重任，便可從壺關、上黨出潞川，此捷濟之機，所謂捷雷不及掩耳。吾當躬自率眾以繼卿後，於鄴相見。已敕運漕相繼，但憂賊，不煩後慮也。」 |
| 依据 | `022` |

| 说明 | 皇帝曾说要与他在邺城相见——后来真来了，还怪他临敌迎接（见 `028`） |
| --- |

### 情节点 3 · 兩城

> 杨安攻晋阳。猛攻壶关，擒了燕的上党太守慕容越。所经郡县都降于猛，猛留屯骑校尉苟苌守壶关。
>
> 碰上杨安攻晋阳，挖了地道，遣张蚝率壮士数百人入城，大呼斩关，猛、安于是入晋阳，擒了燕的并州刺史慕容庄。
>
> 燕遣太傅慕容评率众四十余万来救二城。评怕猛，不敢进，屯在潞川。

| 标记 | ◆ |
| --- | --- |
| 原文 | `024` 楊安攻晉陽。猛攻壺關，執暐上党太守慕容越，所經郡縣皆降於猛，猛留屯騎校尉苟萇戍壺關。會楊安攻晉陽，為地道，遣張蠔率壯士數百人入其城中，大呼斬關，猛、安遂入晉陽，執暐并州刺史慕容莊。暐遣其太傅慕容評率眾四十餘萬以救二城，評憚猛不敢進，屯於潞川。 |
| 依据 | `024` |

| 说明 | 「評憚猛不敢進」五个字，把四十万人的分量一下子泄了。**人数在这一篇里第一次不解决问题** |

### 情节点 4 · 燒其輜重

> 猛留将军毛当守晋阳，进师与评相持。
>
> 遣游击郭庆带锐卒五千，夜里从间道绕到评营后面，靠山放火，烧他的辎重。火光一直照到邺城。
>
> 慕容暐害怕，派使者责备慕容评，催他速战。
>
> 猛知道评在卖水卖柴，有可乘之机。评又来求战，于是猛在渭原列阵誓众：
>
> 「王景略受国厚恩，任兼内外。今日与诸君深入贼地，应当各自勉进，不可退。愿各位戮力行间，以报恩顾；受爵于明君之朝，庆觞于父母之室，不也很美吗！」
>
> 众人都勇奋，**破釜弃粮**，大呼竞进。

| 标记 | ◆ |
| --- | --- |
| 原文 | `025` 猛留將軍毛當戍晉陽，進師與評相持。遣遊擊郭慶以銳卒五千，夜從間道出評營後，傍山起火，燒其輜重，火見鄴中。暐懼，遣使讓評，催之速戰。猛知評賣水鬻薪，有可乘之會，評又求戰，乃陣于渭原而誓眾曰：「王景略受國厚恩，任兼內外，今與諸君深入賊地，宜各勉進，不可退也。願戮力行間，以報恩顧，受爵明君之朝，慶觴父母之室，不亦美乎！」眾皆勇奮，破釜棄糧，大呼競進。 |
| 依据 | `025` |

| 说明 | 三件事并行：**烧粮断他后院、等他被自己朝廷催、再拿一场誓师把兵心点着**。而「賣水鬻薪」四个字说明对面的主帅在发国难财 |
| --- |

---

### 情节点 5 · 司隸之價

> 猛望见评的兵众，心里厌恶（太多了），对邓羌说：
>
> 「今日之事，非将军不能取胜。成败之机，在此一举，将军努力！」
>
> 邓羌说：「如果把司隶给我，公不必担心。」
>
> 猛说：「这不是我能做主的。必以安定太守、万户侯相处。」
>
> 邓羌不高兴，退下。
>
> 不久兵交，猛召他，**邓羌睡着不应**。
>
> 猛驰马过去答应了他。邓羌于是在帐中大饮，与张蚝、徐成等跨马运矛，驰入评军，出入四次，旁若无人，搴旗斩将，杀伤甚众。

| 标记 | ◆ |
| --- | --- |
| 原文 | `026` 猛望評師之眾也，惡之，謂鄧羌曰：「今日之事，非將軍莫可以捷。成敗之機，在斯一舉。將軍其勉之！」羌曰：「若以司隸見與者，公無以為憂。」猛曰：「此非吾之所及也。必以安定太守、萬戶侯相處。」羌不悅而退。俄而兵交，猛召之，羌寢而弗應。猛馳就許之，羌於是大飲帳中，與張蠔、徐成等跨馬運矛，馳入評軍，出入數四，旁若無人，搴旗斬將，殺傷甚眾。 |
| 依据 | `026` |

| 说明 | 全篇最不讲情面的一段：**大将被主帅请战，先开价；价不合，就装睡不接令**。而主帅骑马过去当面答应他。这一节底本照写，不加褒贬 |
| --- |

### 情节点 6 · 五萬與十萬

> 到日中，评众大败，俘斩五万余；乘胜追击，又降斩十万。于是进师围邺。

| 标记 | ◆ |
| --- | --- |
| 原文 | `027` 及日中，評眾大敗，俘斬五萬有餘，乘勝追擊，又降斬十萬，於是進師圍鄴。 |
| 依据 | `027` |

| 说明 | 「俘斬五萬有餘」「降斬十萬」——两个数字，一句一结。**底本写战果从不抒情** |

### 情节点 7 · 何以臨敵而棄眾

> 苻坚听说，留李威辅太子宏守长安，以苻融镇洛阳，亲自率精锐十万向邺。
>
> 七日到安阳，经过旧居，引诸耆老谈起祖父之事，泫然流涕，停了两夜。
>
> 猛悄悄到安阳迎坚。苻坚问他：
>
> 「从前周亚夫不出军迎汉文帝；将军为什么临敌而弃众？」
>
> 猛说：「臣每读亚夫之事，常说他是靠抵触人主而成名将，私下并不推重。臣奉陛下神算，击垂亡之虏，如摧枯拉朽，何足挂虑！监国年幼，銮驾远临，倘有不测，宗庙怎么办！」

| 标记 | ◆ |
| --- | --- |
| 原文 | `028` 堅聞之，留李威輔其太子宏守長安，以苻融鎮洛陽，躬率精銳十萬向鄴。七日而至於安陽，過舊閭，引諸耆老語及祖父之事，泫然流涕，乃停信宿。猛潛至安陽迎堅，堅謂之曰：「昔亞夫不出軍迎漢文，將軍何以臨敵而棄眾也？」猛曰：「臣每覽亞夫之事，嘗謂前卻人主，以此而為名將，竊未多之。臣奉陛下神算，擊垂亡之虜，若摧枯拉朽，何足慮也！監國沖幼，鑾駕遠臨，脫有不虞，其如宗廟何！」 |
| 依据 | `028` |

| 说明 | 苻坚拿周亚夫的标准来问他，他把这个标准顶回去了：**「以抵觸人主成名將，我不推重」**。这一答把「忠」的定义换了一个方向 |
| --- |

### 情节点 8 · 名籍與封賞

> 苻坚于是攻邺，陷之。慕容暐出奔高阳，苻坚的将领郭庆擒了他送来。
>
> 苻坚进邺宫，翻检前燕的名籍——郡、县、户、口，四个数字一笔一笔都记在册上（原文见 `029`）。

| 标记 | ◆ |
| --- | --- |
| 原文 | `029` 堅遂攻鄴，陷之。慕容暐出奔高陽，堅將郭慶執而送之。堅入鄴宮，閱其名籍，幾郡百五十七，縣一千五百七十九，戶二百四十五萬八千九百六十九，口九百九十八萬七千九百三十五。 |
| 依据 | `029`；封赏见 `030` |

| 说明 | 收尾给的不是战功，是**户口册**：郡一百五十七、县一千五百七十九、户二百四十五万余、口九百九十余万，四个数字一路排下来（全数见背景卡「名籍」）。一个国家灭亡的样子，就是这几行账 |

## 四、背景卡

### 潞川

潞水一带，在今山西长治附近，是邺城西面的门户。`024` 记慕容评屯兵于此。

**燕的援军在这里停住，就再没往前走。**

> **依据**：`024`「評憚猛不敢進，屯於潞川」。

---

### 賣水鬻薪

卖水卖柴。`025` 说慕容评在军中做这种买卖，是发军中的财。

**这是猛判断「有可乘之会」的理由之一：一个主帅在算自己的钱，兵就靠不住。**

> **依据**：`025`「猛知評賣水鬻薪，有可乘之會」。

---

### 破釜棄糧

砸锅、丢粮，表示不打算退。`025` 记誓师之后全军如此。

**这一手他在誓师时就用上了——不是在战场上被逼到绝路才砸锅。**

> **依据**：`025`「破釜棄糧，大呼競進」。

---

### 司隸

司隶校尉，掌京畿监察，是极显要的职位。`026` 邓羌开口要的就是这个。

**一个前线大将，在开战前拿「我要当司隶」做条件——底本原样记下了这件事。**

> **依据**：`026`「若以司隸見與者，公無以為憂」。

---

### 渭原

地名，在潞川附近。`025` 记他在此列阵誓众。

> **依据**：`025`「乃陣于渭原而誓眾」。

---

### 名籍

户口与行政簿册。`029` 记苻坚入邺宫查阅，得郡一百五十七、县一千五百七十九、户二百四十五万八千九百六十九、口九百九十八万七千九百三十五。四个数字是全篇最具体的战利品：灭一个国，收的是这些人和地。

**这是本卷一串极长的数字，也是前燕作为一个国家的分量。**

> **依据**：`029` 原文四组数字。

## 七、设计说明

> **这一篇的戏眼是「四十万人为什么不动」。**
>
> 燕的四十余万屯在潞川，底本给的理由只有五个字：「評憚猛不敢進」。
> 而猛做的事是三件：夜里烧他的辎重、等他被自己朝廷催、再逼出自己军中不肯出力的人。
>
> `026` 那一段我没有美化，也没有加重：**邓羌开价、价不合就装睡、主帅骑马过去答应他、然后他大饮一场冲出去。**
> 这就是底本写的样子。**一支能打仗的军队，靠的不只是号令，还有交换。**
>
> 我把 `020`（劝杀慕容垂）放在最前面，是因为它和全篇形成一个反讽：
> **他看得见未来的敌人，皇帝看不见。**八年后淝水一败，替他印证这件事的人不是他——那时他已经死了
> （见下一篇《临终遗言》）。
>
> 结尾我用了名籍那四个数字，而不是战功。**一个国家灭亡，最硬的一句是户口册。**
