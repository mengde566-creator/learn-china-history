# 王猛 · 直译

> **这一份和故事里的白话不是一回事。**
>
> 故事里的白话是**给人读的**：可以顺着现代汉语的语序重排、可以补主语、可以把两句并成一句。
> 这一份是**直译**：跟着原文的字序和句法走，不替它顺句子、不替它补它没说的主语。
>
> **所以它读起来会比故事里的白话生硬——这是有意的。** 它要让人看见原文长什么样：
> 哪一句没有主语、哪一处省略了宾语、哪个词在原文里只是一个字。
> 故事里的白话告诉你「发生了什么」，这一份告诉你「原文是这么说的」。
>
> **四条写法**：
>
> 1. **不补主语。** 原文承前省略，直译也省略（用「（他）」标出来源，不用人名填进去）
> 2. **术语随文注。** 官名、地名、称谓第一次出现时，用（　）就地解释
> 3. **不合并、不拆分。** 原文一个句号，直译一个句号
> 4. **异体照录。** 「硃肜」「捫虱」「上党」都照原卷，直译不替它改成通行字
>
> 段号与 `source.md` 一一对应。**没有直译的段就是还没做**——不是「不需要」。

| 018 | 苻柳出挑戰，猛閉壘不應。柳以猛為憚己，留其世子良守蒲阪，率眾二萬，將攻長安。長安去蒲阪百餘里，鄧羌率勁騎七千夜襲敗之，柳引軍還，猛又盡眾邀擊，悉俘其卒，柳與數百騎入于蒲阪。 | 苻柳出来挑战，王猛闭垒不应。苻柳以为王猛怕自己，留他的世子苻良守蒲阪，率众二万，将要攻长安。长安离蒲阪百余里，邓羌率劲骑七千夜里袭击打败他，苻柳率军回来，王猛又尽众邀击，全部俘虏他的士卒，苻柳与数百骑进入蒲阪。 |
| 019 | 猛又尋破蒲阪，斬柳及其妻子，傳首長安。猛屯蒲阪，遣鄧羌與王鑒等攻陷陝城，克之，送庾于長安，殺之。 | 王猛又随即攻破蒲阪，斩苻柳及其妻子，传送首级到长安。王猛屯蒲阪，派邓羌与王鉴等攻陷陕城，攻克了，送苻庾到长安，杀了他。 |
| 020 | 是時慕容垂避害奔于堅，王猛言於堅曰：「慕容垂，燕之戚屬，世雄東夏，寬仁惠下，恩結士庶，燕、趙之間咸有奉戴之意。觀其才略，權智無方，兼其諸子明毅有幹藝，人之傑也。蛟龍猛獸，非可馴之物，不如除之。」堅曰：「吾方以義致英豪，建不世之功。且其初至，吾告之至誠，今而害之，人將謂我何！」 | 这时慕容垂避害奔到苻坚处，王猛对苻坚说：「慕容垂，是燕的戚属，世代称雄东夏，宽仁惠下，恩结士庶，燕、赵之间都有奉戴他的意思。看他的才略，权智无方，加上他的几个儿子明毅有干艺，是人之杰。蛟龙猛兽，不是可以驯养的东西，不如除掉他。」苻坚说：「我正要以义招致英豪，建立不世之功。况且他刚来，我告诉过他至诚，如今害他，人家将说我什么！」 |
| 021 | 堅大怒，遣王猛輿建威梁成、鄧羌率步騎三萬，署慕容垂為冠軍將軍，以為鄉導，攻暐洛州刺史慕容築于洛陽。暐遣其將慕容臧率精卒十萬，將解築圍。猛使梁成等以精銳萬人卷甲赴之，大破臧于滎陽。築懼而請降，猛陳師以受之，留鄧羌鎮金墉，猛振旅而歸。 | 苻坚大怒，派王猛与建威将军梁成、邓羌率步骑三万，署慕容垂为冠军将军，作为乡导（乡导，向导），在洛阳攻慕容暐的洛州刺史慕容筑。慕容暐派他的将慕容臧率精卒十万，将要解慕容筑的围。王猛使梁成等以精锐万人卷甲赶去，在荥阳大破慕容臧。慕容筑恐惧而请降，王猛陈兵接受，留邓羌镇金墉，王猛整军而回。 |
| 022 | 太和五年，又遣猛率楊安、張蠔、鄧羌等十將率步騎六萬伐暐。堅親送猛於霸東，謂曰：「今授卿精兵，委以重任，便可從壺關、上黨出潞川，此捷濟之機，所謂捷雷不及掩耳。吾當躬自率眾以繼卿後，於鄴相見。已敕運漕相繼，但憂賊，不煩後慮也。」 | 太和五年，又派王猛率杨安、张蚝、邓羌等十将率步骑六万伐慕容暐。苻坚亲自在霸东送王猛，对他说：「如今授你精兵，委以重任，就可以从壶关、上党出潞川，这是捷济的时机，所谓捷雷不及掩耳。我当亲自率众跟在你后面，在邺相见。已敕令运漕相继，只担心敌人，不劳你后面忧虑。」 |
| 023 | 猛曰：「臣庸劣孤生，操無豪介，蒙陛下恩榮，內侍帷幄，出總戎旅，藉宗廟之靈，稟陛下神算，殘胡不足平也。願不煩鑾軫，冒犯霜露。臣雖不武，望克不淹時。但願速敕有司，部置鮮卑之所。」堅大悅。於是進師。 | 王猛说：「臣是庸劣孤生，操行没有可取之处，蒙陛下恩荣，在内侍奉帷幄，出外总领戎旅，藉宗庙之灵，禀受陛下神算，残胡不足平定。希望不劳銮轸（銮轸，皇帝的车驾），冒犯霜露。臣虽不武，希望攻克不拖延时日。只愿速敕有司，部署鲜卑的处所。」苻坚大悦。于是进军。 |
| 024 | 楊安攻晉陽。猛攻壺關，執暐上党太守慕容越，所經郡縣皆降於猛，猛留屯騎校尉苟萇戍壺關。會楊安攻晉陽，為地道，遣張蠔率壯士數百人入其城中，大呼斬關，猛、安遂入晉陽，執暐并州刺史慕容莊。暐遣其太傅慕容評率眾四十餘萬以救二城，評憚猛不敢進，屯於潞川。 | 杨安攻晋阳。王猛攻壶关，抓获慕容暐的上党太守慕容越，所经过的郡县都向王猛投降，王猛留屯骑校尉苟苌戍壶关。恰好杨安攻晋阳，挖地道，派张蚝率壮士数百人进入城中，大呼斩关，王猛、杨安就进入晋阳，抓获慕容暐的并州刺史慕容庄。慕容暐派他的太傅慕容评率众四十余万来救二城，慕容评忌惮王猛不敢进，屯在潞川。 |
| 025 | 猛留將軍毛當戍晉陽，進師與評相持。遣遊擊郭慶以銳卒五千，夜從間道出評營後，傍山起火，燒其輜重，火見鄴中。暐懼，遣使讓評，催之速戰。猛知評賣水鬻薪，有可乘之會，評又求戰，乃陣于渭原而誓眾曰：「王景略受國厚恩，任兼內外，今與諸君深入賊地，宜各勉進，不可退也。願戮力行間，以報恩顧，受爵明君之朝，慶觴父母之室，不亦美乎！」眾皆勇奮，破釜棄糧，大呼競進。 | 王猛留将军毛当戍晋阳，进军与慕容评相持。派游击将军郭庆以锐卒五千，夜里从小路出到慕容评营后，靠山起火，烧他的辎重，火光在邺中都看得见。慕容暐恐惧，派使者责备慕容评，催他速战。王猛知道慕容评卖水卖柴（卖水鬻薪，指慕容评垄断水柴取利），有可乘的机会；慕容评又求战，就列阵在渭原（渭原，地名）而誓众说：「王景略受国厚恩，任兼内外，如今与诸位深入贼地，应当各自勉进，不可退。愿努力于行伍之间，以报恩顾，在明君之朝受爵，在父母之室举杯庆贺，不也美吗！」众都勇奋，破釜弃粮，大呼竞进。 |
| 026 | 猛望評師之眾也，惡之，謂鄧羌曰：「今日之事，非將軍莫可以捷。成敗之機，在斯一舉。將軍其勉之！」羌曰：「若以司隸見與者，公無以為憂。」猛曰：「此非吾之所及也。必以安定太守、萬戶侯相處。」羌不悅而退。俄而兵交，猛召之，羌寢而弗應。猛馳就許之，羌於是大飲帳中，與張蠔、徐成等跨馬運矛，馳入評軍，出入數四，旁若無人，搴旗斬將，殺傷甚眾。 | 王猛望见慕容评的兵众，厌恶它，对邓羌说：「今日之事，不是将军就没有能取胜的。成败之机，在此一举。将军要勉力啊！」邓羌说：「若把司隶（司隶校尉）给我，公不必以此为忧。」王猛说：「这不是我所能做主的。必以安定太守、万户侯相待。」邓羌不高兴而退。不久兵交，王猛召他，邓羌睡着不回应。王猛驰去答应他，邓羌于是在帐中大饮，与张蚝、徐成等跨马运矛，驰入慕容评的军中，出入数次，旁若无人，拔旗斩将，杀伤甚众。 |
| 027 | 及日中，評眾大敗，俘斬五萬有餘，乘勝追擊，又降斬十萬，於是進師圍鄴。 | 到日中，慕容评的兵众大败，俘斩五万余，乘胜追击，又降斩十万，于是进军围邺。 |
| 028 | 堅聞之，留李威輔其太子宏守長安，以苻融鎮洛陽，躬率精銳十萬向鄴。七日而至於安陽，過舊閭，引諸耆老語及祖父之事，泫然流涕，乃停信宿。猛潛至安陽迎堅，堅謂之曰：「昔亞夫不出軍迎漢文，將軍何以臨敵而棄眾也？」猛曰：「臣每覽亞夫之事，嘗謂前卻人主，以此而為名將，竊未多之。臣奉陛下神算，擊垂亡之虜，若摧枯拉朽，何足慮也！監國沖幼，鑾駕遠臨，脫有不虞，其如宗廟何！」 | 苻坚听说，留李威辅佐他的太子苻宏守长安，以苻融镇洛阳，亲自率精锐十万向邺。七天而到安阳，经过旧居的里门，引诸耆老谈到祖父的事，泫然流涕，就停留了两夜。王猛暗中到安阳迎接苻坚，苻坚对他说：「从前周亚夫不出军迎汉文帝，将军为什么临敌而弃众呢？」王猛说：「臣每读周亚夫的事，曾说使君主退让、以此做名将，私下并不推崇他。臣奉陛下神算，击将亡的敌人，像摧枯拉朽，哪里值得忧虑！监国（监国，太子留守）幼冲，銮驾远临，倘有不测，宗庙怎么办！」 |
| 029 | 堅遂攻鄴，陷之。慕容暐出奔高陽，堅將郭慶執而送之。堅入鄴宮，閱其名籍，幾郡百五十七，縣一千五百七十九，戶二百四十五萬八千九百六十九，口九百九十八萬七千九百三十五。 | 苻坚就攻邺，攻陷了。慕容暐出奔高阳，苻坚的将郭庆抓住送他。苻坚进入邺宫，查阅名籍，计郡一百五十七，县一千五百七十九，户二百四十五万八千九百六十九，口九百九十八万七千九百三十五。 |
| 030 | 諸州郡牧守及六夷渠帥盡降於堅。郭慶窮追餘燼，慕容評奔于高句麗，慶追至遼海，句麗縛評送之。堅散暐宮人珍寶以賜將士，論功封賞各有差。以王猛為使持節、都督關東六州諸軍事、車騎大將軍、開府儀同三司、冀州牧、鎮鄴；以郭慶為持節、都督幽州諸軍事、揚武將軍、幽州刺史，鎮薊。 | 各州郡的牧守及六夷（六夷，指匈奴等六种胡族）的渠帅都向苻坚投降。郭庆穷追余烬，慕容评奔到高句丽，郭庆追到辽海，句丽绑了慕容评送来。苻坚散慕容暐的宫人珍宝以赐将士，论功封赏各有等差。以王猛为使持节、都督关东六州诸军事、车骑大将军、开府仪同三司、冀州牧，镇邺；以郭庆为持节、都督幽州诸军事、扬武将军、幽州刺史，镇蓟。 |
| 031 | 後率諸軍討慕容暐，軍禁嚴明，師無私犯。猛之未至鄴也，劫盜公行，及猛之至，遠近帖然，燕人安之。軍還，以功進封清河郡侯，賜以美妾五人，上女妓十二人，中妓三十八人，馬百匹，車十乘。猛上疏固辭不受。 | 后来率各军讨慕容暐，军禁严明，军队没有私自侵掠。王猛没有到邺的时候，劫盗公行；到王猛到了，远近帖然，燕人安于他。军队回，以功进封清河郡侯，赐给他美妾五人，上等女妓十二人，中等妓三十八人，马百匹，车十乘。王猛上疏坚决辞让不接受。 |
| 032 | 時既留鎮冀州，堅遣猛於六州之內聽以便宜從事，簡召英俊，以補關東守宰，授訖，言台除正。 | 当时既留镇冀州，苻坚让王猛在六州之内听凭他便宜行事，简召英俊，以补关东的守宰，授官之后，上报台省正式除授。 |
| 033 | 堅不許，遣其侍中梁讜詣鄴喻旨，猛乃視事如前。 | 苻坚不许，派他的侍中梁谠到邺晓谕旨意，王猛就照旧视事。 |
| 034 | 乃以王猛為丞相，以苻融為鎮東大將軍。代猛為冀州牧。 | 就以王猛为丞相，以苻融为镇东大将军。代替王猛为冀州牧。 |
| 035 | 王猛至長安，加都督中外諸軍事，猛辭讓再三，堅不許。 | 王猛到长安，加都督中外诸军事，王猛再三辞让，苻坚不许。 |
| 036 | 俄入為丞相、中書監、尚書令、太子太傅、司隸校尉，持節、常侍、將軍、侯如故。稍加都督中外諸軍事。猛表讓久之。堅曰：「卿昔螭蟠布衣，朕龍潛弱冠，屬世事紛紜，厲士之際，顛覆厥德。朕奇卿於暫見，擬卿為臥龍，卿亦異朕於一言，回《考槃》之雅志，豈不精契神交，千載之會！雖傅岩入夢，薑公悟兆，今古一時，亦不殊也。自卿輔政，幾將二紀，內厘百揆，外蕩群凶，天下向定，彝倫始敘。朕且欲從容於上，望卿勞心於下，弘濟之務，非卿而誰！」遂不許。 | 不久入为丞相、中书监、尚书令、太子太傅、司隶校尉，持节、常侍、将军、侯照旧。逐渐加都督中外诸军事。王猛上表辞让很久。苻坚说：「你从前以布衣螭蟠（螭蟠，像螭龙盘伏，指未出仕），朕在弱冠时龙潜，遇上世事纷纭，正是砥砺士人之际，颠覆了那德。朕在短暂相见中觉得你奇特，把你比作卧龙（卧龙，指诸葛亮），你也因一句话觉得朕不同寻常，回转了《考槃》（《考槃》，《诗经》篇名，咏退隐）的雅志，难道不是精契神交、千载的相会！即使傅岩入梦（傅岩入梦，指商王武丁梦得傅说）、姜公悟兆（姜公悟兆，指周文王遇姜尚的征兆），古今一时，也没有不同。自从你辅政，将近二纪（纪，十二年），在内治理百揆，在外扫荡群凶，天下趋向平定，彝伦开始有序。朕且想在上从容，望你在下劳心，弘济的事务，不是你还有谁！」就不许。 |
