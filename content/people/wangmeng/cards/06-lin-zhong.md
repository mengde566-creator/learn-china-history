# 复习卡 · 故事 06 · 临终遗言

> 原则：**问动机，不问年代。**

---

## 故事 06 · 临终遗言（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：临终那两句话，各说的是哪一边？**

答：**一句说晋，一句说鲜卑与羌。**

| 句 | 对象 | 主张 |
|---|---|---|
| 臣沒之後，願不以晉為圖 | 东晋 | 不要打 |
| 鮮卑、羌虜，我之仇也，終為人患，宜漸除之 | 境内的异族 | 要防、要渐渐除 |

**两句话，两个方向，说完就死。** 底本接下来只记「時年五十一」。

| | |
|---|---|
| 依据 | `044`「臣沒之後，願不以晉為圖。鮮卑、羌虜，我之仇也，終為人患，宜漸除之，以便社稷」 |
| 标记 | ◆ 出自原文 |
| 考点 | 后人知道结局，所以这两句读起来像预言；在当时，它只是一份政治交代 |

---

### 卡 2 · 动机 ★

**问：他为什么说晋不可图？**

答：**他自己给了两条理由。**

| 理由 | 原话 |
|---|---|
| 名分 | 晉雖僻陋吳、越，乃正朔相承 |
| 邦交 | 親仁善鄰，國之寶也 |

**这两条是底本记下来的。** 兵势、人心那一层，这一段不写——所以「他知道打不赢」是后人的读法，不是他的话。

| | |
|---|---|
| 依据 | `044`「晉雖僻陋吳、越，乃正朔相承。親仁善鄰，國之寶也」 |
| 标记 | ○ 合理推演 |
| 考点 | 理由给的是名分与睦邻，不是军力对比；不要替他补上没有说出口的那一层 |

---

### 卡 3 · 细节 ★

**问：「正朔相承」四个字是什么意思？**

答：**历法与正统的承继。**

| 词 | 意思 | 为什么重要 |
|---|---|---|
| 正朔 | 一年之始与一月之始，颁历是天子的事 | 谁的正朔被奉，谁就是正统 |
| 相承 | 一代一代接下去 | 晋虽偏居吴越，这一条没断 |

**这是他说「不要图晋」的第一层理由：打它不占理。**

| | |
|---|---|
| 依据 | `044`「晉雖僻陋吳、越，乃正朔相承」 |
| 标记 | ○ 训释 |
| 考点 | 「僻陋」是说地方偏、国力弱；后半句才是他要说的 |

---

### 卡 4 · 因果 ★

**问：遗言后来的遭遇，分几步？**

答：**三步：被记住、被引用、被无视。**

| 步 | 段 | 谁 |
|---|---|---|
| 一 | `044` | 他自己说出来 |
| 二 | `047` | 苻融在朝议上泣谏：「其臨終之言不可忘也」 |
| 三 | `049` | 苻坚在城下自悔：「吾不用王景略、陽平公之言」 |

**中间那一步，苻坚的回答是「不納」。**

| | |
|---|---|
| 依据 | `047`「王景略一時奇士，陛下每擬之孔明，其臨終之言不可忘也」；同段「堅不納」；`049`「吾不用王景略、陽平公之言」 |
| 标记 | ◆ 出自原文 |
| 考点 | 遗言没有救他；它被人记住、被人转述，最后只用来后悔 |

---

### 卡 5 · 细节

**问：他死后得到的礼遇，重在哪里？**

答：**重在三处：亲临、赠官、葬礼规格。**

| 项 | 原文 |
|---|---|
| 亲临 | 比斂，三臨 |
| 赠 | 贈侍中，丞相余如故 |
| 器物 | 給東園溫明秘器，帛三千匹，谷萬石 |
| 规格 | 葬禮一依漢大將軍故事 |
| 谥 | 諡曰武侯 |

最后一句是「朝野巷哭三日」。**一个人死了，巷子里哭了三天。**

| | |
|---|---|
| 依据 | `045`「比斂，三臨」；同段「葬禮一依漢大將軍故事」；同段「朝野巷哭三日」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「一依漢大將軍故事」是规格的凭据，比任何形容词都硬 |

---

### 卡 6 · 结构

**问：`048` 慕容冲姐弟入宫那一段，为什么放在这一篇？**

答：**因为它和遗言是同一件事的两面。**

| 面 | 记的是 |
|---|---|
| `048` | 慕容冲姐弟专宠，长安歌「一雌復一雄，雙飛入紫宮」，王猛切谏，苻坚乃出冲 |
| `044` | 临终说：鲜卑是我仇，终为人患，宜渐除之 |

**他死前说要防鲜卑；死前几年，他已经把一个鲜卑送出了宫。**

| | |
|---|---|
| 依据 | `048`「王猛切諫，堅乃出沖」；`044`「鮮卑、羌虜，我之仇也」 |
| 标记 | ○ 合理推演 |
| 考点 | 底本把两件事分开记；放在一篇里读，才看得出这是一条线 |

---

### 卡 7 · 叙述

**问：遗言应验了吗？**

答：**底本没有用「应验」这个词。**

| 事 | 底本的说法 |
|---|---|
| 伐晋 | `047` 苻融谏，`049` 苻坚自悔「吾不用王景略」 |
| 鲜卑 | `049`「使白虜敢至於此」 |
| 引咎 | 记在苻坚自己嘴里，不是史官的评语 |

**「应验」是读者事后拼出来的；底本只记了人事与后悔。**

| | |
|---|---|
| 依据 | `047` 与 `049` 都只记谏与悔，不记「如其言」之类的断语 |
| 标记 | ○ 合理推演 |
| 考点 | 不要把自己的结论说成史书的结论 |

---

### 卡 8 · 细节

**问：「陽平公」「白虜」各指谁？**

答：**一个是苻融的封号，一个是对鲜卑的蔑称。**

| 词 | 指 | 出处 |
|---|---|---|
| 陽平公 | 苻融 | `049` 与 `047` 的泣谏者同一个人 |
| 白虜 | 鲜卑慕容部 | `049`「使白虜敢至於此」 |

**苻坚在城下把两个人并称：一个是他，一个是苻融。**

| | |
|---|---|
| 依据 | `049`「吾不用王景略、陽平公之言，使白虜敢至於此」；`047` 记苻融泣谏 |
| 标记 | ○ 训释 |
| 考点 | 「王景略」是字，「陽平公」是爵；两个称呼并排，说明这是他心里的两份悔 |

---

> **这一篇的读法：** 两句话，一场丧礼，八年之后的两句后悔。<br>
> 他做成的最后一件事不是预言，是**把话说清楚了；听不听，不在他手里**。
