# 复习卡 · 故事 01 · 扪虱谈

> 原则：**问动机，不问年代。**

---

## 故事 01 · 扪虱谈（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里，他走过几个地方？**

答：**四处，一处比一处靠近权力。**

| 地方 | 他在做什么 | 底本 |
|---|---|---|
| 魏郡 · 洛阳 | 卖畚；有人贵买而不给钱，他跟着进山去取 | `003` |
| 邺都 · 华阴山 | 游邺都，徐统召为功曹，他逃去隐居 | `004` |
| 灞上 | 见桓温，扪虱而谈 | `005` |
| 长安 | 苻坚遣吕婆楼来招他 | `006` |

前两处是出身，后两处是选择。**底本按时间排下来，中间没有一句过渡。**

| | |
|---|---|
| 依据 | `003`「家于魏郡」；`004`「遂隱于華陰山」；`005`「桓溫入關，猛被褐而詣之」；`006`「遣呂婆樓招之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 四处里只有两处是他自己走进去的：华阴山和灞上军门。另两处，一处是家，一处是别人来请 |

---

### 卡 2 · 动机 ★

**问：他为什么不跟桓温南下？**

答：**因为回去问过老师。**

```
温之将还    赐车马、拜高官督护、请与俱南
                ↓
           猛还山咨师
                ↓
    师曰：卿与桓温岂并世哉
                ↓
             猛乃止
```

四步全在 `005` 同一段里。**底本没有写他为什么动摇，也没有写他为什么留下。**

| | |
|---|---|
| 依据 | `005`「溫之將還，賜猛車馬，拜高官督護，請與俱南。猛還山咨師……猛乃止」 |
| 标记 | ○ 合理推演 |
| 考点 | 「還山咨師」四个字最要紧：不是自己拍板，是问了人。这一笔让「名士」落了地 |

---

### 卡 3 · 细节 ★

**问：「捫虱而言，旁若無人」八个字，拆开是什么？**

答：**捉虱子；一边说话；旁边站着人，当没有。**

| 字 | 意思 | 为什么重要 |
|---|---|---|
| 捫 | 摸、捉 | 见大帅的场合做这个动作 |
| 虱 | 虱子 | 粗布短衣里才养得住 |
| 而言 | 一边说 | 手上不停，嘴上也不停 |
| 旁若無人 | 当旁边没人 | 军门里站着的都是人 |

**这是全篇的定妆照。底本只写动作，不解释他为什么这样。**

| | |
|---|---|
| 依据 | `005`「一面談當世之事，捫虱而言，旁若無人」 |
| 标记 | ◆ 出自原文 |
| 考点 | 读成「傲慢」或读成「从容」，底本都不反对；它只给了这个动作 |

---

### 卡 4 · 因果 ★

**问：他那句话为什么能问住桓温？**

答：**他答的是「不渡灞水」，不是「兵不够」。**

| 桓温问 | 王猛答 |
|---|---|
| 率锐师十万，仗义讨逆，为何三秦豪杰一个不来 | 长安咫尺而不渡灞水，百姓未见公心 |

一句问，一句答，一句「默然无以酬之」。**中间没有第三个动作。**

桓温问的是豪杰为什么不来；他答的是主帅为什么不渡河。**这两句问的不是一件事。**

| | |
|---|---|
| 依据 | `005`「長安咫尺而不渡灞水，百姓未見公心故也」；同段「溫默然無以酬之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「咫尺」与「不渡」并置，问的是动机，不是兵力 |

---

### 卡 5 · 结构

**问：嵩高山那一段，底本是怎么处理的？**

答：**照录，不解释。**

`003` 记他随人入山取钱，见一父老，以十倍价偿畚钱，出来回头一看是嵩高山。**这是全传唯一一段神异记载。**

当作事实读，整篇就成了传奇；当作传闻读，才知道后面的狠劲是从「少貧賤」来的。

| | |
|---|---|
| 依据 | `003`「猛既出，顧視，乃嵩高山也」——这一段的性质是传闻，不是可核的史事 |
| 标记 | ○ 合理推演 |
| 考点 | 神异记载与后面的史事要分开读；底本把它们并排放在一起，没有替读者划线 |

---

### 卡 6 · 细节

**问：「被褐」「高官督護」各是什么？**

答：**一头是粗布短衣，一头是幕府属官的名目。**

| 词 | 意思 | 出处 |
|---|---|---|
| 被褐 | 穿粗布衣 | `005` |
| 高官督護 | 桓温给的官职名，请他一齐南下 | `005` |

两个词分在同一段的两头：**他穿什么来，对方给什么价。**

| | |
|---|---|
| 依据 | `005`「猛被褐而詣之」；同段「拜高官督護，請與俱南」 |
| 标记 | ○ 训释 |
| 考点 | 这一头一尾的对照是底本自己排的，不是后人的修辞 |

---

### 卡 7 · 叙述

**问：这一篇里，他自己说过几句话？**

答：**只记下一句；另一次问话，底本没有记内容。**

| 场合 | 话 |
|---|---|
| 灞上答桓温 | 「公不遠數千里，深入寇境，長安咫尺而不渡灞水」 |
| 还山问师 | 底本只记「咨師」，不记他问了什么 |

`003`、`004` 两段全是史官的叙述，他一句没说。**他在这五段里的第一句话，就是答桓温的那一句。**

| | |
|---|---|
| 依据 | `004`「懷佐世之志，希龍顏之主，斂翼待時，候風雲而後動」；`005`「猛還山咨師」 |
| 标记 | ○ 合理推演 |
| 考点 | 「常思效用」那一类话是史官的转述；转述不是台词 |

---

> **这一篇的读法：** 一个卖簸箕的人，穿着粗布短衣走进十万人的军门。<br>
> 他做成的事不是说了什么大话，是**在对方停下来的地方，看见了对方的心**。
