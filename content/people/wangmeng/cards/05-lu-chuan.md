# 复习卡 · 故事 05 · 潞川

> 原则：**问动机，不问年代。**

---

## 故事 05 · 潞川（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇的次序是什么？**

答：**受命、两城、烧粮、誓师、一场交易、战果、迎驾、名籍。**

| 段 | 事 |
|---|---|
| `020` | 慕容垂来投，他主张除之，苻坚不听 |
| `022` | 太和五年受命，苻坚送至霸东 |
| `024` | 攻壶关、晋阳；慕容评率四十余万屯潞川 |
| `025` | 夜烧辎重，渭原誓师 |
| `026` | 邓羌索司隶，装睡不接令，驰许，冲阵 |
| `027` | 评众大败 |
| `028` | 苻坚到安阳，问他何以临敌弃众 |
| `029` | 邺陷，阅名籍 |

**八段里他自己动手的只有两处：烧粮、誓师。其余都是别人在动，他在等。**

| | |
|---|---|
| 依据 | `022`「堅親送猛於霸東」；`025`「夜從間道出評營後」；`026`「猛馳就許之」；`028`「猛潛至安陽迎堅」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的主角是四十万人的不动，不是他的勇 |

---

### 卡 2 · 动机 ★

**问：四十余万屯在潞川，为什么不动？**

答：**底本只给了五个字。**

```
評憚猛不敢進
```

| 有的 | 没有的 |
|---|---|
| 一个「憚」字 | 憚的是哪一件事 |
| 一个「不敢進」 | 有没有人催过他 |

后面 `025` 才补上一句：慕容暐「遣使讓評，催之速戰」。**催促是从对面来的，不是从他这边来的。**

| | |
|---|---|
| 依据 | `024`「評憚猛不敢進，屯於潞川」；`025`「暐懼，遣使讓評，催之速戰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 人数在这一篇里第一次不解决问题；四十万的分量被五个字泄掉了 |

---

### 卡 3 · 细节 ★

**问：对付这四十万人，他下了几手？**

答：**三手，顺序不能换。**

| 手 | 动作 | 打的是哪里 |
|---|---|---|
| 一 | 郭庆率五千锐卒夜出间道，傍山放火，烧其辎重 | 粮 |
| 二 | 等慕容暐遣使催战 | 对面的朝廷 |
| 三 | 渭原誓众，「破釜棄糧」 | 自己的兵心 |

**第一手断他的后，第二手等他自己乱，第三手才轮到自己人。**

| | |
|---|---|
| 依据 | `025`「遣遊擊郭慶以銳卒五千，夜從間道出評營後，傍山起火，燒其輜重，火見鄴中」；同段「破釜棄糧，大呼競進」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「火見鄴中」——火光要照到邺城，这一手才成立 |

---

### 卡 4 · 因果 ★

**问：邓羌要司隶，后面那四步是怎么走的？**

答：**开价、压价、装睡、驰许。**

| 步 | 原文 | 谁让的 |
|---|---|---|
| 一 | 若以司隸見與者，公無以為憂 | 邓羌开价 |
| 二 | 此非吾之所及也。必以安定太守、萬戶侯相處 | 王猛压价 |
| 三 | 羌寢而弗應 | 邓羌装睡 |
| 四 | 猛馳就許之 | 王猛让步 |

**然后才是「大飲帳中」与「馳入評軍」。底本照写，不加褒贬。**

| | |
|---|---|
| 依据 | `026`「羌曰：若以司隸見與者，公無以為憂」；同段「猛馳就許之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一支能打仗的军队，靠的不只是号令，还有交换 |

---

### 卡 5 · 细节

**问：「破釜棄糧」是在什么时候做的？**

答：**誓师的时候，不是被逼到绝路的时候。**

`025` 记他在渭原列阵誓众，说完那一段话，「眾皆勇奮，破釜棄糧，大呼競進」。

| 顺序 | 事 |
|---|---|
| 一 | 誓众：宜各勉进，不可退也 |
| 二 | 众勇奋 |
| 三 | 破釜弃粮 |
| 四 | 大呼竞进 |

**砸锅丢粮是主动做的，做在冲锋之前。**

| | |
|---|---|
| 依据 | `025`「乃陣于渭原而誓眾曰……眾皆勇奮，破釜棄糧，大呼競進」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一手是用来断自己退路的；底本把它记在「勇奮」之后 |

---

### 卡 6 · 因果

**问：苻坚问他「何以臨敵而棄眾」，他怎么答？**

答：**他把周亚夫这个标准顶回去了。**

| 苻坚的标准 | 他的回答 |
|---|---|
| 昔亚夫不出军迎汉文 | 前卻人主，以此而為名將，竊未多之 |
| 将军何以临敌而弃众 | 监国沖幼，銮驾远临，脱有不虞，其如宗庙何 |

**「以抵触人主而成名将，我不推重」——这一答把「忠」换了一个方向。**

| | |
|---|---|
| 依据 | `028`「昔亞夫不出軍迎漢文，將軍何以臨敵而棄眾也」；同段「前卻人主，以此而為名將，竊未多之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 他不是在辩礼节，是在说：皇帝的安全比「名将的规矩」重要 |

---

### 卡 7 · 结构

**问：邺城破了以后，底本给的是什么？**

答：**不是战功，是户口册。**

| 项 | 数 |
|---|---|
| 郡 | 一百五十七 |
| 县 | 一千五百七十九 |
| 户 | 二百四十五万余 |
| 口 | 九百九十八万余 |

四个数字一路排下来。**一个国家灭亡的样子，就是这几行账。**

| | |
|---|---|
| 依据 | `029`「堅入鄴宮，閱其名籍」；同段四组数字 |
| 标记 | ◆ 出自原文 |
| 考点 | 收在名籍而不是战果，是底本自己的取舍 |

---

### 卡 8 · 叙述

**问：邓羌要的司隶，最后给了他吗？**

答：**这一篇没有说。**

`026` 记到「猛馳就許之」为止；后面 `027` 是战果，`028` 是迎驾，`029`、`030` 是封赏——**受封的是王猛，不是邓羌的司隶。**

| | |
|---|---|
| 依据 | `030`「以王猛為使持節、都督關東六州諸軍事、車騎大將軍、開府儀同三司、冀州牧、鎮鄴」 |
| 标记 | — 不回答 |
| 考点 | 「许之」是阵前的话；战后有没有兑现，本篇不记 |

---

> **这一篇的读法：** 四十万人不动，一支偏师要价。<br>
> 他打赢的不是一场仗，是**把每一个不肯动的人，都推到了该动的位置上**。
