# 复习卡 · 故事 03 · 整顿吏治

> 原则：**问动机，不问年代。**

---

## 故事 03 · 整顿吏治（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：樊世之死，走了几步？**

答：**三步，一步比一步紧。**

| 步 | 动作 | 谁做的 |
|---|---|---|
| 一 | 当众辱他，扬言悬其头于长安城门 | 樊世 |
| 二 | 把这话原样递上去 | 王猛 |
| 三 | 「必須殺此老氐，然後百僚可整」 | 苻坚 |

**三步走完，杀人的许可已经在皇帝嘴里。** 后面那场「杨璧尚主」的问答，只是执行。

| | |
|---|---|
| 依据 | `012`「世大怒曰：要當懸汝頭于長安城門」→「猛言之於堅，堅怒曰：必須殺此老氐，然後百僚可整」 |
| 标记 | ◆ 出自原文 |
| 考点 | 他先被羞辱、被威胁，然后才动手，而且每一步都在皇帝眼前 |

---

### 卡 2 · 动机 ★

**问：樊世是氐豪、有大功于苻氏，为什么还是死了？**

答：**因为他骂到了「二天子」这句话上。**

| 樊世说 | 犯的是什么 |
|---|---|
| 君無汗馬之勞，何敢專管大任 | 争权 |
| 楊璧，臣之婿也，婚已久定 | 争婚 |
| 要當懸汝頭于長安城門 | 威胁朝臣 |

苻坚先问「吾欲以楊璧尚主」，樊世勃然，王猛随即接上去问罪。**一问、一怒、一骂，命就丢了。**

| | |
|---|---|
| 依据 | `012`「吾欲以楊璧尚主，璧何如人也」→「世勃然曰」→「堅由此發怒，命斬之於西廄」 |
| 标记 | ○ 合理推演 |
| 考点 | 这三句里最要命的是「是為二天子」——争婚被读成争位 |

---

### 卡 3 · 细节 ★

**问：「耕稼」与「宰夫」，差在哪里？**

答：**差一等，而且是他故意降的。**

| 樊世说 | 他答 |
|---|---|
| 是為我耕稼而君食之乎 | 方當使君為宰夫，安直耕稼而已 |

樊世把他比作吃白食的；他反过来把对方从种地的降成做饭的。**一句话把等级倒过来。**

| | |
|---|---|
| 依据 | `012`「是為我耕稼而君食之乎」；同段「方當使君為宰夫，安直耕稼而已」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这不是骂回去，是把对方的身份往下按了一格 |

---

### 卡 4 · 因果 ★

**问：强德是皇后之弟，为什么杀了还要陈尸于市？**

答：**因为要让人看见。**

`013` 先写他的身份与行径：「健妻之弟也，昏酒豪橫，為百姓之患」；再写两个动作：捕而杀之，陈尸于市。

**杀是给强德，陈尸是给所有人。** 紧接着就是「百僚震肅，豪右屏氣」。

| | |
|---|---|
| 依据 | `013`「猛捕而殺之，陳屍於市」；同段「於是百僚震肅，豪右屏氣」 |
| 标记 | ○ 合理推演 |
| 考点 | 与樊世「斬之於西廄」对照：一个在宫里就地处置，一个摆到市上示众 |

---

### 卡 5 · 结构

**问：「歲中五遷」之后，他做了什么？**

答：**辞。**

| 段 | 记的是 |
|---|---|
| `014` 前半 | 一年五迁，权倾内外，宗戚旧臣都忌恨他 |
| `014` 中段 | 仇腾、席宝谮毁，苻坚黜二人，此后无人敢言 |
| `014` 末 | 迁尚书令、太子太傅；又转司徒、录尚书事——「猛辭以無功，不拜」 |

**一个三十六岁、一年五迁、权倾内外的人，最后一次升官时说的是「我没有功」。**

| | |
|---|---|
| 依据 | `014`「時猛年三十六，歲中五遷，權傾內外」；同段「猛辭以無功，不拜」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这话是真心还是程序，底本不写；它只把「五迁」与「不拜」放在同一段里 |

---

### 卡 6 · 细节

**问：「特進」「氐豪」各指什么？**

答：**一个加官名，一个族群身份。**

| 词 | 意思 | 为什么重要 |
|---|---|---|
| 特進 | 加官名，位次三公，多给勋旧 | 樊世、强德都以此身份横行 |
| 氐豪 | 氐族上层 | 前秦是氐人立的国，开国靠的就是这批人 |

**所以这一篇动的不是官场，是立国的本族。**

| | |
|---|---|
| 依据 | `012`「特進樊世，氐豪也，有大勳於苻氏」；`013`「其特進強德，健妻之弟也」 |
| 标记 | ○ 训释 |
| 考点 | 被杀的两个都是特进：一个是勋旧，一个是外戚 |

---

### 卡 7 · 叙述

**问：「吾今始知天下之有法也」应该怎么读？**

答：**这句话是皇帝说的，而且反着读才完整。**

| 正面 | 反面 |
|---|---|
| 今天才知道天下有法 | 此前没有法 |
| 天子之為尊 | 此前天子的亲戚也在法外 |

说这话的人是氐族的天王，被杀的是他自家亲戚。**底本把这句话放在「路不拾遺，風化大行」之后。**

| | |
|---|---|
| 依据 | `013`「吾今始知天下之有法也，天子之為尊也」 |
| 标记 | ○ 合理推演 |
| 考点 | 夸的是法与尊，不全是夸人；这句感叹里有一半是自嘲 |

---

> **这一篇的读法：** 三段，两场死。<br>
> 要紧的不是他敢杀谁，是**每一步都在皇帝眼前，许可从皇帝嘴里出来**。
