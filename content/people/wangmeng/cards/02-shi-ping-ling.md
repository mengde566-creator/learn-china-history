# 复习卡 · 故事 02 · 始平令

> 原则：**问动机，不问年代。**

---

## 故事 02 · 始平令（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇的四段，各在办什么事？**

答：**一夜政变，一次改元，一个县，一场殿上对答。**

| 段 | 事 | 结果 |
|---|---|---|
| `008` | 云龙门之夜：壮士数百潜入，宿卫放下兵器 | 苻生被废为越王，俄而被杀 |
| `009` | 升平元年僭称大秦天王 | 诛幸臣二十余人，赦境内，改元永兴 |
| `010` | 分官：他与薛赞同掌机密 | 中书侍郎 |
| `011` | 转始平令；鞭杀一吏；槛车下狱；殿上对答 | 赦 |

前两段是背景，后两段才是正题。**底本没有一句话解释他为什么被放到那个县。**

| | |
|---|---|
| 依据 | `008`「潛入雲龍門……廢之為越王，俄而殺之」；`009`「改元曰永興」；`010`「與猛、贊並掌機密」；`011`「乃轉猛為始平令」 |
| 标记 | ◆ 出自原文 |
| 考点 | 一个刚杀过二十几个人的新朝，把一个掌机密的人派去治豪强横行的县——这个安排本身就是答案 |

---

### 卡 2 · 动机 ★

**问：他为什么到任就杀人？**

答：**因为他把这里定性为「乱邦」。**

| 苻坚的说法 | 他的说法 |
|---|---|
| 为政之体，德化为先 | 宰宁国以礼，治乱邦以法 |
| 莅任未几而杀戮无数，何其酷也 | 始杀一奸，余尚万数 |

**他不是在替自己辩，是在换一个前提**：你说的是宁国，我这里不是。

| | |
|---|---|
| 依据 | `011`「為政之體，德化為先」→「臣聞宰甯國以禮，治亂邦以法」 |
| 标记 | ○ 合理推演 |
| 考点 | 「治亂邦以法」不是反对德化，是说这地方不适用；这是把自己的做法重新定性 |

---

### 卡 3 · 细节 ★

**问：「宰甯國以禮，治亂邦以法」这两句怎么对读？**

答：**把两种局面，分给两种办法。**

| 句 | 局面 | 办法 |
|---|---|---|
| 宰甯國以禮 | 安定的国家 | 礼 |
| 治亂邦以法 | 混乱的地方 | 法 |

这十个字是全篇的骨架。**他要的不是「可以杀人」，是「这里该用另一套」。**

| | |
|---|---|
| 依据 | `011`「臣聞宰甯國以禮，治亂邦以法」 |
| 标记 | ◆ 出自原文 |
| 考点 | 后面那句「余尚萬數」是这十个字的证据，不是求情 |

---

### 卡 4 · 因果 ★

**问：为什么下狱，又为什么赦？**

答：**下狱走的是程序，赦走的是皇帝的一句话。**

| 动作 | 谁做的 |
|---|---|
| 鞭杀一吏 | 他 |
| 上书讼之 | 始平百姓 |
| 劾奏、槛车征下廷尉诏狱 | 有司 |
| 亲问 | 苻坚 |
| 赦之 | 苻坚 |

**中间那一段答话，是他唯一一次开口的机会。**

| | |
|---|---|
| 依据 | `011`「百姓上書訟之，有司劾奏，檻車征下廷尉詔獄」；同段「於是赦之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 下狱不是皇帝点的头，是程序；赦是皇帝点的头。两件事分量不同 |

---

### 卡 5 · 细节

**问：「檻車」「廷尉詔獄」各是什么？**

答：**装囚犯的木笼车；奉诏治罪的牢狱。**

| 词 | 意思 | 为什么重要 |
|---|---|---|
| 檻車 | 囚车 | 一个县令被装进囚车押走，全郡都看得见 |
| 廷尉詔獄 | 廷尉掌刑狱，诏狱是奉诏治罪之狱 | 这不是普通传唤 |

| | |
|---|---|
| 依据 | `011`「檻車征下廷尉詔獄」 |
| 标记 | ○ 训释 |
| 考点 | 这两个词说明事情已经出了县，到了朝廷手里 |

---

### 卡 6 · 结构

**问：始平为什么难治？**

答：**因为那里的人不是本地编户。**

`011` 一句话交代：「多枋頭西歸之人，豪右縱橫，劫盜充斥」。

| 词 | 意思 |
|---|---|
| 枋頭西歸之人 | 从枋头西来的流民，带着武装与旧部 |
| 豪右 | 地方大族 |
| 劫盜充斥 | 抢掠公然发生 |

**三句一层比一层具体。底本不解释这批人为什么聚在这里。**

| | |
|---|---|
| 依据 | `011`「時始平多枋頭西歸之人，豪右縱橫，劫盜充斥」 |
| 标记 | ○ 训释 |
| 考点 | 他面对的是一群有组织的流民武装，不是一个普通的县 |

---

### 卡 7 · 叙述

**问：「余尚萬數」四个字应该怎么读？**

答：**不是求情，是报账。**

```
始杀一奸      已经办了一个
余尚万数      该办的还有上万
```

**这句话把「杀戮无数」换成了「还没办完」。** 后面接的那句「酷政之刑，臣實未敢受之」，是拒绝这个名目。

| | |
|---|---|
| 依据 | `011`「始殺一奸，余尚萬數」；同段「酷政之刑，臣實未敢受之」 |
| 标记 | ○ 合理推演 |
| 考点 | 他认「翦除凶猾」，不认「酷政」；两句话必须连着读 |

---

> **这一篇的读法：** 一个县，一场对答。<br>
> 他赢的不是辩才，是**把「我已经杀了人」改成了「我还没杀完」**。
