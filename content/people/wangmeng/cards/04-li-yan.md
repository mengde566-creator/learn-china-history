# 复习卡 · 故事 04 · 智取李儼

> 原则：**问动机，不问年代。**

---

## 故事 04 · 智取李儼（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里有几方人马？**

答：**三方，各走一步。**

| 一方 | 这一步 | 结果 |
|---|---|---|
| 前秦 | 遣他与姜衡、邵羌讨敛岐于略阳 | 敛岐被擒 |
| 张天锡 | 引师而还 | 侧翼的压力撤了 |
| 李儼 | 凭城未出 | 最后只剩下他 |

三步走完，局面收紧到一个人身上。**正题从「憑城未出」四个字开始。**

| | |
|---|---|
| 依据 | `015`「羌斂岐叛堅，自稱益州刺史，率部落四千餘家西依張天錫叛將李儼」；`016`「邵羌擒斂岐于白馬，送之長安。天錫遂引師而歸」 |
| 标记 | ◆ 出自原文 |
| 考点 | 敛岐、张天锡、李儼原是连在一起的三方；前两步是拆这条链子 |

---

### 卡 2 · 动机 ★

**问：他去敲李俨的门，为什么要换成白衣、小车？**

答：**因为这一身行头不像是来打仗的。**

| 常规 | 这一回 |
|---|---|
| 甲胄、戎车 | 服白、乘舆 |
| 大军压城 | 從數十人 |
| 攻 | 請與相見 |

**底本只写他换了什么，不写他为什么换。** 「未及設備」四个字是结果。

| | |
|---|---|
| 依据 | `016`「猛乃服白乘輿，從數十人，請與相見。儼開門延之，未及設備」 |
| 标记 | ○ 合理推演 |
| 考点 | 后人读作「示无兵意」；底本没有这句解释，它只给行头与结果 |

---

### 卡 3 · 细节 ★

**问：「未及設備」之后，紧接着是哪一句？**

答：**「而將士續入」。**

| 时序 | 原文 |
|---|---|
| 一 | 儼開門延之 |
| 二 | 未及設備 |
| 三 | 而將士續入 |
| 四 | 遂虜儼而還 |

四步一口气写完，中间没有一战。**前面三步是为第四步铺的。**

| | |
|---|---|
| 依据 | `016`「儼開門延之，未及設備，而將士續入，遂虜儼而還」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「續入」是陆续进来，不是一次冲进来；这三个字才是这一局的机关 |

---

### 卡 4 · 因果 ★

**问：蒲阪城下，他为什么闭垒不出？**

答：**因为要对方以为他怯。**

| 动作 | 对方的反应 |
|---|---|
| 苻柳出挑战，猛閉壘不應 | 柳以猛為憚己 |
| 柳留世子守城，自率二万攻长安 | —— |
| 邓羌七千骑夜袭，他尽众邀击 | 悉俘其卒 |

**上一段他用白衣骗开一座城，这一段反过来装成不敢战。同一个手法，换了方向。**

| | |
|---|---|
| 依据 | `018`「苻柳出挑戰，猛閉壘不應。柳以猛為憚己，留其世子良守蒲阪，率眾二萬，將攻長安」 |
| 标记 | ○ 合理推演 |
| 考点 | 「閉壘」是记下来的；让他以为我怯，是从「以猛為憚己」这句反推的 |

---

### 卡 5 · 细节

**问：「各齧梨以為信」是什么做法？**

答：**咬梨为信，当时结信的一种方式。**

`017` 记苻坚派使者去劝谕，四人都咬梨为信，却都不受命，阻兵自守。

| 动作 | 意思 |
|---|---|
| 齧梨以為信 | 以咬梨立信 |
| 皆不受堅命 | 信立了，命不从 |

**一边立信，一边不奉诏——这一段写的是宗室之间的貌合神离。**

| | |
|---|---|
| 依据 | `017`「堅遣使諭之，各齧梨以為信，皆不受堅命，阻兵自守」 |
| 标记 | ○ 训释 |
| 考点 | 「信」在这里是仪式，不是承诺；底本只记仪式与结果 |

---

### 卡 6 · 结构

**问：这一篇为什么收在「傳首長安」上？**

答：**因为底本连一句评语都没给。**

| 段 | 收在 |
|---|---|
| `018` | 悉俘其卒，柳与数百骑入蒲阪 |
| `019` | 斬柳及其妻子，傳首長安；送庾于長安，殺之 |

**三个动作：破城、斩人、传首。叛乱平了就是平了。**

| | |
|---|---|
| 依据 | `019`「猛又尋破蒲阪，斬柳及其妻子，傳首長安」；同段「送庾于長安，殺之」 |
| 标记 | ○ 合理推演 |
| 考点 | 冷，是这一段的态度；底本不加褒贬，读者也不该替他加 |

---

### 卡 7 · 叙述

**问：李俨为什么开门？底本给理由了吗？**

答：**没有。**

`016` 只有六个字：「儼開門延之」。**开门是记下来的，判断没有记。**

底本也没有写他抵抗：紧接着就是「未及設備，而將士續入，遂虜儼而還」。**中间没有一战。**

| | |
|---|---|
| 依据 | `016`「儼猶憑城未出」→「儼開門延之」 |
| 标记 | — 不回答 |
| 考点 | 史书不写原因，不等于没有原因；这里不替李俨补一个 |

---

> **这一篇的读法：** 三方、一身衣服、一座门。<br>
> 他做成的事不是攻下一座城，是**让对方自己把门打开**。
