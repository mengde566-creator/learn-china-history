| 012 | 居有间，秦将樊於期得罪于秦王，亡之燕，太子受而舍之。 | 过了些时候，秦的将领樊於期得罪了秦王，逃到燕，太子接纳并让他住下。 |
| 013 | 鞠武谏曰：「不可。夫以秦王之暴而积怒于燕，足为寒心，又况闻樊将军之所在乎？是谓『委肉当饿虎之蹊』也，祸必不振矣！虽有管、晏，不能为之谋也。愿太子疾遣樊将军入匈奴以灭口。请西约三晋，南连齐、楚，北购于单于，其后乃可图也。」 | 鞠武劝谏说：「不行。秦王残暴，又对燕国积怒，已经足以让人寒心，何况听说樊将军就在这里？这好比把肉扔在饿虎经过的路上，祸患必将无法挽救。即使有管仲、晏婴，也难以谋划。请太子赶快把樊将军送到匈奴去，消除秦国借此问罪的口实；再向西联合三晋，向南联络齐、楚，向北与单于讲和，然后才可以商量对策。」 |
| 014 | 太子曰：「太傅之计，旷日弥久，心惛然，恐不能须臾。且非独于此也，夫樊将军穷困于天下，归身于丹，丹终不以迫于强秦而弃所哀怜之交，置之匈奴，是固丹命卒之时也。愿太傅更虑之。」 | 太子说：「太傅的计策，费时很久，我心里昏乱，恐怕不能等待片刻。况且不只是为了这个，那樊将军在天下走投无路，把自身托付给丹，丹终究不会因为被强秦逼迫就抛弃所哀怜的朋友，（把他）放到匈奴去，这本来就是丹命终的时候。希望太傅再考虑这件事。」 |
| 015 | 鞠武曰：「夫行危欲求安，造祸而求福，计浅而怨深，连结一人之后交，不顾国家之大害，此所谓『资怨而助祸』矣。夫以鸿毛燎于炉炭之上，必无事矣。且以雕鸷之秦，行怨暴之怒，岂足道哉！燕有田光先生，其为人智深而勇沉，可与谋。」 | 鞠武说：「冒险却想求安定，招祸却想求福，计谋浅而结怨深，为一人的交情不顾国家的大害，这就是助长怨恨、增添祸患。把鸿毛放在炉炭上烧，必定什么也剩不下；何况面对如猛禽般凶猛的秦国，激起它的怨怒，又有什么可说的！燕国有位田光先生，智谋深而勇气沉，可以与他商议。」 |

| 040 | 「夫樊将军，秦王购之金千斤，邑万家。诚得樊将军首与燕督亢之地图，奉献秦王，秦王必说见臣，臣乃得有以报。」 | 「秦王正悬赏樊将军：赏金一千斤、封邑一万户。如果能得到樊将军的头和燕国督亢的地图，献给秦王，他一定会高兴地接见我，我也就有机会报效太子。」（督亢为燕地；这是荆轲提出的取信办法。） |
| 041 | 太子曰：「樊将军穷困来归丹，丹不忍以己之私而伤长者之意，愿足下更虑之！」 | 太子说：「樊将军走投无路来归附丹，丹不忍心因为自己的私心而伤害长者的心意，希望足下再考虑这件事！」 |
| 042 | 荆轲知太子不忍，乃遂私见樊於期曰：「秦之遇将军可谓深矣，父母宗族皆为戮没。今闻购将军首金千斤，邑万家，将奈何？」 | 荆轲知道太子不忍心，便私下去见樊於期，说：「秦国对待将军够狠了，父母宗族都遭了杀戮、没入官府的祸。如今又听说悬赏将军的首级，赏金一千斤、封邑一万户，将军打算怎么办？」 |
| 043 | 於期仰天太息流涕曰：「於期每念之，常痛于骨髓，顾计不知所出耳！」 | 於期仰天长长叹息流泪说：「於期每次想到这些，常常痛到骨髓，只是想不出计策从哪里出罢了！」 |
| 044 | 荆轲曰：「今有一言可以解燕国之患，报将军之仇者，何如？」於期乃前曰：「为之奈何？」 | 荆轲说：「如今有一句话可以解除燕国的祸患、报将军的仇，怎么样？」於期于是上前说：「为这件事怎么办？」 |
| 045 | 荆轲曰：「愿得将军之首以献秦王，秦王必喜而见臣，臣左手把其袖，右手揕其匈，然则将军之仇报而燕见陵之愧除矣。将军岂有意乎？」 | 荆轲说：「我想取得将军的首级献给秦王，秦王一定会高兴地接见我。我左手抓住他的袖子，右手刺他的胸膛，这样将军的仇就报了，燕国受欺凌的耻辱也消除了。将军可有此意？」 |
| 046 | 樊於期偏袒扼腕而进曰：「此臣之日夜切齿腐心也，乃今得闻教！」遂自刭。 | 樊於期袒露一边臂膀，握住手腕，上前说：「这正是我日夜切齿痛心的事，如今才听到您的指教！」于是自刭。（腐心在此形容激愤痛心；《索隐》说明「皆奋怒之意也」，不作心脏腐烂的生理描述。） |
| 047 | 太子闻之，驰往，伏尸而哭，极哀。既已不可奈何，乃遂盛樊於期首函封之。 | 太子听到这件事，驰马前往，伏在尸上而哭，极为哀痛。已经无可奈何，于是便把樊於期的头装进匣子封起来。 |
