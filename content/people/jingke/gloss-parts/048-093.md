| 048 | 于是太子豫求天下之利匕首，得赵人徐夫人匕首，取之百金，使工以药焠之，以试人，血濡缕，人无不立死者。 | 太子预先访求天下锋利的匕首，得到赵国人徐夫人的匕首，用百金购下，让工匠以毒药浸染刀刃，再拿人试验。只要出血足以沾湿丝缕，受试者便立刻死去。（《索隐》释焠为染；《集解》释血濡缕为血出足以沾濡丝缕。徐是姓、夫人是名，《索隐》明指男子。） |
| 049 | 乃装为遣荆卿。燕国有勇士秦舞阳，年十三，杀人，人不敢忤视。乃令秦舞阳为副。 | 于是整治行装，准备派荆轲出发。燕国勇士秦舞阳十三岁时杀过人，人们不敢正眼看他。太子命他做副手。（十三岁记的是杀人旧事，不能据此锁定出使时的年龄。） |

| 055 | 至易水之上，既祖，取道，高渐离击筑，荆轲和而歌，为变徵之声，士皆垂泪涕泣。 | 到了易水之上，已经祭祀了路神（祖：出行前祭路神的礼），上路，高渐离击筑（筑：一种以竹尺击弦的弦乐器），荆轲应和着唱歌（和：跟着唱），作变徵之声（变徵：古代七音之一，音调悲凉），士人都垂下眼泪哭泣。 |
| 056 | 又前而为歌曰：「风萧萧兮易水寒，壮士一去兮不复还！」 | 又上前而唱歌说：「风萧萧兮易水寒，壮士一去兮不复还！」 |
| 057 | 复为羽声忼慨，士皆瞋目，发尽上指冠。 | 又作羽声（羽声：古代五音之一，音调激昂），忼慨（音义同「慷慨」），士人都瞪大眼睛，头发尽向上顶起帽子。 |
| 058 | 于是荆轲就车而去，终已不顾。 | 于是荆轲上车而离去，始终不回头。 |
| 059 | 遂至秦，持千金之资币物，厚遗秦王宠臣中庶子蒙嘉。 | 荆轲到了秦国，带着价值千金的财物礼品，厚赠秦王宠臣中庶子蒙嘉。（中庶子为本段所列官名；此处明确其为秦王宠臣，不套用后世官制补成此时某位太子的属官。） |
| 060 | 嘉为先言于秦王曰：「燕王诚振怖大王之威，不敢举兵以逆军吏，愿举国为内臣，比诸侯之列，给贡职如郡县，而得奉守先王之宗庙。恐惧不敢自陈，谨斩樊於期之头，及献燕督亢之地图，函封，燕王拜送于庭，使使以闻大王。唯大王命之。」 | （他）先向秦王进言说：「燕王确实震惧大王的威势，不敢起兵来迎击军吏，愿意全国上下做内臣，排在诸侯之列，供给贡赋职事如同郡县，而得以奉守先王的宗庙。恐惧不敢自己陈说，谨斩下樊於期的头，以及献上燕国督亢（督亢：燕国富饶之地，在今河北涿州一带）的地图，用匣子封好，燕王在庭中拜送，派使者来禀告大王。唯听大王的命令。」 |
| 061 | 秦王闻之，大喜。乃朝服，设九宾，见燕使者咸阳宫。 | 秦王听后大喜，穿着朝服，设九宾之礼，在咸阳宫接见燕使。（九宾是这里隆重接见的礼名；《正义》引刘说以文物齐备解释，不据礼名补出现场恰有九名传呼官。） |
| 062 | 荆轲奉樊於期头函，而秦舞阳奉地图柙，以次进。 | 荆轲捧着樊於期的头匣，而秦舞阳捧着地图柙（柙：木匣），按次序前进。 |
| 063 | 至陛，秦舞阳色变振恐，群臣怪之。 | 到了台阶下（陛：宫殿的台阶），秦舞阳脸色变了，震动恐惧，群臣觉得他奇怪。 |
| 064 | 荆轲顾笑舞阳，前谢曰：「北蕃蛮夷之鄙人，未尝见天子，故振慴。愿大王少假借之，使得毕使于前。」 | 荆轲回头朝秦舞阳笑了笑，上前谢罪说：「他是北方偏远之地的人，不曾见过天子，所以害怕。请大王稍加宽容，让他在您面前完成使命。」（这是荆轲对秦王的说辞；笑本身不直接等于嘲笑。） |
| 065 | 秦王谓轲曰：「取舞阳所持地图。」 | 秦王对轲说：「取舞阳所拿的地图。」 |
| 066 | 轲既取图奏之，秦王发图，图穷而匕首见。 | 轲已经取了地图献上它，秦王展开地图，地图到尽头而匕首出现。 |
| 067 | 因左手把秦王之袖，而右手持匕首揕之。未至身，秦王惊，自引而起，袖绝。 | 于是左手抓住秦王的衣袖，而右手拿着匕首刺他。还没有到身上，秦王惊，自己挣着起身，衣袖断了。 |
| 068 | 拔剑，剑长，操其室。时惶急，剑坚，故不可立拔。 | 秦王拔剑，剑长，他握住剑鞘。当时仓促惶急，剑又紧，不能立即拔出。（《索隐》释室为鞘；不添剑锁、机关或别的故障。） |
| 069 | 荆轲逐秦王，秦王环柱而走。 | 荆轲追赶秦王，秦王绕着柱子跑。 |
| 070 | 群臣皆愕，卒起不意，尽失其度。而秦法，群臣侍殿上者不得持尺寸之兵；诸郎中执兵皆陈殿下，非有诏召不得上。 | 群臣都惊愕，仓促（卒：同「猝」）发生出乎意料，都失去了他们的常态。而秦国的法律，群臣侍立在殿上的不得拿一尺寸的兵器；各郎中（郎中：宫廷侍卫官）拿着兵器都排列在殿下，不是有诏令召见不得上殿。 |
| 071 | 方急时，不及召下兵，以故荆轲乃逐秦王。而卒惶急，无以击轲，而以手共搏之。 | 正当紧急的时候，来不及召殿下（下：指殿下）的兵，因此荆轲竟追赶秦王。而仓促惶急，没有用来击杀轲的东西，就用手一同与他搏斗。 |
| 072 | 是时侍医夏无且以其所奉药囊提荆轲也。 | 这时侍医（侍医：随侍君主的医官）夏无且用他所捧着的药囊掷击荆轲。 |
| 073 | 秦王方环柱走，卒惶急，不知所为，左右乃曰：「王负剑！」负剑，遂拔以击荆轲，断其左股。 | 秦王仍绕柱而走，仓促惶急，不知如何是好。左右喊：「王负剑！」秦王负剑，终于拔出剑击荆轲，砍断他的左大腿。（股：大腿。「推到背后、使前端变短以便拔剑」的具体解释出自《索隐》引王劭，不是正文另列的操作步骤。） |
| 074 | 荆轲废，乃引其匕首以擿秦王，不中，中铜柱。秦王复击轲，轲被八创。 | 荆轲受创，不能正常行动，仍举起匕首掷向秦王，没有击中，却中了铜柱。秦王又击荆轲，使他受了八处创伤。（擿与掷同；不把后来的笑骂略去而称投匕为全程最后一个动作。） |

| 076 | 于是左右既前杀轲，秦王不怡者良久。 | 于是左右的人已经上前杀了轲，秦王不高兴了很久。 |

| 078 | 于是秦王大怒，益发兵诣赵，诏王翦军以伐燕。十月而拔蓟城。 | 于是秦王大怒，增派军队前往赵国，下诏令王翦的军队来讨伐燕国。十月，攻下蓟城。 |
| 079 | 燕王喜、太子丹等尽率其精兵东保于辽东。 | 燕王喜、太子丹等人尽数率领他们的精兵向东在辽东自保。 |

| 084 | 高渐离变名姓为人庸保，匿作于宋子。 | 高渐离改换名姓做别人的庸保（庸保：受雇做工的佣人），隐藏在宋子（宋子：地名，在今河北赵县北）。 |
