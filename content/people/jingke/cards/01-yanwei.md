# 复习卡 · 故事 01 · 燕国危局

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 01 · 燕国危局（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 主题 ★

**问：早年两次冲突，荆轲的反应有什么相似与不同？**

答：**两段都记他遇到冲突后离开，起因和具体反应则不同。**

| | 在哪 | 和谁 | 起因 | 他的反应 |
|---|---|---|---|---|
| `003` | 榆次 | 盖聂 | 论剑不合，盖聂**怒而目之** | 出去，**已驾而去** |
| `004` | 邯郸 | 鲁勾践 | 博戏争道，鲁勾践**怒而叱之** | **嘿而逃去**，不复会 |

两段都写他离开；榆次一段先写他出门，后写使者发现他已驾车离去，邯郸一段则明确写「嘿而逃去」。

`003` 还记了盖聂自称以目光震慑荆轲。那是盖聂的解释，不能直接当作荆轲本人的想法。

**而这个底色，后面全用上了：** 太子丹催他、怀疑他（`051`），他这次先怒叱、说明等客的理由，再辞别出发（`052`–`053`）。

| | |
|---|---|
| 依据 | `003`、`004` |
| 标记 | ◆ 出自原文 |
| 考点 | 「连写两段」是这一篇的读法；**两段紧邻、都写遇冲突后离开，是原文的事实**——这两样要分得开 |

| 备注 | 「连写两段」这个判断是我们的；**两段紧邻、都写遇冲突后离开，是原文的事实** |
|---|---|

### 卡 2 · 陷阱题 ⚠️

**问：卫人和燕人分别怎样称呼荆轲？**

答：**卫国人叫他「庆卿」，燕国人叫他「荆卿」。**

全篇给了两个称呼，都是别人叫出来的：

| 称呼 | 谁叫的 | 依据 |
|---|---|---|
| **庆卿** | 卫国人 | `001`「卫人谓之庆卿」 |
| **荆卿** | 燕国人 | `001`「而之燕，燕人谓之荆卿」 |

「卿」是当时对人的尊称，不是名字。**但史书并非没有留下他的名字**——开篇第一句就是「荆轲者，卫人也」。

至于「庆」「荆」两字的来由，注家还有讨论（《索隐》就说过本姓或为庆、「荆」「庆」声近这一类话），**没有定论**；这里不替它下结论。

| | |
|---|---|
| 依据 | `001`「荆轲者，卫人也。其先乃齐人，徙于卫，卫人谓之庆卿。而之燕，燕人谓之荆卿。」 |
| 标记 | ◆ 出自原文 |
| 考点 | 别把两个称呼当成两个名字：一个是卫人的叫法，一个是燕人的叫法。**「史书没写他的名字」这句话也站不住——首句写的就是「荆轲」**；本姓的讨论属于注家说法 |

### 卡 3 · 结构

**问：`006`「知其非庸人也」这句话为什么重要？**

答：**它是全篇八篇故事的接线点。**

```
006  田光看出他不是平庸的人
  ↓
015  鞠武向太子丹推荐田光（「智深而勇沉」）
  ↓
016  太子丹想结识田光
  ↓
020  田光说自己老了，推荐荆轲（「所善荆卿可使也」）
  ↓
023  田光去找荆轲，转达太子的意思
  ↓
025  田光自刎，以死激荆轲
```

**从一句"他不是庸人"，长出了整条线。**

| | |
|---|---|
| 依据 | `006`「燕之处士田光先生亦善待之，知其非庸人也」 |
| 标记 | ○ 合理推演 |
| 考点 | 整条线不是从大事长出来的，是**从 `006` 那半句评语长出来的** |

### 卡 4 · 因果

**问：太子丹为什么要收留樊於期？**

答：**因为他做不出把他交出去这件事。**

鞠武劝他把樊於期送往匈奴，消除秦国责燕的口实，太子丹的回答是：

> 「夫樊将军穷困于天下，归身于丹，丹终不以迫于强秦而弃所哀怜之交，置之匈奴，**是固丹命卒之时也**。」
>
> ——那还不如让我死。

太子丹把不肯弃友作为拒绝的理由。 `013` 鞠武说的那句「委肉当饿虎之蹊」，担心的是**进一步激怒秦国**；而 `078` 那次「秦王大怒，发兵伐燕」，接在**刺秦失败之后**——不是收留樊於期招来的即时报复。

| | |
|---|---|
| 依据 | `012`、`013`、`014`、`078` |
| 标记 | ◆ 出自原文 |
| 考点 | 太子以不肯弃友回应鞠武的避祸建议；「灭口」在这里指消除口实，不是杀人 |

---

### 卡 5 · 细节

**问：鞠武提出的方案是什么？**

答：**先止损，再合纵。**

| 步骤 | 内容 |
|---|---|
| 1 | **疾遣樊将军入匈奴以灭口**——把秦国的口实拿掉 |
| 2 | 西约三晋（韩赵魏） |
| 3 | 南连齐、楚 |
| 4 | 北购于单于 |
| 5 | **「其后乃可图也」**——这以后才有得商量 |

太子丹认为这套安排「旷日弥久」，自己「恐不能须臾」。这是他对时间与局势的判断，底本没有算出方案必需多少年。

于是 `015` 鞠武给出那句评价：**「资怨而助祸。」**

| | |
|---|---|
| 依据 | `013`、`014`、`015` |
| 标记 | ◆ 出自原文 |
| 考点 | 鞠武主张先遣樊、再联络各方；太子认为不能久等。两人的判断有分歧 |

---

### 卡 6 · 对照

**问：鞠武和太子丹，分歧在哪里？**

答：**鞠武担忧激怒强秦，太子丹不肯弃友，又认为自己不能久等。**

| 人物 | 主张与理由 |
|---|---|
| 鞠武 | 送樊於期入匈奴以消除口实，再联络三晋、齐楚和单于 |
| 太子丹 | 不愿把来投的朋友送走；认为联络各方「旷日弥久」 |

《刺客列传》这段保存了双方的言辞，没有由叙述者判定哪套办法一定能救燕。后文记刺秦失败、秦军攻燕及燕亡，却没有演示鞠武方案若实施会怎样。不能由结局反推另一方案必能成功。

| | |
|---|---|
| 依据 | `013`–`016`；`078` 发兵伐燕；`082`「后五年，秦卒灭燕」 |
| 标记 | ○ 合理推演 |
| 考点 | 比较人物的理由；本段未裁定，不等于所有史书都没有评价 |

---

### 卡 7 · 动机

**问：荆轲的朋友，为什么是一个屠夫和一个乐师？**

答：**底本没有解释。但它同时记了另一件事。**

`005` 说他「爱燕之狗屠及善击筑者高渐离」，天天在市上喝酒唱歌。
`006` 紧接着说：「其为人沉深好书；**其所游诸侯，尽与其贤豪长者相结**。」

**两边都是他。**

一个和屠夫在市上又笑又哭的人，同时也在和各国贤豪长者结交。

| | |
|---|---|
| 依据 | `005`、`006` |
| 标记 | ◆ 出自原文 |
| 考点 | 屠夫乐师与诸侯贤豪**同时是他**——底本不解释，只把两面并排记下 |

| 备注 | 「为什么是这两个人」原文不答。能确认他与两类人都有交游，不能据此还原择友的全部理由 |
|---|---|

### 卡 8 · 辨析 ★

**问：盖聂的解释，能当作荆轲自己的解释吗？**

答：**不能。原文确实留有解释，但解释出自盖聂。**

`003` 盖聂说「固去也，吾曩者目摄之」，认为是自己的目光使荆轲离开；`004` 则记荆轲遭鲁勾践呵斥后「嘿而逃去」。

两段没有留下荆轲本人说明离开理由的直接引语。读者可以比较他的行为，却不能把盖聂的自信直接写成荆轲心里的恐惧，也不能据此断言他一定是在忍让。

| | |
|---|---|
| 依据 | `003` 盖聂的自述；`004`「荆轲嘿而逃去，遂不复会」 |
| 标记 | ○ 合理推演 |
| 考点 | 分清他人的解释、叙述的行为与荆轲未留下的自述 |
