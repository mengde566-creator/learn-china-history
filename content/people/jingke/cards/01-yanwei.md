# 复习卡 · 故事 01 · 燕国危局

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 01 · 燕国危局（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 主题 ★

**问：原文为什么连着写两段一模一样的事？**

答：**因为这两段是同一个动作，做了两次。**

| | 在哪 | 和谁 | 起因 | 他的反应 |
|---|---|---|---|---|
| `003` | 榆次 | 盖聂 | 论剑不合，盖聂**怒而目之** | 出去，**已驾而去** |
| `004` | 邯郸 | 鲁勾践 | 博戏争道，鲁勾践**怒而叱之** | **嘿而逃去**，不复会 |

两次冲突，两次退让，**都是同一种处理方式**。

底本没有解释为什么。它只是把这两段并排放在一起。

**而这个底色，后面全用上了：** 太子丹催他、怀疑他（`051`），他这次没有走——**他怒了**（`052`）。

| | |

| 依据 | `003`、`004` |
| 标记 | ◆ 出自原文 |
| 考点 | 「连写两段」是这一篇的读法；**两段紧邻、结构一致，是原文的事实**——这两样要分得开 |

### 卡 2 · 陷阱题 ⚠️

**问：荆轲的本名叫什么？**

答：**不知道。史书从来没写。**

全篇只给了两个称呼：

| 称呼 | 谁叫的 | 依据 |
|---|---|---|
| **庆卿** | 卫国人 | `001`「卫人谓之庆卿」 |
| **荆卿** | 燕国人 | `001`「而之燕，燕人谓之荆卿」 |

「卿」是尊称，不是名字。**那个真正的名字，史书里一个字都没有。**

| | |
|---|---|
| 依据 | `001` |
| 标记 | — 史书的沉默 |
| 考点 | 两个称呼都是别人给的。**读者要找的那个本名，底本一次都没有给过** |

### 卡 3 · 结构

**问：`006`「知其非庸人也」这句话为什么重要？**

答：**它是全篇八篇故事的接线点。**

```
006  田光看出他不是平庸的人
  ↓
015  鞠武向太子丹推荐田光（「智深而勇沉」）
  ↓
016  太子丹想结识田光
  ↓
020  田光说自己老了，推荐荆轲（「所善荆卿可使也」）
  ↓
023  田光去找荆轲，转达太子的意思
  ↓
025  田光自刎，以死激荆轲
```

**从一句"他不是庸人"，长出了整条线。**

| | |
|---|---|
| 依据 | `006`「燕之处士田光先生亦善待之，知其非庸人也」 |
| 标记 | ○ 合理推演 |
| 考点 | 整条线不是从大事长出来的，是**从 `006` 那半句评语长出来的** |

### 卡 4 · 因果

**问：太子丹为什么要收留樊於期？**

答：**因为他做不出把他交出去这件事。**

鞠武劝他把樊於期送到匈奴去「灭口」，太子丹的回答是：

> 「夫樊将军穷困于天下，归身于丹，丹终不以迫于强秦而弃所哀怜之交，置之匈奴，**是固丹命卒之时也**。」
>
> ——那还不如让我死。

**这不是一个政治判断，是一个人的判断。** 而 `013` 鞠武说的那句「委肉当饿虎之蹊」，后来应验了：`078` 秦王大怒，发兵伐燕。

| | |
|---|---|
| 依据 | `012`、`013`、`014`、`078` |
| 标记 | ◆ 出自原文 |
| 考点 | 这里做的不是政治判断。**他自己把话说到了「命卒之时」** |

---

### 卡 5 · 细节

**问：鞠武提出的方案是什么？**

答：**先止损，再合纵。**

| 步骤 | 内容 |
|---|---|
| 1 | **疾遣樊将军入匈奴以灭口**——把秦国的口实拿掉 |
| 2 | 西约三晋（韩赵魏） |
| 3 | 南连齐、楚 |
| 4 | 北购于单于 |
| 5 | **「其后乃可图也」**——这以后才有得商量 |

**这是一个要花很多年的方案。** 太子丹的回答是「旷日弥久，心惛然，恐不能须臾」——等不了。

于是 `015` 鞠武给出那句评价：**「资怨而助祸。」**

| | |
|---|---|
| 依据 | `013`、`014`、`015` |
| 标记 | ◆ 出自原文 |
| 考点 | 鞠武的方案要的是**时间**，太子丹缺的恰好是时间——分歧不在对错上 |

---

### 卡 6 · 对照

**问：鞠武和太子丹，谁说得对？**

答：**史书没有裁决。**

| | 鞠武 | 太子丹 |
|---|---|---|
| 主张 | 送走樊於期，结盟，慢慢来 | 不能弃友，等不了 |
| 理由 | 国家的存亡 | 一个人的义 |
| 结果 | 未被采纳 | 采纳了自己的 |

底本两边的话都照录，**没有一句评价**。

而结局是：太子丹收留了樊於期，秦国因此伐燕（`078`），燕国五年后灭亡（`082`）。

**但底本从没说"如果听鞠武的就好了"。**

| | |
|---|---|
| 依据 | `013`–`016`、`078`、`082` |
| 标记 | ○ 合理推演 |
| 考点 | 两边的话底本都照录，**裁决不在**。读者最容易替史书判一个胜负 |

| 备注 | 注意鞠武是**全篇唯一一个从头到尾都在说"不要"的人**，也是唯一活着到最后的人 |
|---|---|

### 卡 7 · 动机

**问：荆轲的朋友，为什么是一个屠夫和一个乐师？**

答：**底本没有解释。但它同时记了另一件事。**

`005` 说他「爱燕之狗屠及善击筑者高渐离」，天天在市上喝酒唱歌。
`006` 紧接着说：「其为人沉深好书；**其所游诸侯，尽与其贤豪长者相结**。」

**两边都是他。**

一个和屠夫在市上又笑又哭的人，同时也在和各国贤豪长者结交。

| | |
|---|---|
| 依据 | `005`、`006` |
| 标记 | ◆ 出自原文 |
| 考点 | 屠夫乐师与诸侯贤豪**同时是他**——底本不解释，只把两面并排记下 |

| 备注 | 「为什么是这两个人」原文不答。**能答的只有：他两边都要** |
|---|---|

### 卡 8 · 沉默 ★

**问：这一篇里，史书没有写的是什么？**

答：**没有写他为什么两次都走开。**

`003` 榆次，被盖聂瞪了一眼——他走了。
`004` 邯郸，被鲁勾践呵斥——他一声不吭逃了。

**两次冲突，两次退让，底本一个字都不解释。**

这是「忍」还是「怯」？是修养还是怕事？
**史书把这个判断留给了读者。**

而这一篇的 60 条问答里，**28 条是「没有回答」（47%）**——八篇里最高。

| | |
|---|---|
| 依据 | `003`、`004`；本故事全部 16 段原文 |
| 标记 | — 史书的沉默 |
| 考点 | 两次退让，底本一个字不解释。**「忍」还是「怯」是读者填的，不是史书写的** |

| 备注 | 唯一的旁证是盖聂那句话：「固去也，吾曩者目摄之。」<br>**但那是盖聂说的，不是史书的结论。** |
|---|---|
