# 复习卡 · 故事 02 · 田光之死

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 02 · 田光之死（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 主题 ★

**问：太子叮嘱保密时，田光怎样回应？**

答：**原文写他低头笑着，答了一个「诺」字。**

> 田光俯而笑曰：「诺。」

`022`「俯而笑曰」是叙述动作和引出话语的文字，不是他回答的四个字。

随后 `024` 田光对荆轲说「是太子疑光也」，交代了自己怎样理解那句叮嘱。底本没有把这个笑命名为苦笑、冷笑或讥笑。

| | |
|---|---|
| 依据 | `022`「田光俯而笑曰：诺」；`024`「是太子疑光也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动作、回答与后来解释各有所属，不替那个笑补语气 |

---

### 卡 2 · 因果 ★

**问：田光为什么选择自杀？**

答：**原文给了两层：他自己的判断，和叙述者的说明。**

```
022  太子送他到门口，叮嘱：「愿先生勿泄」
  ↓   （田光在下文说明自己的理解）
024  田光：「今太子告光曰『愿先生勿泄』，是太子疑光也。
              夫为行而使人疑之，非节侠也。」      ← 他的判断
  ↓
025  叙述：「欲自杀以激荆卿」；遗言「言光已死，明不言也」  ← 史家的说明
```

**这条链子不是后人推的，是原文给的。**

`024` 是田光自己的话：他把那句叮嘱听成了对自己的怀疑，所以说「非节侠也」。
`025` 的「欲自杀以激荆卿」是**叙述句**——史家交代他这份打算里带着激励荆轲的意思。

两层加起来，才是原文给的东西。至于他心里是否还压着别的（受辱、绝望），底本没有写。

| | |
|---|---|
| 依据 | `022`、`024`、`025` |
| 标记 | ◆ 出自原文 |
| 考点 | 这条链子**不是后人推的**：叮嘱 → `024` 的「是太子疑光也」 → `025` 的「欲自杀以激荆卿」，原文自己走完了。**但「怀疑」是田光听出来的，「激励」是史家写的——都不是太子丹的动机** |

---

### 卡 3 · 陷阱题 ⚠️

**问：荆轲后来把田光的死讯带给太子丹了吗？**

答：**带了。原文写得明明白白。**

田光的遗言说得很清楚：

> 「愿足下**急过太子，言光已死，明不言也**。」

`026` 紧接着就是：

> 「荆轲遂见太子，**言田光已死，致光之言**。」

**很多人会记成"史书没写他有没有带到"——其实写了。** 没写的是他的原话：底本只给了一句转述。

| | |
|---|---|
| 依据 | `025`、`026`「荆轲遂见太子，言田光已死，致光之言」 |
| 标记 | ◆ 出自原文 |
| 考点 | 田光用死托付的那句话，下一段第一句就说带到了。**这一篇真正的空白不在"有没有带到"，在"他怎么说的"——底本只有转述，没有原话** |

| 备注 | 田光 `025` 要他带的是「言光已死，明不言也」；`026` 记的是「言田光已死，**致光之言**」——死讯和话都带到了。 |
|---|---|

### 卡 4 · 对照

**问：太子丹对田光，是敬还是疑？**

答：**礼遇、田光的理解和太子的事后解释，都有记载。**

| 记载 | 谁的行为或说法 |
|---|---|
| `018`–`019` 迎接、倒退引路、跪而蔽席、避席请教 | 太子的礼遇 |
| `022`「愿先生勿泄」；`024`「是太子疑光也」 | 太子的叮嘱，被田光理解为怀疑 |
| `027`「欲以成大事之谋也」「岂丹之心哉」 | 太子得知死讯后，自述叮嘱的用意与非本意的后果 |

太子并非没有解释。只是他的事后自述与田光先前的理解属于不同人的话，不能合成一份已经证实的完整内心。

| | |
|---|---|
| 依据 | `018`、`019`、`022`、`024`、`027` |
| 标记 | ◆ 出自原文 |
| 考点 | 既不漏掉太子的解释，也不把人物自述当成全知裁决 |

---

### 卡 5 · 细节

**问：太子丹迎接田光时，一共做了几个动作？**

答：**`018` 连写三项；入座后，`019` 另记「避席而请」。**

| 动作 | 原话 | 意思 |
|---|---|---|
| **逢迎** | `018` | 迎出来 |
| **却行为导** | `018` | 倒退着引路 |
| **跪而蔽席** | `018` | 跪下替他拂席 |
| （入座后）**避席而请** | `019` | 离席上前请教 |

**「蔽席」是拂拭坐席。** 一个太子跪下来替客人掸席子。

迎接、入座请教、告别叮嘱，发生在会面的不同阶段。不能把整场会面的动作合计成三个。

| | |
|---|---|
| 依据 | `018`「太子逢迎，却行为导，跪而蔽席」；`019`「太子避席而请曰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 分清迎接的三项动作与入座后的避席请教 |

---

### 卡 6 · 结构

**问：田光怎样把请托转到荆轲身上？**

答：**他先推辞亲自谋划国事，推荐荆轲，再去请荆轲见太子。**

`020` 田光自述年老、精力已衰，说「所善荆卿可使也」；`021` 太子请他代为结交；`023` 田光便去邀请荆轲赴宫，荆轲答「谨奉教」。

这时答应的是赴见。荆轲正式许诺承担太子所托的国事，在 `034`，是在听完陈说、推辞而又被固请之后。

| | |
|---|---|
| 依据 | `020`–`023`；`034`「然后许诺」 |
| 标记 | ◆ 出自原文 |
| 考点 | 推荐、赴见与受命是三个步骤 |

---

### 卡 7 · 动机

**问：`025` 的「欲自杀以激荆卿」说明了什么？**

答：**说明史家交代了他这份打算，而且它是叙述句——不是田光的原话。**

原文不只记下田光自刎，还明写——

> **「欲自杀以激荆卿。」**

这七个字出自叙述句：**他想用这个死激励荆轲**。至于他是否还有别的心理，底本没有写。

他留给荆轲的那句遗言是：「言光已死，**明不言也**。」
两句话摞在一起：一个是为自己作证，一个是为荆轲加一分推力。

| | |
|---|---|
| 依据 | `025`「欲自杀以激荆卿，曰：『愿足下急过太子，言光已死，明不言也。』因遂自刎而死。」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动机**由叙述者写在原文里**，读者不用猜；但它是史家的说明，**不是田光自己说的**——把「激」字换成别的写法，这一篇的读法就全变了 |

---

### 卡 8 · 反应 ★

**问：田光死了之后，太子丹什么反应？**

答：**原文写了，而且写得很重。**

`026` 荆轲见太子，转达「言田光已死，致光之言」。紧接着 `027`：

> **「太子再拜而跪，膝行流涕，有顷而后言曰：『丹所以诫田先生毋言者，欲以成大事之谋也。今田先生以死明不言，岂丹之心哉！』」**

**再拜、跪、膝行、流涕**——一串动作，然后是那句话：**「难道是丹的本心吗！」**

这不是空白。他当着荆轲的面哭，并自述保密叮嘱是为成大事，田光以死明不言并非自己本意。 这句是辩解还是自责，底本不裁决。随后 `028` 他向荆轲陈说国事。

| | |
|---|---|
| 依据 | `026`「言田光已死，致光之言」；`027`「太子再拜而跪，膝行流涕……岂丹之心哉！」 |
| 标记 | ◆ 出自原文 |
| 考点 | 田光的死**有下文**：`027` 细写太子得知死讯后的动作与言语，随后 `028` 他向荆轲陈说燕国处境。**「岂丹之心哉」是辩解还是自责，史书不回答** |
