# 复习卡 · 故事 02 · 田光之死

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 02 · 田光之死（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 主题 ★

**问：田光临死前，太子丹说了什么？**

答：**「愿先生勿泄也。」**

而田光的回答是四个字：

> **俯而笑曰：「诺。」**

**他笑什么，底本一个字都没有写。**

这不是史书的疏漏——是这一段最要紧的地方。**笑可以是苦笑、冷笑、或者觉得荒唐。原文把这个判断留给了你。**

| | |
|---|---|
| 依据 | `022`「太子送至门，戒曰：『丹所报，先生所言者，国之大事也，愿先生勿泄也！』田光俯而笑曰：『诺。』」 |
| 标记 | ○ 合理推演 |
| 考点 | 太子丹说了什么，底本一字不差地记着；**田光那个笑是什么意思，底本一个字都没给** |

---

### 卡 2 · 因果 ★

**问：田光为什么必须死？**

答：**因为原文自己走完了这条链子。**

```
022  太子送他到门口，叮嘱：「愿先生勿泄」
  ↓   （底本没有写中间的推理）
024  田光：「今太子告光曰『愿先生勿泄』，是太子疑光也。
              夫为行而使人疑之，非节侠也。」
  ↓
025  「欲自杀以激荆卿」
```

**这条链子不是后人推的，是原文给的。**

而且要注意 `025` 那六个字：**「欲自杀以激荆卿」**——**动机是原文明写的。**

他同时做了两件事：证明自己没说出去，以及让荆轲没有退路。

| | |
|---|---|
| 依据 | `022`、`024`、`025` |
| 标记 | ◆ 出自原文 |
| 考点 | 这条链子**不是后人推的**：叮嘱 → `024` 的「是太子疑光也」 → `025` 的「欲自杀以激荆卿」，原文自己走完了 |

---

### 卡 3 · 陷阱题 ⚠️

**问：荆轲后来把田光的死讯带给太子丹了吗？**

答：**不知道。底本没写。**

田光的遗言说得很清楚：

> 「愿足下**急过太子，言光已死，明不言也**。」

但《史记》此后**没有记载荆轲是否转达了这句话**——原文从 `025` 直接跳到后面的事。

**一个人用死托付的一句话，史书没写它有没有被带到。**

| | |
|---|---|
| 依据 | `025` 之后底本未载荆轲见太子时的言语 |
| 标记 | — 史书的沉默 |
| 考点 | 一个人用死托付的一句话，底本没有交代它有没有被带到——**沉默不只在没人关心的地方，也在转折处** |

| 备注 | 这一条和「燕太子丹质秦」那种沉默不同——<br>**它不是"史书不关心"，是"史书在这里转了个弯"** |
|---|---|

### 卡 4 · 对照

**问：太子丹对田光，是敬还是疑？**

答：**两样都是原文写的，而且写在同一场会面里。**

| 顺序 | 原文 | 性质 |
|---|---|---|
| `018` | 逢迎，**却行为导，跪而蔽席** | 极度的敬 |
| `019` | **避席**而请 | 极度的敬 |
| `022` | 送至门，戒曰**「愿先生勿泄」** | 明确的不信任 |

**先跪下来替他掸席子，再叮嘱他别乱说。**

原文把这两件事并排放在一段会面里，**没有做任何裁决**。哪个才是太子丹，史书不回答。

| | |
|---|---|
| 依据 | `018`、`019`、`022` |
| 标记 | ◆ 出自原文 |
| 考点 | 敬和疑**不是两场会面，是同一场会面里的两件事**——底本把两样并排记下，不裁决 |

---

### 卡 5 · 细节

**问：太子丹迎接田光时，一共做了几个动作？**

答：**三个，一个比一个低。**

| 动作 | 原话 | 意思 |
|---|---|---|
| **逢迎** | `018` | 迎出来 |
| **却行为导** | `018` | 倒退着引路 |
| **跪而蔽席** | `018` | 跪下替他拂席 |
| （入座后）**避席而请** | `019` | 离席上前请教 |

**「蔽席」是拂拭坐席。** 一个太子跪下来替客人掸席子。

原文用了三个连续的动作来写这份恭敬——**而三句话之后，他说了「勿泄」。**

| | |
|---|---|
| 依据 | `018`「太子逢迎，却行为导，跪而蔽席」；`019`「太子避席而请曰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 把三个动作按原文数一遍；**下文那句「勿泄」，就接在三个动作之后** |

---

### 卡 6 · 结构

**问：田光推辞了太子的请求，为什么不推辞荆轲？**

答：**他对两个人说的话，性质完全不同。**

| | 对太子丹 | 对荆轲 |
|---|---|---|
| 原话 | 「光**不敢**以图国事，所善荆卿可使也」 | 「愿足下**过太子于宫**」 |
| 性质 | 推辞 + 推荐 | 交付 |
| 荆轲的回答 | — | 「谨奉教」（一个字没推） |

**田光把"做不了"留给了自己，把"必须做"交给了朋友。**

`023` 他见荆轲时是**「偻行」**——弓着背走。`020` 那句「精已消亡」在这里有了身体上的落实。

| | |
|---|---|
| 依据 | `020`、`021`、`023` |
| 标记 | ○ 合理推演 |
| 考点 | 同是推辞，对两个人性质不同：**对太子是「不敢」，对荆轲是「愿足下过太子于宫」** |

---

### 卡 7 · 动机

**问：「欲自杀以激荆卿」——这句话说明了什么？**

答：**说明他的死是有目的的，而且是原文明写的。**

对比一下：如果原文只写「田光自刎而死」，那我们可以猜他是羞愧、是绝望、是抗议。
但原文写的是——

> **「欲自杀以激荆卿。」**

四个字，把动机钉死了：**他要用自己的死，把荆轲的退路堵上。**

再看他最后一句遗言：「言光已死，**明不言也**。」
两句话摞在一起：一个是为了证明自己，一个是为了逼住对方。

| | |
|---|---|
| 依据 | `025`「欲自杀以激荆卿，曰：『愿足下急过太子，言光已死，明不言也。』因遂自刎而死。」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动机写在原文里，**不用读者去猜**：把「激」字换成别的写法，这一篇的读法就全变了 |

---

### 卡 8 · 沉默 ★

**问：田光死了之后，太子丹什么反应？**

答：**底本一个字都没有。**

`025` 田光自刎。`026` 原文接的是「太子丹受而舍之」（收留樊於期）。

**中间没有任何过渡。** 太子丹是否得知、是否后悔、有没有说过什么——全部空白。

这个空白很重：**一个人说完「勿泄」的第二天，另一个人就死了。而说话的人没有下文。**

| | |
|---|---|
| 依据 | `025` 之后原文直接转入 `026` |
| 标记 | — 史书的沉默 |
| 考点 | `025` 和 `026` 之间没有任何过渡。**说完「勿泄」之后，说话的人没有下文** |
