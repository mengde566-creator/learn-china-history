# 复习卡 · 故事 02 · 田光之死

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 02 · 田光之死（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 主题 ★

**问：田光临死前，太子丹说了什么？**

答：**「愿先生勿泄也。」**

而田光的回答是四个字：

> **俯而笑曰：「诺。」**

**他笑什么，底本一个字都没有写。**

这不是史书的疏漏——是这一段最要紧的地方。**笑可以是苦笑、冷笑、或者觉得荒唐。原文把这个判断留给了你。**

| | |
|---|---|
| 依据 | `022`「太子送至门，戒曰：『丹所报，先生所言者，国之大事也，愿先生勿泄也！』田光俯而笑曰：『诺。』」 |
| 标记 | ○ 合理推演 |
| 考点 | 太子丹说了什么，底本一字不差地记着；**田光那个笑是什么意思，底本一个字都没给** |

---

### 卡 2 · 因果 ★

**问：田光为什么选择自杀？**

答：**原文给了两层：他自己的判断，和叙述者的说明。**

```
022  太子送他到门口，叮嘱：「愿先生勿泄」
  ↓   （底本没有写中间的推理）
024  田光：「今太子告光曰『愿先生勿泄』，是太子疑光也。
              夫为行而使人疑之，非节侠也。」      ← 他的判断
  ↓
025  叙述：「欲自杀以激荆卿」；遗言「言光已死，明不言也」  ← 史家的说明
```

**这条链子不是后人推的，是原文给的。**

`024` 是田光自己的话：他把那句叮嘱听成了对自己的怀疑，所以说「非节侠也」。
`025` 的「欲自杀以激荆卿」是**叙述句**——史家交代他这份打算里带着激励荆轲的意思。

两层加起来，才是原文给的东西。至于他心里是否还压着别的（受辱、绝望），底本没有写。

| | |
|---|---|
| 依据 | `022`、`024`、`025` |
| 标记 | ◆ 出自原文 |
| 考点 | 这条链子**不是后人推的**：叮嘱 → `024` 的「是太子疑光也」 → `025` 的「欲自杀以激荆卿」，原文自己走完了。**但「怀疑」是田光听出来的，「激励」是史家写的——都不是太子丹的动机** |

---

### 卡 3 · 陷阱题 ⚠️

**问：荆轲后来把田光的死讯带给太子丹了吗？**

答：**带了。原文写得明明白白。**

田光的遗言说得很清楚：

> 「愿足下**急过太子，言光已死，明不言也**。」

`026` 紧接着就是：

> 「荆轲遂见太子，**言田光已死，致光之言**。」

**很多人会记成"史书没写他有没有带到"——其实写了。** 没写的是他的原话：底本只给了一句转述。

| | |
|---|---|
| 依据 | `025`、`026`「荆轲遂见太子，言田光已死，致光之言」 |
| 标记 | ◆ 出自原文 |
| 考点 | 田光用死托付的那句话，下一段第一句就说带到了。**这一篇真正的空白不在"有没有带到"，在"他怎么说的"——底本只有转述，没有原话** |

| 备注 | 田光 `025` 要他带的是「言光已死，明不言也」；`026` 记的是「言田光已死，**致光之言**」——死讯和话都带到了。 |
|---|---|

### 卡 4 · 对照

**问：太子丹对田光，是敬还是疑？**

答：**敬写在动作里，疑写在田光的话里，而且写在同一场会面里。**

| 顺序 | 原文 | 性质 |
|---|---|---|
| `018` | 逢迎，**却行为导，跪而蔽席** | 极度的敬 |
| `019` | **避席**而请 | 极度的敬 |
| `022` | 送至门，戒曰**「愿先生勿泄」** | 田光把它听成了见疑（`024`） |

**先跪下来替他掸席子，再叮嘱他别乱说。**

原文把这两件事并排放在一段会面里，**没有做任何裁决**。太子丹有没有疑他、那是不是他的本意，史书不回答——**「是太子疑光也」是田光自己说出来的**。

| | |
|---|---|
| 依据 | `018`、`019`、`022` |
| 标记 | ◆ 出自原文 |
| 考点 | 敬和疑**不是两场会面，是同一场会面里的两件事**——底本把两样并排记下，不裁决 |

### 卡 5 · 细节

**问：太子丹迎接田光时，一共做了几个动作？**

答：**三个，一个比一个低。**

| 动作 | 原话 | 意思 |
|---|---|---|
| **逢迎** | `018` | 迎出来 |
| **却行为导** | `018` | 倒退着引路 |
| **跪而蔽席** | `018` | 跪下替他拂席 |
| （入座后）**避席而请** | `019` | 离席上前请教 |

**「蔽席」是拂拭坐席。** 一个太子跪下来替客人掸席子。

原文用了三个连续的动作来写这份恭敬——**而三句话之后，他说了「勿泄」。**

| | |
|---|---|
| 依据 | `018`「太子逢迎，却行为导，跪而蔽席」；`019`「太子避席而请曰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 把三个动作按原文数一遍；**下文那句「勿泄」，就接在三个动作之后** |

---

### 卡 6 · 结构

**问：田光推辞了太子的请求，为什么不推辞荆轲？**

答：**他对两个人说的话，性质完全不同。**

| | 对太子丹 | 对荆轲 |
|---|---|---|
| 原话 | 「光**不敢**以图国事，所善荆卿可使也」 | 「愿足下**过太子于宫**」 |
| 性质 | 推辞 + 推荐 | 交付 |
| 荆轲的回答 | — | 「谨奉教」（一个字没推） |

**田光把"做不了"留给了自己，把"必须做"交给了朋友。**

`023` 他见荆轲时是**「偻行」**——弓着背走。`020` 那句「精已消亡」在这里有了身体上的落实。

| | |
|---|---|
| 依据 | `020`、`021`、`023` |
| 标记 | ○ 合理推演 |
| 考点 | 同是推辞，对两个人性质不同：**对太子是「不敢」，对荆轲是「愿足下过太子于宫」** |

---

### 卡 7 · 动机

**问：`025` 的「欲自杀以激荆卿」说明了什么？**

答：**说明史家交代了他这份打算，而且它是叙述句——不是田光的原话。**

对比一下：如果原文只写「田光自刎而死」，那我们可以猜他是羞愧、是绝望、是抗议。
但原文写的是——

> **「欲自杀以激荆卿。」**

这七个字出自叙述句：**他想用这个死激励荆轲**。至于他是否还有别的心理，底本没有写。

他留给荆轲的那句遗言是：「言光已死，**明不言也**。」
两句话摞在一起：一个是为自己作证，一个是为荆轲加一分推力。

| | |
|---|---|
| 依据 | `025`「欲自杀以激荆卿，曰：『愿足下急过太子，言光已死，明不言也。』因遂自刎而死。」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动机**由叙述者写在原文里**，读者不用猜；但它是史家的说明，**不是田光自己说的**——把「激」字换成别的写法，这一篇的读法就全变了 |

### 卡 8 · 反应 ★

**问：田光死了之后，太子丹什么反应？**

答：**原文写了，而且写得很重。**

`026` 荆轲见太子，转达「言田光已死，致光之言」。紧接着 `027`：

> **「太子再拜而跪，膝行流涕，有顷而后言曰：『丹所以诫田先生毋言者，欲以成大事之谋也。今田先生以死明不言，岂丹之心哉！』」**

**再拜、跪、膝行、流涕**——一串动作，然后是那句话：**「难道是丹的本心吗！」**

这不是空白。**他当着荆轲的面哭，也把"我没有逼他死"说了出来。** 这句是辩解还是自责，底本不裁决。而 `028` 紧接着，这场哭就变成了请托的开场。

| | |
|---|---|
| 依据 | `026`「言田光已死，致光之言」；`027`「太子再拜而跪，膝行流涕……岂丹之心哉！」 |
| 标记 | ◆ 出自原文 |
| 考点 | 田光的死**有下文**：`027` 是太子丹全篇最重的一次失态，而 `028` 他立刻用这场死开了口。**「岂丹之心哉」是辩解还是自责，史书不回答** |
