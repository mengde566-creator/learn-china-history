# 复习卡 · 故事 07 · 图穷匕见

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 07 · 图穷匕见（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 主题 ★

**问：「事所以不成者，以欲生劫之」——荆轲临死说这句话，说的是什么？**

答：**他将失败解释为想活捉秦王、取得约契以报太子。**

太子丹最初交代的任务，原话分两层：

| 顺序 | 原话 | 意思 |
|---|---|---|
| 首选 | 诚得**劫**秦王，使悉反诸侯侵地 | 抓住他，逼他把地吐出来 |
| 退一步 | 则不可，因而**刺杀**之 | 不行，才杀 |

荆轲临死说的「欲生劫之」，正是**先选的那一层**。

**但这是他自己的说法，不是这件事的全部分析。** 现场记下来的过程还有：袖被扯断、他绕着柱子追、殿上群臣徒手扑上去、秦王拔出剑来（`067`–`073`）。这句话是他对自己任务与失败的解释；失败的全部原因，仍需与经过分别考察。

| | |
|---|---|
| 依据 | `075`「事所以不成者，以欲生劫之，必得约契以报太子也」；`032`「诚得劫秦王，使悉反诸侯侵地，若曹沫之与齐桓公，则大善矣；则不可，因而刺杀之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 临死这一句，对应的是 `032` 里的**首选那一层**——「劫」在前、「刺」在后。**但它仍是荆轲自己的说法；`032` 里「刺杀」那一层也写着，不能被这一句抹掉** |

| 备注 | 后世多把这句话读成开脱。**`032` 白纸黑字写着「劫」在前、「刺」在后，所以它并不与任务的原话相抵触**——至于它是否就是失败的全部原因，底本不回答 |
|---|---|

### 卡 2 · 因果 ★

**问：荆轲追秦王的时候，殿上那么多人，为什么拦不住他？**

答：**原文说明了众人惊愕失措，以及殿上禁兵、殿下执兵者须诏才能上殿的限制。**

```
秦法：群臣侍殿上者，不得持尺寸之兵
      诸郎中执兵，皆陈殿下，非有诏召不得上
```

于是那一刻，殿上出现了一个荒谬的局面：

| 谁 | 在哪 | 有兵器吗 | 能动手吗 |
|---|---|---|---|
| 群臣 | 殿上 | **没有** | 只能徒手 |
| 郎中 | 殿下 | 有 | **没有诏书，上不来** |
| 秦王 | 殿上 | **佩着剑**（`068` 记他拔剑，只是拔不出） | 拔剑 |

执兵郎中列于殿下，仓促间又来不及召上；殿上的群臣于是徒手共搏。

急起来来不及下诏，所以殿上的人只能「以手共搏之」。**条文管的是侍殿群臣与殿下郎中，不是连秦王也不得佩剑。**

| | |
|---|---|
| 依据 | `070`「而秦法，群臣侍殿上者不得持尺寸之兵；诸郎中执兵皆陈殿下，非有诏召不得上」；`071`「方急时，不及召下兵……而卒惶急，无以击轲，而以手共搏之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 禁兵、须诏召与仓促失措共同构成现场限制；群臣仍有徒手共搏 |

### 卡 3 · 陷阱题 ⚠️

**问：秦舞阳后来怎么样了？**

答：**本传没有交代他的结局。**

`063` 写他到陛前「色变振恐」，`064` 荆轲回头对他一笑、向秦王解释。`065` 是秦王对**荆轲**下令：「取舞阳所持地图。」取图的是荆轲，不是秦舞阳。

此后这段没有再交代秦舞阳的行动与下落。另要注意，`049` 的「年十三，杀人」说的是他十三岁时杀过人，不是说他出使时才十三岁。

| | |
|---|---|
| 依据 | `049`「年十三，杀人」；`063`–`065`，尤其「秦王谓轲曰」 |
| 标记 | — 史书未载 |
| 考点 | 明确已经发生的取图行动，再限定秦舞阳结局未载的范围 |

### 卡 4 · 结构

**问：秦王的剑，为什么拔不出来？**

答：**正文写剑长、握着剑鞘，又惶急而不能立刻拔出；左右提醒「王负剑」后，才拔了出来。**

| 正文 | 记述 |
|---|---|
| `068`「剑长，操其室」 | 剑长，握住剑鞘 |
| `068`「时惶急，剑坚，故不可立拔」 | 仓促慌乱，剑紧，不能马上拔出 |
| `073`「负剑，遂拔」 | 听从提醒后拔出了剑 |

「把剑推向背后，使前端变短而易拔」是《索隐》所引王劭的解释；佩带位置和拔剑方法的具体说明，要归在注家解释这一层。

| | |
|---|---|
| 依据 | `068`、`073`；《史记索隐》王劭释「王负剑」 |
| 标记 | ○ 训释 |
| 考点 | 区分正文记述与注家对剑鞘、负剑方法的解释 |

### 卡 5 · 细节

**问：史书明确点名、用药囊砸荆轲的人是谁？**

答：**一个捧药囊的侍医，叫夏无且。**

原文点明他的身份是侍医，所用之物是药囊。当时殿上的局面，是 `070`、`071` 两段一起定的：

| 谁 | 在哪儿 | 手里有兵器吗 | 能做什么 |
|---|---|---|---|
| 群臣（侍殿上者） | 殿上 | **不得持尺寸之兵** | 徒手 |
| 郎中（执兵者） | 殿下 | 有 | **非有诏召不得上** |
| 秦王 | 殿上 | 佩剑（`068` 记他拔剑，只是拔不出） | 拔剑 |
| 夏无且 | 殿上 | 只有手里捧的药囊 | 把药囊掷出去 |

所以 `071` 先写了殿上群臣**徒手一起扑上去**（「而以手共搏之」），`072` 才单独点出夏无且这一掷。**史书点了他的名，不等于那一刻只有他动了手，也没有足够记载说他就是第一个出手的**——被点名，是记载的选择。

事后秦王论功，单独给了他一句评价：

> 「无且**爱我**，乃以药囊提荆轲也。」

| | |
|---|---|
| 依据 | `070`「而秦法，群臣侍殿上者不得持尺寸之兵；诸郎中执兵皆陈殿下，非有诏召不得上」；`071`「方急时，不及召下兵……而卒惶急，无以击轲，而以手共搏之」；`072`「是时侍医夏无且以其所奉药囊提荆轲也」；`077`「赐夏无且黄金二百溢，曰：『无且爱我，乃以药囊提荆轲也。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 被点名的是一个捧着药囊的侍医。**禁兵的条文管的是侍殿群臣与殿下郎中，不是连秦王也不得佩剑**；殿上还有一群徒手扑上去的人，别把这一掷读成孤胆英雄 |

### 卡 6 · 对照

**问：那一天的殿上，荆轲和秦王，谁更狼狈？**

答：**两个人都狼狈，但史书记法不同。**

| | 荆轲 | 秦王 |
|---|---|---|
| 动作 | 把袖、揕之、逐、掷 | 惊、引而起、环柱走 |
| 失手 | 未至身 | 剑不可立拔 |
| 结果 | 断股、被八创、死 | 断其股、被左右救下 |

注意 `074` 那个词：**「荆轲废」**——指他受伤失去行动能力，此时尚未死。
受伤之后，他最后一次用匕首进攻是投掷；此后 `075` 还写他倚柱笑骂，不能把投匕说成最后一个动作。

而秦王那边，史书给的最后一句是：**「不怡者良久。」**

**赢的人，很久都不高兴。**

| | |
|---|---|
| 依据 | `067`–`076` |
| 标记 | ○ 合理推演 |
| 考点 | 两边都狼狈，落点却不同：荆轲是「废」，秦王是「不怡者良久」——**赢的人很久都不高兴** |

### 卡 7 · 动机

**问：荆轲临死的笑骂，原文留下了什么？**

答：**留下姿态、当场言辞，也写他自知事情不成。**

`075` 先写「轲自知事不就」，再写倚柱而笑、箕踞以骂，随后录下他关于活捉、约契与报太子的自述。

话里提到太子，不等于太子在场听见，也不能直接判定他是在向太子传话。底本没有注明语气极其冷静，或完整解释为什么以这种姿态笑骂。

| | |
|---|---|
| 依据 | `075`「轲自知事不就，倚柱而笑，箕踞以骂曰」及随后自述 |
| 标记 | ◆ 出自原文 |
| 考点 | 姿态与言辞有记载，受话目的和全部心理没有随之确定 |

### 卡 8 · 辨析 ★

**问：这一场只有动作，没有写到人物心情吗？**

答：**不是。突发动作很多，情绪和判断也有明确记录。**

| 原文 | 记了什么 |
|---|---|
| `063`「色变振恐」「群臣怪之」 | 秦舞阳恐惧，群臣觉得异常 |
| `068`「时惶急」；`073`「卒惶急不知所为」 | 秦王的慌乱与不知所措 |
| `075`「轲自知事不就」 | 荆轲知道事情不成 |
| `076`「秦王不怡者良久」 | 秦王长久不快 |

这些不是完整的内心独白，却也不能删成「心思一个字没写」。读者可以据它们理解局势变化，未载的细节仍应保留。

| | |
|---|---|
| 依据 | `063`、`068`、`073`、`075`、`076` |
| 标记 | ◆ 出自原文 |
| 考点 | 分清已有情绪、判断与未展开的内心，不用题库比例代替史料分析 |
