# 复习卡 · 故事 07 · 图穷匕见

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 07 · 图穷匕见（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 主题 ★

**问：「事所以不成者，以欲生劫之」——这句话是什么意思？**

答：**这不是辩解，是交代任务为什么失败。**

太子丹最初交代的任务，原话分两层：

| 顺序 | 原话 | 意思 |
|---|---|---|
| 首选 | 诚得**劫**秦王，使悉反诸侯侵地 | 抓住他，逼他把地吐出来 |
| 退一步 | 则不可，因而**刺杀**之 | 不行，才杀 |

荆轲临死说的「欲生劫之」，正是**先选的那一层**。

所以这句话不是在说"我本来能杀他"，而是在说——**我到死都在执行你最初给我的那份任务。**

| | |
|---|---|
| 依据 | `075`「事所以不成者，以欲生劫之，必得约契以报太子也」；`032`「诚得劫秦王，使悉反诸侯侵地，若曹沫之与齐桓公，则大善矣；则不可，因而刺杀之」 |
| 标记 | ◆ 出自原文 |

| 备注 | 后世多把这句读成开脱。**读错了。** `032` 白纸黑字写着「劫」在前、「刺」在后 |
|---|---|

### 卡 2 · 因果 ★

**问：荆轲追秦王的时候，殿上那么多人，为什么拦不住他？**

答：**因为一条保护秦王的法令。**

```
秦法：群臣侍殿上者，不得持尺寸之兵
      诸郎中执兵，皆陈殿下，非有诏召不得上
```

于是那一刻，殿上出现了一个荒谬的局面：

| 谁 | 在哪 | 有兵器吗 | 能动手吗 |
|---|---|---|---|
| 群臣 | 殿上 | **没有** | 只能徒手 |
| 郎中 | 殿下 | 有 | **没有诏书，上不来** |

**最该保护秦王的那支力量，被一条保护秦王的法令挡在了殿外。**

急起来来不及下诏，所以殿上的人只能「以手共搏之」。

| | |
|---|---|
| 依据 | `070`「而秦法，群臣侍殿上者不得持尺寸之兵；诸郎中执兵皆陈殿下，非有诏召不得上」；`071`「方急时，不及召下兵……而卒惶急，无以击轲，而以手共搏之」 |
| 标记 | ◆ 出自原文 |

### 卡 3 · 陷阱题 ⚠️

**问：秦舞阳后来怎么样了？**

答：**不知道。史书没写。**

`063` 记了他「色变振恐」，`064` 之后他就不再出现在任何一句里。

**《刺客列传》从此不再提他一个字。**

一个有名有姓、有出身（`049`「燕国有勇士秦舞阳，年十三，杀人，人不敢忤视」）、有年龄的人，走进那座殿之后**消失了**。

| | |
|---|---|
| 依据 | `063` 之后，全篇无秦舞阳 |
| 标记 | — 史书的沉默 |

| 备注 | 这是全篇最彻底的一处沉默。**不是"晚于本场景"，是"史书根本没写"**——两者要分清 |

### 卡 4 · 结构

**问：秦王的剑，为什么拔不出来？**

答：**因为剑太长，而且是挂在腰上的。**

`068` 给了三层原因，一层比一层急：

| 原话 | 什么意思 |
|---|---|
| 剑长 | 剑身太长 |
| 操其室 | 慌乱中只抓住了**剑鞘** |
| 时惶急，剑坚，故不可立拔 | 越急越拔不出来 |

最后解决靠的是左右喊的那句 **「王负剑」**——**把剑推到背上去**，才抽得出来。

| | |
|---|---|
| 依据 | `068`「拔剑，剑长，操其室。时惶急，剑坚，故不可立拔」；`073`「左右乃曰：『王负剑！』负剑，遂拔」 |
| 标记 | ◆ 出自原文 |

### 卡 5 · 细节

**问：那一天，殿上第一个动手的是谁？**

答：**一个捧药囊的侍医，叫夏无且。**

他不是武士，手里没有兵器——**殿上谁也不许有兵器**。他能扔出去的，只有捧着的东西。

事后秦王论功，单独给了他一句评价：

> 「无且**爱我**，乃以药囊提荆轲也。」

**「爱我」——在那一刻的殿上，只有他一个人动了手。**

| | |
|---|---|
| 依据 | `072`「是时侍医夏无且以其所奉药囊提荆轲也」；`077`「赐夏无且黄金二百溢，曰：『无且爱我，乃以药囊提荆轲也。』」 |
| 标记 | ◆ 出自原文 |

### 卡 6 · 对照

**问：那一天的殿上，荆轲和秦王，谁更狼狈？**

答：**两个人都狼狈，但史书记法不同。**

| | 荆轲 | 秦王 |
|---|---|---|
| 动作 | 把袖、揕之、逐、掷 | 惊、引而起、环柱走 |
| 失手 | 未至身 | 剑不可立拔 |
| 结果 | 断股、被八创、死 | 断其股、被左右救下 |

注意 `075` 那个词：**「荆轲废」**——**不是死，是废了**。
废了之后他做的最后一个动作，是把匕首扔出去。

而秦王那边，史书给的最后一句是：**「不怡者良久。」**

**赢的人，很久都不高兴。**

| | |
|---|---|
| 依据 | `067`–`076` |
| 标记 | ◆ 出自原文 ＋ ○ 合理推演 |

### 卡 7 · 动机

**问：荆轲临死前为什么要「倚柱而笑，箕踞以骂」？**

答：**笑和箕踞都是姿态，骂的内容才是正事。**

「箕踞」是两腿叉开坐着 —— 古人席地跪坐，**这是极不敬的姿势**。
他先摆出最不敬的姿态，然后说了一句极其冷静的话：交代任务为什么失败。

**姿态是给秦国人看的，话是说给太子丹听的。**

| | |
|---|---|
| 依据 | `075`「轲自知事不就，倚柱而笑，箕踞以骂曰……」 |
| 标记 | ○ 合理推演 |

| 备注 | 「笑」和「箕踞」是原文的动作；**为什么偏偏用这两个动作，原文不解释**。这一条是推演 |
|---|---|

### 卡 8 · 沉默 ★

**问：这一篇里，史书没有写的是什么？**

答：**这一篇几乎全是动作，几乎没有心思。**

`059`–`076` 共 18 段、约 400 字，写的是：

> 把袖 · 揕之 · 袖绝 · 拔剑 · 环柱走 · 断其左股 · 掷匕首 · 中铜柱 · 被八创 · 倚柱而笑

**史书写了人做了什么，没写人想什么。**

所以这一篇的 60 条问答里，有 **24 条**是「没有回答」——那不是敷衍，**那就是史书本来的样子**。

| | |
|---|---|
| 依据 | 本故事全部 18 段原文 |
| 标记 | — 史书的沉默 |

| 备注 | **不替古人编心思，是这个产品最该守住的东西。** 史书没写的地方，我们选择不写 |
