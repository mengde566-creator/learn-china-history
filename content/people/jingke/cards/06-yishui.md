# 06 · 复习卡

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 场景 06 · 易水送别（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：送行的人为什么都穿着白衣、戴着白冠？**

答：**这一段没有交代穿白的原因。**

《史记》记太子和知道计划的宾客，穿白衣、戴白冠来送荆轲。

衣着是记载明确给出的细节；为什么如此穿戴、每个人怎样想，这一段没有记下。

本次所核《史记三家注》卷八十六电子录文，没有在这句下解释穿白的缘由。这个核查范围不包括历代所有注本，不能据此断言从来无人解释，也不能把“送死之服”说成已查明的《集解》《索隐》定论。

| | |
|---|---|
| 依据 | `054`「太子及宾客知其事者，皆白衣冠以送之」；本次所核《史记三家注》卷八十六电子录文未在此句下解释穿白缘由，这一核查不能代替历代注本检索 |
| 标记 | — 史书未载 |
| 考点 | 分清送行者穿了什么，与他们为什么这样穿、心里怎样想 |

---

### 卡 2 · 因果 ★

**问：在场的人听见了什么？底本记下了什么？**

答：**记载写了先后两个调子，也写了众人两次不同的反应。**

| 调 | 效果 |
|---|---|
| 变徵之声 | 悲凉 → 士皆**垂泪涕泣** |
| 羽声 | 慷慨 → 士皆**瞋目，发尽上指冠** |

同一段离别，众人先哭了一场，随后又全都瞪起眼睛、头发竖起顶起帽子。**这是 `055`、`057` 记下的效果。**

至于荆轲**为什么**先唱悲调、再转羽声——**底本记的是他唱了什么、众人怎么反应，没有记他的用意。**「为了让情绪反转」「他是把一群人唱怒了」都是后人的读法，不是这一段写的事。

| | |
|---|---|
| 依据 | `055`「为变徵之声，士皆垂泪涕泣」；`057`「复为羽声忼慨，士皆瞋目，发尽上指冠」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两个调子对着看：**一段离别，众人的反应先哭后怒**——`055`、`057` 记的是这个效果。**他为什么选这两个调子，底本不解释** |

---

### 卡 3 · 陷阱题 ⚠️

**问：太子丹在易水送别时，说了什么？**

答：**这一段没有留下他的话。**

《史记》写易水送别，**没有记录太子丹的任何言语或个别动作**——`054` 只写了「太子及宾客知其事者，皆白衣冠以送之」。他在场，然后荆轲走了。

**「没有记录」不等于「他什么都没说」**：那一天他说没说话，史书不载，这里也不替他定。

| | |
|---|---|
| 依据 | `054–058` 五段中无太子丹的言语或个别动作（`054` 仅记他与宾客同着白衣冠） |
| 标记 | — 史书未载 |
| 考点 | **史书没写，不等于没发生；也不等于可以随便补。** 本题标 —，说明这段未载；动人的台词也不能替古人补出 |

---

### 卡 4 · 辨析 ★

**问：白衣白冠，能证明每个送行的人都认定荆轲必死吗？**

答：**不能只凭这一处衣着描写作这样的判断。**

这段文字写了谁来送行、怎样穿戴，没有逐一记下众人的想法。

后来荆轲唱“不复还”，是他唱出的歌辞；不能因此把同样的想法逐一安在所有送行者身上。

| | |
|---|---|
| 依据 | `054`「太子及宾客知其事者，皆白衣冠以送之」；`056`「壮士一去兮不复还」——前者记衣着，后者为荆轲歌辞，都没有逐人交代送行者的内心 |
| 标记 | ○ 合理推演 |
| 考点 | 分清记述的衣着、人物的歌辞与对众人心理的推断 |

---

### 卡 5 · 因果

**问：荆轲去秦国，首要任务是刺杀秦王，还是劫持秦王？**

答：**劫持。**

太子丹的原话是：如果能劫持秦王、逼他归还侵占的土地，**那就最好**；如果不行，才刺杀。

荆轲临死前也说了同样的话：「事所以不成者，**以欲生劫之**，必得约契以报太子也。」

取得盟约是劫持方案的目标；刺杀则是任务明确保留的后备方案，不能只讲前一层。

| | |
|---|---|
| 依据 | `032`「诚得劫秦王，使悉反诸侯侵地……则大善矣；则不可，因而刺杀之」<br>`075`「以欲生劫之，必得约契以报太子也」 |
| 标记 | ◆ 出自原文 |
| 考点 | **032 与 075 是一对。** `032` 的方案是先劫持、不行才杀；`075` 是他临死说「以欲生劫之」——**先劫持，是底本写着的，也是他自己的说法** |

---

### 卡 6 · 人物 ⚠️

**问：高渐离在易水这一场里说过话吗？**

答：**本段记他击筑，没有留下他的直接引语。**

`055` 写「高渐离击筑，荆轲和而歌」。这是送行中音乐与歌声的配合，不足以证明高渐离整场一言不发。

后文 `085` 留下一处评艺引语「彼有善有不善」，并用「每出言曰」写他屡次评论。留下一处引语，不是说这个人一生只说了一句话。`087` 还明确记下他不愿长期隐匿、惶恐穷困的念头。

| | |
|---|---|
| 依据 | `055`；`085`「每出言曰」；`087`「念久隐畏约无穷时」 |
| 标记 | — 史书未载 |
| 考点 | 本场未录直接引语，不等于现场沉默，更不能据此定性为寡言的人 |

---

### 卡 7 · 因果

**问：荆轲为什么「终已不顾」——始终不回头？**

答：**底本记录了不回头的行为，没有交代具体用意。**

`058` 写他就车离去、始终不顾。前面 `056` 的歌辞是「壮士一去兮不复还」，可以把歌辞与离去的动作对读；这仍不足以说明他是怕泄气、怕被看见表情，或另有某一种确定心理。

| | |
|---|---|
| 依据 | `056` 歌辞；`058`「于是荆轲就车而去，终已不顾」 |
| 标记 | — 史书未载 |
| 考点 | 读出歌与行动的呼应，保留具体心理未载的边界 |

### 卡 8 · 时间线

**问：把这五件事按发生顺序排列。**

A. 太子丹催促荆轲，荆轲发怒
B. 高渐离击筑，荆轲和而歌，众人垂泪
C. 秦将王翦破赵，进兵至燕南界
D. 荆轲就车而去，终已不顾
E. 荆轲转为羽声，众人瞋目、发上指冠

答：**C → A → B → E → D**

| | |
|---|---|
| 标记 | ◆ 出自原文 |
| 依据 | `037` → `051` → `055` → `057` → `058` |
| 考点 | 注意 **A 在 B 之前**：荆轲是在**发怒之后**才出发的。先后次序明确，但不能据此把前一场争执的全部心情套进送行现场 |
