# 06 · 复习卡

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 场景 06 · 易水送别（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：送行的人为什么都穿着白衣、戴着白冠？**

答：因为那是**送葬的装束**。

到场的人——包括荆轲自己——都认定他不会活着回来。这不是仪式，是**提前举行的葬礼**。

| | |
|---|---|
| 依据 | `054` 太子及宾客知其事者，皆白衣冠以送之。 |
| 标记 | △ 存疑 |
| 考点 | `054` 只写了「白衣冠」三个字，**它是不是丧服，底本没有解释**——那是历代注家的读法 |

---

### 卡 2 · 因果 ★

**问：荆轲为什么先唱「变徵之声」，再转「羽声」？**

答：因为**情绪要反转**。

| 调 | 效果 |
|---|---|
| 变徵之声 | 悲凉 → 士皆**垂泪涕泣** |
| 羽声 | 慷慨 → 士皆**瞋目，发尽上指冠** |

同一段离别，他先用悲调让众人哭，再用慷慨的调子把众人唱怒。

**他不是去赴死，他是把一群哭着的人唱怒了。**

| | |
|---|---|
| 依据 | `055`「为变徵之声，士皆垂泪涕泣」；`057`「复为羽声忼慨，士皆瞋目，发尽上指冠」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两个调子对着看：**先唱哭一屋子人，再唱怒一屋子人**——同一段离别的两种收束 |

---

### 卡 3 · 陷阱题 ⚠️

**问：太子丹在易水送别时，说了什么？**

答：**什么都没说。**

《史记》这一段**没有记录太子丹的任何言语或个别动作**——`054` 只写了「太子及宾客知其事者，皆白衣冠以送之」。他站在人群里，然后荆轲走了。

| | |
|---|---|
| 依据 | `054–058` 五段中无太子丹的言语或个别动作（`054` 仅记他与宾客同着白衣冠） |
| 标记 | — 史书未载 |
| 考点 | **史书没写，不等于没发生；也不等于可以随便补。** 这一类空白必须标 △ 存疑，不能由 AI 填上动人的台词 |

---

### 卡 4 · 辨析 ★

**问：「白衣冠是送葬的装束」——这句话是《史记》原文写的，还是后人解释的？**

答：**后人解释的。**

《史记》原文只写了四个字：**「白衣冠」**。它没有说这是丧服。

「送死之服」是历代注家的解释。这个解释几乎已成定论，但严格来说，它**不是原文**。

| | |
|---|---|
| 依据 | `054` 原文仅有「皆白衣冠以送之」 |
| 标记 | ○ 训释 |
| 考点 | 这是本产品最想让你学会的一件事：**分清"史书上写的"和"后人读出来的"** |

---

### 卡 5 · 因果

**问：荆轲去秦国，首要任务是刺杀秦王，还是劫持秦王？**

答：**劫持。**

太子丹的原话是：如果能劫持秦王、逼他归还侵占的土地，**那就最好**；如果不行，才刺杀。

荆轲临死前也说了同样的话：「事所以不成者，**以欲生劫之**，必得约契以报太子也。」

他要去签一份合同，不是去要一条命。

| | |
|---|---|
| 依据 | `032`「诚得劫秦王，使悉反诸侯侵地……则大善矣；则不可，因而刺杀之」<br>`075`「以欲生劫之，必得约契以报太子也」 |
| 标记 | ◆ 出自原文 |
| 考点 | **032 与 075 是一对。** 大多数人以为荆轲是刺客，其实他是去执行一份合同的 |

---

### 卡 6 · 人物 ⚠️

**问：高渐离在《刺客列传》里说过话吗？**

答：**一句都没有。**

他在《刺客列传》中只以**动作**出现：

- 在燕市击筑，和荆轲一起唱歌、一起哭 `005`
- 在易水边击筑 `055`
- 变名姓为人庸保，忍不住评论别人的筑声 `085`
- 被熏瞎双眼，仍被令击筑 `090`
- **把铅灌进筑里，扑向秦始皇** `091`

**一句话都没有。**

| | |
|---|---|
| 标记 | — 史书未载 |
| 考点 | 一个从不说话的人，最后用乐器去砸皇帝。**史书对他为什么这么做，一个字都没解释**——这是整个故事里最大的留白 |

---

### 卡 7 · 因果

**问：荆轲为什么「终已不顾」——始终不回头？**

答：底本没有解释。

**「终已不顾」四个字是史书给出的全部信息。**

可能的理解（均为推演，非原文）：回头就散了那股气；或者他不想让送行的人看到自己的脸。

| | |
|---|---|
| 依据 | `058`「于是荆轲就车而去，终已不顾」 |
| 标记 | ○ 合理推演 |
| 考点 | 又一个「底本只写行为、不写动机」的例子 |

---

### 卡 8 · 时间线

**问：把这五件事按发生顺序排列。**

A. 太子丹催促荆轲，荆轲发怒
B. 高渐离击筑，荆轲和而歌，众人垂泪
C. 秦将王翦破赵，进兵至燕南界
D. 荆轲就车而去，终已不顾
E. 荆轲转为羽声，众人瞋目、发上指冠

答：**C → A → B → E → D**

| | |
|---|---|
| 标记 | ◆ 出自原文 |
| 依据 | `037` → `051` → `055` → `057` → `058` |
| 考点 | 注意 **A 在 B 之前**：荆轲是在**发怒之后**才出发的。这个顺序决定了他的情绪底色 |
