### 卡 1 · 结构 ★

**问：所录献首方案由谁向太子丹提出？**

答：所录方案由荆轲向太子提出，不等于已知最早构思的时刻。

`039` 荆轲先说了一句条件，`040` 才报出那两样东西：

| 先后 | 原话 | 意思 |
|---|---|---|
| 条件 | 今行而**毋信**，则秦未可亲也 | 手里没有取信的东西，接近不了秦王 |
| 方案 | 诚得**樊将军首**与燕督亢之地图……秦王必说见臣 | 拿这两样，秦王一定高兴见我 |

太子丹先以「秦兵旦暮渡易水」（`038`）催促；荆轲提出献首后，他又明确提到樊将军，并说不忍伤害来投的长者（`041`）。**没有由太子先提出献首，不等于他全程未提樊於期。**

献首取信的方案由荆轲提出。

| | |
|---|---|
| 依据 | `038`「秦兵旦暮渡易水，则虽欲长侍足下，岂可得哉！」；`039`「今行而毋信，则秦未可亲也」；`040`「夫樊将军，秦王购之金千斤，邑万家。诚得樊将军首与燕督亢之地图，奉献秦王，秦王必说见臣，臣乃得有以报。」 |
| 标记 | ◆ 出自原文 |
| 考点 | 区分谁提出献首方案，与太子丹对方案的拒绝和对樊於期的称呼 |

---

### 卡 2 · 因果 ★

**问：太子丹明明说了「不忍」，为什么最后还是把头装进了匣子？**

答：**因为中间隔了一层——荆轲没有等他答应。**

```
040  荆轲当面提出要樊於期的头
041  太子丹：不忍 → 「愿足下更虑之」
042  荆轲「知太子不忍，乃遂私见樊於期」   ← 私自去的
046  樊於期自刭
047  太子丹「闻之」→ 驰往 → 伏尸而哭 → 函封
```

关键在 `042` 的「私」和 `047` 的「闻」两个字：

| 字 | 出处 | 说明了什么 |
|---|---|---|
| 私 | `042`「乃遂私见樊於期」 | 他见樊於期，太子丹不在场 |
| 闻 | `047`「太子闻之」 | 太子丹是**听说**的 |

`047` 的「既已不可奈何」承接樊於期已经自刭的事实；原文随后写太子装匣封首，不必另替他判定是否在推脱。

| | |
|---|---|
| 依据 | `041`「丹不忍以己之私而伤长者之意，愿足下更虑之！」；`042`「荆轲知太子不忍，乃遂私见樊於期」；`047`「太子闻之，驰往，伏尸而哭，极哀。既已不可奈何，乃遂盛樊於期首函封之。」 |
| 标记 | ◆ 出自原文 |
| 考点 | 关键在两个动词：`042` 的「私」和 `047` 的「闻」——**他不在场**，「不忍」和「函封」并不矛盾 |

### 卡 3 · 动机 ★

**问：樊於期为什么自己把头交出去？**

答：可结合他两处自述，看仇痛与听到办法后的回应，不把它们当作全部内心的清单。

| 编号 | 他说的话 | 里面是什么 |
|---|---|---|
| `043` | 於期每念之，**常痛于骨髓**，顾计不知所出耳 | 有仇，**想不出办法** |
| `046` | 此臣之**日夜切齿腐心**也，**乃今得闻教** | 仇还在，**办法来了** |

两句之间，是荆轲那套完整的方案（`045`）：左手抓袖子，右手刺胸口，仇报了，燕国的耻辱也洗掉了。

「乃今」是「直到今天才」。
他在此回应荆轲提出的办法，不能据此确定他从来没有其他考虑。

| | |
|---|---|
| 依据 | `043`；`045`「愿得将军之首以献秦王，秦王必喜而见臣……然则将军之仇报而燕见陵之愧除矣」；`046`「此臣之日夜切齿腐心也，乃今得闻教！」 |
| 标记 | ○ 合理推演 |
| 考点 | 区分樊於期的仇痛自述与荆轲提出的解燕患、报仇预期；没有明说报恩不证明绝无此念 |

| 备注 | 「他在等一个办法」是从 `043`＋`046` 两句的措辞推出来的。**「报恩」不在他给出的动机里——`046` 一个字都没提太子丹** |
|---|---|

---

### 卡 4 · 细节 ★

**问：「偏袒扼腕而进」怎样写樊於期的回应？**

答：**脱一只袖子，露出肩膀；一只手握住另一只手腕；上前。**

| 词 | 动作 |
|---|---|
| 偏袒 | 脱下一只衣袖，露出肩膀 |
| 扼腕 | 一只手握住另一只手腕 |
| 而进 | **上前** |

这组动作后面，紧接着他自己的话「日夜切齿腐心」「乃今得闻教」。读者可以把动作与这番激愤的自述合看，而不只凭姿态补出全部心思。

而在 `044` 他也有一次「乃前曰」。
**两次，他都是自己往前走的。**

| | |
|---|---|
| 依据 | `046`「樊於期偏袒扼腕而进曰」；`044`「於期乃前曰：『为之奈何？』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 动作与随后自述一起读；「进」没有注明走了几步 |

| 备注 | 动作和「日夜切齿腐心」都来自原文；具体步数没有记载 |
|---|---|

### 卡 5 · 陷阱题 ⚠️

**问：樊於期犹豫了多久才答应的？**

答：**底本没有注明时长，但写了他的回答和自刭。**

`045` 荆轲提出献首计划；`046` 樊於期「偏袒扼腕而进」，说「此臣之日夜切齿腐心也，乃今得闻教」，随后「遂自刭」。

不能用没有另写犹豫过程，证明他毫不犹豫；也不能在两段之间凭空加出一场长久挣扎。动作、言语和结果已经相接，缺的是可量的时长与未说出的心思。

| | |
|---|---|
| 依据 | `045`–`046`，包括回应与「遂自刭」 |
| 标记 | — 史书未载 |
| 考点 | 未载具体时长，不等于没有记载回应 |

### 卡 6 · 对照

**问：私下交谈时，荆轲和樊於期各说了什么？**

答：**荆轲逐层提出计划，樊於期从诉说仇痛，到追问办法，再到回应与自刭。**

| 荆轲的三处引语 | 樊於期的三处引语 |
|---|---|
| `042` 提及家族遭难与悬赏，问将奈何 | `043`「常痛于骨髓，顾计不知所出耳」 |
| `044` 提出可解燕患、报将军仇的办法，问何如 | `044`「为之奈何」 |
| `045` 说明献首、近身进攻的计划，问是否有意 | `046`「此臣之日夜切齿腐心也，乃今得闻教」 |

两人都留有三处直接引语，荆轲的计划展开较长。这里数的是这次交谈所录的引语，不是一个人一生说话的次数；太子丹没有参加这场私下交谈。

| | |
|---|---|
| 依据 | `042`–`046` |
| 标记 | ◆ 出自原文 |
| 考点 | 以问、答与行动跟住交谈，不混入先前荆轲与太子的谈话 |

### 卡 7 · 主题

**问：这一篇里最重的是哪一句？**

答：**「此臣之日夜切齿腐心也，乃今得闻教！」**

一个人逃亡到燕国，在那里住了一段时间，父母宗族遭了杀戮、没入之祸，自己被悬赏金千斤、邑万家。
荆轲说完方案，原文留下了樊於期的回应。

他说的是：**这是我想了很久的事，今天才听到办法。**

然后 `047` 把全篇最冷的一句放在了最后——

> **既已不可奈何**，乃遂盛樊於期首函封之。

哭与装匣都有记载；「既已不可奈何」正是原文给的承接：樊於期已死，太子无法挽回。

| | |
|---|---|
| 依据 | `042`「父母宗族皆为戮没」；`046`；`047` |
| 标记 | ◆ 出自原文 |
| 考点 | 「最重」是读出来的判断。哭与装匣之间有「既已不可奈何」承接，不应漏掉 |

| 备注 | 「最重的是哪一句」是编者的判断，不是史书的判断。**史书只是把它记在 `046`，没有加任何评语** |
|---|---|

### 卡 8 · 对读 ★

**问：樊於期之死与秦庭行刺，叙述各怎样推进？**

答：**前者靠交涉与回应推进，后者集中写突发行动和应对；两处都有动作、言语及情绪。**

| 段落 | 怎样推进 |
|---|---|
| `042`–`046` | 荆轲问及仇怨、提出办法，樊於期追问、回应，最后自刭 |
| `067`–`076` | 袖绝、追逐、拔剑、群臣共搏与药囊一掷、断股投匕，最后笑骂被杀 |

樊於期不是听见索首就掉入文字空白：`046` 明录他的动作与回答。秦庭一场也不是只有动作：有秦王惶急、荆轲自知事不就，以及临死自述。

| | |
|---|---|
| 依据 | `042`–`047`；`067`–`076` |
| 标记 | ○ 合理推演 |
| 考点 | 比较叙述重心，不用问答比例或人为分段制造史料沉默 |
