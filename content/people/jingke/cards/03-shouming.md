# 复习卡 · 故事 03 · 受命

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 03 · 受命（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 主题 ★

**问：「受命」受的是什么命？**

答：**先争取劫持秦王、迫还侵地，不成则刺杀。**

太子丹的原话分两层：

| 顺序 | 原话 | 意思 |
|---|---|---|
| 首选 | 诚得**劫**秦王，使悉反诸侯侵地 | 抓住他，逼他把地吐出来 |
| 退一步 | 则不可，因而**刺杀**之 | 不行，才杀 |

荆轲临死前说的那句「以欲生劫之，必得约契以报太子也」，正是**先选的那一层**。

这份任务兼有两层：首选以劫持迫退土地，不成再刺杀，并指望秦国内乱使诸侯得以合纵。不能因首选是劫持，就把刺杀从任务中抹掉。

| | |
|---|---|
| 依据 | `032`「诚得劫秦王，使悉反诸侯侵地，若曹沫之与齐桓公，则大善矣；则不可，因而刺杀之」；`075`「必得约契以报太子也」——临死前他说，事情不成，是因为要活捉秦王 |
| 标记 | ◆ 出自原文 |
| 考点 | 任务关系到归还诸侯侵地，也包含刺杀的后备方案 |

---

### 卡 2 · 因果

**问：太子丹为什么要把国事交给一个从卫国来的游士？**

答：**太子丹陈说了四重困境，又有田光事先推荐荆轲。**

```
秦欲不可足  →  非尽天下之地，臣海内之王者，其意不厌        029
赵国挡不住  →  赵不能支秦，必入臣，入臣则祸至燕             030
燕国挡不住  →  燕小弱……举国不足以当秦                     031
诸侯不敢合纵（太子的判断） →  诸侯服秦，莫敢合从             031
```

太子由此提出**找勇士，带着重利求见秦王**（`032`）。这是他的方案与论证，并不是叙述者证明天下只剩一条路；前文鞠武也提出过联络各方的办法。

而这个人早就被提过一次名字：田光说「所善荆卿可使也」`020`。

| | |
|---|---|
| 依据 | `029`、`030`、`031`、`032`；`020`「光不敢以图国事，所善荆卿可使也」 |
| 标记 | ○ 合理推演 |
| 考点 | 四项困境出自太子的陈说；荆轲的推荐则来自田光。人物的论证不等于史家穷尽全部可能 |

---

### 卡 3 · 陷阱题 ⚠️

**问：受命前后的范围内，荆轲的直接引语有哪些？**

答：**两处：向田光答「谨奉教」，向太子丹说自己恐不足任使。**

这一篇收录 `022`–`035` 十四段，荆轲的言语要区分直接引语与转述：

| 编号 | 荆轲做了什么 |
|---|---|
| `023` | 向田光答「谨奉教」——一处直接引语 |
| `026` | 「言田光已死，致光之言」——转述行为，没有完整直接引语 |
| `027`–`033` | 未录荆轲直接引语；太子有动作，也有长篇陈说 |
| `034` | 「此国之大事也，臣驽下，恐不足任使。」——向太子所说的直接引语 |
| `035` | 底本只写太子做了什么，没有再写他 |

他在不同会面中都开了口，不能把这十四段缩成只与太子相见的十段，再误数成一句。

| | |
|---|---|
| 依据 | `023`「荆轲曰：谨奉教」；`026` 转述行为；`034` 对太子之言 |
| 标记 | ◆ 出自原文 |
| 考点 | 按完整范围区分两处直接引语与一次转述，避免漏掉与田光的会面 |

### 卡 4 · 结构

**问：022–035 这十四段，是谁在说？**

答：太子的连续陈说集中在 `027`–`033`；其中也有哭、坐定、避席顿首等叙述，不能把七段都算成纯引语。

下表把每一段**是谁在记述、谁在说话**分开标：

| 编号 | 记述／行为及言辞 | 内容 |
|---|---|---|
| `022` | 叙述 ＋ 太子丹的**直接引语** | 送到门口：「愿先生勿泄」 |
| `023` | 叙述 ＋ 田光的**直接引语**；荆轲答一句 | 转达太子之言，荐荆轲；荆轲答「谨奉教」 |
| `024` | **田光的直接引语** | 「是太子疑光也」「非节侠也」 |
| `025` | **叙述者的说明**（「欲自杀以激荆卿」）＋ 田光的**直接引语**（遗言），自刎是叙述 | 叙述说明他想以自杀激励荆轲；田光说「愿足下急过太子，言光已死，明不言也」；然后自刎 |
| `026` | 叙述（含荆轲的转述） | 田光已死，转达田光的话 |
| `027` | 叙述 ＋ 太子丹的**直接引语** | 田光之死不是我的本意 |
| `028` | 太子丹的**直接引语** | 天哀燕而不弃其孤 |
| `029` | 太子丹的**直接引语** | 秦欲不可足 |
| `030` | 太子丹的**直接引语** | 秦军已到哪里，祸至燕 |
| `031` | 太子丹的**直接引语** | 燕弱，诸侯莫敢合从 |
| `032` | 太子丹的**直接引语** | **劫持优先，刺杀其次** |
| `033` | 太子丹的**直接引语** | 君臣相疑，而不知所委命 |
| `034` | 叙述 ＋ 荆轲的**直接引语** ＋ 太子的动作 | 推辞 → 固请 → 许诺 |
| `035` | 叙述 | 尊为上卿，日造门下 |

**「欲自杀以激荆卿」是叙述者的话，不在田光的引语里。** `024` 那两句和 `025` 的遗言才是他说出口的。

言辞之外，原文还写了送门、赴见、自刎、转告、拜跪、固请和礼遇。长篇陈说集中在太子丹身上，不等于十四段只剩三个动作。

| | |
|---|---|
| 依据 | `022`–`035` |
| 标记 | ◆ 出自原文 |
| 考点 | 这一段几乎全是太子丹一个人在说。**把这十四段按说话人分一遍，重心就出来了** |

### 卡 5 · 细节

**问：「久之」和「然后许诺」之间，发生了什么？**

答：**荆轲先推辞，太子上前顿首、坚请他不要推让，然后荆轲许诺。**

> 久之，荆轲曰：「此国之大事也，臣驽下，恐不足任使。」太子前顿首，固请毋让，然后许诺。

荆轲说出的推辞理由是事情重大，恐怕自己不能胜任。太子的再次请求和最终许诺，也都写在同一句里。「久之」没有给出精确时长，但这段经过并非空白。

| | |
|---|---|
| 依据 | `034` 全句 |
| 标记 | ◆ 出自原文 |
| 考点 | 按推辞、固请、许诺的顺序读，不抹掉已经记下的理由和经过 |

---

### 卡 6 · 对照

**问：让荆轲接下这件事，田光和太子丹各用了什么办法？**

答：田光自刎，太子反复行礼固请；两段行动分别连到赴见与正式许诺，不是同一种已经证实的唯一受命原因。

| | 田光 | 太子丹 |
|---|---|---|
| 手段 | 自刎 | 再拜、膝行、避席、顿首、前顿首 |
| 记述／原话 | 叙述者交代他想以自杀激励荆轲（`025`「欲自杀以激荆卿」）；他本人的直接引语是「愿足下急过太子，言光已死，明不言也」 | 对荆轲「固请毋让」（`034`）、「以顺适其意」（`035`）**都是叙述者的转述**；他的直接引语在 `027`–`033`，例如「丹所以诫田先生毋言者，欲以成大事之谋也」 |
| 想要的结果 | 让他去见太子 | 让他答应这件事 |

田光希望激励荆轲并让他去见太子；太子则当面固请承担国事。两种行动先后促成赴见与许诺，不能简化成相同目标或已经证实的唯一原因。

> **「欲自杀以激荆卿」出自叙述句，不是田光的原话。** 要找人物说过的话，用上面的直接引语。

`026` 记荆轲赴见并转达遗言；`034` 才记「然后许诺」。这两个结果要分别看，不能把完整受命直接归给单一原因。

| | |
|---|---|
| 依据 | `025`「欲自杀以激荆卿」；`034`「太子前顿首，固请毋让，然后许诺」；`035`「以顺适其意」 |
| 标记 | ○ 合理推演 |
| 考点 | 分清赴见、许诺两个步骤及人物动机在叙述中的归属 |

### 卡 7 · 动机

**问：太子丹为什么每天到荆轲门上，供太牢、送车骑美女？**

答：**原文给了理由，但只给了一层。**

`035` 的最后五个字是：**「以顺适其意」——为了顺他的心意。**

「顺他的意」是为了什么，底本没有往下写。

能确定的是规格：

| 项 | 原文 |
|---|---|
| 位 | 尊为上卿 |
| 住 | 舍上舍 |
| 去 | 太子日造门下 |
| 吃 | 供太牢具 |
| 赠 | 异物间进 |
| 用 | 车骑美女恣荆轲所欲 |

**一个太子每天亲自登门。** 后文 `051` 又记「太子迟之，疑其改悔」。前后形成礼遇与催促的对照，但底本没有说明礼遇越多便必然越急。

| | |
|---|---|
| 依据 | `035`「于是尊荆卿为上卿，舍上舍。太子日造门下，供太牢具，异物间进，车骑美女恣荆轲所欲，以顺适其意」；`051`「太子迟之，疑其改悔」 |
| 标记 | ○ 合理推演 |
| 考点 | 区分原文说明的顺适其意，与读者对前后礼遇、催促的比较 |

---

### 卡 8 · 辨析 ★

**问：受命这一步，哪些已经写明，哪些还不知道？**

答：**说出的顾虑、太子的固请与许诺结果都有记载；完整内心没有展开。**

`034` 荆轲说「恐不足任使」，太子随后「前顿首，固请毋让」，然后许诺。它给了一条可以跟随的经过。

我们还不能据此断定他是否另有未说出的顾虑，也不能把许诺简化为只因感恩、只因压力或只为报答田光。没有完整心理独白，不等于这一步什么理由和行动都没写。

| | |
|---|---|
| 依据 | `034`；`025`–`026` 田光遗言与赴见 |
| 标记 | ○ 合理推演 |
| 考点 | 以明确记载理解受命过程，对未说出的理由保留限度 |
