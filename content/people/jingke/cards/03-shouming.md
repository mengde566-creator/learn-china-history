# 复习卡 · 故事 03 · 受命

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。

---

## 故事 03 · 受命（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 主题 ★

**问：「受命」受的是什么命？**

答：**不是「去杀秦王」，是「劫持优先，刺杀其次」。**

太子丹的原话分两层：

| 顺序 | 原话 | 意思 |
|---|---|---|
| 首选 | 诚得**劫**秦王，使悉反诸侯侵地 | 抓住他，逼他把地吐出来 |
| 退一步 | 则不可，因而**刺杀**之 | 不行，才杀 |

荆轲临死前说的那句「以欲生劫之，必得约契以报太子也」，正是**先选的那一层**。

所以这一篇交出去的任务，从头到尾要的都是**地**，不是**一条命**。

| | |
|---|---|
| 依据 | `032`「诚得劫秦王，使悉反诸侯侵地，若曹沫之与齐桓公，则大善矣；则不可，因而刺杀之」；`075`「必得约契以报太子也」——临死前他说，事情不成，是因为要活捉秦王 |
| 标记 | ◆ 出自原文 |
| 考点 | 「受命」受的不是一条命，是**一块地**——首选是劫，刺杀只是退一步 |

---

### 卡 2 · 因果

**问：太子丹为什么要把国事交给一个从卫国来的游士？**

答：**因为四条路都堵死了，只剩这一条。**

```
秦欲不可足  →  非尽天下之地，臣海内之王者，其意不厌        029
赵国挡不住  →  赵不能支秦，必入臣，入臣则祸至燕             030
燕国挡不住  →  燕小弱……举国不足以当秦                     031
外援没有了  →  诸侯服秦，莫敢合从                           031
```

剩下的那条路，是**找一个天下最勇的人，带着重利去见秦王**（`032`）。

而这个人早就被提过一次名字：田光说「所善荆卿可使也」`020`。

| | |
|---|---|
| 依据 | `029`、`030`、`031`、`032`；`020`「光不敢以图国事，所善荆卿可使也」 |
| 标记 | ○ 合理推演 |
| 考点 | 四条路是**逐条堵死的**；剩下那条路上，田光早就提过荆轲的名字 |

---

### 卡 3 · 陷阱题 ⚠️

**问：荆轲在这一篇里说了几句话？**

答：**被原文写下来的，只有一句。**

十段原文里，荆轲的话是这样分布的：

| 编号 | 荆轲做了什么 |
|---|---|
| `026` | 「言田光已死，致光之言」——说了，但底本没有记下他怎么说的 |
| `027`–`033` | **一个字都没有。** 七段全是太子丹的话 |
| `034` | 「此国之大事也，臣驽下，恐不足任使。」——**唯一一句被写下来的话** |
| `035` | 底本只写太子做了什么，没有再写他 |

**他不是没有开口，是史书只留了一句。**

| | |
|---|---|
| 依据 | `026`「言田光已死，致光之言」；`034`「久之，荆轲曰：『此国之大事也，臣驽下，恐不足任使。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 十段里荆轲只留下一句话。**「他没开口」和「史书没记」是两件事** |

---

### 卡 4 · 结构

**问：022–035 这十四段，是谁在说？**

答：**十四段里有七段是太子丹一个人在说。**

下表把每一段**是谁在记述、谁在说话**分开标：

| 编号 | 记述／行为及言辞 | 内容 |
|---|---|---|
| `022` | 叙述 ＋ 太子丹的**直接引语** | 送到门口：「愿先生勿泄」 |
| `023` | 叙述 ＋ 田光的**直接引语**；荆轲答一句 | 转达太子之言，荐荆轲；荆轲答「谨奉教」 |
| `024` | **田光的直接引语** | 「是太子疑光也」「非节侠也」 |
| `025` | **叙述者的说明**（「欲自杀以激荆卿」）＋ 田光的**直接引语**（遗言），自刎是叙述 | 叙述说明他想以自杀激励荆轲；田光说「愿足下急过太子，言光已死，明不言也」；然后自刎 |
| `026` | 叙述（含荆轲的转述） | 田光已死，转达田光的话 |
| `027` | 叙述 ＋ 太子丹的**直接引语** | 田光之死不是我的本意 |
| `028` | 太子丹的**直接引语** | 天哀燕而不弃其孤 |
| `029` | 太子丹的**直接引语** | 秦欲不可足 |
| `030` | 太子丹的**直接引语** | 秦军已到哪里，祸至燕 |
| `031` | 太子丹的**直接引语** | 燕弱，诸侯莫敢合从 |
| `032` | 太子丹的**直接引语** | **劫持优先，刺杀其次** |
| `033` | 太子丹的**直接引语** | 君臣相疑，而不知所委命 |
| `034` | 叙述 ＋ 荆轲的**直接引语** ＋ 太子的动作 | 推辞 → 固请 → 许诺 |
| `035` | 叙述 | 尊为上卿，日造门下 |

**「欲自杀以激荆卿」是叙述者的话，不在田光的引语里。** `024` 那两句和 `025` 的遗言才是他说出口的。

**这一篇的动作只有三处**：跪、哭、坐。其余全是话。

| | |
|---|---|
| 依据 | `022`–`035` |
| 标记 | ◆ 出自原文 |
| 考点 | 这一段几乎全是太子丹一个人在说。**把这十四段按说话人分一遍，重心就出来了** |

### 卡 5 · 细节

**问：「久之」和「然后许诺」之间，发生了什么？**

答：**有内容的只有五个字，其余全是空白。**

`034` 的原话是：

> 久之，荆轲曰：「此国之大事也，臣驽下，恐不足任使。」太子前顿首，固请毋让，然后许诺。

| 原文给的 | 是什么 |
|---|---|
| 久之 | 时间——很久 |
| 曰…… | 一句推辞的话 |
| 太子前顿首，固请毋让 | 太子的动作 |
| 然后许诺 | 结果 |

**他为什么推辞、又为什么改口，一个字都没有给。**

| | |
|---|---|
| 依据 | `034`「久之，荆轲曰：『此国之大事也，臣驽下，恐不足任使。』太子前顿首，固请毋让，然后许诺」 |
| 标记 | — 史书的沉默 |
| 考点 | 这一问问的就是那段空白。**改口的理由，底本一个字都没有给** |

---

### 卡 6 · 对照

**问：让荆轲接下这件事，田光和太子丹各用了什么办法？**

答：**田光用死，太子丹用礼。**

| | 田光 | 太子丹 |
|---|---|---|
| 手段 | 自刎 | 再拜、膝行、避席、顿首、前顿首 |
| 记述／原话 | 叙述者交代他想以自杀激励荆轲（`025`「欲自杀以激荆卿」）；他本人的直接引语是「愿足下急过太子，言光已死，明不言也」 | 对荆轲「固请毋让」（`034`）、「以顺适其意」（`035`）**都是叙述者的转述**；他的直接引语在 `027`–`033`，例如「丹所以诫田先生毋言者，欲以成大事之谋也」 |
| 想要的结果 | 让他去见太子 | 让他答应这件事 |

一个用死，一个用礼求——**目标完全相同。**

> **「欲自杀以激荆卿」出自叙述句，不是田光的原话。** 要找人物说过的话，用上面的直接引语。

而在这一篇里，两种办法都奏效了：`034` 的最后四个字是「然后许诺」。

| | |
|---|---|
| 依据 | `025`「欲自杀以激荆卿」；`034`「太子前顿首，固请毋让，然后许诺」；`035`「以顺适其意」 |
| 标记 | ○ 合理推演 |
| 考点 | 一个用死，一个用礼，**目标完全相同**——两种办法都落在「然后许诺」四个字上 |

### 卡 7 · 动机

**问：太子丹为什么每天到荆轲门上，供太牢、送车骑美女？**

答：**原文给了理由，但只给了一层。**

`035` 的最后五个字是：**「以顺适其意」——为了顺他的心意。**

「顺他的意」是为了什么，底本没有往下写。

能确定的是规格：

| 项 | 原文 |
|---|---|
| 位 | 尊为上卿 |
| 住 | 舍上舍 |
| 去 | 太子日造门下 |
| 吃 | 供太牢具 |
| 赠 | 异物间进 |
| 用 | 车骑美女恣荆轲所欲 |

**一个太子每天亲自登门。** 这是后来那句「太子迟之，疑其改悔」`051` 的另一面——**给得越多，等得越急。**

| | |
|---|---|
| 依据 | `035`「于是尊荆卿为上卿，舍上舍。太子日造门下，供太牢具，异物间进，车骑美女恣荆轲所欲，以顺适其意」；`051`「太子迟之，疑其改悔」 |
| 标记 | ○ 合理推演 |
| 考点 | 「以顺适其意」只交代了一层，**往下那一层底本没有写**——给得越多，后面那句「迟之」就越冷 |

---

### 卡 8 · 沉默 ★

**问：这一篇里，史书没有写的是什么？**

答：**荆轲为什么答应。**

`034` 给了他推辞的话，给了太子的叩头，给了「然后许诺」四个字——

**唯独没有给他答应的理由。**

所以这一篇的 60 条问答里，有 **28 条**是「没有回答」。拆开看：

| 类别 | 条数 |
|---|---|
| 不在场的人（田光） | 4 |
| 晚于本场景，或人物不在场 | 8 |
| 系统层 | 5 |
| **落在本场景两个人身上的史书沉默** | **11** |

**这 11 条里，有 8 条问的是荆轲。**

> 他不是没有回答——是史书没有替他回答。

| | |
|---|---|
| 依据 | `034`；`026`–`035` 十段 |
| 标记 | — 史书的沉默 |
| 考点 | 推辞的话有了，叩头有了，「然后许诺」也有了——**唯独没有给他答应的理由** |
