# 复习卡 · 故事 05 · 太子丹迟之

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问「为什么」，不问「哪一年」。

---

## 故事 05 · 太子丹迟之（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 动机

**问：太子丹为什么催荆轲？**

答：**因为他怀疑荆轲改悔了——这不是后人推的，是原文写的。**

`051` 一句话给了两层：

> 顷之，未发，太子迟之，疑其改悔

| 原文 | 意思 |
|---|---|
| 迟之 | 嫌他慢了 |
| 疑其改悔 | 怀疑他反悔 |

他催的三句话，一句比一句具体：

> 日已尽矣 → 荆卿岂有意哉 → 丹请得先遣秦舞阳

先提醒日子，再问意向，最后**提出先派秦舞阳走**。

| | |
|---|---|
| 依据 | `051`「顷之，未发，太子迟之，疑其改悔，乃复请曰：『日已尽矣，荆卿岂有意哉？丹请得先遣秦舞阳。』」 |
| 标记 | ◆ 出自原文 |

| 备注 | 史书很少直接写出一个人的动机，这里写了。**所以这一问不需要推演** |
|---|---|

---

### 卡 2 · 因果 ★

**问：荆轲为什么当场发怒？**

答：**因为在「等」和「疑」之间，原文写的是后一个。**

```
050  荆轲有所待……其人居远未来      他在等人，所以没有走
051  太子迟之，疑其改悔              太子把他的「没走」读成了「不干」
052  荆轲怒，叱太子                  他发怒
```

关键就是 `051` 的那四个字：**疑其改悔**。

他回的第一句是「**何太子之遣**」——你为什么这样急着打发人。

催的是行程，听进去的是**信用**。

| | |
|---|---|
| 依据 | `050`「荆轲有所待，欲与俱；其人居远未来」；`051`「太子迟之，疑其改悔」；`052`「荆轲怒，叱太子曰：『何太子之遣？往而不返者，竖子也！』」 |
| 标记 | ◆ 出自原文 ＋ ○ 合理推演 |

| 备注 | 前三行是原文。**「催」和「疑」之间那一步，原文没有写出来，是读出来的**——所以这条标了 ○ |
|---|---|

---

### 卡 3 · 陷阱题 ⚠️

**问：荆轲在等的那个人，是谁？**

答：**不知道。史书没有给名字。**

`050` 的全部内容：

> 荆轲有所待，欲与俱；其人居远未来，而为治行。

只有三件事：**他在等** / **要一起去** / **那人住得远，还没到**。

`053` 他自称「吾客」——还是没给名字。

**底本 91 段里，这个人从此没有再出现过。后世也没有定说。**

| | |
|---|---|
| 依据 | `050`「荆轲有所待，欲与俱；其人居远未来，而为治行」；`053`「待吾客与俱」 |
| 标记 | △ 存疑 |

| 备注 | 不要用别处的人去补这个空。高渐离有自己的位置（`005`、`055`），秦舞阳是 `049` 另派的副手——**原文没有把任何一个人和「吾客」对上** |
|---|---|

---

### 卡 4 · 结构

**问：`052` 和 `053` 是两段话，还是一段？**

答：**是一段。`053` 以「且」字开头。**

「且」是承接词。它接的正是 `052` 那句「往而不返者，竖子也」。

所以那天荆轲对太子丹说的，其实是这么一整段：

```
何太子之遣？往而不返者，竖子也！
且提一匕首入不测之强秦，仆所以留者，待吾客与俱。
今太子迟之，请辞决矣！
```

三层：**叱 → 说明理由 → 辞别**。说完就是两个字：「遂发」。

整个故事的情绪转折，落在 `052` 的头三个字上：**荆轲怒**。

| | |
|---|---|
| 依据 | `052`「荆轲怒，叱太子曰：『何太子之遣？往而不返者，竖子也！』」；`053`「『且提一匕首入不测之强秦，仆所以留者，待吾客与俱。今太子迟之，请辞决矣！』遂发」 |
| 标记 | ◆ 出自原文 ＋ ○ 合理推演 |

### 卡 5 · 细节

**问：那把匕首，是谁准备的？怎么办的？**

答：**是太子丹准备的。四道。**

```
豫求天下之利匕首            预先在天下访求
得赵人徐夫人匕首，取之百金    从赵人徐夫人处买下，一百金
使工以药焠之                让工匠拿毒药淬过
以试人，血濡缕，人无不立死者   用人来试——血只沾湿一缕，没有不立刻死的
```

| | |
|---|---|
| 依据 | `048`「于是太子豫求天下之利匕首，得赵人徐夫人匕首，取之百金，使工以药焠之，以试人，血濡缕，人无不立死者」 |
| 标记 | ◆ 出自原文 |

| 备注 | 「徐夫人」是男子（姓徐，名夫人）——**这是后人的注**，原文只写「赵人徐夫人匕首」。<br>「以试人」三个字没有主语，也没有说试的是谁 |
|---|---|

### 卡 6 · 对照

**问：「怒而叱之」这四个字，在荆轲身上出现过两次。哪两次？**

答：**一次是别人叱他，一次是他叱别人。**

| | 编号 | 原文 | 他的反应 |
|---|---|---|---|
| 别人叱他 | `004` | 鲁勾践与荆轲博，争道，鲁勾践**怒而叱之** | **嘿而逃去**（默不作声，走掉） |
| 他叱别人 | `052` | **荆轲怒，叱太子**曰 | —— |

同一个人。前一次他一个字没说就走了；这一次，他当着太子的面吼了出来。

**底本 91 段里，「荆轲怒」只出现过这一次（`052`）。**

| | |
|---|---|
| 依据 | `004`「荆轲游于邯郸，鲁勾践与荆轲博，争道，鲁勾践怒而叱之，荆轲嘿而逃去，遂不复会」；`052`「荆轲怒，叱太子曰」 |
| 标记 | ◆ 出自原文 ＋ ○ 合理推演 |

| 备注 | 两次用的是原文同一个「叱」字。「嘿而逃去」的「嘿」通「默」（`○ 训释`） |
|---|---|

### 卡 7 · 主题

**问：这一篇在整条链上，处在什么位置？**

答：**它是易水送别的直接前因。**

```
048–053   求匕首 · 定副手 · 等人 · 催 · 怒 · 遂发     ← 这一篇
054–058   白衣冠 · 祭路神 · 击筑 · 歌 · 就车而去       ← 下一篇
```

`053` 的最后两个字是「**遂发**」。
紧接着的 `054` 第一句是「太子及宾客知其事者，皆白衣冠以送之」。

**荆轲是被催走的。** 原文的顺序是：先争，后走，再送。

| | |
|---|---|
| 依据 | `053`「今太子迟之，请辞决矣！遂发」；`054`「太子及宾客知其事者，皆白衣冠以送之」 |
| 标记 | ◆ 出自原文 ＋ ○ 合理推演 |

| 备注 | 下一篇讲的是离别那一刻（歌、哭、走）。**这一篇讲的是离别之前那场争吵**——两边不重复 |
|---|---|

---

### 卡 8 · 沉默 ★

**问：这一篇里，史书没有写的是什么？**

答：**四件事。**

1. **那个人的名字。** `050`「其人」，`053`「吾客」——全程没有名字，后世也没有定说。
2. **`052` 之后太子丹的一个字。** `052` 与 `053` 全是荆轲在说。太子丹当天回没回话，原文不载。
3. **荆轲怒的时候在想什么。** 原文只给了两个动词：**怒**、**叱**。
4. **「往而不返者，竖子也」到底在说谁。** 原文不解释。

| | |
|---|---|
| 依据 | 本故事全部六段原文（`048`–`053`） |
| 标记 | — 史书的沉默 |

| 备注 | 这一篇的 `—` 是 20 条（33%），比 `07-tupo` 的 40% 低——**因为原文在这里真的说了话**。但没说的地方，仍然不说 |
|---|---|
