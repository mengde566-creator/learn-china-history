# 复习卡 · 故事 08 · 尾声 · 余波

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。
> **这一篇尤其如此——它的年代，底本一个都没有记。**

---

## 故事 08 · 尾声 · 余波（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇是从荆轲之死讲到高渐离之死。中间隔了多久？**

答：**底本不用年份记时。它只用相对记时。**

| 原话 | 在哪 | 什么意思 |
|---|---|---|
| 后五年 | `082` | 从荆轲入秦算起，第五年，秦灭燕 |
| 其明年 | `083` | 再过一年，秦并天下，立号为皇帝 |
| 久之 | `085` | 高渐离在宋子藏了很久——**多久，没有数** |

所以能算出来的是**间隔**，算不出来的是一个能画在时间轴上的区间。

而这一篇的三段，也不是连续的时间，是**三次收束**：

| 段 | 原文 | 内容 |
|---|---|---|
| 秦的报复 | `077`–`083` | 蓟城破、东保辽东、斩太子丹、灭燕、并天下 |
| 那个击筑的人 | `084`–`088` | 变名姓、彷徨不能去、更容貌而前、满座流涕 |
| 最后一击 | `089`–`091` | 召见、矐目、置铅、举筑、不中 |

| | |
|---|---|
| 依据 | `082`「后五年，秦卒灭燕，虏燕王喜」；`083`「其明年，秦并天下，立号为皇帝」；`085`「久之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 底本只用「后五年」「其明年」「久之」记时——**能算出间隔，画不出一条时间轴** |

| 备注 | 换成公元前后哪一年，底本不载——属后世系年，标 ○ 外证，**需另行核对** |
|---|---|

### 卡 2 · 因果 ★

**问：燕王喜为什么要杀自己的儿子？**

答：**因为一封信。**

`080` 记的是代王嘉写给燕王喜的信，信里把利害算得很清楚：

> 秦追燕追得急，**是因为太子丹**。
> 大王如果真杀了丹，把头献给秦王，秦王一定会解兵，社稷还能保得住祭祀。

`081` 就是结果：**燕王乃使使斩太子丹，欲献之秦。**

注意「**欲献之秦**」四个字——**杀他不是目的，把他送出去才是。**

然后是这一篇最冷的一句：

> **秦复进兵攻之。**

头送出去了。秦没有停。

| | |
|---|---|
| 依据 | `080`「秦所以尤追燕急者，以太子丹故也。今王诚杀丹献之秦王，秦王必解，而社稷幸得血食」；`081`「燕王乃使使斩太子丹，欲献之秦。秦复进兵攻之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 关键在「欲献之秦」四个字：**杀他不是目的，送出去才是**——而头送出去了，秦没有停 |

| 备注 | `082` 补上了结局：「后五年，秦卒灭燕，虏燕王喜。」**那封信保住的祭祀，多了五年** |
|---|---|

### 卡 3 · 陷阱题 ⚠️

**问：高渐离把铅灌进筑里扑向秦皇帝——他是为了给荆轲报仇吧？**

答：**底本没有这句话。**

`091` 记的是五个动作，一个接一个：

> 以铅置筑中 → 复进得近 → 举筑朴秦皇帝 → 不中 → 遂诛高渐离

**没有一句解释他为什么这么做。**

底本给他的全部心理记载，只有 `087` 那九个字：「念久隐畏约无穷时」——**他念的是藏下去没有尽头。** 那不是报仇，那是一个藏了很久的人算的一笔账。

而且：

- `085` 记的是他忍不住说话——**忍不住的不是恨，是听不下去别人的筑**
- `088` 记的是满座流涕——**他唱得让一屋子人哭了**

这两处离「报仇」都很远。

| | |
|---|---|
| 依据 | `091` 全段；`087`「念久隐畏约无穷时」；`085`「每出言曰」；`088`「客无不流涕而去者」 |
| 标记 | △ 史书未载，后世争讼 |
| 考点 | 「报仇」是读者的读法，不是底本的记载。**底本给他的心理只有九个字：「念久隐畏约无穷时」** |

| 备注 | **「报仇」是读者的读法，不是底本的记载。** 它足够动人——但它是被加进去的。这一条和「—」不同：`—` 是推不出来，`△` 是史书没写而读者一直在争 |
|---|---|

### 卡 4 · 细节

**问：这一篇里，高渐离说过什么？**

答：**一句。七个字。**

> `085`「每出言曰：『彼有善有不善。』」

那是一个佣工在主人家的堂下，听见堂上有人击筑，忍不住做的一句评价——**那个人击的筑，有好的地方，也有不好的地方。**

就是这七个字，把事情推下去了：

| 步 | 原文 | 发生了什么 |
|---|---|---|
| 1 | `085` 每出言曰 | 他忍不住开口 |
| 2 | `086` 从者以告其主 | 跟从的人去告发 |
| 3 | `086` 家丈人召使前击筑 | 主人叫他上来击 |
| 4 | `087` 更容貌而前 | 他拿出筑和好衣服，不再藏了 |
| 5 | `089` 人有识者 | 有人认出了他 |

**他败在自己的手艺上，也败在这一句话上。**

| | |
|---|---|
| 依据 | `085`「每出言曰：『彼有善有不善。』」；`086`「从者以告其主，曰：『彼庸乃知音，窃言是非』」；`087`；`089`「人有识者，乃曰：『高渐离也。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 全篇他只有一句话、七个字：「彼有善有不善」。**他败在自己的手艺上，也败在这一句话上** |

| 备注 | 《刺客列传》写高渐离，全是动作：击筑、彷徨、更容貌、置铅、举筑。**记下他说出口的话，全篇就这一处** |
|---|---|

### 卡 5 · 对照

**问：荆轲那一击和高渐离那一击，有什么一样？**

答：**两次都靠一件「献上去的东西」靠近了秦王，两次都没有中。**

| | 荆轲（`066`–`076`） | 高渐离（`091`） |
|---|---|---|
| 靠什么靠近 | 地图——献督亢之图 | 筑——皇帝要听他击筑 |
| 凶器藏在哪 | 图里（图穷而匕首见） | 筑里（以铅置筑中） |
| 谁让他更近 | 秦王自己：「取舞阳所持地图」 | 皇帝自己：「稍益近之」 |
| 那一下 | 左手把袖，右手揕之——**未至身** | 举筑朴秦皇帝——**不中** |
| 结果 | 被杀；秦王不怡者良久 | 被诛；终身不复近诸侯之人 |

**两次都是「他自己让对方再近一点」。**

而两次的落点不同：荆轲那一次，原文最后写的是赢家的不高兴（`076`「不怡者良久」）；高渐离这一次，原文最后写的是**赢家改掉了自己的做法**（`091`「终身不复近诸侯之人」）。

| | |
|---|---|
| 依据 | `065`「取舞阳所持地图」；`066`「图穷而匕首见」；`067`「未至身」；`076`「不怡者良久」；`090`「稍益近之」；`091` |
| 标记 | ○ 合理推演 |
| 考点 | 两次都靠「献上去的东西」靠近，两次都是**对方自己让他更近一步**——两次也都没有中 |

### 卡 6 · 动机

**问：他为什么忍不住要去评论别人的筑声？**

答：**底本只记了「忍不住」，没有记「为什么」。**

`085` 的原文是：

> 久之，作苦，闻其家堂上客击筑，**彷徨不能去**。每出言曰：「彼有善有不善。」

**「彷徨不能去」是动作，「每出言曰」是动作。** 两句之间，一个字的解释都没有。

而底本唯一一次写到他的念头，在 `087`：

> 而高渐离**念久隐畏约无穷时**，乃退，出其装匣中筑与其善衣，更容貌而前。

他念的是**藏下去没有尽头**。

**这不是解释他为什么说话——这是解释他为什么不再藏了。** 两件事，底本分在两段，中间没有连接词。

| | |
|---|---|
| 依据 | `085`；`087`「念久隐畏约无穷时」 |
| 标记 | — 史书的沉默 |
| 考点 | 底本写了「忍不住」这个动作，没写「为什么」。**「为什么不再藏了」原文答了，「为什么说话」一个字没给** |

| 备注 | 这两条要分开看：**「为什么不再藏了」原文给了一句；「为什么忍不住说话」原文一个字都没给。** 混在一起，就等于替他补了动机 |
|---|---|

### 卡 7 · 主题 ★

**问：全篇的最后一句是什么？它落在谁身上？**

答：**落在被行刺的那个人身上。**

> `091`「于是遂诛高渐离，终身不复近诸侯之人」。

《刺客列传》写了一整篇刺客——曹沫、专诸、豫让、聂政、荆轲，最后是这一段尾声。而它的最后七个字，写的不是刺客，是**被行刺的人从此改掉的活法**。

「诸侯之人」就是六国的人。荆轲是卫人，高渐离是燕人。**两个都是。**

- `067`：荆轲抓住了他的袖子
- `091`：高渐离举起了筑

两次都是六国的人靠到了极近的地方。**第二次之后，他不再让任何一个靠近。**

| | |
|---|---|
| 依据 | `091`「于是遂诛高渐离，终身不复近诸侯之人」；`067`「因左手把秦王之袖」；`049`「燕国有勇士秦舞阳」（副使亦燕人） |
| 标记 | ○ 合理推演 |
| 考点 | 最后七个字写的不是刺客，是**被行刺的那个人从此改掉的活法** |

| 备注 | 底本只记结果，不记原因。**推演链条是：两次近身行刺 → 不再接近六国的人。** 中间那一步，底本没有写 |
|---|---|

### 卡 8 · 沉默 ★

**问：这一篇里，史书没有写的是什么？**

答：**几乎全部的心。**

十五段原文，写的是：

> 论功 · 拔蓟城 · 东保辽东 · 遣书 · 斩丹 · 灭燕 · 并天下 · 变名姓 · 彷徨 · 更容貌 · 矐目 · 置铅 · 举筑 · 不中

**全是动作。**

没写的：

| 没写什么 | 在哪 |
|---|---|
| 他为什么忍不住说话 | `085` 只有「每出言曰」 |
| 「久之」是多久 | `085` 只有两个字 |
| 他唱的是什么 | `088` 只有「使击筑而歌」 |
| 满座的人为什么流泪 | `088` 只有结果 |
| 矐目的具体办法 | `090` 只有「乃矐其目」 |
| 铅怎么放进去的、放了多少 | `091` 只有「以铅置筑中」 |
| **他为什么扑上去** | `091` 只有五个动作 |

所以这一篇的 60 条问答里，有 **25 条**是「没有回答」，另有 **3 条**标 △（史书没写、后世一直在争）。

| | |
|---|---|
| 依据 | 本故事全部 15 段原文 |
| 标记 | — 史书的沉默 |
| 考点 | 动作写得比谁都清楚，心一个字都没有。**「史书没写」不是「晚于本场景」，也不是「人不在场」** |

| 备注 | **不替古人编心思，是这个产品最该守住的东西。** 这一篇里，那个人的动作写得比谁都清楚，心一个字都没有 |
|---|---|

## 附：这一篇的三个边界

> 复习时容易混的三件事，放在一起看。

| 类型 | 例子 | 系统怎么说 |
|---|---|---|
| **晚于本场景** | 问秦始皇「你后来是不是死在沙丘了」 | ⓘ 此事晚于本场景，本场景人物无从知晓。 |
| **人已经不在了** | 问荆轲「秦国后来怎么报复燕国」 | ⓘ 荆轲已经死了。本场景里，他不在场。 |
| **史书根本没写** | 问高渐离「你为什么要扑上去」 | ⓘ 底本只记动作，未载其心。 |

**第一种是时态问题，第二种是人的问题，第三种是史料的问题。**

三者混用，用户就会把"史书沉默"当成"剧透保护"——**那这一篇最重要的教学点就没了。**

**太子丹是第三种和第一、二种的交界**：他死在本篇中途（`081`），所以对 `083` 之后的事，他既属于"晚于本场景"，也已经是"人不在场"。
