# 复习卡 · 故事 08 · 尾声 · 余波

> 原则：**问动机，不问年代。**
> 目标是理解历史，不是应试。所以题目问"为什么"，不问"哪一年"。
> 读尾声时也要看清记时：有月份、相对年序与没有定量的「久之」。

---

## 故事 08 · 尾声 · 余波（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇的时间是怎么记的？**

答：**有月份、有相对年序，也有未定时长；并非全部没有时间线索。**

| 原文 | 位置 | 能知道什么 |
|---|---|---|
| 十月而拔蓟城 | `078` | 记了攻破蓟城的月份；不可直接当作公历十月 |
| 后五年 | `082` | 记秦灭燕的相对年序，不硬换成斩丹后整整五周年 |
| 其明年 | `083` | 接着上一年记秦并天下、立皇帝号 |
| 久之 | `085` | 高渐离隐居后过了一段时间，具体多久未载 |

本段可以整理相对次序；要换算为绝对年份，还需对读编年材料。后面的鲁勾践之评与太史公论赞，也不必强排成紧接行刺发生的两个现场。

| | |
|---|---|
| 依据 | `078`、`082`、`083`、`085`；`092`–`093` |
| 标记 | ◆ 出自原文 |
| 考点 | 时间线索并非全无；月份、相对年序与未定时长各自处理 |

---

### 卡 2 · 因果 ★

**问：燕王喜为什么要杀自己的儿子？**

答：**代王嘉来信称，杀丹献首，秦王便会解兵；燕王随后派人斩丹。**

`080` 的「秦王必解」是代王嘉的许诺，不是史家保证这个办法能保燕。`081` 写「欲献之秦」，紧接着却是「秦复进兵攻之」。

本段没有明确写秦方收到首级；别篇可以补证：《秦始皇本纪》二十一年明记「得太子丹之首」，《燕召公世家》二十九年记「斩丹以献秦」。其中收到首级的明确表述在《秦始皇本纪》。献首与秦继续进兵，两件事要分别看。

| | |
|---|---|
| 依据 | `080`–`081`；外证《史记·秦始皇本纪》二十一年、《燕召公世家》二十九年 |
| 标记 | ○ 外证 |
| 考点 | 人物承诺、本段意图、别篇收到首级的记载，不能混成同一种证据 |

---

### 卡 3 · 辨析 ⚠️

**问：高渐离举筑击秦皇帝，是为了给荆轲报仇吗？**

答：**本段没有明说这个动机；与荆轲的交情，也不能独自证明行刺目的。**

`005` 记两人的交游，`055` 记易水击筑送行，`091` 记高渐离置铅、近前、举筑不中而被诛。把它们连起来，读者会想到报仇，但底本没有在这一击前作这样的说明。

`087` 确实记了他的念头：不愿长期隐匿、惶恐穷困。那解释的是重新示人的选择，不能直接替代后来行刺的理由，也不足以排除报仇。

| | |
|---|---|
| 依据 | `005`、`055`；`087`「念久隐畏约无穷时」；`091` |
| 标记 | ○ 合理推演 |
| 考点 | 承认已有交情与心理记载，不把它们自动等同于行刺动机 |

---

### 卡 4 · 细节

**问：「彼有善有不善」怎样把隐居中的高渐离带回众人眼前？**

答：**评筑引来主人的召见，技艺受到称赞；随后他主动取筑更衣，重新示人。**

| 次序 | 经过 |
|---|---|
| `085` | 听客击筑，屡次评论演奏有善有不善 |
| `086` | 侍从告诉主人他懂音乐，主人召他击筑，众人称善赐酒 |
| `087`–`088` | 他考虑长期隐匿无尽头，取出筑和好衣，重新示人，被奉为上客 |
| `089` | 名声传到秦始皇处，被召见，有人认出他 |

「从者以告其主」是转告其懂音乐、私下评论，不是原文指控他犯罪的「告发」。留下一处评语，也不等于他只说过一次；原文正用了「每出言」。

| | |
|---|---|
| 依据 | `085`–`089` |
| 标记 | ◆ 出自原文 |
| 考点 | 把评艺、获召、主动示人与被识破的经过接全，不只归因于一句话 |

---

### 卡 5 · 对照

**问：荆轲那一击和高渐离那一击，有什么一样？**

答：**两人都借随身物品近身攻击，最终都没有杀死秦王；接近的途径不同。**

| | 荆轲 | 高渐离 |
|---|---|---|
| 接近途径 | 献首献图，受命取图、奏图 | 因善击筑被召，后来渐获亲近 |
| 隐藏凶器 | 图中藏匕首 | 筑中置铅 |
| 进攻 | 把袖、持匕揕之未至身；后投匕不中 | 举筑朴秦皇帝不中 |
| 本段落点 | 被杀，秦王不怡良久 | 被诛，皇帝终身不复近诸侯之人 |

高渐离并非献上一把筑来求见；`065` 也只是命荆轲取图，不能等同于 `090` 明写的「稍益近之」。

| | |
|---|---|
| 依据 | `065`–`067`、`074`–`076`；`089`–`091` |
| 标记 | ○ 合理推演 |
| 考点 | 对照物品与进攻，也保留献图求见和凭技艺被召的差别 |

---

### 卡 6 · 动机

**问：高渐离为什么重新以乐师身份示人？**

答：**原文给了他的考虑：长期隐匿、惶恐穷困，没有尽头。**

`087` 写「念久隐畏约无穷时」，随后他取出匣中的筑与好衣，整理仪容后上前。

这与 `085` 听筑徘徊、屡次评论，以及 `091` 举筑行刺，是不同的选择。`087` 的考虑说明他为何不再这样藏下去，没有包办此前每次评筑及后来行刺的全部动机。

| | |
|---|---|
| 依据 | `085`「彷徨不能去。每出言曰」；`087`「念久隐畏约无穷时」 |
| 标记 | ◆ 出自原文 |
| 考点 | 让原文明写的念头帮助理解选择，不把编者概括冒充原文字眼 |

---

### 卡 7 · 主题 ★

**问：高渐离那一击之后，底本把镜头停在了谁身上？**

答：**暂时落在秦皇帝身上，写他此后不再亲近诸侯各国之人。**

`091` 高渐离被诛后，接着写「终身不复近诸侯之人」。前一次行刺之后 `076` 写秦王不怡良久，这里则写行为的长期改变。

「诸侯之人」可理解为诸侯各国之人，保留原文的宽称，不硬按六国名单缩窄。文末还有 `092` 鲁勾践之评与 `093` 太史公论赞；这不是全传最后一句。

| | |
|---|---|
| 依据 | `076`；`091`「终身不复近诸侯之人」；`092`–`093` |
| 标记 | ○ 合理推演 |
| 考点 | 叙事暂落在被刺者的改变，不替其补出全部恐惧，也不缩窄原称 |

---

### 卡 8 · 辨析 ★

**问：尾声中哪些想法有记录，哪些仍不明确？**

答：**高渐离的考虑、鲁勾践的反省与太史公的评价，都有文字；举筑行刺的具体动机仍未明说。**

| 位置 | 已有记录 |
|---|---|
| `087` | 高渐离想到长期隐匿、惶恐穷困没有尽头 |
| `092` | 鲁勾践感叹自己不知人，并评论刺剑技术 |
| `093` | 太史公辨驳传闻，评价五位刺客的志意 |

尚未明说的，包括 `091` 为什么决定行刺、铅的具体准备过程，以及 `088` 所唱歌辞。正文只说矐目；具体失明方法则有《索隐》引述的解释，要另标注家层次。不能把这些未详之处扩大成全篇「全是动作、心一个字没有」。

| | |
|---|---|
| 依据 | `087`–`093` |
| 标记 | ○ 合理推演 |
| 考点 | 已写的考虑与评价照实读；未详的动机与现场细节不补写 |

## 附：这一篇的三个边界

> 复习时容易混的三件事，放在一起看。

| 类型 | 例子 | 系统怎么说 |
|---|---|---|
| **晚于本场景** | 问秦始皇「你后来是不是死在沙丘了」 | ⓘ 此事晚于本场景，本场景人物无从知晓。 |
| **人已经不在了** | 问荆轲「秦国后来怎么报复燕国」 | ⓘ 荆轲已经死了。本场景里，他不在场。 |
| **史书根本没写** | 问高渐离「你为什么要扑上去」 | ⓘ 底本只记动作，未载其心。 |

**第一种是时态问题，第二种是人的问题，第三种是史料的问题。**

三者混用，用户就会把"史书沉默"当成"剧透保护"——**那这一篇最重要的教学点就没了。**

**太子丹是第三种和第一、二种的交界**：他死在本篇中途（`081`），所以对 `083` 之后的事，他既属于"晚于本场景"，也已经是"人不在场"。
