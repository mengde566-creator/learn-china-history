## 一、情境铺陈

```
回到554年初 · 长安 ← ○

江陵出兵之前，西魏内部已经换过皇帝。元宝炬去世后，儿子元钦继位；宇文泰仍掌握朝政，自己的女儿又是元钦的皇后。 ← ○

宇文泰杀了尚书元烈，元钦对此有怨言。宗室有人劝皇帝收住，元钦没有听。 ← ○

皇帝对执政者的不满，再一次摆到了这个朝廷里。 ← ○
```

## 二、情节点

### 情节点 1 · 废帝与执笔的人

> 宇文泰与公卿议定，废掉元钦，另立元廓。
>
> 新皇帝宴请群臣时，史官柳虬在朝中执简写下批评：元宝炬曾把儿子托付给宇文泰，他又以女儿为皇后，如今先帝的继承人却被废了，责任还能归谁？
>
> 宇文泰让卢辩作诰，承认未能教导好先帝之子，也承认此事可能成为后世议论自己的把柄。皇帝换了，责任并没有因一份诰书就消失。

| 标记 | ○ |
| 原文 | `043` |
| 摘句043 | 魏史柳虬執簡書於朝曰：「廢帝，文皇帝之嗣子。年七歲，文皇帝託於安定公曰：『是子才，由于公，不才，亦由于公，宜勉之。』公既受茲重寄，居元輔之任，又納女為皇后，遂不能訓誨有成，致令廢黜，負文皇帝付屬之意，此咎非安定公而誰？」 |
| 依据 | 043中书于朝指书写，保留史官批评与随后作诰，不编一场当面口头辩论。诰书是政治自陈，不等同已经证实元钦被废全因本人不听教导。 |

### 情节点 2 · 改的是官名，也是办事的朝廷

> 556年，西魏正式施行仿《周礼》的六官。宇文泰任太师、大冢宰，军政重臣也进入新的官职安排。
>
> 这套办法并非那年才忽然想出。此前宇文泰已经让苏绰、卢辩等依周制筹划，只是编次尚未完成，政务仍归旧有机构。到这时，准备才告一段落，开始施行。
>
> 国号还是魏，掌握朝廷的人已经为它重新安排了官制。苏绰死去十年，他参与过的政务工作仍由后来的人续下去。

> 军队也有了层层统属。大统年间取得柱国职位的八人之中，宇文泰总揽军国，元欣留在朝中，其余六人各督两名大将军，再往下统领开府与各军。官号相同的人，实际掌握的军队并不一样。

| 标记 | ○ |
| 原文 | `044` |
| 摘句071 | 自大統十六年以前，任者凡有八人。太祖位總百揆，督中外軍。魏廣陵王欣，元氏懿戚，從容禁闈而已。此外六人，各督二大將軍，分掌禁旅，當爪牙禦侮之寄。 |
| 依据 | 044明确先前筹划、至556年施行；071–072说明此前已形成的分级统军。官制与军队组织的建立有过程，不把它们写成一日完成。 |

### 情节点 3 · 云阳的托付

> 这一年，宇文泰北巡途中患病，召来侄子宇文护，托他辅佐自己的继承人宇文觉。《宇文护传》把这次受命记在泾州；行程最后到了云阳。
>
> 十月，他死在云阳宫。儿子接任太师、大冢宰，侄子承担辅佐的任务，旧日功臣仍各有兵望。这个政权要怎样继续，并不是换一个名字便能安顿的事。
>
> 《于谨传》记，诸公都想执政，彼此不服。宇文护私下求助于谨；次日议事，于谨主张军国事务归他，又先向他再拜，诸公才跟着拜，议论终于定下。
>
> 从当年赶去接掌贺拔岳的军队，到如今把自己的位置交出去，宇文泰走到了另一端。他没有活着看到这次交接的结果。

| 标记 | ○ |
| 原文 | `045` |
| 摘句074 | 謹既太祖等夷，護每申禮敬。至是，謹乃趨而言曰：「公若統理軍國，謹等便有所依。」遂再拜。羣公迫於謹，亦再拜，因是眾議始定。 |
| 摘句075 | 太祖西巡至牽屯山，遇疾，馳驛召護。護至涇州見太祖，而太祖疾已綿篤。 |
| 依据 | `045`、`065`、`074`、`075`。本纪简写病还云阳及托孤，宇文护传分记泾州受命、云阳去世、长安发丧；于谨传记诸公争执政、于谨出面及再拜。人物动机和会场描写均归传文，不增现场对白。 |

### 情节点 4 · 周是身后的国号

> 丧葬以后，宇文护派人向西魏皇帝示意，推动禅代。宇文觉受封周公，随后接受西魏让位。557年，他即天王位，周代替魏。
>
> 宇文泰被追尊为文王，后来再被追尊为文皇帝。那个在晋阳险些被杀、在河桥靠李穆的马脱险的人，终于以开国先人的名义留在另一朝的本纪里。
>
> 他生前没有消灭东面的高氏政权。高欢先走了，他也走了，留下的军队、官府与家族继续相争；留下的土地上，还有必须生活下去的人。

| 标记 | ○ |
| 原文 | `045` |
| 依据 | `045`、`065`、`066`、`076`。076补宇文护派人推动禅代，天命说法归该传的政治解释；065–066记宇文觉继职、受禅、即天王位与追尊；文皇帝追尊见045后句。不倒置为宇文泰在世称帝，不把禅让文书等同全部权力过程。 |

## 四、背景卡

### 宇文护和宇文觉 ○

宇文护是宇文泰的侄子、中山公，接受辅佐的遗命；宇文觉是宇文泰的儿子、承接名位的人。于谨支持宇文护执掌军国，说明继承名位与取得实际执政权不是一回事。两人不是同一个继承人，也不是高欢的儿子高澄、高洋。

> **依据**：045、065–066、074–076；分别读遗命、继职、议定执政与推动禅代。

### 北周建立的年份 ○

西魏恭帝三年十二月的受禅跨入公历557年；周孝闵帝元年正月即天王位。正文以557年北周建立统摄，仍保留旧历次序，不把宇文泰556年去世与北周建立写成同日。

> **依据**：065–066；此处未另换算一个精确的公历日。

### 大业与失去自由的人 ○

官制、选人和军队组织，是宇文泰留下的部分；元修被害、元钦被废、江陵士民被掳，也是这段权力的后果。称其为北周奠基者，不应遮去这些发生在同一生涯里的事。

> **依据**：043–045、065–066；元修058、江陵042、054见前篇，均保留实际来源，不以追尊反证正当性。

### 八柱国怎样带兵 ○

《周书》把大统十六年以前的八位柱国列在一起，又明确区分统军职任：

| 谁 | 所记位置 |
|---|---|
| 宇文泰 | 总理军国，督中外军 |
| 元欣 | 宗室重臣，居于朝中 |
| 其余六位柱国 | 每人督两名大将军，分掌禁旅 |

大将军再各统两名开府，每开府领一军。这里说明的是统属层级，不是八支兵数相等的队伍；所列门第的声望，又带着史书作者回望前代的眼光。

> **依据**：071–072。原书另说一些同官名者不在这套实领兵序列之内。
