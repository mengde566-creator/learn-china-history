# 复习卡 · 故事 02 · 涡阳

> 原则：**问动机，不问年代。**

---

## 故事 02 · 涡阳（9 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：他在涡阳这一军里，到底是什么位置？**

答：**他不是主帅，是有隶属的一路。**

| 原文 | 说明 |
|---|---|
| `007` 隸領軍曹仲宗伐渦陽 | 他隶属曹仲宗 |
| `010` 乃還與諸將連營而進 | 打赢了，还要回来跟诸将一起 |
| `013` 仲宗壯其計，乃從之 | 是否采纳，由曹仲宗决定 |

**到 `012` 之前，他一直在这条线以内。**

| | |
|---|---|
| 依据 | `007`「隸領軍曹仲宗伐渦陽」；`010`「慶之乃還與諸將連營而進」；`013`「仲宗壯其計，乃從之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「隶」字是关键：他是被派到曹仲宗部下的一路，不是这一军的主帅 |

---

### 卡 2 · 动机 ★

**问：韦放反对出战，他的理由错了吗？**

答：**没错，只是站的位置不同。**

韦放说的三句，句句都成立：

| 韦放说 | 成立吗 |
|---|---|
| 前锋必是轻锐 | 常见情况 |
| 与战若捷，不足为功 | 从全军升赏看，成立 |
| 如其不利，沮我军势 | 从全军风险看，成立 |

陈庆之的回应没有反驳这三句。**他换了一个前提：魏人远来，已经疲倦。**

| | |
|---|---|
| 依据 | `008`「與戰若捷，不足為功，如其不利，沮我軍勢」；`009`「魏人遠來，皆已疲倦，去我既遠，必不見疑」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两个人争的不是兵法，是「现在该不该冒险」；`008` 与 `009` 是两种算法 |

---

### 卡 3 · 细节 ★

**问：「杖节军门」是怎么一个画面？**

答：**他持着朝廷的节，在军门申令。**

节是凭信，代表授权。**「杖」是执、持，不是把节插在地上。**

`012` 之后紧接 `013`「仲宗壯其計，乃從之」——**没有人再提退兵。**

| | |
|---|---|
| 依据 | `012`「慶之杖節軍門曰」；`013`「仲宗壯其計，乃從之」 |
| 标记 | ○ 训释 |
| 考点 | 顺序是「杖节」在前、「说话」在后：先持节，再说话，身份先摆出来 |

---

### 卡 4 · 因果 ★

**问：「密敕」是真的吗？**

答：**底本不回答。**

`012` 只记他说了这句话：「審欲班師，慶之別有密敕，今日犯者，便依明詔。」

**有没有这道密敕，这一篇一个字都没有交代。**

能确定的是结果：说完之后，退兵的动议没有了。

| | |
|---|---|
| 依据 | `012` |
| 标记 | — 不回答 |
| 考点 | 「他说有」和「真有」是两件事；史书只记前者时，不要替它补后者 |

---

### 卡 5 · 结构

**问：为什么先陷四垒，再打九城？**

答：**因为剩下的九城不是被打垮的。**

```
013  衔枚夜出 → 陷其四垒 → 王纬乞降
014  陈其俘馘 → 鼓噪而攻之 → 遂大奔溃
```

「陳其俘馘」是把战果摆出来给守城的人看。**先给看见，再给攻打。**

| | |
|---|---|
| 依据 | `013`「陷其四壘，渦陽城主王緯乞降」；`014`「乃陳其俘馘，鼓噪而攻之，遂大奔潰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 九城「兵甲猶盛」却一攻就溃——底本把这个落差写得很清楚 |

---

### 卡 6 · 叙述

**问：「渦水咽流」四个字在写什么？**

答：**写水，不写人。**

尸体堵在涡水里，水声都哑了。底本没有给任何数字。

数字在别处：「降城中男女三萬餘口」——那是**降人**，不是战死的人。

| | |
|---|---|
| 依据 | `014`「斬獲略盡，渦水咽流，降城中男女三萬餘口」 |
| 标记 | ◆ 出自原文 |
| 考点 | 战死与降人是两笔账；「咽流」是形容，不能当统计用 |

---

### 卡 7 · 动机

**问：高祖为什么在诏书里写「本非将种，又非豪家」？**

答：**底本只记「高祖嘉焉」，没有解释为什么写这两句。**

这封手诏不是责难，是嘉奖里的评语：

```
本非将种，又非豪家
觖望风云，以至于此
可深思奇略，善克令终
```

四句里有两句是提醒，一句是期许。**「善克令终」是要他善终。**

| | |
|---|---|
| 依据 | `015`「高祖嘉焉，賜慶之手詔曰……」——**「嘉」是原文；「为什么写」底本不载，下面的读法是推的** |
| 标记 | ○ 合理推演 |
| 考点 | 「本非将种」是与「觖望风云」连读的：正因为不是，才说「以至于此」 |

---

### 卡 8 · 细节

**问：十三城是同时打下来的吗？**

答：**不是，分了两次。**

| 次 | 打了几座 | 怎么打的 |
|---|---|---|
| 第一次 | 四垒 | 衔枚夜出，偷袭 |
| 第二次 | 九城 | 陈俘馘、鼓噪而攻 |

中间夹着一个「渦陽城主王緯乞降」。

| | |
|---|---|
| 依据 | `013`、`014` |
| 标记 | ◆ 出自原文 |
| 考点 | 「掎角作十三城」是先摆好阵形；四垒与九城是两次不同的打法 |

---

### 卡 9 · 因果

**问：这一战之后，涡阳归了谁？**

答：**归梁，朝廷在那里设了西徐州。**

`014` 记的是「詔以渦陽之地置西徐州」。

**设州是给这块地一个编制，不是给陈庆之的赏。** 这一篇里他的赏赐只有那封手诏。

| | |
|---|---|
| 依据 | `014`「詔以渦陽之地置西徐州」；`015` |
| 标记 | ◆ 出自原文 |
| 考点 | 地方建置与个人封赏是两件事；这一篇只记了后者的一部分 |

---

> **这一篇的读法：** 一个人从「有隶属」走到「说话算数」。<br>
> 转折不在打赢，在 `012` 那一句**「審欲班師，慶之別有密敕」**——真不真，底本没说。
