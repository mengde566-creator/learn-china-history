# 复习卡 · 故事 05 · 余生

> 原则：**问动机，不问年代。**

---

## 故事 05 · 余生（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇为什么没有高潮？**

答：**因为它记的是十年间一件件办完的差事，不是一场战役。**

| 段 | 事 | 结果 |
|---|---|---|
| `036` | 沙门僧强自称帝，众三万 | 派他去讨 |
| `037` | 白下临饯，「不宜决战」 | 不到十二天，斩二人 |
| `038` | 围悬瓠，破数路魏军 | 一地一句，清单式 |
| `039` | 罢镇兵、停转运、开田六千顷 | 仓廪充实 |
| `040` | 侯景七万寇楚州 | 援军未至，已破之 |
| `041` | 豫州饥，开仓赈给 | 八百人请立碑；同年卒 |

**落点不在某一场仗，在 `042` 那两行总述。**

| | |
|---|---|
| 依据 | `036`–`041` 各段 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的结构是「越来越平」，不是「越来越紧」 |

---

### 卡 2 · 细节 ★

**问：「射不穿札，马非所便」是什么意思？**

答：**箭射不透甲片；马不是他所擅长的。**

| 词 | 意思 |
|---|---|
| 札 | 甲片 |
| 穿札 | 射透甲片 |
| 非所便 | 不擅长、不习惯 |

**两句都是「短处」的写法。** 底本把这两句放在他一生评价的位置上。

| | |
|---|---|
| 依据 | `042`「射不穿札，馬非所便」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「札」是甲片不是纸；这一句是说射力，不是说不识字 |

---

### 卡 3 · 因果 ★

**问：底本为什么要写他的短处？**

答：**因为紧接着就是他的长处，中间只有一个「而」字。**

```
性祗慎，衣不纨绮，不好丝竹
射不穿札，马非所便
而善抚军士，能得其死力
```

**前四样都不是长处，第五样是。** 转折只有一个字。

| | |
|---|---|
| 依据 | `042`「而善撫軍士，能得其死力」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「死力」不是「拼命」，是「肯为他去死」；这是别人对他的评价 |

---

### 卡 4 · 细节

**问：他死时多大？**

答：**五十六。**

`041`：「五年十月，卒，時年五十六。」

**底本只给这个数，没给生年。** 要推他的生年，得从这一年倒回去。

| | |
|---|---|
| 依据 | `041` |
| 标记 | ◆ 出自原文 |
| 考点 | 「时年五十六」是记死时的岁数；生年是后世倒推的，不在原文里 |

---

### 卡 5 · 结构

**问：这一篇里，百姓替他做了一件事，是什么？**

答：**八百人上表，请求为他树碑颂德。**

`041`：「州民李昇等八百人表請樹碑頌德，詔許焉。」

**这是全传唯一一处百姓为他上书。** 而他做的事是「开仓赈给」。

| | |
|---|---|
| 依据 | `041` |
| 标记 | ◆ 出自原文 |
| 考点 | 碑立不立起来，这 43 段没有下文；能确定的只有诏书准了 |

---

### 卡 6 · 因果

**问：侯景七万人来，为什么被他打破？**

答：**底本只给了一句天气。**

```
040  侯景率众七万寇楚州，贻庆之书使降
040  敕遣湘潭侯退等赴援
040  军至黎浆，庆之已击破景
040  时大寒雪，景弃辎重走
```

**援军还没到，仗已经打完了。** 破敌的经过一个字没有，只有「大寒雪」和「弃辎重走」。

| | |
|---|---|
| 依据 | `040` |
| 标记 | ◆ 出自原文 |
| 考点 | 「已击破景」在援军到达之前；这一句是这一段的重点 |

---

### 卡 7 · 动机 ★

**问：史臣给了他什么评价？**

答：**「颇、牧、卫、霍之亚」。**

| 名 | 是谁 |
|---|---|
| 颇 | 廉颇 |
| 牧 | 李牧 |
| 卫 | 卫青 |
| 霍 | 霍去病 |

**「亞」是次一等。** 史臣把他放在这四个人之下、常将之上。

后面还有一句：「蟬冕組珮，亦一世之榮矣。」

| | |
|---|---|
| 依据 | `043` |
| 标记 | ◆ 出自原文 |
| 考点 | 「亚」的位置要读准：不是「不亚于」，是「次一等」 |

---

### 卡 8 · 叙述

**问：史臣为什么把「早侍高祖」也写进评语里？**

答：**因为他的一生是从那张棋盘边开始的。**

`043` 的后半句是：

```
庆之警悟，早侍高祖
既预旧恩，加之谨肃
蝉冕组佩，亦一世之荣矣
```

**一半是战功，一半是他在皇帝身边坐着的那几十年。** 史臣两样都写了。

| | |
|---|---|
| 依据 | `043`「慶之警悟，早侍高祖，既預舊恩，加之謹肅」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「谨肃」和 `042` 的「祗慎」是同一路评价；史臣的结论与传记本身对得上 |

---

> **这一篇的读法：** 一个人打了二十年仗，留在传末的是一句「射不穿札」。<br>
> **底本没有替他圆这个短，反而把它放在了最末。**
