# 复习卡 · 故事 04 · 嵩高

> 原则：**问动机，不问年代。**

---

## 故事 04 · 嵩高（9 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里，哪些事是他自己决定的？**

答：**只有三件，而且三件都被堵回来了。**

| 他的动作 | 结果 |
|---|---|
| `027` 劝元颢请精兵 | 元延明一句话，没成 |
| `031` 固求赴徐州之镇 | 元颢不遣 |
| `033` 守北中郎城，三日十一战 | 尔朱荣从硖石渡了河 |

其余的事——生疑、停兵、南下、山洪——**没有一件是他做的决定。**

| | |
|---|---|
| 依据 | `027`、`031`、`033` 各段 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的分量在「他没能做什么」，不在「他做了什么」 |

---

### 卡 2 · 动机 ★

**问：他知道元颢要变心，为什么还替他请兵？**

答：**底本只记了「心知之」和「密为其计」两句，没有解释。**

```
026  元颢「外同內異，言多忌刻」
027  庆之「心知之，亦密為其計」
027  他说的是：请精兵、部送南人
```

**知道了，还替他算。** 这两句之间没有过渡，底本也没有评语。

| | |
|---|---|
| 依据 | `027`「慶之心知之，亦密為其計」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「密为」的密字说明他做这件事没有经过元颢以外的第三人 |

---

### 卡 3 · 因果 ★

**问：元延明一句话，为什么能改变结局？**

答：**因为那句话每一句都在为元颢算。**

| 元延明说 | 指向 |
|---|---|
| 兵不出数千，已自难制 | 现在就已经压不住 |
| 增其众，宁肯复为用乎 | 加了兵，他怎么还听你 |
| 权柄一去，动转听人 | 权是你的，不是他的 |
| 魏之宗社，于斯而灭 | 最重的一句放在最后 |

**至于援兵够不够用，这句里一个字没提。**

| | |
|---|---|
| 依据 | `028` |
| 标记 | ◆ 出自原文 |
| 考点 | 这番话是政治判断，不是军事判断；它的落点始终是「权柄」 |

---

### 卡 4 · 动机 ★

**问：马佛念劝他屠颢据洛，他为什么不做？**

答：**底本只给四个字：「慶之不從」。**

马佛念的话说得很完整：

```
功高不赏，震主身危
自古以来，废昏立明，扶危定难，鲜有得终
屠颢据洛，则千载一时也
```

**理由、先例、机会，三样都给到了。** 然后就是「庆之不从」。

**为什么不做，这一篇一个字都没有。**

| | |
|---|---|
| 依据 | `030` |
| 标记 | — 不回答 |
| 考点 | 这是全传里最像政变的一幕；底本记了方案，不记拒绝的理由 |

---

### 卡 5 · 细节

**问：他为什么要「固求」去徐州？**

答：**底本只记他「固求之镇」；可以推想，那是他想离开洛阳的一次尝试。**

`031` 记的顺序：

```
顥前以庆之为徐州刺史 → 因固求之镇 → 颢心惮之，遂不遣
```

**徐州刺史是他自己的官；去上任，等于离开洛阳。**

元颢用一番很客气的话把这个出口堵上了。

| | |
|---|---|
| 依据 | `031`「因固求之鎮。顥心憚之，遂不遣」——**「固求之鎮」「遂不遣」是原文；离开洛阳的出口，这一层是推的** |
| 标记 | ○ 合理推演 |
| 考点 | 「心惮之」三个字说明元颢知道他想走，所以不放 |

---

### 卡 6 · 结构

**问：他的最后一场仗，底本写了什么？**

答：**只有一个数目。**

`033`：「慶之渡河守北中郎城，三日中十有一戰，傷殺甚眾。」

**没有胜负，没有战果，没有对手的名字。** 三天十一战之后，下一段就是尔朱荣渡河。

| | |
|---|---|
| 依据 | `033` |
| 标记 | ◆ 出自原文 |
| 考点 | 「伤杀甚众」说的是双方的代价，不是战果 |

---

### 卡 7 · 因果 ★

**问：全军是怎么没的？**

答：**不是被打垮的，是遇上山洪。**

```
035  慶之馬步數千，結陣東反
035  榮親自來追
035  值嵩高山水洪溢，軍人死散
```

**一个「值」字**：是遇上的，不是被设计出来的。

底本写他的结局用的是一场天灾，不是一场决战。

| | |
|---|---|
| 依据 | `035` |
| 标记 | ◆ 出自原文 |
| 考点 | 「死散」两个字要分开读：死了一部分，散了另一部分 |

---

### 卡 8 · 细节 ★

**问：他为什么要剃发做僧人？**

答：**底本不回答，只记了动作和路线。**

```
落须发为沙门 → 间行至豫州 → 程道雍等潜送出汝阴 → 至都
```

**一个败军之将走在路上会被认出来，僧人不会。** 这是推的，不是原文写的。

| | |
|---|---|
| 依据 | `035`「慶之乃落鬚髮為沙門，間行至豫州」 |
| 标记 | — 不回答 |
| 考点 | 动作有记载，动机没有；「怕死」「避祸」都是后人替他补的 |

---

### 卡 9 · 因果

**问：一个军队散了的将军，回来为什么还能封侯？**

答：**底本只说「仍以功」，没有说这个功指什么。**

`035` 的最后一句：「至都，仍以功除右衛將軍，封永興縣侯，邑一千五百戶。」

**「仍以功」三个字**：功劳还在，没有作废。**从上下文看，最可能指他先前北伐的战功；这一步是推的，不是原文写的。**

| | |
|---|---|
| 依据 | `035`「至都，仍以功除右衛將軍」；`033`「凡所得城，一時反叛」——**「仍以功」是原文；功指先前打下的城，这一层是推的** |
| 标记 | ○ 合理推演 |
| 考点 | 「仍」字说明这是延续原来的记功，不是新的恩典；但功指什么，底本不载 |

---

> **这一篇的读法：** 一个人把能做的三件事都做了，三件都被堵回来。<br>
> 最后带走他的不是敌人，是**嵩高山下的那场水**。
