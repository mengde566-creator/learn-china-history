# 复习卡 · 故事 01 · 斩关夜退

> 原则：**问动机，不问年代。**

---

## 故事 01 · 斩关夜退（9 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里，他做过几件事？**

答：**三件，一件比一件难。**

| 次序 | 事 | 结果 |
|---|---|---|
| 一 | 接应彭城来归附的元法僧 | 办完了，回来升官 |
| 二 | 送豫章王入镇徐州，破浔梁一垒 | 一鼓便溃 |
| 三 | 豫章王弃军奔魏，全军溃散 | 他砍开关门，把兵带回去 |

前两件是差事，第三件是收场。**底本把三件事按时间排下来，没有一句评语。**

| | |
|---|---|
| 依据 | `003`「以慶之為武威將軍，與胡龍牙、成景俊率諸軍應接」；`004`「進薄其壘，一鼓便潰」；`005`「慶之乃斬關夜退，軍士得全」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三件差事的性质不同：接应、送人、退兵。前两件有主将，第三件他必须自己决定 |

---

### 卡 2 · 动机 ★

**问：他为什么会被派去带兵？底本给了理由吗？**

答：**没有给理由，只给了三件排在一起的事。**

```
001  他一直待在萧衍身边，别人睡了，他醒着
002  他做主书，散财聚士，「常思效用」
003  然后他就出现在了带兵的名单里
```

「常思效用」四个字，是他这一边唯一一句表态。

**从文书到将军，中间没有一步是底本写明的。** 这一步是读者自己走过去的。

| | |
|---|---|
| 依据 | `002`「散財聚士，常思效用」 |
| 标记 | ○ 合理推演 |
| 考点 | 底本没有写「于是他被任命为将军」这样的过渡句；三件事之间是并置，不是因果 |

---

### 卡 3 · 细节 ★

**问：「斬關夜退」四个字，拆开是什么？**

答：**砍开关门；当夜退走。**

| 字 | 意思 | 为什么重要 |
|---|---|---|
| 斩 | 砍 | 关门是要有人守的，砍它等于打一场小仗 |
| 关 | 关隘、城门 | 出不去，人就留在溃散里 |
| 夜 | 当夜 | 天亮以前必须走完 |
| 退 | 退兵 | 不是溃逃，是有动作的退 |

**「退」前面的两个动词，说明这一夜不是逃，是打出来的。**

| | |
|---|---|
| 依据 | `005`「慶之乃斬關夜退，軍士得全」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「斩关」是有阻力的动作；把它读成「推门出去」就丢了这一段的分量 |

---

### 卡 4 · 因果 ★

**问：他拦不住溃散，为什么还能把人带回去？**

答：**因为这两件事不矛盾。**

| 原文 | 说的是什么 |
|---|---|
| 眾皆潰散，諸將莫能制止 | 全军已经散了，谁也止不住 |
| 慶之乃斬關夜退，軍士得全 | 在散掉的全军里，有一部分人跟着他出去了 |

**止不住的是「全军」，带得走的是「军士」。** 底本没有说这两句哪一句更重要。

| | |
|---|---|
| 依据 | `005`「眾皆潰散，諸將莫能制止。慶之乃斬關夜退，軍士得全」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「得全」不等于「没有损失」——它说的是有人活着回来了 |

---

### 卡 5 · 结构

**问：萧衍为什么信他？**

答：**底本只写了一个画面：别人都睡着了。**

```
高祖性好棋，每从夜达旦不辍
等辈皆倦寐
惟庆之不寝，闻呼即至
```

三行里没有一个字提到能力、家世、功劳。**只有「还在」和「喊得应」。**

| | |
|---|---|
| 依据 | `001`「等輩皆倦寐，惟慶之不寢，聞呼即至，甚見親賞」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「每」「惟」两个字：不是一次，是每一次；不是几个人，是只有他 |

---

### 卡 6 · 细节

**问：「奉朝请」是什么意思？**

答：**一种名位：有资格参加朝会，不是实职。**

`002` 记他「除奉朝請」；紧接着 `003` 就被派出去接应元法僧。**从名位到差事，中间隔了一段。**

底本没有写这一段有多长。

| | |
|---|---|
| 依据 | `002`「除奉朝請」；`003`「以慶之為武威將軍」 |
| 标记 | ○ 训释 |
| 考点 | 这一职的分量后人解释不一；能确定的是它是名位，不是差事 |

---

### 卡 7 · 动机

**问：豫章王萧综为什么要投魏？**

答：**这一篇一个字都没写。**

`005` 全文只有十四个字：「後豫章王棄軍奔魏，眾皆潰散」。

**没有原因，没有过程，没有一句话。** 他走之后的事，这一篇也不记。

| | |
|---|---|
| 依据 | `005` |
| 标记 | — 不回答 |
| 考点 | 史书不写原因，不等于没有原因；这里不替他补一个 |

---

### 卡 8 · 因果

**问：如果那一夜他不砍关门，会怎样？**

答：**底本不回答「如果」，但它给了结果。**

`005` 记的是「軍士得全」。**这是底本写下来的结果，不是推演。**

反过来说：没有这一句，我们只知道溃散；有了这一句，才知道有一部分人出去了。

| | |
|---|---|
| 依据 | `005`「軍士得全」 |
| 标记 | ○ 合理推演 |
| 考点 | 结果有记载，原因没有；不要把「结果」当成「他知道会这样」 |

---

### 卡 9 · 叙述

**问：这一篇里，他说过一句话吗？**

答：**没有。**

001–005 里全是动作与任命：幼而从、稍为主书、率军应接、进薄其垒、斩关夜退。**没有一句引语。**

他在这五段里的第一句「话」，其实是底本的一处转述——「常思效用」，主语是他，可没有一个字是他说的。

| | |
|---|---|
| 依据 | `002`「散財聚士，常思效用」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「常思效用」是史官的叙述，不是他的自述；两者不要混 |

---

> **这一篇的读法：** 三件差事，一次溃散。<br>
> 他做成的事不是杀了多少人，是**在拦不住的时候，还带走了一部分人**。
