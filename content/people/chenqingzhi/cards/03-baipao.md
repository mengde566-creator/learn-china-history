# 复习卡 · 故事 03 · 白袍

> 原则：**问动机，不问年代。**

---

## 故事 03 · 白袍（10 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天 → 第 14 天**

---

### 卡 1 · 结构 ★

**问：七千人凭什么走到洛阳？**

答：**底本给了三个办法，都不靠「勇」。**

| 办法 | 出处 | 做法 |
|---|---|---|
| 打组织，不打人 | `018` 七万分筑九城，只陷三垒 | 破了三座，剩下的组织就不成立了 |
| 把地形反着用 | `019` 城四面萦水 | 「浮水筑垒」，在水上筑进攻的依托 |
| 不在平原比力气 | `021` 虜騎不可爭力平原 | 先下城，再背城而战 |

**三次都不是硬碰硬。** 底本把过程写得很短，可每一步都在换算法。

| | |
|---|---|
| 依据 | `018`「陷其三壘，大千乃降」；`019`「慶之命浮水築壘」；`021`「吾以虜騎不可爭力平原」 |
| 标记 | ◆ 出自原文 |
| 考点 | 三处都是「换一个打法」而不是「多派一些人」 |

---

### 卡 2 · 动机 ★

**问：荥阳城下那段宣喻，为什么先说「屠城略地」？**

答：**因为他要先把退路一条条说断。**

那段话分三层：

```
一层：我屠城略地不少 —— 我们不是干净的
二层：你们杀人父兄 —— 你们也不是
三层：七千对三十余万，义不图存 —— 今天没打算活
```

**先把自己和对方说成一样的人，第三层才立得住。** 说完之后是「一鼓悉使登城」。

| | |
|---|---|
| 依据 | `021`「吾至此以來，屠城略地，實為不少；君等殺人父兄，略人子女，又為無算」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一段不是鼓动，是取消选项：既不能退，也不能指望宽恕 |

---

### 卡 3 · 细节 ★

**问：「解鞍秣马」是什么信号？**

答：**解鞍是不走了，秣马是喂马。**

`021` 在「士眾皆恐」与「宣喻」之间插了这四个字。

**它和「准备突围」正好相反**：解鞍等于把马放了，喂马等于今天还要用。

| | |
|---|---|
| 依据 | `021`「慶之乃解鞍秣馬，宣喻眾曰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这个动作是在讲话之前做的；先给姿态，再给话 |

---

### 卡 4 · 因果 ★

**问：城破了，为什么还要出城打？**

答：**因为他需要一个可以背靠的东西。**

`022` 的顺序是：

```
一鼓悉使登城 → 遂克之
俄而魏阵外合 → 背城逆战
```

**城是他刚拿下来的，所以「背城」背的是自己的城。** 有城墙在后面，三千骑才敢正面对上外面的援军。

| | |
|---|---|
| 依据 | `022`「俄而魏陣外合，慶之率騎三千背城逆戰，大破之」 |
| 标记 | ○ 合理推演 |
| 考点 | 「背城」的方向要读对：不是背对敌人，是背靠自己的城 |

---

### 卡 5 · 叙述

**问：一场几万人的仗，底本记了谁的名字？**

答：**只记了两个先登的壮士。**

| 名 | 籍贯 |
|---|---|
| 宋景休 | 东阳 |
| 鱼天愍 | 义兴 |

**义兴是陈庆之自己的籍贯**（`001`「義興國山人也」）。

底本没有记这一战里任何一个魏将的部下，只记了这两个人。

| | |
|---|---|
| 依据 | `022`「壯士東陽宋景休、義興魚天愍踰堞而入」；`001`「義興國山人也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 记名不记功：底本只写了他们「先上去」，没写他们后来怎样 |

---

### 卡 6 · 结构

**问：「白袍」这个记号，是谁定的？**

答：**底本没说是谁定的，只说「悉著白袍」。**

`025` 记的是「慶之麾下悉著白袍，所向披靡」。

**颜色不是军服，是这一支军队的标识**：七千人走在别人国土上，穿一样的白，老远就认得出来。

至于为什么是白，这一卷一个字都没有解释。

| | |
|---|---|
| 依据 | `025` |
| 标记 | ◆ 出自原文 |
| 考点 | 「悉」是全体的意思；记的是这一支军队统一着装这个事实，不是某个人的主意 |

---

### 卡 7 · 细节 ★

**问：洛阳童谣在传里是什么地位？**

答：**它是这一卷里唯一一段不是史官写的文字。**

| 谁在说 | 说了什么 |
|---|---|
| 史官 | 克、降、走、陷 |
| 皇帝 | 手诏里的期许 |
| 他自己 | 军门前的宣喻 |
| **洛阳的孩子** | **「名師大將莫自牢，千兵萬馬避白袍」** |

四个人群里，只有最后这一句不归功于谁。

| | |
|---|---|
| 依据 | `025`「先是洛陽童謠曰：『名師大將莫自牢，千兵萬馬避白袍。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「先是」说明这首童谣在他入洛之前就在唱了；它不是战后的总结 |

---

### 卡 8 · 叙述

**问：童谣里为什么没有他的名字？**

答：**因为唱的人未必知道他是谁。**

唱的是「白袍」。**一支穿白衣的军队走过，比一个将军的名字好记。**

底本只录了这四句，没有解释。

| | |
|---|---|
| 依据 | `025` |
| 标记 | — 不回答 |
| 考点 | 这是史料本身的样子：它保存了当时的声音，没有保存当时的解释 |

---

### 卡 9 · 细节

**问：「十四旬平三十二城，四十七战」是多快？**

答：**一百四十天，三十二城，四十七战。**

平均下来：**不到三天一仗，四天多下一城。**

底本没有评论这个速度，只是把三个数排在一句里。

| | |
|---|---|
| 依据 | `025`「自發銍縣至于洛陽，十四旬平三十二城，四十七戰」 |
| 标记 | ○ 训释 |
| 考点 | 「旬」是十天；这一句是全传唯一一处连着给三个数字的地方 |

---

### 卡 10 · 因果

**问：这一篇里他败过吗？**

答：**没有，一次都没有。**

`018` 到 `024` 记的全是：陷、降、克、走、归款。

到了 `025` 就是「所向無前」。

**下一篇从洛阳的酒席上开始，那才是这一路真正的结局。**

| | |
|---|---|
| 依据 | `025`「所向無前」；`018`–`024` 各段 |
| 标记 | ◆ 出自原文 |
| 考点 | 「这一篇没有败」不等于「这一路没有败」；下一篇紧接着写崩溃 |

---

> **这一篇的读法：** 七千人走了三个多月，走到一个不属于自己的都城。<br>
> 留在这段历史里的，不是他打下的城，是**四个不唱他名字的句子**。
