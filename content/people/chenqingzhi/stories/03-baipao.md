# 03-baipao · 白袍

| | |
|---|---|
| **封面** | — |
| **地点** | 铚县 → 睢阳 → 考城 → 荥阳 → 洛阳 |
| **原文** | 016–025 |

> 十段，八百六十余字。
> **全传的高点。** 七千人从铚县走到洛阳，十四旬，三十二城，四十七战。
> 洛阳的孩子替他留下了一首童谣——那也是这一卷里唯一一次，有人替他说话。

## 一、情境铺陈

```
涡阳之后，高祖赐了他一封手诏。   ← ◆

诏里说：本不是将种，也不是豪家，能走到这里，是因着风云际会。   ← ◆

那年冬天以后，北魏的朝廷自己先乱了。   ← ○ 016

魏的北海王元颢在本朝待不住，自己跑到梁朝来，请梁人送他回去做魏主。   ← ◆ 016

高祖答应了，把这件差事交给了他。   ← ◆ 016

给他的兵，比十五万少得多。   ← ○ 021
```

### 逐行依据

| 行 | 标记 | 依据 |
|---|---|---|
| 涡阳之后，高祖赐了他一封手诏 | ◆ | 前一篇的收束：「高祖嘉焉，賜慶之手詔」（见 `02-guoyang`） |
| 诏里说：本不是将种，也不是豪家，能走到这里，是因着风云际会 | ◆ | 同上：「本非將種，又非豪家，觖望風雲，以至於此」 |

| 魏的北海王元颢在本朝待不住，自己跑到梁朝来，请梁人送他回去做魏主 | ◆ | `016`「自拔來降，求立為魏主」 |
| 高祖答应了，把这件差事交给了他 | ◆ | `016`「高祖納之，以慶之為假節、飆勇將軍，送元顥還北」 |
| 给他的兵，比十五万少得多 | ○ 021 | `021` 他自述「我等纔有七千」；十五万是涡阳那一路的魏军，见 `02-guoyang` |

## 二、正文

### 情节点 1 · 一个要回去做皇帝的人

> 大通初年，魏的北海王元颢来了。
>
> 他不是来投降的——他是来借兵的。本朝乱了，他要回去，做魏主。
>
> 高祖收下了这个人，也收下了这件事。以陈庆之为假节、飙勇将军，送元颢北还。
>
> 走到涣水，元颢即了魏帝位。
>
> 他授陈庆之使持节、镇北将军、护军、前军大都督。
>
> 从铚县出发。攻下荥城，进至睢阳。

| 标记 | ◆ |
| 原文 | `016` 大通初，魏北海王元顥以本朝大亂，自拔來降，求立為魏主。高祖納之，以慶之為假節、飆勇將軍，送元顥還北。 |
| 依据 | `016`；`017`「顥於渙水即魏帝號，授慶之使持節、鎮北將軍、護軍、前軍大都督，發自銍縣，進拔滎城，遂至睢陽」 |

| 说明 | 一个梁人，带着梁兵，送一个魏的宗室回去做魏的皇帝。**这一趟从一开始就不是梁的北伐，是元颢的复国** |
|---|---|
| 说明 | `017` 里元颢给陈庆之的官衔一连串。**官衔是元颢给的，兵是梁的**——这两件事在这一篇里一直没有对齐 |
|---|---|

---

### 情节点 2 · 九座城，七万人

> 睢阳的守将是丘大千。
>
> 他有七万人。他把这七万人分筑成九座城，一城接一城，互相照应。
>
> 陈庆之攻了整整一天——从天亮到申时。
>
> 陷了三座垒。
>
> 丘大千降了。

| 标记 | ◆ |
| 原文 | `018` 魏將丘大千有眾七萬，分築九城以相拒。慶之攻之，自旦至申，陷其三壘，大千乃降。 |
| 依据 | `018`；`017`（此行的方向） |

| 说明 | 七万人分筑九城，是守势的排法；**陈庆之只陷了三垒，丘大千就降了**。剩下的六座城，没有人再守 |
|---|---|

---

### 情节点 3 · 考城四面是水

> 魏人又派了人来救。
>
> 征东将军、济阴王元晖业率羽林与宗室子弟两万人，救梁、宋，进屯考城。
>
> 考城四面环水，守备很严。
>
> 陈庆之命令士兵浮水筑垒，攻陷了这座城。
>
> 生擒元晖业。缴获租车——运粮的车——七千八百辆。
>
> 大军继续向大梁去，所到之处望旗归附。
>
> 元颢进他为卫将军、徐州刺史、武都公。他仍率众向西。

| 标记 | ◆ |
| 原文 | `019` 時魏征東將軍濟陰王元暉業率羽林庶子二萬人來救梁、宋，進屯考城，城四面縈水，守備嚴固。慶之命浮水築壘，攻陷其城，生擒暉業，獲租車七千八百輛。仍趨大梁，望旗歸款。顥進慶之衛將軍、徐州刺史、武都公。仍率眾而西。 |
| 依据 | `019`；`018`（连战） |

| 说明 | 「浮水築壘」四个字：**城被水围着，他就在水上筑出进攻的依托**。困住城的那个条件，被他反过来用了 |
|---|---|
| 说明 | 缴获的是「租车」——运粮车。**七千八百辆粮车被夺，意味着这一路的魏军没有粮了** |
|---|---|

---

### 情节点 4 · 荥阳城下

> 前面的城是荥阳。
>
> 魏的左仆射杨昱、西阿王元庆、抚军将军元显恭，率御仗羽林与宗室子弟，共七万人，据荥阳拒元颢。
>
> 兵精，城险。陈庆之攻不下来。
>
> 而元天穆的大军又要到了。
>
> 他先遣骠骑将军尔朱吐没儿领胡骑五千，骑将鲁安领夏州步骑九千，来援杨昱。
>
> 又遣右仆射尔朱世隆、西荆州刺史王罴，率骑一万，据虎牢。
>
> 天穆与吐没儿前后继至，旗鼓相望。
>
> 前有坚城，后有大敌。

| 标记 | ◆ |
| 原文 | `020` 魏左僕射楊昱、西阿王元慶、撫軍將軍元顯恭率御仗羽林宗子庶子眾凡七萬，據滎陽拒顥。兵既精強，城又險固，慶之攻未能拔。魏將元天穆大軍復將至，先遣其驃騎將軍爾朱吐沒兒領胡騎五千，騎將魯安領夏州步騎九千，援楊昱；又遣右僕射爾朱世隆、西荊州刺史王罴騎一萬，據虎牢。天穆、吐沒兒前後繼至，旗鼓相望。 |
| 依据 | `020`；`019`（此前的连胜） |

| 说明 | 这一段的数字要自己加：**七万守城，五千加九千加一万的援军，后面还有一个元天穆。** 底本不替你算 |
|---|---|
| 说明 | 「旗鼓相望」是说两支军队的旗帜与鼓声能互相看见听见——**离得很近，而且不怕你知道** |
|---|---|

### 情节点 5 · 七千对三十余万

> 荥阳还没攻下。
>
> 军中开始怕了。
>
> 陈庆之解下马鞍，喂马——像是在准备后事，也像是在告诉所有人：今天不走了。
>
> 然后他当众讲话。他说的是最难听的那种实话。

> 「吾至此以來，屠城略地，實為不少；君等殺人父兄，略人子女，又為無算。天穆之眾，並是仇讎。我等纔有七千，虜眾三十餘萬，今日之事，義不圖存。吾以虜騎不可爭力平原，及未盡至前，須平其城壘，諸君無假狐疑，自貽屠膾。」
>
> ——我到这里以来，屠城略地，实在不少；你们杀人父兄、掠人子女，也不计其数。元天穆的兵，都是仇敌。我们只有七千，敌众三十余万，今天这件事，按道理不打算活着回去。我**因为**敌骑在平原上不能和我们争力，趁他们还没全部到达，必须先平掉这座城垒。诸位不必再迟疑，自取被人宰割。

| 标记 | ◆ |
| 原文 | `021` 時滎陽未拔，士眾皆恐，慶之乃解鞍秣馬，宣喻眾曰：「吾至此以來，屠城略地，實為不少；君等殺人父兄，略人子女，又為無算。天穆之眾，並是仇讎。我等纔有七千，虜眾三十餘萬，今日之事，義不圖存。吾以虜騎不可爭力平原，及未盡至前，須平其城壘，諸君無假狐疑，自貽屠膾。」 |
| 依据 | `021`；`020`（前有坚城后有大军） |

| 说明 | 这番话里有三个不客气的地方：**先说自己屠城略地；再说你们杀人父兄；最后说——今天按道理不打算活**。他不是在鼓动，是在把退路一条条说断 |
|---|---|
| 说明 | 「解鞍秣馬」是这一段唯一的动作。**解鞍是准备停驻，不是准备逃跑** |
|

### 情节点 6 · 一鼓

> 一通鼓，全军登城。
>
> 壮士东阳宋景休、义兴鱼天愍越过城墙的垛口，先上去了。
>
> 荥阳城破。
>
> 很短的时间里，魏军在城外合围。陈庆之率三千骑，背城逆战。
>
> 大破之。鲁安在阵前乞降。元天穆、尔朱吐没儿单骑逃走，得以免死。
>
> 收荥阳的储备，牛马谷帛多得数不清。

| 标记 | ◆ |
| 原文 | `022` 一鼓悉使登城，壯士東陽宋景休、義興魚天愍踰堞而入，遂克之。俄而魏陣外合，慶之率騎三千背城逆戰，大破之，魯安於陣乞降，元天穆、爾朱吐沒兒單騎獲免。收滎陽儲實，牛馬穀帛不可勝計。 |
| 依据 | `021`（宣喻）；`022` |

| 说明 | 先登的两个人有名有姓：**宋景休、鱼天愍**。底本在一场几万人的仗里，只记了这两个人的名字，和他们是哪里人 |
|---|---|
| 说明 | 「背城逆戰」——城已经是自己的了，所以背靠的是自己的城。**进城不是结束，是为了有一个可以背靠的东西去打城外的大军** |
|

### 情节点 7 · 入洛阳

> 他继续向虎牢去。尔朱世隆弃城走了。
>
> 魏主元子攸怕了，奔并州。
>
> 临淮王元彧、安丰王元延明带着百官，封了府库，备了法驾，把元颢迎进洛阳宫，登御前殿，改元大赦。
>
> 元颢以陈庆之为侍中、车骑大将军、左光禄大夫，增邑万户。
>
> 可魏人没有停下来。元天穆又带四万人攻陷大梁，另遣两路：一路据虎牢，一路入梁、宋。
>
> 陈庆之随方掩袭，这些人都降了。元天穆带着十几骑北渡黄河。
>
> 高祖又赐手诏称赞他。

| 标记 | ◆ |
| 原文 | `023` 進赴虎牢，爾朱世隆棄城走。魏主元子攸懼，奔并州。其臨淮王元彧、安豊王元延明率百僚，封府庫，備法駕，奉迎顥入洛陽宮，御前殿，改元大赦。顥以慶之為侍中、車騎大將軍、左光祿大夫，增邑萬戶。 |
| 依据 | `023`；`024`「魏大將軍上黨王元天穆、王老生、李叔仁又率眾四萬，攻陷大梁……慶之隨方掩襲，並皆降款」 |

| 说明 | 进城这一段，动手的是元彧和元延明——**两个魏的宗室，替元颢开的路**。这一段里陈庆之没有出现 |
|---|---|
| 说明 | 元颢给他的官，是魏的官。**他此时的身份是梁将，做的却是魏的侍中、车骑大将军** |
|---|---|

### 情节点 8 · 白袍

> 那一阵子，他麾下的兵都穿白袍。
>
> 白袍的军队走到哪里，哪里就破。
>
> 在此之前，洛阳的孩子已经在唱一首童谣了。

> 「名師大將莫自牢，千兵萬馬避白袍。」
>
> ——名号响亮的军队和大将，都不要以为自己的营垒牢靠；千兵万马，都要避着白袍走。

> 从铚县到洛阳，十四旬，平三十二城，四十七战，所向无前。

| 标记 | ◆ |
| 原文 | `025` 慶之麾下悉著白袍，所向披靡。先是洛陽童謠曰：「名師大將莫自牢，千兵萬馬避白袍。」自發銍縣至于洛陽，十四旬平三十二城，四十七戰，所向無前。 |
| 依据 | `025`；`017`（发自铚县）；`023`（入洛阳） |

| 说明 | 「先是」两个字要留意：**童谣不是打完才唱的，是之前就有**。所以它不是总结，是当时人先看见了这支白袍的军队 |
|---|---|
| 说明 | 十四旬是三十二城、四十七战的全部时间。**这一句是全传里唯一一次连着给三个数字**，也是唯一一处替这一路兵记账的地方 |
|---|---|

## 四、背景卡

### 元颢

魏的北海王。本朝大乱，他「自拔来降」，向梁借兵，要回去做魏主。

**他不是梁的臣子，是梁的客人。** 这一路打下的城，名义上是给他的。

> **依据**：`016`「魏北海王元顥以本朝大亂，自拔來降，求立為魏主」；`017`「顥於渙水即魏帝號」。

---

### 白袍

`025` 的「麾下悉著白袍」——他部下的兵都穿白。

**白不是军服的颜色，是这一支军队的记号**：七千人走在别人的国土上，穿一样的白，老远就认得出来。

> **依据**：`025`「慶之麾下悉著白袍，所向披靡」。**为什么穿白，底本不载**；后世有说是丧服、有说是便于相认，都不在这一段里。

---

### 洛阳童谣

`025` 记的那四句，是这一卷里唯一一段不是史官写的文字。

**它不唱陈庆之的名字，唱的是「白袍」。** 唱的人当时未必知道白袍的将军叫什么。

> **依据**：`025`「先是洛陽童謠曰：『名師大將莫自牢，千兵萬馬避白袍。』」。

---

### 荥阳与虎牢

荥阳在洛阳东，虎牢在荥阳东，两处都是自东入洛的关口。**守住了这两处，洛阳就在手里；丢了，洛阳就空了。**

`020` 魏军据荥阳，另一支据虎牢；`023` 尔朱世隆弃虎牢走。

> **依据**：`020`「據滎陽拒顥」「據虎牢」；`023`「進赴虎牢，爾朱世隆棄城走」。<br>两处的地理位置是后世注家的对照，不是这两段写的。

---

### 十四旬

「旬」是十天。十四旬就是一百四十天。

从铚县出发到进洛阳，一百四十天，平三十二城，四十七战——**平均不到三天一仗，四天多下一城。**

> **依据**：`025`「自發銍縣至于洛陽，十四旬平三十二城，四十七戰」。<br>「旬为十日」是通行的历法训释。

## 七、设计说明

> **这一篇要回答的问题只有一个：七千人凭什么走到洛阳。**
>
> 底本给的答案不是「勇」。它给的是三次计算：`018` 七万分作九城而只陷三垒——
> **打掉的是组织，不是人**；`019` 城四面环水而「浮水筑垒」——
> **把困住城的东西变成进攻的依托**；`021` 他说「虜騎不可爭力平原」——
> **不在平原上跟骑兵比力气，先拿下城**。
>
> 至于「白袍」和童谣，我放在最后一段，而不是开头。
> **因为童谣不是胜利的原因，是胜利留下的唯一一件别人的话。**
> 这一卷里所有关于他的句子，都是史官写的、皇帝写的、他自己说的——
> 只有这四句，是洛阳街上的人唱的。
>
> **这一篇与下一篇是一件事的两半。** 这一篇到最后一句都还是「所向无前」；
> 下一篇从洛阳的酒席上开始。
