# 05-yusheng · 余生

| | |
|---|---|
| **封面** | — |
| **地点** | 北兖州 · 悬瓠 · 淮上 · 豫州 |
| **原文** | 036–043 |

> 八段，五百七十余字。
> **他从洛阳回来之后，又活了十年。** 这十年里他打过假皇帝、围过悬瓠、击破过侯景。
> 这一篇写的不是他还能打，是他最后留在纸上的两行字。

---

## 一、情境铺陈

```
他从嵩高山下脱身的时候，头发是剃掉的。   ← ◆

朝廷仍记了他的功：除右卫将军，封永兴县侯，邑一千五百户。   ← ◆

一个军队散了的将军，回来封了侯。   ← ○

之后他出为北兖州刺史，都督缘淮诸军事。   ← ◆ 036

那一带刚经过大乱，什么人都冒了出来。   ← ○ 036

有一个和尚，自称皇帝。   ← ◆ 036
```

## 二、正文

### 情节点 1 · 一个自称皇帝的和尚

> 他出为持节、都督缘淮诸军事、奋武将军、北兖州刺史。
>
> 赶上妖贼沙门僧强自称皇帝，土豪蔡伯龙起兵响应他。
>
> 僧强颇懂幻术，靠它互相煽惑，部众到了三万，攻陷北徐州。
>
> 济阴太守杨起文弃城走了，钟离太守单希宝被害。
>
> 朝廷派陈庆之去讨。

| 标记 | ◆ |
| 原文 | `036` 出為持節、都督緣淮諸軍事、奮武將軍、北兗州刺史。會有妖賊沙門僧強自稱為帝，土豪蔡伯龍起兵應之。僧強頗知幻術，更相扇惑，眾至三萬，攻陷北徐州，濟陰太守楊起文棄城走，鐘離太守單希寶見害，使慶之討焉。 |
| 依据 | `036`；他从洛阳归来之事见 `04-songgao` |

| 说明 | 这个对手和尔朱荣完全不是一类：**一个会幻术的和尚，加上一个土豪，聚了三万人就攻陷了一个州**。底本用「妖賊」两个字定性，别的没多说 |
|---|---|
| 说明 | 死了两个人：**一个弃城走，一个遇害**。底本把两个人的结局并列写下来 |
|---|---|

---

### 情节点 2 · 皇帝送他出征

> 皇帝到了白下，亲自为他饯行。
>
> 临走，皇帝交代了他一句话。

> 「江、淮兵勁，其鋒難當，卿可以策制之，不宜決戰。」
>
> ——江淮的兵很精劲，它的锋头难以正面抵挡；你可以用计谋制服它，不宜硬打决战。

> 陈庆之受命而去。
>
> 还不到一个浃辰（古人一说十二天）——他斩了蔡伯龙、僧强，把头送到京城。

| 标记 | ◆ |
| 原文 | `037` 車駕幸白下，臨餞謂慶之曰：「江、淮兵勁，其鋒難當，卿可以策制之，不宜決戰。」慶之受命而行。曾未浹辰，斬伯龍、僧強，傳其首。 |
| 依据 | `037`；`036`（此行的差事） |

| 说明 | 皇帝给的是「不宜决战」四个字。**这是这一卷里唯一一次，皇帝给他作战方略** |
|---|---|
| 说明 | 「曾未浃辰」（浃辰，一说十二天）和「斩」「传其首」三个动作连在一起，中间没有过程。**底本只给结果，不给打法** |
|

---

### 情节点 3 · 围悬瓠

> 中大通二年，他被任为都督南、北司、西豫、豫四州诸军事，南、北司二州刺史，其余照旧。
>
> 他到镇之后，就围了悬瓠。
>
> 在溱水破了魏的颍州刺史娄起、扬州刺史是云宝。
>
> 又在楚城破了行台孙腾、大都督侯进、豫州刺史尧雄、梁州刺史司马恭。

| 标记 | ◆ |
| 原文 | `038` 中大通二年，除都督南、北司、西豫、豫四州諸軍事、南、北司二州刺史，餘並如故。慶之至鎮，遂圍懸瓠。破魏潁州刺史婁起、揚州刺史是云寶於溱水，又破行臺孫騰、大都督侯進、豫州刺史堯雄、梁州刺史司馬恭於楚城。 |
| 依据 | `038`；`036`（他此时的方镇身份） |

| 说明 | 这一段的写法是清单：**一地一战，一战一串人名**。底本没有写任何一场的经过，只记了谁被破在哪里 |
|---|---|
| 说明 | 从这一年起，他的身份变了：**不再是朝廷派出去的一路将，而是坐镇一方的刺史** |
|

### 情节点 4 · 不打仗的那些事

> 他罢了义阳的镇兵，停了水陆转运。
>
> 江湖诸州因此得以休息。
>
> 他开田六千顷。两年之后，仓廪充实。
>
> 高祖常常嘉奖慰劳他。
>
> 他又上表请求省去南司州，恢复安陆郡，设置上明郡。

| 标记 | ◆ |
| 原文 | `039` 罷義陽鎮兵，停水陸轉運，江湖諸州並得休息。開田六千頃，二年之後，倉廩充實。高祖每嘉勞之。又表省南司州，復安陸郡，置上明郡。 |
| 依据 | `039`；`038`（他镇守四州） |

| 说明 | 一个以军功立传的人，传里忽然出现「開田六千頃」——**这是这一卷里唯一一段不写打仗的记载** |
|---|---|
| 说明 | 「罷」「停」「開」三个动词排在一起：**罢掉镇兵、停掉转运、开出田来**。三件事都是减法，除了最后一件 |
|

---

### 情节点 5 · 淮上的一场大雪

> 大同二年，魏派侯景率七万兵寇楚州。
>
> 刺史桓和陷没。侯景继续进军淮上，还写了一封信给陈庆之，劝他投降。
>
> 朝廷命湘潭侯退与右卫夏侯夔等赴援。
>
> 援军走到黎浆的时候，陈庆之已经击破了侯景。
>
> 那时天寒大雪。侯景丢下辎重走了。
>
> 陈庆之把这些辎重收下来，带了回去。
>
> 他因此进号仁威将军。

| 标记 | ◆ |
| 原文 | `040` 大同二年，魏遣將侯景率眾七萬寇楚州，刺史桓和陷沒，景仍進軍淮上，貽慶之書使降。敕遣湘潭侯退、右衛夏侯夔等赴援，軍至黎漿，慶之已擊破景。時大寒雪，景棄輜重走，慶之收之以歸。進號仁威將軍。 |
| 依据 | `040`；`038`（他的方镇位置） |

| 说明 | 这一段的顺序很要紧：**朝廷先派人来救他，援军还没到，他已经打赢了**。「軍至黎漿，慶之已擊破景」 |
|---|---|
| 说明 | 「貽慶之書使降」——侯景给他写过劝降信。**这封信的内容底本一句都没收** |
|

---

### 情节点 6 · 开仓与死

> 这一年，豫州闹饥荒。
>
> 他开仓赈给，救活的人很多。
>
> 州民李昇等八百人上表，请求为他树碑颂德。诏书准了。
>
> 大同五年十月，他死了。时年五十六。
>
> 赠散骑常侍、左卫将军，鼓吹一部。谥曰武。
>
> 朝廷敕义兴郡发五百丁会丧。

| 标记 | ◆ |
| 原文 | `041` 是歲，豫州饑，慶之開倉賑給，多所全濟。州民李昇等八百人表請樹碑頌德，詔許焉。五年十月，卒，時年五十六。贈散騎常侍、左衛將軍，鼓吹一部。謚曰武。敕義興郡發五百丁會喪。 |
| 依据 | `041`；`040`（侯景退走之后） |

| 说明 | 死前最后记的一件事不是打仗：「開倉賑給」。**而替他说话的是州民八百人**——这是全传里唯一一处百姓为他上书 |
|---|---|
| 说明 | 「發五百丁會喪」是派人来会丧。**五百个丁，是从他的家乡义兴征的** |
|---|---|

### 情节点 7 · 射不穿札

> 陈庆之性情恭谨。衣服不用细绢绮罗，不喜欢丝竹。
>
> 箭射不透甲片，马也不是他所擅长的。
>
> 而他能安抚军士，能得他们的死力。

> 「慶之性祗慎，衣不紈綺，不好絲竹，射不穿札，馬非所便，而善撫軍士，能得其死力。」
>
> ——陈庆之性情恭谨，衣服不用细绢绮罗，不喜欢丝竹；箭射不透甲片，马也不是他所擅长的。但他善于安抚军士，能得他们的拼死之力。

| 标记 | ◆ |
| 原文 | `042` 慶之性祗慎，衣不紈綺，不好絲竹，射不穿札，馬非所便，而善撫軍士，能得其死力。長子昭嗣。 |
| 依据 | `042`；**这是传末的总述，不是他的自述** |

| 说明 | 七千白袍、三十二城、四十七战，写到这里收成一句话：**射不穿札，马非所便**。这一卷没有替他圆这个短，反而把它放在最末 |
|---|---|
| 说明 | 「而善撫軍士，能得其死力」——**转折在「而」字上**。前面四样都不是长处，后面一样是 |
|---|---|

---

### 情节点 8 · 史臣的话

> 史臣说：
>
> 陈庆之、兰钦都有将略，战胜攻取，大概是廉颇、李牧、卫青、霍去病那一类人的次一等吧。
>
> 陈庆之机警敏悟，早年就侍奉高祖；既已列入旧恩，又加上谨慎肃敬，蝉冕组佩——也是一世的荣耀了。

> 「陳慶之、蘭欽俱有將略，戰勝攻取，蓋頗、牧、衛、霍之亞歟。」
>
> ——陈庆之、兰钦都有将略，战胜攻取，大约是廉颇、李牧、卫青、霍去病的次一等吧。

| 标记 | ◆ |
| 原文 | `043` 史臣曰：陳慶之、蘭欽俱有將略，戰勝攻取，蓋頗、牧、衛、霍之亞歟。慶之警悟，早侍高祖，既預舊恩，加之謹肅，蟬冕組珮，亦一世之榮矣。 |
| 依据 | `043`；`042`（祗慎、善抚军士） |

| 说明 | 「亞」是次一等。**史臣把他放在名将之下、常将之上**——这个位置定得很谨慎 |
|---|---|
| 说明 | 最后一句落回「早侍高祖」和「謹肅」。**史臣给他的评语里，一半是战功，一半是他在皇帝棋盘边坐着的那几十年** |
|---|---|

## 四、背景卡

### 白下

建康城北的一处要地，临江。`037` 记皇帝「車駕幸白下」，在那里为他饯行。**这是后世地理对照，不是 `037` 的原文内容。**

**皇帝出城送一个刺史出征，这个动作的分量可以想见。**

> **依据**：`037`「車駕幸白下，臨餞謂慶之曰」。<br>建康城北、临江，是后世地理对照。

---

### 浃辰

`037` 的「曾未浹辰」。浃是满、周遍；辰指日。**「浃辰」是十二天**（一说十日）。

不到十二天，蔡伯龙、僧强都斩了。

> **依据**：`037`「曾未浹辰，斬伯龍、僧強，傳其首」。<br>「十二日」是通行的训释。

---

### 悬瓠

`038` 的「遂圍懸瓠」。故城在今河南汝南一带，是淮西的重镇。

**围悬瓠不是一次战斗，是一次战役的开头**——这一年他在溱水、楚城连着破了魏的几路人。

> **依据**：`038`「慶之至鎮，遂圍懸瓠」；`038` 后文两处「破」。<br>今河南汝南一带，是后世地理对照。

---

### 侯景

`040` 里率七万兵寇楚州的魏将。后来他在梁朝做了更大的事，但那不在这 43 段里。

**这一篇只记了他这一次**：写信劝降、遇大雪、弃辎重走。

> **依据**：`040`「魏遣將侯景率眾七萬寇楚州……貽慶之書使降」。

---

### 鼓吹一部

`041` 的赠官之后跟着「鼓吹一部」。按后人对赠典的解释，这是丧仪的一部分：**给一支乐队，走在丧列里**。

不是给他生前听的。**`041` 只记「鼓吹一部」四个字，具体仪节不在这 43 段里。**

> **依据**：`041`「贈散騎常侍、左衛將軍，鼓吹一部」。

---

### 谥曰武

`041` 的「謚曰武」。

「武」是谥法里给克定祸乱、威强睿德一类人的字。**这一卷给他这一个字，和史臣那句「颇、牧、卫、霍之亚」是一路的评价。**

> **依据**：`041`「謚曰武」；`043` 史臣的评语。谥法的具体条目不在这 43 段里。

---

## 七、设计说明

> **这一篇要处理的难题是：它没有高潮。**
>
> 前四篇都有一件事可以指着说——斩关、杖节、入洛、山洪。这一篇没有。
> 它是一串差事：讨一个和尚、围一座城、开一片田、打退一个人、死。
>
> 所以这一篇的结构换了：**不按战功排，按"他留下了什么"排。**
> 前面几段越来越平，落到 `042` 那两行自述上——那是全传里唯一一处正面写他身体的话。
>
> **`042` 是这一篇的重心，也是全传的最后一句实写。**
> 一个人打了二十年仗，最后的评语是「射不穿札，馬非所便」。
> 底本没有替他解释，也没有替他辩护，紧接着就是「而善撫軍士，能得其死力」。
>
> **`043` 是史臣的话，不是他自己的话。** 把它放在最后，是因为这一卷到这里才合上：
> 前面四十三段里，别人替他说过的所有话，最后都被这一句收进去——「亦一世之榮矣」。
