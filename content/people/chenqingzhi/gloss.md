# 陈庆之 · 直译

> **这一份和故事里的白话不是一回事。**
>
> 故事里的白话是**给人读的**：可以顺着现代汉语的语序重排、可以补主语、可以把两句并成一句。
> 这一份是**直译**：跟着原文的字序和句法走，不替它顺句子、不替它补它没说的主语。
>
> **所以它读起来会比故事里的白话生硬——这是有意的。** 它要让人看见原文长什么样：
> 哪一句没有主语、哪一处省略了宾语、哪个词在原文里只是一个字。
> 故事里的白话告诉你「发生了什么」，这一份告诉你「原文是这么说的」。
>
> **四条写法**：
>
> 1. **不补主语。** 原文承前省略，直译也省略（用「（他）」标出来源，不用人名填进去）
> 2. **术语随文注。** 官名、地名、称谓第一次出现时，用（　）就地解释
> 3. **不合并、不拆分。** 原文一个句号，直译一个句号
> 4. **阙字照录。** `004` 的「陟□」是录文本身缺一字，直译不替它补
>
> 段号与 `source.md` 一一对应。**没有直译的段就是还没做**——不是「不需要」。

| 031 | 顥前以慶之為徐州刺史，因固求之鎮。顥心憚之，遂不遣。乃曰：「主上以洛陽之地全相任委，忽聞捨此朝寄，欲往彭城，謂君遽取富貴，不為國計，手敕頻仍，恐成僕責。」慶之不敢復言。 | 元颢先前以庆之为徐州刺史，庆之就坚决请求赴镇。元颢心里忌惮他，就不派。于是说：「主上把洛阳之地完全委任给你；忽然听说你舍弃这里的朝寄，要去彭城，人家会说你急于取富贵，不为国家打算。手敕一封接一封，恐怕变成我的罪责。」庆之不敢再说。 |
| 032 | 魏天柱將軍爾朱榮、右僕射爾朱世隆、大都督元天穆、驃騎將軍爾朱吐沒兒、榮長史高歡、鮮卑、芮芮，勒眾號百萬，挾魏主元子攸來攻顥。 | 魏的天柱将军尔朱荣、右仆射尔朱世隆、大都督元天穆、骠骑将军尔朱吐没儿、尔朱荣的长史高欢，以及鲜卑、芮芮，统勒部众号称百万，挟着魏主元子攸来攻元颢。 |
| 033 | 顥據洛陽六十五日，凡所得城，一時反叛。慶之渡河守北中郎城，三日中十有一戰，傷殺甚眾。 | 元颢据洛阳六十五日，凡是所得过的城，一时都反叛。庆之渡河守北中郎城，三日中十一战，杀伤甚众。 |
| 034 | 榮將退，時有劉助者，善天文，乃謂榮曰：「不出十日，河南大定。」榮乃縛木為筏，濟自硤石，與顥戰於河橋，顥大敗，走至臨潁，遇賊被擒，洛陽陷。 | 尔朱荣将要退，其时有个刘助，善于天文，就对尔朱荣说：「不出十日，河南大定。」尔朱荣就缚木作筏，从硖石渡河，与元颢在河桥交战；元颢大败，走到临颍，遇贼被擒，洛阳陷落。 |
| 035 | 慶之馬步數千，結陣東反，榮親自來追，值嵩高山水洪溢，軍人死散。慶之乃落鬚髮為沙門，間行至豫州，豫州人程道雍等潛送出汝陰。至都，仍以功除右衛將軍，封永興縣侯，邑一千五百戶。 | 庆之马步数千，结阵向东回。尔朱荣亲自来追，正遇上嵩高山洪水暴涨，军人死的死、散的散。庆之就剃去须发做沙门（沙门，僧人），走小路到豫州；豫州人程道雍等秘密送他出汝阴。到京城，仍以功授右卫将军，封永兴县侯，食邑一千五百户。 |
| 036 | 出為持節、都督緣淮諸軍事、奮武將軍、北兗州刺史。會有妖賊沙門僧強自稱為帝，土豪蔡伯龍起兵應之。僧強頗知幻術，更相扇惑，眾至三萬，攻陷北徐州，濟陰太守楊起文棄城走，鐘離太守單希寶見害，使慶之討焉。 | 出为持节、都督缘淮诸军事、奋武将军、北兖州刺史。恰逢妖贼沙门僧强自称皇帝，土豪蔡伯龙起兵响应他。僧强颇懂幻术，更相煽惑，众到三万，攻陷北徐州；济阴太守杨起文弃城逃走，钟离太守单希宝被害，派庆之去讨伐。 |
| 037 | 車駕幸白下，臨餞謂慶之曰：「江、淮兵勁，其鋒難當，卿可以策制之，不宜決戰。」慶之受命而行。曾未浹辰，斬伯龍、僧強，傳其首。 | 皇帝到白下，临行饯别时对庆之说：「江淮的兵强劲，它的锋头难以抵挡；你可以用计策制服它，不宜决战。」庆之受命而行。还不满一个浃辰（浃辰，十二日），斩伯龙、僧强，传送他们的首级。 |
| 038 | 中大通二年，除都督南、北司、西豫、豫四州諸軍事、南、北司二州刺史，餘並如故。慶之至鎮，遂圍懸瓠。破魏潁州刺史婁起、揚州刺史是云寶於溱水，又破行臺孫騰、大都督侯進、豫州刺史堯雄、梁州刺史司馬恭於楚城。 | 中大通二年，授都督南、北司、西豫、豫四州诸军事、南、北司二州刺史，其余都照旧。庆之到镇，就围悬瓠。在溱水破魏颍州刺史娄起、扬州刺史是云宝，又在楚城破行台孙腾、大都督侯进、豫州刺史尧雄、梁州刺史司马恭。 |
| 039 | 罷義陽鎮兵，停水陸轉運，江湖諸州並得休息。開田六千頃，二年之後，倉廩充實。高祖每嘉勞之。又表省南司州，復安陸郡，置上明郡。 | 罢去义阳的镇兵，停止水陆转运，江湖各州因此得以休息。开田六千顷，二年之后，仓廪充实。高祖常常嘉奖慰劳他。又上表请求省去南司州，恢复安陆郡，设置上明郡。 |
| 040 | 大同二年，魏遣將侯景率眾七萬寇楚州，刺史桓和陷沒，景仍進軍淮上，貽慶之書使降。敕遣湘潭侯退、右衛夏侯夔等赴援，軍至黎漿，慶之已擊破景。時大寒雪，景棄輜重走，慶之收之以歸。進號仁威將軍。 | 大同二年，魏派将侯景率众七万寇楚州，刺史桓和陷没；侯景就进军淮上，送信给庆之使他投降。敕派湘潭侯退、右卫夏侯夔等赴援，军到黎浆，庆之已经击破侯景。其时大寒下雪，侯景丢弃辎重逃走，庆之收取了回来。进号仁威将军。 |
| 041 | 是歲，豫州饑，慶之開倉賑給，多所全濟。州民李昇等八百人表請樹碑頌德，詔許焉。五年十月，卒，時年五十六。贈散騎常侍、左衛將軍，鼓吹一部。謚曰武。敕義興郡發五百丁會喪。 | 这一年，豫州饥荒，庆之开仓赈给，多所全济。州民李昇等八百人上表请求树碑颂德，诏书准许。五年十月，去世，当时年五十六。赠散骑常侍、左卫将军，鼓吹一部。谥为武。敕义兴郡发五百丁会丧。 |
| 042 | 慶之性祗慎，衣不紈綺，不好絲竹，射不穿札，馬非所便，而善撫軍士，能得其死力。長子昭嗣。 | 庆之性情恭敬谨慎，衣服不用细绢绮罗，不喜欢丝竹；射箭穿不透甲札，骑马不是他所擅长；却善于抚慰军士，能得到他们的死力。长子昭，嗣爵（本篇采用这一断句，嗣解为继承爵位）。 |
| 043 | 史臣曰：陳慶之、蘭欽俱有將略，戰勝攻取，蓋頗、牧、衛、霍之亞歟。慶之警悟，早侍高祖，既預舊恩，加之謹肅，蟬冕組珮，亦一世之榮矣。 | 史臣说：陈庆之、兰钦都有将略，战胜攻取，大概是廉颇、李牧、卫青、霍去病的次一等吧。庆之警悟，早先侍奉高祖；既已列入旧恩，又加上谨慎肃敬；蝉冕组佩，也是一世的荣耀了。 |
