# 复习卡 · 故事 04 · 優孟

> 原则：**问动机，不问年代。**

---

## 故事 04 · 優孟（5 张）

---

### 卡 1 · 结构 ★

**问：这一篇从孙叔敖遗命写到封寝丘，走了几步？**

答：**五步。**

| 步 | 发生了什么 |
|---|---|
| `016`–`018` | 优孟是楚乐人；孙叔敖善待他，临终命子往见 |
| `019`–`020` | 其子穷困负薪，路遇优孟；优孟为孙叔敖衣冠 |
| `021`–`022` | 岁余像孙叔敖，庄王欲以为相 |
| `023`–`025` | 请归与妇计；妇言「楚相不足为」，又歌 |
| `026` | 庄王谢优孟，封其子寝丘四百户 |

|---|---|
| 依据 | `016`–`026` |
| 标记 | ◆ 出自原文 |
| 考点 | 主角是优孟，题目仍是孙叔敖 |

---

### 卡 2 · 因果 ★

**问：孙叔敖为什么让儿子去見优孟？**

答：**因为他知道优孟贤，也预知自己死后家贫。**

「我死，汝必贫困。若往见优孟，言我孙叔敖之子也。」不托权贵，托一个乐人；这一句是全篇的起点。

| | |
|---|---|
| 依据 | `017`–`018` |
| 标记 | ◆ 出自原文 |
| 考点 | 「必贫困」是他对身后的判断 |

---

### 卡 3 · 论辩

**问：优孟为什么不直接谏，而借「妇言」？**

答：**因为家常话比奏议更容易让庄王听进去。**

他请归与妇计，三日后转述：楚相不值得做——孙叔敖尽忠为廉，助楚王成霸，死后儿子无立锥之地。庄王听到的是「妇言」，不是臣下的批评。

| | |
|---|---|
| 依据 | `023`–`024` |
| 标记 | ◆ 出自原文 |
| 考点 | 批评的是「楚相」这个位置 |

---

### 卡 4 · 细节

**问：优孟的歌把哪两条路都堵死了？**

答：**贪吏与廉吏。**

贪吏有余财，却怕受贿枉法、身死家灭；廉吏奉法守职，到死不敢为非，可孙叔敖廉洁至死，妻子负薪而食。两条路都「安可为也」，问题就落到庄王身上。

| | |
|---|---|
| 依据 | `025` |
| 标记 | ◆ 出自原文 |
| 考点 | 歌是问句，不是结论 |

---

### 卡 5 · 判断

**问：庄王最后的处置为什么是封四百户？**

答：**因为要解决的是祭祀与生计，不是相位。**

「召孙叔敖子，封之寝丘四百户，以奉其祀。后十世不绝。」封地不大，却让孙叔敖的祭祀延续；史家评「此知可以言时矣」。

| 考点 | 不是给孙叔敖平反，是给他儿子一条活路 |
