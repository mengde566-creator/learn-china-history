# 复习卡 · 故事 02 · 更币

> 原则：**问动机，不问年代。**

---

## 故事 02 · 更币（4 张）

---

### 卡 1 · 结构 ★

**问：这一篇从改币写到市复，走了几步？**

答：**四步。**

| 步 | 发生了什么 |
|---|---|
| `007` | 庄王以为币轻，改小为大，百姓不便，皆去其业 |
| `008`–`009` | 市令告市乱三月 |
| `010` | 孙叔敖承诺「吾今令之复矣」 |
| `011`–`012` | 五日后入朝请复旧币；王许之，三日市复 |

| | |
|---|---|
| 依据 | `007`–`012` |
| 标记 | ◆ 出自原文 |
| 考点 | 收回成命也是政绩 |

---

### 卡 2 · 因果 ★

**问：庄王改币，为什么市场乱了？**

答：**因为百姓不便，弃业而去。**

「庄王以为币轻，更以小为大，百姓不便，皆去其业。」市令报告「市乱，民莫安其处，次行不定」，说的是市场次序乱了，不是物价涨跌。

| | |
|---|---|
| 依据 | `007`–`008` |
| 标记 | ◆ 出自原文 |
| 考点 | 底本不记改币的具体形制 |

---

### 卡 3 · 论辩

**问：孙叔敖在朝堂上怎样说？**

答：**引市令原话，请复如故。**

「前日更币，以为轻。今市令来言曰『市乱，民莫安其处，次行之不定』。臣请遂令复如故。」他不添自己的判断，只把事实与请求分开。

| | |
|---|---|
| 依据 | `011` |
| 标记 | ◆ 出自原文 |
| 考点 | 请求的是恢复，不是折中 |

---

### 卡 4 · 细节

**问：乱与复各用了多久？**

答：**乱三个月，复三天。**

市令说「三月顷」；孙叔敖请复之后，「下令三日而市复如故」。两个数字并置，不用评论。

| | |
|---|---|

| 标记 | ◆ 出自原文 |
| 考点 | 改回来比改过去快 |
