# 复习卡 · 故事 01 · 處士

> 原则：**问动机，不问年代。**

---

## 故事 01 · 處士（3 张）

---

### 卡 1 · 结构 ★

**问：这一篇从孙叔敖的身份写到总评，走了几步？**

答：**三步。**

| 步 | 发生了什么 |
|---|---|
| `001`–`002` | 孙叔敖是楚之处士；虞丘相进荐，以自代 |
| `003`–`004` | 三月为楚相，政缓禁止；劝民山采水作 |
| `005`–`006` | 不教而民从其化；三得相不喜，三去相不悔 |

| | |
|---|---|
| 依据 | `001`–`006` |
| 标记 | ◆ 出自原文 |
| 考点 | 全篇没有具体事件，只有身份、政绩与总评 |

---

### 卡 2 · 因果 ★

**问：孙叔敖为什么能由处士为相？**

答：**因为虞丘相推荐他自代。**

「虞丘相进之于楚庄王，以自代也。」处士是没有出仕的士人；他能入相，靠的是现任相的让位与推荐，不是世族。

| | |
|---|---|
| 依据 | `001`–`002` |
| 标记 | ◆ 出自原文 |
| 考点 | 「以自代」是把相位让给他 |

---

### 卡 3 · 判断

**问：「三得相而不喜，三去相而不悔」是在说什么？**

答：**说他对权位的态度。**

得相不喜，因为才具自得；去相不悔，因为不是自己的罪。底本把这句放在全篇末尾作总评，也为后两篇「不轻下令」的做法作注。

| | |
|---|---|
| 依据 | `006` |
| 标记 | ◆ 出自原文 |
| 考点 | 三得三去的具体年月，底本不载 |
