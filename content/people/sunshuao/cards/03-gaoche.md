# 复习卡 · 故事 03 · 高車

> 原则：**问动机，不问年代。**

---

## 故事 03 · 高車（3 张）

---

### 卡 1 · 结构 ★

**问：这一篇只有三段，写了什么？**

答：**王要下令高车，孙叔敖反对，改教闾里高其梱。**

| 步 | 发生了什么 |
|---|---|
| `013` | 楚俗好庳车，王以为不便马，欲令高之 |
| `014` | 孙叔敖说令数下则民不知所从；请教闾里高其梱 |
| `015` | 王许之，半岁民悉自高其车 |

| | |
|---|---|
| 依据 | `013`–`015` |
| 标记 | ◆ 出自原文 |
| 考点 | 不动车制，只动车梱 |

---

### 卡 2 · 论辩 ★

**问：孙叔敖反对发令的理由是什么？**

答：**「令数下，民不知所从。」**

不是「民不便」，是命令太多，百姓无所适从。他提出替代办法：教闾里加高车梱；乘车者皆君子，君子不能屡次下车，自然会改乘高车。

| | |
|---|---|
| 依据 | `014` |
| 标记 | ◆ 出自原文 |
| 考点 | 用不便逼出自愿，不用刑罚 |

---

### 卡 3 · 判断

**问：这一篇与更币篇有什么关系？**

答：**一篇收回已下的令，一篇根本不发令。**

更币是改错，高车是防错；合起来才是「不教而化」的完整意思。底本在处士篇末已有「此不教而民从其化」的评语，这两篇是它的注脚。

| | |
|---|---|
| 依据 | `005`、`012`、`015` |
| 标记 | ○ 合理推演 |
| 考点 | 车梱加高多少，底本不载 |
