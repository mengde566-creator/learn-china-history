# 孫叔敖 · 直譯

> **這一份和故事裡的白話不是一回事。**
>
> 故事裡的白話是給人讀的，可以順語序、補主語；這一份跟著原文的字序和句法走，不替它順句子。
>
> **四條寫法**：
>
> 1. 不補主語；原文承前省略，直譯也省略。
> 2. 官名、禮制、地名第一次出現時，用（　）就地解釋。
> 3. 不合并、不拆分；原文一個句號，直譯一個句號。
> 4. 原文欄逐字照抄 `source.md`。

## 故事 01 · 處士

| 編號 | 原文 | 直譯 |
|---|---|---|
| 001 | 孫叔敖者，楚之處士也。 | 孙叔敖，是楚国的处士（未出仕的士人）。 |
| 002 | 虞丘相進之於楚莊王，以自代也。 | 虞丘相把他进荐给楚庄王，以自代。 |
| 003 | 三月為楚相，施教導民，上下和合，世俗盛美，政緩禁止，吏無奸邪，盜賊不起。 | 三月为楚相，施教导民，上下和合，世俗盛美，政缓禁止，吏无奸邪，盗贼不起。 |
| 004 | 秋冬則勸民山採，春夏以水，各得其所便，民皆樂其生。 | 秋冬就劝民山采，春夏以水（水作），各得其所便，民都乐其生。 |
| 005 | 此不教而民從其化，近者視而效之，遠者四面望而法之。 | 这是不教而民从其化：近者看着效法，远者四面望而取法。 |
| 006 | 故三得相而不喜，知其材自得之也；三去相而不悔，知非己之罪也。 | 所以三得相而不喜，知自己的才具足以自得；三去相而不悔，知不是自己的罪。 |

## 故事 02 · 更幣

| 編號 | 原文 | 直譯 |
|---|---|---|
| 007 | 莊王以為幣輕，更以小為大，百姓不便，皆去其業。 | 庄王以为币轻，改小币为大币，百姓不便，都弃其业。 |
| 008 | 市令言之相曰：「市亂，民莫安其處，次行不定。」 | 市令对相说：「市乱，民没有安于其处的，次行不定。」 |
| 009 | 相曰：「如此幾何頃乎？」市令曰：「三月頃。」 | 相说：「如此多久了？」市令说：「三个月左右。」 |
| 010 | 相曰：「罷，吾今令之復矣。」 | 相说：「罢，我现在就让它恢复。」 |
| 011 | 後五日，朝，相言之王曰：「前日更幣，以為輕。今市令來言曰『市亂，民莫安其處，次行之不定』。臣請遂令復如故。」 | 五日后入朝，相对王说：「前日更币，以为轻。今市令来说『市乱，民没有安于其处的，次行不定』。臣请就下令恢复如故。」 |
| 012 | 王許之，下令三日而市復如故。 | 王许之，下令三日而市复如故。 |

## 故事 03 · 高車

| 編號 | 原文 | 直譯 |
|---|---|---|
| 013 | 楚民俗好庳車，王以為庳車不便馬，欲下令使高之。 | 楚民俗好低车，王以为低车不便马，想下令使车变高。 |
| 014 | 相曰：「令數下，民不知所從，不可。王必欲高車，臣請教閭里使高其梱。乘車者皆君子，君子不能數下車。」 | 相说：「令数次下，民不知所从，不可。王一定要高车，臣请让闾里加高车梱。乘车者都是君子，君子不能屡次下车。」 |
| 015 | 王許之。居半歲，民悉自高其車。 | 王许之。过了半年，民都自己把车加高。 |

## 故事 04 · 優孟

| 編號 | 原文 | 直譯 |
|---|---|---|
| 016 | 優孟，故楚之樂人也。長八尺，多辯，常以談笑諷諫。 | 优孟，是从前楚国的乐人。身长八尺，多辩，常以谈笑讽谏。 |
| 017 | 楚相孫叔敖知其賢人也，善待之。 | 楚相孙叔敖知道他是个贤人，善待他。 |
| 018 | 病且死，屬其子曰：「我死，汝必貧困。若往見優孟，言我孫叔敖之子也。」 | 病将死，嘱咐儿子说：「我死，你必贫困。你去見优孟，说你是孙叔敖之子。」 |
| 019 | 居數年，其子窮困負薪，逢優孟，與言曰：「我，孫叔敖子也。父且死時，屬我貧困往見優孟。」 | 过了几年，其子穷困负薪，路遇优孟，对他说：「我是孙叔敖之子。父亲将死时，嘱咐我贫困时去見优孟。」 |
| 020 | 優孟曰：「若無遠有所之。」即為孫叔敖衣冠，抵掌談語。 | 优孟说：「你不要远走。」就为孙叔敖衣冠（穿上他的衣冠），抵掌谈语。 |
| 021 | 歲餘，像孫叔敖，楚王及左右不能別也。莊王置酒，優孟前為壽。 | 一年多，像孙叔敖，楚王及左右不能分别。庄王置酒，优孟上前为寿。 |
| 022 | 莊王大喜，以為孫叔敖復生也，欲以為相。 | 庄王大喜，以为孙叔敖复生，想用他为相。 |
| 023 | 優孟曰：「請歸與婦計之，三日而為相。」莊王許之。 | 优孟说：「请让我回去与妻子商量，三日后为相。」庄王许之。 |
| 024 | 三日後，優孟復來。王曰：「婦言謂何？」孟曰：「婦言慎無為，楚相不足為也。如孫叔敖之為楚相，盡忠為廉以治楚，楚王得以霸。今死，其子無立錐之地，貧困負薪以自飲食。必如孫叔敖，不如自殺。」 | 三日后，优孟又来。王说：「妇人怎么说？」孟说：「妇人说千万不要做，楚相不值得做。像孙叔敖做楚相，尽忠为廉以治楚，楚王得以霸。如今死了，其子无立锥之地，贫困负薪以自饮食。一定要像孙叔敖，不如自杀。」 |
| 025 | 因歌曰：「山居耕田苦，難以得食。起而為吏，身貪鄙者餘財，不顧恥辱。身死家室富，又恐受賕枉法，為奸觸大罪，身死而家滅。貪吏安可為也！念為廉吏，奉法守職，竟死不敢為非。廉吏安可為也！楚相孫叔敖持廉至死，方今妻子窮困負薪而食，不足為也！」 | 于是唱道：「山居耕田苦，难以得食。出而为吏，身贪鄙者有余财，不顾耻辱。身死家室富，又怕受赇枉法、为奸触大罪，身死而家灭。贪吏怎么做！想为廉吏，奉法守职，到死不敢为非。廉吏怎么做！楚相孙叔敖持廉至死，如今妻子穷困负薪而食，不值得做！」 |
| 026 | 於是莊王謝優孟，乃召孫叔敖子，封之寢丘四百戶，以奉其祀。後十世不絕。此知可以言時矣。 | 于是庄王谢优孟，就召孙叔敖之子，封他寝丘四百户，以奉其祀。后十世不绝。这是知道可以说话的时机。 |
