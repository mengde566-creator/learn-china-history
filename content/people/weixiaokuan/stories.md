# 韦孝宽 · 故事一览

> 六篇。〈韋孝寬傳〉39 段，头是弱冠请为军前驱，尾是七十二岁平尉迟迥当年病卒；中间立得最深的是 546 年那座没被拔掉的玉壁。

---

## 为什么是这几篇

〈韋孝寬傳〉是一篇把二十多年边镇职务排成一条线的传，攻守场面却集中于玉壁六十天与 580 年两个月两处，叙序本身就有主次。要变成可以走进去的故事，每一篇都得落在一个「事后无法回头」的动作上，而这个动作必须是原文写下来的。按这个标准切，原文自己给出了六道坎：

1. **移镇玉壁**——西魏把东境最要的冲城交给这个人；玉壁的姓氏从此挂在他的名下（`005`）。
2. **玉壁守城**——高欢倾山东之众攻城，土山、地道、攻车、火竿、灌柱，每回攻都有每回的现造反制；「城外盡其攻擊之術，孝寬咸拒破之」（`006`–`010`）。
3. **反射募格**——劝降、「能斬城主降者」的募格相继落到城中，孝宽弟子迁被鎖至城下、臨以白刃；他手题书背，把「斬高歡」的赏格射回城外（`011`–`013`）。
4. **高欢病退**——六十天之后，「智力俱困，因而發疾。其夜遁去。後因此忿恚，遂殂」（`014`–`015`）。
5. **三策平齐**——建德之后上疏陈三策，六年后武帝东进，「再駕而定山東，卒如孝寬之策」（`024`–`028`）。
6. **平尉迟迥**——宣帝崩、关东反；他一路侦察、称疾徐行、毁桥道纵退追兵，最后引军至邺，「迥窮迫自殺」，同年十一月薨（`034`–`038`）。

第二篇与第三篇连着读是同一件事的两半：前半问「他为什么守得住」，后半问「他靠什么站直」。第四篇是前两篇的账本，收在敌人一边。第五篇把前线换了地方：不再有城，只有纸上的一篇文章。第六篇是三十四年后的同一个人：先称疾，再毁桥道，再决战。

## 六篇之间的关系

| 篇 | 走的哪一段 | 出口通向哪 |
|---|---|---|
| 01 移镇玉壁 | 接下一座要城，把它变成自己的职务 | 他此后二十年的底座 |
| 02 玉壁守城 | 546 年的攻防，攻到哪、守到哪，当场见技术 | 城守住了；高欢的军队困在城下 |
| 03 反射募格 | 城下的心理战，赏格被原样射回 | 城里士气从此定住（「士卒莫不感勵」） |
| 04 高欢病退 | 六十天攻防的坏账，由敌方签名 | 对手的死把玉壁写进了历史 |
| 05 三策平齐 | 守边二十年的老将在纸上画下灭齐图 | 武帝东进以三策为纲 |
| 06 平尉迟迥 | 年过七旬的最后一战，从侦察到凯旋 | 同年十一月薨，諡曰襄 |

**02 与 03 是同一场守城的两个层面。** 分开写，是因为它们回答的问题相反：前者是工程问题，后者是信心问题。06 与 546 年的玉壁之战相隔三十四年，前后两辈——而两战里作假的都是同一个人：玉壁城下他反射募格，580 年道上他「稱疾徐行」、令橋道毀撤，都在骗对手多为停留。

## 哪一篇可以单独进

**`02-shoucheng`。** 它不依赖前一篇：玉壁为什么是冲城、高欢是谁、攻了多大阵仗，这一篇里自己交代得清。它也是全部六篇里唯一一场「攻到每一件兵器出尽」的完整攻防。

**`03-fanshe` 建议紧接 02 读。** 单看是一封奇怪的书：接在 02 后面，才知道是六十天内守军听到的第几句话。
