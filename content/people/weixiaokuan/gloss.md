# 韦孝宽 · 直译

> **这一份和故事里的白话不是一回事。**
>
> 故事里的白话是**给人读的**：可以顺着现代汉语的语序重排、可以补主语、可以把两句并成一句。
> 这一份是**直译**：跟着原文的字序和句法走，不替它顺句子、不替它补它没说的主语。
>
> **所以它读起来会比故事里的白话生硬——这是有意的。** 它要让人看见原文长什么样：
> 哪一句没有主语、哪一处省略了宾语、哪个词在原文里只是一个字。
> 故事里的白话告诉你「发生了什么」，这一份告诉你「原文是这么说的」。
>
> **四条写法**：
>
> 1. **不补主语。** 原文承前省略，直译也省略（用「（他）」标出来源，不用人名填进去）
> 2. **术语随文注。** 官名、地名、称谓第一次出现时，用（　）就地解释；「皮韛」「排楯」「縵」这类器械词首次出现处也注
> 3. **不合并、不拆分。** 原文一个句号，直译一个句号；`025`–`027` 三策长文照原文的句号一句一句走，不合段
> 4. **阙字与校补照录。** 底本无阙字；页面正文里的校补夹注如「（幽）〔豳〕」原样保留，不替它改成被校改后的字
>
> 段号与 `source.md` 一一对应。**没有直译的段就是还没做**——不是「不需要」。

| 020 | 汾州之北，離石以南，悉是生胡，抄掠居人，阻斷河路。孝寬深患之。而地入於齊，無方誅剪。欲當其要處，置一大城。乃於河西徵役徒十萬，甲士百人，遣開府姚岳監築之。岳色懼，以兵少為難。孝寬曰：「計成此城，十日即畢。既去晉州四百餘里，一日創手，二日偽境始知；設令晉州徵兵，二日方集；謀議之間，自稽三日；計其軍行，二日不到。我之城隍，足得辦矣。」乃令築之。齊人果至南首，疑有大軍，乃停留不進。其夜，又令汾水以南，傍介山、稷山諸村，所在縱火。齊人謂是軍營，遂收兵自固。版築克就，卒如其言。 | 汾州以北，离石以南，都是生胡（生胡，未归附的胡人），抄掠居民，阻断河路。孝宽深以为患。而地入于齐，没有法子诛剪。想要当其要害处，置一座大城。就在河西征发役徒十万、甲士百人，派开府（开府，开府仪同三司的省称）姚岳监督筑城。姚岳面有惧色，以兵少为难。孝宽说：「计成此城，十日即毕。既去晋州四百余里，一日创手，二日伪境始知；设令晋州征兵，二日方集；谋议之间，自稽三日；计其军行，二日不到。我之城隍，足得办矣。」就令筑城。齐人果然到南首，疑心有大军，就停留不进。当夜，又令汾水以南，靠近介山、稷山各村的，所在放火。齐人以为是军营，就收兵自固。版筑（版筑，筑墙的工程）完成，终于如他所说。 |
| 021 | 四年，進位柱國。時晉公護將東討，孝寬遣長史辛道憲啟陳不可，護不納。既而大軍果不利。後孔城遂陷，宜陽被圍。孝寬乃謂其將帥曰：「宜陽一城之地，未能損益。然兩國爭之，勞師數載。彼多君子，寧乏謀猷。若棄崤東，來圖汾北，我之疆界，必見侵擾。今宜於華谷及長秋速築城，以杜賊志。脫其先我，圖之實難。」於是畫地形，具陳其狀。晉公護令長史叱羅協謂使人曰：「韋公子孫雖多，數不滿百。汾北築城，遣誰固守？」事遂不行。天和五年，進爵鄖國公，增邑通前一萬戶。 | 四年，进位柱国（柱国，最高武官勋号）。其时晋公护将要东讨，孝宽派长史辛道宪启陈不可，护不采纳。既而大军果然不利。后来孔城就陷落，宜阳被围。孝宽就对他的将帅说：「宜阳一城之地，未能损益。然两国争之，劳师数载。彼多君子，宁乏谋猷。若弃崤东，来图汾北，我之疆界，必见侵扰。今宜于华谷及长秋速筑城，以杜贼志。脱其先我，图之实难。」于是画地形，具陈其状。晋公护令长史叱罗协对使者说：「韦公子孙虽多，数不满百。汾北筑城，遣谁固守？」事就不行。天和五年，进爵郧国公，增邑通前一万户。 |
| 022 | 是歲，齊人果解宜陽之圍，經略汾北，遂築城守之。其丞相斛律明月至汾東，請與孝寬相見。明月云：「宜陽小城，久勞戰爭。今既入彼，欲於汾北取償，幸勿怪也。」孝寬答曰：「宜陽彼之要衝，汾北我之所棄。我棄彼圖，取償安在？且君輔翼幼主，位重望隆，理宜調陰陽，撫百姓，焉用極武窮兵，搆怨連禍！且滄、瀛大水，千里無烟，復欲使汾、晉之間，橫屍暴骨？苟貪尋常之地，塗炭疲弊之人，竊為君不取。」 | 这一年，齐人果然解了宜阳之围，经略汾北，就筑城守它。他们的丞相斛律明月到汾东，请求与孝宽相见。明月说：「宜阳小城，久劳战争。今既入彼，欲于汾北取偿，幸勿怪也。」孝宽回答说：「宜阳彼之要冲，汾北我之所弃。我弃彼图，取偿安在？且君辅翼幼主，位重望隆，理宜调阴阳，抚百姓，焉用极武穷兵，构怨连祸！且沧、瀛大水，千里无烟，复欲使汾、晋之间，横尸暴骨？苟贪寻常之地，涂炭疲弊之人，窃为君不取。」 |
| 023 | 孝寬參軍曲巖頗知卜筮，謂孝寬曰：「來年，東朝必大相殺戮。」孝寬因令巖作謠歌曰：「百升飛上天，明月照長安。」百升，斛也。又言：「高山不摧自崩，槲樹不扶自豎。」令諜人多齎此文，遺之於鄴。祖孝徵既聞，更潤色之，明月竟以此誅。 | 孝宽的参军曲岩颇懂卜筮（卜筮，占卜），对孝宽说：「来年，东朝必大相杀戮。」孝宽就令曲岩作谣歌说：「百升飞上天，明月照长安。」百升，是斛。又说：「高山不摧自崩，槲树不扶自竖。」令间谍多带此文，遗留在邺。祖孝征既然听到，再加润色，明月终于因此被杀。 |

| 025 | 其第一策曰：臣在邊積年，頗見間隙，不因際會，難以成功。是以往歲出軍，徒有勞費，功績不立，由失機會。何者？長淮之南，舊為沃土，陳氏以破亡餘燼，猶能一舉平之。齊人歷年赴救，喪敗而反，內離外叛，計盡力窮。傳不云乎：「讐有釁焉，不可失也。」今大軍若出軹關，方軌而進，兼與陳氏共為掎角；并令廣州義旅，出自三鵶；又募山南驍銳，沿河而下；復遣北山稽胡絕其并、晉之路。凡此諸軍，仍令各募關、河之外勁勇之士，厚其爵賞，使為前驅。岳動川移，雷駭電激，百道俱進，竝趨虜庭。必當望旗奔潰，所向摧殄。一戎大定，實在此機。 | 他的第一策说：臣在边多年，颇见间隙，不因际会，难以成功。所以往年出军，徒然有劳费，功绩不立，由于失了机会。为什么？长淮以南，原是沃土，陈氏以破亡的余烬，还能一举平定它。齐人历年赴救，丧败而回，内离外叛，计尽力穷。传上不是说过：「仇有衅焉，不可失也。」如今大军若出轵关，并轨而进，兼与陈氏共为掎角（掎角，分兵夹击）；并令广州义旅，出自三鸦；又募山南骁锐，沿河而下；又派北山稽胡断绝他们并、晋的路。凡这些军，仍令各募关、河之外的劲勇之士，厚其爵赏，使他们做前驱。山岳震动、川流移动，雷骇电激，百道俱进，齐趋虏庭。必定望旗奔溃，所向摧殄。一次用兵大定，实在此机。 |
| 026 | 其第二策曰：若國家更為後圖，未即大舉，宜與陳人分其兵勢。三鵶以北，萬春以南，廣事屯田，預為貯積。募其驍悍，立為部伍。彼既東南有敵，戎馬相持，我出奇兵，破其疆埸。彼若興師赴援，我則堅壁清野，待其去遠，還復出師。常以邊外之軍，引其腹心之眾。我無宿舂之費，彼有奔命之勞。一二年中，必自離叛。且齊氏昏暴，政出多門，鬻獄賣官，唯利是視，荒淫酒色，忌害忠良。闔境熬然，不勝其弊。以此而觀，覆亡可待。然後乘間電掃，事等摧枯。 | 他的第二策说：若国家另作后图，不即刻大举，就应与陈人分散他们的兵势。三鸦以北，万春以南，广开屯田，预作贮积。招募他们的骁悍，立为部伍。他们既在东南有敌，戎马相持，我出奇兵，破其疆埸（疆埸，边境）。他们若兴师赴援，我就坚壁清野，等他们去远，再出兵。常以边外的军，牵引其腹心之众。我没有宿舂（宿舂，隔夜捣粮，指转运之费）之费，他们有奔命之劳。一二年中，必自离叛。况且齐氏昏暴，政出多门，鬻狱卖官，唯利是视，荒淫酒色，忌害忠良。全境熬然，不胜其弊。由此看来，覆亡可待。然后乘间电扫，事等摧枯。 |
| 027 | 其第三策曰：竊以大周土宇，跨據關、河，蓄席卷之威，持建瓴之勢。太祖受天明命，與物更新，是以二紀之中，大功克舉。南清江、漢，西龕巴、蜀，塞表無虞，河右底定。唯彼趙、魏，獨為榛梗者，正以有事三方，未遑東略。遂使漳、滏遊魂，更存餘晷。昔勾踐亡吳，尚期十載；武王取亂，猶煩再舉。今若更存遵養，且復相時，臣謂宜還崇隣好，申其盟約。安人和眾，通商惠工，蓄銳養威，觀釁而動。斯則長策遠馭，坐自兼并也。 | 他的第三策说：我私下认为大周的疆宇，跨据关、河，蓄席卷的威势，持建瓴（建瓴，居高倒水，喻势不可挡）之势。太祖受天明命，与物更新，所以二纪（纪，十二年）之中，大功能举。南清江、汉，西龛巴、蜀，塞表无虞，河右底定。只有那赵、魏，独为榛梗（榛梗，草木阻塞，喻障碍），正是因为有事三方，未遑东略。就使漳、滏的游魂，还能苟存余晷（晷，日影，指时日）。从前勾践亡吴，还期望十年；武王取乱，还要两次用兵。如今若再存遵养（遵养，遵养时晦，等待时机），且再相时，臣以为应回崇邻好，申明盟约。安人、和众，通商惠工，蓄锐养威，观衅而动。这就是长策远驭，坐自兼并。 |

| 032 | 大象元年，除徐兗等十一州十五鎮諸軍事、徐州總管。又為行軍元帥，狥地淮南。乃分遣杞公宇文亮攻黃城，郕公梁士彥攻廣陵，孝寬率眾攻壽陽，竝拔之。初孝寬到淮南，所在皆密送誠款。然彼五門，尤為險要，陳人若開塘放水，即津濟路絕。孝寬遽令分兵據守之。陳刺史吳文育果遣決堰，已無及。於是陳人退走，江北悉平。 | 大象元年，授徐兖等十一州十五镇诸军事、徐州总管。又做行军元帅（元帅，战时最高统兵号），略地淮南。就分派杞公宇文亮攻黄城，郕公梁士彦攻广陵，孝宽率众攻寿阳，都攻克。起初孝宽到淮南，所在都秘密送诚款。但那五门，尤其险要，陈人若开塘放水，渡口的路就断绝。孝宽急忙令分兵据守它。陈的刺史吴文育果然派人决堰，已经来不及。于是陈人退走，江北全平。 |

| 034 | 及宣帝崩，隋文帝輔政，時尉遲迥先為相州總管，詔孝寬代之。又以小司徒叱列長义為相州刺史，先令赴鄴。孝寬續進，至朝歌，迥遣大都督賀蘭貴齎書候孝寬。孝寬留貴與語以察之，疑其有變，遂稱疾徐行。又使人至相州求醫藥，密以伺之。既到湯陰，逢長义奔還。孝寬兄子魏郡守藝又棄郡南走。孝寬審訐其狀，乃馳還。所經橋道，皆令毀撤，驛馬悉擁以自隨。又勒（騎）〔驛〕將曰：「蜀公將至，可多備餚酒及芻粟以待之。」迥果遣儀同梁子康將數百騎追孝寬，驛司供設豐厚，所經之處，皆輒停留，由是不及。 | 到宣帝崩，隋文帝辅政，其时尉迟迥先做相州总管，诏孝宽代替他。又任命小司徒叱列长义做相州刺史，先令他赴邺。孝宽继续前进，到朝歌，尉迟迥派大都督贺兰贵带信迎候孝宽。孝宽留住贺兰贵与他说话，借此观察他，疑心有变，就称病慢慢走。又派人到相州求医药，暗中侦察。已到汤阴，遇上长义逃回来。孝宽哥哥的儿子魏郡守韦艺又弃郡南逃。孝宽审问出他的情形，就驰马回。所经过的桥与道路，都令人毁撤，驿马全部收来自随。又勒令（骑）〔驿〕将（底本骑是误字、驿是校改字，此栏照录不改）说：「蜀公将至，可多备肴酒及刍粟以待之。」尉迟迥果然派仪同（仪同，仪同三司的省称）梁子康率数百骑追孝宽，驿司供给丰厚，所经之处，都就停留，因此追不上。 |
| 035 | 時或勸孝寬，以為洛京虛弱，素無守備，河陽鎮防，悉是關東鮮卑，迥若先往據之，則為禍不小。乃入保河陽。河陽城內舊有鮮卑八百人，家竝在鄴，見孝寬輕來，謀欲應迥。孝寬知之，遂密造東京官司，詐稱遣行，分人詣洛陽受賜。既至洛陽，竝留不遣。因此離解，其謀不成。 | 其时有人劝孝宽，认为洛京虚弱，素来没有守备，河阳的镇防，都是关东鲜卑，尉迟迥若先去据守它，就为祸不小。就入保河阳。河阳城内原有鲜卑八百人，家都在邺，见孝宽轻装而来，谋划响应尉迟迥。孝宽知道，就秘密到东京官府，假称遣他们出行，分人往洛阳受赐。到洛阳后，都留住不放。因此离解，他们的谋划不成。 |
| 036 | 六月，詔發關中兵，以孝寬為元帥東伐。七月，軍次河陽。迥所署儀同薛公禮等圍逼懷州，孝寬遣兵擊破之。進次懷縣永〔橋〕城（橋）之東南。其城既在要衝，雉堞牢固，迥已遣兵據之。諸將士以此城當路，請先攻取。孝寬曰：「城小而固，若攻而不拔，損我兵威。今破其大軍，此亦何能為也。」 | 六月，诏发关中兵，以孝宽做元帅东伐。七月，军驻扎河阳。尉迟迥所署的仪同薛公礼等围逼怀州，孝宽派兵击破他们。前进驻扎怀县永〔桥〕城（桥）之东南（底本此处有补字〔桥〕与衍文（桥），此栏照录不改）。那座城既然在要冲，雉堞（雉堞，城上女墙）牢固，尉迟迥已派兵据守它。诸位将士因这城挡在路上，请求先攻取。孝宽说：「城小而固，若攻而不拔，损我兵威。今破其大军，此亦何能为也。」 |
| 037 | 於是引軍次于武陟，大破迥子惇，惇輕騎奔鄴。軍次於鄴西門豹祠之南。迥自出戰，又破之。迥窮迫自殺。兵士在小城中者，盡坑於遊豫園。諸有未服，皆隨機討之，關東悉平。 | 于是引军驻扎武陟，大破尉迟迥的儿子惇，惇轻骑奔邺。军驻扎在邺西门豹祠的南面。尉迟迥亲自出战，又击破他。尉迟迥穷迫自杀。兵士在小城中的，全被坑杀在游豫园。凡有未归服的，都随机讨伐，关东全平。 |
| 038 | 十月，凱還京師。十一月薨，時年七十二。贈太傅、十二州諸軍事、雍州牧。諡曰襄。 | 十月，凯旋回京师。十一月去世，当时年七十二。赠太傅、十二州诸军事、雍州牧。谥叫襄。 |
| 039 | 孝寬在邊多載，屢抗強敵。所有經略，布置之初，人莫之解；見其成事，方乃驚服。雖在軍中，篤意文史，政事之餘，每自披閱。末年患眼，猶令學士讀而聽之。又早喪父母，事兄嫂甚謹。所得俸祿，不入私房。親族有孤遺者，必加振贍。朝野以此稱焉。長子諶年已十歲，魏文帝欲以女妻之。孝寬辭以兄子世康年長。帝嘉之，遂以妻世康。孝寬有六子，總、壽、霽、津知名。 | 孝宽在边多年，屡抗强敌。所有经略，布置之初，人不能理解；见其成事，才惊服。虽然在军中，笃意文史，政事之余，常自己披阅。末年患眼，还令学士读给他听。又早年丧父母，事奉兄嫂很恭谨。所得俸禄，不入私房。亲族有孤遗的，必定加以赈赡。朝野因此称赞他。长子谌年已十岁，魏文帝想把女儿嫁给他。孝宽推辞，以哥哥的儿子世康年长。帝嘉奖他，就把（女）嫁给世康。孝宽有六个儿子，总、寿、霁、津知名。 |
