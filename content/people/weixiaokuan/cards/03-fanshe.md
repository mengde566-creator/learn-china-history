# 复习卡 · 故事 03 · 反射募格

> 原则：**问那一张纸，不问喊话的人。**

---

## 故事 03 · 反射募格（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：六轮攻法用尽之后，对方改用了几种办法？**

答：**四步，一步比一步往城里逼。**

| 步 | 对方做什么 | 冲着谁 |
|---|---|---|
| 一 | 祖孝徵到城下问「未聞救兵，何不降也」 | 守将 |
| 二 | 转口对城中军士喊「何事相隨入湯火中」 | 军士 |
| 三 | 射募格进城，开价斩城主 | 城里任何一个能动刀的人 |
| 四 | 把韦子迁锁到城下，临以白刃 | 守将的亲人 |

**前三步都停在城墙外，第四步把人也押来了。** 底本按这个次序写，一步比一步近。

| | |
|---|---|
| 依据 | `011`「乃遣倉曹參軍祖孝徵謂曰」；`012`「孝徵復謂城中人曰」「乃射募格於城中」；`013`「又鎖至城下，臨以白刃」。四步的排列是照原文次序读的 |
| 标记 | ○ 归纳；**一步比一步往城里逼**是读法，底本不评 |
| 考点 | 前三步要的是城，第四步要的是他这个人 |

---

### 卡 2 · 细节 ★

**问：他答祖孝徵的那段话，句子是怎么排的？**

答：**城 → 兵食 → 劳逸 → 救兵 → 对方 → 自己。**

`011` 的原句次序：先「我城池嚴固」，再「兵食有餘」，再「攻者自勞，守者常逸」，再「豈有旬朔之間，已須救援」，再「適憂爾眾有不反之危」，最后才是「孝寬關西男子，必不為降將軍也」。

**道理全在前，身份在最后一句。** 这样说，落下的是身份，不是情绪。

| | |
|---|---|
| 依据 | `011`「我城池嚴固，兵食有餘，攻者自勞，守者常逸。豈有旬朔之間，已須救援。適憂爾眾有不反之危。孝寬關西男子，必不為降將軍也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「旬朔」是十天与一个月；他答的是**不需要救兵**，不是**救兵会来** |

---

### 卡 3 · 细节 ★

**问：那张募格上写的四个价码是什么？**

答：**官、爵、食邑、帛。**

`012` 写「能斬城主降者，拜太尉，封開國郡公，邑萬戶，賞帛萬疋」——太尉是官，开国郡公是爵，万户是食邑，万疋是帛。

**开价的对象不是守将。** 赏格写给的是守将身边的人：斩了城主，这些就是你的。

| | |
|---|---|
| 依据 | `012`「能斬城主降者，拜太尉，封開國郡公，邑萬戶，賞帛萬疋」 |
| 标记 | ◆ 出自原文 |
| 考点 | 四个价码一层比一层实：官可以夺，爵可以降，食邑与帛是立刻能拿到手的 |

---

### 卡 4 · 细节 ★

**问：「手題書背，反射城外」这八个字，具体是几个动作？**

答：**三个：翻过来、亲手写、射回去。**

`012` 用的是「手題」，不是**答書**——**他没有另起一封，就写在对方射进来的那张纸上。** 然后在背面写「若有斬高歡者，一依此賞」，再射出去。

| | |
|---|---|
| 依据 | `012`「孝寬手題書背，反射城外云」「若有斬高歡者，一依此賞」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「書背」是纸张的背面；「反射」是射回城外，不是退还 |

---

### 卡 5 · 因果

**问：把赏格原样射回去，为什么比另写一封更狠？**

答：**因为纸和价钱都是对方的，他只改了一个人名。**

`012` 先写对方「射募格於城中」，再写他「手題書背，反射城外」。**同一张纸，同一套赏格，只把「斬城主」换成「斬高歡」。**

| | |
|---|---|
| 依据 | `012`「乃射募格於城中」「孝寬手題書背，反射城外云」；两处赏格文字同段。**更狠**是从「手題書背」与「一依此賞」推的读法 |
| 标记 | ○ 合理推演 |
| 考点 | 这一手不靠文辞，靠形式：对方的文书格式替他把话说完了 |

---

### 卡 6 · 细节 ★

**问：弟弟在城下，他的反应与士卒的反应，原文各写了什么？**

答：**两句，一前一后。**

`013` 先写他「慷慨激揚，略無顧意」，再写「士卒莫不感勵，人有死難之心」。

**底本把这两句并排放，没有说前一句是后一句的原因。** 但次序在那里：他先不回头，士卒才人人有死难之心。

| | |
|---|---|
| 依据 | `013`「孝寬慷慨激揚，略無顧意。士卒莫不感勵，人有死難之心」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「略無顧意」是没有回头的顾惜；「感勵」是士卒那一头的变化 |

---

### 卡 7 · 空白

**问：韦子迁后来怎样了？高欢这一手是谁出的主意？**

答：**两件都不在本卷。**

`013` 只写到子迁被锁至城下、临以白刃，此后不再提他。`011` 只写「神武無如之何，乃遣倉曹參軍祖孝徵」，不记这一手出于谁。

| | |
|---|---|
| 依据 | `013` 到「人有死難之心」即止；`012` 只记派遣，不记谋主 |
| 标记 | — 不回答 |
| 考点 | 两处空白性质不同：一处是人的下落，一处是计的来源 |

---

> **这一篇的读法：** 六轮攻城要的是城墙，这一篇要的是城里的人。<br>
> 他的回答只有一张纸：**翻过来，写一个名字，射回去。**
