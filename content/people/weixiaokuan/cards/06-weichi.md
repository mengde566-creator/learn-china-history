# 复习卡 · 故事 06 · 平尉迟迥

> 原则：**问走位，不问兵法。**

---

## 故事 06 · 平尉迟迥（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇五段，他走了哪几处地方？**

答：**五处，一路往东，再一路打回邺城。**

| 段 | 到过的地方 | 做的事 |
|---|---|---|
| `034` | 朝歌、汤阴 | 察贺兰贵、称疾徐行、驰还、毁桥收马 |
| `035` | 河阳 | 入保，调走八百鲜卑 |
| `036` | 怀县永桥城东南 | 破薛公礼，不攻小城 |
| `037` | 武陟、邺城 | 破尉迟惇、破尉迟迥，迥自杀 |
| `038` | 京师 | 凯还，薨 |

**前几篇的核心是**不动**，这一篇的核心是「动」。** 七十二岁的人，最后一场仗靠走位。

| | |
|---|---|
| 依据 | `034`「至朝歌」「既到湯陰」「乃馳還」；`035`「乃入保河陽」；`036`「進次懷縣永〔橋〕城（橋）之東南」；`037`「引軍次于武陟」「軍次於鄴西門豹祠之南」；`038`「凱還京師」 |
| 标记 | ○ 归纳；五处地名都在原文里，串成一条线是读法 |
| 考点 | 先往东走，再掉头往西退，再东伐——方向变了两次，不是一路东进 |

---

### 卡 2 · 细节 ★

**问：「稱疾徐行」四个字里，哪一个是真话？**

答：**没有一个是真话，这是拖时间。**

`034` 先写「疑其有變」，再写「遂稱疾徐行」。**称病是假的，慢走是给人看的。** 同一段还写他「又使人至相州求醫藥，密以伺之」——求医是幌子，侦察是真的。

| | |
|---|---|
| 依据 | `034`「疑其有變，遂稱疾徐行。又使人至相州求醫藥，密以伺之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「密以伺之」的「密」字，说明求医那一趟是公开的、伺察是暗的 |

---

### 卡 3 · 细节 ★

**问：退的路上，他一共设了几道障碍？**

答：**三道，一道比一道阴。**

| 道 | 原文 | 作用 |
|---|---|---|
| 一 | 所經橋道，皆令毀撤 | 让追兵过不来 |
| 二 | 驛馬悉擁以自隨 | 让追兵换不上快马 |
| 三 | 可多備餚酒及芻粟以待之 | 让追兵每到一处就停下来吃 |

**第三条最狠：他不是躲追兵，是给追兵设席。** 结果写在 `034` 末句：「由是不及」。

| | |
|---|---|
| 依据 | `034`「所經橋道，皆令毀撤，驛馬悉擁以自隨」「可多備餚酒及芻粟以待之」「由是不及」 |
| 标记 | ◆ 出自原文 |
| 考点 | 毁桥、收马是硬的，备酒肉是软的；三道并用，追兵是自己停下的 |

---

### 卡 4 · 细节 ★

**问：河阳城里那八百鲜卑，他是怎么处理的？**

答：**不杀，调走，扣下。**

`035`：这八百人的家都在邺城，见他轻骑而来，便「謀欲應迥」。他知道后「密造東京官司，詐稱遣行，分人詣洛陽受賜」，到了洛阳「竝留不遣」——于是「因此離解，其謀不成」。

**又是伪造文书那一手。** 八百人没有反，也没有死一个人。

| | |
|---|---|
| 依据 | `035`「河陽城內舊有鮮卑八百人，家竝在鄴」「詐稱遣行，分人詣洛陽受賜。既至洛陽，竝留不遣。因此離解，其謀不成」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「詐稱」两字是全部关键：他没有查办，也没有动刀 |

---

### 卡 5 · 细节 ★

**问：永桥城挡路，他为什么不打？**

答：**因为攻不下会掉士气。**

`036` 里诸将的理由是「此城當路，請先攻取」；他的回答是「城小而固，若攻而不拔，損我兵威。今破其大軍，此亦何能為也」。

**诸将看到的是**挡路**，他看到的是**打不下来怎么办**。** 这是守了一辈子城的人才有的算法。

| | |
|---|---|
| 依据 | `036`「諸將士以此城當路，請先攻取。孝寬曰：『城小而固，若攻而不拔，損我兵威。今破其大軍，此亦何能為也。』」 |
| 标记 | ◆ 出自原文 |
| 考点 | 他不是轻敌：先说「固」，再算「不拔」的代价，最后才说不必打 |

---

### 卡 6 · 结局 ★

**问：邺城之下，最后一段写了哪几件事？**

答：**破惇、破迥、迥自杀、坑小城兵、关东悉平。**

`037` 的句子连着下来，中间没有一句评语。尤其最后两件：「兵士在小城中者，盡坑於遊豫園」「諸有未服，皆隨機討之，關東悉平」。

**他打赢了，也坑了人。** 底本不替他缓颊。

| | |
|---|---|
| 依据 | `037`「大破迥子惇，惇輕騎奔鄴」「迥自出戰，又破之。迥窮迫自殺」「兵士在小城中者，盡坑於遊豫園」「關東悉平」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「盡坑」的主语是他这一方；读这一篇不能只读前面那几段走位 |

---

### 卡 7 · 收束 ★

**问：从凯旋到去世，原文给了多少字？**

答：**两句，两个月份。**

`038`：「十月，凱還京師。十一月薨，時年七十二。」

**中间那一个月，底本一个字都没有。** 一生的收束，就是两句并列的记事。

| | |
|---|---|
| 依据 | `038`「十月，凱還京師。十一月薨，時年七十二」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「薨」是诸侯、重臣之死的用字；这里与「凱還」并列，不给过渡 |

---

### 卡 8 · 空白

**问：这一篇里，哪些事没有写？**

答：**至少四件。**

| 没写的 | 本卷只有 |
|---|---|
| 他得的什么病 | 十一月薨，時年七十二 |
| 游豫园坑了多少人 | 盡坑於遊豫園 |
| 尉迟迥起兵有多少兵 | 不记 |
| 他死后家中情形 | 不载 |

| | |
|---|---|
| 依据 | `037`、`038` 两段全部内容；上表四项都查不到 |
| 标记 | — 不回答 |
| 考点 | 「盡坑」不给数目，「薨」不给病名——底本对这两处都只给结果 |

---

> **这一篇的读法：** 前四篇他都在同一座城里不动，这一篇他一直在动。<br>
> 称病、驰还、毁桥、备酒、调人、绕城——**最后停在「十一月薨」四个字上。**
