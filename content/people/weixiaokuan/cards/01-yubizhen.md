# 复习卡 · 故事 01 · 移镇玉壁

> 原则：**问动机，不问年代。**

---

## 故事 01 · 移镇玉壁（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇五段，写的是哪几件事？**

答：**五段，一份资格。**

| 段 | 事 | 底本留下的那一句 |
|---|---|---|
| `001` | 家世与父亲 | 世為三輔著姓；父旭，武威郡守 |
| `002` | 自己请战、杨侃嫁女、荆州联璧 | 乃詣闕，請為軍前驅 |
| `003` | 潼关到河桥的一串战事 | 乃令孝寬以大將軍行宜陽郡事 |
| `004` | 一封烧过边的伪书 | 擒道恆及琛等，崤、澠遂清 |
| `005` | 晋州到玉壁 | 尋移鎮玉壁 |

前四段是履历，第五段是落点。**「移鎮玉壁」四个字之后，下一篇的六轮攻守才有地方发生。**

| | |
|---|---|
| 依据 | `001`–`005` 五段依次：家世、请战、战功、伪书、移镇。各段原句见上表 |
| 标记 | ○ 通读五段后归纳；底本没有一句总评 |
| 考点 | 不是**升官记**：五段里有三处是他自己动手做的事（请战、伪书、移镇），不是被动迁转 |

---

### 卡 2 · 细节 ★

**问：「少以字行」是说他从小没有名字吗？**

答：**不是没有名，是名不常用。**

`001` 第一句是「韋叔裕字孝寬，京兆杜陵人也，少以字行」——他名叔裕，字孝宽，从小就以字行世。**后世叫了一千五百年的“韦孝宽”，其实一直是他的字。**

那个**少**字，说明这件事从少年时就定了，不是后来改的。

| | |
|---|---|
| 依据 | `001`「韋叔裕字孝寬，京兆杜陵人也，少以字行」 |
| 标记 | ◆ 出自原文 |
| 考点 | 名与字是两个人称系统；这里能确定的只有「以字行」，为什么这样，本卷不写 |

---

### 卡 3 · 动机

**问：萧宝夤作乱，他为什么自己跑到朝廷去请做前锋？**

答：**本卷不写为什么，只写他去了。**

`002` 只给了一串动作：「弱冠，屬蕭寶夤作亂關右，乃詣闕，請為軍前驅。朝廷嘉之，即拜統軍。」

**去、请、拜，三个动作，中间没有一个字解释动机。** 是家世、是志向、是判断——底本一句都没说。

| | |
|---|---|
| 依据 | `002`「乃詣闕，請為軍前驅。朝廷嘉之，即拜統軍」。动机本卷不载 |
| 标记 | — 不回答 |
| 考点 | 史书写动作不写心思；**主动**可以核对，**为什么主动**核不到 |

---

### 卡 4 · 细节 ★

**问：那封离间牛道恒的伪信，分几步做成？**

答：**四步，一步写在原文里。**

| 步 | 底本的句子 | 做什么 |
|---|---|---|
| 一 | 遣諜人訪獲道恆手迹 | 先弄到牛道恒的亲笔字迹 |
| 二 | 令善學書者偽作道恆與孝寬書 | 找会写这种字的人伪造一封降书 |
| 三 | 又為落燼燒迹，若火下書者 | 把纸边烧出残迹，做成火下匆忙写的 |
| 四 | 還令諜人送於琛營 | 仍由那个间谍送进段琛的营里 |

**注意第三步：伪造已经够了，他还要再烧一下。** 底本把这道工序写出来了，说明它是要紧的一步。

| | |
|---|---|
| 依据 | `004`「乃遣諜人訪獲道恆手迹，令善學書者偽作道恆與孝寬書，論歸款意，又為落燼燒迹，若火下書者。還令諜人送於琛營」 |
| 标记 | ◆ 出自原文 |
| 考点 | 顺序不能颠倒：没有真手迹，伪书不像；没有烧迹，信不像仓促写成 |

---

### 卡 5 · 因果

**问：段琛为什么信了那封信？**

答：**底本只给结果，不给理由。**

`004` 写「琛得書，果疑道恆，其所欲經略，皆不見用」——**「果」字说明这个结果在写书人看来是顺理成章的**，但信里到底哪一点打动了他，底本不写。

可以推的只有一层：手迹是真的，字是照着学的，纸边是烧过的。**三样加起来，才像一封真的降书。**

| | |
|---|---|
| 依据 | `004`「琛得書，果疑道恆，其所欲經略，皆不見用」；伪作三步见同段。**三样加起来**是从这三步推的 |
| 标记 | ○ 合理推演 |
| 考点 | 「果」是史官的判断词，不是段琛的自述；段琛心里怎么想，本卷不载 |

---

### 卡 6 · 词义

**问：联璧是什么意思？为什么用在他和独孤信身上？**

答：**两块玉并在一起。**

`002` 写：「時獨孤信為新野郡守，（司）〔同〕荊州，與孝寬情好款密，政術俱美，荊部吏人，號為聯璧。」

**送这个名号的是「荊部吏人」，不是朝廷。** 理由也写了：情好款密，政术俱美——私交好，政绩也好。

| | |
|---|---|
| 依据 | `002`「荊部吏人，號為聯璧」；同段「情好款密，政術俱美」 |
| 标记 | ○ 训释 |
| 考点 | 名义、送名号的人、理由，三样都在原文里；**两块玉**只是字面 |

---

### 卡 7 · 时间

**问：这一篇从哪一年写到哪一年？**

答：**底本不给公元年份，只给年号。**

这一篇里出现的纪年只有两处：`001` 的「永安二年」与「建義初」（记父亲），`005` 的「大統五年」「八年」（记他自己）。

**中间那些战事，底本一处年份也没写。** 换算成公元是后世系年，不在本卷。

| | |
|---|---|
| 依据 | `001`「建義初」「永安二年」；`005`「大統五年」「八年」。其余各段不记年 |
| 标记 | — 不回答 |
| 考点 | 年号是底本的写法，公元是后人的换算；不要把换算结果挂到原文上 |

---

> **这一篇的读法：** 五段里最重的是最后四个字——「尋移鎮玉壁」。<br>
> 前四段攒下的资格，全部押在这一句之后的那座城上。
