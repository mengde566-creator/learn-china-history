# 复习卡 · 故事 05 · 三策平齐

> 原则：**问条陈，不问忠心。**

---

## 故事 05 · 三策平齐（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：三策是三个并列的办法，还是三层？**

答：**三层，按朝廷愿意花多大力气排。**

| 策 | 主张 | 代价 |
|---|---|---|
| 第一 | 现在就大举，几路齐出 | 最大：要征发、要几路同时动 |
| 第二 | 不大举，屯田耗敌，一两年拖垮他 | 中：要时间、要边军轮转 |
| 第三 | 连屯田也先不做，通商养威，等时机 | 最小：先下聘礼、修邻好 |

**越往后越慢，也越省。** 上疏的人把三种代价都写明，选择权交回朝廷。

| | |
|---|---|
| 依据 | `024`「上疏陳三策」；三策分见 `025`（大举）、`026`（屯田）、`027`（通商养威）。**三层**是照三策的投入大小排的 |
| 标记 | ○ 归纳；**代价大小**是读法，底本不排优劣 |
| 考点 | 三策不是**上中下**三策，底本没有这个说法 |

---

### 卡 2 · 细节 ★

**问：第一策一共点了几条出兵的路？**

答：**五条。**

| 路 | 原文 |
|---|---|
| 主力 | 大軍若出軹關，方軌而進 |
| 南线 | 兼與陳氏共為掎角 |
| 东南 | 廣州義旅，出自三鵶 |
| 沿河 | 山南驍銳，沿河而下 |
| 北面 | 北山稽胡絕其并、晉之路 |

**每一路都从具体的关口出去。** 这不是壮语，是一张可以照着调的兵单。

| | |
|---|---|
| 依据 | `025`「今大軍若出軹關，方軌而進，兼與陳氏共為掎角；并令廣州義旅，出自三鵶；又募山南驍銳，沿河而下；復遣北山稽胡絕其并、晉之路」 |
| 标记 | ◆ 出自原文 |
| 考点 | 掎角是一军在前牵引、一军在后夹击；这里拉上的是南朝的陈 |

---

### 卡 3 · 细节 ★

**问：第二策的核心账目是哪十二个字？**

答：**我無宿舂之費，彼有奔命之勞。**

`026` 的算法：屯田就地取粮，我就不必隔夜舂米转运；对方却要为每一次赴援来回奔跑。

**「宿舂」是军粮转运的耗费。** 十二个字，把屯田的意义算完了。

| | |
|---|---|
| 依据 | `026`「我無宿舂之費，彼有奔命之勞」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一策要的不是打赢，是让对方疲于奔命；「一二年中，必自離叛」是同段的判断 |

---

### 卡 4 · 细节 ★

**问：第三策为什么反而主张先不动手？**

答：**因为它算的是形势，不是士气。**

`027`：「竊以大周土宇，跨據關、河，蓄席卷之威，持建瓴之勢」——形势在我，不必急。所以「宜還崇隣好，申其盟約。安人和眾，通商惠工，蓄銳養威，觀釁而動」。

**一个以守城闻名的人，上疏劝皇帝先通商。** 这一策最不像军人写的。

| | |
|---|---|
| 依据 | `027`「蓄席卷之威，持建瓴之勢」「宜還崇隣好，申其盟約。安人和眾，通商惠工，蓄銳養威，觀釁而動」 |
| 标记 | ◆ 出自原文 |
| 考点 | 建瓴是高屋倒水；等的理由不是弱，是「持建瓴之勢」 |

---

### 卡 5 · 措辞

**问：三策里，他自己说哪一策最好了吗？**

答：**没有。**

三策各用一个「若」起头：`025`「今大軍若出軹關」、`026`「若國家更為後圖」、`027`「今若更存遵養」。

**三个「若」，把决定权交出去。** 他只把三种代价写清，不替朝廷拍板。

| | |
|---|---|
| 依据 | `025`「今大軍若出軹關」；`026`「若國家更為後圖」；`027`「今若更存遵養」 |
| 标记 | ○ 合理推演 |
| 考点 | 「若」是条件句，不是谦辞；三个条件句并排，本身就是不选 |

---

### 卡 6 · 结果 ★

**问：这道疏最后落地了吗？**

答：**落了，五个字：卒如孝寬之策。**

`028` 的次序是：书奏 → 武帝派元伟、伊娄谦重币聘齐 → 尔后大举 → 再驾而定山东 → 卒如孝宽之策。

**注意中间隔了一步聘齐。** 先按第三策走，后来才大举。

| | |
|---|---|
| 依据 | `028`「書奏，武帝遣小司寇淮南公元（衞）〔偉〕、開府伊婁謙等重幣聘齊。爾後遂大舉，再駕而定山東，卒如孝寬之策」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「再駕」是两次出兵；「卒如」是最终合于其策，不是逐条照办 |

---

### 卡 7 · 空白

**问：这道疏的年份、武帝的批答、他是否随军，本卷写了吗？**

答：**都没写。**

`024` 只记「建德之後」，不记年；`028` 只记结果，不载批答；他本人有没有随大军东进，这五段里也没有。

| | |
|---|---|
| 依据 | `024`、`028` 两段的全部内容；上列三项都查不到。他晚年的行迹另见下一篇 |
| 标记 | — 不回答 |
| 考点 | 上疏与用兵之间隔了几年，本卷不给；「建德之後」是一个区间，不是一个时点 |

---

> **这一篇的读法：** 前面几篇看见的是「挡」，这一篇看见的是「算」。<br>
> 算五路怎么出、算粮从哪来、算几年能拖垮对方——**最后只留下五个字的结算。**
