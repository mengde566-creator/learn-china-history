# 复习卡 · 故事 02 · 玉壁守城

> 原则：**问攻守的次序，不问兵数。**

---

## 故事 02 · 玉壁守城（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇五段，攻与守是怎么对上的？**

答：**五段，一段对一段。**

| 段 | 攻 | 守 |
|---|---|---|
| `006` | 城南起土山 | 城上两高楼，縛木接之 |
| `007` | 城南地道、城北土山攻具 | 掘长堑截地道，堑外积柴贮火 |
| `008` | 造攻车 | 縫布為縵，随其所向张设 |
| `009` | 缚松于竿，灌油加火 | 长铁钩，遥割火竿 |
| `010` | 四面穿地二十一道，灌柱烧柱 | 隨崩處竪木柵 |

**没有一段是他先出手的。** 每一段的句序都是攻在前、守在後。

| | |
|---|---|
| 依据 | `006`「乃於城南起土山」「孝寬更縛木接之」；`007`「遂於城南鑿地道」「孝寬復掘長塹」；`008`「城外又造攻車」「孝寬乃縫布為縵」；`009`「城外又縛松於竿」「以鈎遙割之」；`010`「外又於城四面穿地，作二十一道」「竪木柵以扞之」 |
| 标记 | ○ 归纳五段的句序；五段攻守的说法是读出来的，底本只说「攻擊之術」 |
| 考点 | 顺序是判断的依据：他每一段都在对方之后动，但都在城墙被破之前动 |

---

### 卡 2 · 细节 ★

**问：「縛木接之」的「更」字是什么意思？**

答：**再、又——原有的两座楼不够高了。**

`006` 先写「城上先有兩高樓」，再写「孝寬更縛木接之」。**先有的楼是旧的，接到极高峻的是新的。** 一个「更」字，把**原来不够用**这件事说完了。

| | |
|---|---|
| 依据 | `006`「當其山處，城上先有兩高樓。孝寬更縛木接之，命極高峻」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「接」是接高，不是新建；土山有多高，楼就要比它更高 |

---

### 卡 3 · 细节 ★

**问：对付地道，他为什么是「掘長塹」而不是堵洞口？**

答：**因为堑是横着截的，堵不及那么多洞口。**

`007` 写「復掘長塹，要其地道，仍飭戰士屯塹」——**要**是拦截。城外的地道挖到堑就断了，人在堑里等着。

| | |
|---|---|
| 依据 | `007`「孝寬復掘長塹，要其地道，仍飭戰士屯塹」 |
| 标记 | ◆ 出自原文 |
| 考点 | 守的方法是**截住通道**，不是**找到入口**；一个堑管所有地道 |

---

### 卡 4 · 细节 ★

**问：硬的排楯挡不住攻车，一块布为什么能？**

答：**底本只写结果，不写道理。**

`008` 的次序是：攻车「車之所及，莫不摧毀」→ 排楯「莫之能抗」→ 他「縫布為縵」→末句「布既懸於空中，其車竟不能壞」。

**硬的挡不住，换软的。** 至于软的东西怎样卸掉力，底本一个字也没解释。

| | |
|---|---|
| 依据 | `008`「雖有排楯，莫之能抗」「孝寬乃縫布為縵」「布既懸於空中，其車竟不能壞」 |
| 标记 | ◆ 出自原文 |
| 考点 | 不要把后世的力学解释补进底本；「竟」字只是史官的意外语气 |

---

### 卡 5 · 细节

**问：火竿来烧布，他用什么护住布？**

答：**一支长铁钩，隔着距离割。**

`009` 写火竿「規以燒布，并欲焚樓」——上一轮的布，这一轮成了要护的东西。他的办法是「長作鐵鈎，利其鋒刃」，火竿伸来就「以鈎遙割之」，结果「松麻俱落」。

**不是每轮换一套新办法，是把上一轮的办法再护一层。**

| | |
|---|---|
| 依据 | `009`「復長作鐵鈎，利其鋒刃，火竿來，以鈎遙割之，松麻俱落」 |
| 标记 | ○ 合理推演 |
| 考点 | 「遙」字要紧：钩要够长，人不必探出城头 |

---

### 卡 6 · 因果 ★

**问：二十一道地道把城墙烧崩了，他还能守吗？**

答：**能，靠木栅。**

`010` 的次序极清楚：穿地二十一道 → 立梁柱 → 灌油 → 放火 → 柱折 → 城崩 → 他「隨崩處竪木柵以扞之」→「敵不得入」。

**城墙已经坏了，人还在守。** 木栅不是城墙，是一层临时的挡头。

| | |
|---|---|
| 依据 | `010`「柱折，城並崩壞。孝寬又隨崩處竪木柵以扞之，敵不得入」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一段是五段里唯一城被打破的一段；守的含义在这一段变了 |

---

### 卡 7 · 判断

**问：「城外盡其攻擊之術，孝寬咸拒破之」，这两个字该怎么读？**

答：**「盡」与「咸」——一个说攻方用完了，一个说守方全挡了。**

`010` 收在这一句。**这是史官替这场仗下的判语，不是战报。** 它没有写死伤、没有写日数、没有写谁先退。

| | |
|---|---|
| 依据 | `010`「城外盡其攻擊之術，孝寬咸拒破之」 |
| 标记 | ○ 读法 |
| 考点 | 「盡」是全，「咸」也是全；两个绝对字并在一句里，是判断而不是记录 |

---

> **这一篇的读法：** 五段里没有一句他的内心，只有五段问答。<br>
> 攻的人每出一件器具，他就还一件器具——**最后还剩下木栅。**
