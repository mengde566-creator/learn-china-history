# 复习卡 · 故事 04 · 高欢病退

> 原则：**问账目，不问情绪。**

---

## 故事 04 · 高欢病退（6 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 账目 ★

**问：两段八十字，记了哪几笔账？**

答：**一笔攻方的，一笔守方的。**

| 段 | 记的是 | 原文 |
|---|---|---|
| `014` | 攻方：时长、死伤、困、病、遁、殂 | 苦戰六旬，傷及病死者十四五 |
| `015` | 守方：嘉功、遣使、授官、进爵 | 魏文帝嘉孝寬功 |

**攻方的账由敌人签名，守方的账由朝廷结。** 底本把两笔并排放在一起，中间没有一句评论。

| | |
|---|---|
| 依据 | `014`「神武苦戰六旬，傷及病死者十四五」；`015`「魏文帝嘉孝寬功」「進爵建忠郡公」 |
| 标记 | ◆ 出自原文 |
| 考点 | 两段的主体不同：一段写齐神武，一段写韦孝宽 |

---

### 卡 2 · 数字

**问：「十四五」是十四五个，还是十分之四五？**

答：**是十分之四五。**

原文是「傷及病死者十四五」，与「苦戰六旬」并列，说的是比例。**若读成十四五人，这一句就轻得没有意义了。**

| | |
|---|---|
| 依据 | `014`「傷及病死者十四五」。**十四五**是分数；本卷不给具体人数 |
| 标记 | ○ 训释 |
| 考点 | 古书里的「十四五」有两种读法，这里由上下文定：紧接「六旬」，讲的是整场攻守的代价 |

---

### 卡 3 · 因果 ★

**问：他退兵的次序，原文是怎么排的？**

答：**困 → 病 → 夜遁 → 忿恚 → 殂。**

`014` 的原句：「智力俱困，因而發疾。其夜遁去。後因此忿恚，遂殂。」

**先困，后病，再走，最后死。** 五件事排在一句里，因果只用「因而」「因此」两个词连着。

| | |
|---|---|
| 依据 | `014`「智力俱困，因而發疾。其夜遁去。後因此忿恚，遂殂」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「智力俱困」在「發疾」之前：是先没法子，后生病，不是病得没法子 |

---

### 卡 4 · 措辞

**问：能不能说高欢是气死的？**

答：**不能这样说。**

底本给的是「後因此忿恚，遂殂」——**忿恚**是恼恨，**殂**是死。它把两件事连着写，但没有说死因就是恼恨。

**能读到的只有：他为此事恼恨，后来死了。** 再往前一步，底本就不管了。

| | |
|---|---|
| 依据 | `014`「後因此忿恚，遂殂」 |
| 标记 | ○ 合理推演 |
| 考点 | **因此**在这里是**因为这件事**，不是**由此导致**的病理判断 |

---

### 卡 5 · 收束 ★

**问：守方这一头，战后得到的是什么？**

答：**一次劳问，三个名目。**

`015`：「魏文帝嘉孝寬功，令殿中尚書長孫紹遠、左丞王悅至玉壁勞問，授驃騎大將軍、開府儀同三司，進爵建忠郡公。」

**先嘉功，再遣使，再授官，再进爵。** 人没有回朝，赏送到了城下。

| | |
|---|---|
| 依据 | `015`「魏文帝嘉孝寬功，令殿中尚書長孫紹遠、左丞王悅至玉壁勞問，授驃騎大將軍、開府儀同三司，進爵建忠郡公」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「開府儀同三司」是可以自置府署、仪仗同三公；这是打赢一场守城战的价码 |

---

### 卡 6 · 空白

**问：这一篇里，哪些事本卷一个字都没写？**

答：**至少四件。**

| 没写的 | 本卷只有 |
|---|---|
| 高欢死在哪一年、什么地方 | 後因此忿恚，遂殂 |
| 城里守军的伤亡 | 不记 |
| 齐军的具体死亡人数 | 只给「十四五」的比例 |
| 玉壁城下双方的兵力 | 只写「傾山東之眾」 |

| | |
|---|---|
| 依据 | `014`、`015` 两段的全部内容；上表四项在两段里都查不到 |
| 标记 | — 不回答 |
| 考点 | 「傾山東之眾」是形容，不是兵数；比例也不是人数 |

---
