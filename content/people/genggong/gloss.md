# 耿恭 · 直譯

> **這一份和故事裡的白話不是一回事。**
>
> 故事裡的白話是給人讀的，可以順語序、補主語；這一份跟著原文的字序和句法走，不替它順句子。
>
> **四條寫法**：
>
> 1. 不補主語；原文承前省略，直譯也省略。
> 2. 官名、禮制、地名第一次出現時，用（　）就地解釋。
> 3. 不合并、不拆分；原文一個句號，直譯一個句號。
> 4. 原文欄逐字照抄 `source.md`。

## 故事 02 · 疏勒

| 編號 | 原文 | 直譯 |
|---|---|---|
| 017 | 恭以疏勒城傍有澗水可固，五月，乃引兵據之。 | 耿恭因疏勒城旁有涧水可以固守，五月，就引兵据守它。 |
| 018 | 七月，匈奴復來攻恭，恭募先登數千人直馳之，胡騎散走，匈奴遂於城下擁絕澗水。 | 七月，匈奴又来攻耿恭，耿恭募先登数千人直冲，胡骑散走，匈奴于是在城下堵绝涧水。 |
| 019 | 恭於城中穿井十五丈不得水，吏士渴乏，笮馬糞汁而飲之。 | 耿恭在城中打井十五丈不得水，吏士渴乏，压马粪汁来喝。 |
| 020 | 恭仰嘆曰：「聞昔貳師將軍拔佩刀刺山，飛泉湧出；今漢德神明，豈有窮哉。」 | 耿恭仰天叹说：「听说从前贰师将军拔佩刀刺山，飞泉涌出；如今汉德神明，哪有穷尽。」 |
| 021 | 乃整衣服向井再拜，為吏士禱。 | 于是整理衣服向井再拜，为吏士祈祷。 |
| 022 | 有頃，水泉奔出，眾皆稱萬歲。 | 不久，水泉奔出，众人都称万岁。 |
| 023 | 乃令吏士揚水以示虜。 | 于是令吏士扬水给虏看。 |
| 024 | 虜出不意，以為神明，遂引去。 | 虏出其不意，以为神明，就引兵而去。 |

## 故事 04 · 迎歸

| 編號 | 原文 | 直譯 |
|---|---|---|
| 036 | 初，關寵上書求救，時肅宗新即位，乃詔公卿會議。 | 起初，关宠上书求救，当时肃宗新即位，就诏公卿会议。 |
| 037 | 司空第五倫以為不宜救。 | 司空第五伦认为不宜救。 |
| 038 | 司徒鮑昱議曰：「今使人於危難之地，急而棄之，外則縱蠻夷之暴，內則傷死難之臣。誠令權時後無邊事可也，匈奴如復犯塞為寇，陛下將何以使將？又二部兵人裁各數十，匈奴圍之，歷旬不下，是其寡弱盡力之效也。可令敦煌、酒泉太守各將精騎二千，多其幡幟，倍道兼行，以赴其急。匈奴疲極之兵，必不敢當，四十日間，足還入塞。」 | 司徒鲍昱议论说：「如今把人放在危难之地，一急就抛弃，对外是纵容蛮夷之暴，对内是伤了死难之臣。若让权宜一时、以后无边事，那还可以；匈奴若再犯塞为寇，陛下将凭什么使将？又二部兵各才数十人，匈奴围他们，过旬不下，这是他们人少力弱而尽力之效。可令敦煌、酒泉太守各率精骑二千，多设幡帜，倍道兼行，以赴其急。匈奴疲极之兵，必不敢当，四十日间，足可还入塞。」 |
| 039 | 帝然之。 | 帝认为对。 |
| 040 | 乃遣征西將軍耿秉屯酒泉，行太守事；遣秦彭與謁者王蒙、皇甫援發張掖、酒泉、敦煌三郡及鄯善兵，合七千餘人，建初元年正月，會柳中擊車師，攻交河城，斬首三千八百級，獲生口三千餘人，駝驢馬牛羊三萬七千頭。 | 于是派征西将军耿秉屯酒泉，行太守事；派秦彭与谒者王蒙、皇甫援发张掖、酒泉、敦煌三郡及鄯善兵，合七千余人，建初元年正月，会柳中击车师，攻交河城，斩首三千八百级，获生口三千余人，驼驴马牛羊三万七千头。 |
| 041 | 北虜驚走，車師復降。 | 北虏惊走，车师又降。 |
| 042 | 會關寵已殁，蒙等聞之，便欲引兵還。 | 恰逢关宠已死，王蒙等听说，就想引兵还。 |
| 043 | 先是恭遣軍吏范羌至敦煌迎兵士寒服，羌因隨王蒙軍俱出塞。 | 此前耿恭派军吏范羌到敦煌迎兵士寒衣，范羌于是随王蒙军一同出塞。 |
| 044 | 羌固請迎恭，諸將不敢前，乃分兵二千人與羌，從山北迎恭，遇大雪丈餘，軍僅能至。 | 范羌坚决请求迎耿恭，诸将不敢前进，就分兵二千人给范羌，从山北迎耿恭，遇大雪丈余，军队仅能到达。 |
| 045 | 城中夜聞兵馬聲，以為虜來，大驚。 | 城中夜里听到兵马声，以为虏来，大惊。 |
| 046 | 羌乃遙呼曰：「我范羌也。漢遣軍迎校尉耳。」 | 范羌于是远远喊道：「我是范羌。汉朝派军迎校尉罢了。」 |
| 047 | 城中皆稱萬歲。 | 城中都称万岁。 |
| 048 | 開門，共相持涕泣。 | 开门，共同相持涕泣。 |
| 049 | 明日，遂相隨俱歸。 | 第二天，就相随一起回去。 |
| 050 | 虜兵追之，且戰且行。 | 虏兵追击，且战且行。 |
| 051 | 吏士素飢困，發疏勒時尚有二十六人，隨路死沒，三月至玉門，唯餘十三人。 | 吏士一向饥困，从疏勒出发时还有二十六人，沿路死亡，三月到玉门，只剩十三人。 |
