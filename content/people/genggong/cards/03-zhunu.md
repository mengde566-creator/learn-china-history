# 复习卡 · 故事 03 · 煮弩

> 原则：**问动机，不问年代。**

---

## 故事 03 · 煮弩（5 张）

---

### 卡 1 · 结构 ★

**问：这一篇从「救兵不至」写到「单于不能下」，走了几步？**

答：**五步。**

| 步 | 发生了什么 |
|---|---|
| `025`–`027` | 焉耆、龟兹杀陈睦，北匈奴围关宠；明帝崩，救兵不至，车师叛，共攻耿恭 |
| `028` | 后王夫人先世汉人，私告虏情，供给粮饷 |
| `029`–`030` | 数月食尽，煮铠弩食筋革；与士推诚同死生，余数十人 |
| `031`–`032` | 单于知恭已困，许封白屋王、妻以女子 |
| `033`–`035` | 耿恭诱杀使者，炙于城上；单于增兵，不能下 |

| | |
|---|---|
| 依据 | `025`–`035` |
| 标记 | ◆ 出自原文 |
| 考点 | 没有交战，全是围城里的消耗与拒绝 |

---

### 卡 2 · 因果 ★

**问：耿恭为什么要煮铠甲弓弩？**

答：**因为食尽穷困。**

「数月，食尽穷困，乃煮铠弩，食其筋革。」煮的是装备上的筋与革，不是粮食。此前车师叛、救兵不至，后王夫人虽给粮饷，也撑不住数月。

| | |
|---|---|
| 依据 | `026`–`029` |
| 标记 | ◆ 出自原文 |
| 考点 | 「筋革」是弓弩铠甲上的兽筋与皮革 |

---

### 卡 3 · 论辩

**问：单于开的条件是什么？耿恭怎么回答？**

答：**封白屋王、嫁女子；耿恭把使者诱上城杀了，在城上烤。**

「若降者，当封为白屋王，妻以女子。」「恭乃诱其使上城，手击杀之，炙诸城上。」这不是口头拒绝，是让城外所有人看见的回答。

| | |
|---|---|
| 依据 | `032`–`033` |
| 标记 | ◆ 出自原文 |
| 考点 | 诱、手击杀、炙，三步；底本不写他说了什么 |

---

### 卡 4 · 细节

**问：城里还剩多少人？**

答：**数十人。**

「恭与士推诚同死生，故皆无二心，而稍稍死亡，余数十人。」没有写具体数目，也没有写死的是谁；只写人心没有二心。

| | |
|---|---|
| 依据 | `030` |
| 标记 | ◆ 出自原文 |
| 考点 | 「余数十人」是这一篇的兵力，也是下一篇的起点 |

---

### 卡 5 · 判断

**问：后王夫人在这一篇起什么作用？**

答：**她是孤城唯一的城外消息与粮源。**

「后王夫人先世汉人，常私以虏情告恭，又给以粮饷。」底本只记她做什么，不记姓名，也不写她后来如何；这一条线让「救兵不至」不至于变成完全隔绝。

| | |
|---|---|
| 依据 | `028` |
| 标记 | ◆ 出自原文 |
| 考点 | 她帮的是情报与粮，不是兵 |
