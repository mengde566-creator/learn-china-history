# 复习卡 · 故事 01 · 金蒲

> 原则：**问动机，不问年代。**

---

## 故事 01 · 金蒲（5 张）

---

### 卡 1 · 结构 ★

**问：这一篇从耿恭的出身写到匈奴解围，走了几步？**

答：**五步。**

| 步 | 发生了什么 |
|---|---|
| `001`–`005` | 耿恭字伯宗，少孤，有将帅才；随刘张击车师，任戊己校尉，屯金蒲城 |
| `006`–`007` | 到部移檄乌孙，乌孙愿遣子入侍，耿恭发使去迎 |
| `008`–`010` | 匈奴二万骑击车师，三百人往救尽殁；后王被杀，金蒲被攻 |
| `011`–`014` | 毒药傅矢，传语「汉家箭神」，强弩射之，创沸 |
| `015`–`016` | 暴风雨，随雨击之；匈奴以为神，解去 |

| | |
|---|---|
| 依据 | `001`–`016` |
| 标记 | ◆ 出自原文 |
| 考点 | 先立身份与职位，再写第一场守城 |

---

### 卡 2 · 因果 ★

**问：耿恭为什么把毒药涂在箭上，还要先传一句话？**

答：**因为城里兵少，他要让敌人先怕。**

「恭乘城搏战，以毒药傅矢。传语匈奴曰：『汉家箭神，其中疮者必有异。』因发强弩射之。」先传话，再射；中箭的人伤口沸腾，匈奴于是大惊。

| | |
|---|---|
| 依据 | `011`–`014` |
| 标记 | ◆ 出自原文 |
| 考点 | 毒药与「箭神」之说是一套，不是两件事 |

---

### 卡 3 · 战术

**问：三百人出去救车师，为什么回不来？**

答：**因为路上遇到的是大队匈奴骑兵。**

「恭遣司马将兵三百人救之，道逢匈奴骑多，皆为所殁。」二万骑对三百人，底本只记结果，不写交战过程。

| | |
|---|---|
| 依据 | `008`–`009` |
| 标记 | ◆ 出自原文 |
| 考点 | 数字差是这一篇的第一个打击 |

---

### 卡 4 · 细节

**问：金蒲解围，是靠杀退了匈奴吗？**

答：**不是。匈奴是「以为神」而退。**

暴风雨来了，汉军随雨出击，杀伤甚众；匈奴震怖，互相说「汉兵神，真可畏也」，于是解去。底本不写斩首多少，只写敌人的判断。

| | |
|---|---|
| 依据 | `015`–`016` |
| 标记 | ◆ 出自原文 |
| 考点 | 「汉兵神」是匈奴说的话，不是史家评语 |

---

### 卡 5 · 判断

**问：这一篇为什么先写「移檄乌孙」？**

答：**因为它交代耿恭到任后的第一件事，也交代汉朝在西域还有威信。**

乌孙献名马、博具、愿遣子入侍，耿恭派使者去迎。紧接着匈奴就来攻；前面的外交场面越完整，后面的孤城越显眼。

| | |
|---|---|
| 依据 | `004`–`008` |
| 标记 | ○ 合理推演 |
| 考点 | 不要把移檄当成闲笔；它是金蒲被围前的最后一次通使 |
