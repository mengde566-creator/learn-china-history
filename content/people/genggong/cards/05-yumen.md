# 复习卡 · 故事 05 · 玉门

> 原则：**问动机，不问年代。**

---

## 故事 05 · 玉门（5 张）

---

### 卡 1 · 结构 ★

**问：这一篇从郑众上疏写到耿恭卒于家，走了几步？**

答：**五步。**

| 步 | 发生了什么 |
|---|---|
| `053`–`055` | 郑众洗沐易衣冠、上疏请显爵；鲍昱奏节过苏武 |
| `056`–`057` | 拜骑都尉，石修、张封、范羌等各授职；追行母丧，诏释服 |
| `058`–`063` | 迁长水校尉；羌反，率五校士副马防讨羌；十三种降 |
| `064`–`065` | 上言荐窦固、请马防屯汉阳，大忤于防 |
| `066`–`070` | 李谭承旨奏劾，下狱免官，卒于家；子溥战殁，孙为郎 |

| | |
|---|---|
| 依据 | `053`–`070` |
| 标记 | ◆ 出自原文 |
| 考点 | 守城之后是做官，做官之后是免官 |

---

### 卡 2 · 论辩 ★

**问：郑众怎样评价耿恭？**

答：**「恭之节义，古今未有」，请显爵以厉将帅。**

上疏把前几篇压缩成四句：「单兵固守孤城」「凿山为井，煮弩为粮」「出于万死无一生之望」「前后杀伤丑虏数千百计」。这是耿恭回朝时，朝廷方面第一次公开的评价。

| | |
|---|---|
| 依据 | `054` |
| 标记 | ◆ 出自原文 |
| 考点 | 鲍昱另有一句「节过苏武」，两人评价并录 |

---

### 卡 3 · 因果

**问：耿恭立了大功，后来为什么被免官？**

答：**因为他上言荐窦固、替马防安排屯军，忤了马防。**

「由是大忤于防。及防还，监营谒者李谭承旨奏恭不忧军事，被诏怨望。坐征下狱，免官归本郡，卒于家。」底本只写「承旨」，不写是谁的意思。

| | |
|---|---|
| 依据 | `064`–`067` |
| 标记 | ◆ 出自原文 |
| 考点 | 不是战败，是人事 |

---

### 卡 4 · 细节

**问：十三个人回朝后，分别得了什么安排？**

答：**耿恭拜骑都尉；石修为雒阳市丞，张封为雍营司马，范羌为共丞，余九人补羽林。**

「于是拜为骑都尉……余九人皆补羽林。」石修是耿恭的司马，张封、范羌是军吏；跟着他守城的人，都有安置。

| | |
|---|---|
| 依据 | `056` |
| 标记 | ◆ 出自原文 |
| 考点 | 赏的不止主将，连军吏与九人都在内 |

---

### 卡 5 · 判断

**问：这一篇为什么以耿溥战殁、孙辈为郎结束？**

答：**因为耿恭的故事结束了，耿家的将门没有。**

「子溥，为京兆虎牙都尉。元初二年，击畔羌于丁奚城，军败，遂殁。诏拜溥子宏、哗并为郎。」耿恭本人免官卒于家，没有平反；下一代的死与下一代的郎官，是这条线的余音。

| | |
|---|---|
| 依据 | `067`–`070` |
| 标记 | ○ 合理推演 |
| 考点 | 不要把孙辈为郎写成对耿恭的平反 |
