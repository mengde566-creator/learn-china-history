# 复习卡 · 故事 04 · 迎归

> 原则：**问动机，不问年代。**

---

## 故事 04 · 迎归（5 张）

---

### 卡 1 · 结构 ★

**问：这一篇从朝议写到十三人入玉门，走了几步？**

答：**五步。**

| 步 | 发生了什么 |
|---|---|
| `036`–`039` | 关宠上书求救；第五伦说不宜救，鲍昱主张发兵，帝从之 |
| `040`–`041` | 七千余人会柳中、攻交河；北虏惊走，车师复降 |
| `042`–`044` | 关宠已殁，诸将欲还；范羌固请，分兵二千，遇大雪 |
| `045`–`048` | 城中夜闻兵马声；范羌遥呼，开门相持涕泣 |
| `049`–`052` | 且战且行；二十六人发疏勒，至玉门余十三人 |

| | |
|---|---|
| 依据 | `036`–`052` |
| 标记 | ◆ 出自原文 |
| 考点 | 主角从耿恭转到朝廷与范羌 |

---

### 卡 2 · 论辩 ★

**问：鲍昱为什么主张救？**

答：**他把「救不救」说成以后还能不能使将的问题。**

「今使人于危难之地，急而弃之，外则纵蛮夷之暴，内则伤死难之臣……匈奴如复犯塞为寇，陛下将何以使将？」后面还算出兵力与期限：敦煌、酒泉各二千骑，倍道兼行，四十日可还入塞。

| | |
|---|---|
| 依据 | `038` |
| 标记 | ◆ 出自原文 |
| 考点 | 第五伦只有一句「不宜救」，鲍昱给的是制度与算法 |

---

### 卡 3 · 因果

**问：七千兵为什么先打柳中、交河，而不是直接去疏勒？**

答：**因为关宠还被围在柳中，车师也叛了。**

「会柳中击车师，攻交河城」；北虏惊走、车师复降之后，才谈得上西进。等王蒙等听到关宠已殁、想引兵还时，范羌才分兵二千从山北去迎耿恭。

| | |
|---|---|
| 依据 | `040`–`044` |
| 标记 | ◆ 出自原文 |
| 考点 | 柳中与疏勒是两处，救兵先解近的 |

---

### 卡 4 · 细节

**问：城中听到兵马声，为什么先大惊？**

答：**因为他们不知道来的是汉军。**

「城中夜闻兵马声，以为虏来，大惊。」范羌远远喊「我范羌也。汉遣军迎校尉耳」，城中才称万岁、开门涕泣。夜里来的兵马，先被当成敌人。

| | |
|---|---|
| 依据 | `045`–`048` |
| 标记 | ◆ 出自原文 |
| 考点 | 一句话把敌情变成援军 |

---

### 卡 5 · 判断

**问：二十六人到十三人，这个数字说明了什么？**

答：**说明回程也是战斗。**

「发疏勒时尚有二十六人，随路死没，三月至玉门，唯余十三人。衣屦穿决，形容枯槁。」底本不写谁死在路上，只用数字收束；玉门关前的十三人，是这一篇的终点。

| | |
|---|---|
| 依据 | `049`–`052` |
| 标记 | ◆ 出自原文 |
| 考点 | 去时二十六，到时十三 |
