# 复习卡 · 故事 02 · 疏勒

> 原则：**问动机，不问年代。**

---

## 故事 02 · 疏勒（5 张）

---

### 卡 1 · 结构 ★

**问：这一篇从「引兵据疏勒」写到「虏引去」，走了几步？**

答：**五步。**

| 步 | 发生了什么 |
|---|---|
| `017` | 耿恭因疏勒城傍有涧水可固，五月引兵据守 |
| `018` | 七月匈奴复攻，先登数千人直驰，胡骑散走；匈奴绝涧水 |
| `019` | 穿井十五丈不得水，吏士渴乏，笮马粪汁而饮 |
| `020`–`022` | 耿恭引贰师将军刺山事，向井再拜祈祷；水泉奔出 |
| `023`–`024` | 扬水示虏，匈奴以为神明，引去 |

| | |
|---|---|
| 依据 | `017`–`024` |
| 标记 | ◆ 出自原文 |
| 考点 | 全篇的压力在「水」，不在「战」 |

---

### 卡 2 · 因果 ★

**问：匈奴为什么要堵绝涧水？**

答：**因为耿恭守疏勒，靠的就是这股涧水。**

「恭以疏勒城傍有涧水可固，五月，乃引兵据之」；七月匈奴来攻，先登击散胡骑之后，「匈奴遂于城下拥绝涧水」。断水就是拆掉他守城的根据。

| | |
|---|---|
| 依据 | `017`–`018` |
| 标记 | ◆ 出自原文 |
| 考点 | 不是攻城，是断水源 |

---

### 卡 3 · 细节

**问：城中没有水，到了什么程度？**

答：**打井十五丈不见水，吏士压马粪汁来喝。**

「恭于城中穿井十五丈不得水，吏士渴乏，笮马粪汁而饮之。」底本把失败的深度和渴的程度都写出来，不省略。

| | |
|---|---|
| 依据 | `019` |
| 标记 | ◆ 出自原文 |
| 考点 | 「十五丈」是实数，「笮」是压榨 |

---

### 卡 4 · 论辩

**问：耿恭在井边说了什么，做了什么？**

答：**他引贰师将军刺山出泉的旧事，整衣向井再拜，为吏士祈祷。**

「闻昔贰师将军拔佩刀刺山，飞泉涌出；今汉德神明，岂有穷哉。」他没有命令水出来，只是拜；「有顷，水泉奔出，众皆称万岁」。

| | |
|---|---|
| 依据 | `020`–`022` |
| 标记 | ◆ 出自原文 |
| 考点 | 引故事、再拜、祈祷，三步；底本不解释水为什么出 |

---

### 卡 5 · 判断

**问：水出来之后，耿恭为什么还要「扬水示虏」？**

答：**因为退兵的不是水，是城外的判断。**

井水出了，城里人知道；匈奴不知道。耿恭令吏士把水扬起来给匈奴看，匈奴出其不意，以为神明，才引兵去。这一扬，是给敌人看的证据。

| | |
|---|---|
| 依据 | `023`–`024` |
| 标记 | ◆ 出自原文 |
| 考点 | 与金蒲的「箭神」同一手法：先让对方相信 |
