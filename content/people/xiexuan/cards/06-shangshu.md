# 复习卡 · 故事 06 · 上疏自陳

> 原则：**问动机，不问年代。**

---

## 故事 06 · 上疏自陳（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里，他一共做了几次动作？**

答：**三次上疏，加一次上路。**

| 次序 | 事 | 结果 |
|---|---|---|
| 一 | 即路，于道疾笃，上疏 | 疏里自陈本志，求医、求归 |
| 二 | 诏遣高手医一人，使还京口疗疾 | 奉诏便还，病久不差 |
| 三 | 又上疏：同生七人，凋落相继 | 表寝不报 |
| 四 | 前后表疏十余上，久之 | 转授会稽内史；舆疾之郡，卒于官 |

**三次上疏，一次都没换来他想求的那件事。**

| | |
|---|---|
| 依据 | `041`「玄即路，於道疾篤，上疏曰」；`047`「表寢不報」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「前后表疏十余上」是他这一生里最密的一次动作；底本只用一句话交代 |

---

### 卡 2 · 动机 ★

**问：他反复上疏，求的到底是什么？**

答：**求回去，求治病，求看见坟上的柏树。**

| 原文 | 求的 |
|---|---|
| 聽臣所乞，盡醫藥消息 | 让他把药吃到底 |
| 使臣得及視息，瞻睹墳柏 | 活着回去看一眼祖坟 |
| 伏願陛下矜其所訴 | 求一次宽恕 |

**没有一句求官、求赏、求留任。** 他的疏越写越短，求的越来越少。

| | |
|---|---|
| 依据 | `044`「使臣得及視息，瞻睹墳柏」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇里他的请求全部是「退」，而朝廷的答复全部是「挪」 |

---

### 卡 3 · 细节 ★

**问：「驅馳十載」后面那一句，原文是什么？**

答：**「不辭鳴鏑之險，每有征事，輒請為軍鋒。」**

底下还有一句解释：「由恩厚忘軀，甘死若生也。」

| 原文 | 说的是什么 |
|---|---|
| 驅馳十載 | 十年在外 |
| 不辭鳴鏑之險 | 不怕箭 |
| 輒請為軍鋒 | 每次都自己请做前锋 |
| 由恩厚忘軀 | 因为恩厚，所以忘了自己的身子 |

**「輒」是每一次。** 这不是一次请战，是一个习惯。

| | |
|---|---|
| 依据 | `042`「驅馳十載，不辭鳴鏑之險，每有征事，輒請為軍鋒」 |
| 标记 | ◆ 出自原文 |
| 考点 | 他自己给的理由是「恩厚忘軀」；底本照录，不加评语 |

---

### 卡 4 · 细节

**问：「同生七人，凋落相繼」说的是什么？**

答：**七个同母所生的兄弟，一个接一个走了，只剩他一个。**

`046` 记：臣同生七人，凋落相继，惟臣一己，孑然独存。在生荼酷，无如臣比。

**这一句是整篇疏里最不公文的一句。** 它不陈述职务，只陈述家里剩几个人。

| | |
|---|---|
| 依据 | `046`「臣同生七人，凋落相繼，惟臣一己，孑然獨存」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「同生」是同母所生，不是同族；这个字不能读宽 |

---

### 卡 5 · 因果

**问：「表寢不報」是什么意思？**

答：**疏递上去了，搁下了，没有回音。**

| 字 | 意思 |
|---|---|
| 表 | 上给皇帝的疏 |
| 寢 | 搁下、压住 |
| 不報 | 不给答复 |

**这不是驳回，是连驳回都没有。** 底本紧接着写：前后表疏十余上，久之。

| | |
|---|---|
| 依据 | `047`「表寢不報」 |
| 标记 | ○ 训释 |
| 考点 | 「不许」是有答复，「不报」是没有答复；第 05 篇是前者，这一篇是后者 |

---

### 卡 6 · 训释

**问：「瞻睹墳柏」为什么能当请求写进奏疏？**

答：**因为坟上的柏树就是祖坟本身。**

`044` 记：使臣得及视息，瞻睹坟柏，以此之尽，公私真无恨矣。

**「视息」是还能看、还能喘气。** 他把「活着」定义成「能走到坟前看一眼」。

| | |
|---|---|
| 依据 | `044`「瞻睹墳柏」 |
| 标记 | ○ 训释 |
| 考点 | 这一句后面紧接「伏枕悲慨，不觉流涕」；八個字，是这份公文里唯一失态的地方 |

---

### 卡 7 · 结构

**问：「南北二玄」是怎么来的？**

答：**两个同名的玄，同一年到郡。**

`047` 记：时吴兴太守晋宁侯张玄之亦以才学显，自吏部尚书与玄同年之郡，而玄之名亚于玄，时人称为南北二玄，论者美之。

**注意最后四个字：玄之名亚于玄。** 底本自己写明了谁在前。

| | |
|---|---|
| 依据 | `047`「時人稱為南北二玄，論者美之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「名亚于玄」是底本的判断，不是时人的话；两句要分开读 |

---

### 卡 8 · 叙述

**问：全传里他说的最后一句话是什么？**

答：**「我尚生瑍，瑍那得生靈運！」**

`049` 记：瑍少不惠，而灵运文藻艳逸，玄尝称曰：「我尚生瑍，瑍那得生灵运！」

**这是一句夸孙子的话，写在卒年之后。** 底本把他最后一句话，留给了下一代。

| | |
|---|---|
| 依据 | `049`「玄嘗稱曰：我尚生瑍，瑍那得生靈運」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这句话的位置在 048 卒年之后；它不是遗言，是追记 |

---

> **这一篇的读法：** 三段疏，一个「不许」，一个「不报」。<br>
> 他求的都是退，朝廷给的都是挪。
> **最后落到他手上的，是「卒于官」三个字，和一句夸孙子的话。**
