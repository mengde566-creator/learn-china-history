# 复习卡 · 故事 03 · 肥水

> 原则：**问动机，不问年代。**

---

## 故事 03 · 肥水（8 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里，他到底做了哪几手？**

答：**六手，一手比一手险。**

| 次序 | 手 | 结果 |
|---|---|---|
| 一 | 受前锋之任，与谢石、谢琰、桓伊等共八万 | 众凡八万 |
| 二 | 先遣刘牢之五千人直指洛涧 | 斩梁成兄弟，对方步骑崩溃 |
| 三 | 苻坚进屯寿阳，临肥水列阵 | 玄军不得渡 |
| 四 | 遣使对苻融说话：诸君稍却 | 对方麾使却阵 |
| 五 | 以精锐八千涉渡 | 决战肥水南 |
| 六 | 苻坚中流矢，苻融临阵被斩 | 众奔溃，肥水为之不流 |

**第三手过不去，第四手才出现。** 他不是在能打的时候打，是先把条件改掉。

| | |
|---|---|
| 依据 | `017`「詔以玄為前鋒、都督徐兗青三州揚州之晉陵幽州之燕國諸軍事」；`021`「諸君稍卻」 |
| 标记 | ◆ 出自原文 |
| 考点 | 转折不在「勇」，在第四手：一封请对方挪一挪的信 |

---

### 卡 2 · 细节 ★

**问：他派人送给苻融的那句话，原文是什么？**

答：**「君遠涉吾境，而臨水為陣，是不欲速戰。」**

后面还有一句：「諸君稍卻，令將士得周旋，僕與諸君緩轡而觀之，不亦樂乎！」

**这是一封请战书，形式却是邀请。** 它要的不是对方答应，是对方动。

| | |
|---|---|
| 依据 | `021`「君遠涉吾境，而臨水為陣，是不欲速戰」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「緩轡而觀之」四个字最险：他要对方相信这只是一场好看的阵 |

---

### 卡 3 · 因果 ★

**问：对方为什么会「眾因亂不能止」？**

答：**因为他们真的退了，而退的时候阵就散了。**

| 原文 | 说的是什么 |
|---|---|
| 堅眾皆曰：宜阻肥水，莫令得上 | 众将主张守住水 |
| 堅曰：但卻軍，令得過 | 苻坚要的是半渡而击 |
| 融亦以為然，遂麾使卻陣 | 命令下了，旗也挥了 |
| 眾因亂不能止 | 阵一动，止不住 |

**底本把对方的算盘写全了：退是为了让敌人过河再打。** 这不是蠢，是要一场歼灭战。

| | |
|---|---|
| 依据 | `022`「融亦以為然，遂麾使卻陣，眾因亂不能止」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「不能止」三个字，主语是「众」，不是「融」：命令还管用的时候，人已经乱了 |

---

### 卡 4 · 细节

**问：这一篇里有三个数字，各是什么？**

答：**百萬、八萬、八千。**

| 数字 | 出处 | 说的是什么 |
|---|---|---|
| 眾號百萬 | `016` | 号称。不是实数 |
| 眾凡八萬 | `017` | 晋军总数，含谢石、谢琰、桓伊等部 |
| 精銳八千 | `023` | 真正涉渡的 |

**三个数字一层比一层小。** 底本把最小的那个写在第 023 段，紧挨着「涉渡肥水」。

| | |
|---|---|
| 依据 | `016`「眾號百萬」；`017`「眾凡八萬」；`023`「精銳八千」 |
| 标记 | ◆ 出自原文 |
| 考点 | 八万是全军，八千是过河的那一批；把它含糊成全军渡河，就丢了这一段的分量 |

---

### 卡 5 · 训释

**问：「肥水為之不流」是什么意思？**

答：**投水死的人太多，水被堵住，流不动了。**

`025` 记：自相蹈藉投水死者不可胜计，肥水为之不流。

**底本在这里没有给数字，只给了水的状态。** 紧接着的一句是「死者十七八」，那是溃退路上的账。

| | |
|---|---|
| 依据 | `025`「自相蹈藉投水死者不可勝計，肥水為之不流」 |
| 标记 | ○ 训释 |
| 考点 | 这一句常被当成形容战场之壮；底本写的是溃退时的死人数 |

---

### 卡 6 · 训释

**问：「風聲鶴唳」原句写的是什么？**

答：**写的是逃跑路上的耳朵。**

`025` 记：余众弃甲宵遁，闻风声鹤唳，皆以为王师已至，草行露宿，重以饥冻，死者十七八。

| 词 | 本义 | 在这一句里 |
|---|---|---|
| 风声 | 风的声音 | 被听成追兵 |
| 鹤唳 | 鹤叫 | 被听成追兵 |
| 草行露宿 | 睡在草里、露天过夜 | 不敢进村 |

**它不是形容这场仗有多神，是形容溃退的路上死了多少人。**

| | |
|---|---|
| 依据 | `025`「聞風聲鶴唳，皆以為王師已至」 |
| 标记 | ○ 训释 |
| 考点 | 这个成语的出处就在本传；但它的主语是逃的人，不是赢的人 |

---

### 卡 7 · 边界 ⚠️

**问：「投鞭斷流」「草木皆兵」也是这一篇里的吗？**

答：**不是。**

这两句见《晋书·苻坚载记》，不在本传——那是另一卷、另一套编号。

本传写对面之众，只到「眾號百萬」为止；写溃退，只到「風聲鶴唳」为止。

| | |
|---|---|
| 依据 | 见《晉書·苻堅載記》，不在本傳。**本传写对面之众，只有「眾號百萬」一句** |
| 标记 | ○ 外证 |
| 考点 | 三句里只有「風聲鶴唳」和「肥水為之不流」在本传；另两句要另找书，不能挂本传的编号 |

---

### 卡 8 · 叙述

**问：这一篇里，哪些事底本没有回答？**

答：**至少三件。**

| 问题 | 底本 |
|---|---|
| 秦军实数多少 | — `016` 只记「眾號百萬」 |
| 苻融被谁所斩 | — `024` 只记「臨陣斬融」 |
| 这场仗打了几日 | — 本卷不记日数 |

**三处都不是漏写，是这一类史传本来就不记。** 读者问到这里，只能答「本卷不载」。

| | |
|---|---|
| 依据 | `016`「眾號百萬」；`024`「臨陣斬融」 |
| 标记 | — 不回答 |
| 考点 | 「号称百万」与「实数多少」是两个问题；把前者当后者，是这一篇最容易犯的错 |

---

> **这一篇的读法：** 八万对号称百万，过河的只有八千。<br>
> 他做的事不是冲，是**先请对方挪一挪**——对方挪了，阵就散了。
