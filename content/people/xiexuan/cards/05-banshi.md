# 复习卡 · 故事 05 · 上疏送節

> 原则：**问动机，不问年代。**

---

## 故事 05 · 上疏送節（6 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这五段里，他做了几件事？**

答：**四件。一件进，三件退。**

| 次序 | 事 | 结果 |
|---|---|---|
| 一 | 请以先封东兴侯赐兄子玩 | 诏听之，更封玩豫宁伯 |
| 二 | 想布一个局：朱序镇梁国，自己住彭城 | 朝议以为征役既久，宜置戍而还 |
| 三 | 河北生变，自以处分失所，上疏送节 | 诏慰劳，令且还镇淮阴 |
| 四 | 还镇遇疾，上疏解职 | 诏书不许 |

**第二件是进，第三第四件是退。** 而退是他自己发起的。

| | |
|---|---|
| 依据 | `036`「更封玩豫甯伯」；`038`「上疏送節，盡求解所職」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的转折不是兵败，是后方两处叛乱；底本把它写成「河北骚动」四个字 |

---

### 卡 2 · 动机 ★

**问：他为什么要送节？**

答：**底本给了五个字：自以处分失所。**

`038` 记：会翟辽据黎阳反，执滕恬之，又泰山太守张愿举郡叛，河北骚动，玄自以处分失所，上疏送节，尽求解所职。

**「自以」两个字最要紧：是他自己认的，不是朝廷定的。**

| | |
|---|---|
| 依据 | `038`「玄自以處分失所」 |
| 标记 | ◆ 出自原文 |
| 考点 | 兵权不是被夺的，是他上疏送回去的；这一篇整篇都在写这个动作 |

---

### 卡 3 · 细节

**问：「處分失所」四个字，拆开是什么？**

答：**处置、安排，没有落到该落的地方。**

| 字 | 意思 |
|---|---|
| 处分 | 处置、布置 |
| 失 | 没做到 |
| 所 | 该在的位置 |

**他认的不是战败，是布置错了。** 反的是他留守的两个人：翟辽执了滕恬之，张愿举郡叛。

| | |
|---|---|
| 依据 | `038`「自以處分失所」 |
| 标记 | ○ 训释 |
| 考点 | 这四个字是他上疏的理由；底本不写他究竟错在哪一步 |

---

### 卡 4 · 结构

**问：朝议为什么不让他留在彭城？**

答：**一句话：征役既久，宜置戍而还。**

`037` 记：朝议以征役既久，宜置戍而还，使玄还镇淮阴，序镇寿阳。

**留兵守，人回来。** 这不是处分，是收摊。

| | |
|---|---|
| 依据 | `037`「朝議以征役既久，宜置戍而還」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这句话在前，河北之变在后；两件事不要倒过来读成因果 |

---

### 卡 5 · 因果

**问：他上疏解职，朝廷准了吗？**

答：**没有。连着两次都没有。**

| 次序 | 他做的 | 朝廷答的 |
|---|---|---|
| 一 | 上疏送节，尽求解所职 | 诏慰劳，令且还镇淮阴 |
| 二 | 还镇遇疾，上疏解职 | 诏书不许 |
| 三 | 又自陈，虑有旷废 | 诏使移镇东阳城 |

**三次请求，三次都不是「准」。** 最后那一次，是把他挪到另一个城。

| | |
|---|---|
| 依据 | `039`「上疏解職，詔書不許」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「不许」两个字，是这一篇和第 06 篇之间的那道门 |

---

### 卡 6 · 边界

**问：翟辽为什么反？张愿带走了多少人？**

答：**这一篇都不回答。**

`038` 只给了结果：翟辽据黎阳反，执滕恬之；张愿举郡叛，河北骚动。

**没有原因，没有兵数，没有过程。** 底本把两处叛乱压进一句话里。

| | |
|---|---|
| 依据 | `038`「河北騷動」 |
| 标记 | — 不回答 |
| 考点 | 这一篇的重点不是河北怎么乱，是他对这个乱的反应 |

---

> **这一篇的读法：** 北伐推到最远的时候，后方出了事。<br>
> 他没有等朝廷来问，先上疏把节送回去。
> **底本用的词是「自以」——不是被问责，是自己认。**
