# 复习卡 · 故事 01 · 违众举亲

> 原则：**问动机，不问年代。**

---

## 故事 01 · 违众举亲（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里，他做过几件事？**

答：**四件，前两件在家里，后两件在朝廷。**

| 次序 | 事 | 结果 |
|---|---|---|
| 一 | 叔父问子弟之事，诸人莫有言者 | 他答芝兰玉树，安悦 |
| 二 | 少好佩紫罗香囊 | 叔父赌取焚之，于此遂止 |
| 三 | 有经国才略，屡辟不起 | 后被桓温辟为掾，并礼重之 |
| 四 | 朝廷求良将镇北方 | 谢安举他，拜建武将军、领广陵相 |

前两件是家事，后两件才是差事。**底本把四件事按时间排下来，没有一句评语。**

| | |
|---|---|
| 依据 | `001`「安嘗戒約子侄」；`004`「安乃以玄應舉」 |
| 标记 | ◆ 出自原文 |
| 考点 | 第四件才是这一篇的转折：一个人被举上去，举他的是自己的叔父 |

---

### 卡 2 · 动机

**问：谢安为什么举自己的侄子？底本给了理由吗？**

答：**没有给理由，只给了一个动作和两句别人的话。**

```
001  他少年时被叔父器重，答过芝兰玉树那一句
003  长大后有经国才略，屡辟不起；后被桓温辟为掾
004  朝廷求良将，安乃以玄应举
```

「安乃以玄應舉」五个字，是一个动作，不是一条理由。

**从「器重」到「应举」，中间没有一步是底本写明的。**

| | |
|---|---|
| 依据 | `004`「安乃以玄應舉」 |
| 标记 | ○ 合理推演 |
| 考点 | 郗超说「安違眾舉親，明也」，那是郗超的评语；把它当成谢安的理由，就多走了一步 |

---

### 卡 3 · 细节 ★

**问：「違眾舉親」四个字，拆开是什么？**

答：**违背众人的意见，推举自己的亲人。**

| 字 | 意思 | 为什么重要 |
|---|---|---|
| 违 | 违背 | 反对的不是一个人，是「众」 |
| 众 | 众人的意见 | 下一句就写「時咸以為不然」 |
| 举 | 推举 | 举的是一个人的名字 |
| 亲 | 自己的亲人 | 举的是侄子 |

**两个字评价这件事：明、才。** 说这话的人，素来与他不善。

| | |
|---|---|
| 依据 | `004`「安違眾舉親，明也」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「违众」与「举亲」是同一件事的两面；把它读成单纯的任人唯亲，就丢了「违众」 |

---

### 卡 4 · 因果

**问：为什么「時咸以為不然」，郗超反而叹服？**

答：**因为他的理由不是人情，是他见过这个人办事。**

| 原文 | 说的是什么 |
|---|---|
| 雖素與玄不善，聞而歎之 | 两人关系不好，他仍然叹服 |
| 吾嘗與玄共在桓公府，見其使才 | 理由是亲眼见过 |
| 雖履屐間亦得其任 | 连小事都派得对 |

**底本让他自己把理由说完。** 这一篇里唯一一段完整的推理，出自一个外人。

| | |
|---|---|
| 依据 | `004`「雖素與玄不善，聞而歎之」；`005`「吾嘗與玄共在桓公府，見其使才，雖履屐間亦得其任」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「不善」与「歎之」并置；关系不好的人作证，比朋友作证重 |

---

### 卡 5 · 细节

**问：香囊那件事，叔父用的是什么办法？**

答：**赌。**

```
玄少好佩紫羅香囊
安患之，而不欲傷其意
因戲賭取，即焚之
於此遂止
```

四行里没有一个「禁」字、一个「责」字。**他没有当面没收，是赌赢了再烧的。**

| | |
|---|---|
| 依据 | `002`「因戲賭取，即焚之，於此遂止」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「不欲傷其意」五个字，是这件事的做法，也是这个人的做法 |

---

### 卡 6 · 训释

**问：拜官那一串名目里，哪一个给了兵？**

答：**建武将军是武号，兖州刺史、广陵相是官，带兵的是最后那一个。**

`006` 记「拜建武將軍、兗州刺史、領廣陵相、監江北諸軍事」。

**「監……諸軍事」是差遣，管的是军。** 前面的名目是位子，后面这一句才是兵。

| | |
|---|---|
| 依据 | `006`「拜建武將軍、兗州刺史、領廣陵相、監江北諸軍事」 |
| 标记 | ○ 训释 |
| 考点 | 官与差遣是两套；底本把兵放在最后一名目上，不是随手排的 |

---

### 卡 7 · 叙述

**问：这一篇里，他说的第一句话是什么？**

答：**「譬如芝蘭玉樹，欲使其生於庭階耳。」**

那时他还是个少年，叔父戒约子侄，问了一句「子弟亦何豫人事，而正欲使其佳」，诸人莫有言者。

**他答了一句比喻，叔父「悅」。** 底本记他少年时的话，只记到这一处。

| | |
|---|---|
| 依据 | `001`「玄答曰：譬如芝蘭玉樹，欲使其生於庭階耳」「安悅」 |
| 标记 | ◆ 出自原文 |
| 考点 | 全篇他开口两次，一次是少年，一次没说；「玄答曰」是史官的转述框架，不是他的自称 |

---

> **这一篇的读法：** 四件事，两个动作。<br>
> 一个是叔父把一个香囊赢走烧掉，一个是叔父把他的名字举上去。
> **同一双手，先管他的佩饰，后管他的前程。**
