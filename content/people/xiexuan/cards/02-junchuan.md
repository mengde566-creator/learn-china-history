# 复习卡 · 故事 02 · 守淮

> 原则：**问动机，不问年代。**

---

## 故事 02 · 守淮（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里，他办了几件差事？**

答：**五件，一件接着一件往南压。**

| 次序 | 事 | 结果 |
|---|---|---|
| 一 | 诏发三州人丁，遣何谦游军淮泗为形援 | 牵制，不是主力 |
| 二 | 襄阳没后，驻泗口，想派间使报彭城 | 其道无由，报不进去 |
| 三 | 扬声要打留城 | 彭超还保辎重，何谦驰进，解彭城围 |
| 四 | 盱眙陷落、朝廷震动，自广陵西讨 | 解田洛围，斩都颜、邵保 |
| 五 | 追到君川 | 复大破之，对方仅以身免 |

**前两件是布置，第三件是解围，第四五件才是野战。** 底本按时间排，没有一句评语。

| | |
|---|---|
| 依据 | `007`「遣彭城內史何謙遊軍淮泗，以為形援」；`015`「進號冠軍，加領徐州刺史」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的起点不是战功，是「形援」两个字：他先被派去做疑兵 |

---

### 卡 2 · 细节 ★

**问：田泓临死前在城下喊的那一句，原文是什么？**

答：**「南軍垂至，我單行來報，為賊所得，勉之！」**

| 阶段 | 底本写的 |
|---|---|
| 请行 | 小将田泓请行 |
| 被获 | 没水潜行，为贼所获 |
| 受赂 | 贼厚赂泓，使说南军已败；泓伪许之 |
| 喊话 | 告城中：南军垂至，我单行来报，为贼所得，勉之 |
| 结局 | 遂遇害 |

**他答应过的话，和他喊出来的话，正好相反。** 底本把这两句并排放在一段里。

| | |
|---|---|
| 依据 | `009`「南軍垂至，我單行來報，為賊所得，勉之」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「伪许之」三个字是关键：他不是当场拒绝，是先答应了再反口 |

---

### 卡 3 · 因果

**问：为什么扬声要打留城，彭城的围就解了？**

答：**因为对方的辎重在那里。**

```
超置輜重於留城
玄揚聲遣謙等向留城
超聞之，還保輜重
謙馳進，解彭城圍
```

**四步一步不缺。** 打的是辎重，救的是城，中间那一步是对方自己走回来的。

| | |
|---|---|
| 依据 | `010`「玄乃揚聲遣謙等向留城。超聞之，還保輜重」 |
| 标记 | ◆ 出自原文 |
| 考点 | 底本用「揚聲」两个字，说明这一手是假动作；真动的是何谦那一支 |

---

### 卡 4 · 动机

**问：田泓为什么请行？**

答：**这一篇一个字都没写。**

`009` 只有五个字记他的动机位置：「小將田泓請行。」

**没有理由，没有对话，没有一句他心里的话。** 后面直接就是他没水潜行、被获、受赂、喊话、遇害。

| | |
|---|---|
| 依据 | `009`「小將田泓請行」 |
| 标记 | — 不回答 |
| 考点 | 史书不写动机，不等于没有动机；这里不替他补一个 |

---

### 卡 5 · 结构

**问：盱眙城陷那一天，军里出了什么事？**

答：**不是打散，是惊散。**

`012` 记：盱眙城陷，高密内史毛藻没，毛安之等军人相惊，遂各散退，朝廷震动。

**「相惊」两个字：没有人打他们，他们自己惊了。** 这一句之后，才是他自广陵西讨。

| | |
|---|---|
| 依据 | `012`「安之等軍人相驚，遂各散退，朝廷震動」 |
| 标记 | ◆ 出自原文 |
| 考点 | 底本把「城陷」和「军惊」分成两句写；散退的原因不是战败 |

---

### 卡 6 · 细节

**问：「僅以身免」四个字，说的是谁？**

答：**说对方的主将，不是说自己的兵。**

`014` 记君川大破之后：难等相率北走，仅以身免。

**能走的只有他们自己。** 底下的人、辎重、浮航、白船、运舰，前面都写了被谁破掉。

| | |
|---|---|
| 依据 | `014`「難等相率北走，僅以身免」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「身免」是免于被俘，不是免于损失；这一篇没有记斩获数字 |

---

### 卡 7 · 因果

**问：打赢了，朝廷第一件事做的是什么？**

答：**罢戍。**

`015` 的第一句是「於是罷彭城、下邳二戍」，然后才是遣使慰劳、进号冠军、加领徐州刺史、封东兴县侯。

**先撤掉两个戍，再论功。** 底本把这两件事写在同一段里，顺序不是随手排的。

| | |
|---|---|
| 依据 | `015`「於是罷彭城、下邳二戍」 |
| 标记 | ◆ 出自原文 |
| 考点 | 战功与撤防是同一段的两半：打回来的地方，不一定留着守 |

---

> **这一篇的读法：** 一封信送不进去，一个人替它送了命。<br>
> 底本给他的评价只有一句：**「僅以身免」是说对方，不是说自己。**
