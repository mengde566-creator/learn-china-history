# 复习卡 · 故事 04 · 北定四州

> 原则：**问动机，不问年代。**

---

## 故事 04 · 北定四州（7 张）

复习节奏建议：**读完当天 → 第 3 天 → 第 7 天**

---

### 卡 1 · 结构 ★

**问：这一篇里，北伐走了几步？**

答：**六步，从彭城一路推到河北。**

| 次序 | 事 | 结果 |
|---|---|---|
| 一 | 谢安奏苻坚丧败，宜乘其衅会；以玄为前锋都督 | 受命北上 |
| 二 | 进驻彭城，遣刘袭攻张崇于鄄城 | 走之，使刘牢之守鄄城 |
| 三 | 兖州既平，堰吕梁水，立七埭 | 自此公私利便 |
| 四 | 进伐青州，高素三千向广固 | 苻朗降 |
| 五 | 进伐冀州，据碻磝、滑台，颜雄渡河立营 | 三魏皆降 |
| 六 | 兖青司豫平 | 加督七州，封康乐县公 |

**第二步是打，第三步是修水。** 底本把修水写在打城中间，不是插叙。

| | |
|---|---|
| 依据 | `028`「以玄為前鋒都督」；`035`「以勳封康樂縣公」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一篇的动作不全是攻城；立埭、树栅、通漕运占了整整一段 |

---

### 卡 2 · 细节 ★

**问：堰水那件事，底本是怎么写的？**

答：**「堰呂梁水，樹柵，立七埭為派，擁二岸之流，以利運漕。」**

| 动作 | 做的什么 |
|---|---|
| 堰 | 在吕梁水上筑堰，把水位抬起来 |
| 树栅 | 打桩立栅，护住水道 |
| 立七埭 | 分成七道挡水的埭 |
| 为派 | 把水拆成几股分流 |
| 拥二岸之流 | 把两岸的水拢住 |

**后面八个字是结果：「自此公私利便。」**

| | |
|---|---|
| 依据 | `030`「堰呂梁水，樹柵，立七埭為派，擁二岸之流，以利運漕」 |
| 标记 | ◆ 出自原文 |
| 考点 | 五个动词都是工程动作；这一段是全传里唯一一段水工 |

---

### 卡 3 · 因果

**问：一个将军的传里，为什么会写水工？**

答：**因为粮运不上来，打下来的地方也留不住。**

```
玄患水道險澀，糧運艱難
用督護聞人奭謀
堰呂梁水，樹柵，立七埭
自此公私利便
```

**底本先写「患」，再写「谋」，再写工程，最后写结果。** 四步是一条链，不是一段闲笔。

| | |
|---|---|
| 依据 | `030`「自此公私利便」 |
| 标记 | ○ 合理推演 |
| 考点 | 「公私利便」四个字，说明受益的不只是军；这是他能站住的原因 |

---

### 卡 4 · 细节

**问：「走之」和「降」不是一个字，差在哪里？**

答：**一个是赶跑，一个是过来。**

| 原文 | 对象 | 结果 |
|---|---|---|
| 攻堅兗州刺史張崇于鄄城，走之 | 张崇 | 跑了，城归晋 |
| 降堅青州刺史苻朗 | 苻朗 | 降了，人还在 |

**同一篇里两种收场。** 底本用字很省，但从不混用。

| | |
|---|---|
| 依据 | `029`「攻堅兗州刺史張崇于鄄城，走之」；`031`「降堅青州刺史苻朗」 |
| 标记 | ◆ 出自原文 |
| 考点 | 「走之」的主语是对方，「降」的主语也是对方；他这一边只出了兵 |

---

### 卡 5 · 结构

**问：加督七州之前，他先做了一件什么事？**

答：**上疏改区划。**

`035` 记：以兖、青、司、豫平，加玄都督徐、兖、青、司、冀、幽、并七州军事。玄上疏以方平河北，幽冀宜须总督，司州县远，应统豫州。以勋封康乐县公。

**加官与上疏写在同一段里，顺序是先受官、后上疏。** 他改的是谁管哪一块。

| | |
|---|---|
| 依据 | `035`「玄上疏以方平河北，幽冀宜須總督，司州縣遠，應統豫州」 |
| 标记 | ◆ 出自原文 |
| 考点 | 这一段里他谈的不是战功，是辖区怎么划；这是文官的事，不是将军的事 |

---

### 卡 6 · 训释

**问：「埭」和「派」分别是什么？**

答：**埭是挡水的堰，派是分出去的水路。**

`030` 记「立七埭為派」。七道埭把一条水拆成几股，船就能一段一段过。

**这是江南通漕的老办法。** 底本只写「为派」，不写各埭的位置。

| | |
|---|---|
| 依据 | `030`「立七埭為派，擁二岸之流，以利運漕」 |
| 标记 | ○ 训释 |
| 考点 | 这两个字是技术词；读不懂它们，就看不出这一段为什么写在战功中间 |

---

### 卡 7 · 因果

**问：苻丕说饿，他为什么给米？**

答：**因为对方已经要降了。**

`033` 记：丕告饥，玄馈丕米二千斛。

前一句是「丕惶遽欲降，玄许之」。

**先许降，再给米。** 二千斛不是赏赐，是把一个要降的人稳住。

| | |
|---|---|
| 依据 | `033`「丕告饑，玄饋丕米二千斛」 |
| 标记 | ◆ 出自原文 |
| 考点 | 底本不写他为什么给；能确定的只有顺序：许降在前，馈米在后 |

---

> **这一篇的读法：** 打赢之后往北推了一整年。<br>
> 最要紧的一段不是攻城，是**在吕梁水上立了七道埭**——
> 没有那七道埭，前面打下的城守不住。
