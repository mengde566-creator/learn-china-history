## 为什么自己做子集，而不是用 fontsource 的现成分片

fontsource 把中文字体切成 **92 个 unicode-range 分片**，浏览器按需下载。看起来省事，但：

> **"哪一片里有哪些字"是个查表问题。**
> 每次想换一个字，都得跑一次查询才知道要引哪一片。
> 那个知识只存在于某次查询的输出里，**不在代码里**。

我一开始就是这么干的——为了省体积，专门挑"最便宜的那一片"选字。
结果：**68.2 KB 买到一个不知道装了哪些字的文件**，而且加一个字就要加一条 `@font-face`。

自己做子集反过来：

| | fontsource 分片 | 自己子集 |
|---|---|---|
| 体积 | 68.2 KB | **18.2 KB** |
| 覆盖 | ~30 字（**不知道是哪 30 个**） | **61 字，字表写在文件里** |
| 加字 | 查表 → 引新分片 → 加 `@font-face` | **改一行字表，跑一条命令** |
| 换字成本 | 要重新算体积 | **几乎为零**（一个汉字几百字节） |

**结论：省下来的是 KB，赔进去的是可维护性。而 KB 不值钱。**
