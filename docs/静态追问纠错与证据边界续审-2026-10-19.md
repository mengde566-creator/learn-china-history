# 静态追问纠错与证据边界续审 · 2026-10-19

本轮处理独立复审F01列出的具体实例及同一主题的重复出口。核心是让读者能从回答中得到可靠事实和已有理由，不以无据台词、现场动作或时间推定填空，也不把所有理由一律抹成“未载”。

开始时工作区干净，3100为本项目生产服务。实际打开手机页面，确认旧回答仍将田光转告死讯答成“没有”，将敌方被杀人数放在曹军伤亡题下，以及将白衣安排解释为众人自行决定。范围提示、推论标记均未能取消这些已经显示的说法。

## 复审所列实例与处理

| 具体问题 | 核对与修订 |
|---|---|
| 田光死讯是否转告太子 | 026明确记荆轲转告太子并致田光之言。回答据实补出，不再以范围说明配合人物断言“没有”；同篇太子是否听到死讯的另一问同步。 |
| 官渡千余名士卒是谁的人 | 244为裴注引《曹瞒传》，在曹军围屯焚粮后记杀戮、割鼻示袁军，属于对方士卒。曹军当夜阵亡数未由这两段给出；保留暴力事实与来源，不换受害者。 |
| 距袁营北四十里为何能说粮车一天行程 | 044给相对宿处，不给车速、行程天数及选址理由。删掉“正好一天”，保留有据位置。 |
| 白衣冠是谁安排 | 054记太子及知情宾客的装束，没有交代安排者。既不认定太子下令，也不反向补成宾客自主决定。 |
| 高渐离是否预知荆轲不归 | 055、056有击筑与歌辞，没有记他的私人归期判断。删除看白衣的目光动作，说明歌辞与个人判断的区别。 |
| 鞠武是否一句建议都未获采纳 | 013、014的送樊方案被拒，015、016的荐田光与请求介绍则有后续。相关题面限定为送樊方案，回答保留两者区别；第二篇“荐完没有之后”也修正。另补回“智深而勇沉，可与谋”的明载推荐理由。 |
| 献出的首级被写成丹的头 | 047装函的是樊於期首级。题面改为“献樊於期的头，就能救下燕国吗”，回答对接040取得进见机会的计划，不把献首等同救国已成。 |
| 太子若亲往，父王第二天知道 | 032–034记太子提出计划、荆轲推辞后许诺，不记太子未亲往的解释。删除具体翌日推定。 |
| 樊於期自述日夜切齿的起点 | 043、046表现痛苦、激愤与日夜思念，没有给具体起始日期。删除“到燕国那天起”，保留自述本身。 |

这些问题包含确定的对象混淆、与记载冲突、证据不足和题面范围不清，不能一概称作已证实相反的历史事实。例如没有记录衣着安排者，不证明当时一定没有安排。

| 篇目 | 修订条数 | 同步内容 |
|---|---|---|

| 荆轲《田光之死》 | 4 | 死讯两问、荐田光的后续、偻行与田光自述衰老分清，不捏造荆轲对往日步态的回忆。 |

29条不等于29个独立史实错误。同主题的多条回答可能重复同一个问题。没有用只改标记代替修改主句；有记载的动作、建议与理由继续保留。五份稿件的标记统计同步，去掉将旧拒答比例当作文献特征的过时说明。

## 对读材料与归属

本轮重新查阅[《史记三家注》卷八十六](https://zh.wikisource.org/wiki/史記三家註/卷086)的荐田光、转告、献首、日夜切齿与白衣送行段。上述事实均分别对应《刺客列传》正文，未把后世释义伪装成现场记事；对衣着安排者的判断只限所列送行句，没有断言所有其他文献都不曾说明。

另对读[带注《三国志》卷一](https://zh.wikisource.org/wiki/三國志/卷01)官渡段：044属于《武帝纪》正文，244属于裴注引《曹瞒传》。焚粮建议归书中许攸说辞，营中惊乱、割鼻与杀士卒等归该书补记，不冒充陈寿本纪逐项写出或现代独立统计。

以上采用可访问的电子录文，不冒称纸本或影印原刻逐页校勘。对“未载”的处理限定于所列段落，不扩大成任何史书均无记载。也不把记录下来的建议等同人物全部未说出的私心。
